# T3 테라포밍 전체 구현 항목 — 탐험 콘텐츠 제외

2026-09-09. 최초 사용자 요청으로 정리한 구현 범위이며, 후속 **커밋·개발 요청에 따라 T3-01~10의 첫 전체 묶음을 구현했다.** 실제 기능·검사·수급 밸런스와 획득 콘텐츠의 연결 경계는 [T3 제작 기록](../production/100-tier3-terraforming.md)을 따른다. 아래 표의 초기 수치/구성 제안과 실제 데이터 값을 구분한다. 지역 사업 규칙의 소관은 [지역 테라포밍](../game/20-regional-terraforming-and-surface-supply.md), 제품·설비는 [생산 단계](../game/15-terraforming-production-progression.md), 설계도 정책은 [경제·해금](../game/05-economy-and-progression.md)을 따른다.

T3의 핵심은 **계속 유입되는 문제의 원인을 현장에서 억제하고, 영향받은 지역을 복원해 유지하는 사업**이다. T2보다 시설 수·원료량·시간만 늘리는 방식으로 만들지 않는다. 설계도를 확보한 뒤 수급→제작→현장 배치→원인 제어→영향 지역 복원→정산까지 한 사업으로 연결하는 것을 완료 범위로 잡는다.

## 1. 출발점과 다른 작업의 경계

현재 Mk.3 제작소, 고합금 프레임·저온 전해 셀·산업 코어, 직접 운송과 부재중 생산이 있다. 새 세계 T1/T2의 지역별 재고·전력·환경·중간 보상과 Tab 지도도 있다. 당시 출발점에는 T3 지역 사업과 전문 환경 설비가 없고 `facility_factory_mk3`만 있었다. 후속 구현에서 네 현장·두 문제 유형·전문 개조/제어 장치와 6개 설계도 정의로 확장했다.

다른 작업 담당: 유적·발견물·사건·전투·생물 발견·설계도 획득 및 획득 경로로서의 정거장 판매. 이 계획에서는 해당 콘텐츠를 만들거나 보상 규칙을 수정하지 않는다. 테라포밍용 오염원은 계약의 환경 설비 대상이며, 탐험 보상·수집 발견물로 중복 등록하지 않는다.

이 작업 담당: 필요한 설계도 ID/효과/최초 제작 조건을 제공하고, 공동 사용권을 실제 제작·개조 권한으로 연결한다. 완성 설계도를 받은 뒤 같은 설계를 다시 연구하도록 요구하지 않는다. 설계도 등록 API와 저장 계약은 [현재 접점](../production/98-regional-terraforming-and-map.md#t3-설계도-연결-계약)을 확장한다. 대표 사업 검수에는 등록된 설계도의 준비 저장을 사용할 수 있으나 실제 획득 콘텐츠 완성을 주장하지 않는다.

## 2. 플레이와 환경 규칙

- T3는 기본 **4개 현장**을 제안한다: 착륙 정착지·유입원·1차 영향 지역·최종 복원 지역. 기존 3~4지역 제안 중 대표 기준이다. 현장 역할은 문제 유형에 맞게 바뀐다. 최종 거리·반경·구획 수는 지형과 운송 시간에 맞춰 데이터로 조정한다.
- 첫 전체 묶음은 **반응성 가스 유입형 / 산성 수질 유입형** 두 프로필을 제공한다. 한 행성은 주된 유입원 한 유형을 사용한다. 유형에 맞지 않는 조건을 모두 요구하지 않는다.
- 호스트가 구획별 `현재 잔류량 + 유입량 − 처리량 − 통제된 이동량`을 계산한다. 유입원과 영향 대상은 시드로 고정하고, 전달량에는 방향·용량·시간 상한을 둔다. 지도 연결선만으로 원인이 제어됐다고 처리하지 않는다.
- T1/T2 설비는 기본 온도·급수·대기·토양 작업에 계속 유효하다. T3 전문 설비는 대응 물질의 분리/중화나 유입원 억제를 맡는다. 처리하지 못하는 물질을 기초 설비 증설로 제거할 수 없다.
- 원인 억제 상태와 남은 오염량은 별개다. 원인 설비를 설치했어도 기존 오염을 제거하고 목표 구획을 유지해야 정산한다. 원인 억제에도 실제 가동·소모품·전력이 필요하며 단순 건설 완료로 보상하지 않는다.
- 보급 중단 시 유지 가능 시간과 악화 추세를 먼저 표시한다. 다시 유입되는 문제만 악화시키고 기존 건물·가공품·토양 개량·광맥 고갈 기록은 초기화하지 않는다.
- 부재중에는 호스트 세션의 실제 경과와 가용 재료만 집계한다. 재접속·호스트 종료 시간을 중복 계산하거나 현실 시간만으로 무제한 악화시키지 않는다.

T3-01~02에서 공통 데이터/설계도 ID를 먼저 고정해 다른 작업과 공유 가능한 상태로 만든다. T3-03~06에서 대표 수질 사업 한 개의 수급·처리 경로를 연결하고 가스 프로필을 추가한다. 각 시설은 해당 구현 단계부터 모델·조작·가동 표현을 연결하며 T3-08을 마지막에 버튼 기능 전체에 외형만 붙이는 단계로 취급하지 않는다. T3-07~10에서 지도·경제·저장을 마무리한다.

## 4. 시설·제품 구성 제안

| 시설 또는 개조 | 맡는 기능 | 주요 입력/유지 역할 |
| --- | --- | --- |
| Mk.3 제작소 | 전문 제품 생산 기반 | 기존 산업 코어 경로 유지, 원광→기초 부품부터 다시 재설계하지 않음 |
| 유입원 제어 장치 | 현장에서 가스/수질 유입량 감소 | 공통 본체와 문제별 처리 모듈, 중화 또는 흡착 소모품 |
| 선택성 대기 처리기 | 기초 대기 조절로 제거되지 않는 반응성 가스 처리 | 교환막·흡착 제품·전력 |
| 폐쇄 수자원 순환기 | 산성/오염수 처리와 처리수 재사용 | 교환막·중화 제품·순환 모듈; 재사용은 실제 투입/회수량 이하 |
| 지역 열교환기 | 온도 편차로 인한 순환/정착 효율 저하 완화 | 내식 재료·열교환 모듈·전력; T4 극한 정격 장비와 구분 |
| 선구종 정착기 | 처리된 토양에 지속 가능한 초기 식생 정착 | 기존 토양 제품·정착 배양 팩·급수; 신규 생물 발견 없이 표준 배양 제품으로 가능 |

이 표는 기능별 구성안이다. 독립 신축과 기존 시설 Mk.3 개조 중 적합한 형태를 선택하며 같은 기능을 둘 다 제작하도록 요구하지 않는다. 모든 원료·가격·가공시간·소모주기는 확정 전이며 구현할 때 생산 소관 문서와 콘텐츠 데이터에 한 번 정의한다. 기존 광물을 우선 사용하고 새 원광·새 화폐·보석 의무 소비를 추가하지 않는다.

산업 코어는 기존대로 Mk.2에서 만들 수 있어야 한다. 전문 제품을 만드는 Mk.3 제작소의 최초 업그레이드에 Mk.3 전용 제품을 요구하지 않는다. 필수 공급은 접근 가능한 현지 광물이나 이미 가능한 운송 경로로 확보할 수 있어야 하며, 미구현 Lotus/상점 상품을 조달 보장으로 계산하지 않는다.

## 5. 사업 경제와 완료 경계

원인 제어·영향 지역 복원에 중간 대금을 배분하고 최종 안정 상태에서 잔금을 지급한다. 현장 수가 늘었다고 현재 T2의 20%를 모든 현장에 그대로 복제하지 않는다. 중간 지급 총합은 생산 거점 유지 시의 총대금을 넘지 않게 제한한다. 기존 생산 이정표 보상이 지역 수만큼 복제되지 않게 한다.

원료 채집·제품 제작·운송 한 묶음으로 현장을 일정 시간 운영할 수 있게 소비량을 조정한다. 사업 시작 전에 예상 물량과 비용을 표시하고, 미리 확보한 생산망이 실제로 진행 비용과 이동 횟수를 줄이도록 한다. 목표 수익·왕복 횟수·진행 시간은 대표 사업을 연결한 후 조정하며 지금 확정하지 않는다.

완료 기준은 **설계도 잠금→현장 수급→전문 제품→원인 제어→영향 구획 복원→유지→단일 정산**이다. 지역별 차이가 실제 풍경과 지도에 반영되고, 원인 설비를 멈추면 설명 가능한 변화가 있어야 한다. 별도 작업의 설계도 획득 결과까지 합친 전체 통합 완주는 획득 경로가 연결된 뒤 확인한다.

최초 항목 정리에서는 코드·자산을 변경하거나 게임 검사를 실행하지 않았다. 이후 구현과 실제 확인은 위 제작 기록을 따른다. 실제 개발 때 프로젝트의 테스트 최소화 규칙에 따라 해당 거래·원인 처리·저장과 대표 화면/가동만 확인한다. 전체 회귀·6인 장시간 검사를 관행적으로 추가하지 않는다. T4/T5 극한/광역 평가·새 탐험 콘텐츠·자동 화물 운송·전 행성 물리 유체 계산은 이번 구현 목록에 포함하지 않는다.
