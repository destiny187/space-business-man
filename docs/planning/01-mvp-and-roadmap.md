# MVP와 개발 단계

이 문서의 범위·순서·수치는 모두 설계 제안이다. 전체 원안을 작은 완결 루프로 검증한 뒤 확장하기 위한 계획이며, 구현 완료 보고가 아니다.

## 첫 플레이 버전의 목표

**작은 행성 하나에서 직접 자원을 캐고, 로봇에게 일을 맡기고, 환경을 개선해 판매한 뒤 같은 로봇을 다음 행성에 보내는 경험**을 완성한다.

테라포밍 설비만 만드는 데서 끝내지 않고 사업 정산·계승까지 연결한다. 개발 초기에는 단순 도형과 최소 소리로 기능을 검증하고, 이후 대표 장면의 카툰 아트를 완성한다. 최종 그래픽 목표는 고품질 카툰 렌더링으로 유지한다.

## 포함 범위

| 분야 | MVP 범위 |
| --- | --- |
| 세계·조작 | 싱글플레이, 유한 3D 작업 구역, 수동장비 하나, 시점은 임시 1인칭 제안 |
| 행성 | 척박한 위성 유형 하나, 첫 행성과 후속 행성 인스턴스 생성 |
| 채집 | 철·구리·암석·얼음 4종, 노드 고갈·화물·보관 |
| 건축 | 기지·보관함·발전기·충전 패드·로봇 제작기와 테라포밍 설비 |
| 로봇 | 채광·운반 겸용 1모델, 3등급, 작동하는 특성 3종 중 추첨 |
| 자동화 | 작업 배정, 채광·운반·하역·충전 반복, 정체 사유 표시 |
| 테라포밍 | 대기 처리·온도 조절·물 공급, 표준 미생물 정착, 환경 시각 변화 |
| 평가·거래 | 환경 점수·필수 조건·등급, 판매 내역, 대금·자산 정산 |
| 경제·기술 | 기본 상점, 필요한 기초 기술 구매, 행성 재구매 |
| 계승 | 회수 기술, 1슬롯 소형선, 로봇 1대 회수·재파견 |
| 탐험 | 고정 유적 이벤트 하나, 기록과 행성 가치 가산 |
| 저장 | 단일 프로필, 활성 행성, 제작·발견·거래·계승 상태 복원 |
| 제작 품질 | 핵심 장비·자원의 Blender 아트 검증, 우선 효과음의 ElevenLabs 제작·적용 |

기술 가격과 시작 예산은 [경제 문서](../game/05-economy-and-progression.md)의 완결 가능 조건을 따른다. 후속 행성은 다른 시드와 배치를 가질 수 있지만 새 생태계·새 행성 유형을 추가할 필요는 없다.

## 첫 버전에서 보류할 확장

- 실제 구형 행성, 복셀 지형 파괴, 광범위한 지하 탐험.
- 멀티플레이, 여러 행성 동시 운영, 오프라인 생산.
- 복잡한 정제·합금·컨베이어·유체관·배선 체계.
- 다수 제조사·전문 로봇, 로봇 영구 파괴·보험·합성·등급 재추첨.
- 레어 상점, 다수 우주선, 큰 화물·동물의 우주 운송.
- 야생 미생물 다양성, 야생동물 포획·판매, 전투 AI와 문명 선택.
- 지역별 기후·복잡한 생태 상호작용, 전체 음성 연출과 대규모 음악 구성.

이 항목들은 전체 설계에서 유지한다. 특히 문명 파괴·노예화·보존은 [이벤트 문서](../game/06-exploration-and-civilizations.md)에 기록된 후속 콘텐츠다.

## 개발 순서와 완료 조건

| 단계 | 산출물 | 다음 단계로 넘어갈 기준 |
| --- | --- | --- |
| 0. 기반 결정·실행 확인 | 에디터 버전 확인, 테스트 장면, 시점·월드 프로토타입 전제 | 프로젝트 실행·종료 가능, 임시 전제를 결정 기록에 명시 |
| 1. 수동 개척 | 이동·시점·상호작용, 자원 4종, 화물·보관, 기초 저장 | 채집→운반→보관 반복, 재로드 후 잔량·재고 보존 |
| 2. 건축·첫 자동화 | 시설 배치·철거, 전력·충전, 기술 구매·로봇 제작·작업 | 로봇 한 대가 채광→하역→충전→재개를 자동 반복 |
| 3. 테라포밍 | 설비 효과, 표준 미생물, 환경 대시보드·시각 변화 | 원인과 변화를 설명할 수 있고 필수 조건·안정성·B등급 달성 가능 |
| 4. 사업 루프·계승 | 평가·판매·회수·지구 보관·행성 구매·재파견 | 같은 로봇 ID·등급·특성이 다음 행성에서 유지, 현금 중복 지급 없음 |
| 5. 발견·복구·통합 | 유적 이벤트, 정산 가산, 사업 재시작, 중단 복원 | 유적 보상 중복 없음, 자원·현금 고갈에서 복구 가능, 한 회차 저장 재개 가능 |
| 6. 아트·사운드 완성 | 대표 Blender 에셋·재질·효과, ElevenLabs 오디오·믹스 | 실제 플레이 화면·소리 검수, 다중 로봇 성능 측정, 자원·상태 가독성 확보 |

단계 0~2에서 작은 아트 검증 장면을 함께 만들어 시각 방향의 큰 실패를 일찍 발견한다. 전체 에셋의 마감은 루프가 안정된 후 진행한다. 일정·담당 인원은 아직 정하지 않는다.

## 첫 30~45분의 목표 경험

시간은 검증용 목표이며 확정 플레이 타임이 아니다. 목표는 불필요한 대기를 늘려 이 시간을 채우는 것이 아니다.

| 대략적인 구간 | 플레이어가 할 일 | 체감해야 할 결과 |
| --- | --- | --- |
| 시작~5분 | 행성 조건 확인, 착륙, 첫 채집·보관 | 조작·자원 용도를 이해 |
| 5~15분 | 기술 구매, 시설 배치, 첫 로봇 제작·배정 | 직접 하던 일이 자동으로 진행 |
| 15~30분 | 생산 확장, 유적 탐사, 환경 설비 가동 | 풍경 변화와 개선 목표가 보임 |
| 30~45분 | 안정화·평가, 회수 선택, 행성 판매 | 투자 결과와 다음 성장 방향 이해 |
| 다음 회차 시작 | 보관 로봇 편성·파견 | 좋은 로봇을 보존한 이점 체감 |

플레이테스트에서는 안내 없이 멈춘 지점, 첫 로봇 제작까지 걸린 시간, 개입이 필요한 정체 횟수, 테라포밍 변화 인지, 판매 결정 이유를 관찰한다.

## MVP 최종 인수 시나리오

2026-09-06 로컬 실행판에서 다음 항목을 확인했다. 테스트 종류·시드 반복·실제 입력의 구분과 제한은 [검증 근거](03-implementation-status.md)를 따른다.

- [x] 새 프로필에서 시작해 행성을 구매하고 수동장비로 채집할 수 있다.
- [x] 기술을 구매하기 전에는 해당 제작이 잠기고, 구매 후에도 재료·시설 조건이 적용된다.
- [x] 로봇 제작 시 등급·특성이 부여되고 저장·복원으로 재추첨되지 않는다.
- [x] 로봇이 스스로 채광·운반·충전을 반복하고, 창고 포화·길 차단에서 이유를 표시한다.
- [x] 건설 취소·철거·제작 취소로 자원이 복제되거나 사라지지 않는다.
- [x] 테라포밍 설비의 입력·전력·가동 상태에 맞게 환경과 풍경이 변한다.
- [x] 점수·필수 조건·안정화 시간을 확인하며 B등급 이상을 달성할 수 있다.
- [x] 유적을 발견해 기록하고 매각 내역에서 가치 가산을 확인할 수 있다.
- [x] 판매 전 남는 자산·회수 자산·가격을 확인하고 취소할 수 있다.
- [x] 판매 확정 후 현금은 한 번 지급되고, 회수한 로봇은 잔존가치에서 제외된다.
- [x] 다음 행성에서 동일한 회수 로봇이 작동하고 초반 수동 작업이 줄어든다.
- [x] 제작·운반·환경 안정화·판매 전후의 저장과 재개가 올바르다.
- [x] 준비금·자원 고갈 또는 저가 매각 뒤에도 사업 재시작으로 진행을 복구할 수 있다.
- [x] 대표 플레이 화면에서 카툰 아트·UI·소리가 함께 읽히며 성능을 측정했다.

## 이후 확장 순서

1. **생산과 선택:** 전문 로봇, 새 제조사·특성, 정제 공정, 더 어려운 자원 배치.
2. **사업 성장:** 레어 상점, 우주선 등급, 다수 회수 편성, 다양한 행성 계약.
3. **탐험과 생태:** 절차적 유적, 고대 기술, 야생 미생물, 동물의 정착·반출·판매.
4. **문명과 충돌:** 전투 AI, 파괴·노예화·보호 선택, 보상·가격·장기 결과.
5. **월드·출시 품질:** 결정된 지형 범위, 접근성·입력·설정, 플랫폼별 최적화·내보내기.

확장 순서는 실제 플레이에서 확인한 재미와 병목에 따라 조정한다. 한 단계가 완성될 때 범위를 다시 확인하고 결정 기록을 갱신한다.
