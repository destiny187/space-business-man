# 자유 배치·거리와 환경에 따른 테라포밍 — 기획 초안

2026-09-09. 사용자는 정해진 복원 포인트를 방문하는 방식의 재미를 재검토하고, 한곳에 모아도 되는 시설과 떨어뜨려 배치할수록 유리한 시설을 구분하는 거리 기반 효율을 제안했다. 최초에는 기획 요청이었으며, 후속 사용자가 네 항목의 테라포밍 탭 시각화와 T3까지의 개발을 승인했다. **F01~F04를 T1~T3에 연결했으며 실제 범위·검증·단순화는 [제작 기록](../production/102-free-terraforming-and-globe.md)을 따른다.** 후속 사용자 구체화에 따른 시설별 방향은 아래 확정 요구사항으로 구분한다. 세부 계산·평가·수치는 설계 제안이다. 지역 테라포밍의 [소관 문서](../game/20-regional-terraforming-and-surface-supply.md)를 보완하며, 채택 시 고정 현장 수·고정 복원 구획을 사업 목표로 삼는 부분을 대체한다.

전환 전 구현은 [T1/T2 지역 사업](../production/98-regional-terraforming-and-map.md)과 [T3 네 현장](../production/100-tier3-terraforming.md)이다. 후속 신규 세계의 자유 배치 적용과 기존 지역 규칙의 보존은 위 제작 기록을 따른다. 탐험 사건·발견물·설계도 획득 콘텐츠는 계속 다른 작업의 범위다.

## 1. 사용자 구체화와 핵심 플레이

2026-09-09 후속 사용자 방향:

- **공장·창고:** 플레이어가 필요한 위치에 자유롭게 짓는다. 테라포밍을 위한 집중/분산 유도 대상에서 제외한다.
- **대기:** 테라포밍 탭에서 행성 구 전체의 대기 분포와 변화를 확인한다.
- **수질:** 낮은 지대가 유리한 입지로 삼되, 물에 잠기면 사용할 수 없다. 효율과 침수 위험을 보고 플레이어가 판단한다.
- **토양:** 분산 배치가 유리한 면적 처리로 한다.
- **오염원:** 예외적으로 오염 구역이 존재하며, 대응 설비를 그 내부에 지어야 효과가 있다.

**시설별로 지도를 다르게 읽게 한다.** 대기는 구체 위의 분포, 수질은 낮은 땅과 수면, 토양은 처리되지 않은 면적, 오염 대응은 실제 오염 구역을 보고 입지를 결정한다. 모두에 동일한 거리 보너스를 주지 않는다.

T1은 작은 기지 주변의 낮은 목표로 시작하고 높은 티어는 범위·문제·유지 조건을 늘린다. 시설 간 거리가 멀다는 이유로 점수를 주지 않으며, 공장·창고의 위치를 환경 평가에 넣지 않는다. 원료 공급과 실제 운송의 편의는 기존 산업 플레이의 선택이다.

### 대기: 행성 구체의 분포

Tab 행성 화면에 **테라포밍 탭**을 추가하고, 회전·확대할 수 있는 행성 구체에 대기 상태를 표시한다. 산소·기압·일반 독성/해당 특정 가스는 선택 레이어로 구분한다. 현재 분포와 시설 가동 시 변화 예상은 서로 다른 표시를 사용한다.

분포 계산은 시설 위치의 배출/처리량과 구면상 인접 권역 사이의 유한한 전달량을 사용하는 안이다. 공장이 있는 곳을 기준으로 한 임의의 거리 배율이나 전 행성 공통 숫자 하나로 대체하지 않는다. 한 거점도 시간이 흐르면 넓은 대기 개선에 기여할 수 있지만, 반대편이 즉시 같은 값으로 바뀌지는 않는다. 모든 대기 설비를 멀리 떨어뜨리도록 강제하지 않는다.

대기의 광역 개선은 대기 항목만 바꾼다. 토양·수질·생태는 별도 조건으로 남는다. 현재 48m 국소 계산과 사업권 내 혼합만으로 이 구체 기능의 구현을 완료했다고 기록하지 않는다. 전 행성 상태 표현을 T5에서만 여는 잠금으로 삼지 않되, 저티어의 완료 목표는 작은 복원 범위로 유지한다.

현재 지표 좌표와 구면상의 위치 대응, 구면 셀 면적과 연결은 개발 전에 정의해야 한다. 평면 지도를 구체에 임의로 감아 반대편이 연결된 것처럼 보여 주지 않는다. 구 전체를 보여 주더라도 원래 관측/시드 상태·예측·실제로 처리한 변화를 구분한다. 확인되지 않은 곳은 불확실성으로 표시하고, 구체가 모두 보인다는 이유로 미방문 지표가 복원됐다고 칠하지 않는다.

### 수질: 저지대의 이점과 침수 위험

낮은 지대에 입지 이점을 주는 것은 게임 설계다. 행성 전체의 절대 고도보다 **해당 분지/주변 지형 대비 상대 고도**로 유리함을 평가하고, 이점에는 상한을 두는 안이다. 저지대라는 이유로 물·처리 재료를 무료 생성하지 않으며 기존 급수 입력과 처리 제품은 실제로 소비한다. 정확한 고도 구간과 효율 곡선은 미정이다.

건설 고스트에서 현재 수면·설비의 실제 침수 판정 외곽·입지 효율을 함께 확인하게 한다. 미래 수위가 계산 가능한 경우에만 예상 수면/여유 높이를 표시한다. 침수 위험이 있는 마른 부지의 설치를 자동 거절하거나, 게임이 항상 안전한 높이로 시설을 옮겨 주지 않는다. 현재 이미 잠긴 부지의 건설 판정은 기존 침수 규칙을 출발점으로 한다.

가동 중 침수되면 수질 설비의 효과와 처리 소모품 소비를 멈추고 원인을 표시한다. 침수만으로 즉시 파괴·재고 소실을 추가하지 않는다. 물이 빠지거나 플레이어가 설비를 옮긴 뒤 기존 가동 조건을 다시 만족하면 사용할 수 있게 한다. 수질 개선 자체가 행성 수위를 반드시 올리는 것은 아니며, 실제 급수·수면 계산에서 발생한 변화만 침수에 반영한다.

낮은 곳 하나에 시설을 몰아도 다른 독립된 수역/땅으로 효과를 순간 전달하지 않는다. 자연 유역 전달과 범용 배관·자동 운송은 별도 구현 전까지 제공하지 않는다. 입지 보너스를 위한 지형 기준을 자연 지형으로 고정할지 실제 굴착 결과까지 반영할지는 조정 항목으로 남긴다.

### 토양: 분산이 직접 면적으로 이어짐

토양 개량은 미처리 면적을 덮도록 분산하는 것이 기본이다. 같은 성능의 두 설비가 겹친 셀에서는 **가장 강한 한 설비의 효과만 적용**하는 안으로 집중 처리 속도 증가를 제거한다. 남는 처리 능력은 각 설비가 실제로 도달하는 다른 미처리 셀에 배분하고, 다른 셀이 없으면 해당 처리 소모품을 소비하지 않는다. 겹친 면적은 한 번만 센다.

분산 거리 자체의 보너스는 없고 너무 멀리 두면 사이의 땅은 미처리로 남는다. 좋은 지형을 따라 띠·군집·넓은 면으로 펼칠 수 있다. 이미 개량한 토양은 설비를 옮겨도 남으며 순차 복원도 허용한다. 토양의 중첩 규칙을 대기·수질·열 처리에 일괄 적용하지 않는다. 선구종 정착은 그 땅의 물·온도·토양 조건을 별도로 요구한다.

### 오염: 구역 내부 설치라는 명확한 예외

시드에 따라 가스/오염수 등 대응할 **오염 구역 면적**을 둔다. 해당 전문 기능은 설비의 설치 기준점이 해당 구역 내부에 있을 때만 유효한 안으로 한다. 구역 밖에서 처리 반경만 걸치거나, 더 많은 기계를 쌓아 이 조건을 우회할 수 없다. 내부에서도 전력·소모품·맞는 처리 능력과 실제 도달 범위를 충족해야 한다. 내부에 한 대 설치했다고 구역 전체를 즉시 정화하지 않는다.

정답 핀·단일 소켓·지정된 설비 개수는 두지 않는다. 구역 안에서 넓게 커버할지, 보급에 가까운 곳을 고를지 판단한다. 원인 가까울수록 추가 이점을 주는 규칙은 이번 확정 방향에 포함하지 않는다. 접근 가능하고 가동 가능한 부지와 필요한 재료의 선행 확보 경로를 생성 조건으로 점검한다.

**설치 자격을 판정하는 오염 구역 경계와 현재 잔류 오염 분포를 분리**한다. 기본안은 전자를 시드/계약 생성 시 고정해 정화로 구역이 줄어든 순간 자신의 시설이 구역 밖이 되는 문제를 막는 것이다. 지도에는 둘을 다른 윤곽/무늬로 표시한다. 정화 후 잔류가 없으면 대기하며, 유입이 남아 있다면 내부 설비로 유지 처리한다.

기존 초안의 ‘구역 밖 후단 처리로 오염원 대응을 대신하는 선택’은 철회한다. Mk.3 복합 설비의 일반 급수·대기 조절 기능까지 구역 밖에서 금지하는 뜻은 아니며, **해당 오염을 처리하는 전문 기능**에 내부 설치 조건을 적용한다.

## 3. 거리·중첩·처리량 계산

플레이어에게는 연속적인 영향 얼룩과 복원된 땅으로 보이고, 내부에서는 지형에 고정된 환경 셀을 계산한다. 셀 중심을 밟거나 그 위에 건설할 필요가 없다. 청크 로딩·플레이어 이동·시설 재배치로 셀 ID와 진행도가 바뀌지 않는다.

국소 시설은 중심부에서 안정적으로 작동하고 가장자리로 갈수록 영향이 부드럽게 줄어드는 형태를 출발점으로 한다. 예시 커널은 중심 반경 40%까지 일정, 바깥 반경까지 연속 감소이며 실제 반경·곡선은 시설별 데이터다. 현재 48m를 모든 종류·등급의 정답 반경으로 고정하지 않는다.

```text
셀의 처리 가중치 = 거리 영향 × 지형 전달성 × 해당 문제의 남은 처리 수요
시설의 이번 처리 예산 = 정격 처리량 × 실제 가동 시간 × 실제 공급 가능한 비율
셀에 배분할 처리량 = 처리 예산 × 해당 셀 가중치 / 대상 셀 가중치 합
```

이 식은 국소 처리의 개념 초안이다. 토양은 위의 셀당 최대 효과 규칙, 오염 전문 기능은 내부 설치 자격, 수질은 저지대 입지 계수와 침수 정지를 먼저 적용한다. 실제 계산에서는 셀 수요 상한을 적용하고 남는 예산을 다른 도달 셀에 재배분한다. 여러 시설의 배분을 호스트가 함께 조정해 같은 오염량을 두 번 제거하지 않으며, 투입 제품 하나를 대상 셀마다 복제하지 않는다. 수요가 없으면 대기하고 불필요한 처리 소모품을 태우지 않는다. 별도 기본 가동 전력이 있다면 표시한다.

- 토양은 셀당 최대 효과로 중복 가동을 억제한다. 대기·수질·오염 처리는 실제 수요와 전달/처리 상한 안에서 합산할 수 있으며 모든 설비에 같은 중첩 규칙을 쓰지 않는다.
- 반경 안이라는 이유만으로 전부 완료 면적이 되지 않는다. 충분한 실제 투입과 모든 필수 환경 조건을 갖춘 땅만 평가한다.
- 반경 밖에 미세한 효과를 무한히 누적해 한곳에서 전부 복원하지 않는다. 국소 전달 범위는 유한하며 자연 확산·생태 전파를 추가할 때도 별도 속도·도달·유지 한도를 둔다.
- 대기와 유역은 해당 물질의 별도 전달 모델을 사용한다. 직선거리, 지표 도달 거리, 흐름 연결 중 해당 시설이 실제 구현한 방식만 적용한다. 지형 차폐를 계산하지 않는 단계에서는 지도에도 차폐 효과를 약속하지 않는다.
- 열·물·토양·생태는 같은 거리 곡선을 복사하지 않는다. 특히 높은 곳의 태양광 입지처럼 환경에 따른 생산 이익과 테라포밍 면적 기여는 구분한다.

| --- | --- | --- |
| 거의 같은 위치 | 겹친 면적/속도는 중복 증가하지 않음 | 토양 복원에서는 분산 배치로 옮기는 편이 유리 |
| 영향 가장자리가 일부 겹침 | 넓은 면적과 연결된 안정 구역을 함께 확보 | 생활권을 확장하는 일반 배치 |
| 영향 범위보다 훨씬 멀리 분리 | 두 별도 생활권, 사이의 미복원 땅은 그대로 | 떨어진 자원 현장·다른 유역 개발 |

부분 중첩과 완전 분리 중 무엇이 좋은지는 필요한 생활권 형태와 실제 지형에 달렸다. 토양 자체의 판정은 도달 면적이며 급수·오염·생태는 그 땅의 전체 거주 조건에서 따로 확인한다. 실제 투입이 같으면 총 처리량을 공짜로 늘리지 않고, 필요한 곳에 얼마나 유효하게 쓰는지가 달라진다.

## 4. 고정 포인트 없이 완료를 평가하는 방법

**‘몇 곳에 건설했는가’를 없애고 ‘얼마나 넓은 땅을 어떤 상태로 유지하는가’를 평가한다.**

1. 사업 시작 시 지도에서 넓은 사업권과 목표를 보여 준다. 표준 사업권은 접근 가능한 지형·티어·시드로 정해진 충분히 넓은 면적이며 시설 위치나 필수 복원 셀 목록은 지정하지 않는다. 경계는 보상 평가 범위일 뿐 건설 금지선이 아니다.
2. 플레이어는 그 안에서 어느 땅을 복원할지 선택한다. 호스트는 셀 면적을 가중해 기준을 만족하는 땅의 **합집합 면적**을 계산한다. 겹침, 수직 층, 설치/철거 횟수로 면적을 중복 인정하지 않는다.
3. 기본 적합도·유효 면적·필요한 문제의 처리 능력·현재 안정성을 모두 요구한다. 평균 대기 점수가 좋아도 마른 토양·오염수가 있는 땅은 거주 가능 면적에 포함하지 않는다.
4. T3 이상은 사업권에 영향을 주는 지속 유입과 처리/보급의 균형을 함께 검사한다. 해당 오염 구역 내부에서 가동하는 전문 설비의 실제 유입 억제·잔류 제거를 요구한다. 선택한 안전한 땅만 잠깐 가꾸고 문제를 옆으로 밀어낸 행위는 오염 처리 성과가 아니다.
5. 생활권 연결은 ‘최소 한 덩어리의 유효 면적’ 같은 목표로 제안한다. 별도 거점도 총면적에 기여하며 모든 시설을 잇는 선이나 고정된 거점 개수를 요구하지 않는다. 가느다란 미달 지표 띠로 연결됐다고 판정하지 않는다.

처음부터 좋은 자연환경은 총 거주 가능 면적에는 포함하지만 복원 성과로 이중 보상하지 않는다. 계약은 **최소 신규 개선 면적과 시작 상태 대비 처리 과제**를 함께 정하고, 작은 티어는 그 기준을 작게 잡는다. 쉬운 입지 선택의 이익은 남기되 기존 낙원을 찾기만 해 같은 복원 대금을 받지는 않는다.

사업권 면적·초기 상태·요구 개선량·적용 문제·총액은 계약 생성 시 동결한다. 기본 시작점은 행성 진입 때 보여 준 표준 사업권을 사용하고, 착륙선 이동으로 유리한 곳에 평가 범위를 옮기지 않는다. 자유 경계 편집·자동 재견적은 첫 전환에서 제외한다. 전 행성 면적을 실제 계산하기 전에는 완료 명칭을 ‘생활권 복원’ 또는 ‘광역 사업 완료’로 유지한다.

오염 구역 내부 설치는 예외적인 위치 조건이다. 구역을 제외한 토양 등 일반 복원은 자유 면적을 평가하며, 이 예외를 모든 시설의 필수 지역/건설 포인트로 확대하지 않는다.

## 5. 티어별로 늘어나는 판단

| 티어 | 플레이와 조건 제안 | 넓혀 갈 이유 |
| --- | --- | --- |
| T1 | 기지 주변 작은 신규 복원 면적·기초 환경·짧은 유지 | 첫 기지의 풍경 변화를 쉽게 경험; 원거리 분산 의무 없음 |
| T2 | 더 넓은 면적·염분/토양·쓸 수 있는 연결된 생활권 | 토양·급수의 도달 공백을 보완하며 좋은 땅으로 확장 |
| T3 | 더 넓은 면적과 해당 가스/수질 문제·지속 유입을 감당하는 운영 | 오염 구역 내부의 자유 배치·보급·전문 처리, 구역 밖 생활권의 토양 분산 |
| T4 | 실제 존재하는 극한 온도/부식·정격과 전달 손실 | 안전한 생산 거점과 현장 환경 장치의 역할 분리 |
| T5 | 광역 대기/물질 장부와 지역별 거주 조건·유지 능력 | 집중 광역 처리와 분산 지표 복원의 조합 |

면적만 크게 늘리거나 이동 시간을 의무 대기로 만들지 않는다. 지역 수·설비 개수·최소 간격은 티어 완료 조건에서 제외하는 안이며 오염 전문 기능의 구역 내부 조건은 유지한다. 인원별 사업량은 기존 협동 규칙에 따라 면적/처리 부담 중 한 번만 적용하고, 점수·거리·안정 시간을 중복 배율로 늘리지 않는다.

## 6. 수급·보상·재배치

기존 P1~P3 제품·설비·설계도 ID와 직접 운송은 재사용한다. 중앙 제작소가 먼 시설의 재고를 자동 소비하게 하지 않는다. 고정 지역을 없애더라도 창고·전력·작업 범위는 별도 운영 단위로 남기며, 가까운 지역 중심점이 바뀌었다고 재고 소유를 바꾸지 않는다.

보상은 고정 외부 지역별 지급에서 **계약별 유효 신규 복원 면적·문제 개선의 단계**로 전환한다. 예시 진행률 25/50/100%는 조정안이며 크레딧 배분과 동일한 비율이라는 뜻이 아니다. 이미 지급한 단계는 다시 지급하지 않고 최종 대금에서 기지급액을 차감한다. 일시적으로 넓게 펼쳤다가 이전 지역이 무너지는 순회 운영은 현재 유효 면적을 늘리지 않는다.

토양 개량 등 완료된 작업은 설비를 옮겨도 남는다. 계속 급수·유입 제어가 필요한 조건만 공급 중단에 따라 변한다. 수질 설비의 침수도 가동 중단 사유에 포함한다. 휴대 설비로 순차 복원하는 플레이 자체는 허용한다. 철거 환급·재배치 비용은 기존 정책을 출발점으로 하고, 재설치를 막는 임의 벌금으로 분산을 강제하지 않는다.

## 7. 건설·지도에서 판단을 돕는 표현

FIELD v1에 따라 건설 고스트 주변에 **이번 시설의 실제 도달 범위, 기존 범위와 겹치는 곳, 새로 처리할 수 있는 땅**을 서로 다른 윤곽/무늬로 표시한다. 지도에는 대기·급수·온도·토양·생태 레이어를 따로 고를 수 있게 한다.

배치 중에는 ‘출력 효율 73%’ 하나 대신 **새 도달 면적 / 현재 예상 처리량 / 부족한 공급**을 짧게 보여 준다. 새 도달 면적은 즉시 복원 완료 면적이 아니라고 구분한다. 겹침은 경고색 낭비 판정으로 고정하지 않고 ‘기존 오염 처리 속도 증가’처럼 실제 이익도 보여 준다. 토양은 중첩 시 ‘신규 면적 없음’과 대기할 처리량을 표시하고 속도 증가를 약속하지 않는다.

대기 분포는 테라포밍 탭의 구체로, 수질 입지는 저지대와 실제 수면으로, 토양은 신규 도달 면적으로 표현한다. 오염 구역은 내부/외부 자격을 구분하는 윤곽과 설비 고스트의 유효/무효 표시를 제공한다. 지도에서 권장 위치는 여러 대안의 히트맵이며 단일 필수 핀으로 만들지 않는다. 플레이어가 표시한 목표 지점과 지형상의 수원·분출 위치 표시는 유지할 수 있다. 바람/유역 전달을 아직 계산하지 않는 버전에서 임의의 방향 화살표를 그리지 않는다.

## 8. 구현으로 넘길 때의 순서와 경계

| 단계 | 범위 | 작은 확인으로 판단할 항목 |
| --- | --- | --- |
| F01 자유 면적 기반 | 고정 5구획을 위치 독립 환경 셀로 확장, 사업권/초기 상태/현재 면적 원장 | 임의 위치 건설이 반영되고 겹친 면적은 한 번만 셈 |
| F02 T1/T2 배치 | 토양 분산/최대 효과·수질 저지대 효율/침수 정지·면적 계약·고스트/지도, 창고·전력 단위 분리 | 토양 중복 이득 없음, 수질 입지 선택과 실제 침수 정지/복구 |
| F03 T3 구역 대응 | 기존 두 오염 유형의 구역 경계/잔류 분포 분리·내부 설치 자격·면적 보상 | 밖에서 효과 없음, 안의 임의 위치에서 전문 처리·보급·정산 가능 |
| F04 대기 분포·테라포밍 탭 | 지표/구면 좌표 대응·구면 권역의 대기 전달·회전 가능한 분포 구체 | 실제 가동/시간에 따른 분포 변화가 지도·현장과 일치하고 반대편 즉시 개선 없음 |
| F05 광역 확장 | T4/T5 정격·광역 물질/유지 평가 | 먼저 구현한 실제 계산 범위를 넘어 행성 전체 완료를 주장하지 않음 |

F02~03만 끝난 단계는 자유 지표 배치의 구현이며 사용자 요청의 행성 구체 대기 분포까지 완료된 것은 아니다. F04는 이 요청의 완료에 포함하며 T5 후속으로 미루지 않는다. 자연 유역 물량 전달은 별도 후속이다. 한 설비의 전체 예산 보존·동시 처리·호스트 저장·현장 렌더를 해당 단계에서 확인한다. 최초 문서 단계에는 게임 테스트를 실행하지 않았으며 후속 구현의 확인은 제작 기록을 따른다.

셀은 고정 공간 인덱스로 조회하고, 영향받은 셀과 희소 변경분만 저장하는 방식을 제안한다. 백만 행성의 전 표면을 매 틱 계산하지 않는다. 미로드 셀도 같은 시드 초기값과 저장 변화분을 사용하고 호스트의 실제 산업 시간만 진행한다. 실제 처리 상태와 시각 샘플이 같은 좌표 함수를 읽어야 한다.

구 규칙의 저장은 기존 판정으로 보존한다. 후속 구현은 별도 규칙 버전으로 생성하며 진행 중 사업을 강제 전환하지 않는다. 고정 지역 재고·건물 소유·안정/지급 이력을 자유 셀로 변환하는 이행은 별도 검증 전까지 제공하지 않는다. 탐험 측 설계도 6개와 등록 API의 식별자는 유지한다.

## 9. 구현 전 조정할 값

시설별 유효 반경·중심부 비율·정격 처리량, 티어별 신규 면적과 연결 면적, 사업권 크기, 저지대 효율 상한·고도 기준·침수 판정, 대기 혼합 속도·구면 해상도, 오염 구역 규모와 운영 비용, 유지 기간은 아직 확정하지 않는다. 첫 비교는 같은 시드·같은 투입으로 집중/분산 배치를 만들어 **처리 시간·유효 면적·보급 왕복·예상 이익**을 보는 것으로 충분하다. 정답 간격이 반복되면 숨은 벌점을 더하지 않고 지형 적합성·수요·공급 관계를 조정한다.
