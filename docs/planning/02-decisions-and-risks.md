# 결정 대기 항목과 위험

## 2026-09-07 — 2티어까지만 공통 성장 구현

사용자 확정: 전체 5단계보다 2티어 제품·무기부터 구현해 분야별 한 번의 강화를 연결한다. 제품 7종, 휴대 장비/탐험복/로봇/설비/선박 첫 개량과 신규 T2의 염류·토양 복원을 연결했다. 기존 소유 고등급과 계약을 보존하며 P3~P5 생산망은 보류한다. [구현·수치·제약](../production/36-tier2-production-and-retrofits.md).

## 2026-09-07 — 테라포밍의 가공 재료·고급 제품 단계

사용자 확정: 초반 행성의 간단한 기계 기반 복원은 유지하고, 더 깊은 단계에서는 재료를 가공하고 높은 티어의 제품을 확보해야 테라포밍할 수 있게 한다. [소관 설계](../game/15-terraforming-production-progression.md)에 5단계 생산·환경 처리 능력·표준 진행 경로·현재 화산 냉각/저장 보존을 정의했다. 구체적 단계명·제품/레시피·행성 티어별 배정은 제안이다. 이번 작업은 문서만이며 생산망·새 환경 평가를 구현하지 않았다.

## 2026-09-07 — 200m 굴착 상한·시드 동굴·매장 자원

사용자 확정: 동굴 밖에도 광물·보석을 매장하며 어디서든 200m를 넘는 굴착을 차단한다. 동굴은 시드별 자연스러운 구조와 지질 장식·고유 경관을 갖추는 방향으로 확장하고, 추후 아이템·재화 획득을 추가한다. [지하 설계](../technical/07-seeded-underground.md)에 최초 지표 기준 수직 깊이·기반암·연결 그래프·독립 자원 시드·미래 보상 지점을 정의했다. 세부 측정 방식·생성 수치·경관 후보는 설계 제안이다. 이번 작업은 문서만이며 코드·자산·게임 테스트를 변경/실행하지 않았다.

### 2026-09-06 — 탐험 중심으로 게임 방향 확장

[비전](../game/01-vision-and-loop.md), [고도화 단계](06-exploration-expansion-roadmap.md)와 관련 시스템·기술·제작 문서를 갱신했다. 계약·과학 모델·생물·복구·단계 수량은 제안이며 이번에는 문서만 수정했다.

[협동 게임 설계](../game/12-host-coop-and-crew.md)와 [네트워크·세션 저장](../technical/04-coop-networking-and-session-save.md)을 추가하고 경제·선체·시간·관심 지역·저장·개발 계획을 연결했다. 개인 원본 장비 유지, 공용 세계 장부, 신규 보상의 세계 내 보관, 출항 준비·권한 위임·호스트 종료 복구는 구체화를 위한 제안이다. 연결 서비스·영구 보상 반출·자동 호스트 이전은 확정되지 않았으며 게임 코드·네트워크 검증은 수행하지 않았다.

### 2026-09-06 — 생물 렌더링 범위와 기본 모델 500개

사용자가 서브 작업의 범위를 생물 전체 렌더링으로 정하고 공격 동물은 공격 모션·효과도 포함하도록 요청했다. 기본 모델 수는 250개 요청을 거쳐 최종 **500개**로 수정됐다. 20개 구조군에서 환경·해부 변형으로 만든 500개 형상과 형상당 색상/크기 변형 20개, 총 10,000개 외형 프로필의 제작 구조는 구현 선택이다. 외형 변형을 독립 종·능력치로 세지 않는다. 모든 행성의 생명 존재를 강제하지 않고 행성 환경에 맞는 사례를 선택한다는 사용자 방향을 유지한다. ## 2026-09-06 — 스캔·생물 정착 확장

## 2026-09-06 — 성간 초고속 항해 확정

항성계 내부 자유 비행·항성계 사이 무료 초고속 항해를 적용한다. 순간이동 명칭과 점프권 지급/소비안은 사용하지 않는다. 은하 전체 일반 추진 비행안보다 이 결정이 우선한다. [소관 구현·제한](../production/26-stellar-cruise.md).

## 2026-09-07 — 마우스 시선 기본화

평소 이동·항해 시 마우스 방향으로 바라보도록 변경한다. 직접 조종은 마우스 선회, 자동 항해 중에는 카메라 둘러보기로 구분한다. 메뉴에서 커서를 풀고 기존 감도/반전 설정을 적용한다. [실제 연결·확인](../production/26-stellar-cruise.md).

## 2026-09-07 — 태양계 착륙 금지·우주 HUD 정리

사용자 요청으로 태양계 8행성 착륙·테라포밍을 금지하고 우주의 숫자 입력을 제거한다. 중앙 주시 스캔 후 최소 정보를 홀로그램 카드로 표현한다. [구현·확인 범위](../production/27-planet-gaze-scan.md).

## 2026-09-07 — 첫 출격 튜토리얼

환영 편지로 안내하고 태양계 자유 관측 후 전용 출격 버튼으로 인근 개척 항성계에 고속 항해한다. 홀로그램을 마우스 오른쪽 위로 옮겨 확대한다. [구현·검증](../production/28-first-departure.md).

## 2026-09-07 — 항성계 표현·추진 상태

별의 빛, 행성별 크기 차이·느린 공전, 선체 체력·고속 이동 에너지와 비행 불빛/사운드가 사용자 요구다. 자동 충전·충돌 피해·응급 수리는 초기 구현 규칙으로 적용했다. [수치·제약·확인](../production/29-space-light-and-drive.md).

## 2026-09-07 — 항성 위험과 이동 거리 확대

항성 발광을 줄이고 근접 경고/소리·지속 피해를 추가한다. 항성계 거리를 확대해 추진 업그레이드의 가치를 살리고 우주 배경을 강화한다. [초기 수치·구현 범위](../production/30-stellar-hazard-and-depth.md).

## 2026-09-07 행성 다양성과 냉각 개척

사용자 확정: Blender 외형 변형·시드 색상·복합 자원·초기 물/대기 특징을 함께 확장한다. 추가로 불타는 행성을 식혀 자원을 얻는다. 현재 지역 환경 시스템을 사용한 냉각 해금과 기존 저장 보존 범위는 [제작 기록](../production/31-planet-diversity.md)을 따른다.

## 2026-09-07 — 지표 자연물과 평지 확대 검토

사용자는 매끈하고 무난한 지표를 개선할 행성별 디자인용 자연물 정의와 평지 비율 확대에 대한 의견을 요청했다. [소관 설계 제안](../production/31-planet-diversity.md#지표-자연물과-평지-확장--설계-제안)에 착륙 가능한 9계열의 후보·평지 목표·군집 배치·건설/굴착/저장 처리 방향을 기록했다. 세부 비율·수치·제작 순서는 제안이며 사용자 승인이나 구현 완료로 간주하지 않는다. 이번 변경은 문서만이며 게임 테스트를 실행하지 않았다.

후속 사용자 확정: 여러 종류의 Blender 자연물 모델과 실제 렌더를 제작하고 게임에 반영한다. 9계열 36개 지질 장식·군집 배치·표면 무늬·새 은하의 평지 확대를 반영했다. [제작·저장 보존·확인 기록](../production/31-planet-diversity.md#자연물-제작과-평지-반영--2026-09-07)이 실제 범위이며 앞선 후보 전체나 고정 면적 비율의 확정을 의미하지 않는다.

후속 피드백과 승인: 단색 지표에 돌을 얹은 듯한 표현을 개선한다. 산화 사막부터 모래·노출 암반·마른 유로와 돌 배치가 같은 구역을 따르도록 연결하고 평지를 유지한다. [실제 적용·저장 호환 범위](../production/31-planet-diversity.md#산화-사막의-지표-구역-연결--2026-09-07)를 따른다. 다른 행성 전체의 재개편 완료로 기록하지 않는다.
