## 설계상 위험과 대응 제안

기존 위험에 더해 단일 은하·티어 단조로움, 실제 자료와 가상 배치 혼동, 지형 비용, 연구 대기·표본 만능화, 사례 생물 반복은 [확장 실패 신호와 범위 조절](06-exploration-expansion-roadmap.md)을 함께 확인한다.

| 위험 | 발생 신호 | 대응 |
| --- | --- | --- |
| 시작 기술 구매에서 진행이 막힘 | 첫 매각 전 다음 필수 기술 비용을 마련할 수 없음 | 전체 기초 경로와 계승 검증 예산을 먼저 검산 |
| 수동 채집의 반복 피로 | 첫 로봇 전에 흥미를 잃음 | 첫 자원 접근성·제작 비용·안내 조정 |
| 자동화가 관리 노동이 됨 | 매번 로봇을 구조·재배정해야 함 | 채광·운반 겸용 모델, 충전·정체 이유·복구 개선 |
| 테라포밍이 진행 막대만 됨 | 풍경 변화나 설비 원인을 알아보기 어려움 | 환경값에 연결된 아트·음향과 변화량 표시 |
| 항상 최고 등급을 기다리게 됨 | 판매 시점 선택이 사라짐 | 추가 투자 대비 가격 상승·다음 행성 기회를 비교 |
| 희귀 로봇만 의미 있음 | 낮은 등급을 전부 버림 | 기본 모델 유용성, 작업별 특성·수송 제약 검증 |
| RNG 때문에 필수 진행이 막힘 | 랜덤 기술·발견이 없으면 완료 불가 | 기본 상점과 표준 생태 경로 보장 |
| 저장·거래 중복 | 로봇·유물·현금 복제, 반쪽 매각 | 고유 ID·한 스냅샷 거래·중단 복원 검증 |
| 아트 비용이 루프 검증을 앞섬 | 많은 고품질 모델이 있지만 플레이 불가 | 작은 대표 아트 세트와 기능 프로토타입 병행 |
| 동적 건축으로 경로가 깨짐 | 로봇이 벽에 걸리거나 영구 정체 | 배치·경로 갱신·작업 접근점·구조 수단 검증 |
| 문명 콘텐츠가 별도 대형 게임이 됨 | 전투·외교가 생산 루프 개발을 압도 | MVP 후 독립 확장, 선택·가격 결과부터 설계 |

| 사운드 반복 피로 | 다수 로봇 소리가 겹쳐 확인음을 가림 | 변형·거리·동시 재생 수·버스 믹스 조절 |

### 2026-09-06 — 1.2 그래픽 피드백 반영

기존 장비 모델을 유지하고 Godot의 조명·그림자·접지 음영·재질별 반사와 지면·물·하늘 표현을 보강했다. 반복되는 원뿔 산은 Blender 암벽 3종으로 교체했다. 과도한 전체 메시 증설이나 추가 유료 소프트웨어 도입 없이 ‘성능 우선·균형·높음’ 프리셋으로 GPU 비용을 선택하게 한다. [측정과 선택 근거](../production/03-rendering-and-performance.md)를 참고한다.

### 2026-09-06 — 데모 이후의 전체 아트 교체와 품질 기준 장면

사용자가 게임 고도화 전에 가능한 높은 품질의 카툰 렌더링 예제를 요청했다. 이어서 **기존 3D 모델을 전부 교체할 예정이며 배경도 품질을 높이므로 기존 모델과의 비교에 집중하지 말 것**을 명시했다. 이에 D-15의 다음 작업을 기존 1.2 자산 보정에서 신규 로봇·시설·지형·식생을 포함한 독립 품질 연구 장면으로 전환한다. 전체 교체 방향은 확정 요구사항이며, 예제의 색감·셰이딩 방식·최종 성능 예산은 사용자 검토 전까지 후보로 유지한다. 이번 예제 제작이 모든 게임 자산의 교체 완료를 뜻하지 않는다.

### 2026-09-06 — 탐험 중심으로 게임 방향 확장

사용자가 행성 구매를 자유 우주 탐사·선정으로 변경하고, 탑승 우주선 성장·우주해적·실제 천체 자료·광활한 지표/지하·발견 연구·생물 표본 운송/이식·문명 단계/협상/거래를 요청했다. X-01~X-10은 확정 방향으로 반영한다. 기존 구매·지구 전용 원격 역할을 현재 목표에서 대체하고 나머지 원안 이력·현재 실행 결과는 보존한다. [비전](../game/01-vision-and-loop.md), [고도화 단계](06-exploration-expansion-roadmap.md)와 관련 시스템·기술·제작 문서를 갱신했다. 계약·과학 모델·생물·복구·단계 수량은 제안이며 이번에는 문서만 수정했다.

### 2026-09-06 — 단일 은하·티어·시드·생물 사례 추가

추가 사용자 지시에 따라 X-11~X-13을 반영했다. 하나의 은하, 티어별 시드 행성, 우측 또는 중심 방향의 고티어 분포, 생물 사례별 렌더링이 현재 방향이다. 중심 방향의 방사형 지도와 같은 항로의 가로 보기, 5티어 가중 분포·시드 계층·환경별 생물 사례 선택은 설계 제안이다. [은하·티어·시드](../game/11-galaxy-tiers-and-seeds.md)가 소관이며, 확정 티어 수·확률·생물 수량·게임 코드 변경은 아직 없다.

### 2026-09-06 — 굵은 검은선 스타일 예제 요청

D-15 후속 검토로 사용자가 제시한 굵은 검은선 중심의 카툰 표현을 로봇·자원·풀·건물 각 한 종에 적용했다. 고밀도 로봇 형상은 유지하고 새 광물·풀·정제소를 Blender로 제작했다. [실제 네 가지 렌더](../production/05-ink-style-study.md)로 검토하며, 전체 게임의 스타일 확정과 구분한다.

### 2026-09-06 — 호스트 포함 6인 협동과 공동 승선

사용자가 호스트가 만든 세션에 호스트 포함 최대 6명이 참여하고, 각자의 기본 캐릭터·소유 장비를 유지하면서 같은 우주선에 타고 다니는 구조를 요청했다. X-14~X-16은 확정 요구사항이며 D-05의 기존 싱글플레이 전제·멀티플레이 미정/제외를 대체한다. 현재 1.2의 싱글플레이 구현 이력은 유지한다.

[협동 게임 설계](../game/12-host-coop-and-crew.md)와 [네트워크·세션 저장](../technical/04-coop-networking-and-session-save.md)을 추가하고 경제·선체·시간·관심 지역·저장·개발 계획을 연결했다. 개인 원본 장비 유지, 공용 세계 장부, 신규 보상의 세계 내 보관, 출항 준비·권한 위임·호스트 종료 복구는 구체화를 위한 제안이다. 연결 서비스·영구 보상 반출·자동 호스트 이전은 확정되지 않았으며 게임 코드·네트워크 검증은 수행하지 않았다.

### 2026-09-06 — INK v1 공식 품질 기준 승인

사용자가 네 가지 검은선 카툰 예제를 승인하고 앞으로 개발할 모든 요소에 같은 품질을 적용하는 문서와 필수 요소 전체 재렌더를 요청했다. D-15의 시각 방향을 [INK v1](../production/06-rendering-quality-standard.md)으로 확정한다. 실제 게임 27종과 승인 기준작 4종의 렌더·도감 경로를 공통화하며, 기존 형상의 재제작 상태와 렌더 적용 완료를 구분한다. 최종 플랫폼 성능 예산과 전체 3D 모델 교체는 이 승인만으로 완료되지 않는다.

### 2026-09-06 — 순차 개발 착수와 품질 재확인

사용자가 설계 커밋 후 E0~E5 전체 순차 개발을 요청했다. 진행 중이던 카툰 작업의 완료를 기다린 뒤 기준 커밋을 보존하고 개발을 시작했다. 사용자는 추가 렌더링에서도 승인 품질을 반드시 지킬 것을 재확인했다. [확장 개발 기록](07-expansion-development-log.md)에 단계별 실제 결과를 누적하며 INK v1과 모델 형상 검수를 유지한다.

### 2026-09-06 — 3D 우주선 항해와 은하당 100만 행성

사용자가 성도 중심 실증을 수정해 3D 천체·우주선 이동을 주 경험으로 명시했다. D-16은 실제 3D 항해로 확정하며 조작 세부·착륙은 실증한다. 은하당 1억 개 요청은 이어진 사용자 수정으로 **100만 개**로 대체했다. D-20의 규모는 100만 논리 주소이며 전체 동시 생성·시뮬레이션은 요구하지 않는다. [소관 설계](../game/11-galaxy-tiers-and-seeds.md)와 [구현 기록](07-expansion-development-log.md)을 따른다.
