## 2026-09-10 — 항성계 밖의 동일 자연종 금지 방향과 2~3천 종 검토

사용자는 종 추가의 목적이 행성 탐험에서 같은 생물을 반복해서 보는 문제를 줄이는 데 있다고 정정했고, 같은 항성계 내 공유는 허용할 수 있지만 다른 항성계에서 완전히 같은 종이 자연 발생하는 것은 원하지 않는다고 밝혔다. 중심 방향의 생명권 집중·반대 방향의 무생물 비중 증가와 전체 2,000~3,000종 확장에 대한 의견을 요청했다. 현재 구현은 1,000개 기본형을 행성별 독립 선택하므로 항성계 간 중복이 남는다. 아직 분포나 종 수를 변경하지 않았다. [생태 소관](../game/09-discovery-research-and-ecology.md)의 항성계 독점 배정·조건부 생물권 비율·2,000종 후 3,000종 단계 확장은 제안이며, 최종 규모·생명권 항성계 예산·기존 저장 이행은 미정이다. 좌우 화면 좌표를 세계의 고정 생태 방향으로 취급하지 않고 자연 분포와 플레이어 반입 이식을 구분한다.

사용자가 최종 설계의 개발 항목 전체 확인과 구현을 요청했다. [개발 대조표](08-expansion-execution-matrix.md)로 X-01~X-16과 품질·저장·플랫폼 조건을 연결했다. E0-B의 지하 운반 로봇과 E0-C의 개인 프로필/호스트 세계 분리·ENet 6인·권한/거래 확정·선내 이동·공동 항해를 구현했다. D-05/D-22~D-24 관련 내부 선택으로 직접 UDP 접속, 고정 선내 좌표와 별도 외부 3D 뷰포트, 개인 원본 장비의 읽기 전용 반입, 세계별 재접속 자격, 도약 중 체크포인트를 채택했다. 접속 서비스 최종 확정이나 자동 호스트 이전·영구 보상 반출의 승인을 뜻하지 않는다. [협동 검증](../production/10-crew-cabin-and-playtest.md)과 [기술 선택](../technical/04-coop-networking-and-session-save.md)에 실제 근거·미완료 범위를 남겼다. INK v1을 유지하며 새 선내/탐사복/회수 상자는 최종 아트 승인과 구분한다.

### 2026-09-06 — 완성된 생물 모델을 행성 시드·연구·운송에 연결

사용자가 생물 제작 완료 후 누락 기능 진행을 요청했다. 현재 매질에 적합한 제작 사례를 명시적 환경/구조군 규칙으로 사용하고 행성 생태 시드에 계통·외형·고유 생명 기원을 고정한다. 도감의 시연용 출현 플래그를 일괄 활성화하지 않는다. 스캔 지식과 실물 표본, 착륙지 광물 창고와 원정 격리 화물을 분리한다. 단독 관리 구획의 천이·지원 팩·생물량을 먼저 연결하며 실제 선체의 질량/에너지·전투/번식·공동 지표 완료와 구분한다. [소관 기록](../production/11-seeded-ecology-integration.md)의 환경 수치·비용·지연은 밸런스 확정값이 아니다.

### 2026-09-06 공동 지표 구현 선택

- 생물 모델 완료 후 같은 시드 규칙을 공동 착륙 세계에 연결했다. 서버 위치·굴착·스캔 유지 시간·저장 성공이 실제 작업 결과를 확정한다.

- 미지원 매질의 생물을 임의의 땅에 배치하지 않는 기존 선택을 유지한다. 상세 구현/검증과 남은 범위는 [공동 지표 기록](../production/12-shared-surface-and-ecology.md)을 따른다.

[산업 소관 기록](../production/13-expedition-industry-and-contracts.md)에 검증·아트 및 후속 제한을 남긴다.
