# 최종 설계 개발 대조표

2026-09-08 [부재중 생산·FINCH 소형선 개별 구현](../production/57-distributed-industry-and-finch.md): 호스트 세션 중 거점 생산과 같은 항성계의 개인 출동·직접 운송·귀환을 연결했다. 실제 두 클라이언트의 서로 다른 행성 이동, 제작/비행 화면, 화물/재접속을 확인했다. 아래 부재중 생산 일시 정지·전원 동일 행성 전제는 이전 이력이며, 6인 인터넷·구조 회수는 후속이다.

2026-09-06 사용자가 최종 문서의 개발 항목 전체를 확인하고 구현하도록 요청했다. 소관 규칙은 기존 문서에 유지하며 이 표는 실행 순서·의존성·검증 누락을 추적한다. `기능 실증`은 최종 통합 완료나 아트 승인을 뜻하지 않는다. 세부 증거는 [개발 기록](07-expansion-development-log.md)에 남긴다.

진행 순서: **E0-B 로봇·지형/비용 → E0-C 공동 상태·접속·선내 → E1 탐사 사업 → E2 발견 연구 → E3 이동 연구실·생태 → E4 사건·문명·정산 → E5 통합 품질**. 자료가 없거나 실행 환경을 확보하지 못한 검증은 미검증으로 남기며 기능 목록만 존재한다고 체크하지 않는다.

생명체 모델 완성 후 우선 연결한 실행 범위와 상세 제한은 [행성 생태 통합 기록](../production/11-seeded-ecology-integration.md)을 따른다. 후속 [공동 지표 통합](../production/12-shared-surface-and-ecology.md)에서 착륙·굴착·생태·표본 동기화를 연결했다. 이후 [탐험 산업과 복원 계약](../production/13-expedition-industry-and-contracts.md)에서 지상 공동 사업 루프를 연결했다. [생물공학](../production/14-biological-field-engineering.md)과 [선박 모듈 성장](../production/16-vessel-refits-and-progression.md)을 후속 연결했다. 지하 산업·발견 연구 분기·행성 전체 테라포밍·문명 권리·새 선체/격납고 내부·출시 품질은 남아 있다.
