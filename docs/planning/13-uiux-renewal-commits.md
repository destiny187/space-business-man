# 자원 확장 UI/UX 개편 개발 계획

2026-09-08 사용자가 [조사 항목 U01~U13](../production/70-uiux-audit.md) 전체 개발을 승인했다. 범위가 많으면 나누어 개발한 뒤 다음 진행을 요청하는 방식도 승인했다. 이번 작업은 아래 3차로 나눈다.

## 확정 방향

- 쉽고 편한 인터페이스를 우선한다. 텍스트·탭·설명문을 계속 추가해 복잡성을 해결하지 않는다.
- **보유하지 않은 아이템은 0개 카드로 표시하지 않는다.** 보유 목록·화물·장치 투입 후보에서 숨긴다. 빈 실제 장착/드롭 슬롯, 제작 필요 재료, 발견 도감은 서로 다른 의미로 취급한다. 필요 재료가 없으면 ‘부족’을 표시하고, 이미 발견한 지식은 소지품이 사라져도 보존한다.
- 호스트 거래·개인 소유·실물 운송·제작 거리·연구 해금 조건을 유지한다. 선택과 조회는 재화를 소비하지 않는다.

## 단계와 완료 조건

| 차수 | 범위 | 커밋 단위 | 현재 상태 |
| --- | --- | --- | --- |
| UX01 | U01/U03/U08: 검색·분류·정렬, 이름/수량, 창고 이동량/목적지, 알려진 사용처 | 공통 자원 탐색과 창고 동선 | 완료 · [UX01 기록](../production/71-resource-browser-and-cargo.md) |
| UX01 | U02/U04/U09/U12: 전 자원 나열 제거, 작은 창 배치, 건설 카드 배경/이름, 잘못된 안내 | 건설·아이템 배치와 보유 표시 정리 | 완료 · [UX01 기록](../production/71-resource-browser-and-cargo.md) |
| UX02 | U05/U06/U10/U11: 발견 도감 전체 탐색, 제작 분류/고정 실행 영역, 생태 작업 단계, 항해 자원 펼치기/검색·생산 거점 | 발견 도감·제작/생태·항해/거점 | 완료 · [UX02 기록](../production/72-discovery-factory-and-navigation.md) |
| UX03 | U07/U13: I 개인 상태/장비, J 발견/공동 연구, 장치에서 실제 개조, 선체 위 모듈 슬롯/비교, 교역 검색 | 성장 메뉴 동선 → 선박 정비/교역 | 대기 |

1차는 실제 창의 검색·선택·수량 이동·마지막 수량 소진·메뉴 입력 차단·960×640 배치와 건설 렌더를 최소 확인하고 마감한다. 저장은 전용 테스트 세계를 사용한다. 단계별 실제 검증 결과와 남은 범위를 기록하며 전체 완료로 과장하지 않는다. 신규 모델/음원 대신 기존 Blender 자산과 ElevenLabs UI 피드백을 재사용한다.
