# 탐험 중심 고도화 계획

2026-09-06 사용자의 탐험·단일 은하·티어·시드·호스트 협동 요청을 위한 설계 계획이다. **이 문서의 단계·수량·완료 조건은 제안이며 구현 완료 항목이 아니다.** 기존 1.2 실행·테스트 이력은 [구현 현황](03-implementation-status.md)에 보존한다. 첫 버전 MVP는 역사적 기준이고 앞으로의 확장 우선순위는 이 문서를 따른다.

구현 착수 후 부분 완료와 근거는 [확장 개발 기록](07-expansion-development-log.md)을 따른다. E0-A의 100만 주소·시드·천문 카탈로그·3D 항해와 E0-B의 착륙·굴착·저장·지하 보행 왕복을 부분 구현했다. 지하 운반 로봇의 실제 왕복·화물 보존과 E0-C의 6인 접속·선내 이동·공동 항해까지 부분 실증했다. 최종 지형 아트·충전/다중 로봇·공동 지표 분업과 사업 통합은 남아 있다. [개발 대조표](08-expansion-execution-matrix.md)에 미완료 연결을 추적한다.

## 달라지는 게임의 중심

“내가 찾은 행성에서 발견한 원리와 생물이, 다음 행성을 바꾸는 나만의 기술이 된다.”

| 사용자 방향 | 설계 결과 | 다음에 검증할 핵심 |
| --- | --- | --- |
| 행성 구매 대신 우주 탐사·자유 선정 | [항해·우주선](../game/07-space-exploration-and-ships.md), 개척·계약 기반 경제 | 추천을 거절하고 다른 후보로 사업 시작 가능 |
| 광활한 오픈월드·지하 탐험 | [지역·지하·국소 굴착](../game/08-open-world-and-underground.md) | 실제 여행·굴착·물류·저장·재방문 연결 |
| 모든 발견의 연구·테라포밍 활용 | [연구·표본·생태 이식](../game/09-discovery-research-and-ecology.md) | A행성의 발견이 B행성의 해결 방법을 바꿈 |
| 다양한 단계의 외계문명·여러 선택 | [접촉·협약·교역·갈등](../game/10-alien-civilizations-and-diplomacy.md) | 거래·협력·철수·충돌에 서로 다른 결과 |
| 호스트 포함 최대 6인·개인 캐릭터/장비·공동 승선 | [협동 탐험대](../game/12-host-coop-and-crew.md), [네트워크·저장](../technical/04-coop-networking-and-session-save.md) | 서로 다른 장비로 같은 배를 타고 원정·이탈·재접속 |

추가 방향인 단일 은하·티어·시드·생물 사례 렌더링의 소관은 [은하·티어·시드](../game/11-galaxy-tiers-and-seeds.md)다. 중심 방향으로 고티어가 증가하는 한 은하 안에서 자유 탐험을 유지한다.

## 함께 제안하는 재미

- **탐사 계획의 재미:** 먼저 연구할지, 빠르게 착륙할지, 항로를 돌아갈지 고른다. 결과를 이해할 수 있는 불확실성을 둔다.
- **나만의 해결법:** 동일한 저온 행성을 산업 열원, 발열 생물, 생물 모방 설비로 서로 다르게 개척한다.
- **살아 있는 기억:** 직접 이름 붙인 우주선·로봇·발견 장소·배양 계통과 이전 사업의 변화가 남는다.
- **재방문의 발견:** 마른 강에 물이 흐르고, 녹은 얼음 아래 길이 열리며, 유적 복원으로 새 신호가 연결된다.
- **경관을 남기는 사업:** 광물을 캐는 수익과 자연 관측·보호·관광 계약의 수익을 비교한다.
- **원정을 위한 자동화:** 로봇이 반복 일을 맡고 플레이어가 돌아왔을 때 생산과 환경이 달라져 있다. 부재 중 계산 범위는 화면에서 명시한다.
- **성과를 남기는 정산:** 완전 매각 외에 복원 계약 완료·공동 운영을 제안한다. 사후 방문은 권한 범위 안에서 허용한다.

- **협동의 재미:** 같은 배의 조종·탐사·채광·연구·정비를 나눠 맡고, 지표와 지하의 발견을 공유한다. 고정 직업이나 6인 충원을 강제하지 않는다.

## 첫 확장 실증의 범위

거대한 우주 전체보다 **한 항성계의 후보 비교 → 한 행성의 지하 발견 → 우주선 표본 운송 → 다른 행성의 시험 이식 → 계약 정산**을 먼저 끝까지 연결한다. 아래 수량은 시험용 상한의 제안이며 콘텐츠 확정 수량이 아니다.

| 분야 | 첫 실증 | 이후 확장 |
| --- | --- | --- |
| 협동 기반 | 호스트+게스트에서 시작해 총 6인 정원·개인 장비·공동 승선·저장 검증 | 같은 원정 전체의 6인 인터넷·성능·장애 검증 |
| 우주 | 단일 은하의 성역 2개에 티어 분포·항로 검증, 항성계 1개의 후보 천체 3개와 보급 거점 1개를 상세 플레이 | 같은 은하 안의 다중 성역·항성계·장거리 원정 |
| 실제 데이터 | 소규모 카탈로그와 출처·가상 생성층 표시 | 더 많은 천체·관측 자료 갱신 도구 |
| 우주선 | 기본 선체 1개, 특화 선체 후보 2개, 센서·연구·생물실·추진 개량 | 다중 선체 보유·인양·제조사·내부 생활 공간 |
| 뽑기·개발 | 게임 내 시제품 추첨 1종과 확정 개발 경로·중복 처리 | 역할별 풀·누적 확정 획득·상세 밸런스 |
| 행성 | 상세 착륙지 2곳, 첫 행성의 인접 지역 2개와 지하 1계통 | 더 넓은 지역·행성 지질·수중·복수 깊이 |
| 지형 | 국소 굴착·수직 연결·저장, 로봇 1종의 지하 운반 | 광범위 굴착·복잡한 붕괴·전 지형 이동 |
| 연구 | 생물·유적·자연 경관에서 원리 각 1개 | 원리 조합·연쇄 발견·특화 기술망 |
| 생태 | 검수한 고유 생물 사례 1종의 환경 배치·휴면 해제·연구·운송·시험 이식 | 사례 라이브러리·군집 천이·공생·계통 관리 |
| 우주 사건 | 해적 1개·비전투 사건 1개, 회피·협상·실패 복구 | 다양한 활동권·추격·인양·세력 연쇄 |
| 문명 | 한 주요 문명의 조사·교역·복원 협약·갈등 분기 | 최소 3개 산업·통신 단계의 서로 다른 접촉 사례 |
| 사업 | 개발 권한 등록·단계 지급·정산·권한에 맞는 재방문 | 복수 거점·공동 운영·관광·장기 공급 |

실제 천체가 선택 범위에 없거나 표면 자료가 부족하면 별도 표시한 가상 후보를 포함한다. 원천 데이터 부족을 숨기기 위해 존재하지 않는 관측값을 만들지 않는다.

E0와 E0-C의 위험·협동 기반 실증 결과를 보고 E1을 시작하며, 전체 게임 자산을 미리 대량 제작하지 않는다. 신규 아트는 사용자 지시대로 교체 방향을 유지하고 실제 이동·굴착·기후 전환의 대표 장면에서 품질을 정한다. 기간·담당 인원·차기 버전명은 아직 정하지 않는다.

## 한 원정의 예시

1. **준비:** 기본선에서 궤도 센서와 생물실 중 우선 개량을 고른다. 첫 원정에는 필수 탐사 기능을 기본 제공한다.
2. **후보 비교:** 얼음 위성, 건조 암석 행성, 독성 대기 행성을 비교하고 자신의 기술로 해결할 수 있는 곳을 고른다.
3. **기지·자동화:** 수동 자원 확보로 기지를 세우고 로봇에게 반복 생산을 맡긴다.
4. **지하 발견:** 열 신호를 따라 동굴에 들어가 바위형 생물을 조사한다. 구조와 집수 원리도 관찰해 연구한다.
5. **작은 성공:** 시험 구획의 물·온도가 안정되고 휴면 생물의 활동과 풍경 변화가 드러난다.
6. **확장 판단:** 추가 개발, 협약 정산, 표본 운송을 선택한다. 현지 문명이 있으면 환경 목표와 권한부터 조율한다.
7. **항해:** 화물과 귀환 여유를 확인하고 출항한다. 해적 신호를 피해 돌아가거나 협상한다.
8. **다음 활용:** 다른 행성에 시험 서식지를 만들고 같은 계통의 생물을 정착시킨다. 이전 발견이 다음 사업의 비용·설비 구성을 바꾼다.

협동 원정은 각자의 캐릭터·소유 장비로 합류하고 출항 때 탑승·준비를 확인한다. 현장에서는 같은 행성 안에서 분업하며 연구·공동 화물·정산은 호스트 세계에 한 번 반영한다. 이탈·재접속 후에도 원본 개인 장비를 유지한다.

각 단계는 안내 순서의 예이며 행동 순서를 강제하지 않는다. 1.2의 30~45분 MVP 목표를 전체 확장 행성의 플레이 시간으로 그대로 사용하지 않는다. E1의 첫 후보 선정·첫 자동화, E3의 첫 연구 전이까지 걸린 시간을 따로 측정한다.

## 요구사항 인수 시나리오 — 전체 인수 미완료

- [ ] X-01: 행성 구매 없이 후보를 조사·비교·선택하고 첫 사업을 시작한다.
- [ ] X-02: 선체/모듈 추첨과 확정 개발을 각각 사용하며, 둘 중 뽑기를 생략해도 진행 가능하다.
- [ ] X-03: 해적·우주 사건에 선택·후속 결과·실패 복구가 있고 중복 보상이 없다.
- [ ] X-04: 실제 천체 출처·관측/추정/가상 표시가 있고 네트워크 단절·카탈로그 갱신에도 기존 세계가 유지된다.
- [ ] X-05: 광활한 지역과 지하를 왕복하며 굴착·운반·저장·재방문 상태가 이어진다.

- [ ] X-10: 협력·철수·파괴 선택의 알려진 결과를 예고하고 자산·협약·정산 이력을 보존한다.

- [ ] X-11: 한 은하의 성도·항로·행성 선택이 같은 세계 ID로 연결된다.
- [ ] X-12: 고정된 여러 시드에서 티어·행성·광맥·발견을 재현하고, 중심/우측 진행의 분포가 상승하며 T1 S등급과 T5 F등급을 구분한다.
- [ ] X-13: 검수한 생물 사례만 환경에 맞게 선택·렌더링하며 LOD·재방문·카탈로그 변경으로 종·능력이 바뀌지 않는다.

- [ ] X-14: 호스트가 세계·방을 만들고 호스트 포함 1/2/6인이 접속한다. 일곱 번째·동시 마지막 자리 요청을 거부하고 중도 합류·이탈·재접속·호스트 종료를 복구한다.
- [ ] X-15: 서로 다른 기본 캐릭터·장비 ID/등급/특성을 유지하고 정상 퇴장·연결 끊김·추방 후에도 원본 소유가 보존된다. 공동 화물·신규 세계 보상이 개인 장비로 복제되지 않는다.
- [ ] X-16: 같은 우주선에서 전원 탑승·출항·조종 인계·착륙·지표/지하 분업·회수·재출항을 완료하고 모든 참가자의 선체/위치/화물 상태가 일치한다.

X-ID는 [요구사항 추적](02-decisions-and-risks.md)에 정의한다. 구현 시 자동 규칙 검사, 실제 조작, 시각·음향, 성능, 플레이테스트의 근거를 분리해 채운다.
