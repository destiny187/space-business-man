# 신체 증강·탐사 연구 — 개발 명세와 커밋 계획

2026-09-08 사용자 승인: 보석을 소비하는 순수 플레이어 성장(이동속도·피해량·체력)과 버튼 구매를 넘어서는 고티어 연구를 추가한다. 우주선의 증강 장치·연구실, 개인 증강/공동 연구, 첫 3종 증강·T3 연구 1개부터 구현하는 방향을 승인했다. 이번 문서는 전체 개발 내역을 커밋 단위로 관리한다. **A01 이후 항목은 아직 구현 전이다.** 이전 초반 개방·직접 로봇 작업 선택은 별도 선행 커밋 `4c478ed8`이다.

## 한 줄기와 범위

`지하 탐험 → 보석/표본 회수 → 선박 귀환 → 개인 증강 또는 탐사 연구 → 실제 이동/전투/채집 성능 변화 → 다음 개척`을 연결한다. 자동화나 매번 같은 튜토리얼 순서를 요구하지 않는다. T1/T2 기본 설계 개방을 유지한다.

- **신체 증강**은 장비 교체·해제 뒤에도 남는 캐릭터 능력이다. 이번 첫 3종은 기동·전투·생명이다. 환경 적응은 후속 확장이다.
- **탐사 연구**는 발견·분석·시제품·현장 시험으로 기술 사용권을 얻는 원정대 활동이다. 해금과 실제 장비 제작 비용을 나눈다.
- 감정 품질·보석 소켓·강화 실패·장비 파괴·추첨·무한 단계·장비별 강화는 이번 첫 줄기에 넣지 않는다. 현재 보석은 수량 재고이므로 별도 품질 인벤토리가 이미 있다고 가정하지 않는다.
- 기존 생태 분석·표본 이식·공학 시험은 유지한다. 기존 생태 화면 전체를 한꺼번에 개편하지 않는다.

## 소유와 이전 저장

- `crew.members[character_id].augmentation`에 세계 안의 개인 증강을 저장한다. 장비 `loadout`이나 원본 개인 프로필에 합치지 않는다. 장비 매각/교체, 죽음·구조, FINCH 이동, 재접속으로 지워지지 않는다.
- 최초 범위는 **같은 호스트 세계에 귀속**한다. 다른 세계·원본 개인 프로필 반출은 미정이며 자동 이전하지 않는다. 클라이언트가 프로필에 임의 필드를 보내도 성장 단계로 신뢰하지 않는다.
- 공동 연구는 호스트 세계에 1회 저장하고 승무원 전원이 사용한다. 누구나 발견·시험에 기여하며 같은 조건을 중복 수행하도록 요구하지 않는다.
- 개인 증강은 자기 배낭의 보석만 사용한다. 공동 창고에서 무단 자동 차감하지 않는다. 연구도 참여자가 직접 낸 재료를 사용하고 공동 재고 자동 차감은 만들지 않는다.
- 이전 `research.logistics`의 유료 이동속도 성장은 동등한 기동 증강 단계로 한 번 옮긴다. 기존 가방 칸은 그대로 보존한다. 이후 개인 물류 개조는 가방만 증가시킨다. 기존 속도와 새 증강을 중복 곱하지 않는다.
- 단계·영수증·정상 형식 검증 후 이행한다. 재로드로 재료를 지급하거나 이미 소비한 증강을 다시 처리하지 않는다. 저장 실패는 성공 연출 전에 거절한다.

## 신체 증강 초기 규칙

아래 효과·보석 배정·비용은 **조정 가능한 첫 구현값**이며 사용자 확정 밸런스가 아니다. 값은 데이터 파일에 둔다.

| 계열 / ID | 단계당 효과 | 재료 | 시각 초점 |
| --- | --- | --- | --- |
| 기동 / `mobility` | 지상 보행·달리기 기본 속도 +10% | 사파이어 | 다리와 달리기 동작 |
| 전투 / `combat` | 소유자가 사용하는 펄스 무기 피해 +10% | 루비 | 팔·신경 경로와 표적 반응 |
| 생명 / `vitality` | 최대 체력 +20% | 에메랄드 | 흉부와 체력 눈금 |

- 최초 상한은 계열별 5단계, 비용은 A02에서 단계에 비례하는 보석 수량(초안 `3 × 목표 단계`)으로 데이터화한다. 실제 채집 가능한 매장량을 보고 조정한다.
- 효과는 기본값에 가산 비율을 한 번 적용한다. 달리기 배율은 그 뒤에 적용하며 선내 이동·로버/우주선 속도에는 기동을 적용하지 않는다. 피해는 최종 정수로 한 번 반올림한다. 채집량·채집 등급·지형 굴착 피해는 전투 증강으로 바꾸지 않는다.
- 최대 체력 증가 시 현재 체력은 자동 완충하지 않는다. 기존 회복·낙하 피해·구조 규칙을 따르고 HUD 상한과 검증 상한도 함께 바꾼다.
- 다이아몬드는 첫 T3 연구 뒤의 정밀 장비 소비처 후보로 남긴다. 첫 증강을 다이아몬드로 잠그지 않는다. A07에서 첫 실제 소비처를 함께 연결한다.

## 배치·물건·조작

### 공동 우주선

기본선에 무료 기본 장치 두 개를 제공한다. 선내 의료·정비 공간의 **증강 장치**와 연구 공간의 **표본 연구대**다. 출입·6인 동선·화물 적재 위치를 침범하지 않도록 A03에서 현재 선내 모델의 실측 위치를 정한다. 새 방 전체나 함선 전면 재제작을 선행 의존성으로 만들지 않는다.

착륙 중에도 같은 선박 장치에 접근할 수 있어야 한다. 현재 선내/선외 전환 구조상 선내 접근이 차단되는 경우에는 선박 측면 서비스 장치로 같은 기능에 접근하게 하고 별도 연구/증강 원장을 만들지 않는다. FINCH는 기본적으로 운송·기록 열람만 제공한다.

- 장치를 보고 F → 실제 자기 캐릭터 미리보기 → 부위 선택 → 보석 슬롯 → 전후 능력치 → 실행으로 진행한다. 슬롯 클릭과 드래그를 모두 지원한다.
- 카메라·스캔 헤드·보석 처리부의 준비/진행/성공/거절 상태가 구분된다. 완료 효과는 호스트 저장 응답 후 재생한다. 강제 카메라 이동·장시간 반복 의식은 피한다.
- 다른 승무원의 증강 조작이 장치를 오래 독점하지 않도록 개인 화면과 짧은 장치 상태를 나눈다. 장치 앞에서 전원이 줄 서야 하는 진행 제한은 넣지 않는다.
- J는 탐사 기록·연구 현황 열람, I는 장비와 자기 능력 확인이다. 실행 가능한 장치에 접근했을 때 연구·증강 조작을 제공한다. 휴대 메뉴에서 원거리 증강을 확정하지 않는다.

### 지상 기지와 현장

시제품은 기존 제작소에서 만든다. 현장 시험은 실제 대상·환경·측정 장치가 있는 장소에서 수행한다. 휴대 연구 기록에서 시험 목표를 선택하면 관측할 대상의 아이콘·범위·상태만 보조한다. 별도 지상 증강 장치와 연구대는 A09에서 건설 가능한 편의 시설로 추가하며, 첫 증강·연구를 위해 필수 건설하지 않는다.

### 제작 기준

신규 증강 장치와 연구대는 Blender 원본·GLB, 공통 제작 규격·INK v1로 제작한다. Godot 미리보기와 실제 Forward+ 장면을 모두 확인한다. 보석·캐릭터·시제품 모델은 가능한 기존 제작 자산을 재사용한다. ElevenLabs는 스캔 준비·가공 루프·증강 완료·분석/시험 결과 효과음을 제작하거나 적합한 기존 음원을 재사용한다. 접근 불가 시 필요한 프롬프트·미생성 항목을 기록하고 오디오 완료로 표시하지 않는다.

## 첫 T3 연구 — 심부 정밀 채집

첫 프로젝트는 기존 지하·보석과 연결되는 **심부 정밀 채집**으로 잡는다. 신규 적·고온 피해 시스템을 먼저 만들어야 하는 연구는 첫 구현의 의존성에서 제외한다. 내열/환경 처리 연구는 같은 구조로 후속 확장한다.

| 상태 | 필요한 실제 행동 | 연구대의 변화 |
| --- | --- | --- |
| 단서 없음 | 지하 광물 신호·지질 단서를 찾음 | 완성 장비의 윤곽과 단서 아이콘 |
| 발견 | T2 채집기로 회수 가능한 보석·지질 표본을 조사 | 발견한 실물 표본과 연결 선 |
| 분석 | 귀환 후 표본 일부를 연구대에 투입 | 보석 단면·계측 파형·결과 부품 |
| 시제품 | T2 재료로 시험용 채집 헤드 제작 | 미완성 헤드가 조립되고 시험 슬롯 활성 |
| 현장 시험 | 노출된 지하 광체에서 시제품을 사용해 실제 회수 | 헤드 동작·회수 진행·검증된 결과 표시 |
| 설계 개방 | 완료한 결과로 Mk.3 채집 설계 확정 | 완성 모델·III 표식·제작 위치 표시 |

- T3 제작을 열기 위해 다이아몬드나 T3 채집 자체를 요구하지 않는다. 시험용 헤드는 T2 광물만 회수하고 정식 Mk.3를 공짜로 대체하지 않는다.
- 단순 실제 시간 대기·크레딧 구매로 모든 단계를 생략하지 않는다. 이미 기록된 해당 발견은 인정하되, 새 시제품 시험은 호스트가 실제 채집 결과로 판정한다.
- 기존 세계의 보유 장비·제작 예약은 보존한다. 연구 도입 이전에 제공하던 해당 T3 설계는 이전 세계에 사용권으로 이행해 재잠금하지 않는다. 새 세계는 신규 연구를 따른다. 세계 단위 연구 버전과 설계 사용권을 A05에서 명시한다.
- 첫 프로젝트 완료 뒤 다이아몬드를 사용하는 정밀 헤드 개조를 A07에서 추가한다. 채집 간격 개선을 첫 효과로 삼되 상한/비용은 데이터로 관리한다. 증강과 별개인 장비 ID별 개조이며, 기존 채집 등급을 우회하지 않는다.
- 다른 T3~T5 설계·시설은 이 프로젝트로 일괄 잠그지 않는다. 각 콘텐츠를 담당하는 발견·시험과 대체 공급 경로가 준비됐을 때 별도 프로젝트로 연결한다.

의존성: A01→A02→A03→A04로 개인 성장을 먼저 완성하고, A03·A05→A06→A07로 첫 연구를 완성한다. A08은 두 흐름의 연결, A09는 거점 확장이다. 환경 적응·추가 T3~T5 프로젝트·고품질 보석 감정/정제·세계 간 계승은 다음 명세에서 다룬다.

## 검사 범위와 기록

초기 테스트 최소화 규칙을 유지한다. 각 커밋은 바뀐 거래/계산과 대표 화면·동작·소리만 확인한다. 이상이 발견된 경우 그 재현·수정 확인에 한해 범위를 넓힌다. 실제 6인 인터넷/장시간 검증을 매번 반복하지 않는다. 사용자 세이브는 건드리지 않고 격리 fixture를 사용한다.

A01 진행 및 근거는 [제작 기록](../production/62-character-augmentation-foundation.md)에 기록한다. 이 문서의 대기 항목을 코드·모델·실행 증거 없이 완료로 바꾸지 않는다.
