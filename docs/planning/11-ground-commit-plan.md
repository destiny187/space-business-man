# 지상 개선 커밋 계획과 작업 종료 지점

2026-09-07 사용자 요청으로 커밋 단위를 나눴고, 후속으로 **C00~C08 개발·개별 커밋을 승인받았다.** 2026-09-08 후속으로 **C09~C12 구현·개별 커밋도 승인받았다.** C13 이후는 이번 실행 범위가 아니다. 요구사항은 [최종 결정](09-ground-play-feedback.md), 구현 규칙은 [개발 명세](10-ground-development-spec.md)를 따른다. 이 문서는 새 기능·새 페널티를 추가하지 않는다.

## 커밋 공통 기준

- 커밋은 관련 도메인 규칙·호스트 판정·화면·저장 호환·필요한 효과/소리와 실제 확인 기록을 함께 묶는다. 정상 실행을 깨뜨리는 중간 코드를 커밋하지 않는다.
- 일반 플레이 기능은 현재 원정 진입 경로에 연결한다. 기존 협동에서 동작하던 기능을 싱글 전용으로 바꾼 뒤 나중에 고치는 순서를 쓰지 않는다. 호스트 권한·요청 중복 방지·저장은 기능별 커밋에 포함한다.
- 모델 변경은 Blender 원본/GLB, 실제 INK 렌더를 포함한다. 음향은 ElevenLabs 제작/기존 자산을 동작에 연결한다. 필요한 자산을 못 만들면 그 범위를 미완료로 보고한다.
- 확인은 해당 버그/기능의 최소 실행·화면·소리에 한정한다. 다중 클라이언트·전체 회귀·장시간 검사를 커밋마다 반복하지 않는다. 실제 확인한 범위와 코드 연결만 한 범위를 분리한다.
- **C13과 C16은 후속 기능의 준비 커밋**이다. 기본 게임에 미완성 제작 버튼·가짜 기능을 노출하지 않는다. 제작 검토/데이터 조회로 확인 가능하지만 사용자에게 완성 기능을 전달하는 종료 지점으로 추천하지 않는다.
- 아래 번호는 실행·범위 식별자다. 실제 수정량이 커져 기계적인 분할이 필요해도 승인받은 기능 범위는 늘리지 않는다. 기능별 소관 문서와 구현 현황은 해당 커밋에서 함께 갱신한다.

## 문서 기준점

**C00 — 최종 설계·정적 계산·커밋 계획 보존**

현재 미커밋인 이번 설계 문서, 목차/결정/구현 상태 연결, `tools/estimate_ground_pacing.py`, 본 커밋 계획을 한 기준점으로 남기는 안이다. 기존 사용자 변경이 새로 생겼다면 내용을 확인해 이번 문서 범위만 포함한다. 게임 기능 변경은 없다. C00은 `f313cd2d`로 보존했다. 기능별 진행과 확인 기록은 [실행 기록](../production/46-ground-play-repairs.md)을 따른다.

C09의 시간 관찰은 전체 게임/전 시드 반복 검증이 아니다. 설계 계산과 실제 걸린 시간을 구분하고 예산 이탈 원인을 짧게 기록한다. C10은 로버 없이 도보로 완료 가능한 경로를 제공하므로 로버 구현을 선행 조건으로 삼지 않는다. 기존 고정 실증 동굴과 접근 가능한 얕은 지하를 사용하며 200m 동굴망 전면 개편은 별도다.

C11에서 플레이어의 **숙련도 자체를 숨은 스탯으로 만들지 않는다.** 효율적인 경로·병행 작업으로 빨라지는 효과를 유지하고 연구로 제공하는 보너스만 데이터에 연결한다. 로버 전용 현장 물류 I/II 효과는 C14/C15에서 실제 소비처와 함께 추가한다.

C12는 현재 환경 집중도/적합도를 배수로 바꾸는 구현이 아니다. 처리 대상 총량·처리 능력·동일 목표 상태를 분리하는 도메인 변경을 포함하므로 별도 커밋으로 둔다. 협동 시간이 인원수만큼 줄거나 늘어난다고 미리 보장하지 않는다.

**C12 종료:** 현재 T1/T2 범위에서 연구·탐험과 협동 사업량까지 제공한다. 탈것 없이 진행 가능한 완결 지점이다.

C14는 다른 기능보다 큰 커밋이다. 제작만 되고 운전·충전·복구가 막히는 차량을 완료로 넘기지 않기 위해 지상 사용에 필요한 흐름을 함께 묶는다. 협동·저장을 C15로 미루지 않는다. C15의 운송 해금은 캐릭터 연구/선박 강화이며 행성 완료 횟수 잠금을 추가하지 않는다.

**C14 종료:** 행성 안에서 쓸 수 있는 로버까지. 행성 사이 운송은 아직 없다.

**C15 종료:** 제작한 로버를 강화하고 우주선에 실어 다음 행성에서도 사용한다.

| 번호 | 커밋 내용 | 완료 시 확인할 결과 | 선행 |
| --- | --- | --- | --- |
| C16 | 천체 시간 데이터·시드·저장 기반 | 항성/행성 물리 메타데이터·자전/공전·공유 시계·시간 압축·버전. 동일 시드와 위상 복원 확인, 기존 항해/하늘 활성 경로 보존 | C00 |
| C17 | 낮밤·태양/별·구름·광원 실제 연결 | 새 버전의 우주 공전/지상 태양 방향 일치, 별 이동·구름 흐름·조명/그림자·동주기 예외·야간 가독성. 저장/합류 시각 일치 | C16, C08 |

C16은 새 값이 기존 천체 표시 주기를 자동 변경하지 않는 준비 커밋이다. 새 버전의 실제 활성화·항해 위치/도착 호환은 C17에서 함께 연결한다. C17은 일반 자전과 동주기부터 전달하고 특수 공명 상태의 미지원 범위를 표시한다. 일사 발전·주야 기온에 의한 생산 난도 변경, 날씨/강수 전면 구현은 포함하지 않는다.

**C17 종료:** 이번 확정 개선의 첫 구현 범위 전체. P3~P5 생산망·다른 탈것·고급 날씨·성능 집중 안정화는 후속이다.

## 사용자가 고를 수 있는 범위

| 선택 | 전달되는 범위 | 추천 용도 |
| --- | --- | --- |
| C00~C03 | 문서 기준점 + 채집/건설/창고 | 가장 작은 불편 수정 묶음 |
| **C00~C08** | **기본 플레이 불편·로봇·시설 동작·환경 HUD** | **먼저 체감을 확인할 권장 범위** |
| C00~C12 | 위 범위 + T1/T2 탐험·연구·협동 사업량 | 새 기본 성장 루프까지 |
| C00~C14 | 위 범위 + 지상 로버 | 행성 이동 수단까지 |
| C00~C15 | 위 범위 + 로버 강화·행성 간 운송 | 이동 수단의 성장/계승까지 |
| C00~C17 | 이번 개선의 첫 구현 전체 | 낮밤까지 포함한 전체 범위 |

순서는 기본 제안이다. 예를 들어 **C00~C08 + C16~C17**을 선택하면 탐험/로버 전에 낮밤을 적용할 수 있다. 로버와 낮밤은 서로 선행 관계가 아니다. 의존성에 없는 앞 번호를 반드시 모두 실행할 필요는 없으며, 선택한 범위와 필수 선행만 작업한다.

현재 C00~C08은 **구현·개별 커밋 완료**, C09~C12는 승인 후 진행 중이며 C13~C17은 후속 계획이다. 실제 화면·음원 재생·저장 확인과 미확인 범위는 [실행 기록](../production/46-ground-play-repairs.md)에 정리했다.
