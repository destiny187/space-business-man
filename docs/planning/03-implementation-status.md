## 플레이 가능한 기능

- 지구의 청년 사업가가 행성을 구매하고, 1인칭 수동장비로 이동·점프·질주·채광·화물 반납을 수행한다. 관찰 카메라와 레이더, 단계별 업무 안내, 도움말이 있다.
- 행성 3종, 자원 5종, 시설 9종을 제공한다. 무작위 배치는 광맥·발견물의 간격을 확보하며 첫 자원은 기지 근처에 둔다.
- 시설 배치·회전·취소·철거, 유효·무효 색상 미리보기, 공유 보관함·창고 확장·초과 자원 폐기를 지원한다.
- 기술 10종, 기본·희귀 상점, 우주선 4단계, 로봇 3모델·3등급·랜덤 특성을 구현했다. 회수한 로봇은 ID·등급·특성을 유지한다.
- 로봇이 광맥 탐색→채광→운반→하역→충전→재개를 반복한다. 개별 자원 지정·작업 정지·재개·구조·수리가 가능하다. 접근 불가능한 목표를 거르고 출고 공간도 다시 찾는다.
- 전력 우선 배분과 설비별 대기 이유, 제작 예약·완료·취소, 대기·온도·물·생태·안정화 계산, 거주 등급 상한, 가격 내역과 일회성 매각 정산을 연결했다.
- 유적의 보존·반출·기술 분석, 황산 적응 미생물, 동물 보호·지구 판매, 문명 보호·파괴·노예화 및 경비로봇의 전투 작전을 제공한다. 선택은 보상·환경·판매 가치·현장 표현에 반영된다.
- 저장 파일의 구조·수치·고유 ID·소유권·예약 작업을 검증한다. 임시 파일과 정상 백업, 쓰기 실패 시 구매·매각·제작 완료 롤백, 사업 시작점 복구를 지원한다.
- 그래픽 3단계, 키 재설정, 마우스 감도, 음량, 전체 화면 설정이 저장·재실행에 반영된다. 한글 글꼴을 앱에 포함했다.
