# 첫 원정의 단계와 행성 환경별 개척 — 작업안

2026-09-08 변경: 초반 T2까지 기초 설계는 연구 구매 없이 사용할 수 있다. 재료·제작소 Mk.2 개조 등 실물 조건은 유지한다. 자동화는 필수 진행 단계가 아니며 로봇은 출고·재파견 후 대기한다. 플레이어가 자동(전체) 또는 해당 행성에서 발견한 광물 카드를 선택해 시작한다. R은 지정 광맥 작업 후 대기로 돌아간다. [현재 구현·검증·상위 해금 경계](../production/61-early-access-and-explicit-robot-work.md). 아래의 기초 기술 구매·기본 자동 채광·필수 자동화 안내는 이전 이력이다.


2026-09-07 사용자 요청을 구체화한 문서. **채광 로봇의 2티어 진입과 시드별 동굴은 구현 대상**이며, 아래 환경 시스템과 안내 개편은 검토할 제안이다. 환경 수치와 물성은 게임 규칙으로 단순화하며 실제 지구과학 시뮬레이션을 주장하지 않는다.

## 확정한 성장 순서

수동 채집 → 현장 발전·제작소 → 정제 금속·보강 프레임·제어 회로 → 제작소 Mk.2 → 채광 로봇 Mk.2 → 탐험과 생산의 분업.

자동 채집은 2티어 도달의 보상이다. 기초 제작소의 부품 가공은 1티어부터 가능해야 하며 첫 로봇이나 상위 채집기만 얻을 수 있는 재료를 선행 조건으로 요구하지 않는다. 이번 실제 비용은 [제작 기록](../production/46-seeded-caves-and-automation.md)에 둔다. 기존 소유 로봇·제작 예약은 보존한다.

## 첫 원정 완성도: 단계별 작업과 완료 조건 — 제안

| 단계 | 플레이어의 구체적 행동 | 필요한 안내·기능 | 완료 조건 |
| --- | --- | --- | --- |
| 1. 목적지 선정 | 가까운 착륙 가능한 행성을 조사하고 선택 | 거리·항속거리·관측 자원·환경 문제, 아직 모르는 정보 구분 | 왜 이 행성을 골랐는지 설명할 수 있고 실제로 도착 가능 |
| 2. 착륙·현장 파악 | 착륙선 위치를 기억하고 철·구리·암석·얼음 찾기 | 장비 슬롯과 조준 대상의 채집 가능 표시, 창고까지 거리 | 첫 자원을 직접 캐서 창고에 넣음 |
| 3. 수동 기반 마련 | 발전과 제작소를 배치하고 필요한 부품 생산 | 건설·제작 비용에서 보유/부족 재료, 전력 부족과 진행 중 구분 | 로봇 없이 정제 금속·첫 부품 제작에 성공 |
| 4. 첫 2티어 선택 | 채집기 개선 또는 제작소 개조에 부품 투자 | 강화 전후 성능과 소비 부품, 로봇 해금 조건을 같은 화면에서 확인 | 첫 강화 효과를 실제 채집/생산에서 체감 |
| 5. 첫 자동화 | Mk.2 제작소에서 로봇 제작, 광맥 배정, 충전기 마련 | 경로·배터리·작업 불가 이유, 재고가 늘어나는 표시 | 플레이어가 직접 채집하지 않는 동안 로봇이 채집·운반·하역·충전을 수행 |
| 6. 탐험과 생산 분업 | 로봇을 가동해 두고 동굴 조사·매장 자원 탐색 | 입구·귀환 동선·깊이·장비 조건, 배낭과 창고 여유 | 발견/자원을 들고 살아서 복귀하고 지상 생산물을 활용 |
| 7. 환경 문제 해결 | 현장의 병목을 확인하고 설비·소모품을 선택 | 문제의 원인, 먼저 해결할 조건, 설비가 처리하는 항목 | 목표 수치뿐 아니라 가동 상태와 주변 변화로 개선을 확인 |
| 8. 정산·다음 원정 | 계약 정산, 로봇 회수, 필요한 물자를 선적, 출항 | 인계되는 시설·남는 재고·실제로 가져가는 물자·보상 명세 | 다음 행성에서 보유 장비·로봇·선적 물자·잔액이 이어짐 |

모든 단계를 장문의 튜토리얼로 강제하지 않는다. 현재 행동에서 다음 한 단계만 대상·아이콘·짧은 문구로 안내하고 이미 수행한 행동은 다시 요구하지 않는 안이다. 2티어의 첫 강화와 첫 자동화는 같은 업적이 아니다. 강화 선택의 순서는 플레이어에게 남긴다.

"완성도" 작업은 위 과정에서 발견한 진입 누락, 설명과 실제 비용의 불일치, 필수 자원 교착, 지나친 왕복/대기를 구체적인 수정 항목으로 만드는 것이다. 이번 문서 작성은 이 안내들을 구현했다는 뜻이 아니다. 실제 시간·재료량은 수동 진행에서 측정한 뒤 조정하며 임의의 목표 분수를 확정하지 않는다.

## 환경을 어떤 구조로 다르게 만들 것인가 — 제안

행성 타입에 고정 정답 하나를 넣기보다 **행성의 기후 + 지역의 지질 + 물의 출처 + 지속 유입원**을 조합한다. 같은 사막 행성에서도 염류 분지와 금속 광맥 주변의 물 문제는 달라진다. 초반 T1은 주요 문제 하나, T2는 서로 연관된 문제 두 개부터 시작하고 각 티어 안에서 해결 가능한 수단을 보장한다.

| 분야 | 분리할 상태 | 플레이 선택 |
| --- | --- | --- |
| 대기 | 총기압, 산소 비율/분압의 적합도, 유해 가스 종류, 분진, 주변 유입 | 부족한 대기는 공급·보유, 과도한 대기는 감압, 독성은 종류에 맞춘 흡착/중화, 분진은 집진 |
| 온도 | 현재 온도, 외부 열 유입/손실, 낮밤 변동 | 냉각·가열 용량과 전력, 단열·차광·축열, 가동 순서 선택 |
| 수원 | 얼음·지하수·염수·대기 응축, 취수 가능량 | 해빙의 전력과 지하수 취수량 비교, 수원 위치에 맞춘 기지 배치 |
| 수질 | 염류, 용존 금속, 산도, 부유물, 처리 부산물 | 침전/여과·흡착·중화·담수화의 순서와 소모품 선택 |
| 지질·토양 | 투수성, 보수성, 염류, 영양 기반, 오염물 재용출 | 바닥 차수·저수, 배수, 토양 기반재, 오염원 격리 |
| 생태 | 정착 가능한 온도/수질/토양, 배양종의 적합성 | 환경을 먼저 맞춘 뒤 적합한 종 도입·정착 유지 |

물은 "얼음을 넣으면 물 점수 상승"에서 **취수량 → 처리 가능한 물 → 저장량 → 설비/생태 소비량**으로 나눠 간다. 정화한 물이 오염된 지층과 접촉하면 다시 나빠질 수 있다. 물이 많다는 이유만으로 식생용 물이 충분한 것은 아니다.

## 예시로 보는 다른 해결 순서

| 지역 | 문제가 생기는 원인 | 개척 순서 | 보여 줄 변화 |
| --- | --- | --- | --- |
| 염류 분지 | 지하수에 염분이 있고 지표의 염층이 계속 녹아듦 | 수원 조사 → 유입 분리 → 담수화 → 농축 부산물 보관 → 토양 개량 | 염분 띠 감소, 저장수 적합 표시, 식생 정착 |
| 금속질 산성 지층 | 지층에서 금속과 산성 물질이 다시 유입 | 오염층 차단/배수 → 중화 → 침전·흡착 → 처리수 저장 | 침전물과 오염 경계, 처리 설비별 다른 작업 효과 |
| 화산·열수 지대 | 지속 열 유입과 뜨거운 수원·가스 | 열원 관측 → 냉각·열 차단 → 가스 처리 → 취수·수질 처리 | 열기 약화, 냉각 구역 확대, 광맥 접근 가능 |
| 균열 빙원 | 물이 얼어 있고 노출된 관로/저수조에서 재결빙 | 전력 확보 → 해빙 → 보온 저장 → 필요 수질 처리 | 얼음 감소, 액상 저장량, 설비 가동/재결빙 구분 |
| 다공성 건조 지층 | 공급한 물이 빠르게 지하로 빠짐 | 지질 조사 → 차수·저수층 → 급수 → 보수성 토양 개량 | 누수 감소, 습윤 구역 유지, 급수 중단 후 변화 |

이 표는 신규 기계·공정을 이미 구현했다는 뜻이 아니다. 단순한 처리 점수에 장비 이름만 바꾸지 않고 공급/소비·원인 제거·처리 한계를 실제 규칙에 연결해야 한다.

## 구현을 시작한다면 — 작은 첫 범위

1. 기존 T2 염류·토양 상태를 지역별 규칙으로 분리한다. 과거 계약에는 조건을 소급 추가하지 않는다.
2. 우선 염류 분지와 균열 빙원 두 곳을 대비시킨다. 전자는 수질/유입, 후자는 해빙/보온이 핵심이다.
3. 물의 원수·처리수·소비량과 전력·처리 한계를 연결한다. 정밀 유체 시뮬레이션·배관 전체망은 이 첫 범위에 강제하지 않는다.
4. 조사 화면에 원인과 필요한 처리 능력을 표시하고, 기존 Mk.2 제품 중 필터·열전달 유닛·기반재를 먼저 활용한다.
5. 처리·정지·자원 부족·재오염·목표 유지가 실제 풍경과 설비 동작에 드러나게 한다.

이 환경 확장 범위는 사용자 논의를 위한 제안이다. 이번 변경에서는 동굴 구조와 로봇 해금만 구현한다.
