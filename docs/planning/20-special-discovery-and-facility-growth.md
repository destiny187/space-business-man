# 특수 발견 활용, 설비 종류와 강화, 복수 제조법 고도화 계획

2026-09-15 [196 추가 개발](../production/196-discovery-utilities.md): 껍질 쉼터, 표본 배양 조명, 시설 기초 침수 경보와 공명 정원을 기존 전시품과 별도로 구현한다. 광물 선별 공정과 모든 발견의 버프화는 이번 범위가 아니다.

2026-09-14 추가 구현: [195 전시품](../production/195-discovery-exhibits.md)에서 특수 발견 21종과 사건 22종의 연구 및 지표 전시, 도감의 현재 효과 설명을 추가했다. 아래 초기 단계 구분보다 이 현재 구현 범위가 우선한다.

2026-09-14 피드백 7번과 8번의 약식 초안을 구체적인 고도화 문서로 확장했다. 사용자는 발견물 목록을 정리하고 재미, 장식, 실용적 이득으로 다양하게 활용하도록 요청했다. 후속 정정에 따라 전기와 대기처럼 계열별로 서로 다른 설비 3종을 두고, 각 설비는 기본 상태에서 한 번 강화하는 2단계로 설계한다. 같은 제품을 저티어 또는 고티어 재료로 만드는 복수 제조법도 추가한다. 이전의 각 기계 3단계 성장 해석은 폐기한다.

**후속 상태: 발견 기반 환경 설비 2종의 첫 개발을 진행했다.** [194 구현 및 확인](../production/194-discovery-industry.md)의 응결 집수기, 열수 발전기와 개별 강화가 현재 범위다. 아래 전체 특수 도감, 장식, 계열 재편 및 복수 제조법은 개발 대기다. 최초 문서화 단계에서는 게임 코드, 모델, 음원과 저장을 변경하지 않았다. 기존 항해, 제작대 및 스캔 수정은 [193 구현 기록](../production/193-field-and-navigation-followup.md)의 별도 작업이다.

## 방향과 미정 항목

발견은 현장에서 먼저 재미를 주고, 연구 후에는 기록을 토대로 장식이나 특정 공정에 유용한 부품을 만든다. 스캔만 반복해 재료와 크레딧을 받는 방식은 되살리지 않는다. 하나의 희귀 발견을 못 찾아 기본 진행이 막히지 않도록 대체 연구 경로를 둔다.

설비 종류는 용도와 운용 조건으로 구분하고, 강화는 같은 설비의 성능을 한 번 개선한다. 플레이어에게 Mk 숫자로 단계 증가를 요구하지 않는다. 여러 종류의 조합과 강화로 T5까지 대응하며 같은 제품의 고티어 소재 제조법으로 기초 원료를 구하기 위한 강제 귀환을 줄인다.

전기와 대기의 각 3종 및 설비당 2개 상태는 사용자 방향이다. 다른 계열까지 적용한 6계열 18종, 구체적 명칭, 강화 수치, 전력 간섭과 제조법 배합은 설계 제안이다. 토양은 생태 계열에 포함한다. 발견물 목록과 활용 방향은 유지한다.

D02 이후 D03과 F01은 독립된 개발 작업으로 진행할 수 있다. F05는 D02의 연구 증거와 F01의 설비 구조를 사용한다. R02는 R01을 바탕으로 진행한다. F06은 각 계열의 실제 처리와 R02의 지속 공급 경로가 연결된 뒤 진행한다.

각 묶음은 데이터 등록만으로 완료하지 않는다. 새 모델은 Blender와 Forward+의 INK 렌더, 새 소리는 ElevenLabs 생성과 실제 가동 연결, UI는 960px에서 핵심 동작을 확인한다. 실패가 없으면 변경과 관련된 최소 실행만 수행하며 전체 회귀를 관행적으로 반복하지 않는다.

## 최초 문서 작업의 확인

`exploration_discoveries.json` 21개 ID, `exploration_incidents.json` 22개 ID와 활용표를 대조했다. 기존 50종 기획의 T3~T5 후보 30개 ID도 별도 표에 정리했다. 일반 생태는 네 카탈로그의 기본종을 합산했다. 현재 발견의 완료, 표본, 단서, 유한 물 방출 및 설계도 경로와 기존 T3/T4 설비 정의를 코드로 확인했다.

문서의 링크, 목록 누락과 중복을 정적으로 확인했다. 발견 21종, 사건 22종과 기존 고티어 후보 30종이 일치하고 신규 소관 문서의 끊어진 파일 링크는 없었다. 문서만 변경했으므로 Godot 실행, 게임 회귀, 모델 및 음원 제작은 하지 않았다. 최초 정정에서는 종류/강화 구분과 복수 제조법의 소관 링크 및 이전 해석의 잔존 여부를 추가 확인했다. 후속 두 설비의 실제 실행과 모델 확인은 194 기록을 따른다. 사용자가 별도 분석하기로 한 저장 실패 제보는 조사하지 않는다.
