우주 비즈니스맨 — Windows 테스트판 {version}

실행
1. ZIP을 '모두 압축 풀기'로 풀어 주세요.
2. 생성된 폴더의 Locus.exe를 실행하세요. Godot나 Blender 설치는 필요 없습니다.
3. Locus.pck는 게임 데이터입니다. 실행 파일과 같은 폴더에 두세요.

대상은 Windows 10/11의 Intel·AMD 64비트(x64) PC입니다.
Direct3D 12 또는 Vulkan을 지원하는 그래픽 장치와 드라이버가 필요합니다.
Windows ARM 전용 빌드는 아닙니다. 첫 실행에는 셰이더 준비 시간이 들 수 있습니다.
개발 테스트용 실행 파일로, 배포자 코드 서명은 적용하지 않았습니다.

그래픽과 실행 문제
- 기본은 Direct3D 12 / Forward+입니다.
- 실행이 안 되거나 그래픽 드라이버 오류가 나면 Start-Vulkan.cmd를 실행하세요.
  같은 게임을 Vulkan / Forward+로 시작합니다. 저장 데이터는 함께 사용합니다.
- 시작 화면이나 게임 하단의 '설정', 또는 F10 → 그래픽 프리셋에서 '성능 우선'을 선택하세요.
- 그래픽·시야거리 탭에서 지형 시야거리 600~8,000m, 렌더 배율, FSR, MSAA/FXAA/TAA,
  모델 LOD, 태양/실내 그림자 품질·거리, SSAO/SSIL/SSR, 글로우, 안개를 조절합니다.
- 화면·성능 탭은 창 모드/창 해상도, VSync, FPS 제한·표시를 제공합니다.
  화면 모드 변경은 15초 내 '화면 변경 유지'를 누르지 않으면 복구합니다.
- 조작·소리 탭은 시야각, 마우스 감도/세로 반전, 전체 음량입니다.
- 설정은 개인 PC의 client_settings.json에 자동 저장합니다. 설정 중에도 세계는 진행됩니다.
  시야거리는 원경 범위이며 굴착 청크·생물 활성 거리나 세계 시드를 변경하지 않습니다.
- 오류 기록이 필요하면 Start-Diagnostics.cmd를 실행하고 나타난 안내를 따라 주세요.
  로그는 Windows 임시 폴더의 Locus-Windows-test.log에 저장됩니다.
  이 실행기는 로그를 자동 전송하지 않습니다.

게임 시작
- '혼자 게임 시작': 방 주소·포트 설정 없이 오프라인으로 바로 원정을 시작합니다.
  혼자 저장한 기록이 있으면 '혼자 이어하기'로 표시합니다.
- '함께 플레이 · 최대 6명': 방 만들기 또는 호스트 주소로 참가합니다.
  직접 UDP 접속이며 기본 포트는 24560입니다. 같은 빌드로 참가하세요.
  인터넷 참가에는 호스트 포트 접근이 필요하고 Steam 로비/중계는 아직 없습니다.
- 이전 구매형 버전과 단독 실증 모드의 시작 항목은 제거했습니다.

혼자 첫 탐험
새 은하는 태양계 안의 지구 궤도에서 시작합니다. 편지를 접고 태양계를 둘러본 뒤
G '출격하기' 또는 Tab 항성 지도에서 목적지를 선택해 출발합니다.
성간 이동 후에는 행성에서 떨어진 곳에 정지합니다. 행성을 바라보며 스캔 결과를 확인하고,
E로 접근하거나 직접 비행하세요. 착륙 가능한 행성 가까이에서 F로 착륙합니다.
일부 항성계에는 정거장이 있습니다(첫 이동 목적지 제외).
정거장을 바라보고 F로 접근한 뒤, 근접 정지 상태에서 F로 물자 거래·선체 구매/교체를 엽니다.

탐험 조작
WASD 이동 / 마우스 시선 / C 우주선 외부 시점 / Shift 질주·우주선 가속
지표: 1~5 장비 선택 / 클릭으로 장착 장비 사용 / I 아이템·제작·개조
E 스캔 / Q 표본 채집 / F 주변 대상 상호작용
B 건설 / J 연구 / K 우주선 정비 / P 승무원 / Tab 항성 지도
Esc는 열린 창을 닫고, 플레이 중에는 계속하기·설정·종료 메뉴를 엽니다.
건설 배치: 클릭 확정·Esc 취소. 아이템창과 다른 창을 전환한 뒤 닫으면 시점 조작으로 돌아갑니다.
지상에서는 시설에 가까이 가서 F로 해당 시설의 작업 화면을 엽니다.
이륙하려면 착륙선 주변으로 돌아와 F로 착륙선 단말을 여세요.
여러 명일 때는 전원이 승선·준비한 뒤 조종사가 출발·착륙·이륙합니다.
공동 자금 거래와 선체 교체는 호스트가 확정합니다.

저장
혼자 플레이와 공동 탐험 모두 중요한 거래를 저장 성공 후 확정합니다.
기본 저장 경로: %APPDATA%\Godot\app_userdata\우주 비즈니스맨\
정확한 경로는 게임 설정에서도 확인할 수 있습니다.
세계별 solo_*.json / crew_*.json 및 기존 버전 저장을 사용하며, 최근 선택한 세계를 이어합니다.
개인 원본 프로필과 해당 호스트 세계에서 제작한 장비는 구분해 보존합니다.
기존 campaign.json과 이전 단독 탐험 기록은 삭제하지 않고 보존합니다.
압축을 새 폴더에 풀어도 같은 사용자 계정의 진행 기록은 유지됩니다.
새 은하 시작은 기존 세계 기록을 보존합니다.

2티어 생산·개조
B → 생산·개조에서 제작소와 제품 카드를 선택합니다. 원광을 정제재·부품으로 가공하며
가동 전력과 제작 시간이 필요합니다. I → 화물 → 공동 창고에서 필요한 수량을 인수한 뒤
무기·채집기·지형 변환기·탐험복을 Mk.2로 개조합니다. 시설·로봇은 B에서 개조합니다.
원정선의 첫 개량에도 같은 부품을 사용합니다. 신규 T2 현장은 필터·토양 기반재로
염류와 토양 조건을 개선해야 복원 계약을 완료할 수 있습니다.

포함 내용과 검증 범위
현재 커밋의 은하 탐험·항해·착륙, 행성 지형/자원, 현장 산업·장비와 2티어 생산을 포함합니다.
계획 문서의 모든 후속 기능이 구현됐다는 뜻은 아닙니다.
개별 기능의 화면·동작은 macOS Godot에서 확인했고, 이 Windows ZIP은
파일 해시·ZIP·PE x64·PCK 리소스 포함 여부를 검사했습니다.
Windows 실기에서의 실행·드라이버·입력·음향·프레임 성능은 아직 미검증입니다.

licenses 폴더에 Godot와 Noto Sans KR의 라이선스·의존성 고지가 있습니다.
build-info.json은 소스 커밋, 구성 파일 해시와 빌드 정보를 담고 있습니다.
