우주 비즈니스맨 — Windows 테스트판 {version}

실행
1. ZIP을 '모두 압축 풀기'로 풀어 주세요.
2. 생성된 폴더의 Locus.exe를 실행하세요. Godot나 Blender 설치는 필요 없습니다.
3. Locus.pck는 게임 데이터입니다. 실행 파일과 같은 폴더에 두세요.

대상은 Windows 10/11의 Intel·AMD 64비트(x64) PC입니다.
Direct3D 12 또는 Vulkan을 지원하는 그래픽 장치와 드라이버가 필요합니다.
Windows ARM 전용 빌드는 아닙니다. 첫 실행에는 셰이더 준비 시간이 들 수 있습니다.
개발 테스트용 실행 파일로, 배포자 코드 서명은 적용하지 않았습니다.

그래픽과 실행 문제
- 기본은 Direct3D 12 / Forward+입니다.
- 실행이 안 되거나 그래픽 드라이버 오류가 나면 Start-Vulkan.cmd를 실행하세요.
  같은 게임을 Vulkan / Forward+로 시작합니다. 저장 데이터는 함께 사용합니다.
- 화면이 끊기면 Esc → 설정 → 그래픽 품질에서 '성능 우선'을 선택하세요.
- 오류 기록이 필요하면 Start-Diagnostics.cmd를 실행하고 나타난 안내를 따라 주세요.
  로그는 Windows 임시 폴더의 Locus-Windows-test.log에 저장됩니다.
  이 실행기는 로그를 자동 전송하지 않습니다.

현재 확장 테스트 경로
시작 화면에서 '우주 탐험 · 사업 시작'을 선택하세요.
혼자 방을 만들거나, 호스트 포함 최대 6명이 같은 버전으로 접속합니다.
다른 PC에서는 호스트 주소를 입력합니다. 직접 UDP 접속이며 기본 포트는 24560입니다.
인터넷 접속에는 호스트 포트 접근이 필요하고, Steam 로비/중계는 아직 없습니다.

행성 주소 선택 → 전원 준비 → 실제 항해 → 전원 준비 후 착륙
→ B 사업 단말 → 무료 개발 등록 → F 채광·창고 반납 → 건설·자동화·환경 연구.
'우주선 정비 · 모듈' 메뉴에서 추진·연구·로봇 수송 모듈을 제작/장착합니다.

공동 탐험 조작
WASD 이동 / 우클릭을 누른 채 마우스로 시선 / C 우주선 외부 시점
지표: 클릭 굴착 / E 유지 스캔 / Q 표본 채집 / F 채광·상호작용
B 사업·건설 / 배치 중 클릭 확정·Esc 취소
공동 탐험은 개인 메뉴를 열어도 세계가 계속 진행됩니다.
출항 전 사업 자원을 반납하고 모두 우주선 주변에서 준비하세요.

기존 구매형 사업 모드도 별도로 남아 있습니다. 위 안내는 새 공동 탐험 기준입니다.

저장
공동 탐험은 호스트 세계를 저장합니다. 중요한 거래는 저장 성공 후 확정합니다.
기본 저장 경로: %APPDATA%\Godot\app_userdata\우주 비즈니스맨\
정확한 경로는 게임 설정에서도 확인할 수 있습니다.
공동 세계는 crew_world.json, 개인 장비는 별도 프로필에 저장됩니다.
기존 구매형 사업은 campaign.json과 campaign.json.bak를 사용합니다.
압축을 새 폴더에 풀어도 같은 사용자 계정의 진행 기록은 유지됩니다.
새 사업 시작 시 기존 기록 교체 여부를 확인하세요.

포함 내용과 검증 범위
100만 시드 행성 주소, 실제 3D 항해·지표 탐험, 공동 산업·생물공학,
선박 모듈 성장, 생명체 모델과 INK v1 렌더링, 한국어 글꼴을 포함합니다.
전체 출시 완성판이 아닌 현재 개발 단계 테스트판입니다.
공식 Godot 4.7.2 템플릿으로 Windows x64 실행 파일을 생성했습니다.
ZIP 무결성, 실행 파일 형식, 게임 데이터와 포함 리소스를 검사했습니다.
게임의 기존 기능·화면 검증은 macOS에서 수행했습니다.
Windows 실기에서의 실행·드라이버·입력·음향·프레임 성능은 아직 미검증입니다.

licenses 폴더에 Godot와 Noto Sans KR의 라이선스·의존성 고지가 있습니다.
build-info.json은 구성 파일 해시와 빌드 정보를 담고 있습니다.
