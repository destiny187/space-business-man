# 시드 지하·매장 자원·굴착 한계

2026-09-07 사용자 요청에 따른 **구현 전 구조 설계**다. 게임 규칙의 소관은 [오픈월드·지하](../game/08-open-world-and-underground.md), 자원 종류·채집·강화는 [광물·보석](../game/14-minerals-gems-and-enhancement.md)다. 아래 200m 상한·매장 자원·시드 동굴 방향은 확정 요구사항이며, 깊이 구간·생성 크기·경관 사례·데이터 구조는 구현용 설계 제안이다.

## 요구와 현재 상태

- 동굴이 없는 흙·암반 안에도 광물과 보석을 매장한다. 동굴은 접근·발견을 돕는 공간이며 자원의 필수 생성 조건이 아니다.
- 어디서든 200m를 넘는 굴착을 차단한다. 깊이는 **굴착·건설·테라포밍 전, 해당 수평 좌표의 최초 생성 지표에서 수직으로 잰 거리**로 정의하는 안을 채택한다. 200m 상한은 사용자 지시이며 이 측정 기준은 구현을 위한 해석이다. 경사진 갱도의 이동 거리는 200m보다 길 수 있다.
- 동굴 구조는 행성 시드·지질에 따라 재현하며 고정 실증 통로를 대체한다. 동굴별 지질 장식과 기억할 경관을 포함한다.
- 추후 동굴 아이템·재화 획득을 확장할 수 있게 한다. 이번 설계가 보상 목록·드롭률·경제 밸런스 또는 보상 구현의 확정을 뜻하지 않는다.

현재 코드에는 고정 통로/공동과 국소 굴착, 별도 시드의 지하 광맥 생성·노출/채집이 있다. `terrain.json`의 `minimum_depth=-72`는 현재 스트리밍 설정이며 최초 지표에서 200m를 재는 새 기반암 판정이 아니다. 광물 규칙은 깊이 10~58m와 생성 좌표 하한 -64를 사용한다. 이번 문서 작성에서는 코드·모델·음원을 변경하거나 새 기능을 실행하지 않았다.

## 뚫리지 않는 기반암

최초 지표 높이를 `H0(x,z)`, 위치의 높이를 `y`라 하면 깊이는 `H0(x,z)-y`, 기반암 경계는 `H0(x,z)-200`이다. `H0`는 저장된 지형 생성 버전으로 재현하고 플레이 중 바꾸지 않는다. 지표 위에서 재거나 기존 갱도 바닥을 새 지표로 삼아 한계를 늘리지 않는다. 자연수 수면은 지표 기준이 아니며 물 아래의 원래 지면을 사용한다.

- 경계 아래는 연속된 비굴착 기반암이다. 모든 캐릭터·로봇·지형 도구와 향후 폭발/지형 변형에도 같은 규칙을 적용한다. 장비 강화로 상한을 늘리지 않는다.
- 굴착 중심만 검사하지 않고 **굴착 부피 전체를 기반암 경계에서 잘라낸다.** 경사·측면·청크 경계·반복 굴착으로 우회할 수 없어야 한다. 일부만 굴착 가능하면 가능한 부분만 처리한다.
- 양수가 고체인 현재 밀도장에서는 동굴·굴착 계산 뒤 기반암 밀도를 합쳐 경계 아래를 다시 고체로 확정한다. 호스트 명령 판정·메시·충돌·클라이언트 미리보기·경로 탐색 모두 이 최종 밀도를 사용한다. 화면만 막거나 좌표 중심만 거부하는 방식은 사용하지 않는다.
- 전부 기반암인 요청은 세계/재고/자원 보상을 변경하지 않는다. 혼합 범위도 실제 제거된 부분만 굴착 결과로 계산하고 반복 빈 요청으로 보상을 얻지 못하게 한다.
- 기반암은 조밀한 결·다른 파손 흔적·스캔 아이콘과 짧은 실패 피드백으로 알린다. 호스트 거절 전에 성공 파괴·획득 연출을 재생하지 않는다. 색 하나에만 의존하지 않는다.
- 자연 동굴·광체·보상은 **전체 크기와 접근 여유**가 한계 위에 들어가야 한다. 중심점만 위에 있고 바닥이나 보석 끝이 기반암 안에 묻히는 배치는 제외한다. 생성 동굴의 바닥 목표는 우선 180m 이내로 두어 하부 여유를 확보한다.
- 스트리밍 세로 범위·낙하 구조 기준·저장 검증·탐지 범위·자원 깊이도 함께 갱신한다. 전역 `minimum_depth`를 -200으로 바꾸는 것만으로 완료하지 않는다. 높고 낮은 지표에 따라 필요한 청크의 절대 높이가 달라진다.

## 깊이별 공간 구성 — 제안

| 최초 지표 아래 깊이 | 공간·자원 | 탐험 역할 |
| --- | --- | --- |
| 0~20m | 토사·풍화암, 얕은 매장 광물, 작은 틈 | 지표 단서를 보고 짧게 파서 발견 |
| 20~70m | 완만한 동굴·가지 통로, 주력 광맥, 일부 보석 | 첫 지하 탐사와 수동 운반 |
| 70~130m | 연결 공동·지질 경계, 규모 있는 광맥·보석 포켓 | 운반 경로와 임시 거점 마련 |
| 130~180m | 깊은 공동·좁은 연결부, 지질에 맞는 드문 자원 | 장비·준비·귀환 경로를 고려한 탐사 |
| 180~200m | 두꺼운 하부 모암, 접근 가능한 매장 후보 | 직접 굴착의 마지막 구간, 기반암 예고 |
| 200m 경계 아래 | 파괴 불가 기반암 | 동굴·자원·보상 생성 제외 |

깊이만으로 보석이나 최고급 자원을 보장하지 않는다. 기존 행성 티어·주/보조 지질·장비 등급 제한을 유지하고 얕은 곳의 드문 발견도 허용한다. 깊은 낭떠러지만으로 난도를 올리지 않는다.

## 동굴 생성 순서 — 제안

1. **지질부터 결정한다.** 행성 지질과 지표의 암반·유로·빙하·충돌 흔적에서 동굴 성향을 고른다. 균열형, 퇴적 침식형, 용암관형, 빙하형 등을 게임 생성 사례로 사용한다.
2. **동굴계의 연결 그래프를 만든다.** 입구·갈림길·작은 방·큰 공동을 노드로, 통로를 연결선으로 둔다. 처음부터 모든 공간이 구멍으로 이어지는 전역 노이즈는 사용하지 않는다. 지역마다 동굴 밀도가 다르고 동굴 없는 지역도 남긴다.
3. **접근 가능한 주 경로를 확보한다.** 입구에서 주요 공동까지 기본 이동으로 왕복 가능한 폭·천장·경사를 가진 경로를 만든다. 주 경로에는 회수 수단 없는 필수 낙하를 넣지 않는다. 일부 순환로·지름길·막힌 가지를 추가한다. 장비가 필요한 수직 가지는 별도로 표시한다.
4. **연결선을 자연스러운 통로로 바꾼다.** 곡선 중심선을 따라 폭·천장 높이·타원 단면·기울기를 완만하게 바꾼다. 지질에 따라 층리·균열 방향을 따른다. 매 구간이 같은 굵기의 원통이 되지 않게 한다.
5. **공동과 바닥을 만든다.** 큰 방의 바닥에는 걷고 장비를 놓을 수 있는 공간을 남긴다. 가장자리에 낮은 단차·암주·무너진 잔해를 두고 천장 굴곡을 달리한다. 작은 노이즈가 통로를 막거나 바닥을 끊지 않게 한다.
6. **지표 연결을 제한한다.** 입구 후보는 노출 암반·계곡 옆·절벽 밑 등을 사용하고 착륙선·필수 시작 자원 동선과 겹치지 않게 한다. 지정 입구 밖의 천장이 얇아져 지표가 벌집처럼 뚫리지 않도록 최소 덮개 두께를 검사한다.
7. **자원·경관·미래 보상 지점을 배치한다.** 실제 노출면·기질·바닥 경사·통로 여유를 기준으로 배치한다. 길목 전체를 장식이나 보상으로 막지 않는다.
8. **국소 유효성 검사를 한다.** 입구→주요 공동의 연결, 기반암과 천장 여유, 플레이어/운반 장비의 통과 공간을 확인한다. 실패한 방·연결선만 안정된 재시도 번호로 보정한다. 청크 로드 순서나 플레이어 방문 시점으로 다시 추첨하지 않는다.

입구가 없는 봉쇄 공동도 드물게 허용하되 별도 유형으로 둔다. 이를 기본 접근 경로의 연결 실패로 숨기지 않는다. 지표 광물 신호·암반 균열 등에서 직접 굴착해 접근할 수 있도록 하고, 필수 진행 아이템을 봉쇄 공동에만 두지 않는다.

## 매장 자원과 동굴 자원의 관계

자원 시드를 동굴·장식 시드와 분리한다. 모암 내부의 렌즈형 매장지·층을 따라 이어지는 광맥·작은 보석 포켓을 먼저 정의한다. 동굴이 광체를 가로지르면 벽이나 천장에 일부 드러나고, 동굴이 지나지 않으면 완전히 매장된 채로 남는다. 빈 공동 중심의 공중에는 광체를 띄우지 않는다.

탐지는 매장 후보의 방향·깊이 범위를 알려 주고, 굴착은 모암을 열며, 채집기는 실제 드러난 광체를 회수한다. 각 기능은 기존 장비 규칙을 따른다. 현재 지하 광맥 노드에서 연속적인 광체 형태로 확장하는 것은 후속 구현이며, 노드가 있다고 연속 광맥이 이미 구현됐다고 기록하지 않는다. 동굴 개수나 장식 밀도를 바꿔도 미채굴 자원을 다시 추첨하거나 매장량을 늘리지 않는다.

## 지질 장식과 고유 경관 — 제작 후보

| 행성 계열 | 작은 지질 장식 | 동굴에서 기억할 경관 |
| --- | --- | --- |
| 산화 사막 | 붉은 낙석·층리 파편·퇴적 모래 | 퇴적층이 드러난 넓은 방, 굽은 마른 지하 유로 |
| 습윤 대륙 | 둥근 자갈·습윤 암면·조건부 침전물 | 유수 흔적의 아치와 침전 기둥, 낮은 물웅덩이 |
| 충돌 고원 | 각력·충격 유리·갈라진 암판 | 충격 균열을 따라 갈라진 비대칭 공동 |
| 균열 빙원 | 얼음 박편·빙결 돌·서리 | 푸른 얼음 벽과 빙하 균열 회랑 |
| 해빙 툰드라 | 빙하 퇴적 자갈·잔빙·진흙층 | 얼음과 암반이 만나는 해빙 경계의 방 |
| 극저온 설원 | 서리 바늘·불투명 얼음판 | 겹겹이 쌓인 얼음 층리와 서리 천장 |
| 불타는 화산 | 현무암 조각·용암 껍질·기공 | 굳은 용암관과 로프 모양 암면, 드문 열 균열 |
| 염류 분지 | 염류 껍질·침전 조각 | 소금층의 줄무늬 벽과 염류 결정 공동 |
| 황토 열수대 | 황색 침전·다공질 돌 | 열수 침전 단과 광물 띠가 이어진 방 |

대표 경관은 모든 방에 반복하지 않고 동굴계에 소수 배치한다. 장식 결정과 채집 보석은 실루엣·규모·조준/스캔 표시로 구분한다. 모든 밝은 결정을 채집할 수 있는 것처럼 표현하지 않는다. 생물·균사·식생은 실제 생태 조건과 생성 규칙이 있을 때만 추가한다. 물과 열 경관도 유체·열 피해 구현과 시각 표현의 상태를 구분한다.

Blender에서 지질별 파편·벽면 부착물·암주·대표 경관의 여러 변형을 제작한다. 모델 간격만 바꾸지 않고 형상·회전·크기·매몰·기질 색을 함께 변형한다. 지형의 실제 법선·층리와 연결하며 큰 암주는 충돌과 경로에 반영한다. 바닥 장식은 통로를 비우고 굴착으로 지지면을 잃으면 제거/재접지한다. INK v1의 굵은 윤곽·3단 명암을 유지하고 실제 손전등·그늘·이동 화면에서 검수한다. 물방울·열수·공명 등의 음원이 필요하면 ElevenLabs로 제작해 실제 게임에서 확인한다. 현재 이 동굴 전용 자산·음원은 미제작이다.

## 미래 아이템·재화의 확장 지점

동굴 생성 시 `discovery_socket`이라는 안정된 위치/용도 ID를 정의할 수 있게 한다. 유형은 광물 포켓·경관 조사점·매몰 잔해·유물 자리·은닉 화물 등으로 분리한다. 자연 동굴마다 이유 없는 보물 상자를 반복하지 않는다. 지금 보상을 넣지 않는 자리는 비활성 상태로 둔다.

- 보상 정의는 `loot_table_id`, 콘텐츠 버전, 티어/지질 조건을 참조한다. 확률·가격·개인/공동 귀속의 세부 규칙은 보상 구현 단계에서 기존 협동 자산 규칙과 맞춰 결정한다.
- 안정된 동굴 ID와 지점 ID로 개봉/회수 여부를 저장하고, 호스트가 지급과 소진을 한 거래로 확정한다. 동시 회수·요청 재전송·재접속으로 중복 지급하지 않는다.
- 그래픽 설정·청크 재생성·동굴 재방문은 보상을 초기화하지 않는다. 전리품용 시드는 동굴 형상과 분리한다.
- 새 보상 콘텐츠를 기존 탐사 지역에 소급 추가하는 정책은 별도 버전/이주 규칙을 둔다. 업데이트만으로 이미 회수한 지점의 보상을 다시 지급하지 않는다. 현재는 아이템/재화 콘텐츠를 생성하거나 지급하지 않는다.

## 스트리밍·저장 구조 — 제안

먼저 256m 단위 수평 생성 구역을 후보로 삼되 크기는 성능에 맞춰 데이터로 조정한다. 렌더 청크와 동굴계의 소유 구역은 분리한다. 동굴계의 노드/연결선을 인접 청크에서 조회하고, 청크 자체가 독립 동굴을 뽑지 않게 한다.

경계 연결은 정렬된 인접 구역 ID 쌍과 시드에서 공유 포털을 계산한다. 양쪽이 같은 좌표·폭·방향을 사용하고 소유자는 하나로 정한다. 청크 경계에 놓인 방·광체·경관도 하나의 ID를 유지한다. 주변 구역 여유 범위를 조회한 뒤 자기 청크의 밀도만 메시화한다.

저장 규칙 스냅샷에는 `underground_generator_version`, 최대 굴착 깊이, 깊이 측정 방식, 동굴/자원/경관 규칙을 둔다. 파괴·채굴 잔량·획득 기록·발견·시설 등 변경분만 누적한다. 시드 스트림은 동굴 구조·표면 변형·매장 자원·장식·미래 보상으로 분리한다. 호스트와 클라이언트는 동일한 생성 버전·규칙 서명을 사용한다.

기존 세계에는 새 동굴을 강제로 뚫지 않는다. 기존 고정 통로·굴착·시설·광맥 좌표는 보존하고 새 동굴계는 새 은하에서 사용한다. 200m 차단은 기존 세계에도 원래 지표/생성 버전을 기준으로 적용하는 방향이다. 이미 경계 아래에 저장된 편집·플레이어·시설이 있을 경우 원본을 백업한 뒤 명시적 이주/복구가 필요하며 조용히 매몰·삭제하지 않는다. 현재 기존 세계의 전수 호환성 확인이나 이주는 수행하지 않았다.

## 구현 순서와 완료 기준

1. 200m 기반암 밀도/명령 판정과 해당 깊이의 스트리밍·복구를 연결한다. 경계 위·아래·혼합 부피·측면 굴착의 최소 확인으로 차단을 검증한다.
2. 동굴 없이 모암에 매장된 광체의 탐지→노출→회수와 기반암 안쪽 생성 제외를 연결한다.
3. 산화 사막·화산 또는 빙하 중 대비되는 두 계열로 시드 동굴의 입구·주 경로·공동·경계 연결을 구현한다. 실제 창에서 왕복 가능한지 먼저 확인한다.
4. Blender 지질 장식·대표 경관·필요 음원을 실제 동굴에 적용하고 다른 계열로 확장한다.
5. 이후 사용자 요청에 따라 동굴 아이템/재화 보상표와 회수 거래를 연결한다.

새 시스템은 기존 높이 함수·원거리 지형·밀도/굴착·공동 표면 명령·광맥 생성·운반 경로·세션 저장에 함께 연결해야 한다. 초기 개발의 테스트 최소화 규칙을 유지하며, 실제 변경한 깊이 경계·청크 연결·채집·저장 문제를 확인하는 범위로 검증한다. 문서 작성만으로 200m 굴착·시드 동굴·경관·보상 구현 완료를 표시하지 않는다.
