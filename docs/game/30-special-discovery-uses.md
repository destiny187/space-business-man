현재도 노래하는 돌기둥 등에는 환경군 공통 음원의 근접 재생 경로가 있다. 플레이어 행동에 응답하는 개별 연주와 연구 후 장식 재생은 새 설계다. `catalogue_only` 17종 모두가 스캔 한 번으로 끝나는 것은 아니다. `observe`와 `miner` 모드는 스캔으로 완료하고, 굴착, 차광, 표본, 물길 개방 등 다른 모드는 기존 단계 처리가 남아 있다. 표본은 해당 행성의 유효한 실제 계통이 있을 때만 회수한다.

기존 설명의 “보석을 회수했습니다” 같은 표현만으로 현재 지급을 판정하지 않는다. 속 빈 수정암과 화석 둥지는 현재 일반 보상 데이터가 비어 있다. 후속 결과 카드는 실제 발생한 행동과 지급 내역을 기준으로 써야 한다.

## 2. 활용 원칙

발견은 먼저 그 자체로 볼거리와 작은 놀이가 되어야 한다. 장식과 실용 효과는 그 장소를 기억하고 다시 활용할 이유를 만든다. 모든 발견물에 동일한 능력치 보너스를 붙이지 않는다.

- **즐거움:** 소리, 빛, 물, 흔적, 기구가 이동과 조작에 반응한다. 이미 조사한 장소에서도 반복 감상과 협동 놀이가 가능하다.
- **장식:** 장소를 통째로 철거하는 대신 기록을 토대로 복제품이나 전시품을 제작한다. 이름, 원산 행성, 발견자와 원정 기록을 보조 표찰에 남긴다.
- **이득:** 실제 정보를 더 잘 읽기, 공정 하나의 원료 절약, 국소 보호, 선택 가능한 설비 원리, 기존 표본 이식과 유한 회수를 활용한다. 장식 자체를 필수 버프 세트로 만들지 않는다.
- 스캔 완료만으로 일반 광물이나 크레딧을 반복 지급하는 방식은 되살리지 않는다. 실물 회수는 채집, 수리, 운반 등 실제 행동과 유한한 현장 재고를 요구한다.
- 한 원리에는 여러 발견물이나 실험실 대체 연구 경로를 제공한다. 특정 시드의 희귀 장소 하나를 못 찾았다고 기본 생산과 테라포밍이 막히지 않는다.
- 미니게임 성공은 조작 숙련만 요구하지 않는다. 소리의 파형과 빛의 상태도 함께 보여주고 혼자서도 모든 핵심 연구를 끝낼 수 있게 한다.

## 6. 발견부터 활용까지의 공통 흐름

| 단계 | 플레이어 행동과 화면 | 기록 및 실제 성과 |
| --- | --- | --- |
| 발견 | 접근하면 소리, 빛과 형태로 특이점을 알림 | 방문만으로 재료 지급 없음 |
| 스캔 | T로 이름, 정체, 관측된 현상, 가능한 다음 행동 표시 | 일반 생물은 기존 번호, 특수 발견은 별도 기록 카드 |
| 현장 체험 | F 상호작용 또는 기존 도구로 그 대상에 맞는 행동 | 영구 상태를 바꾸지 않는 감상은 자유 반복. 실물 회수는 유한 상태 |
| 기록 및 연구 | J 특수 발견에서 체험과 증거 확인, 연구대에 재료나 실제 표본 투입 | 검증된 증거와 공동 연구를 분리. 근처에 없던 사람도 공동 연구 결과 이용 |
| 제작 | 장식 제작대에서 복제품, 해당 공장에서 실용 부품 제작 | 실제 재료 소비와 호스트 확정 후 물건 지급 |
| 배치 및 활용 | B의 장식 분류에서 배치, F로 소리, 밝기, 패턴 조절 | 장식과 실용 설비의 가동 조건 및 효과를 명확히 분리 |

새 **장식 제작대**는 연구로 얻은 복제품, 표찰, 전시 용기와 모형을 만드는 소형 무전력 작업대 제안이다. 기본 장비와 무기는 기존 장비 제작대, 금속은 금속 공장에서 만든다. 장식 제작대가 선행 필수 연구나 기본 건설 재료의 공급처가 되지 않는다. 선내는 보행 동선과 창문을 보존하는 전시 슬롯부터, 지표는 자유 배치부터 구현한다.

특수 도감은 일반 도감을 대체하지 않는다. 한 생물에서 발생한 특수 사건은 그 종의 기존 카드와 교차 연결하고 종수를 늘리지 않는다. 카드에는 정체, 원산지, 관측한 행동, 현재 가능한 체험, 장식 설계, 연구 근거, 실제 효과를 서로 구분해 표시한다. “이미 연구함”과 “지금 가동 중”도 다르다.

스캔 결과 문구 예시: **노래하는 돌기둥 / 바람이 틈을 지나며 서로 다른 음을 냅니다 / F로 공명 비교 / 공명 풍경 제작 연구 가능**. 보이지 않은 원리나 얻지 않은 효과를 확정형으로 쓰지 않는다. 게임 표시 문구에 중간점을 사용하지 않는다.

## 7. 효과, 연구와 반복 방문의 규칙

여기부터의 수치와 동작은 구현용 제안이다. 최종 밸런스 데이터는 후속 작업에서 확정한다.

- 장식은 기본적으로 외형과 체험을 제공한다. 실용 부품을 별도 제작해 장착해야 공정 효과가 생긴다. 장식 개수를 채워야 생산이 가능한 구조는 피한다.
- 발견 원리는 무료 기록으로 확보하고, 공학 연구에는 기존 연구대와 정상 재료 비용을 사용한다. 표본 연구에는 실제 표본이 필요하다. 동일 원리를 찾는 다른 장소는 새 색과 패턴, 보충 증거가 되며 무한한 연구 속도 배수가 되지 않는다.
- 실용 효과는 대상 설비, 공정, 조건과 처리 단위를 갖는다. 원료 절약은 해당 레시피 한 번에서만 계산하고 누적 소수 잔량을 보존해 반올림 복제를 막는다. 수율, 속도와 소비 감소는 같은 효과로 숨겨 합치지 않는다.
- 동일 원리의 활성 효과는 대상 설비당 가장 강한 하나를 적용하는 안을 우선한다. 서로 다른 원리는 제한된 장착 슬롯을 경쟁한다. 현재 생태 보조와 공학 개조의 중첩 방식은 [시설 문서](31-facility-growth-and-tradeoffs.md)에 둔다.
- 감상과 연주는 반복 가능하다. 같은 장소의 보상과 연구 증거는 한 번만 처리한다. 부품을 뜯은 장소가 다시 온전해져 재료를 반복 주지 않는다.
- 복제품은 원본의 위치, 생물 원산지와 시드 배치를 바꾸지 않는다. 실물 전시에는 소모나 운송 비용을 적용하되 장식을 철거하면 그 물건을 돌려받고 최초 보상은 재발행하지 않는다.
- 장식에는 전투 판정, 생물 공격 유도, 임무 완료 자격이 없다. 발광 수조 조명이 실제 배양용 광원이 되는 경우에는 별도의 실용 설비 사양이 있어야 한다.

## 10. 저장, 협동과 변경 범위 설계

기존 발견 ID, 장소 좌표, `stage`, `claimed`, 표본과 설계도는 보존한다. 새로운 `experience`, `research_evidence`, `decor_recipes`는 별도 버전의 추가 기록으로 제안한다. 이전 `claimed`를 초기화해 기존 보상을 다시 받을 수 있게 하지 않는다. 기존 완료 기록은 이름과 장소를 알고 있는 상태로 인정하고 새 체험 증거만 별도로 채운다.

공동 도감과 장식 설계는 원정 공유, 제작 재료와 운반 물건은 현재 개인 배낭 및 공동 창고 규칙을 따른다. 배치물의 권한도 기존 건설 정책을 재사용한다. 진행 중 합류에는 완료 기록과 현재 가동 상태를 보내며 매 프레임 음원 위치나 애니메이션 전체를 저장하지 않는다.

F 입력은 대상 ID, 행동, 예상 단계만 보내고 호스트가 거리, 장소 상태와 재료를 검증한다. 영구 변경과 물건 지급은 호스트 확정 후 연출한다. 단순 감상 입력은 저장 거래와 분리한 제한된 현장 메시지로 처리하되 영구 연구 증거를 클라이언트 주장만으로 지급하지 않는다.

배치와 효과 갱신은 해당 물건과 영향 범위의 설비만 처리한다. 모든 발견물, 전체 생태 또는 다른 행성의 건물을 순회하지 않는다. 도감은 바뀐 카드만 갱신하고 닫힌 전시 화면은 미리보기 모델을 생성하지 않는다. 장식의 위치 목록과 활성 효과 목록을 나누어 효과 없는 전시품이 매 틱 산업 계산에 참여하지 않게 한다.

## 11. 입지와 생산을 바꾸는 발견의 보강

사용자는 모든 발견에 효과를 줄 필요는 없지만 일부 발견이 환경에 맞는 건설과 이어지길 요청하고 개발을 승인했다. 감상과 전시 중심 발견은 그대로 남긴다. 아래 연결은 효율 수치만 추가하는 방식보다 새로운 공급 경로, 공정이나 배치 선택을 제공한다.

## 12. 자연의 원리를 외형에서도 읽게 한다

2026-09-14 사용자 정정: 자연물에서 배운 장치는 그 자연물을 닮거나 자연과 결합한 형태여야 한다. **자연의 구조가 본체를 이루고, 필요한 기계 부품이 그 기능을 돕는다.** 일반 공장에 돌 하나를 장식으로 붙이는 접근은 피한다.

응결 집수기는 원본 이슬 돌그릇의 얕은 수반, 침전된 가장자리와 집수 홈을 살린 계단식 수반이다. 작은 냉각기와 수거 배관을 가장자리 아래에 붙인다. 열수 발전기는 원본 굴뚝의 속 빈 광물 기둥을 재현하고 분할 고정구, 열 회수 배관과 작은 터빈을 붙인다. 두 종류 모두 강화해도 자연적인 본체를 유지한다.

연구 후 제작한 광물질 구조는 원본을 무료 복제하거나 자연물을 통째로 회수했다는 뜻이 아니다. 실제 제작 재료를 사용하고 원래 발견 장소는 보존한다. 장치에 실제 살아 있는 표본을 쓰는 경우만 원산지, 운송과 생장 조건을 적용한다. 외형의 이끼색 광물 피막을 살아 있는 표본이나 추가 생태 효과로 취급하지 않는다.
