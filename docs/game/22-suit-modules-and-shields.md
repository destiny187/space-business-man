# 내장 모듈·랜덤 장비·실드

## 2026-09-09 확정 방향

사용자는 캐릭터 외형을 바꾸지 않는 장착 아이템과 디아블로처럼 무작위 능력치가 붙는 파밍을 요청했다. 방어 부위에 **실드**를 추가한다. 후속 확정으로 희귀도는 일반·개량·희귀·유니크·전설의 5단계이며 전설에는 특수 효과가 붙는다. 일반 무작위 옵션의 낙하 감소 제외는 유지하되, 사용자가 다시 요청한 **전설의 추가 낙하 완충**은 기존 감소 후 남은 피해에 곱해서 적용한다. 획득·장착·실제 효과를 T3까지 개발한다. 인간 상대 전투에서도 실드를 사용하는 방향이며 인간 적·PvP 자체를 이번 요청으로 구현하지 않는다.

이전 탐험 T1/T2는 `7587f6f0`에 커밋했다. 이번 T3 범위는 **아이템 티어와 획득**이며 사건형 탐험의 T3 신규 시나리오 전체·시설 설계도 획득/정거장 구매는 별도 후속이다.

## 현재 구현안

| 부위 | 물건 | 기본 성능 | 전용 옵션 예 |
| --- | --- | --- | --- |
| 수납 | 압축 수납 모듈 | 가방 수납 칸 | 추가 칸·운반 감속 완화·달리기 효율 |
| 기동 | 구동 보조 모듈 | 이동속도 | 점프·달리기 효율·운반 |
| 생존 | 생명유지 모듈 | 최대 체력 | 체력·회복 효율·달리기 효율 |
| 방어 | 실드 발생기 | 최대 실드 | 실드 용량·재충전 속도·대기 감소·교전/폭발 저항 |
| 작업 | 도구 제어 칩 | 채집 속도 | 채집·무기 피해·사격 속도 |
| 탐지 | 센서 코어 | 분석 속도 | 분석·충전 대기·회복 효율 |

한 부위에 하나를 장착한다. 일부 체력·이동·회복 옵션을 공통으로 허용하되 같은 아이템에는 동일 옵션을 중복 추첨하지 않는다. 신체 증강은 영구 성장, 모듈은 교체 가능한 성능이다. 곱연산 효과와 상한은 데이터로 제한하며 기존 증강·염색·외장 단계는 바꾸지 않는다. 에너지 소모·광물 중첩 한도·탐지 거리처럼 이번에 연결하지 않는 능력은 추첨 풀에 넣지 않는다.

T1~T3는 기본 성능과 무작위 수치 범위를 높인다. **일반/개량/희귀/유니크/전설**은 추가 옵션 **0/1/2/3/3개**를 갖고, 전설은 여기에 **특수 효과 1개**를 더 갖는다. 티어와 희귀도는 독립된 축이다. 유니크도 현재는 무작위 옵션형이며 이름이 고정된 별도 세트를 뜻하지 않는다. 기존 특급의 내부 ID `epic`은 저장 호환을 위해 유지하고 표시만 유니크로 바꾼다. 기존 물건의 옵션은 다시 추첨하지 않는다.

현재 일반/개량/희귀/유니크/전설 가중치는 T1 **45/40/15/0/0**, T2 **25/39/30/5/1**, T3 **10/28/44/15/3**이다. 모듈 지급이 결정된 뒤의 비율이며, 발견 35% 지급 확률과 별도다. T1은 희귀까지, T2부터 낮은 확률로 전설을 얻는다. 가격·확률·수치는 밸런스 초안으로 `suit_modules.json`에서 관리한다. T4/T5 행성의 이번 모듈 보상은 T3으로 제한하며 T4/T5 장비가 구현됐다고 기록하지 않는다.

## 획득·정리

- 기존 현장 사건을 완수하면 모듈 한 개를 자원/장비 보상과 함께 회수한다. 지진 공동은 마지막 결정 채굴 시 지급한다.
- 조사형 발견은 완수 시 35%의 장소별 고정 추첨으로 한 개를 추가한다. 사건과 발견은 원정 공유 상태이며 실제 회수한 플레이어가 소유한다. 다른 플레이어에게 복제 지급하지 않는다.
- 발생 장소·세계 시드에서 결정되는 옵션은 재접속·저장 다시 열기로 바뀌지 않는다. 이미 완료한 장소에는 소급 보상을 생성하지 않는다.
- 쿠퍼테크는 방어/작업, 난파선은 수납/생존/방어/탐지, 드론은 수납/기동/작업처럼 장소에 따라 풀을 제한한다. T3 행성의 하위 사건에서도 T3 모듈을 얻는다.
- 기초 일반 T1 실드 발생기는 개인당 한 번 철 6·구리 4로 직접 조립할 수 있다. 장착은 별도로 한다. 첫 실드를 무작위 발견에만 의존하지 않는다.
- 개인 모듈 케이스 32칸(장착분 포함)을 별도 관리한다. 보유 도구/자원은 기존 배낭 칸을 유지한다. 모듈 종류 확장으로 초반 배낭이 즉시 막히는 일을 피하려는 이번 구현 선택이다.
- 미장착 모듈은 확인 후 분해해 티어만큼 정제 철을 회수한다. 케이스/배낭이 가득 차면 획득/분해 거래를 거절하고 원래 물건을 보존한다. 공동 창고 모듈 이동·교환·판매·옵션 재설정은 후속이다.
- 작은 가방으로 교체하거나 해제했을 때 기존 화물이 넘치면 거절한다. 슬롯을 바꿔도 물건이 삭제되지 않는다.

## 실드 규칙

실드 발생기를 장착하면 별도 방어량이 생긴다. 현재 기초 최대치는 T1 30/T2 55/T3 85이며 옵션으로 늘어난다. 기본적으로 마지막 교전 피해 후 6초를 기다리고 초당 8씩 회복한다. 교전/폭발 저항 적용 → 실드 소모 → 초과분 체력 피해 순서다. 실드가 0인 상태에서도 새 피해는 대기를 다시 시작한다.

낙하 피해는 기존 증강·탐험복 규칙대로 체력에 적용하고 실드로 흡수하지 않는다. 전설 관성 완충이 있으면 기존 계산 결과를 다시 절반으로 줄인다. 기존 30% 감소라면 `원래 피해 × 0.70 × 0.50 = 원래 피해의 35%`이며 80% 감소로 더하지 않는다. 이후 환경 피해를 추가할 때는 피해 종류에 따라 실드 통과 여부를 별도 정한다.

장착/교체는 체력이나 실드를 즉시 채우지 않는다. 최대치가 줄면 현재치를 새 최대치로 제한하고, 발생기 교체는 재충전 대기를 다시 건다. 긴급 구조 시 실드는 비우며, 저장·재접속은 현재량과 대기를 보존한다. 기존 저장은 실드 없는 상태로 이행한다.

## 전설 특수 효과 — 현재 11종

각 전설에는 부위별 후보 중 하나가 시드로 정해진다. 같은 특수 효과를 두 부위에 장착해도 한 번만 적용하고 서로 다른 효과는 조합한다. 수치는 아래 데이터의 현재 밸런스 초안이다.

| 효과 | 발동·성능 | 등장 부위 |

자가복원은 자신이 공격하거나 피해를 받으면 대기하며 장비 교체로 대기를 우회하지 못한다. 선박 주변의 기존 회복·자가복원·처치 회복은 과잉 회복 전환에 연결된다. 별도 회복 아이템 체계를 구현했다는 의미는 아니다. 분석 충전은 기존에 분석한 대상의 반복 스캔에 보상을 주지 않는다. 처치 효과는 마지막 공격자에게 적용한다.

실드 파쇄는 실드 소모에만 1.5배를 적용한다. 기본 피해 40, 상대 실드 30이면 기본 피해 20만으로 실드 30을 없애고 남은 기본 피해 20이 체력에 적용된다. 실드가 없는 적의 체력 피해는 늘리지 않는다. 새로 생성되는 T3 이상 쿠퍼테크 전투로봇에 실드 60과 피격 후 6초/초당 8 회복을 적용해 실제 대상을 제공한다. 기존 생성된 로봇의 실드 없는 기록은 그대로 둔다. 이는 새 T3 사건 시나리오 전체 구현과 구분한다.

기획 참고는 [디아블로 IV 공식 패치의 조건부 고유 효과·회복의 보호막 전환](https://news.blizzard.com/en-us/article/24092662/diablo-iv-patch-notes-1-0-1-2)이다. 발동 조건과 자원 전환 구조를 참고해 이 게임의 탐험·운반·분석·실드에 맞춰 구성했으며 이름과 설명을 복제하지 않는다.

## 표현·권한

I → 모듈에 6부위 슬롯, 소유 격자, 기존 Blender 산업 부품의 INK 미리보기, 티어/희귀도/옵션과 장착 대비 증감, 장착·해제·분해를 둔다. 이번 첫 표현은 기존 부품 모델 재사용이며 부위별 신규 최종 모델 제작을 주장하지 않는다. 월드 캐릭터 외형은 유지하고 피격 순간의 실드 효과만 표시한다.

실드 HUD는 체력과 별도의 청색 게이지·수치·충전 대기를 표시한다. 피격·소진을 구분하고 기존 ElevenLabs 제작 음원을 재사용한다. 요청은 소유자·현재 장비 버전을 호스트에서 검사하고 성공한 저장 결과 뒤 UI/효과에 반영한다. 클라이언트가 옵션·티어·가격을 정하지 않는다.

전설 상세에는 효과 이름·발동 조건을 금색으로 표시하며 교체 시 잃는 기존 특수 효과도 보여 준다. 순간 발동은 호스트의 발동 기록을 받은 뒤 HUD·기존 발견 음원으로 알린다. 지속 효과는 해당 수치와 이동/재생 상태로 확인한다.
