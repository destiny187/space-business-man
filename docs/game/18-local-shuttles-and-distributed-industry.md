# 항성계 소형선과 분산 생산

2026-09-12 **항성계 내부 해적 습격 첫 구현**: 새 원정의 FINCH는 추격기 한 척을 만나도 독립 도주와 긴급 복구로 이동을 계속할 수 있다. 비무장 운송선 역할·성간 이동 금지·개인 화물을 유지하고 실제 포드 인양을 연결했다. [해적 소관](28-pirate-interdiction.md), [제작·확인·기존 저장 보존](../production/139-pirate-flight-combat.md)을 따른다. 아래 최초 운송 기록과 이번 후속을 구분한다.

## 2026-09-08 이탈 승무원 회수 추가

사용자가 이탈 FINCH 회수를 승인했다. 호스트는 P 승무원 창에서 접속이 끊긴 출동자를 공동선으로 회수할 수 있다. 접속 중/재접속 처리 중에는 거부하며, 개인 가방·장비·소형선 화물을 같은 소유자에게 보존한다. 공동 창고 자동 하역·상시 자동 운송은 하지 않는다. 회수 후 재접속은 현재 공동선 위치에서 이어지고, 다른 출동/조립이 없으면 기존 공동 출항 조건을 다시 사용할 수 있다. 아래 ‘출동 위치에서 재접속’은 회수하지 않은 경우에 유지된다. [구현·저장 경계·확인](../production/60-shuttle-recovery-and-snapshot-packets.md).

## 2026-09-08 사용자 확정 방향

부재중 거점 생산을 먼저 개발하고, 운송은 플레이어끼리 직접 맡는다. 작은 소형선을 제작하여 다른 플레이어가 같은 항성계의 다른 행성에 다녀오는 협동 콘텐츠로 연결한다. 앞서 제안한 자동 운송·묶음 처리 중심 2순위는 이번 작업에서 대체한다. 성간 원정은 공동 우주선을 유지하고, 항성계 내부에서만 승무원의 독립 출동을 허용한다. 최대 6인·개인 캐릭터와 소유 장비 보존은 유지한다.

## 1. 호스트 세션 중 거점 생산

운영 중인 복원 현장과 보유 생산 거점은 현재 착륙지와 관계없이 같은 호스트 틱에서 한 번 생산한다. 호스트 세션 종료 후 현실 시간 소급 생산은 없다. 기존 실제 광맥 잔량·로봇 배터리/운반·지원 지형/경로·전력 배분·제품 입력·창고 한도를 사용한다. 시설 입력과 출력은 해당 거점 재고에만 반영하며 운송으로 바꾸지 않는다. 모든 현장의 3D 장면을 실행하지 않고 호스트 데이터와 지형 필드로 처리한다. 별도 대규모 집계 근사나 무한 오프라인 생산은 아니다.

제작·채광·정화 결과는 호스트 저장 성공 뒤 공개한다. 한 저장이 실패하면 공개 상태를 보존하고 세션 진행을 정지한다. 재방문/재접속으로 이미 진행한 생산 시간을 다시 지급하지 않는다. 기존 로버 조립의 출고 공간 검사는 실제 해당 행성 충돌 공간에서 완료한다.

## 2. 직접 운송 소형선 — 첫 구현 기준

FINCH라는 1인승 소형선, 개인별 한 대·세계 최대 6대·화물 4칸·Mk.2 이상 제작소의 조립을 첫 구현값으로 사용한다. 이름·제작 시간·레시피·용량은 사용자 확정 밸런스가 아니며 `data/shuttles.json`에서 관리한다. 제작 부품은 작업자의 가방에서 소비한다. 제작소 전력과 실제 진행을 거쳐 소형선을 받는다.

- 착륙선 옆 소형선에 접근해 출발한다. W/S·마우스·Shift의 기존 직접 조종과 같은 항성계 행성 선택/접근을 사용한다.
- 다른 승무원은 원래 행성에서 작업을 계속한다. 각자 위치·항해·착륙·지형/재고 전송을 구분하며, 호스트가 같은 행성의 공유 작업을 확정한다.
- 첫 FINCH의 적재 대상은 자원·생산품·개인 장비다. 로버 적재·공동 격납고 로봇 이동·표본 연구/이식은 공동 원정선에서 수행한다.
- 개인 화물창에 직접 적재하고 도착지에서 인수한다. 원정선 공동 화물과 다른 소형선 재고를 원격으로 차감하지 않는다.
- 성간 목표는 호스트에서 거부한다. 공동 원정선으로 돌아와 함께 다음 항성계로 간다. 소형선 조립/출동 중 공동 출항은 대기한다.
- 원정선이 있는 행성으로 귀환하여 합류한다. 소형선의 남은 화물은 소형선에 보존하며 합류를 자동 하역으로 취급하지 않는다.
- 연결 종료 시 조종 입력을 멈추고 소형선·가방·화물·행성 주소를 호스트 저장에 보존한다. 재접속은 해당 출동 위치에서 이어간다. 타인의 캐릭터/개인 프로필로 이전하지 않는다.
