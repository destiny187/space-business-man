## 확정 방향과 제안의 경계

**사용자 확정 방향**

- 현재의 적은 광물·행성 조합을 확장하고 행성마다 얻을 수 있는 자원에 차이를 둔다. 지표와 지하의 자원 구성을 행성 생성 구조에 포함한다.
- 다소 판타지적인 요소를 허용하며, **최고급 장비에 공통으로 쓰이는 소재 약 2종을 추가**한다.
- **주로 지하에서 얻는 보석류**를 추가하고, 추후 장비와 별개의 캐릭터 강화 및 무기 강화 등에 활용한다. 채집과 지하 탐험의 장기 목표로 연결한다.
- 후속 확정: 소재 이름은 **암흑광**, 보석은 **루비·사파이어·에메랄드·다이아몬드**로 쓴다. 공허 명칭은 추후 콘텐츠용으로 남긴다. 현재 구성의 광물·보석 모델을 제작하며 흙·지면 받침 없이 광물 자체가 지표에 노출되도록 한다.

**설계 제안**

이전 대화의 일반 광물 10종에 최고급 소재 2종을 더한 **산업·장비 소재 12종**, 별도 **보석 4종**으로 시작한다. 암석·얼음·물·기체·생물 재료·크레딧은 별도 분류다. 여기서 분류는 게임 아이템 용도이며 현실 광물학의 분류와 같다는 의미가 아니다. 원광과 정제재, 보석의 품질 차이를 각각 새로운 원소 종류로 중복 집계하지 않는다.

아래 명칭·ID·16종 구성은 제작 데이터에 반영했다. 레시피·분포 확률·강화 수치는 아직 밸런스 확정값이 아니다.

### 보석의 형태·품질·가공

- 광체에서는 **보석 원석**을 얻고, 감정·가공을 거쳐 강화에 사용할 수 있게 하는 흐름을 제안한다. 감정은 숨겨진 고정 정보를 확인하며 다시 뽑는 행동이 아니다.
- 종류는 효과 계열, 품질은 강화 재료로서의 가치, 가공 상태는 사용 준비 여부를 뜻한다. 장비의 제작 등급·강화 단계·행성 티어와 별개다.
- 초기 품질 구간은 일반·고순도·완전 3단계를 제안한다. 명칭·품질 산정·가공 수율은 미정이다.
- 낮은 품질도 초급 강화나 가공에 사용한다. 상위 품질만 유효하고 나머지는 전부 버리는 구조를 피한다.
- 원석→가공 보석 변환은 입력과 출력을 한 거래로 확정한다. 품질을 올리는 합성·분해·보석 장착 소켓은 별도 검토 항목이며 이번 요구만으로 확정하지 않는다.

## 행성·깊이별 분포

2026-09-07 확정 방향: 광물·보석은 동굴이 없는 모암에도 매장한다. 동굴은 광체 일부를 드러내거나 접근을 돕는 공간으로 두고, 직접 굴착해 매장지를 찾는 경로도 유지한다. 200m 굴착 상한과 광체 전체의 기반암 제외·노출/회수 구조는 [지하 설계](../technical/07-seeded-underground.md)를 따른다. 아래 깊이별 가중치는 제안이며 새 분포의 구현 완료를 뜻하지 않는다.

행성의 환경과 지질을 별도 축으로 정한다. **채굴 가능한 주력 자원 2~3종, 보조 2~3종, 희귀 0~1종**은 초기 배치 가이드이며 최고급 소재나 보석을 모든 행성에 하나씩 보장하는 할당 규칙이 아니다. 판타지 소재가 있는 행성도 일반 광물 공급 역할을 함께 가진다.

| 구역 | 자원 배치와 플레이 제안 |
| --- | --- |
| 지표 | 기본 원료와 노출 광맥, 지하 매장지의 단서. 보석은 드물게 노출될 수 있음 |
| 얕은 지하 | 일반 광맥·소규모 보석 원석. 초기 장비로 지하 채집을 배울 구간 |
| 중간 지하 | 규모 있는 광맥·다양한 보석. 탐지·굴착·운송망의 가치가 커짐 |
| 깊은 지하 | 고품위 광체·고순도 보석·최고급 소재 후보. 보급·열·압력·접근 경로가 중요 |
| 특수 공동·균열 | 드문 큰 결정·특이 소재. 위치 탐색과 안전한 회수 과정이 발견의 핵심 |

**보석의 주 획득처는 지하**로 둔다. 더 깊다고 무조건 최고 품질이 나오는 것은 아니며 행성 지질·매장 조건을 함께 고려한다. 깊이의 정확한 미터 경계·가스/열 위험 구현·수중 채굴은 [오픈월드·지하](08-open-world-and-underground.md)의 기술 범위와 맞춘 뒤 정한다. 가스/얼음 거대행성에는 착륙 지하 광맥을 만들지 않는다.

태양계/시작권에는 기초 생산망을 만들 재료와 초기 보석 탐사 경로를 마련하되, 최고급 소재 둘을 시작 행성에 모두 배치하지는 않는 안을 제안한다. 나중에도 물류·자동화와 다른 행성 탐사가 필요해야 한다.

## 지하 채집과 자동화

`지표/동굴 단서 → 스캔·매장지 탐색 → 진입로 굴착 → 채집기로 원석 회수 → 운반·가공 → 제작 또는 강화`를 하나의 흐름으로 연결한다.

- 지형 변환기는 길과 모암을 열고, 자원채집기는 광체/보석을 회수한다. 굴착만으로 보석을 중복 지급하거나 필요한 채집 등급을 우회하지 않는다.
- 한 보석을 얻기 위해 소모품·미니게임을 반복 강제하지 않는다. 최초 발견·진입로·회수 방법 선택을 수동 탐험의 중심으로 둔다.
- 조사 후 안전해진 일반 광맥은 로봇 자동화로 넘긴다. 특수 결정도 적합한 연구·정밀 채집 장비를 얻으면 자동화할 여지를 둔다. 희귀함을 이유로 영구 수동 채집만 강제하지 않는다.
- 형태·결정 성장·광맥 단서·조준 진행·채집 결과로 상태를 전달한다. 색과 텍스트만 다른 자원으로 끝내지 않는다. 실제 제작 때 Blender·INK v1·ElevenLabs 기준을 적용한다.

## 제작과 강화의 구분

| 성장 방식 | 대상·결과 | 재료의 역할 |
| --- | --- | --- |
| 장비 제작·상위 등급 제작 | 새로운 장비 개체·기본 성능 | 일반 광물과 최고급 공통 소재 |
| 순수 캐릭터 강화 | 캐릭터 자체 능력의 지속 성장 | 가공 보석과 해당 연구·비용 |
| 무기·장비 강화 | 소유한 장비 개체의 성능 성장 | 효과 계열에 맞는 가공 보석과 보조 재료 |

### 캐릭터 자체 강화

장착 장비의 보석 효과만으로 대체하지 않는다. 캐릭터 ID에 귀속되는 별도의 성장 기록을 두어 **무기를 교체하거나 맨손이 되어도 강화 성과가 남는 방향**을 제안한다. 지구력·운반 능력·환경 적응 등을 후보로 삼고 공격력만 반복 상승시키는 구조를 피한다. 구체적인 능력치·강화 시설·세계 간 계승은 미정이다.

### 무기·채집 장비 강화

무기/장비 ID별로 강화 이력을 기록한다. 무기는 출력·효율·제어, 채집기는 작업 효율·정밀도·안정성처럼 기본 기능에 연결한다. 강화 때문에 무기가 자원채집기를 대신하거나 채집기가 지형 변환기를 대신하지 않는다. 보석 강화가 기본 제작 등급의 채집 제한을 우회하는지는 별도 결정 전까지 허용하지 않는 안을 제안한다.

### 초기 강화 방식 제안

처음에는 **재료를 소비하면 명시된 결과를 얻는 확정 강화**를 권장한다. 강화 실패·장비 파괴·하락·확률 재추첨은 사용자 확정 요구가 아니다. 최대 단계·효과 상한·필요 수량·분기 선택·초기화/환급·성공 확률은 아직 확정하지 않는다. 희귀 보석 확보가 탐험 목표가 되고, 반복 실패가 주 소비처가 되는 구조는 우선하지 않는다.

모든 캐릭터가 같은 보석만 찾거나 한 개체에 강화가 무한 누적되지 않도록 효과 계열·상한·비용을 후속 설계한다. 최고급 장비와 보석 강화는 일반 테라포밍 사업을 시작하기 위한 필수조건으로 두지 않는다.

## 생성·소유·저장 연결 — 설계 제안

- 세계 생성 시 행성 환경·지질·허용 자원군·광체 분포 시드·생성 버전을 고정한다. 광체 좌표·원석 종류·잠재 품질은 청크 접근 시 결정적으로 재현한다. 백만 행성의 광맥 목록을 메모리에 미리 만들지 않는다.
- 매장량과 발견/감정 여부는 별도다. 재접속·미발견 상태·감정 취소·굴착 순서·렌더 LOD가 자원이나 품질을 다시 추첨하지 않는다. 청크 경계의 한 광체는 같은 ID를 사용한다.
- 저장에는 광체 고갈·회수한 원석·가공 결과·강화 대상 ID·강화 이력과 거래 결과가 필요하다. 소유 자산 수량을 시드에서 다시 지급하지 않는다.
- **세계에서 채집한 보석과 개인 성장의 소유 관계를 별도로 정해야 한다.** 기본 제안은 이 세계의 보석을 소모하고 해당 세계의 캐릭터별/장비별 강화 기록에 반영하는 것이다. 장비 교체·저장·재접속 후 유지하되, 다른 호스트 세계나 개인 원본 프로필로 자동 반출하지 않는다. 세계 간 영구 계승은 [협동 소유 규칙](12-host-coop-and-crew.md)의 미정 항목으로 유지한다.
- 남의 장비를 강화·소비·처분할 수 없게 하고, 공동 창고 재료를 개인 강화에 쓰는 권한·배분은 후속 결정한다. 초기 제안은 본인이 운반·보유한 재료를 사용하는 것이다.
- 호스트가 소유·재료·단계 조건을 검증하고, 재료 차감과 강화 기록을 한 번 저장한 뒤 성공 연출을 확정한다. 저장 실패·재요청·동시 채집으로 재료나 강화가 복제되지 않게 한다.
- 현재 `iron`, `copper`, `stone`, `ice`, `crystal`과 기존 레시피·재고를 보존한다. 특히 기존 `crystal`을 새 보석이나 희토류로 자동 치환하지 않는다. 실제 확장 때 ID·세이브 버전과 변환 정책을 별도로 정한다.

## 2026-09-07 — 초반 철·얼음 확보

후속 사용자 확정(Q4): **첫 자동화·기초 복원은 근거리에서 가능하게 하고, 생산 확대·T2 가공 재료부터 외곽/지하 탐험을 요구한다.** [I3·Q4 결정 이력](../planning/09-ground-play-feedback.md). 초반 철·얼음 등 필수 자원 접근성과 유한 광맥 보장은 유지한다. 구체적인 거리·재료 종류·양은 조정값이며, 아래 기존 배치·수량·고갈 이력을 이번에 변경하지 않았다.

사용자 확정: 필수 재화인 철·얼음은 대부분의 초반 행성에서 구하기 쉽게 분포 또는 위치를 조정한다. 구현 선택으로 착륙 가능한 생성 T1·T2 행성에는 착륙지 주변의 안전한 시작 광맥을 보장한다. 주 지질의 차이와 고티어 탐험 자원은 유지한다.

현재 시작 재고는 아이템 지급이 아니라 직접 채집하는 유한 광맥이다. 기존 철·구리·암석 광맥을 보존하고 T1·T2 전용 추가 철/얼음을 별도 ID로 배치한다. 기존 저장의 고갈량을 초기화하지 않는다. 수량·좌표 원본은 `data/landing_resources.json`이며 현재 조정값과 실제 확인 범위는 [제작 기록](../production/45-progression-repairs.md)에 둔다.

## 2026-09-09 — 성장 외장과 염색 확장

사용자 확정: 강화할수록 실제 탐험복 파츠가 점차 보강되며, 기존 리깅과 동작을 유지한다. 추후 파츠별 염색을 지원한다. 현재 3계열별 투자 단계에서 누적 외장을 계산하고 실제 승무원과 I 신체에 표시한다. 헬멧·흉부·팔·다리·배낭·벨트의 도색 영역을 분리했다. 단계 문턱과 모델 경로는 `data/suit_appearance.json`이 소유한다. 염색 메뉴·저장·동기화는 아직 구현하지 않았다. [제작·실제 확인 범위](../production/94-progressive-suit-appearance.md).

## 2026-09-09 — 부위별 염색 메뉴 후속 구현

이전 절의 염색 메뉴·저장·동기화 미구현 상태를 갱신한다. I 염색에서 6부위의 3색을 미리보고 한 부위당 보석 1개로 적용한다. 사용자 후속 요청에 따라 사파이어(헬멧/다리), 루비(팔/벨트), 에메랄드(배낭), 다이아몬드(흉부)로 나눈다. 기본색 복원은 무료다. 비용 원본은 `data/suit_appearance.json.dye_costs`이며 세계별 개인 승무원 색상을 저장한다. [실제 범위와 검증](../production/95-suit-dye-menu.md).
