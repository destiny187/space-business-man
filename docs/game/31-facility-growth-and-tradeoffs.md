# 계열별 설비 3종과 개별 강화, T5 운용 설계

2026-09-14 첫 부분 구현: 발견 기반 응결 집수기와 열수 발전기의 기본/강화 두 상태, 자연물을 닮은 본체와 환경 운용을 [194 구현](../production/194-discovery-industry.md)에 연결했다. 아래 전체 6계열 18종 구성과 기존 설비 이행은 여전히 목표 설계다.

2026-09-14 사용자 정정 반영. **계열 안에 용도가 다른 설비 3종을 두고, 각 설비는 기본 상태에서 한 번 강화하는 2단계 구조**다. 전기 3종과 대기 3종은 서로 다른 건물 종류를 뜻한다. 앞서 작성한 기초형 → 개량형 → 전문형의 3단계 성장 해석은 폐기한다. 플레이어 표기는 건물 고유 이름과 `강화`를 사용한다.

이번 작업은 문서 정정이다. 실제 건물, 모델, 연구, 제조법은 아직 이 구조로 전환하지 않았다. [발견 활용](30-special-discovery-uses.md), [복수 제조법](32-alternative-manufacturing-recipes.md), [개발 순서](../planning/20-special-discovery-and-facility-growth.md)를 함께 따른다.

## 1. 종류, 강화와 행성 티어를 분리한다

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 설비 종류 | 역할과 운용 조건이 다른 독립 건물 | 태양광 발전기, 지열 발전기, 고출력 유도 발전기 |
| 개별 강화 | 같은 건물의 성능과 작동부를 개선하는 1회 강화 | 태양광 발전기 → 강화 태양광 발전기 |
| 행성 티어 | 해결할 환경 문제, 공급과 운용 난도 | T5에서도 조건에 맞는 태양광 발전기를 보조 전원으로 사용 |
| 제조법 | 동일 제품을 서로 다른 원료 경로로 생산 | 보강 프레임의 표준 제조법과 고티어 소재 제조법 |

설비 3종을 순서대로 교체하는 필수 사다리로 만들지 않는다. 후반 해금 설비는 새로운 역할과 운용 조건을 제공하며 다른 두 종의 모든 기능을 공짜로 포함하지 않는다. 강화는 두 번째 상태까지이며 강화의 강화나 숨은 세 번째 단계는 추가하지 않는다. 별도 부품을 장착하더라도 제3 강화 단계로 취급하지 않는다.

이 정정은 현재 논의 중인 건설 설비 성장에 적용한다. 총기 등급, 탐험복과 신체 증강의 기존 전체 성장 체계를 일괄 2단계로 바꾸는 지시로 확대하지 않는다.

## 2. 계열별 3종 구성안

전기와 대기 각각 3종 및 설비당 기본/강화 2단계는 사용자 방향이다. 아래 구체적 이름과 역할, 나머지 계열까지 같은 구성을 적용한 것은 설계 제안이다. **6계열 18종, 각 2개 상태**를 작업 기본안으로 둔다. 강화 상태를 독립 설비 1종으로 중복 세지 않는다. 토양은 생태 계열에 포함한다.

| 계열 | 설비 1 | 설비 2 | 설비 3 |
| --- | --- | --- | --- |
| 전기 | 태양광 발전기: 빛과 넓은 부지 사용, 연료 불필요 | 지열 발전기: 실제 열원 필요, 안정 출력과 주변 열 변화 | 고출력 유도 발전기: 연료와 냉각 필요, 큰 출력 대신 국소 열과 전자기 간섭 |
| 대기 | 대기 조절기: 작은 생활권의 기초 산소, 기압과 일반 독성 조정 | 선택 가스 분리탑: 반응성 가스와 혼합 오염을 처리재로 분리 | 대기 순환 플랜트: 넓은 복원 구역의 순환과 회수, 큰 전력 및 관로 필요 |
| 수질 | 집수 정화기: 물 또는 얼음 확보와 기초 급수 | 수질 분리기: 염분과 산성 오염을 처리재로 제거 | 폐쇄 수자원 순환기: 사용한 물 회수와 재이용, 초기 물과 손실 보충 필요 |
| 온도 | 기후 조절탑: 작은 구역의 기초 온도 조정 | 열교환 설비: 실제 열원, 폐열과 수요 사이 열 이동 | 극한 기후 안정기: 극열 또는 극저온을 전용 처리재로 완충 |
| 생태 및 토양 | 생태 배양기: 적합한 토양에서 기초 정착과 배양 | 토양 재생기: 기반재와 관수로 토양의 염류 및 정착 조건 개선 | 생물권 온실: 보호 구획과 적합한 표본 조합으로 극한 환경의 생장 유지 |
| 오염 유입원 제어 | 유입 봉합기: 좁고 확인된 누출 지점을 국소 차단 | 유입 포집기: 계속 나오는 가스 또는 오염수를 포집하여 처리 설비로 전달 | 유입 안정화 장치: 열과 복합 원인의 재유입을 관측하며 지속 억제 |

대기 순환 플랜트가 선택 가스 분리탑을 대신해 모든 가스를 정화하지 않는다. 물 순환기가 원수 없이 물을 생성하지 않는다. 유입 포집과 잔류 오염 정화는 별도 역할이다. 열을 이용하는 발전과 열을 옮기는 설비도 에너지를 중복 생산하지 않는다.

유입원이 없는 시작 행성에는 유입 제어가 필요하지 않다. 설비 종류를 채우려고 모든 행성에 새로운 문제를 강제하지 않는다. 작은 현장의 초기 복원에는 기존처럼 최소한의 기초 설비로 시작할 수 있어야 한다.

## 3. 각 설비의 강화와 외형

| 계열 | 강화의 주된 개선 후보 | 눈에 보이는 변화 |
| --- | --- | --- |
| 전기 | 같은 발전 방식의 출력 안정 또는 전환 효율 | 추가 패널, 열교환 코일, 냉각 배관과 차폐판 |
| 대기 | 같은 처리 대상의 처리량 또는 처리재 수명 | 필터통, 송풍부, 회수 배관 |
| 수질 | 처리량 또는 물 회수율 | 막 탱크, 보조 펌프, 누수 회수부 |
| 온도 | 열 전달 효율 또는 안정 운용 범위 | 코일, 축열조와 방열판 |
| 생태 및 토양 | 조건에 맞는 배양 속도 또는 유지 원료 절약 | 관수 링, 배양 트레이, 보호 덮개 |
| 유입원 제어 | 같은 원인의 억제 안정성 또는 소모품 효율 | 고정 클램프, 포집 헤드와 감지기 |

강화는 원래 건물의 실루엣을 알아볼 수 있는 변화다. 같은 계열의 다른 종류는 구조, 크기와 작동부부터 달라야 한다. 예를 들어 대기 조절기의 강화는 추가 필터와 팬으로 보이고, 가스 분리탑은 처리탑과 재생실을 갖춘 별개의 건물이다.

강화 버튼에는 현재 상태, 이번 개선, 비용, 전력 변화와 부작용을 표시한다. `Mk.2` 대신 `강화`, 완료 후 `강화됨` 또는 `강화 대기 조절기`처럼 표현한다. 이번 정정은 숫자 이름만 교체하고 기존 3단계 기능을 숨기는 작업이 아니다.

연구한 강화 기술은 공동으로 사용하되 실제 강화 비용은 건물마다 지불한다. 강화 효과는 데이터로 정하며 모든 건물에 일률적인 배수를 적용하지 않는다. 강화가 연료, 열원 또는 적합한 표본 등의 본래 조건을 없애지 않는다.

## 4. T5까지 운용하는 방법

설비 종류와 강화 상태를 조합해 T5의 문제를 해결한다. 특정 행성 티어라는 이유만으로 설치를 금지하지 않고 해금, 재료, 공간과 실제 환경 적합성으로 판정한다. 각 종류의 정확한 해금 시점은 구현 시 정한다.

| 진행 구간 | 필요한 선택 |
| --- | --- |
| T1 | 조건에 맞는 기초 전원과 작은 복원 설비로 시작. 모든 계열 3종을 건설할 의무 없음 |
| T2 | 필요한 설비의 강화와 토양 및 염류 대응 설비를 선택 |
| T3 | 반응성 가스, 산성 수질과 지속 유입에 맞춰 서로 다른 종류를 조합 |
| T4 | 극한 온도 처리재와 온실, 열 회수 및 안정 전원으로 운용 조건 유지 |
| T5 | 복수 지역의 원인 억제, 순환, 보호와 유지 공급을 조합. 현지 고티어 원료의 대체 제조법으로 기초 제품까지 공급 |

T5 대응은 계약에서 지정한 복원 영역의 필수 조건과 안정 유지 충족을 의미한다. 가스행성 착륙이나 전 행성 물리 기후 시뮬레이션을 추가하지 않는다. 고티어에서 저티어 설비를 쓰더라도 해당 설비의 실제 처리 한계는 유지한다.

낮은 티어 재료가 현지에 없을 때는 [대체 제조법](32-alternative-manufacturing-recipes.md)을 사용한다. 운송은 비용과 생산 효율에 따른 선택으로 남기고, 기초 재료를 구하러 과거 행성으로 반드시 돌아가게 하지 않는다. 실제 모든 고티어 행성에 저티어 광물이 없다고 단정하거나 기존 지질 분포를 바꾸지 않는다.

## 5. 발전 방식의 이득과 생태 간섭

전기는 위 표의 독립 설비 3종에 포함된다. 축전기, 차폐와 폐열 회수기는 지원 설비이며 발전기 네 번째 종류나 세 번째 강화 단계가 아니다.

고출력 유도 발전기는 큰 전력을 얻는 대신 연료 및 냉각 공급과 주변 열 및 전자기 간섭을 관리한다. 지열은 실제 열원, 태양광은 빛과 면적을 요구한다. 어떤 방식도 모든 상황에서 항상 우월하지 않도록 한다.

간섭의 초기 예시는 가동 발전소의 24m 안쪽에서 생태 처리 속도 최대 15% 감소, 48m에서 0으로 감쇠, 대상당 합산 상한 30%다. 모두 미확정 밸런스 제안이다. 생태 구역과의 거리, 차폐, 출력 제한으로 보완한다. 강화 후에도 발전 방식의 본래 선택 조건은 남긴다.

온도 변화와 전자기 간섭을 구분하여 같은 열 문제로 두 번 감점하지 않는다. 정지한 발전기는 지속 간섭을 만들지 않는다. 장식 소리와 발광에는 효율 불이익을 붙이지 않는다. 초기 범위는 배양 속도와 유지 비용이며 간섭만으로 생물이나 기존 생태를 즉시 파괴하지 않는다.

## 6. 발견 연구와 제조 시설

발견 연구는 설비의 특정 기능이나 제조법 선택을 넓힌다. 소금꽃은 분리막, 돌기둥은 수동 환기, 열수 굴뚝은 열교환, 자성 아치는 집진 원리로 연결할 수 있다. 효과는 실제 해당 공정에만 적용하고 희귀 장소 하나를 못 찾아 기본 진행이 막히지 않도록 대체 연구를 제공한다.

처리 부품이나 원리 부품이 필요하면 해당 설비의 용도에 맞춰 정의한다. 이전 초안의 모든 전문형 공통 3슬롯은 채택하지 않는다. 장착 부품을 모아 또 다른 본체 강화 단계를 만드는 구조는 피한다.

금속 가공 공장은 정제와 프레임, 장비 제작대는 기본 장비와 무기, 현장 제작소는 조립 부품과 로봇을 담당한다. 다른 원료 제조법도 같은 제품의 소관 제작 시설을 사용한다. 이들 시설에도 기본/강화 표현 원칙을 적용하되 제조 시설마다 종류 3개를 강제로 만드는 범위는 아니다. 장식 제작대는 [발견 소관](30-special-discovery-uses.md)의 별도 제안이다.

## 7. 현재 구현과 이행 경계

현재 [기존 개조](../../우주-비즈니스/data/production_tier2.json)와 [T3 모듈](../../우주-비즈니스/data/terraforming_tier3.json)은 Mk 표기와 숫자 단계 구조를 사용한다. 현재 유입원 제어는 하나의 T3 독립 건물이고, [T4 열 처리 팩](../../우주-비즈니스/data/terraforming_tier4.json)도 구현되어 있다. 위 18종과 새 강화 상태가 이미 존재하는 것으로 읽지 않는다.

구현 전 기존 ID별로 새 종류와 상태, 해금 권리를 대응시키는 표를 작성한다. 기존 첫 개조는 동등한 강화 상태로, T3 전문 기능은 해당 기능을 가진 독립 종류로 이행하는 안을 검토한다. 1:1로 대응되지 않으면 기존 규격을 유지하며 이미 가진 기능과 설계도를 잃거나 다시 구매하지 않게 한다.

기존 시설에 더 큰 모델과 충돌체를 즉시 덮어쓰지 않는다. 공간이 부족하면 기존 규격을 계속 사용할 수 있고, 확장 전환은 배치 고스트로 확인한 뒤 한다. 생산 작업, 재고, 연결, 건물 소유와 기존 계약 성과를 보존한다. 실패하면 재료와 상태를 유지한다. 새 간섭 규칙은 버전으로 구분하고 기존 원정을 조용히 전환하지 않는다.

## 8. 표현, 변경 범위와 완료 조건

건설 화면은 계열 안의 서로 다른 종류 3개를 보여준다. 강화는 각 설치물의 상호작용 화면에서 처리한다. 종류를 고를 때 역할, 면적과 작동 조건을 비교하고, 강화할 때 그 건물의 변화만 비교한다. 재료 선택은 제조법 화면에서 별도로 다룬다.

모델과 음향은 준비, 정상 가동, 재료 부족, 전력 부족, 환경 부적합과 정지를 구분한다. Blender 원본과 GLB, ElevenLabs 음원과 INK v1 Forward+ 렌더를 실제 연결해 확인한다. 게임 문구에는 중간점을 사용하지 않는다.

데이터는 `family`, `facility_type`, `enhanced`, `capabilities`, `power`, `footprint`, `influence`, `model`, `motion`을 분리하는 안이다. 기존 숫자 단계와 호환할 변환 규칙은 별도 버전으로 둔다. 한 건물 강화나 부품 변경은 대상과 연결된 공급망 및 영향 반경만 갱신한다. 전체 행성의 모델이나 지형을 다시 만들지 않는다.

후속 완료 조건:

- 채택한 각 계열에 역할이 다른 3종이 있고 각 종류의 기본/강화 상태가 실제 기능과 외형으로 구분된다.
- 종류, 강화와 제조법 선택이 연구, 건설, 가동 화면에서 혼동되지 않는다.
- T3~T5의 대표 문제를 설비 조합과 실제 공급으로 처리하고 지역별 계약 판정과 일치한다.
- 대체 제조법으로 만드는 동일 제품이 기존 장비와 시설에서 정상 소비된다.
- 기존 시설, 작업과 권리를 보존하고 한 건물의 변화가 다른 현장을 불필요하게 수정하지 않는다.

전체 계열 재편은 문서 설계다. 첫 두 설비의 구현과 확인은 194 기록을 따른다. 후속 구현 시 변경 계열과 대표 조합의 최소 확인을 수행하고 새 실패 없이 전체 회귀를 반복하지 않는다.
