# 무기 드롭 등급·무작위 옵션·속성 공격

2026-09-14 후속: **개체 피해 품질 ±20%·최소~최대 피해**를 승인·적용했다. 새 제작/무작위 전리품부터 적용하고 기존 개체는 보존한다. [187 실제 기록](../production/187-weapon-damage-quality.md)과 아래 피해 범위 절을 따른다.

2026-09-14 **사용자 후속 개발 승인·현재 T1~T3 첫 구현**. 사용자는 티어와 별도로 일반·매직(초록)·고급(파랑)·희귀(보라)·전설(황금)을 사용하고 속성별 공격을 넣도록 요청한 뒤 실제 반영을 승인했다. 이 문서는 목표 규칙의 단일 소관이며 디아블로 특정 작품의 수치를 재현하는 명세가 아니다.

현재 다섯 등급·유효한 개체 옵션·다섯 속성·전설 네 종·현장 회수·일반 속성 제작·잠금/분해·기존 저장 호환을 연결했다. [186 제작 기록](../production/186-weapon-loot-and-elements.md)에 실제 자산·Forward+·소리·거래/저장 확인과 미구현 세부를 구분한다. 아래 수치는 첫 밸런스이며 W04의 상위 기반총·추가 전설·정밀 제작/계승은 후속 설계다. 별도 내성/발견 도감·나란한 두 모델 비교 등 화면 목표를 모두 완료한 것은 아니다.

## 1. 원하는 경험과 현재 출발점

**원하는 계열을 제작한다 → 탐험 중 더 좋은 개체를 발견한다 → 옵션·속성·전설 효과로 주력 무기를 고른다 → 남은 총은 부품으로 돌려 생산과 다음 출격을 준비한다.** 동일 모델을 다시 발견해도 확인할 이유를 만들되, 전투 파밍을 테라포밍 진행의 필수 관문으로 만들지 않는다.

개편 전 기반과 유지할 경계:

- 총기 9계열·17개 정의, T1~T3 제작과 사건 전리품, 개체별 희귀도·출처 저장이 있다. 구형 희귀도는 고정 피해/재장전 배율이었다. 새 개체에는 아래 무작위 옵션과 최초 전설 효과를 적용하고 구형 개체의 배율은 호환 보존한다.
- 기본 권총은 약한 위력·무한 예비탄·유한 탄창/재장전을 유지한다. 다른 총기는 기존 6종 탄약·전지, 부분 장전, 반동·탄도·레이저 과열을 유지한다. 속성 때문에 탄약 품목을 다섯 배로 늘리지 않는다.
- 기존 `loot()`는 사건 티어를 T1~T3으로 제한한다. T4/T5 총기 완성품과 전용 제작 기반은 별도 제작 대상이며 이 문서로 이미 존재하게 되지 않는다.
- [지상 전투](27-ground-and-flight-combat.md), [총기·탄약](../production/166-firearm-ammunition-and-ballistics.md), [레이저·사격 후속](../production/169-firearm-precision-and-laser.md)을 기반으로 한다. 지상 휴대 무기를 첫 적용 범위로 하며 함포·미사일·도구·6부위 내장 모듈의 규칙을 일괄 교체하지 않는다.

## 2. 티어·등급·속성의 역할

| 축 | 결정하는 것 | 예 |
| --- | --- | --- |
| 계열/모델 | 사거리·탄창·반동·발사 방식·고유 조작 | 카빈, 산탄총, 저격총, 지속 레이저 |
| 기술 티어 | 기본 성능과 제작/해금 단계 | 내부 T1~T5, 화면에는 기존 Mk.1~Mk.5 |
| 드롭 등급 | 무작위 옵션 수·전설 효과 유무 | 일반~전설 |
| 공격 속성 | 피해 성격·상성·상태 효과 | 물리, 열, 냉기, 전격, 부식 |
| 개체 옵션 | 같은 모델 안의 특화 | 재장전, 탄창, 약점, 열 관리 |

모든 기술 티어에 다섯 등급을 허용한다. **Mk.1 전설과 Mk.5 일반이 모두 가능**하며, 티어가 전설 획득 자격을 잠그지 않는다. 속성도 등급과 독립적으로 배정해 일반 냉기총·매직 전격총·물리 전설총을 허용한다. 특정 모델의 구조상 지원하지 않는 속성 조합만 후보에서 제외하고 표시한다.

티어는 기본 위력의 상승, 등급은 개체의 선택 폭을 맡는다. 새 무기의 등급 자체에는 기존처럼 일괄 피해/재장전 보너스를 다시 얹지 않고 옵션과 전설 효과로 차이를 낸다. 같은 수치를 두 번 보상하지 않는다. 후속 사용자 승인으로 기본 피해 품질도 기준값의 **±20%**에서 독립 추첨한다. 아래 피해 범위 규칙이 앞선 고정 기본 피해 전제보다 우선한다.

**밸런스 목표:** 잘 맞는 하위 티어 전설은 인접한 상위 일반과 비교할 가치가 있지만, 몇 단계 위의 모든 총기를 계속 압도하지 않는다. 동티어 일반 제작 총기로 동티어 핵심 사건을 완수할 수 있어야 한다. 성장곡선은 현재 적 체력·탄약 소비·장전 포함 처치시간과 함께 조정하며 이 목표만으로 기존 피해량을 일괄 변경하지 않는다.

### 2026-09-14 확정 — 개체 피해 품질 ±20%와 타격 피해 범위

사용자는 최소~최대 피해와 동일 등급 내 개체별 피해 차이에 동의하고, 품질 폭을 ±10%가 아닌 **±20%**로 지정했다. 등급/옵션과 독립된 품질 계수 0.8~1.2 하나를 개체 생성 시 추첨해 기준 최소·최대 피해에 함께 곱한다. 최소와 최대를 따로 뽑아 순서가 뒤집히지 않게 한다.

- 현재 고정 피해 D를 기준 평균으로 삼아 기본 범위 `0.8D~1.2D`를 두는 것은 이번 구현 선택이다. 평균을 유지하면서 최소/최대가 있는 무기로 전환한다.
- 품질 계수 q가 붙은 개체 범위는 `0.8Dq~1.2Dq`다. **품질 ±20%는 개체 간 차이이며, 한 발의 피해 편차와 별도**다. 따라서 옵션/상성을 빼도 개별 타격 전체 범위는 기존 D의 0.64~1.44배까지 가능하다.
- 기준 범위 20~30의 무기는 품질 0.8일 때 16~24, 1.2일 때 24~36이다. 등급이 높다고 품질을 자동으로 최대로 만들지 않는다. 기존 피해 증가 옵션은 이 범위에 적용한다.
- 생성된 품질·기준 양 끝값·최종 양 끝값을 저장하고 실제 사격에서는 그 안에서 균등 추첨한다. 산탄은 한 사격의 피해 추첨을 탄립에 공유하고 폭발은 같은 값에 거리 감쇠를 적용한다. 레이저는 탄약/열을 지불하는 기존 100ms 판정마다 추첨한다.
- 장전 포함 평균 DPS·연소·전설의 기준 피해는 개체 범위의 평균을 사용한다. 우연히 높은 직접 타격이 나왔다고 연소나 전설 계수까지 다시 증폭하지 않는다. 약점·실드·속성·신체/모듈 배율은 기존 판정 순서에 연결한다.
- 개조안의 일반→매직은 원본의 품질·피해 범위를 보존하고 선택 옵션만 추가한다. 매직 개조/설치형 제작대 자체는 아직 별도 미구현이다.
- 기존 보유품과 이미 확정된 사건 보상은 재추첨하지 않는다. 새 피해 프로필이 없는 개체는 기존 고정 피해로 해석한다. 새 일반 제작과 새 무작위 전리품부터 적용하며, 미리보기는 기준 범위와 품질 80~120%를 안내한다.

실제 구현·저장·사격/화면 확인은 [187 제작 기록](../production/187-weapon-damage-quality.md)을 따른다.

## 3. 다섯 드롭 등급

| 표시 등급 | 색 | 무작위 옵션 제안 | 전용 효과 | 발견 의미 |
| --- | --- | ---: | --- | --- |
| 일반 | 백회색 | 0 | 없음 | 기본 전력, 원하는 계열 확보 |
| 매직 | 초록 | 1 | 없음 | 한 가지 장점이 명확한 개체 |
| 고급 | 파랑 | 2 | 없음 | 두 장점의 조합으로 실전 특화 |
| 희귀 | 보라 | 3 | 없음 | 원하는 세 옵션과 좋은 수치를 찾음 |
| 전설 | 황금 | 3 | 1개 | 사격·표적 선택 방식이 달라짐 |

전설은 이름과 전용 효과가 묶인 모델 후보에서 나오고 일반 옵션 세 개와 그 수치는 무작위다. 같은 전설도 개체별 차이가 있다. 전설의 옵션 수치를 무조건 최댓값으로 만들지 않으며 잘 맞는 희귀가 특정 용도에서 더 좋을 수 있다. 여섯 번째 유니크/세트 등급은 추가하지 않는다.

기존 무기 내부 ID는 `standard/improved/rare/epic/legendary`를 보존하고 표시를 각각 일반/매직/고급/희귀/전설로 대응시킨다. 영문 `rare`를 한국어 ‘희귀’라는 문자열만 보고 다시 연결하면 파랑과 보라가 뒤바뀌므로 저장 ID와 표시명을 분리한다. [내장 모듈](22-suit-modules-and-shields.md)의 등급명/확률은 현재 그대로이며 공통 명칭 전환은 별도 범위다.

## 4. 무작위 옵션

옵션은 실제 작동하는 것만 추첨한다. 같은 옵션 중복, 이름만 다른 동일 피해 배율 중복, 레이저의 산탄 수처럼 무의미한 조합은 금지한다. 한 무기에 순수 피해 증가 옵션은 최대 한 개를 제안한다. 조작성 옵션도 좋은 결과로 느껴지게 한다.

| 옵션 묶음 | 첫 후보 | 제한·계열 연결 |
| --- | --- | --- |
| 위력 | 직접 피해 증가, 약점 피해 증가 | 같은 무기에서 둘 중 하나, 지속 피해 재증폭 금지 |
| 조작성 | 재장전 시간 감소, 반동 감소, 정조준 전환 단축 | 기존 손·탄창 동작도 실제 시간에 맞춤 |
| 운용 | 탄창 증가, 교체 시간 단축 | 탄창 증가로 예비탄/예약 탄을 생성하지 않음 |
| 속성 | 상태 축적 증가, 상태 지속시간 증가 | 상태가 없는 물리총과 실드 피해만 있는 전격 기본형에서는 제외 |
| 레이저 | 열 발생 감소, 냉각 속도 증가 | 최소 과열/냉각 리듬과 소모 전지는 유지 |
| 투사체 | 탄속 증가 | 광선에는 제외, 낙차와 충돌에 실제 적용 |

초기 수치 예는 직접 피해 +5~10%, 재장전 시간 -8~15%, 탄창 +10~20%다. 이는 초기 실행값이며 공통 데이터로 관리한다. 티어별 곡선 조정은 후속 밸런스다. 탄창은 정수로 반올림하고 적어도 한 발 증가하는 유효 결과만 생성한다. 등급이 높다는 이유로 옵션 하나의 수치까지 자동으로 높이지 않는다.

옵션·신체 증강·모듈이 같은 수치를 바꾸면 공통 합산 묶음과 최종 상한을 사용한다. 공격속도·무작위 치명타·흡혈·탄약 환급은 첫 옵션 풀에서 제외하고 필요성이 확인되면 추가한다. 기존 계열의 연속 약점 명중·실드 파괴 후 재장전 개성은 유지하며 같은 효과를 전설이라는 이름으로 다시 지급하지 않는다.

## 5. 속성별 공격

무기 한 개는 주 속성 하나를 갖는다. 기본 직접 피해를 해당 속성으로 **전환**하며 원래 피해 위에 속성 피해 100%를 더하지 않는다. 속성은 무작위 옵션 칸을 쓰지 않는다. 제작에서는 지원 속성을 부품으로 지정하고 드롭에서는 모델/출처 풀에서 추첨한다.

아래 값은 첫 실험값이다. 물리의 안정성, 상태 효과가 있는 속성의 효용, 실드/장갑 전문성을 함께 비교한다.

| 속성 / ID | 역할 | 초기 효과 제안 | 대가·경계 |
| --- | --- | --- | --- |
| 물리 / `kinetic` | 안정적인 직접 피해·약점 사격 | 직접 피해 100%, 별도 상태 없음 | 약점/부위 판정 유지, 속성 완전 면역 적에 의존하지 않음 |
| 열 / `thermal` | 움직이면서 압박하는 지속 피해 | 직접 피해 90%, 축적 완료 시 3초 연소 | 연소 1회 총량은 해당 무기 기준 DPS의 30%, 자체 재치명타·재발동 없음 |
| 냉기 / `cryo` | 접근하는 적과 거리 확보 | 직접 피해 90%, 축적 완료 시 2초간 이동속도 20% 감소 | 기본형은 완전 동결 없음, 공격 준비/판정 시간을 임의로 늘리지 않음 |
| 전격 / `shock` | 실드가 있는 표적 대응 | 실드 피해 125%, 체력 피해 90% | 기본형은 기절/연쇄 없음, 전설에 별도 행동 효과 |
| 부식 / `corrosive` | 장갑형 로봇 상대 | 실드 피해 90%, 장갑 태그의 체력 피해 120%, 나머지 체력 100% | 실드 통과·시설/지형 손상 없음, 생물 전체에 장갑 태그를 강제하지 않음 |

열/냉기의 ‘축적’은 공격 한 번마다 고정 확률을 여러 번 굴리는 대신 유효 명중 시간에 비례한다. 중립 표적에 온전히 명중하는 약 1초를 최초 발동 기준으로 제안한다. 산탄은 한 발의 축적 예산을 탄립 수로 나누고, 레이저는 실제 명중 시간, 폭발은 표적별 감쇠를 적용한다. 느린 총은 발사 간격에 해당하는 축적량을 받고 과도한 한 발 축적은 상한으로 제한한다. 직접 피해가 없는 접촉과 엄폐에 막힌 발사에는 축적이 없다.

연소 피해 기준 DPS는 발사 시 무기 정의와 개체 옵션으로 고정한 지속 사격값이며 약점·대상 상태 배율을 재적용하지 않는다. 장전/과열을 반영하는 공통 기준을 사용한다. 이동 감속은 명시적 전투 상태인 동안만 적용하고 종료 즉시 정상 속도로 복귀한다. 애니메이션 품질을 이유로 생물의 기본/최고 이동속도를 낮추지 않는 기존 사용자 지시는 유지한다.

### 상성·실드·상태 중첩

- 기본은 중립이다. 스캔으로 알 수 있는 실드·장갑·내열 같은 **실제 표적 프로필**로 상성을 배정한다. 생물 외형색이나 행성 이름만으로 모든 종에 같은 약점을 주지 않는다. 기존 종은 프로필이 없으면 중립으로 처리한다.
- 열의 연소와 냉기의 감속 축적은 체력에 도달한 유효 명중분만 사용한다. 실드가 전부 흡수하면 직접 피해만 적용하고, 넘친 부분에 비례해 축적한다. 속성 공격을 산성비·낙하 등 실드 통과 환경 피해로 분류하지 않는다.
- 실드 피해 배율은 실드를 소모하는 부분에만 적용한다. 전격 기본 피해 40, 실드 25라면 피해 예산 20으로 실드를 없애고 남은 20에 체력 배율 0.9를 적용해 체력 피해 18이다. 실드 보너스를 남은 체력에 다시 적용하지 않는다. 모듈 ‘위상 파쇄’와 합칠 때 같은 실드 배율 묶음에서 처리하고 최초 합산 상한 2배를 제안한다.
- 표적 속성 저항은 해당 피해 구간에 한 번 적용한다. 초기 저항은 약점 -25%~저항 50% 범위, 완전 면역은 사용하지 않는 안이다. 장갑 상성과 속성 저항은 별도 값이며 같은 방어를 두 번 차감하지 않는다.
- 같은 속성 상태는 표적당 하나다. 연소는 활성 효과 중 강한 값을 사용하고 중첩 피해를 합산하지 않는다. 약한 공격으로 강한 연소를 계속 연장하지 않으며 각 기여자의 남은 지속시간을 보존한다. 냉기 감속도 합산하지 않는다. 열과 냉기는 공존하되 첫 단계에는 추가 반응/폭발을 만들지 않는다.
- 정예/대형 개체는 감속 효율을 절반으로 적용하는 안이다. 완전 동결·기절을 전설에 추가할 경우 표적별 재발동 대기와 저항을 별도로 갖춰 6인 영구 행동 봉쇄를 막는다.
- 지속 피해는 적용한 공격자의 소유이며 후속 실제 처치도 한 번만 판정한다. 장비 교체로 이미 발사한 탄·연소의 수치를 바꾸거나 전설 대기를 초기화하지 않는다. 아군·중립 시설·식물·비전투 표적에 속성 전이로 피해를 확대하지 않는다.

## 6. 전설 무기 후보

이름·효과·조건은 제안이다. 첫 개발 묶음은 앞 네 개를 추천하고, 신규 모델 전체 교체보다 기존 계열의 구조와 사격 감각을 활용한다. 수치·추가 피해는 일반 옵션과 합친 총 성능 예산에서 조정한다.

| 후보 | 기반 / 속성 | 전용 효과 | 선택하는 행동·제한 |
| --- | --- | --- | --- |
| 잔화 | 카빈 / 열 | 자신이 연소시킨 적을 직접 격파하면 가까운 적 하나에 짧은 연소를 옮김 | 약한 적부터 정리, 시야/거리 검사, 전이로 재전이 불가 |
| 쇄빙 | 산탄총 / 냉기 | 냉각된 적에게 가까이서 충분한 탄립을 맞히면 추가 파쇄 피해 후 자신의 냉각 효과 소비 | 거리 확보 후 접근 사격, 한 발 한 번, 대상별 대기 |
| 도약 전류 | 기관단총 / 전격 | 같은 적에게 짧은 시간 안에 3회 유효 발사 명중 시 주변 적 최대 둘에 약한 전류 | 한 표적 집중 후 분산, 발사 단위 집계, 엄폐 너머 전이·재귀 발동 금지 |
| 천공 | 저격총 / 물리 | 약점 명중 후 남은 탄이 같은 직선상의 뒤쪽 적 하나를 감쇠 피해로 관통 | 두 적을 일렬로 조준, 지형/엄폐 관통 없음, 두 번째 적의 추가 관통 금지 |
| 용해로 | 플라스마 / 부식 | 직접 착탄점에 짧은 부식 잔류장을 만듦 | 예상 이동로 사격, 장판 수/수명 제한, 지형·식생·산업 시설 피해 없음 |
| 여명선 | 레이저 / 열 | 같은 적을 지속 조준하면 열 효율이 좋아지지만 과열 시 효과 소멸 | 조준 유지와 방열 선택, 최소 발열·기존 전지 소모 유지 |

연쇄/전이/관통은 별도 추가 공격 기록으로 출처를 남기되 다른 전설을 발동시키지 않는다. 한 적의 격파 보상·모듈 처치 회복은 원래 처치 기록에서 한 번만 처리한다. 기본 무한 예비탄 권총은 강한 범위 피해·탄약 생성 전설의 기반에서 제외해 보조 무기 역할을 보존한다.

## 7. 드롭 출처와 확률

추첨 순서는 **보상 출처 확정 → 무기 지급 여부 → 기술 티어 → 등급 → 지원 모델 → 속성/전설 → 중복 없는 옵션·수치 → 저장**이다. 전설은 해당 계열/티어에 실제 제작된 전용 효과 후보가 있을 때만 풀을 연다. 개발 중 없는 후보를 일반 총기로 조용히 대체하지 않는다.

티어는 출처 행성/사건 단계로 정하고 플레이어가 장착한 무기에 맞춰 자동 보정하지 않는다. 모든 티어의 일반 풀에도 전설 확률을 열되 정예·보관함의 가치가 높다. 다음은 **무기 지급이 결정된 뒤**의 등급 비율이며 각 행의 합은 100%다.

| 출처 | 일반 | 매직 | 고급 | 희귀 | 전설 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 일반 회수/무기 전리품 | 52% | 30% | 14% | 3.5% | 0.5% |
| 무기 보관함·일반 사건 완료 | 25% | 38% | 27% | 9% | 1% |
| 정예 전투·위험 사건 보상 | 10% | 28% | 42% | 17% | 3% |
| 고유 전설을 추적하는 특수 목표 | 0% | 15% | 45% | 32% | 8% |

일반 로봇의 무기 지급 자체는 예컨대 15%, 전용 무기 보관함은 100%를 첫 실험값으로 둔다. 따라서 일반 로봇의 전설 획득률은 `15% × 0.5% = 0.075%`이며 표의 0.5%와 다르다. 적 수·접근 시간·탄약 비용을 포함한 시간당 보상은 아직 측정하지 않았다. 첫 구현 후 실제 동선을 보고 조정하며 희귀함을 위해 적 수만 늘리지 않는다.

- 쿠퍼테크 전투 잔해/군수 상자는 전격·부식과 전투 총기, 난파선/탐사 보관함은 넓은 계열·물리/열/냉기에 가중치를 준다. 일반 풀에서도 모든 최초 전설을 얻을 수 있게 하고 특정 장소는 원하는 것을 노릴 확률만 높인다.
- 생물 무력화 시 몸에서 완성 총기가 떨어지지 않는다. 생물 사건의 남겨진 장비·보호한 화물·임무 보상으로 연결한다. 아직 없는 임무나 반복 보스가 현재 출처라고 표시하지 않는다.
- 비전투 회수·탐험 사건에도 무기 보상을 남겨 전투만이 파밍 경로가 되지 않게 한다. 현재 사건 출처에 먼저 적용하고 [활동형 미션 제안](../planning/18-active-field-missions.md)은 실제 개발된 뒤 연결한다.
- 출처 ID에 결과와 풀 버전을 묶는다. 미리보기·재접속·인벤토리 부족·구역 이동으로 재추첨하지 않는다. 반복 사건은 실제 새 발생 ID에서만 새 보상을 만들고 기존 장소의 완료 기록을 되돌리지 않는다.
- 협동은 현재의 공유 전리품 한 개·실제 회수자 소유를 유지하는 첫 안이다. 마지막 타격자가 자동 독점하지 않고 F 회수에서 호스트가 한 명만 확정한다. 개인별 6배 복제 지급·거래/우편·세계 간 반출은 별도 설계다.

## 8. 제작·분해·애착 무기

기본 제작은 원하는 모델/Mk.의 일반을 확정 지급한다. 호환 속성 부품을 추가하면 지원하는 속성을 지정할 수 있다. 재료·장비/탄약 운반·해금 조건은 기존 생산과 연결한다. 제작 화면에서 등급 상승 확률을 숨겨 놓는 방식은 사용하지 않는다.

### 2026-09-14 후속 제안 — 일반 무기를 매직으로 개조

사용자는 제작대의 역할을 보강하기 위해 **일반 무기 + 아이템/광물로 매직까지 직접 제작**하는 방향을 제안했다. 아래는 이를 구체화한 설계이며 아직 게임에 반영하지 않았다. 이 안은 앞선 매직/고급 정밀 제작 구상 중 매직을 먼저 분리하고, 고급 이상은 현재 탐험 획득으로 유지한다.

- 기본식은 `일반 무기 1개 + 선택한 기존 광물 → 같은 계열·Mk.·속성의 매직 무기`다. 신규 전용 재료를 필수로 늘리지 않고 채집 자원의 소비처로 시작한다.
- **재료로 옵션 종류를 선택하고 값만 표시된 범위에서 추첨**하는 안이다. 철은 탄창 증가, 구리는 재장전 단축, 규소는 정조준 전환 단축, 희귀 결정은 상태 축적 증가를 예시로 둔다. 희귀 결정 개조는 열/냉기처럼 실제 축적이 있는 총기에만 제공한다. 매직의 옵션 한 개 규칙과 현재 옵션 범위를 공유한다.
- 성공은 100%이며 원래 티어·속성·소유 ID·탄창 잔량을 유지한다. 일반을 매직으로 바꾸는 한 번의 거래이고 원본과 결과를 두 자루로 지급하지 않는다. 이미 매직 이상인 총의 재추첨·추가 옵션은 첫 개조 범위에 넣지 않는다.
- 총기 모델을 거치하고 광물 슬롯/옵션 아이콘/결과 범위를 표시하는 **설치형 무기 제작대**를 제안한다. 일반 제작·매직 개조·분해를 한곳에 모으고 기존 휴대 일반 제작은 보존한다. 현재 구현은 휴대 제작 중심이며 전용 제작대 모델/설치 기능이 이미 있다는 뜻은 아니다.
- 장착/잠금/재장전 중 개조를 막고 대상 총과 개인 재료만 호스트가 원자적으로 변경한다. 미리보기에는 수치 범위만 표시한다. 확정 결과를 영수증과 함께 저장해 재접속/중복 요청으로 재추첨하거나 재료를 두 번 소비하지 않는다. 거래 실패는 원본과 재료를 유지한다.
- 재료량은 티어별로 조정하고 개조 비용이 분해로 회수되지 않게 한다. 레시피/제작대 건설비·해금 단계·개조 연출 시간은 미정이다. Mk.1부터 이용 가능한 경로를 목표로 하되 새로운 상위 티어 접근을 우회하지 않는다.

예시는 `일반 열 카빈 Mk.1 + 구리 → 재장전 시간이 단축된 매직 열 카빈 Mk.1`이다. 광물/수치 매핑과 제작대의 설치 방식은 확정 요구사항과 구분한 제안이다. 고급 이상의 정밀 제작과 전설 계승은 별도 후속 범위로 둔다.


불필요한 총기는 선택 분해해 티어별 무기 부품으로 회수한다. 장착/잠금 상태는 분해를 막고 확인 화면에 실제 회수품·탄창/예약 탄 처리·수납 여유를 표시한다. 정상 장전/예약 탄은 기존 탄약 원장으로 반환하되 무한 예비탄 권총에서는 탄약을 생성하지 않는다. 전부 수납할 수 없으면 거래를 거절하고 총과 탄을 보존한다. 자동 분해는 첫 단계에 넣지 않는다.

저티어 전설의 장기 가치는 **기록 + 제한된 계승**으로 남기는 안을 제안한다. 처음 얻은 전설의 원형을 발견 기록에 등록하고, 나중에 같은 계열의 상위 티어 기반총·해당 단계 특수 부품·연구를 확보하면 전설 효과만 한 번 이전한다. 원본 총은 소비하고 일반 옵션은 대상 총의 것을 유지하며 전설 효과는 하나만 허용한다. 대상은 희귀 3옵션 기반총으로 제한하고, 결과는 대상 티어의 전설로 정한다. 상위 티어 접근을 우회하거나 전설 효과를 복제하지 않는다.

계승은 후속 제안이며 첫 드롭 개편의 필수 개발 항목이 아니다. [보석 강화](14-minerals-gems-and-enhancement.md)의 확정 강화 방향과 조정해 비용·해금 위치를 정한다. 영구 파괴 확률·등급 하락·실패 강화는 도입하지 않는다.

## 9. 발견·비교 화면과 실제 표현

[FIELD v1](../production/22-uiux-guide.md)·[INK v1](../production/06-rendering-quality-standard.md)을 따른다. 기술 티어는 문서/데이터에서 사용하고 플레이어 화면에는 기존 Mk. 모델명과 실성능을 보여 준다.

- 현장에서는 실제 총기/상자 모델, 작은 등급 표식, 속성 모양을 먼저 보여 준다. 희귀/전설은 짧은 발견 효과·소리로 구분하되 화면을 덮는 상시 광기둥이나 넓은 지면 원은 사용하지 않는다. 주변 후보를 조준할 때 이름/핵심 비교를 표시한다.
- 등급 색은 이름/작은 테두리 표식, 속성은 탄종 아이콘/총의 작은 코어 부위로 나눈다. 파란 고급의 열 속성처럼 두 정보가 공존한다. 카드 전체나 총 전체를 등급색으로 덮지 않는다. 색과 함께 등급명·서로 다른 표식을 쓴다.
- 비교는 같은 슬롯의 현재 총과 나란히 모델·직접 피해·장전 포함 지속 DPS·탄창/장전·탄약·속성·옵션·전설 조건을 보여 준다. 열 지속 피해나 연쇄 피해를 조건 없는 기본 DPS에 합산하지 않는다. 다른 계열의 유불리는 단일 초록 화살표로 판정하지 않는다.
- 예: `도약 전류 Mk.2` / `전설` / 전격 아이콘 / 재장전 -12%·반동 -10%·탄창 +15% / ‘3회 명중 후 주변 적에게 전류’. 내부 T2나 저장 필드는 표시하지 않는다.
- F 회수 후 자동 장착하지 않는다. 배낭이 가득 차면 물건과 추첨 결과를 현장에 보존하고 이유를 표시한다. 기존 8칸·장착 포함 수납 규칙을 유지하며 별도 무한 무기 가방을 추가하지 않는다. 등급/계열/속성 정렬, 즐겨찾기 잠금과 발견 기록이 정리를 돕는다.
- 속성 발사·명중·상태 시작/종료를 구분한다. 피해 숫자는 기존 실드/체력 의미를 유지하고 필요한 작은 속성 아이콘만 더한다. 열 불씨·냉각 서리·전격의 짧은 접촉·부식 얼룩은 표적 실루엣과 조준점을 가리지 않는다.
- 실제 제작 시 Blender 원본/GLB·가동부·전설 식별 부품을 만들고 Forward+로 발사/장전/드롭/작은 화면을 확인한다. 필요한 신규 음원은 ElevenLabs로 제작하고 출처를 남긴다. 실제 제작된 최초 네 전설과 재사용 음원은 186 기록을 따른다. 나머지 후보는 제작 완료가 아니다.

## 10. 데이터·저장·단일 행동 범위

현재 `equipment.json`의 모델/티어 정의, `firearms.json`의 계열/희귀도, `loadout.weapon_rolls`와 `weapon_states`를 확장하는 방향이다. 신규 정의는 무기 옵션·속성·전설·전리품 풀을 별도 데이터 묶음으로 관리하고 런타임/UI가 같은 해석기를 사용한다. 파일 분리는 구현 시 정하되 수치를 코드에 중복하지 않는다.

새 개체에는 기존 ID/소유/출처 외에 `roll_version`, `loot_pool_version`, `element_id`, `affixes[{id,value}]`, `legendary_id`, 결과 생성 근거를 보존한다. 난수 시드만 저장해서 데이터 업데이트 때 이미 본 물건이 바뀌게 하지 않고 최종 결과를 저장한다. 탄창·장전 예약·열·전설 대기는 별도 전투 상태다.

기존 물건은 재추첨하지 않는다. 구형 `weapon_rolls`는 기존 고정 피해/장전 보너스를 가진 호환 프로필로 해석하고 소유 ID·슬롯·탄·성능을 유지한다. 표시 등급만 새 이름에 대응시키며 새 옵션 세 개나 전설 능력을 소급 생성하지 않는다. 상세에 구형 효과를 명시해 새 전설과 효과가 다른 이유를 알 수 있게 한다. 이미 생성된 미회수 사건도 구 풀을 보존한다. 구 저장에 `roll_version`이 없다는 이유로 새 일반 프로필을 씌워 성능을 낮추지 않는다.

새 속성 피해는 호스트가 무기/표적/현재 엄폐로 판정한다. 표시 클라이언트는 실제 결과를 재생하며 옵션·속성·보상 값을 지정할 수 없다. 상태 만료시각·기여자·전설 대기와 처치 결과를 호스트 시간 기준으로 보존한다. 비활성 지역/호스트 종료 중에는 전투 상태 시간을 진행하지 않고, 재접속으로 상태를 지우거나 오프라인 처치/보상을 만들지 않는다.

| 단일 행동 | 변경/발행 범위 | 실패·중복/닫힌 화면 |
| --- | --- | --- |
| 무기 생성·회수 | 해당 발생 보상 + 회수자 개체/배낭 + 중복 방지 영수증 | 저장 실패/만석에는 원본 유지, 다른 사건 추첨·전체 지형 재생성 없음 |
| 발사·속성 틱 | 사수 무기 상태 + 실제 명중 대상/근처 전이 대상 + 전투 결과 | 중복 탄 소모·축적·전설 발동 없음, 틱마다 세계 복사/파일 저장을 새로 추가하지 않음 |
| 장착·비교 | 해당 캐릭터의 무기 성능 캐시 + 열린 비교 카드/손 모델 | 닫힌 아이템창의 전 카드·행성 모델을 재생성하지 않음 |
| 분해·계승 | 해당 무기/재료/탄 원장 + 완료 영수증 | 전체 수납 확인 후 원자적으로 확정, 취소/재전송의 재지급 금지 |

활성 상태 효과만 만료 큐에서 처리하고 50만 행성·8,000종을 매 틱 순회하지 않는다. 전이는 가까운 유효 표적 수·거리·시야·발동 깊이 상한을 갖고 동일 표적을 중복 선택하지 않는다. 한 행동의 입력→변경→복사/검증→저장→발행→표현을 실제 구현 때 추적한다. 기존 체크포인트의 전체 검증/직렬화 비용은 유지되는 경계로 기록하며 국소 처리 설계만으로 사라졌다고 주장하지 않는다.

## 11. 제안하는 제작 순서와 최소 확인

| 단계 | 구현 범위 | 필요한 최소 확인 |
| --- | --- | --- |
| W01 | 새 등급 표시·개체 옵션·제작/드롭 연결·비교·기존 저장 호환 | 같은 티어 다섯 등급, 다른 티어 동일 등급, 구형 성능/탄 보존, 만석/중복 회수 한 번씩 |
| W02 | 물리/열/냉기/전격/부식·저항·호스트 상태와 실제 표현 | 실드 넘침·열 틱·감속 복귀, 산탄/레이저 축적 예산, 정상 사격/장전/탄 소모와 렌더·소리 |
| W03 | 최초 전설 네 종·출처별 풀·잠금/분해 | 실제 전리품 회수→장착→전용 효과, 전이 엄폐/재귀 차단, 저장 재개·한정된 협동 중복 확인 |
| W04 | T4/T5 기반총/제작·나머지 전설·정밀 제작/계승 | 실제 신규 자산·상위 티어 접근·재료 비용과 선택한 성장 거래 확인 |

W01~W03의 현재 T1~T3 드롭/전투/제작 첫 묶음을 구현했다. 위 화면/도감 목표 전체의 완료와는 구분하며 실제 범위는 186 기록을 따른다. 모든 티어의 등급 독립이 목표이며 W04가 끝나기 전 T4/T5까지 플레이 구현 완료라고 기록하지 않는다. 단계별 통과 수량을 늘리는 전체 회귀/반복 검사는 하지 않고, 버그가 생기면 재현·수정 확인 범위만 넓힌다.

미정은 정확한 티어 성장곡선·시간당 드롭량·상태/전설 수치·계승 비용과 해금 위치다. 내장 모듈까지 명칭 통일, 개인별 전리품, 함선 무장 속성, 세트·독·방사선·중력 속성은 이번 첫 안의 범위 밖이다. 현재 첫 묶음의 게임 구현과 좁은 실행 확인은 186 기록을 따른다. 실제 재미·장시간 전설 획득 빈도의 검증은 아직 수행하지 않았다.
