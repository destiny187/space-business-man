## 확정 요구사항과 구현 선택

사용자 확정: 아이템창에 채집 재화가 쌓이고, 무기를 직접 제작한 뒤 번호 슬롯에 장착해 사용한다. 채집기는 등급이 높을수록 빨리 획득하며 상위 광물에는 필요한 최소 등급이 있다. 자원채집기·공격무기·지형 변환기는 기능과 모델을 분리한다.

슬롯 수 5, 장비 보관 한도 24, 최초 7개 설계도와 아래 수치는 조정 가능한 구현 선택이다. 원본은 [`equipment.json`](../../우주-비즈니스/data/equipment.json)이며 사용자 확정 밸런스가 아니다.

## 시작과 제작 루프

1. 새 개인 캐릭터는 탐험복과 내장 스캐너, 자원채집기 Mk.1을 가지고 시작한다.
2. **2026-09-07 사용자 확정:** 최초 장비 구성 시 채집기를 1번 슬롯에 자동 장착하고 선택한다. 기존 프로필에 반입 채집기가 있으면 해당 ID·등급을 유지해 장착한다.
3. 시작 채집기는 기초 조립 키트를 사용한 상태로 지급한다. 기존 저장의 장착·선택 상태는 유지하며 이후 제작 장비는 직접 장착한다.
4. B로 기존 무료 현장 사업을 등록하고, 광맥에서 철·구리·암석 등을 채집한다. 재료는 내 배낭에 쌓인다.
5. 배낭 재료로 상위 채집기·공격무기·지형 변환기를 제작하고 슬롯에 배치한다. 장비를 바꾸면 실제 1인칭 모델과 행동이 함께 바뀐다.
6. 건설·로봇·환경 개선에 사용할 나머지 재료는 F로 기존 현장 창고에 반납한다.

초기 기초 채집기만 조립 키트를 사용하며 추가 기초 채집기 복제 제작은 막는다. 다른 설계도는 재료가 있으면 복수 제작할 수 있다. 내 배낭에서 휴대 제작하고, 공동 크레딧이나 현장 창고를 원격 차감하지 않는다. 제작 시간 대기열·제작대·장비 매각/분해·드롭 획득은 아직 없다.

| 종류 | 현재 등급 | 실제 기능 |
| --- | --- | --- |
| 자원채집기 | Mk.1 / 2 / 3 | 각각 0.6 / 0.4 / 0.3초 간격, 한 번에 최대 3 / 4 / 5개. 광맥 잔량과 배낭 여유로 제한 |
| 펄스 카빈 | Mk.1 / 2 | 단발 펄스. 동물에 20 / 40 피해, 기본 체력 60. 체력 0은 무력화 자세로 표시. 아군·시설·식물에는 피해 없음 |
| 지형 변환기 | Mk.1 / 2 | 국소 굴착 반경 1.4 / 1.7m. 기존 굴착 거리·지층·기록 한도 안에서 지형 변경. 굴착 암석 1개 획득 |

철·구리·암석·얼음은 채집기 1등급, 결정은 2등급을 요구한다. Mk.3은 현재 속도·획득량 성장 단계이며 전용 3등급 광물은 아직 없다. 광물별 최소 등급은 행성 티어와 별도다. 로봇 자동화의 기존 채광 등급 규칙은 이번 휴대 장비 변경 대상이 아니다.

지형 변환기로 사업 광맥 잔량을 차감하거나 결정·철을 얻지 못한다. 굴착 암석은 기존 별도 운반 화물로 기록하고 아이템창에서 함께 표시하며, 반납 때 현장 창고 암석과 합친다. 매립·평탄화·광역 행성 테라포밍은 지형 변환기에 아직 포함되지 않는다.

## 소유·협동·저장

- `crew.members[character_id].loadout`에 개체→설계도, 5개 슬롯, 현재 슬롯, 조립 키트, 개체 순번을 기록한다. 기존 개인 프로필은 덮어쓰지 않는다.
- 구 프로필의 `rock_tool`은 원래 ID와 등급을 유지해 채집기로 표시한다. 자동으로 버리거나 새 기초 장비로 치환하지 않는다. 구 저장에 `loadout`이 없으면 첫 장비 거래에서 추가한다.
- 새 제작 장비는 해당 캐릭터가 이 호스트 세계에서 소유한다. 다른 참가자가 장착·처분할 수 없고, 재접속/호스트 재시작 후 남는다. 다른 호스트 세계로 제작 장비를 반출하는 기능은 아직 없다. 개인 반입 장비 보존과 세계에서 제작한 장비 반출은 구분한다.
- `equipment_craft`, `equipment_equip`, `equipment_select`는 기존 세션 요청 순번·리비전·중복 수령 기록·원자적 저장 경로를 사용한다. 호스트가 소유·재료·슬롯을 판정하고 저장한 후 클라이언트에 반영한다.
- 채광 간격·광물 등급·실제 획득량과 굴착/공격 장착 조건도 호스트가 확인한다. 클라이언트의 효과가 판정을 대체하지 않는다.
- 배낭 자원은 기존 `business.bags`, 공동 크레딧·창고는 기존 사업 원장을 사용한다. 메뉴 표시를 위해 복사 재화를 새로 만들지 않는다. 이탈 시 기존 세계 화물 회수 규칙을 유지한다.
- 동물 피해는 행성 주소+개체 ID별 `crew.combat`에 남고 현재 스냅샷으로 공유한다. 무력화는 전리품 생성·표본 지급과 별개다. 현재는 동물 반격 AI·플레이어 체력/방어구·완결된 전투 생태를 구현하지 않았다.

구현·렌더와 실제로 확인한 범위는 [제작 기록](../production/21-ground-equipment.md)을 따른다.

## 2026-09-07 — 중첩형 통합 아이템창 (현재 규칙)

사용자 확정: 자원 0개 목록과 장비/화물을 따로 나열하는 구조를 없애고, 최대 중첩 수가 있는 하나의 아이템창에서 관리한다. 이 절은 위의 개인 장비 24개·배낭 총량 96개 및 굴착 암석 별도 취급 설명에 우선한다.

- 개인 장비·광물·가공품은 **아이템** 격자와 공통 칸 한도를 사용한다. 2026-09-07 후속 사용자 확정으로 기본 수납은 **8칸**, 자원/가공품은 칸당 100개, 개별 장비는 1개다. 원본은 `data/inventory.json`이다. 보유량 0인 키는 저장 호환용으로 남을 수 있지만 화면과 칸 계산에서는 제외한다.
- 장비의 개체 ID·개조 상태·번호 슬롯은 보존한다. 자원 합계는 기존 호스트 원장에 한 번만 저장하고, 100개를 넘으면 화면에서 여러 스택으로 나타낸다. 수동 스택 이동/분할은 이번 범위가 아니다.
- 채광·굴착·창고 인수·회수 화물과 제작은 공통 칸 여유를 검사한다. 굴착 암석은 같은 배낭의 `stone`으로 들어가 제작/반납에 사용한다. 구 저장의 `carried`는 다음 관련 호스트 거래의 복사본에서 합치고 저장 성공 후 확정한다.
- 공동 창고는 개인 소유와 구분되는 같은 창의 별도 탭이며, 품목별 총재고를 표시해 대량 재고로 불필요한 수만 개 카드를 생성하지 않는다. 현장에서는 기존 거리 조건으로 인수/반납하고, 선내의 기존 암석 보관함도 통합 배낭과 연결한다. 생체 표본의 연구/선박 소유 체계는 기존 규칙을 유지한다.
- 원장/장비의 저장 구조를 강제로 재작성하지 않는다. 정상 종료 시 운반품을 회수 화물로 보존하는 기존 이탈 규칙도 유지한다.

## 2026-09-07 — 초기 8칸과 추후 수납 확장

사용자 확정: 초반 아이템창은 8칸으로 시작하고 추후 업그레이드로 확장한다. 현재 8칸은 장비·자원·가공품의 공통 수납 칸이며, 번호키 장착 슬롯 5개와 구분한다. 시작 채집기 1개가 1칸을 사용한다. 장착한 장비도 수납 칸에서 빠지지 않는다.

- 아이템 탭을 기본으로 열고 1280×800·960×640에서 4×2 격자로 표시한다. 미개방 칸 수십 개를 미리 나열하지 않는다. 제작·공동 창고의 별도 탭과 실제 3D 미리보기는 유지한다.
- 채집·굴착·인수·회수·제작은 해당 캐릭터의 수납 용량을 사용한다. 8칸이 모두 사용 중이어도 같은 자원의 마지막 스택에 남는 공간은 채울 수 있다. 새 칸이 필요한 획득은 거절한다.
- 기존 저장의 용량 필드가 없으면 기본 8칸으로 해석한다. 8칸을 넘는 기존 물건은 삭제하지 않고 전부 표시하며 `10 / 8칸 · 초과 보관`처럼 알린다. 초과 상태에서는 추가 수령을 막지만 장착·창고 반납·저장은 유지한다. 기존 장비/원장 저장 허용 상한 48칸은 호환 검사에만 남긴다.
- `loadout.inventory_slots`에 캐릭터별 수납 용량을 보존하고, 같은 값을 호스트 거래·화면이 읽는다. 이 필드는 추후 호스트가 확정하는 수납 업그레이드의 연결점이다. **현재 확장 구매/제작 기능은 없다.** 확장 단계·재료·가격·최종 상한은 후속 설계로 두고, 검사용 상한 48을 확정 성장 규칙으로 간주하지 않는다. 기존 탐험복 Mk.2 개조는 자동 수납 확장이 아니다.

[실제 화면·거래 경계·저장 확인](../production/41-eight-slot-inventory.md).

## 2026-09-07 — 유한 창고와 출항 물품

사용자 확정: 행성 기본 창고와 공동 우주선 창고는 각 10칸이며 아이템 드래그로 보관한다. 개인 기본 8칸은 유지한다. 행성 창고는 남겨두고 개인 배낭과 우주선 창고의 물품만 다음 행성으로 이동한다. 위의 무제한 공동 재고·일괄 반납·암석 전용 선박 창고·출항 전 배낭 비우기 설명을 대체한다. [단일 소관 규칙·구현·제약](../production/43-warehouse-and-fps-input.md).


## 2026-09-07 — 창고 빠른 이동 적용

C03에서 기존 드래그에 Shift+클릭 한 묶음 이동, 선택 수량 입출고, 자원 일괄 보관을 추가했다. 실제 재고·거리·수납 공간은 호스트가 판정하며 일괄 이동에서 장비는 제외한다. 행성/우주선 창고의 소유·출항 규칙은 유지한다. [실제 창·거래·저장 확인](../production/46-ground-play-repairs.md#c03--창고-빠른-입출고).

## 2026-09-09 — 성장 외장과 염색 확장

사용자 확정: 강화할수록 실제 탐험복 파츠가 점차 보강되며, 기존 리깅과 동작을 유지한다. 추후 파츠별 염색을 지원한다. 현재 3계열별 투자 단계에서 누적 외장을 계산하고 실제 승무원과 I 신체에 표시한다. 헬멧·흉부·팔·다리·배낭·벨트의 도색 영역을 분리했다. 단계 문턱과 모델 경로는 `data/suit_appearance.json`이 소유한다. 염색 메뉴·저장·동기화는 아직 구현하지 않았다. [제작·실제 확인 범위](../production/94-progressive-suit-appearance.md).

## 2026-09-09 — 부위별 염색 메뉴 후속 구현

이전 절의 염색 메뉴·저장·동기화 미구현 상태를 갱신한다. I 염색에서 6부위의 3색을 미리보고 한 부위당 보석 1개로 적용한다. 사용자 후속 요청에 따라 사파이어(헬멧/다리), 루비(팔/벨트), 에메랄드(배낭), 다이아몬드(흉부)로 나눈다. 기본색 복원은 무료다. 비용 원본은 `data/suit_appearance.json.dye_costs`이며 세계별 개인 승무원 색상을 저장한다. [실제 범위와 검증](../production/95-suit-dye-menu.md).
