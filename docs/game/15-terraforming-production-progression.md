## 설계 원칙

- 초반에는 채집한 기초 재료로 기존 대기·열·물·배양 설비를 직접 만들고 작동시켜 지역 복원 계약을 끝낼 수 있다. 기존 기초 제작에 정제·화학·부품 공정을 소급 강제하지 않는다.
- 고급 제품은 처리 속도뿐 아니라 **처리 대상, 가동 가능한 환경 범위, 목표에 도달할 수 있는 성능, 영향 면적, 자립 유지 능력**을 연다. 기초 설비를 수십 대 쌓아도 처리할 수 없는 오염·온도·물질 문제를 둔다.
- 행성 티어, 생산 기술 단계, 환경 복원 단계, 최종 평가 등급을 구분한다. 행성 T3라는 이유만으로 모든 설비를 3급으로 교체하지 않는다. 그 행성의 주요 환경 문제에 맞는 고급 제품이 필요하다.
- 저티어 행성의 표준 복원 목표는 기초 설비로 완료 가능하다. T1에도 더 넓은 개발·고급 생태 정착이라는 선택 목표를 둘 수 있으나, 이를 기존 입문 계약의 필수 조건으로 만들지 않는다. 지역 계약과 행성 전체 완료의 범위는 명시한다.
- 후반에도 철·구리·얼음·인산염 등 기초 자원의 수요를 유지한다. 고급 제품은 기존 재료를 가공·조합하며, 모든 기초 부품을 최고급 원광으로 대체하지 않는다.

## 제안하는 5개 생산 단계

표의 행성 티어는 대표적인 요구 분포다. 특정 행성에는 여러 단계의 문제가 섞일 수 있으며 수치 상향만으로 난도를 결정하지 않는다.

| 생산 단계 | 대표 행성·문제 | 새로 생산할 핵심 제품 | 환경 설비·해결 능력 | 눈에 보이는 성과 |
| --- | --- | --- | --- | --- |
| P1 기초 개척 | T1 중심 · 온화한 범위의 온도·대기·물 부족 | 기존 기초 건설 재료와 얼음 보급 | 현재 대기 처리기·열 조절기·물 공급기·기초 배양기 | 거점 주변 먼지 감소·습윤 지면·작은 정착 구역 |
| P2 정제·화학 복원 | T2 중심 · 염류·특정 독성·척박한 토양 | 정제 금속, 광물 필터, 중화 카트리지, 토양 기반재 | 선택 오염 정화기·담수 처리기·토양 개량기 | 오염층/염류 껍질 감소·맑아진 물·흙 구역 형성 |
| P3 복합 환경 조성 | T3 중심 · 물·열·토양·생물 조건이 얽힘 | 내식 합금, 교환막, 열교환 모듈, 정착 배양 팩 | 폐쇄 수자원 순환기·지역 열교환기·선구종 정착기 | 물 공급 구역 연결·토양 확장·풀/관목 정착 |
| P4 극한 환경 제어 | T4 중심 · 지속 과열·극저온·강한 외부 유입 | 내환경 복합재, 정밀 제어기, 고효율 반사판, 대용량 열전달 모듈 | 고온/저온 전용 설비·대형 방열/차광 설비·광역 정화 거점 | 용암 지각 안정·해빙 전선·환경 경계 후퇴 |
| P5 광역 연결·자립 안정화 | T5 중심 · 넓은 범위와 장기 유지 문제 | 성핵 전달 코어, 암흑 안정화 코어, 생태 순환 패키지 | 광역 환경 중계·에너지 조절망·생태 유지망 | 여러 복원 구역 연결·안정된 식생/물 순환·지원 부담 감소 |

식생·물 흐름·해빙 등의 시각 성과는 목표다. 현재 지면 색 변화만으로 위 성과를 구현 완료로 취급하지 않는다. P5도 한 기계로 행성 전체를 즉시 바꾸지 않으며 관측·유지·범위별 평가를 요구한다. 궤도 설비는 P4/P5의 후속 확장 후보로 두고 첫 생산 고도화에 강제하지 않는다.

## 실제 제작 흐름 — 제품 후보

아래 화살표는 **게임용 압축 제작식**이다. 현실의 화학 반응식·정확한 물질수지 또는 확정 제작 수량이 아니다. 추가 원료·유체가 필요하면 후속 데이터에서 출처를 함께 정의한다. 보석 4종은 캐릭터/장비 강화의 주 용도를 유지하며 표준 테라포밍의 필수 소모품으로 전용하지 않는다.

| 제품 후보 ID | 원료/선행 제품 | 만드는 시설 | 사용 방식 |
| --- | --- | --- | --- |
| `refined_metal` | 철·구리·알루미늄 등 대응 원광 | 기초 정제기 | 금속별 정제재로 보관; 고급 시설/부품의 건설 재료 |
| `mineral_filter` | 규소 + 정제 프레임 | 여과재 작업기 | 오염 유형에 맞는 필터 제작; 포화 시 교체/재생 |
| `neutralizer_cartridge` | 해당 오염에 맞는 현지 반응 광물 + 처리수 | 화학 처리기 | 독성 처리량에 따라 소비; 모든 독성을 한 약품으로 지우지 않음 |
| `soil_base` | 분쇄 암석 + 인산염 + 처리수 | 토양 혼합기 | 대상 면적에 투입해 토양 기반 형성 |
| `resistant_alloy` | 정제 티타늄 + 정제 니켈 | 합금로 | 내식/내열 시설·모듈의 영구 건설 재료 |
| `exchange_membrane` | 여과재 + 내식 합금 + 검증된 설계 | 정밀 부품기 | 순환·선택 분리 모듈에 장착; 수리/교체 가능 |
| `heat_exchange_module` | 정제 구리 + 내식 합금 + 제어 부품 | 모듈 조립기 | 수원·열원·외부 방열 경로와 연결해 운용 |
| `pioneer_culture_pack` | 토양 기반재 + 인산염 + 적합한 배양종 | 배양 설비 | 정착 면적에 투입; 생존 조건을 갖춘 뒤 효과 발생 |
| `environment_composite` | 내식 합금 + 규소계 재료 | 복합재 가공기 | 극한 환경에 견디는 외피·반사판 제작 |
| `precision_controller` | 정제 구리·규소 + 희토류 부품 | 정밀 조립기 | 고급 설비의 안정 범위·연동 제어 확보 |
| `stellar_transfer_core` | 가공 성핵광 + 전도 부품 + 복합재 | 고급 코어 조립기 | P5 고출력 전달 설비의 핵심 부품 |
| `dark_stability_core` | 가공 암흑광 + 정밀 제어기 + 복합재 | 고급 코어 조립기 | P5 안정화 설비의 핵심 부품 |
| `ecological_cycle_package` | 복수의 검증된 정착 배양 팩 + 기반재 | 생태 조립/배양 설비 | 서식지 연결·분해/영양 순환의 초기 정착 |

`refined_metal`은 설계상의 제품군 표기이며 실제 재고는 철·구리 등을 구분한다. 새 제품용 정제재를 추가하더라도 기존 원광 재고나 P1 레시피의 의미를 바꾸지 않는다. 성핵광·암흑광은 [기존 최고급 공통 소재](14-minerals-gems-and-enhancement.md)의 확장 소비처 제안이며 실제 효능을 주장하는 광물이 아니다.

건설 재료, 영구 장착 모듈, 운전 소모품, 초기 정착 투입물을 별도 속성으로 둔다. 비싼 코어를 매초 태우는 방식은 피하고 소모품은 처리량과 연동한다. 이미 정착한 생태를 매 주기 다시 구매하게 만들지 않는다. 지원이 필요한 종의 물·영양 공급은 별도 운영 비용이다.

## 기초 기계가 고급 문제를 해결하지 못하는 이유

단순 `planet_tier >= 3` 잠금 대신 설비가 실제 필요한 처리 능력을 갖추었는지 확인한다.

- **처리 대상:** 일반 먼지 필터는 고염도·특정 용해 오염을 제거하지 못한다. 맞는 막·중화 제품이 필요하다.
- **작동 범위:** 일반 외피/열교환기는 극한 열·부식에서 정격 성능을 내지 못한다. 내환경 재료를 장착해야 한다.
- **도달 한계:** 주변에서 열·오염이 계속 유입되면 소형 설비는 목표 이전에 평형에 도달한다. 같은 유입원에는 중복 설비의 유효 처리량 상한을 두고, 고급 방식으로 원인을 처리해야 한다.
- **영향 범위:** 소형 설비는 자기 구역의 상태만 바꾼다. 넓은 지역 목표에는 수송·중계·복수 거점의 연결과 실제 범위 충족이 필요하다.
- **생태 유지:** 온도·물 지수가 맞아도 토양·기질·종 구성이 부족하면 자립 정착하지 않는다. 기초 배양기는 입문 목표까지, 복합 배양 제품은 후속 정착을 담당한다.

동일 기초 설비 추가는 지원 범위 안에서 처리량·중복 대비를 높이는 유효한 선택으로 남긴다. 부족한 처리 방식·정격 환경 범위를 무한 증설로 우회하지 못하게 한다. 해당 이유와 필요한 제품을 탐사/건설 화면에서 미리 알린다. 건설 후 이유 없이 진행도가 멈추는 숨은 장벽으로 만들지 않는다.

## 고온 행성의 한 원정 예시

1. 이전 행성에서 P3 내식 합금·열교환 모듈과 보급품을 제작해 가져온다.
2. 안전한 착륙 후보에 임시 기지를 세우고 지역 냉각으로 접근 가능한 자원을 확보한다.
3. 현지 원료를 정제하고 P4 내환경 복합재·정밀 제어기·대용량 열전달 모듈을 만든다. 부족한 원료는 이전 거점의 실제 화물이나 명시된 교역 경로로 공급한다.
4. 외부 열 유입을 줄이는 차광/반사와 방열 경로를 함께 구성해 개척 구역의 지각과 온도를 안정시킨다.
5. 처리수·토양 기반재·정착 배양 팩을 공급해 정착 범위를 늘린다. 냉각 완료를 생태 완료로 간주하지 않는다.
6. 지역 계약은 해당 목표에서 정산할 수 있고, 더 넓은 복원은 다음 사업 목표로 이어진다.

현재 기본 열 설비가 약 320°C 화산을 냉각해 광맥을 해금하는 기능은 이미 있다. 이 설계는 기존 저장에서 그 능력을 갑자기 회수하는 변경이 아니다. 기존 화산·계약·설비는 저장 버전대로 유지하고 새 복합/극한 문제 프로필에서 고급 능력 요구를 적용하는 안이다. 입문 경로의 현재 실제 가능성을 보존한다.

## 선행 조건과 막힘 방지

생산 시설의 해금 순서는 **기초 재료로 정제기 건설 → 정제재로 화학/합금 시설 건설 → 그 산출물로 정밀/배양 시설 건설 → 복합재/제어기로 고급 조립 시설 건설**로 둔다. 어떤 시설도 자기 시설에서만 나오는 첫 제품을 건설 선행 재료로 요구하지 않는다.

최고급 코어 전에 확보할 수 있는 T4 소규모 광체·탐사 경로를 남긴다. 기존 최고급 원광의 T4 이상 분포와 채집 등급 3 경로를 기준으로 하고, P5 코어를 만들려면 P5 완전 복원이 먼저 필요하게 만들지 않는다. 첫 광체가 냉각이 필요하면 P3/P4 국소 접근으로 확보할 수 있어야 한다. 200m 기반암 아래에 필수 자원을 놓지 않는다.

필수 표준 도면·입문 배양종은 확정 연구/제작 경로로 제공한다. 희귀 생물·유물은 효율·특화 해결책을 열되 필수 랜덤 추첨으로 진행을 막지 않는다. 완제품 구매·다른 행성에서의 생산/운송은 가능한 대안이지만 해당 고급 **제품과 능력의 필요성**을 없애지는 않는다. 실제 가격·재고·운송 조건은 경제 설계에서 조정한다.

첫 고급 생산 전에 조사·국소 복원·공급 과제 등 확정 수익을 마련한다. 전력·가공·수송·설비를 한 번에 무상 지급하지 않는다. P2 첫 구현은 기존 창고 입출고로 공정을 연결하고, 컨베이어·배관·다중 행성의 상시 자동 생산은 후속으로 구분한다.

## 생태 단계·평가·화면

생산 단계는 해결 도구의 수준이며, 환경 변화는 기존 `국소 제어 → 물·토양 기반 → 선구종 → 공생·정착 → 안정화 → 광역 연결`을 따른다. 모든 행성이 동일한 여섯 단계를 처음부터 거칠 필요는 없다. 이미 물과 토양이 좋은 행성은 해당 기반을 활용한다. 자연 생태가 있는 곳은 무조건 지우고 지구형 생태를 새로 심지 않는다.

평가에는 목표 범위·처리되지 않은 핵심 문제·면적 충족·안정성·운영 의존도를 사용한다. P5 제품을 보유했다는 이유로 S등급을 주지 않는다. 단계별 보상은 고유 계약 ID로 한 번 지급하고 최종 정산에서 이중 지급하지 않는다. 정확한 점수·가격·유지 시간은 별도 밸런스다.

UI는 행성 문제 아이콘 → 필요한 처리 능력/제품 카드 → 생산 과정과 부족한 재료 → 실제 설비 미리보기 → 환경 변화로 연결한다. FIELD v1을 따르며 새 화면은 아직 제작하지 않았다. 세계에서는 필터 포화·토양 살포·서리/염류 경계 변화·정착 개체를 실제 모델·효과로 보여준다. Blender·INK 렌더, 필요한 ElevenLabs 음원 연결 전까지 제품 아이콘/수치만으로 시각 완료를 표시하지 않는다.

## 데이터와 실제 구현 순서

후속 데이터는 레시피 입력/출력·가공 시간·전력, 설비의 처리 태그/정격 범위/상한/면적, 환경 문제의 요구 능력·유입/손실·목표, 제품의 건설/장착/소비/정착 용도를 분리한다. 처리되지 않는 문제는 생태 점수 평균으로 숨기지 않는다. 새 규칙은 저장 스냅샷·버전을 유지하고 호스트가 재료 소비·생산·장착·계약 지급을 확정한다.

1. P1 유지와 환경 문제/설비 능력 구조를 먼저 연결한다.
2. **P2 염류·독성 복원 한 경로**를 구현한다. 정제 → 여과재/처리수 → 토양 기반재 → 실제 지표 변화 → 지역 정산까지 작게 완주한다.
3. P3에서 열·물 순환과 배양 제품을 연결한다.
4. P4의 극한 환경 및 P5의 광역/자립 목표를 별도 단계로 확장한다.

최초 설계 시점에는 기본 지역 환경 설비가 중심이었다. 후속 사용자 요청으로 2티어 공통 가공 제품·첫 개조·염류/토양 처리까지 구현했다. 위 표의 전체 정제/화학 생산망, P3~P5 및 다단계 생태/광역 평가는 아직 미구현이다. 실제 구현과 검증은 [2티어 제작 기록](../production/36-tier2-production-and-retrofits.md)을 따른다.
