# 경제·기술·계승

## 확정 요구사항

- 초기 자본으로 행성과 기초 장비를 마련한다. 첫 행성은 작고 척박하다.
- 로봇 제작에 필요한 초기 기술부터 구매해야 한다.
- 행성 판매 수익으로 추가 기술과 다음 테라포밍 행성을 구매한다.
- 기본 상점과 레어 상점 등이 존재한다.
- 우수한 AI 장비를 지구로 가져왔다가 다음 행성으로 보내는 기술이 있다.
- 높은 등급의 우주선일수록 더 많은 로봇을 운반한다. 후반에는 좋은 로봇을 동반해 초기 작업을 줄일 수 있다.

## 자산과 경제 경계 — 설계 제안

| 자산 | 용도 | 행성 판매 후 |
| --- | --- | --- |
| 크레딧 | 행성·기술·우주선 구매 | 유지 |
| 기술 소유권 | 제작법·설비·회수 기능 해금 | 유지 |
| 현지 자원 | 건설·제작·운영 | 기본적으로 행성에 남음 |
| 현지 시설·로봇 | 생산·테라포밍 | 회수하지 않으면 행성에 남음 |
| 지구 보관 로봇 | 다음 행성 출발 편성 | 유지 |
| 반출품·도감 | 수집·판매·추가 해금 | 해당 반출 규칙에 따라 유지 |

MVP는 한 번에 한 행성을 소유·운영하는 구조를 제안한다. 여러 행성의 동시 시뮬레이션, 오프라인 생산, 금융·주식·복잡한 무역은 확장 전까지 제외한다.

## 기술 구조 — 설계 제안

기술 구매는 영구 해금이며 장비 즉시 지급과 구분한다. 기술을 산 후에도 장비 제작 자원이 필요하다.

| 기술 ID | 기술 | 선행 조건 초안 | 해금 |
| --- | --- | --- | --- |
| `basic_robotics` | 입문 로봇공학 | 시작 상점에서 구매 가능 | 채광로봇 제작 |
| `atmosphere_processing` | 기초 대기 처리 | 입문 로봇공학 | 대기 처리기 |
| `thermal_control` | 열 제어 | 기초 대기 처리 | 온도 조절기 |
| `water_processing` | 물 공급 | 기초 대기 처리 | 물 공급 설비 |
| `basic_biotech` | 기초 생태 정착 | 물 공급 | 표준 미생물 정착 |
| `robot_recovery` | 로봇 회수 | 입문 로봇공학 | 지구 보관·재파견 |
| `advanced_robotics` | 고급 생산 공정 | 입문 로봇공학 | 상위 모델·공정 |
| `artifact_analysis` | 유물 분석 | 유적 발견 등 | 고대 기술 분석 |

가격, 정확한 선행 관계, 구매 가능 시점은 밸런스 미정이다. 모든 기술은 구매 전에 효과·선행 조건·후속 제작 비용을 보여 준다. 미구현 기술은 구매할 수 없다.

### 상점

- **기본 상점:** 입문·필수 기술, 일반 행성, 기본 수송 능력을 안정적으로 공급한다.
- **레어 상점:** 희귀 기술, 특수 제조사 장비·설계도, 독특한 행성을 제공한다.
- 제안 갱신 시점은 행성 정산 후다. 다시 열거나 재접속했다고 상품을 재추첨하지 않는다.
- 레어 상품은 도감·회차 진행 등으로 해금하되 정상적인 회차 완료에 필수인 기술을 운에 맡기지 않는다.
- 기본 상점은 MVP에 포함하고, 레어 상점은 확장 단계로 둔다.

## 시작 자본과 막힘 방지 — 설계 제안

시작 예산은 임의의 숫자보다 ‘첫 행성 구매 + B등급 달성에 필요한 전체 기초 기술 경로’가 가능한지를 기준으로 잡는다. MVP에는 중간 현금 수입원이 없으므로 첫 매각 전 필수 기술을 모두 구매할 수 있어야 한다. 계승 검증용 시작 예산에는 회수 기술과 1슬롯 소형선까지 포함한다. 이는 테스트 예산 기준이며 출시 밸런스의 확정 가격이 아니다. 첫 버전의 구매 목록은 필수 경로를 잃지 않도록 제한하고, 선택 투자에는 준비금 경고를 표시한다.

- 수동장비·착륙 기지·기초 채집 도구는 시작 키트다. 채집과 기초 구조 활동을 유료 소모품으로 막지 않는다.
- 시작 지점의 보장 자원은 첫 채광로봇·전력·환경 개선에 필요한 양과 여유분을 포함한다.
- 자원이 시설에 묶였을 때 철거 환불로 회복할 수 있게 한다. 운영 소모 자원까지 환불하지 않는다.
- 판매 등급이 낮아도 현 상태 매각과 정산이 가능하다.
- 현금과 자원이 모두 바닥난 경우에는 **사업 재시작**을 최후 복구안으로 제안한다. 정상 출발 가능한 지구 상태를 안전 시작점으로 저장하고, 명확한 확인 후 사업 전체를 그 시점으로 되돌린다. 현금·기술·도감·지구 보관소를 함께 복원하므로 현재 회차에서 새로 얻은 자산과 진행은 사라진다. 기술을 산 뒤 현금만 다시 받는 반복 이익을 허용하지 않는다.
- 정상 매각 후 다음 행성을 살 돈이 부족한 상황에서도 사업 재시작 경로를 제공한다.

새 프로필의 초기 상태를 첫 안전 시작점으로 삼고, 이후 행성 구매 직전에 필수 진행 경로가 성립하는 지구 상태로 갱신한다. 새 출발이 불가능한 저가 매각 결과로 기존 안전 시작점을 덮어쓰지 않는다. 파산·대출·보험을 별도 경제 콘텐츠로 발전시킬지는 미정이다. 첫 버전에서는 영구 진행 불능을 막는 것이 우선이다.

## 로봇 회수와 수송 — 설계 제안

**회수 기술은 기능을 열고, 우주선은 수량을 제한한다.** 둘 중 하나만 만족해도 되는 구조로 구현하지 않는다.

| 수송 단계 예시 | 로봇 슬롯 | 조건 |
| --- | --- | --- |
| 초기 수송 | 0 | 수동장비만 기본 파견 |
| 회수 가능한 소형선 | 1 | 회수 기술 + 해당 우주선 구매 |
| 중형선 | 3 | 우주선 업그레이드 |
| 대형선 | 6 | 상위 우주선 업그레이드 |

슬롯 수는 제안값이다. MVP에서는 모든 로봇이 1슬롯을 사용하고 소형선까지만 구현한다. 크기·질량·특수 화물칸은 확장 시 검토한다. 수동장비는 기본 파견 대상이며 이 로봇 슬롯을 차지하지 않는다.

### 이전 절차

1. 매각 또는 귀환 준비 화면에서 회수 기술·우주선·로봇 소유권을 확인한다.
2. 회수 대상을 선택한다. 한도를 초과하면 조정 사유를 보여 주고 확정을 막는다.
3. 작업을 정리하고 현지 화물을 내린 뒤, 매각 거래에서 지구 보관소로 로봇 소유 위치를 이전한다.
4. 지구 보관소에는 같은 ID, 등급, 특성, 이름, 내구 상태를 유지한다. 경로·작업 예약·현지 좌표는 제거한다.
5. 다음 행성 출발 시 우주선 한도 안에서 편성하고, 지구 보관소와 새 행성에 동시에 존재하지 않게 이전한다.

회수 기술이 없는 로봇 또는 남기기로 한 로봇은 행성 잔존가치에만 반영한다. 출발 시 배터리는 기본 충전 상태로 시작하는 안을 제안한다. 수리비와 장기 보관 비용은 추후 결정한다.

## 성장 곡선 — 설계 제안

첫 행성에서는 첫 자동화와 판매를 익힌다. 다음 행성에서는 회수 로봇 덕분에 수동 초반 작업이 줄고, 그 시간으로 새로운 자원·환경·탐험에 도전한다. 후반의 복잡성은 같은 광석을 더 오래 캐게 하는 방식보다 새로운 설비 조합·물류·환경 조건에서 만든다.

경제 검증에서는 첫 필수 기술 구매 가능성, 판매 후 다음 행성 접근성, 회수의 이득과 남기는 가치의 비교, 희귀 로봇 의존도, 제작·철거·반출의 중복 수익, 사업 재시작 악용 여부를 확인한다.
