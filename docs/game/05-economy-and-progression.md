## 확정 요구사항과 변경

초기 자본·장비로 시작해 기술을 구매하고 AI 로봇을 제작한다. 기본·레어 상점, 테라포밍 평가·행성 판매, 좋은 로봇의 회수·계승과 우주선 성장에 따른 수송 능력 확대는 유지한다. **다음 행성을 구매한다는 전제는 자유 탐사·선정으로 대체**한다. 우주선에는 뽑기·개발·업그레이드 경로를 추가하며, 원주민과 협상·거래할 수 있다.

## 비용과 수익 — 설계 제안

| 비용 | 목적 | 수익 | 확보한 가치 |

| 항해·정비·보급 | 새 후보·연구 기회 접근 | 개발 성과·권리 매각 | 개선한 환경·시설·허용된 처분 권한 |
| 기지·생산·수송 | 채집·로봇·물류 기반 | 단계별 복원 계약 | 검증된 수질·기후·생태·유지 성과 |

| 생물실·표본·배양 | 다음 환경의 해결책 운송 | 교역·탐사 의뢰·인양 | 실제 인도한 화물·조사·구조 성과 |

첫 발견이나 개척 등록을 행성 구매 가격의 대체 장벽으로 만들지 않는다. 예산은 **첫 항해 왕복·기초 기술·기지·필수 환경 개선 경로**를 끝낼 수 있는지로 검산한다. 단계 지급을 쓰더라도 첫 지급 전 선행 투자가 가능한지 확인한다.

## 사업을 끝내는 방법

| 방식 | 정산 대상 | 정산 뒤 접근·자산 |
| --- | --- | --- |
| 완전 개발권 매각 | 처분 권한을 가진 개발 범위·시설·환경 가치 | 채굴·건축 권한 종료; 계약에 방문 권한이 있으면 관찰·교역 가능 |
| 복원 계약 완료 | 약속한 환경 성과 | 계약상 남기는 설비·접근 권한·유지 의무를 각각 확정 |
| 공동 운영 | 합의된 거점·생산·연구 서비스 | 지분·수익 배분·유지비; 상세 운영은 후속 확장 |
| 보류·철수 | 반출 자산·확정 단계 보상 | 미완료 사업 상태와 재방문 권한 유지, 위약 조건이 있으면 정산 |

주인이 있는 행성을 발견만으로 매각할 수 없다. 개발 권한은 [우주 탐사](07-space-exploration-and-ships.md), 문명과의 협약은 [외계문명](10-alien-civilizations-and-diplomacy.md)이 정의한다. 매각은 해당 권리·계약 범위에 한 번 적용하며 재방문이 재매각 권한을 만들지 않는다. 특정 권리가 없는 행성은 교역·조사·복원 계약으로도 사업을 할 수 있다.

첫 확장에서는 활성 개발 사업 하나와 보존된 탐사 목적지들을 관리한다. 여러 행성의 동시 운영과 오프라인 수익은 별도 범위다.

## 기술과 상점

2026-09-07 [테라포밍 생산 단계](15-terraforming-production-progression.md)를 설계했다. 기초 직접 제작을 유지하며 후반에는 정제·화학·합금·배양·코어 제품이 새 환경 문제의 처리 능력을 연다. 원료/제품의 수송·거래도 대안으로 두고 필수 희귀 추첨이나 시설 자기 산출물의 선행 요구로 첫 제작을 막지 않는다. 공정·경제 수치는 아직 구현 전 제안이다.

기술 소유권은 영구 해금이며 장비 즉시 지급과 다르다. 기술이 있어도 제작·배양에는 재료·전력·시설이 필요하다. 입문 로봇공학, 대기·열·물 처리, 기초 생태, 회수 기술은 확정 경로로 확보한다. 기존 제안 ID와 실제 코드 ID는 다를 수 있으며 구현 형식은 현재 카탈로그가 기준이다.

- **기본 상점:** 필수 기술·표준 선체·일반 모듈·보급품. 행성은 상품에서 제외한다.
- **레어 상점:** 특화 도면·장비·분석 의뢰·탐사 정보. 희귀 기술만으로 필수 진행을 잠그지 않는다.
- **현지 거래:** 문명·세력의 실제 수요와 재고, 허용된 지식·표본·서비스 교환.
- **연구실:** 발견 원리와 실험으로 특화 경로 해금. 연구의 기준은 [발견·연구](09-discovery-research-and-ecology.md).
- 상품·시제품 추첨·갱신 회차는 저장한다. 상점을 다시 열거나 재접속해 결과를 바꾸지 않는다. 갱신은 정산·새 보급 주기 등 확정 이벤트에 연결한다.

선체 추첨과 확정 개발의 역할·중복 처리·진행 보장은 [우주선 설계](07-space-exploration-and-ships.md)만을 기준으로 한다. 행성 티어와 선체 등급은 별개이며, 높은 티어 사업에도 표준 장비의 조합 경로를 남긴다.

## 협동의 소유·공동 장부 — 설계 제안

2026-09-07 최종 승인: 협동 계약은 [인원별 사업량·보상 기준](12-host-coop-and-crew.md)을 따른다. 시작 때 확정한 실제 사업 규모에 비례해 공동 보상을 한 번 지급하며, 참가자별 보상 복제나 전 품목 가격/제작식의 인원 배율은 적용하지 않는다. 진행 중 합류·이탈로 현재 계약의 목표·보상을 재산정하지 않는다. 기존 계약은 보존하고 새 프로필부터 구현한다.

멀티플레이에서는 개인 캐릭터·반입 장비와 호스트 세계의 선체·공동 화물·사업 현금·연구·기지를 분리한다. 소유와 현재 운반 위치를 따로 표시하며, 아래 표의 사업 자산은 각 참가자에게 복제하는 보상이 아니다. 개인 장비의 보존·세계 간 반출 범위·권한은 [호스트 협동](12-host-coop-and-crew.md)이 기준이다.

여러 명이 같은 구매·채집·제작·정산을 요청해도 입력은 한 번 차감하고 결과는 한 번 지급한다. 공동 지출·판매 확정은 협동 권한을 검사하며 호스트도 타인의 개인 장비를 처분할 수 없다. 초기에는 세션에서 얻은 신규 장비·재화를 호스트 세계에 보관하는 안으로 개인 원본 장비 유지와 분리한다.

## 자산과 우주선 계승

| 자산 | 기본 위치·역할 | 원정 간 유지 |
| --- | --- | --- |
| 현금·기술·연구·도감 | 프로필의 확정 기록 | 유지; 실물 표본 지급과 구분 |
| 우주선·모듈 | 고유 선체·장착 위치·개조 이력 | 유지; 교체 시 화물·전력·환경 조건 재검사 |
| 현지 자원·시설·로봇 | 행성의 실제 소유·위치 | 남기거나 적법한 회수 거래로 이전 |
| 운송 로봇 | 행성↔격납고↔목적지, 지구 보관소 | 같은 ID·등급·특성·이름·내구 유지 |
| 시료·생물·유물 | 개체/묶음 ID·용기·환경·반출 권한 | 실제 인계한 수량만 유지 |
| 협약·정산 이력 | 당사자·권한·지급·의무 | 재방문·단계 지급·관계에 반영 |

**회수 기술은 기능을 열고 우주선 구성은 운송 조건을 제한한다.** 출발은 매각과 독립적인 거래다. 회수 작업을 정리하고, 가져갈 물품과 남길 화물을 선택한 뒤, 출발지 감소·선박 적재·도착지 증가를 각각 안전하게 확정한다. 로봇·표본이 두 장소에 동시에 존재하지 않게 한다.

격납고 슬롯·질량·부피와 생물실의 조건은 별개이며, 정확한 단위·용량은 데이터로 조정한다. 모든 로봇을 1슬롯으로 보던 1.2 모델을 생물·차량에 그대로 적용하지 않는다. 반출한 물품은 현지 매각 잔존가치에서 제외하고, 생물은 [운송·이식 조건](09-discovery-research-and-ecology.md)을 따른다.

## 시작과 막힘 방지

기본선·수동 채집 장비·착륙 키트·첫 항해 여유는 확정 제공을 제안한다. 초보 후보의 필수 자원과 기초 기술 경로를 보장하고, 고티어 도전을 앞둔 화면에는 부족한 능력과 우회·외부 보급 대안을 보여 준다.

- 탐사·물자 운반·소규모 복원 같은 확정 일감으로 첫 매각 전 수입을 얻을 수 있게 한다.
- 자원이 시설에 묶였으면 철거·작업 취소로 아직 소비하지 않은 자산을 돌려받는다. 운영 중 소비한 연료·재료는 환불하지 않는다.
- 저등급 매각·협약 결렬·연료 고갈 후에는 구조·대여선·보급 거점·다른 후보의 길을 남긴다. 대여품·구조 보상을 되팔아 무한 수익을 얻지 못하게 한다.
- 희귀 로봇·선체·생물 없이도 일반 사업을 끝낼 수 있다. 생물 이식이 안 되면 표준 설비·다른 연구를 쓸 수 있다.
- 기존 **사업 재시작**은 안전 복구 기능으로 유지한다. 되돌리는 현금·기술·관계·화물·세계 변경 범위를 함께 안내하고 전부 같은 안전 시작점으로 복원한다. 현재 얻은 기술을 남기고 현금만 돌려주는 방식은 금지한다.

구조 비용·영구 손실·보험은 미정이다. 재시작은 세계를 새 시드로 재추첨하는 기능이 아니며, 시작점의 은하·행성·추첨 상태까지 함께 복원한다.
