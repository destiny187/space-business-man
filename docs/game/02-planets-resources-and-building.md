# 행성·자원·건축

현재 공동 탐험의 무료 지역 개발·유한 자원·지상 산업/로봇·복원 계약/계승 구현 범위는 [현장 사업 통합 기록](../production/13-expedition-industry-and-contracts.md)을 따른다. 아래 전체 목표 설계와 부분 구현을 구분한다.

## 확정 요구사항

2026-09-06 변경: 행성을 구매하지 않고 우주 탐사로 자유롭게 선정한다. 광활한 행성의 지표·지하를 탐험하며 자원을 채광·채집하고 장비·로봇·시설을 만들어 규모를 키운다. 초기 자본이 적다는 전제는 유지하되 작은 척박한 위성은 추천 출발 후보로 제안한다.

지하 탐험은 새 확정 요구사항이다. 블록 그래픽·무한 월드·전 지형 복셀 파괴는 미정이다. 지형·지하·이동의 기준은 [오픈월드](08-open-world-and-underground.md), 티어·시드 생성은 [은하 설계](11-galaxy-tiers-and-seeds.md)에 둔다. 아래 ‘MVP·첫 버전’은 초기 설계 범위이며 현재 구현과 구분한다.

## 행성 속성 — 설계 제안

| 속성 | 플레이에 미치는 영향 |
| --- | --- |
| 크기·가용 지면 | 건축 공간, 이동·운반 거리 |
| 표면 환경 | 온도, 대기압, 기체 조성, 독성, 물 접근성 |
| 자원 분포 | 광물 종류·양·위치, 초반 생산 난이도 |
| 지형 | 평지·협곡·경사·위험 구역, 기지 후보지 |
| 발견 잠재력 | 유적·미생물·동물·문명의 생성 조건 |
| 개발 조건 | 착륙·보급 난도, 권한, 목표 환경, 투자 대비 가치 |
| 천체 기반 | 관측·추정·게임 생성의 출처, 중력·일사·자전 |
| 지하·유역 | 굴착·수직 운반·수위 변화·기지 안전 |
| 시드 | 생성 결과와 발견 위치의 재현 |

초보자용 후보에는 접근 가능한 철·구리·암석과 최소 전력 자원을 보장한다. 후보 화면에는 알려진 환경·자원, 조사 수준·불확실성, 필요한 장비·보급, 귀환 가능성을 보여 준다. 고난도 행성에는 외부 물자 의존이 있을 수 있다. 실제 자료와 게임 생성의 구분은 [천체·월드 설계](../technical/03-universe-data-and-world-streaming.md)를 따른다.

### 월드 표현

- 현재 1.2는 유한한 3D 구역·고갈 자원 노드·고정 중력 방향이다.
- 목표는 연결된 광활한 지역과 지표·지하 탐험이다. 지역 스트리밍·동굴망·국소 굴착부터 실증한다.
- 실제 구체 표면 이동과 굴착 범위는 별도 기술 결정이다. 축척·접근 영역을 표시하고 행성 전체를 실제 크기로 구현했다고 오해시키지 않는다.

## 자원과 변환 — 설계 제안

| 자원 ID | 용도 | 주 획득처 | 첫 버전 |
| --- | --- | --- | --- |
| `iron_ore` | 철 부품·로봇·구조물 | 철 광맥 | 포함 |
| `copper_ore` | 전력·전자 부품 | 구리 광맥 | 포함 |
| `stone` | 기초 시설·토대 | 암석 | 포함 |
| `ice` | 물 확보·일부 테라포밍 | 얼음 지대 | 포함 |
| `rare_mineral` | 고급 장비·기술 재료 | 위험 구역·희귀 광맥 | 확장 |
| `bio_sample` | 생물 분석·증식 | 발견 이벤트 | 확장 |

원안의 ‘철 100, 구리 10’은 예시 재료다. MVP에서는 `iron_ore`·`copper_ore`를 직접 사용하는 단순 제작을 제안하고, 정제·합금·복잡한 중간재 공정은 확장 단계로 둔다.

### 수동 채집 흐름

1. 수동장비가 자원 노드에 접근한다.
2. 이름, 종류, 잔량, 채집 가능 여부를 확인한다.
3. 도구를 사용하면 작업 진행도, 충격 효과, 소리와 함께 자원이 나온다.
4. 장비의 화물 한도까지 자원을 적재한다.
5. 기지 보관함에 반납하거나 건축·제작에 사용한다.

작업 중 취소한 채집은 완료되지 않은 산출물을 주지 않는다. 가득 찬 화물칸은 명확히 알리고, 노드 잔량과 지급량은 같은 처리에서 갱신한다. 고갈된 노드는 시각적으로 구분하며 매 프레임 새로 생성하지 않는다.

## 건축과 설비 — 설계 제안

| 시설 | 역할 | 주요 연결 |
| --- | --- | --- |
| 착륙 기지 | 수동장비 배치·복구, 기본 관리 | 보관함, 사업 화면 |
| 보관함 | 자원 입출고와 건설 재료 공급 | 플레이어·로봇 |
| 발전기 | 시설·로봇용 전력 생산 | 전력 용량 |
| 충전 패드 | 로봇 배터리 보충 | 전력·귀환 경로 |
| 로봇 제작기 | 기술·재료로 로봇 생산 | 보관 자원·전력 |
| 대기 처리기 | 대기 조성 또는 독성 개선 | 전력·소모 자원 |
| 온도 조절기 | 행성 온도 조정 | 전력·소모 자원 |
| 물 공급 설비 | 얼음 등을 사용한 물 확보 | 자원·환경 상태 |

시설명과 재료량은 초안이다. MVP 전력은 기지 단위 공유 용량을 제안하며 전선·유체관 시뮬레이션은 확장 범위다. 자원은 실제 보관함 재고로 관리하고 로봇은 채광 후 운반한다.

### 배치·철거

- 건축 모드에서 반투명 미리보기, 회전, 스냅을 제공한다.
- 지면·경사·중첩·장애물·재료 조건을 검사하고 실패 이유를 보여 준다.
- 배치를 확정할 때 재료를 한 번 차감하고 건물을 만든다. 미리보기와 취소는 재료를 소비하지 않는다.
- 시설의 입력·출력·전력·가동 상태를 선택 화면에서 확인한다.
- MVP 철거는 건설 재료 전액 환불을 제안한다. 처리 중인 작업·적재물은 먼저 취소·반환하고, 최초 건설에 쓰인 재료와 운영 중 소비된 재료를 구분한다.
- 착륙 기지는 철거 불가다. 길을 막는 건축과 로봇의 경로 실패는 [자동화 문서](03-robots-and-automation.md)의 복구 규칙을 따른다.

## 조작과 화면 — 설계 제안

현재 1.2는 1인칭 원격 조종·관찰 카메라·키보드/마우스를 사용한다. 확장의 우주선·현장 조작 주체와 최종 시점은 미정이며 카메라·입력을 분리한다. 이동, 상호작용, 스캔, 굴착, 인벤토리, 건축, 로봇 관리, 사업 화면의 행동을 일관되게 정의하고 키 재지정을 제공한다.

| 화면 | 반드시 전달할 정보 |
| --- | --- |
| 현장 HUD | 조작 주체·장비·화물, 도구, 위험·귀환 여유, 현재 목표 |
| 건축 메뉴 | 비용, 재고, 기능, 설치 불가 사유 |
| 로봇 관리 | 등급·특성, 작업·위치, 전력, 정체 이유 |
| 환경 대시보드 | 현재값·목표 범위, 변화 방향, 가동 설비, 평가 |
| 사업 화면 | 현금, 기술, 행성 정보, 예상 매각가, 회수 화물 |
| 발견 기록 | 위치, 내용, 선택, 보상, 매각 영향 |
| 지역·지하 지도 | 고도·연결 통로, 탐사 흔적·중계기·안전 지점 |
| 기지 확장 계획 | 물류·전력·유역·서식지·협약의 배치 제한 |

초반 목표 안내는 ‘철 수집 → 보관 → 발전기 → 기술 구매 → 첫 로봇 → 작업 배정 → 첫 환경 개선’의 행동을 돕는다. 플레이어가 먼저 수행한 행동은 즉시 완료로 인정한다. 색상 외에 아이콘·문자로 상태를 구분하고 카메라 흔들림은 조절 가능하게 둔다.

## 구현 시 확인할 상황

화물 포화, 노드 동시 채굴, 재료 부족, 배치 취소, 경로를 막는 건설, 저장 후 고갈량 복원, 시설 철거 시 중복 환불, 기본 자원 소진 후 복구를 확인한다. 마지막 항목의 경제 규칙은 [경제·기술·계승](05-economy-and-progression.md)을 따른다.
