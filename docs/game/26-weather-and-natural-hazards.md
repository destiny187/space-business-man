# 행성 날씨와 자연재해 — T2부터의 현장 판단

2026-09-11 **첫 묶음 개발 승인**. 사용자는 아래 방향을 승인하고 “재난 빈도는 더욱 적게”, “플레이하는데 제약을 너무 주고 싶진 않아”라며 전체 개발을 요청했다. 첫 범위는 물비·산성비·뇌우, 차양·접지봉, 관측·예보·정화 연결이다. 눈보라·먼지돌풍·강우 침수·신규 지질 재해는 후속 제안으로 유지한다. 현재 코드·자산·실제 확인 범위는 [기상 제작 기록](../production/135-planet-weather.md)을 따른다. 수치는 사용자 확정 밸런스가 아닌 첫 구현의 조정값이다.

## 1. 목표 경험과 현재 출발점

**하늘을 보고 작업 위치를 고르고, 준비한 장비로 활동을 이어가며, 복원한 지역의 날씨가 순해지는 경험**을 만든다. 파밍·건축·자동화·테라포밍이 중심이며 날씨 대응은 그 사이에 들어가는 짧은 선택이다.

T2 광맥을 캐던 중 먼 구름과 천둥으로 뇌우를 알아챈다. 광맥 한 덩이를 더 캐고 이동하거나, 안전한 곳으로 작업을 옮기거나, 접지봉을 설치해 그 자리에서 계속 일한다. 지나간 비에 젖은 절벽에서는 원래 있던 광맥이 더 잘 드러난다. 다음 방문에는 복원 지역에서 해로운 비가 평범한 비로 바뀐다.

| 기존 기반 | 일반 날씨와의 경계 |
| --- | --- |
| [먼지·얼음 입자·안개](../production/41-surface-atmosphere.md), [습윤 지표 표현](../production/76-surface-presence-and-recovery.md) | 환경 연출이며 일반 강수 주기·노출 피해가 아님 |
| [시드 낮밤·천체 시계](../technical/08-seeded-planetary-cycles.md) | 기존 시간 기반은 있으나 일반 날씨는 별도 |
| [T2 지진 공동·T3 폭풍 기록고](21-exploration-incidents.md) | 장소에 묶인 재해 사건은 존재함. 기록고 방전·지붕 대피를 일반 날씨 구현으로 세지 않음 |
| [시설 전체 침수 정지](02-planets-resources-and-building.md), [실드](22-suit-modules-and-shields.md) | 기존 규칙을 보존하고 기상 연결만 별도로 설계 |

날씨는 넓은 현장에 잠시 영향을 주는 상태, 사건은 특정 장소의 단서·행동·보상을 가진 콘텐츠다. 폭풍이 올 때마다 난파선이나 보석 공동을 새로 생성하지 않는다.

## 2. 티어와 환경별 배정

| 단계 | 경험 제안 | 부담 제한 |
| --- | --- | --- |
| T1 | 환경에 맞는 평범한 비·눈·바람 | 새 날씨 피해 없음. 기존 낙하·사건은 유지 |
| T2 | 산성비 또는 국소 낙뢰처럼 대응 하나를 배우는 현장 | 한 위치에서 피해 날씨 한 종류. 모든 행성에 재해를 강제하지 않음 |
| T3 | 눈보라·먼지돌풍 등 환경별 후보와 지역 이동 판단 확대 | 행성에 여러 후보가 있어도 현재 위치의 주된 위험은 하나 |
| T4~T5 | 위험 구역·강약 변화·복원 거점 사이의 경로 선택 | 피해·빈도·지속시간을 티어마다 배수로 늘리지 않음. 세부 콘텐츠 후속 |

환경으로 가능한 날씨를 먼저 걸러내고 티어로 위험한 변형과 대응 난도를 정한다. 같은 티어라도 평온한 행성과 간헐적으로 위험한 행성이 공존한다.

- 대기·액체 조건과 수분 공급이 있는 지역에는 물비, 추운 지역에는 눈, 건조한 대기 지역에는 먼지돌풍 후보를 둔다.
- 산성비는 명시적인 반응성 대기/강수 성분이 있는 프로필에만 배정한다. 노란 지형·유황 광맥·높은 종합 오염도만으로 산성비를 확정하지 않는다.
- 무대기 행성에는 비·뇌우·대기 바람을 생성하지 않는다. 가스/얼음 거대행성은 현재 착륙 불가이므로 지상 재해 대상이 아니다. 대기가 매우 희박하거나 성분이 미정이면 위험 강수를 제외하는 쪽으로 시작한다.
- 기존 온도·대기·수분·지역 환경값을 참조하되 강수 가능 여부와 성분은 별도 생성 설정으로 둔다. 현재 환경 점수를 실제 기압·산도 단위로 해석하지 않는다. 이는 게임용 조건 모델이며 실제 외계행성 기상 관측이나 정밀 대기역학 재현이 아니다.

## 3. 종류별 행동

| 현상 / 후보 ID | 현장 변화와 영향 | 기본 대처 | 재미·이득 |
| --- | --- | --- | --- |
| 맑은 비 `water_rain` | 구름·빗줄기·물방울·젖은 암반. 체력 피해 없음 | 평소처럼 작업 | 젖은 면과 광물의 대비로 기존 광맥이 잘 보임. 첫 강우 E 관측을 J 기록으로 남김 |
| 산성비 `acid_rain` / T2 | 구분되는 물방울 형태·접촉 기포·탐험복 경고. 연속 노출 후 서서히 체력 피해 | 실제 지붕·선내·간이 차양으로 이동 | 차양 위치를 골라 작업 범위 확보. 복원 후 같은 비가 순해지는 보상 |
| 뇌우 `thunderstorm` / T2 | 먼 천둥 → 지면 방전 전조 → 예고한 작은 범위에 낙뢰 | 범위 밖 이동, 접지봉 보호 구역에서 작업, 보호된 선내로 귀환 | 조금 더 캘지 이동할지 판단. 준비한 작업장은 폭풍 중에도 이용 |
| 눈보라 `snow_squall` / 후속 T3 | 눈 띠·바람 방향, 먼 시야 감소·노출 후 스태미나 회복 둔화 | 지형 뒤로 우회, 지붕과 바람막이가 있는 거점 | 지형·귀환 표식 활용. 이동·도구 사용은 계속 가능 |
| 먼지돌풍 `dust_gust` / 후속 T3 | 이동하는 먼지 띠·먼 시야 감소. 기본형은 체력 피해 없음 | 띠를 가로질러 빠져나가거나 암벽 뒤 경로 선택 | 먼지가 걷힐 때 기존 매장물 단서가 잘 보임. 실제 매장물 개방은 별도 사건 |

평범한 비가 내리는 뇌우는 가능하다. T2 산성비와 피해 낙뢰는 겹치지 않는다. 눈보라 둔화와 낙뢰도 첫 범위에서는 중첩하지 않는다. 플레이어를 계속 따라오는 추적 폭풍을 만들지 않는다.

열파·결빙비·분화·낙석·일시 범람은 후속 후보다. 지진과 분출은 우선 기존 사건형 현장을 확장한다. 일상 날씨가 시설 밑을 무작위로 무너뜨리거나 전 지역 지형을 바꾸는 범위는 첫 묶음에 넣지 않는다.

## 4. 리듬과 피해 — 낮은 빈도의 첫 구현

**평온 → 예고 → 발생 → 약화 → 평온**으로 이어진다. 아래 시간은 실제 플레이 시간이며 천체 시간 압축 배율을 다시 곱하지 않는다.

| 항목 | T2 첫 조정안 |
| --- | --- |
| 위험 날씨 예고 | 35초. 짧은 알림·소리와 현장 지도로 대응을 안내 |
| 위험 구간 | 45~60초. 마지막 5초는 약화하며 강수 강도와 피해 조건을 일치시킴 |
| 다음 위험까지 평온 | 최소 25분, 추첨 간격 25~40분. 해당 행성에 위험 프로필이 있을 때도 25%만 발생 |
| 첫 T2 착륙 | 최초 방문 행성의 첫 위험 추첨은 25~40분 뒤. 재진입자는 지형 준비 후 15초 유예하며 예보는 재추첨하지 않음 |
| 개별 낙뢰 | 위치를 고정해 3초 예고. 전조 시작 뒤 플레이어를 따라 표적을 이동하지 않음 |
| 산성비 노출 | 12초 연속 노출 여유 뒤 최대 초당 체력 0.5 피해. 정화 상태에 따라 감소 |
| 낙뢰 피해 | 1회 12. 반경 3m, 최대 체력에 비례해 증폭하지 않음. 낙뢰 간격 12~17초 |

산성비는 실드를 통과하고 낙뢰는 실드부터 소모한 뒤 초과분을 체력에 적용한다. 실드가 없어도 전조만으로 회피할 수 있어야 한다. 산성비는 보호 구역에 들어간 순간 추가 피해와 노출을 해소하고, 다시 나가면 여유 시간이 다시 시작한다. 짧게 나가 채집하고 들어오는 행동은 허용한다. 피신 후에도 독 피해가 이어지거나 장비 내구도가 닳는 방식은 쓰지 않는다.

기상 피해 종류를 구분하고 기존 사건의 폭발 저항을 전기·부식 저항으로 임의 재사용하지 않는다. 실제 피해는 해당 체력/실드의 기존 회복 대기를 갱신한다. 공격·처치가 필요한 효과는 날씨로 발동시키지 않으며 낙하·낙하 감소는 기존 규칙을 유지한다.

위험을 계속 무시하면 기존 긴급 구조로 이어질 수 있다. 건강한 T2 플레이어가 첫 한 번에 쓰러지거나 조작 불능·연속 밀쳐내기로 절벽에서 떨어지지 않게 한다. 무피해 날씨가 체류 시간의 대부분을 차지하게 하고, 재해를 피한 뒤에는 충분한 작업 시간을 준다.

## 5. 대처의 성장과 기지 운영

| 수단 | 역할 | 첫 구현 접근 조건 |
| --- | --- | --- |
| 자연 지붕·기존 선박 | 비를 피하며 근처 작업·제작·화물 관리로 전환 | 소모품 없음. 실제 보호되는 공간이 보여야 함 |
| 간이 작업 차양 `field_canopy` | 덮인 범위의 비를 막고 작업 장소 확보 | T2 기초 설계 개방. 철 8·돌 4, 기존 철거·재건설 이용 |
| 접지봉 `grounding_mast` | 작은 작업 구역의 기상 낙뢰를 봉으로 유도 | T2 기초 설계 개방. 철 5·구리 5·돌 3, 반경 18m, 별도 연료·교체 소모품 없음 |
| 내후 작업 거점 | 차양·접지봉·기존 창고/제작소를 동선에 맞춰 조합 | 별도의 필수 기지 등급 없이 위 장치를 활용 |

비 차폐는 실제 덮인 공간을 사용한다. 건설 고스트·옆면 벽·시설 근처라는 이유만으로 보호하지 않는다. 보통 차양은 비를, 접지봉은 낙뢰를 막는다. 동굴 입구는 실제 천장 차폐를 확인하고 천장 없는 구덩이를 지하라는 이유로 안전 처리하지 않는다. 로버의 개방형 좌석에 자동 면역을 주지 않으며 선박도 밀폐된 선내/탑승 상태와 선체 바깥을 구분한다. 이 보호 판정은 게임 규칙이다.

접지봉 고스트에는 보호 범위를 표시하고 봉으로 흐르는 낙뢰 효과로 가동을 알린다. 첫 접지봉은 전력망 없이 동작한다. 낙뢰 에너지 수집·별도 축전망은 후속이다. 필수 대응을 무작위 설계도·희귀 내성 장비로 잠그지 않으며 시설 없이도 이동·자연 차폐·선내 귀환으로 진행할 수 있게 한다. 충분한 예고와 피할 경로를 제공할 수 없는 현장에는 위험을 예약하지 않는다.

**첫 묶음에서 시설·로봇은 기본 내후 구조로 둔다.** 날씨마다 공장 전체를 멈추거나 수리 재료를 청구하지 않는다. 재고·가공품·로봇·설계도는 날씨로 소실되지 않는다. 차양과 접지봉의 주된 이득은 플레이어가 야외에서 계속 작업하는 것이다. 후속 자동 대피/출력 변동은 실제 복귀·작업 예약 보존까지 별도로 설계한다.

## 6. 테라포밍과 발견의 보상

- 강수 성분과 연결된 대기 정화가 진행되면 산성비의 피해가 낮아지고, 충분히 안정된 지역에서는 같은 강우가 맑은 비가 된다. 하늘·물방울·접촉 효과·예보에 함께 반영한다.
- 효과 범위는 [현재 지역 복원과 구면 대기](04-terraforming-and-sales.md)에 맞춘다. 물 정화기 하나가 행성 전체 비를 바꾸지 않는다. 경계의 변화는 부드럽게 연결하고 이미 예고한 낙뢰 위치·위력은 갑자기 바꾸지 않는다.
- **일시 날씨와 장기 환경 원장을 분리한다.** 비 한 번에 복원 면적·안정화 시간·단계 정산을 초기화하지 않으며, 날씨가 무료로 계약을 완료시키지도 않는다. 환경 개선이 날씨를 순하게 만드는 연결부터 시작한다.
- 초기 강우는 젖음·물방울까지만 반영한다. 장식 웅덩이를 실제 수위로 계산하거나 산성비 종료로 기존 수질 오염을 지우지 않는다. 후속 강우 유입은 기존 수량·배수·시설 전체 침수 정지와 연결한다.
- 젖은 광맥·먼지가 걷힌 단서는 **기존 위치·잔량**을 드러낸다. 고갈 광맥을 다시 채우지 않는다. 첫 관측은 행성·날씨 프로필별 한 번 기록하며 날씨 전용 필수 재료나 반복 보상 파밍을 만들지 않는다.
- 비 뒤 생물 행동은 실제 서식종이 있는 행성에만 후속 제작한다. 무생물 행성에 새 종을 생성하거나 단일 자연 원산지 규칙을 바꾸지 않는다.

## 7. 예보·시청각 표현

현재 궤도 목적지 카드에는 대기 프로필·위험 가능성을, 현장 지도에는 고정된 날씨 범위·차양·접지 범위를 표시한다. 전선 이동과 궤도 위험 강도 아이콘은 후속이다. 현장 HUD는 레이더 인근의 작은 날씨 아이콘과 시작/강화 때의 짧은 알림을 사용한다. 정확한 잔여 시간·성분·대응은 지도/선택 상세에서 확인한다.

[FIELD v1](../production/22-uiux-guide.md)의 최신 정정대로 체력·실드·스태미나 게이지 아래에 상시 상태 문장을 추가하지 않는다. 산성비 노출은 날씨 아이콘의 차오름·탐험복 접촉 반응, 낙뢰는 바닥 범위·방전 전조로 전달한다. 색만으로 위험을 구분하지 않는다. 메뉴 중 기존 이동·발사·채집 입력과 소리는 차단하지만 필요한 기상 경고는 보이고 들려야 한다. 협동 개인 메뉴를 피해 면역으로 사용하지 않는다.

비는 선내·완전한 지붕 안에 그리지 않는다. 섬광을 낮추어도 바닥 전조·소리로 회피할 수 있게 하며 화면 전체 백색 점멸·강제 시점 회전·지속 흔들림은 피한다. 낮음 품질에서도 같은 전조와 판정 범위가 읽혀야 한다.

차양·접지봉은 Blender 원본/내보내기를 보존하고 [INK v1](../production/06-rendering-quality-standard.md) 게임 렌더로 확인한다. ElevenLabs로 비/지붕 타격 루프·먼 천둥/가까운 낙뢰·산성 접촉·보호 가동음을 준비하고 실제 게임에서 전조/결과의 타이밍·음량을 확인한다. 두 설비의 Blender 원본·GLB·게임 카드와 새 ElevenLabs 음원 3개를 제작했다. 지붕 아래는 강우 루프 음량을 줄이며 독립 지붕 타격 음원은 추가 제작하지 않았다.

## 8. 협동·저장·사건 경계

같은 장소의 승무원은 같은 예보·낙뢰 위치·피해 결과를 공유한다. FINCH로 다른 행성에 간 승무원은 그곳의 날씨를 본다. 발생 빈도·피해를 인원수만큼 늘리지 않고 혼자도 설치·작업을 순서대로 수행할 수 있게 한다.

호스트가 독립 기상 시드·버전·행성/기상 구역 ID·회차·단계·시각·예고한 낙뢰·개인 노출·관측 여부를 관리한다. 개인 노출·재진입 유예는 호스트 세션에서 계산하며 재접속 시 유예를 새로 주고 노출을 해제한다. 기존 지형·광물·생물·사건 난수열은 재사용하지 않는다. 기상 구역은 현재 탐사 좌표에 배정하며 구형 행성 기후 전체 시뮬레이션을 전제하지 않는다. 구역 경계를 왕복해도 회차·관측 보상을 새로 뽑지 않는다. 수치·종류는 `planet_weather.json`에 둔다.

시간은 기존 호스트 활성 시뮬레이션 시계를 따른다. 저장/재접속으로 날씨를 재추첨하지 않고 호스트 종료 중에는 멈춘다. 무인 지역에는 기상 피해·수리비·재고 손실을 쌓지 않으며 기존 부재중 생산을 유지한다. 재진입자는 지형·경고 준비 후 짧은 유예를 받되 세계 단계는 되감지 않는다. 피해 계산은 모든 승무원의 실제 활성 지역만 평가한다.

`storm_archive_wreck`의 기존 회로/배터리·방전·지붕·설계도 보상은 유지한다. 사건의 주된 위험이 활성화된 구역에서는 일반 날씨의 추가 피해를 억제해 이중 경보·겹침 피해를 방지한다. 일반 접지봉으로 사건 회로 수리를 건너뛰거나 보상을 반복 획득할 수 없다. 사건 전조와 보호 범위가 일반 기상보다 분명히 읽혀야 한다.

새 세계에는 독립 `weather.version=1`을 넣고 기존 세계는 기상을 소급 활성화하지 않는다. 기존 방문 행성·시설·지형·생명권·저장을 재배치하지 않는다. 새 설비는 T2에서 건설할 수 있다.

## 9. 첫 제작 범위와 판단 기준

승인된 첫 제작 순서는 **환경 프로필·예보 → 맑은 비/산성비와 실제 차폐 → 뇌우와 접지봉 → 지역 복원으로 위험 감소**다. 비 2종·뇌우, 차양·접지봉, 관측 기록을 첫 묶음으로 두고 눈보라·먼지돌풍·강우 침수·신규 지질 재해·기상 전용 보상 아이템은 후속으로 남긴다.

구현 시 대표 T2 한 곳에서 채집 중 예보 → 이동/차양/접지 대응 → 작업 재개 → 복원 뒤 같은 강우 비교를 최소 실행으로 확인한다. 실제 차폐·낙뢰 전조/소리·저장/재접속 시 경고 없는 피격 방지가 핵심 확인 대상이다. 추가 검사는 발견한 버그에 맞추며 전체 회귀·모든 시드·장시간·6인 반복 검사를 관행적으로 붙이지 않는다.

재미의 판단은 **위험과 대처가 읽히는가, 날씨 중에도 할 일이 남는가, 대비·복원으로 활동 범위가 넓어지는가**다. 매번 선내에서 끝나기만 기다리거나 같은 시설을 수리한다면 빈도·지속시간·피해부터 낮춘다. 제작·검증 결과와 단순화한 범위는 [제작 기록](../production/135-planet-weather.md)에 모은다.
