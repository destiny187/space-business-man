# 외계문명·협상·갈등

## 2026-09-09 — 거주 마을 제거·고지능체 고도화 보류

사용자는 이미 주민이 살고 있는 기존 마을을 제거하고 고지능체를 추후 고도화하기로 했다. 이 변경이 아래의 기존 문명 실증 우선순위에 앞선다. 아래 사회·접촉·협약·갈등은 **미래 설계 이력**으로 보존하며 이번 탐험 확장에 마을·주민·단순 문명 선택을 넣는 근거로 사용하지 않는다. 세계관에서 모든 지능체를 영구 삭제하는 요구가 아니다.

이번에는 자연·생태·지하·무인 유산의 발견을 확장한다. [새 발견 기획](20-exploration-discovery-expansion.md)에 제거 범위·기존 기록 보존·높은 티어의 발견 증가안을 둔다. 기존 캠페인 마을의 생성 제외·이력 이행을 적용했으며 고지능체 재등장 시점·사회 규모·행동 모델은 별도로 설계한다.

2026-09-06 확장 설계. **탐사 중 원주민 발견, 다양한 문명 단계, 파괴·협상·거래 등 여러 선택**은 확정 요구사항이다. 문명 단계의 구분, 협약·평판·세력 운영과 전투 규모는 설계 제안이며 현재 1.2의 일회성 문명 이벤트보다 넓은 목표다.

## 문명을 발견한다는 것

문명은 보상 상자가 아니라 환경을 이용하고 바꾸며 이해관계를 가진 주체다. 궤도에서 아무 신호도 보이지 않았다는 사실은 무인 행성의 증명이 아니다. 지하 거주지·생물 기반 기술·비전파 통신도 가능하며 현장 탐사로 기존 판단을 수정할 수 있다. 큰 지형 변경 전에 주변의 거주·활동 단서를 확인할 기회를 준다.

### 문명 단계와 차이

아래 단계는 **산업·통신·우주 활동 범위**를 설명한다. 지능·도덕성·협상 가치의 서열로 사용하지 않는다. 기술 단계와 생물학·사회 구조·환경 지식·외부 세력 관계는 독립 축이다.

| 유형 예시 | 보이는 흔적 | 주요 관심과 상호작용 |
| --- | --- | --- |
| 이동·소규모 공동체 | 계절 거처·이동로·돌 표식 | 먹이·물·성지, 관찰·물물교환·통로 합의 |
| 정착·농경 문명 | 수로·농경지·계절 관측소 | 토양·강·작황, 물 관리·재해 대응·공동 복원 |
| 산업 문명 | 공장·수송망·오염·집중 열원 | 에너지·생산·환경 피해, 기술 거래·정화 계약 |
| 행성 통합·정보 문명 | 통신망·행성 센서·복수 행정권 | 데이터·권한·기후 목표, 개발 구역·감사 협약 |
| 우주 진출 문명 | 궤도 정거장·항로·함선 | 교역권·안전·외교, 통행·공동 탐사·경쟁 |
| 쇠퇴·분산된 유산 문명 | 가동 중인 무인 설비·단절된 거점 | 지식 보존·생존 기반, 구조·복구·승계 문제 |

낮은 산업 단계에서도 현지 생태 지식은 플레이어보다 뛰어날 수 있다. 한 행성을 단일 의견으로 취급하지 않고 장기적으로 공동체·세력별 입장을 둔다. 첫 구현은 한 행성의 주요 협상 상대 하나부터 검증한다.

## 접촉에서 협약까지

```text
활동 단서 → 원거리 관찰 → 통신·의도 해석 → 첫 접촉
→ 허용된 조사·교역 → 쟁점 제안·협상 → 협약 실행
→ 결과 확인·관계 갱신 → 후속 협력·갈등·이탈
```

번역은 모든 대사를 곧바로 완벽하게 이해하는 버튼보다 관찰·교류로 정확도를 높이는 과정으로 제안한다. 초기에는 확실한 정보와 추정 의미를 구분한다. 중대한 계약 조건과 플레이어가 확정하는 행동의 실제 범위는 번역 미완성을 이유로 숨기지 않는다. 언어 퍼즐을 원하지 않는 플레이어에게 보조 번역·요약을 제공한다.

| 행동 | 얻는 기회 | 비용·상대 반응의 예 |
| --- | --- | --- |
| 관찰·비접촉 | 생태·문화 정보, 후속 접근 준비 | 시간이 들고 기술·자원 직접 거래는 제한 |
| 협상·공동 테라포밍 | 개발 구역·연구 협력·안정적 관계 | 환경 한도·보호 구역·성과 배분 이행 |
| 거래 | 현지 물자·설계도·표본·서비스 | 실제 재고·수요·반출 권한·가격 |
| 보호·복원 | 고유 생태·문화 보전, 보상·장기 계약 | 개발 면적·완전 매각 권리 감소 |
| 철수·다른 행성 선택 | 자산·관계 보존, 새 후보 탐사 | 투입비 일부 미회수, 조사 데이터는 유지 |
| 무력 충돌·파괴 | 적대 시설 무력화·강제 점유 시도 | 전투·수리·생태 손실·잔존 세력·교역 단절 |

플레이어가 언제나 우월한 군사력을 가진다고 가정하지 않는다. 우주 진출 문명은 플레이어의 항로와 보급을 제약할 수 있고, 갈등은 승리·패배·휴전·철수로 끝날 수 있다. 전투는 개척·물류·테라포밍의 결과와 연결하고 상세 전술 게임으로 별도 확장하는 범위는 보류한다.

### 기존 문명 선택과의 관계

원안 R-15와 현재 1.2에는 보호·파괴·노예화의 일회성 선택, 보호의 랜덤 기술/보물, 큰 매각 단가 감소가 존재한다. 이 구현 이력을 삭제하지 않는다. 확장에서도 기존 강압적 선택은 요구 이력으로 보존하되, 구체적인 통제·저항·전환·묘사 규칙은 D-10에서 재검토한다. 새로운 모든 문명을 그 세 버튼으로만 처리하지 않는다.

보호로 완전한 개발·처분 권리가 줄어드는 경우 **기존의 큰 매각 단가 감소**를 유지하는 연결안을 제안한다. 동시에 공동 복원 대금·장기 거래·독점 기술을 얻는 수익 경로를 추가한다. 이 대안 수입까지 무조건 감소시키거나 보호가 항상 최대 이익이 되도록 보장하지 않는다. 파괴 역시 권리·수익을 즉시 정상화하지 않으며 피해·분쟁을 남긴다.

## 협약의 내용

| 항목 | 예시 |
| --- | --- |
| 당사자·대상 | 공동체·기업·행정 세력, 지표/지하/수계 범위 |
| 환경 목표 | 허용 온도·압력·기체·수위 범위, 보존할 기존 서식지 |
| 권한 | 조사·건축·채굴·표본 채취·반출·방문·재판매의 허용 여부 |
| 성과·대가 | 정화 완료·물 공급·설비 유지, 단계별 지급·물자·기술·수익 배분 |
| 관측·기간 | 관측소 위치·안정화 기간·검수 방법·갱신 조건 |
| 위반·변경 | 경고·시정 기간·보상·중단·재협상·철수 |

행성 대기는 국경에서 멈추지 않는다. 한 구역의 산소 증가가 이웃에게 해가 되면 지역 권한만으로 전 행성 대기 변경을 완료할 수 없다. 분리된 돔·유역 관리·영향권 공동 협상 등 대안을 제공한다. 사람에게 살기 좋은 환경과 그 문명의 좋은 환경이 다를 때 **무엇을 위한 테라포밍인지**를 선택하게 한다.

처음에는 영향받는 집단과 예상 변화 방향만 보여 주고, 상세 물리·정치 모형은 늘리지 않는다. 협상 실패는 새로운 조사 과제·다른 구역·다른 행성의 가능성으로 이어진다.

## 관계와 사건의 기억

평판 하나로 모든 종족의 호감도를 대체하지 않는다. 세력별 신뢰, 이행한 약속, 피해·보상, 기술·교역 의존, 알려진 사건을 저장한다. 상대가 알 수 없는 먼 사건이 즉시 전 은하에 퍼지지 않게 정보 전파 경로·시점을 둔다.

보호 보상을 받고 파괴로 전환해 이익만 합치는 행동은 막아야 한다. 협약 파기 자체를 영구 금지하는 대신, 지급된 보상·미이행 의무·배상·관계 결과를 같은 이력에 묶는 방식을 제안한다. 휴전·재협상도 새 계약 버전으로 남기고 기존 보상을 다시 지급하지 않는다. 장기적으로 선택 전환을 허용하되 첫 실증에서는 몇 가지 명시적 전환만 다룬다.

거래 물자는 실제로 인도하고, 표본·유물·로봇은 인계 전후에 한 소유 위치만 가진다. 낮은 산업 단계의 사회가 필요도 없는 첨단 부품을 무제한 구매하는 식의 판매 허점을 만들지 않는다.

## 확인할 경험

동일한 기술 단계라도 환경·가치관 때문에 다른 협상을 하는가, 거래와 보호로도 한 사업을 완결하는가, 파괴 선택의 비용과 결과를 미리 이해하는가, 협약 이후 실제 환경 변화가 관계·지급에 반영되는가를 확인한다. 문명별 제작·번역·전투 수량은 [단계 계획](../planning/06-exploration-expansion-roadmap.md)에서 제한한다.
