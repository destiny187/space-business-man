## 2026-09-10 — 선박 성능으로 T3~T5 진입

**사용자 확정:** T1·T2는 기초선으로 자유롭게 진행하고, T3~T5는 필요한 성능을 갖춘 우주선을 구매하거나 보유·운용해야 진입한다. 우주선은 이후 전투·무역·탐사·운송에 함께 쓰이므로 역할과 항해 가능 티어를 분리한다. 아래 이전 자유 진입 제안보다 이 결정을 우선한다.

이번 구현은 **현재 운용 선체의 입자 차폐·열 제어·항법 안정**을 확인한다. 창고에 보관 중인 다른 선체를 소유했다는 이유로 기본선의 성능이 올라가지 않는다. 선체 기본 성능과 선체별 영구 개장, 장착 모듈의 성능을 합산하며, 항속거리·역할·모듈 희귀도는 별개다. 같은 역할의 선박도 단계적으로 개장할 수 있다. 공동선의 항해 성능은 승무원 모두에게 적용하고 인원별 비용을 받지 않는다.

- T1·T2 행성 접근/착륙에는 새로운 장비 조건이 없다. 은하의 중간·내곽·중심 항성권에는 각각 T3·T4·T5 항해 환경을 적용한다. 고위험 항성권 안의 낮은 티어 행성은 그 항성권까지 이동할 수 있는 배가 필요하다. 행성 티어와 항성권 환경을 같은 값으로 재생성하지 않는다.
- 성간 출발은 목적 항성권을, 항성계 내 자동 접근과 실제 착륙은 목적 행성의 티어를 검사한다. 짧은 도약 반복·직접 조종 후 착륙·FINCH 출동으로 조건을 우회하지 않는다. 천체의 원격 관측과 궤도 통과 자체를 삭제하거나 즉사 장벽으로 막지는 않는다.
- T3 성능을 갖춘 SWIFT/MULE 구매 또는 기본 KESTREL의 영구 개장을 선택한다. T4·T5는 현재 보유 선체를 순서대로 개장한다. 정비창(K)은 공동 자금과 현장 가공 부품을, 일반 정거장은 부품 포함 개장 가격을 사용한다. 무작위 모듈 추첨이 필수인 경로는 없다.
- T3 현장 개장은 T2에서 생산할 수 있는 부품만 요구한다. 현재 T4·T5 개장은 구현된 T3 생산품과 사업 수익을 사용하며, 정거장 서비스는 부품까지 공급한다. T4 산업이 추가되면 T5 부품 구성을 다시 조정하되, 진입하려는 티어 안의 자원을 선행 요구하지 않는다.
- 개장은 기존 차폐·냉각·항법 부품의 교체로 취급하여 현행 선체의 질량/전력 설계 범위와 두 임무 모듈 슬롯을 유지한다. 선체 교체 시 개장도 해당 선체의 기록을 읽는다. 새 하드포인트·함포·실제 무역 계약/시세는 후속 콘텐츠다.
- 기존 은하·자산·진행 중 항해는 유지한다. 부족한 선박으로 이미 안쪽에 있는 저장은 외곽 방향의 항로를 이용해 나올 수 있다. 기존 지상 활동과 FINCH의 모선 귀환도 보존한다. 과거 방문 기록이 새 고티어 진입 권한을 대신하지 않는다.

조건·초기 가격·실제 확인과 미구현 경계는 [항해 내성 구현 기록](../production/116-vessel-tier-access.md)을 따른다. 실제 T3 도달 시간을 다시 확정한 것은 아니며, 기존 24분대 측정은 변경 전 기준이다.

## 탐사의 목적 — 설계 제안

행성은 난이도 순서대로 구입하는 상품에서, 내 우주선·기술·표본으로 해결할 수 있는 환경을 찾아가는 장소로 바뀐다. 탐사로 얻는 것은 새 목적지, 물질, 연구 단서, 관계와 사업 기회다. 우주선은 이동 수단이자 이동 연구실·로봇 격납고·생물 보관소다.

첫 출발에는 기본선과 장비를 제공한다. 가까운 탐사권에 초보 장비로 개척 가능한 후보를 여러 개 제공하되 추천 행성을 강제하지 않는다. 실재 천체를 초보자용으로 임의 개조하지 않고, 필요하면 별도 표시한 가상 위성을 입문 후보로 넣는다.

## 항해와 정보의 단계

| 범위 | 플레이 | 선택의 근거 |
| --- | --- | --- |
| 성도 | 방문할 항성계와 경유지 선택 | 알려진 거리·보급·정세·관측 신뢰도 |
| 항성계 | 행성·위성·소행성대·정거장 조사 | 항로 연료, 탐사 신호, 위험과 화물 여유 |
| 행성 궤도 | 스캔·탐사기 투하·착륙 지점 선택 | 환경 범위, 자원, 생명·인공 신호, 귀환 가능성 |
| 지표·지하 | 관측을 현장 확인, 기지·연구 거점 선정 | 실제 지형, 서식지, 물류 거리, 지역 권리 |

정보는 `미탐사 → 원격 관측 → 궤도 조사 → 현장 검증`으로 축적한다. 과학 자료의 관측 오차와 플레이어의 미탐사 상태는 별개다. 스캔은 행성을 다시 생성하지 않고 고정된 세계의 정보를 공개한다. 이미 관측한 조건은 자료 갱신·실제 환경 변화 없이 뒤집히지 않는다.

후보 비교 화면은 종합 점수 하나 대신 **목표 환경까지 부족한 조건, 사용 가능한 내 기술, 예상 물자·에너지·항해 비용, 불확실성, 보존해야 할 영역**을 나란히 보여 준다. 예상 수익도 낙관·기준·불리한 경우의 범위로 제시한다. 위험을 완전히 스캔하는 데 드는 시간과 빨리 개척을 시작하는 이익이 선택이 된다.

### 이동의 현실성과 생략

- 성간 이동은 무료 성간 초고속 항해로 연결한다. 순간이동·퀀텀점프 대신 충전→가속→순항→감속→진입을 표현한다. 항성계 내부는 직접 비행하며, 외곽 경계 밖은 항법도로 설정한 성간 항로를 이용한다. 초기 점프권·매각 시 점프권 지급안은 채택하지 않는다.
- 물리 거리와 성도의 배치, 항해 시간을 별도 관리한다. 실재 항성계의 좌표를 게임 난이도 때문에 바꾸지 않는다. 항로 연결은 가상 항법망으로 표시한다.
- 기본 성간 항해는 연료·화폐를 차감하지 않는다. 항성계 내 직접 조종과 목적지 자동 접근을 제공한다. 성간 항해 중 자유 이탈은 후속이다. 새 해적 규칙의 원정은 목적 항성계 감속 때 습격으로 자동 접근을 중단할 수 있다.
- 비행 난도는 항해 보조와 수동 조작으로 조절한다. 완전한 궤도역학·중력 도움 항법·무중단 궤도 착륙은 후속 검토 대상이다.
- 초반 보급·구조 항로를 보장한다. 현재 장비로 귀환이 불가능한 착륙에는 연료·중력·추력의 부족 사유와 탐사기 대안을 알린다.

## 발견과 개척 권한

발견만으로 원주민이나 다른 세력의 행성이 플레이어 소유가 되지 않는다. 다음은 이 세계의 **가상 계약 규칙**이며 현실 우주법을 설명하는 규칙이 아니다.

| 상태 | 가능한 행동 | 다음 단계 |
| --- | --- | --- |
| 미확인 | 원격 탐사, 접근 | 활동·거주·권리 신호 확인 |
| 미점유로 조사된 구역 | 시험 기지·조사 비콘 설치 | 개발 범위 등록, 사업 시작 |
| 권리·거주 여부 불명 | 비파괴 조사, 연락 시도 | 추가 조사·잠정 합의 또는 다른 후보 탐사 |
| 원주민·세력 거주지 | 관찰, 협상, 거래, 갈등 선택 | [문명 규칙](10-alien-civilizations-and-diplomacy.md)에 따른 권한 |
| 정산한 구역 | 협약에 허용된 방문·교역 | 계약 범위 밖 채굴·건축은 불가 |

개발 등록 비용이 있더라도 행성 가격을 이름만 바꾼 진입 장벽으로 쓰지 않는다. 첫 조사·후보 선정은 무료이며 주요 비용은 실제 항해·기지·연구 투자다. 행성 매각과 개발 성과의 수익화는 [경제 문서](05-economy-and-progression.md)가 담당한다.

## 협동 탐험대의 공동 승선

호스트 포함 최대 6명이 각자의 캐릭터·장비를 유지하면서 같은 주력 우주선에 탄다. 이 인원수와 공동 승선은 확정 방향이며, 기본 승선 공간·출항 준비·조종 인계·합류/이탈·세계 자산 경계는 [호스트 협동](12-host-coop-and-crew.md)의 제안을 따른다. 게스트가 합류했다고 별도 함선을 자동 배치하지 않는다. 승무원 수용과 로봇·생물·일반 화물 용량은 별개다.

## 우주선 성장

| 구성 | 바뀌는 경험 | 함께 생기는 제약 |
| --- | --- | --- |
| 선체 | 기본 적재·모듈 배치·착륙 성능 | 질량, 정비 비용, 대형선 착륙 제약 |
| 추진·항법 | 항로 선택, 도약 거리, 회피 | 연료·전력·폐열 |
| 센서 | 더 먼 단서, 환경 오차 축소 | 능동 스캔 시 노출, 분석 전력 |
| 연구실 | 표본 분석·실험·현장 기술 개발 | 연구 장치·실험실 공간 |
| 격납고 | 로봇·탐사기·지상 차량 운송 | 문 크기·부피·질량, 회수 작업 |
| 화물·생물실 | 광물·유물·살아 있는 표본 보관 | 환경 유지·격리·먹이·예비 전력 |
| 방어·유틸리티 | 교란, 보호막, 구조, 잔해 인양 | 탐사 모듈과의 슬롯 경쟁 |

기본 슬롯은 모든 필수 기능을 수행할 수 있게 구성한다. 대형선이 모든 성능에서 우월한 일직선 등급 대신 **탐사선·산업선·생태 연구선·장거리 수송선** 등 역할과 개체 품질을 분리한다. 선체 개체 ID·이름·개조 이력을 보존하여 오래 타던 배에 애착을 만든다.

### 뽑기·개발·획득 경로

| 경로 | 얻는 것 | 진행 보장 |
| --- | --- | --- |
| 표준 구매·제작 | 성능이 알려진 선체·모듈 | 필수 항속·연구·수송 기능은 이 경로로 확보 |
| 개발 | 탐사 원리+설계도+재료로 개량 | 원하는 역할을 선택, 다음 개량 목표를 표시 |
| 조선소 시제품 추첨 | 선체 또는 모듈의 품질·특성 변형 | 게임 내 재화 사용을 기본 제안; 현금 결제 도입은 요구되지 않음 |
| 난파선 인양 | 손상됐지만 특색 있는 배·부품 | 수리·해독으로 상태를 확인한 후 인수 |
| 문명 거래·공동 연구 | 문화별 특화 모듈 | 관계·계약 조건을 충족하면 확정 획득 |

추첨은 결과 풀·확률·중복 처리·확정 획득까지의 진척을 사전에 공개한다. 중복은 연구 부품으로 바꾸거나 기존 선체 개량에 쓴다. 특정 역할을 계속 놓치면 개발 도면을 확정 획득하는 누적 진척을 제안한다. 정확한 확률·천장 수치는 미정이며, 취소·재접속으로 결과를 재추첨하지 않는다. 뽑기 없이도 탐험·사업을 완결할 수 있어야 한다.

## 우주 이벤트 묶음

| 이벤트 | 단서와 선택 | 탐사·테라포밍으로 이어지는 결과 |
| --- | --- | --- |
| 해적 검문·추격 | 항로 경고, 교신; 우회·협상·미끼·도주·교전 | 화물·수리비의 위험, 새 항로 정보·인양 부품 |
| 구조 신호 | 신호 진위 조사, 구조·견인·보급 | 생존자 관계, 안전 정박지, 환경 기술의 단서 |
| 혜성·얼음 잔해 | 접근 시간대, 채집·드론 투하·통과 | 물·휘발성 물질, 동결 표본과 연구 기질 |
| 항성 활동 경보 | 센서 경고, 차폐·대기·우회 | 방사선 대응 재료의 조사, 방호 설비 연구 |
| 고대 중계 구조물 | 손상 패턴, 해독·수리·분해·보존 | 항로 연결, 에너지 분배 원리, 세력 반응 |
| 떠도는 연구선 | 로그·오염 경고, 격리 인양·자료만 복사 | 미완성 실험의 후속 연구, 생물실 개선 |
| 이동 상단·조사단 | 통신, 교역·정보 교환·호위 | 현지 수요, 기술·물자, 공동 조사 계약 |

발생 조건은 지역 정세·항로 이용·센서 노출·활동 이력으로 설명하고, 위험을 숨겨 갑자기 전체 자산을 잃게 하는 추첨은 피한다. 해적도 보급망과 활동권을 가진 세력이며 모든 항로에 같은 확률로 나타나지 않는다. 한 항해의 큰 사건 이후에는 완충 구간을 두고 같은 구조 신호를 무한 반복 지급하지 않는다.

### 손상·실패·복구

일반 탐험 모드에서는 선체 손상, 일부 화물 손실, 구조 비용·시간으로 실패를 처리하는 안을 제안한다. 연구 도감과 확정 설계도는 보존하고, 실물 표본의 손상은 [생물 운송 규칙](09-discovery-research-and-ecology.md)을 따른다. 기본선까지 잃어 진행 불가가 되면 구조용 대여선과 소규모 확정 일감을 제공한다. 구조 보상·대여품을 반복 판매해 이득을 얻지 못하게 한다. 영구 선체 손실은 별도 난이도 결정 사항이다.

## 확인할 경험

같은 후보 목록에서 다른 장비를 가진 플레이어가 다른 행성을 고르는가, 우주선 개량이 새 접근 방법을 여는가, 비전투 선택으로 해적 사건을 넘길 수 있는가, 낯선 신호가 다음 행성의 해결책이 되는가를 플레이테스트한다. 데이터 출처·생성 범위는 [실제 천체 데이터 설계](../technical/03-universe-data-and-world-streaming.md)를 따른다.

## 현재 실행: 기존 선체의 모듈 성장

공동 탐험의 KESTREL 정비 메뉴에서 추진·연구·로봇 수송 모듈을 제작/추첨/개량하고 실제 장착한다. 비용·보장·전력·질량·효과·검증과 미완료 범위의 단일 소관은 [E3 모듈 기록](../production/16-vessel-refits-and-progression.md)이다. 2026-09-07 정거장 선체 구매·보관·교체를 추가했다. 출현·교역·자산 보존·확인 범위는 [정거장과 선체](../production/42-space-stations-and-hulls.md)를 따른다. 선체별 전용 내부 공간은 후속 범위다.

## 성간 초고속 항해 적용

사용자 확정 방향·조작·검증·남은 범위는 [성간 초고속 항해 구현 기록](../production/26-stellar-cruise.md)을 따른다.

태양계는 착륙·테라포밍 금지 대상이며, 우주에서는 행성 주시 스캔으로 이름과 기본 정보를 확인한다. [주시 스캔 적용](../production/27-planet-gaze-scan.md).

첫 진입은 환영 편지→태양계 자유 관측→태양계 전용 출격 버튼→가까운 T1 항성계 고속 항해로 연결한다. [튜토리얼 구현](../production/28-first-departure.md).

우주선에 선체 체력·자동 충전 추진 에너지를 적용한다. Shift 고속 추진과 성간 항해에 에너지를 쓰며 화폐/소모 아이템은 요구하지 않는다. 항성 발광·크기·기울어진 느린 공전은 [적용 기록](../production/29-space-light-and-drive.md)을 따른다.

항성 근접 경고/열 피해와 넓어진 항성계, 직접 비행에 적용되는 추진 모듈 속도 배율은 [후속 적용](../production/30-stellar-hazard-and-depth.md)을 따른다.

2026-09-07: 항성의 표면·코로나·홍염을 네 시각 계열로 구분한다. 공전선은 화면·항법도에서 제거하고 실제 공전은 유지한다. [제작과 범위](../production/33-stellar-appearance.md).

2026-09-07 사용자 확정: 진입 연출·비행 감각·스캔 판단·탐험 기록·방향 안내를 단계별 적용한다. 천체명은 영어 고유명사로 유지한다. [규칙과 단계별 구현](../production/34-space-experience.md).

## 2026-09-07 — 행성 진입·착륙 연출

사용자 확정: 우주에서 행성으로 접근하고, 필요한 로딩을 자연스러운 진입 전환 중 처리한 뒤, 지표의 특정 위치로 하강·착륙하고 게임 조작을 시작한다. 필요한 사운드는 ElevenLabs로 제작한다. 현재 기본 원정의 구현·검수·제약은 [행성 진입 제작 기록](../production/35-planet-arrival.md)을 따른다. 자유 착륙 지점 선택이나 구면 지표 연속 비행의 구현 완료를 뜻하지 않는다.

## 2026-09-07 — 항해 패널 간소화

사용자 승인: 상시 항해 목록을 없애고 우측 상단 지도, 주시/선택 천체의 짧은 정보, 근접 시 선택하는 착륙으로 구성한다. 큰 지도에서만 먼 목적지·기록·조사 상세를 다루고 승무원/화물/정비는 소관 화면으로 옮긴다. 직접 비행해 가까워진 행성도 실제 거리와 호스트 조건을 충족하면 착륙할 수 있다. [현재 구현과 입력 검증](../production/38-navigation-context-and-menus.md).

후속 간소화: 지도에서 즐겨찾기 추가와 긴 조사 상세를 제거한다. 관측한 환경은 수자원·대기 적합·기온 적합 막대, 자원은 아이콘, 위험/착륙 제한은 짧은 표기로 전달한다. 정확한 수치는 막대 툴팁에 둔다.

2026-09-07 정정: 위의 지도 간소화는 우주 주시 스캔 말풍선 삭제를 뜻하지 않는다. 비행 중 스캔 완료 말풍선에서 자원·환경·위험·개선 부담을 확인하고 접근 여부를 결정할 수 있어야 한다. [복구와 확인](../production/38-navigation-context-and-menus.md).

2026-09-07 도착 시야 확정: 성간 이동 직후 행성 바로 앞까지 자동 접근하지 않고, 조금 떨어진 상공에서 항성계 안쪽을 바라보며 정지한다. 스캔으로 방문 여부를 판단한 뒤 직접 조종 또는 명시적 접근으로 이어진다. 구현 수치와 확인 범위는 [항성계 구성](../production/32-system-diversity.md)을 따른다.

2026-09-07 추가 확정: 성간 항해에서 출발 항성계가 점점 멀어지고 목적지 항성계는 먼 곳에서 점점 가까워지는 연출을 제공한다. 천체의 갑작스러운 표시 전환을 원경 이동·점진적 감쇠로 바꾼다. [구현·확인](../production/26-stellar-cruise.md).

2026-09-07 사용자 재확정: 첫 시작은 태양계 내부 지구 궤도이며, 성간 이동의 원경 도착 규칙에서 제외한다. [시작 위치·표현·검증](../production/20-galaxy-start-and-lobby.md).

2026-09-07 출발 연출 재확정: 주변 천체와 충돌하지 않는 전방 항로를 먼저 찾고 선체를 정렬한 뒤 그 방향으로 전진한다. 후방을 보며 후진처럼 보이는 출발 카메라는 사용하지 않는다. [구현·확인](../production/26-stellar-cruise.md).

## 2026-09-07 — 3D 은하 항로와 항속거리

사용자 확정: 첫 출격과 후속 성간 이동은 3D 은하 지도에서 항성계를 선택한다. 미방문 항성계의 이동은 허용하고 내부 정보만 숨긴다. 선체/추진 모듈별 항속거리, 범위 내 주변 확대, 확대별 표시 밀도, 우주 화면 방향별 가까운 별의 주시/호버 후 직접 출발을 적용한다. 초기 범위 축소·거리 단위·실제 구현 및 검증은 [단일 소관 기록](../production/43-galaxy-routes.md)을 따른다. 이전 자동 첫 목적지와 미방문 클릭 전체 차단보다 이 결정이 우선한다.
