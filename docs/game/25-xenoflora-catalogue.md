# 추가 식물·미생물 100종 구조 목록

2026-09-10. 식물 60개·미생물 군락 40개의 별도 기본 모델이다. 전체 생물 기본형은 동물 700 + 식물 185 + 미생물 115 = 1,000개다. 색·크기 외형 프로필은 기본종에 중복 계산하지 않는다. 미생물 모델은 눈에 보이는 군락이며 단일 세포를 사람 크기로 확대한 것이 아니다.
