# 동일 제품의 복수 제조법과 고티어 현지 조달

2026-09-14 사용자 요청: 후반 행성에서 낮은 티어 재료가 없을 때 높은 티어 광물로 대신 생산할 수 있게 한다. **같은 제품에 표준 제조법과 고티어 소재 제조법을 제공**하는 방향이다. 새 광물 분포나 제조법을 이번에 구현한 것은 아니다. 설비 종류 및 강화는 [시설 성장 소관](31-facility-growth-and-tradeoffs.md), 개발 순서는 [통합 계획](../planning/20-special-discovery-and-facility-growth.md)을 따른다.

## 1. 제품 하나와 제조법 둘을 구분한다

출력 제품의 ID, 용도와 품질은 같다. 달라지는 것은 입력 재료, 소요 시간, 전력, 필요한 공정과 생산량이다. 고티어 원료를 썼다는 이유만으로 같은 제품에 숨은 성능 차이나 별도 배낭 스택을 만들지 않는다. 성능이 다른 제품은 별도 제품 설계로 다룬다.

첫 범위는 후반까지 계속 필요한 프레임, 회로, 필터, 열전달 부품과 유지용 처리재다. 제품마다 제조법 2개를 기본안으로 삼되 모든 장식, 고유 표본과 임무 물건까지 억지로 두 개씩 채우지 않는다. 기본 장비 및 건설 재료가 원광을 직접 요구하는 경우도 빠뜨리지 않고 대체 입력 묶음이나 공통 가공 부품 사용으로 연결한다.

높은 티어 광물을 모든 낮은 티어 원광으로 일괄 변환하는 만능 환전은 기본안이 아니다. 제품에 필요한 구조, 전도, 여과 등의 기능을 다른 재료와 공정으로 충족한다. 현지에 저티어 광물이 실제로 있는지는 기존 시드와 지질에 따르며, 이번 요구를 이유로 광물을 없애거나 생성하지 않는다.

## 2. 대표 제품의 두 경로

아래 표의 표준 경로는 [현재 제품 데이터](../../우주-비즈니스/data/production_tier2.json)의 입력 종류를 요약했다. 고티어 경로는 게임용 설계 예시이며 실재 제조법이나 확정 배합이 아니다. 정확한 수량, 가공 중간재와 해금 조건은 후속 설계에서 정한다.

| 동일 출력 제품 | 표준 경로의 현재 입력 | 고티어 경로 제안 | 공정 차이 |
| --- | --- | --- | --- |
| 보강 프레임 | 정제 철 + 암석 | 티타늄 또는 니켈 계열의 구조용 가공재 | 금속 가공 공장에서 고온 성형. 원료는 덜 들 수 있지만 가공 전력 필요 |
| 제어 회로 | 정제 구리 + 암석 | 규소와 고티어 전도성 가공재 | 현장 제작소의 정밀 공정. 고급 가공재 안에 구리 필수 경로를 다시 숨기지 않음 |
| 광물 필터 | 정제 철 + 암석 | 고티어 다공성 또는 선택 흡착 가공재 | 같은 필터 생산. 처리 대상과 수명은 제품 규격대로 유지 |
| 열전달 유닛 | 정제 구리 + 정제 철 | 티타늄 및 고티어 열전달 가공재 | 같은 유닛 생산. 내열 가공에 시간과 전력 사용 |
| 토양 기반재 | 암석 + 얼음 | 적합한 현지 광물 기질 + 회수수 | 재료 경로는 달라도 실제 수분과 기질 필요. 금속만으로 물을 생성하지 않음 |

T3의 가스 흡착 팩, 수질 중화 팩과 T4의 극열 흡수 팩, 극저온 완충 팩도 같은 방식으로 후반 공급을 점검한다. 기존 제품 ID와 이미 비축한 물건을 유지한다. 임의의 고티어 광물 하나가 영양분, 물과 유효 생물 표본을 모두 대신하도록 만들지 않는다.

## 3. 후반에 다시 막히지 않는 생산 경로

최종 제조법에 고급 소재를 넣어도 그 소재를 만드는 하위 공정에 저티어 전용 원료가 필수라면 대체 경로가 아니다. 완제품부터 원료까지 의존 경로 전체를 확인한다.

- 대표 T3, T4, T5 조달 묶음에서 기초 설비의 건설, 강화, 수리와 지속 소비품까지 생산 경로를 정한다. 표준 경로의 저티어 전용 원료 없이 가능한지 확인한다.
- 대체 공정에 필요한 건물 자체가 대체할 저티어 원료를 필수 요구하는 순환 잠금을 피한다. 기존 원정선의 작업 능력이나 반입 가능한 준비 부품으로 첫 공정을 열거나, 해당 건설비에도 대체 경로를 제공한다.
- 같은 기능의 현지 고티어 원료가 여러 개라면 한 고티어 제조법 안에 명시된 대체 재료군과 교환비를 둘 수 있다. 아무 광물이나 받는 와일드카드는 사용하지 않는다.
- 전력, 냉각과 소모품까지 포함한 실제 운용 경로를 점검한다. 단 한 번 제작 가능하다는 이유만으로 지속 현지 조달이 완성된 것으로 기록하지 않는다.
- 지역에 필요한 원료가 전혀 없으면 조사한 다른 현장이나 같은 진행 구간의 행성에서 직접 조달할 수 있다. 모든 행성의 완전 자급을 보장하는 방향은 아니며 저티어 전용 재료를 위한 강제 귀환을 줄이는 것이 목표다.

표준 제조법은 낮은 가공 비용과 기존 공급망 때문에 계속 유용하다. 고티어 제조법은 현지 조달과 운송 절약의 이득을 제공한다. 비싼 광물이 항상 더 적은 총비용이나 더 빠른 생산을 뜻하지 않으며 불필요하게 큰 벌칙으로 대체 경로를 사실상 못 쓰게 만들지도 않는다.

## 4. 선택 화면과 제작 확정

제품 카드 하나를 열면 `표준 제조법`과 `고티어 소재 제조법`을 비교한다. 결과 제품, 입력 재료, 생산량, 시간, 전력과 사용 시설을 나란히 보여준다. 부족한 재료가 있을 때 사용 가능한 다른 경로를 안내한다.

플레이어가 제조법을 명시적으로 선택한다. 재료가 부족하다고 희귀 광물을 몰래 소비하지 않는다. 자동 생산은 선택한 제조법을 기본 고정하며, 자동 대체를 지원할 경우 허용한 제조법과 우선순위를 별도로 설정한다. 이 설정도 희귀 재료 사용 권한을 임의로 넓히지 않는다.

생산 중 제조법 변경은 새 작업부터 적용한다. 진행 중 작업을 취소하면 해당 작업의 실제 투입 내역과 기존 취소 정책으로 반환한다. 저티어 재료를 넣고 고티어 재료로 환불받을 수 없어야 한다. 철거와 분해도 선택했던 실제 비용 기록 또는 별도로 정한 회수 산출물을 사용하며 제조법을 바꾸어 재료가 증식하지 않게 한다.

## 5. 데이터, 협동과 기존 작업

`product_id`와 `recipe_id`를 분리한다. 제조법에는 입력 묶음, 출력 수량, 공정 조건, 시간과 전력을 둔다. 생산 예약에는 선택 제조법과 규칙 버전, 확정한 비용 내역을 보존한다. 기존 제조법이 없는 예약은 기존 표준 제조법으로 해석하여 원래 비용과 결과를 유지한다.

호스트는 선택한 제조법의 해금과 시설 능력, 해당 재고만 검증하고 비용 차감과 예약을 한 거래로 처리한다. 요청 실패나 재전송으로 재료가 중복 차감되지 않게 한다. 장비 제작대의 개인 배낭과 공장의 현장 재고 구분은 유지한다.

화면에서 제조법을 비교하는 것만으로 저장 거래를 만들지 않는다. 선택과 제작 확정은 대상 제품, 제작 시설과 관련 재고만 갱신한다. 모든 행성의 제조법이나 생산 큐를 순회하거나 모델을 다시 만들지 않는다.

후속 확인은 동일 제품의 두 제조법 출력 호환, 고티어 원료에서 출발한 하위 생산 경로, 제작 확정 및 취소 비용, 기존 예약 보존에 한정한다. 이번 문서 작업에서는 게임 테스트를 실행하지 않았다.
