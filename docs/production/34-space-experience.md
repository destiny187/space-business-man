## 명명 조사와 구현

[NASA 외계행성 명명 설명](https://science.nasa.gov/exoplanets/how-do-exoplanets-get-their-names/)과 [IAU 외계행성 명명 규칙](https://iauarchive.eso.org/public/themes/naming_exoplanets/)을 확인했다. 과학 표기는 항성의 목록 명칭/번호에 행성 소문자 b, c 등을 붙인다. 숫자는 항성 목록의 식별 번호이며 행성 소문자는 통상 발견 순서다. 공모로 지정된 고유명은 이와 별도다.

게임의 생성 항성계는 `Spica 00024`, 그 행성은 `Spica 00024 b`와 같이 표시한다. 기존 영어 항성명에서 이름 어휘를 가져오되 번호·위치·천체 특성은 **가상 은하의 생성 데이터**다. 실제 Spica의 관측 행성을 재현한 것이 아니다. 게임에서는 고정 궤도 순서에 b부터 부여해 플레이어별 발견 순서로 이름이 바뀌지 않는다. 항성계 번호는 은하 안에서 유일하며 시드가 같으면 같은 이름을 재현한다. 태양계는 Sol / Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune이다.

표시 이름만 바꾸며 기존 행성 ID·시드·매니페스트·지형·소유권은 변경하지 않는다. 이름 어휘는 `celestial_names.json`, 명명 함수는 `FrontierCelestialNames`가 담당한다. 번역 키로 처리하지 않는다.

## 1단계 — 항성계 진입

진입 시 큰 중앙 제목, 펼쳐지는 수평선, 상하의 얇은 시네마틱 프레임과 항성 분광형·행성 수·항성계 특징을 표시하고 6.5초 안에 사라진다. 입력을 막는 팝업이 아니며 기존 성간 충전/도착 효과음을 유지한다. 목적지의 경사진 외곽 진입 위치를 유지하고 호스트의 성간 항해 완료 방향을 도착 행성 쪽으로 맞춰 렌더와 실제 조종 방향을 연결한다.

Metal Forward+에서 실제 우주선·항성·행성·제목을 렌더링했다. 영어 이름의 재현과 Earth 표기, 행성 b 접미사를 확인했다. `check_space_experience.gd`, 대표 화면 `media/space-experience/arrival.png`. 전체 멀티플레이 회귀 검사는 수행하지 않았다.

## 2단계 — 거리감과 감속

실제 항해 속도에 따라 화면 주변의 희미한 입자 궤적이 길어지고 추진·엔진의 기존 속도 반응과 함께 표시된다. 목적지의 접근 여유 거리까지 남은 거리, 현재 목적지 방향 속도로 계산한 예상 도착 시간을 표시한다. 정지/반대 방향일 때는 잘못된 도착 시간을 제시하지 않는다. 예상 시간은 현재 속도 기준으로 이후 감속·우회 시간은 포함하지 않는다.

호스트 직접 비행에서 진행 방향의 항성·행성·고리·위성을 검사해 제동 거리 안에서 부드럽게 감속한다. 회피 방향에는 속도를 제한하지 않는다. 기존 충돌·항성 열 피해·외곽 경계는 유지한다. 관련 수치는 `flight_experience.json`에 두고 협동 콘텐츠 해시에 포함한다. 최소 실행 검사에서 빠른 접근 감속과 양수 ETA를 확인했고 Forward+ 실제 화면의 거리 표시를 확인했다.

## 3단계 — 궤도 스캔 판단 정보

주시 스캔 완료 카드에 최대 네 종류의 광물 아이콘·이름, 수자원 비율·대기 적합 막대, 고열/극저온/독성/기압 위험과 환경 개선 부담을 표시한다. Tab 항법도의 스캔 상세를 펼치면 주요·부수 광물, 지하 보석 후보, 특이 소재 반응과 기온·기압·산소를 확인한다. 미스캔 천체는 상세를 공개하지 않는다.

정보는 행성 시드에 고정된 초기 원격 관측이며 현재 개발 현황·매장량·채굴 위치와 구분한다. 개선 부담은 기존 환경 평가의 대기·온도·물 적합도 평균 부족분으로 낮음/보통/높음을 나누는 안내용 추정이다. 화산은 냉각 선행을 별도로 표시하고 가스행성·태양계는 개발 불가다. 제작 비용·수익·완료 시간을 확정하는 판정이 아니다.

Forward+ 실제 스캔 카드 렌더, 복합 광물 보고서, 태양계 개발 불가 정보를 확인했다. 대표 `media/space-experience/scan.png`.
