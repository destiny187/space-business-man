# 공통 조사와 살아 있는 정착물

2026-09-06. 소관 설계는 [발견·연구·생태](../game/09-discovery-research-and-ecology.md), 시각 표현은 [FIELD v1](22-uiux-guide.md)을 따른다.

## 사용자 확정 방향

- 플레이어가 궁금해하는 대상을 폭넓게 스캔할 수 있어야 한다. 광물도 포함한다.
- 생물은 스캔/표본 수집 뒤 연구와 실제 성능에 연결한다.
- 테라포밍한 세계에서 살 수 있게 만들고 배치하여 정원·서식지·장식물로도 활용한다. 외형을 감상하고 세계를 꾸미는 것 자체도 유효한 수집 동기다.
- 스캔 정보, 연구 지식, 실물 표본, 배양된 개체, 실제 정착 상태를 구분한다.

## 설계 제안: 관찰 → 이해 → 실물 확보 → 정착

모든 물건에 경험치나 레시피를 붙이지 않는다. 일반 바위·토양도 구성과 환경 정보를 줄 수 있지만 독립 도감 항목/영구 보상을 무한히 만들지 않는다. 스캔은 비소모 관찰이며 이미 아는 대상을 다시 조사하면 현재 상태를 보여준다. 미확인·측정 불가 상태를 정직하게 표시한다.

| 대상 | 조사 정보 | 플레이 연결 |
| --- | --- | --- |
| 광물 | 성분·품위·매장량·채집기 등급·용도 | 채집 판단, 위치 기록, 자동화 후보 |
| 식물 | 생존 조건·형태·수분/토양 특성 | 배양, 조경, 녹화·환경 설비 연구 |
| 미생물 | 기질·대사·정화 조건 | 배양 구획, 토양 형성·처리 설비 |
| 동물 | 행동·먹이·서식 조건·위험성 | 관찰 정원, 이주·보전, 생체 구조 연구 |
| 바위·토양·물 | 지질·수분·오염·환경 | 입지와 복원 방식 선택 |
| 시설·유적 | 기능·상태·이상 구조 | 수리·탐험·공학 연구 |

위 표는 확장 목표다. 현재 구현된 측정값이 없는 품위·먹이망·오염 분석을 숫자로 꾸며 표시하지 않는다. 스캔은 생물의 실제 성능을 모두 증명하지 않는다. 기본 관찰에는 활용 후보, 실물 분석에는 검증된 조건, 현장에는 실제 작동 상태를 보여준다.

스캔 데이터는 복제 가능한 지식이고 표본은 단일 실물이다. 분석/배양의 씨앗으로 표본을 쓸 수 있게 확장하되 기존 환경별 기초 연구 해금을 갑자기 회수하지 않는다. 표본 소비·배양 기간·생산량·가격은 데이터로 관리할 초기 밸런스이며 아직 확정하지 않았다.

## 설계 제안: 테라포밍 이후의 생물 배치

**살아 있는 정착물**은 장식 가치와 생태 기능을 함께 갖는다. 정원에 심은 식물, 연못/동굴의 생물 군락, 제한된 영역에서 움직이는 동물을 기존 Blender 모델과 행동으로 표현한다. 장식용이라는 이유로 생존 조건을 무시하거나 동일 개체의 효과를 무한 중첩하지 않는다.

- 자연 정착: 배치 위치의 온도·압력·수분·기질과 종별 요구를 검사한다. 적합한 세계에서 외부 지원 없이 유지될 수 있는 것이 목표다.
- 관리 서식지: 부적합한 곳에서는 전력·수분·급이 등 지원을 갖춘 온실/격리 구획을 이용한다. 지원 상태를 실제 모델·상태 아이콘으로 보여준다.
- 배치 조작: 생물 카드 선택 → 실제 모델 고스트와 활동 범위 → 적합/부적합 지표 → 호스트 확정 → 실물 소모와 정착 연출. 목록 버튼만 추가해서 자유 배치 완료로 기록하지 않는다.
- 실물 보존: 설치한 개체는 해당 위치/행성에 속한다. 회수·이주와 배양으로 얻은 새 개체를 구분한다. 표본 하나가 여러 행성에 동시에 존재하지 않는다.
- 성능: 토양 형성·지역 생물량·수분 유지·시설 처리 등 종별 역할을 검증 가능한 수치로 정의한다. 면적·지원량·개체 밀도에 상한을 두고 장식 반복 설치를 무한 버프 수단으로 만들지 않는다.
- 지속성: 행성/개체 ID, 출처, 위치, 서식지, 지원 상태를 저장한다. 화면 밖에서는 구획 단위로 계산하고 가까이에서는 모델/행동으로 표현한다. 생존 판정을 카메라 거리나 LOD에 종속시키지 않는다.
- 협동: 공동 세계의 배치는 호스트가 소유/실물/환경/공간을 확인한 뒤 확정한다. 생물 반출·공동 표본 사용 권한은 기존 승무원 소관에 맞춰 확장한다.

번식·먹이망·생물의 사망/휴면·회수 손실과 종별 정량 성능은 후속 결정 대상이다. 우선 외형 감상과 안전한 정착 흐름부터 만들고 자동 번식으로 세계 개체 수가 무제한 증가하지 않도록 한다.

## 이번 구현

- `FrontierSurfaceSurvey`가 기존 생물 스캔과 노출된 지표 광물 스캔을 같은 호스트 입력 흐름으로 처리한다. E 유지, 거리·조준·지형 가림, 도구 소유 판정을 따른다. 광물 조사는 사업 등록/채집기 장착을 요구하지 않는다.
- 광물 스캔은 이름, 실제 광맥 잔량/용량, 필요한 채집기 등급, 실제 장비 제작 데이터에서 찾은 활용처를 표시한다. 미연결 재료는 활용 조사 중으로 구분한다. 매장 광물 투시, 품위 정밀 분석은 추가하지 않았다.
- 생물 결과 카드는 현재 기초 분석→복원 구획, 실물 표본→다른 행성 이식, 환경에 맞는 기존 공학 과제의 처리 속도 효과를 보여준다. 연구·설치 후 효과임을 명시하며 스캔만으로 보너스를 주지 않는다.
- J 연구창에 조사 타일과 선택 상세를 추가했다. 생물 선택 시 기존 Blender 모델의 실제 INK 3D 미리보기를 보여준다. 생물 형태와 광물 아이콘이 먼저 보이고 정확한 조건·용도가 보조한다.
- 기존 생물 기록은 `ecology.observations`, 광물 기록은 `crew.survey`에 유지한다. 광물은 행성/자원별로 묶고 중복 스캔 보상을 만들지 않는다. 당시에는 최근 광물 256개를 보존하고 UI에서 마지막 24개만 표시했다. **2026-09-08 [UX02](72-discovery-factory-and-navigation.md)**부터 저장 기록 삭제를 제거하고 검색·분류·전체 페이지 조회를 구현했다. 기존 버전에서 삭제한 기록은 복원하지 못한다.
- 저장 성공 후에만 완료 카드와 기록을 확정한다. 지식과 재고의 저장 경계를 유지한다. `survey_version`으로 구버전과 세션 호환성을 구분한다. 기존 저장의 조사 필드가 없어도 읽는다.

**이번에 새로 구현하지 않은 것:** 일반 토양·물·유적/시설 스캔, 자유 배치 고스트, 테라포밍 완료 지역의 자립 정착, 표본 배양/번식, 새로운 종별 환경 보너스. 기존의 우주선 지원 시험 구획 이식·생물량 증가·공학 설비 효과는 유지한다.

## 확인 범위

`tests/test_surface_survey.gd`는 임시 세계에서 광물 E 유지/중단·중복 조사·결과 수치·메뉴 차단·기존 생물 조사·조사창/실제 모델·저장 재개와 기록 검증을 확인한다. 접근 위치는 짧은 검증을 위한 테스트 배치다. 실제 다중 클라이언트·전체 회귀·장시간 성능 검사는 수행하지 않는다. 신규 3D/사운드 생성은 없으며 기존 Blender 모델과 ElevenLabs 발견/스캔 효과를 재사용한다.

최종 확인: **18개 흐름 항목, 실패 0**. 별도 좁은 검사에서 저장 실패 시 기록/완료 카드가 확정되지 않음을 확인했다. 이후 카드의 다음 행동 안내·타일 선택과 연구 대상 연결·작은 화면 배치를 보완하고 규칙/실제 창을 확인했다. 현재 작업 트리의 별도 광물 확장 변경도 포함된 실행 환경이며, 이번 변경만 분리한 커밋을 검증했다고 주장하지 않는다.
