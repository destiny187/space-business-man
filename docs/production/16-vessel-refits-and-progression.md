# KESTREL 모듈 성장과 이동 실험실

2026-09-06 E3 첫 실행 범위. **기존 공동 원정선의 모듈 제작·추첨·개량·장착을 구현했다.** 새 선체 획득/교체, 선내 격납고와 표본 보관실 전체 구현은 남아 있다. X-02 전체 완료로 표시하지 않는다.

## 플레이 경로

원정 참가 → 실제 항해와 착륙 → 무료 사업 등록 → 광맥 채광/창고 반납 또는 공동 자금으로 재료 보급 → `우주선 정비 · 모듈` 메뉴. 호스트가 착륙선 주변에서 공동 자금을 사용한다. 승무원은 동일한 보유 목록·장착·추첨 결과를 확인한다. 정비 후에는 출항 준비를 다시 확인해야 한다.

| 모듈 | 슬롯 | 실제 효과 | 게임 내 형태 |
| --- | --- | --- | --- |
| 벡터 추진 보조기 | 추진 | 접근 속도·가속 ×1.10 / 1.20 / 1.30 | 이중 노즐·열교환 핀·봉인 레일 |
| 이동 실험실 | 공용 | 가동 조건을 충족한 시제품·현장 시험 진행 ×1.15 / 1.30 / 1.45 | 관측창·배양 챔버·방열판·멸균 포트 |
| 로봇 운송 포드 | 공용 | 기본 2칸 → 3 / 4 / 4칸 | 적재 케이지·서비스 해치·잠금 장치 |

등급 순서는 표준·개량·희귀다. 슬롯을 교체하면 이전 효과는 즉시 사라지고 모듈은 소유 목록에 남는다. 연구실은 시설 전력·재료·생물 적합성 검사를 우회하지 않는다. 추진 효과는 성간 도약 시간을 바꾸지 않는다.

## 성장·비용·제약

모든 수치는 초기 밸런스이며 `data/vessel_refit.json`이 단일 소관이다. 표준 모듈은 지정 제작 가능하다. 게임 내 크레딧 추첨의 등급 확률은 70/25/5%, 일반 추첨 종류는 세 종류 균등이며 매 6번째는 선택 종류의 개량 등급이다. 같은 종류·등급은 중복 소유하지 않고 부품 8개로 전환한다. 분해는 해제한 모듈만 가능하다. 부품·재료·크레딧을 소비하는 확정 개량 경로가 있고, 희귀 개발은 관련 생물공학 인증을 요구한다. 추첨에서 얻은 희귀 모듈에는 개발 인증을 요구하지 않는다. 현실 화폐 결제는 없다.

추진 1슬롯·공용 1슬롯, 전력 12 MW, 기본 질량 40 t·최대 54 t, 회수 로봇당 1.5 t를 적용했다. 최상급 추진과 실험실은 전력 한도로 함께 장착할 수 없고, 무거운 추진과 가득 찬 포드도 질량 한도를 초과할 수 있다. 적재한 로봇 수보다 격납고 용량을 줄이는 장착 해제/교체를 거절한다.

현재 질량 모델은 선체·장착 모듈·회수 로봇을 대상으로 한다. 일반 재료·격리 표본의 질량/가스/열 관리와 실제 궤도 물리 시뮬레이션은 포함하지 않는다. 모듈 외형은 종류별 세 모델이며 등급별 별도 형상·손상·작동 애니메이션은 후속 범위다.

## 저장과 동기화

- 선택한 세계에 귀속되는 원정선 ID, 모듈 고유 순번, 보유 종류/등급, 슬롯, 추첨 순번·최근 결과·부품을 보존한다.
- 호스트 권한·선박 거리·사업 창고·비용·전력·질량을 검사하고, 세계 복사본 저장 성공 후 응답한다. 거절·저장 실패는 재료/자금/추첨 순번을 소비하지 않는다. 같은 네트워크 영수증은 재지급하지 않는다.
- 기존 저장은 모듈 기록이 없어도 기본 선박으로 읽는다. 세계를 재생성하지 않는다. 새로운 모듈 규칙 서명은 접속 콘텐츠 검사에 포함된다.
- 클라이언트가 모듈 구조와 슬롯 연결을 검증한다. GLB는 비동기 요청 후 프레임당 하나씩 장착한다. 지표 선체와 실제 3D 항해 선체에 같은 소유 모듈을 표시한다.

## 제작과 검증
