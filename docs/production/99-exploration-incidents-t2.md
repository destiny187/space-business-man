# T1/T2 사건형 탐험 제작

2026-09-09. 사용자가 T5까지 분류하고 T1/T2만 먼저 개발하도록 승인했다. 소관 규칙과 T3 이후 후보는 [사건형 탐험](../game/21-exploration-incidents.md), 기존 정적 발견물 20종은 [97번 기록](97-exploration-discoveries-t2.md)에 둔다.

## 이번 연결 범위

현재 원정의 지표·동굴에 다음 8종을 연결한다. 조사 단계 선택창으로 추적·회피·교전을 대체하지 않는다. F는 가까운 실물 회수/전원 연결에, 장비 클릭은 조준한 부위 작업에 사용한다.

T2 난파선은 배터리 전원 격실 변형을 포함한다. 회수 장비는 I의 실제 개인 장비로 들어가며 자동 장착하지 않는다. T1/T2 기초 제작 개방을 유지하며 설계도는 지급하지 않는다. 보석 종류·장비 조건은 기존 광물/강화 체계를 사용한다. 새 손상 장비 수리 체계·전용 회사 화폐·설계도 아이템은 만들지 않았다.

수치·밀도·보상은 `data/exploration_incidents.json`의 조정 가능한 값이다. 현재 640m 타일당 T1 최대 2 / T2 최대 3 지표 사건에 조건이 맞는 동굴 사건을 추가한다. 기초 행성에서도 모든 종류가 반드시 등장하지 않는다. 얼음 사건은 추운 행성, 생물 사건은 고유 생명이 정착한 행성에 배치한다. T3~T5 신규 사건은 이번 생성 풀에 없다.

## 진행·저장·권한

- 호스트가 시드·행성·타일로 위치를 고정하고 170m 접근 때 사건을 활성화한다. 기존 건물 주변은 배치에서 제외한다. 지진 방은 기존 동굴에서 가지를 내며 200m 기반암 위에 머문다.
- `incidents.records`가 파괴/적 체력·단계·운반자·배터리·채굴 잔량·보상 수령을 저장한다. 기존 저장에는 비어 있는 사건 기록을 추가한다. 재접근·재접속으로 화물과 적을 다시 뽑지 않는다.
- 도구 종류·등급·거리·조준·지형 및 물체 엄폐·사용 간격을 호스트에서 판정한다. 기존 요청 수령 기록과 저장 성공 후 확정 경로를 사용한다. 배낭이 가득 차면 화물·보석을 남기고 회수를 거절한다.
- 운반 중 이동 속도는 기본의 65%다. X로 현재 위치에 내려놓는다. 이탈·다른 행성 이동·구조 후에는 원래 사건의 회수 가능한 위치로 반환한다. 운반자는 한 번에 한 물건만 든다.
- 현장 승무원이 없는 사건은 진행을 정지한다. 메뉴를 연 승무원을 대상으로 새 전투·재해 진행을 하지 않는다. 지진으로 열린 지형은 계속 남으며, 보석을 모두 채굴해도 현장 분출은 남는다.
- 발견한 사건은 J 발견 기록의 ‘현장 사건’에서 모델·현장 좌표·행동·회수 상태를 확인한다. 처음부터 모든 난파선 좌표를 공개하지 않는다.
- 소형선 행성 문맥과 사건 저장/스냅샷을 연결했다. 6인·다행성 실기 전체 확인은 이번 최소 검사에 포함하지 않았다.

## 제작 자산과 표현

`tools/build_exploration_incidents.py`로 Blender 원본 11개와 GLB를 제작한다. 산업 재질·곡면·분리 관절·해치/얼음 파괴 부품을 사용하며, 기존 생물 모델은 가동 부위 보행을 재사용한다. 원본은 `art/blender/incidents/`, 출력은 `assets/models/incidents/`에 보존한다. 완성형 후속 아트 전체와 구분하는 첫 제작 자산이다.

난파선/빙하는 실제 내부와 충돌을, 로봇은 몸체 기동·코어 노출·조준선을, 드론은 회전익과 이동을 표현한다. 지진은 먼지·화면 진동·실제 지형 변경, 분출은 점멸 범위 표시·효과·피해를 연결한다. 설정의 ‘탐험 사건 화면 흔들림’을 꺼도 범위 표시와 음향은 유지한다. 운반물은 1인칭 시야 아래에 표시한다.

ElevenLabs에서 지진·로봇 기동·구조 신호 3종을 생성했다. 원본·프롬프트·선택 변형·PCM 처리·해시는 `audio/manifests/exploration-incidents.json`에 둔다. 기존 도구 파괴·펄스 사격·회수음도 재사용한다.

## 최소 확인 기록

- `check_exploration_incidents.gd`: 실제 시드 T1/T2 8종 생성·보상·저장 검증·다시 열기 70개 확인 통과.
- Blender 렌더와 Godot Forward+ INK 스튜디오에서 모델 확인. 실제 원정의 난파선·일루티·지진 공동 화면을 별도 확인.
- 실행 중 발견한 소켓 엄폐, 운반물 시야·960px 기록 설명의 줄바꿈, 자연 동굴과 겹친 공동의 발판 문제를 수정했다. 테스트용 시작 재료가 기존 재접속 처리로 회수 상자에 들어간 것과 테스트 배낭 부족도 구분했다. 생물의 운반 소품을 비동기로 미리 읽도록 고쳐 빈 모델 참조도 해결했다.
- `check_incident_play.gd`: 지진 중심 확인 16개, 드론 중심 확인 20개, T1 장비/기록 확인 15개 통과. 최초 묶음에서 배낭 부족으로 거절된 회수는 테스트 배낭을 비우고 해당 흐름만 재확인했다.
- 게임 창에서 전력 복구·배터리 운반·해치 파괴·내부 화물 회수, 로봇 조준 예고·실제 체력 감소·격파 회수를 확인했다. 지진 통로·실제 충돌 개방·Mk.2 사파이어 채굴을 확인했다. 생물 모델/이동, 절벽 화물의 운반·귀환, 얼음 충돌 해제·화물 회수, 이동 드론 사격·X 내려놓기·재운반·귀환도 실제 창에서 확인했다.

대표 화면은 [난파선 내부](media/incidents-t2/wreck-open.png), [일루티 조준](media/incidents-t2/illuti-aim.png), [지진 공동](media/incidents-t2/seismic-chamber.png), [드론 화물](media/incidents-t2/drone-carried.png), [960px 사건 기록](media/incidents-t2/incident-journal-960.png)에 보존했다. 화면 이동은 격리 테스트의 현장 좌표 이동을 사용했으므로 행성 전체 보행 완주와 구분한다.

병행 작업 중인 T3 사업 화면의 `terraform3/source_control.png` 누락 로그가 실행에 함께 나타났다. 사건 기능 검사와 별개의 자산이며 해당 작업을 이 제작 기록의 완료로 세지 않는다.

## 이번 범위 밖

T3~T5 신규 사건, 로스트 테크놀로지 기록 복원/설계도 획득과 정거장 구매는 후속이다. T2 제안 중 정교한 선체 기울기/다중 중계기, 손상 장비 수리·후속 좌표 보상, 생물 경계 AI·사건 표본 채취, 얼음 용융으로 생기는 유입수, 무인 정비고·로봇 방패/돌진은 이번 기본형에 포함하지 않는다. 모든 사건의 수동 보행 완주·Windows·장시간/6인 검증을 했다고 기록하지 않는다.
