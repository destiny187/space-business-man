# 공동 우주선·FINCH 화물 UI 통일

2026-09-08 사용자는 앞선 작업의 커밋과 함께 공동 우주선·개인 소형선의 인터페이스를 기존 아이템창과 맞추고 텍스트 중심 구성을 개편하도록 요청했다. 먼저 미커밋 상태의 공급망·행성 재질·원격 생산·FINCH를 `6d93d58f`에 보존했다. 이 기록은 이어진 선박 관리/화물 UI 변경이다.

## 현재 화면

선박 단말의 긴 버튼 목록을 실제 Blender 선체를 보여주는 회전 미리보기와 기능 카드로 바꿨다. 공동 원정선은 화물·아이템·연구·정비·탑승을 보여준다. FINCH는 개인 운송선과 화물 4칸을 표시하고, 사용할 수 있는 화물·아이템·독립 이륙·원정선 합류를 보여준다. 공동선 전용 연구·정비·로버 적재함은 FINCH 단말에 노출하지 않는다. 공동 원정선의 차량 적재 진입은 유지한다.

화물 카드는 기존 `FrontierEquipmentPanel`의 **화물** 탭으로 연결된다. 왼쪽 실제 선체, 내 배낭/선박 화물의 아이콘 격자, 각 보관함의 사용 칸/한도 막대, 선택 물건과 수량을 보여준다. 동일 `FrontierItemTile`·FIELD 테마·드래그 입력을 재사용한다. FINCH는 개인 화물, 원정선은 공동 화물로 명시한다. 행성 창고 전환도 유지한다.

자원은 선택 후 수량 지정·Shift+클릭·반대편 슬롯에 드래그하여 옮긴다. 장비도 선택 버튼과 드래그를 모두 지원하며 다른 승무원의 소유 장비는 기존 규칙을 따른다. 호스트 요청 대기 중에는 추가 이동을 막고, 성공/실패 응답 뒤 수량과 선택을 갱신한다. 별도 화물 원장이나 로컬 선반 이동으로 호스트 거래를 우회하지 않는다. 화물 UI 개편으로 거리·용량·소유권·실제 거래 규칙을 바꾸지 않았다.

FINCH 제작 탭도 반복 키 설명을 툴팁으로 옮기고 모델·재료 아이콘·진행과 짧은 행동명을 유지했다. 기존 ElevenLabs 요청 결과음과 메뉴 중 조작/작업음 차단을 사용한다. 새 모델이나 음원을 생성한 작업은 아니다.
