# 2티어 생산·공통 개조 — 2026-09-07

사용자 확정: 전체 5단계를 한꺼번에 만들지 않고, 2티어 제품과 무기를 포함해 각 분야가 한 번 강화되는 생산 기반을 먼저 구현한다. 현재 원정 실행 경로에 연결했다. P3~P5 생산망은 설계로 남긴다. 수치·제작식은 조정 가능한 초기 밸런스이며 현실 화학 공정의 재현이 아니다.

## 플레이 흐름

1. 기초 채집기로 철·구리·암석·얼음을 확보하고 F로 현장 창고에 반납한다. 기존 입문 로봇공학·제작소·태양광 건설 경로를 유지한다.
2. B → **생산·개조**에서 제품 카드와 제작소를 선택한다. 제작소 8m 이내에서 생산 예약하며, 공동 창고의 재료를 한 번 차감한다. 전원이 켜진 제작소에서 시간이 흐르면 결과를 공동 창고에 넣는다. 전력 부족·정지는 진행을 멈춘다.
3. I → 화물 → 공동 창고에서 부품과 수량을 선택해 배낭으로 인수한다. 창고 9m 이내·배낭 여유를 확인한다.
4. I → 장비에서 기존 장비를 Mk.2로 개조한다. 개체 ID와 장착 슬롯을 유지하며, 제작 탭에서 Mk.2 완제품을 별도로 만드는 것도 가능하다. 탐험복은 같은 화면의 영구 개조다.
5. B → 생산·개조에서 현장 설비·로봇을 선택해 공동 창고 부품으로 Mk.2 개조한다. 원정선은 기존 선박 정비 화면의 첫 개량에 같은 제품을 사용한다.

## 공통 제품 7종

정확한 원본은 `data/production_tier2.json`이다. 첫 상위 채집기 제작에 상위 채집기가 필요한 광물을 요구하지 않는다.

| 제품 | 한 작업의 입력 → 출력 | 기본 시간 | 소비처 |
| --- | --- | ---: | --- |
| 정제 철 | 철 4 → 2 | 4초 | 프레임·필터·열전달 유닛 |
| 정제 구리 | 구리 4 → 2 | 4초 | 회로·열전달 유닛·발전 설비 |
| 보강 프레임 | 정제 철 3 + 암석 2 → 1 | 6초 | 휴대 장비·탐험복·로봇·환경 설비·원정선 |
| 제어 회로 | 정제 구리 2 + 암석 2 → 1 | 6초 | 채집기·무기·제작소·배양기·로봇·원정선 |
| 광물 필터 | 정제 철 1 + 암석 4 → 2 | 5초 | 대기/급수 개조, 추가 독성·염류 처리 소모품 |
| 열전달 유닛 | 정제 구리 3 + 정제 철 1 → 1 | 7초 | 지형 변환기·탐험복·발전/충전/열 설비·원정선 |
| 토양 기반재 | 암석 4 + 얼음 2 → 2 | 5초 | 배양기 개조·토양 처리 소모품 |

제작소 한 대에서 제품 작업 하나를 실행한다. 로봇 제작·공학 시제품과 동시에 같은 제작소를 예약할 수 없다. 제작 중 철거·개조·계약 인계를 막는다. 예약 재료와 진행도는 저장되며, 반복 생산/다중 작업 대기열·배관·컨베이어는 이번 범위가 아니다.

창고는 원래 무제한 공용 재고라 수치만 올리는 가짜 개조를 추가하지 않았다. 기존 생물공학 개조는 별도 특화이며 Mk.2 성능과 함께 적용한다. 기존 고등급 소유 장비·로봇/선박 품질은 보존한다. 새 휴대 제작에서는 채집기 Mk.3을 숨기고 호스트도 제작을 거절한다. 기존 선박의 희귀 품질/고급 개량 경로를 삭제한 작업은 아니다.

## 2티어 지역 복원

새로 등록한 비태양계 T2 현장에만 `restoration2`를 만든다. 초기 염류 70, 토양 10에서 시작한다. Mk.2 급수 설비가 필터 1개당 염류 10, Mk.2 배양기가 기반재 1개당 토양 10을 6초 주기로 처리한다. 기본 배양·안정화·계약 정산에는 염류 ≤20, 토양 ≥60을 추가로 확인한다. 기본 기계를 늘려 이 별도 조건을 우회하지 못한다.

기존 계약과 T1 입문 목표에는 조건을 소급 추가하지 않는다. 현재 모든 신규 T2에 같은 두 조건을 주는 첫 구현이며 행성 계열별 오염 화학·배양종·P3~P5 복합 환경은 후속이다. 지표의 염류 색면이 줄고 토양색과 기존 생태 복원이 연결된다. 실제 유체 수질·유로·복합 생태계 구현을 의미하지 않는다.

## 저장·검증 범위

기존 사업/원정선 규칙 해시를 바꾸지 않고 선택 필드로 확장한다. 제품을 자원 사전과 재고 검증에 등록하고, 호스트의 기존 요청 순번·리비전·원자적 저장 경로로 예약/인수/개조한다. 장비·탐험복·시설·로봇 개조 등급, 제품 생산 진행도, 염류/토양 범위를 검증한다. 협동 콘텐츠 해시에는 새 생산 데이터를 포함한다. 이미 있던 계약의 환경 조건은 유지한다.

Godot 4.7.2 / Metal Forward+ 실제 창에서 `check_tier2_progression.gd`의 핵심 확인 29개 실패 0건: 원광 가공→공동 창고→배낭 인수→장비/탐험복 개조→설비/로봇/원정선 개량→염류/토양 처리→생태 진행→저장 복원. 기존 채집/건설 시간을 반복하지 않도록 원광 재고·지지되는 시설은 검증용 배치로 제공했다. 실제 시간 기준의 전체 밸런스 검증은 아니다.

화면 검토에서 소유 장비 개조 후 구형 이름이 남던 선택 상태를 수정했다. 작은 화면에서 제품 카드·화물 인수·Mk.2 장비 표시와 기존 ElevenLabs 생산 루프를 별도 최소 확인했다(6개 실패 0건). 실제 현장의 개조 팩과 전방 방향도 확인했다.
