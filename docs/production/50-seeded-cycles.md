# C16~C17 — 시드 천체 시간과 낮밤

소관 명세는 [천체 시간](../technical/08-seeded-planetary-cycles.md), 범위는 [C 커밋 계획](../planning/11-ground-commit-plan.md)을 따른다. 남은 구형 모델 재제작은 [별도 아트 후속](49-common-blender-art.md)으로 유지한다. 집중 성능 안정화도 이번 C 범위 밖이다.

## C16 — 데이터·계산·저장 경계

`planetary_cycles.json`의 버전 1 규칙을 새 세계의 생성 매니페스트에 고정한다. 항성 분광형에 맞는 질량·반경·광도, 물리 AU와 이심률, 케플러 공전 주기, 일반/동주기 자전, 지역 위도/경도와 초기 위상을 독립 시드로 계산한다. 천체 메타데이터는 `body.astro`로 조회하고 백만 행성의 레코드를 저장하지 않는다.

호스트가 이미 저장·공유하는 `crew.navigation.orbit_time`을 **활성 시뮬레이션 초**의 단일 원본으로 사용한다. 별도 복제 시계를 누적하지 않는다. 물리 시간은 이 값×60+기준 시각으로 평가하고 채집·생산 시간은 그대로 둔다. 대기실과 세션 종료 중에는 기존 호스트 물리 틱이 돌지 않아 시간이 진행하지 않는다. 개인 메뉴는 세계 시계를 중단하지 않는다.

C16에서는 `enabled=false`로 저장하여 기존 활성 공전과 하늘을 변경하지 않는다. 활성화는 C17에서 신규 세계에만 적용한다. 규칙이 없는 옛 저장은 `legacy_cycles` 취급하며 기존 궤도 위상과 속도를 유지하고 접속 매니페스트 검증도 이를 허용한다. 자동 이행으로 기존 행성·광맥·계약 주소를 바꾸지 않는다.

일반/동주기 생성과 별/태양의 같은 좌표 변환이 첫 범위다. 생성 행성의 3:2 공명·느린 역행 상태와 조석 진화는 후속이다. 태양계의 자전·기울기·궤도 수치는 NASA 자료를 참고한 근사값, 공전 주기는 항성 질량과 AU에서 유도한 `estimated`로 구분한다. 태양계 초기 위상은 시드이며 실시간 천체력/JPL Horizons 재현이 아니다. 태양계 착륙 금지는 유지한다.

[기본 태양계 자료](https://science.nasa.gov/learn/basics-of-space-flight/chapter1-2/) · [지구 자전·공전](https://science.nasa.gov/earth/facts/)를 2026-09-08 확인했다. 생성 항성 프로필·확률·시간 압축은 게임 기본안이다.

최소 실행: `./tools/godot.sh --headless --script res://tests/check_planetary_cycles.gd`. 동일 시드/저장 메타데이터, 지구의 평균 태양일, 동주기 태양 고정과 별 방향 변화, 오른손 좌표계, 첫 낮 면 경도, 기존 매니페스트 합류 호환을 확인한다. C17 화면 검수와 실제 연결은 아래에 기록한다.

## C17 — 현재 게임의 활성 경로

2026-09-08 신규 세계는 `enabled=true`로 생성한다. C16에서 생성한 비활성 매니페스트와 규칙이 없는 이전 저장은 기존 동작을 유지한다. 기존 세계를 자동 전환하거나 시간을 되감지 않는다.

- 우주 화면의 위치·자전, 항해의 접근/진입/착륙 위치, 지표의 태양 방향이 같은 `orbit_time`과 천체 계산을 사용한다. 물리 AU와 게임 공간은 분리한다. 압축된 궤도가 겹치지 않도록 표시 이심률을 인접 궤도 간격으로 제한하며 물리 주기·진근점이각·태양 방향은 유지한다.
- 첫 추천 후보는 일반 자전·평균 태양일 16~30시간·기울기 25° 이하·입문 일사 범위에서 선택한다. 첫 적격 착륙 때 낮 면의 경도를 한 번 선택해 `celestial_regions`에 저장한다. 재방문은 같은 지역을 사용한다.
- 지표의 태양 원반·직사광·그림자는 같은 방향이다. 별은 관성 좌표계를 자전/지역 좌표로 변환하고, 구름은 공유 시각에 따라 흐른다. 동주기는 낮/밤 면이 고정된다. 별의 운동까지 정지시키지 않는다.
- 하늘/환경광/안개 색은 태양 고도와 기존 지역 환경값을 함께 반영한다. 얇은 대기에서는 낮에도 어두운 하늘과 별이 보일 수 있다. 밤의 환경광은 해당 행성의 낮보다 밝아지지 않는다.
- 밤에는 탐험복 작업등과 가동 가능한 로버의 전조등 두 개가 켜진다. 작업등이 손에 든 도구를 과도하게 비추던 문제를 광원 대상 레이어로 수정했다. 기존 INK 윤곽선·3단 명암을 유지한다.
- 행성명 아래 기존 위치 표시 옆에 작은 태양/지평선 다이얼과 낮·황혼·밤·동주기 상태를 표시한다. 도움말에는 물리 하루와 플레이 시간을 구분한다. 전체 UI 재설계는 포함하지 않는다.
- 기존 ElevenLabs 황무지 바람/복원 자연 환경음을 재사용한다. 밤의 환경음은 기존 믹스에서 최대 2dB 낮추며 누적 감쇠하지 않는다. 메뉴의 음향 정지는 유지한다. 신규 음원 생성이나 새 음성은 없다.

표면 스냅샷은 저장한 지역 위도/경도를 전달하며 클라이언트는 공유 시각을 보간한다. 패킷이 멈췄을 때 화면만 계속 하루를 진행하지 않도록 최대 1초까지만 외삽한다. 채집·생산·연구·전력 생산량과 산업 시간에는 배율을 추가하지 않았다.

## 실제 확인과 재현

Godot 4.7.2 / Metal Forward+ / Apple M2의 실제 창에서 격리된 새 세계(시드 71491)를 생성하고 추천 행성에 착륙했다. 행성의 하루는 약 22.12시간, 플레이 약 22.12분이었다. 검수 도구가 공전 시각을 하루의 0/¼/½/¾ 지점으로 옮겼으며 실제 22분 대기를 측정한 것은 아니다.

- 실제 지표에서 태양 방향과 광원 일치, 낮/밤의 환경광·작업등, 960×640 화면, 로버의 두 전조등 연결을 확인했다.
- 환경음 스트림 재생과 메뉴 정지, 개인 메뉴 중 호스트 시계 진행, 실제 저장 후 지역/천체 위상 복원을 확인했다. 검수 모드만 백그라운드 창의 환경음 재생을 허용한다. 주관적인 청취 품질 재평가나 6인 음향 중첩 검사는 하지 않았다.
- 별도의 복원 대기 장면에서 태양 원반·주광/황혼/야간 하늘을 렌더링하고, 같은 시각에 따른 구름 오프셋과 별 좌표 변화·동주기 태양 고정을 확인했다. 이 장면의 환경값은 검수용이며 캠페인의 복원 완료를 뜻하지 않는다.
- 계산 검사에서 동일 시드/JSON 복원, 지구 태양일, 일반/동주기, 오른손 좌표계, 기존 규칙 없음/C16 비활성 저장, 새 공전 경로 일치와 재방문 지역 보존을 확인했다.
