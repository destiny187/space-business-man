# Q01~Q03 — 설정·현재 입력·산업 초안

2026-09-14 사용자 승인: [Q01~Q09 계획](../planning/17-existing-play-polish-plan.md)을 세 묶음으로 개발하고 순서대로 커밋한다. 첫 묶음은 Q01~Q03이다.

## 현재 변경

- 감도·음량 등 설정의 변경값만 적용한다. 새 노드는 등록 시 한 번 적용하고, 그래픽 등록 대상도 해당 필드만 처리한다. 물 품질이 같으면 메시를 다시 지정하지 않는다. 감도 드래그/연속 입력은 즉시 체감값에 반영하고 300ms 유휴 또는 닫기/종료 시 저장한다. 화면 변경은 기존 15초 복구와 별도로 저장한다.
- `play_input.json`의 맥락별 행동을 현재 지상·선내·비행·로버·관전 입력에 연결했다. 키 설정은 개인 설정 `input_version: 1`, `play_bindings`에 보존한다. 없는 항목은 기존 기본키를 쓰며 구형 원격 장면의 의미가 다른 키는 자동 이행하지 않는다. 같은 맥락 충돌·Esc/F10 예약을 검사한다. 기본 가이드·현장 조준 안내·슬롯·관전 안내가 매핑을 읽는다.
- 유지/전환 조준·지상 질주, 100/115/130% 글자/클릭 영역 확대를 추가했다. 메뉴·입력 차단에서 전환을 해제한다. 제트팩은 재입력 유지 규칙을 그대로 쓴다. 총기 표시가 FOV를 매 프레임 76으로 덮던 문제를 고쳤다.
- 산업 1초 진행은 운영 현장·공동 재정·조립/실험/보급 분기만 가변 초안으로 만든다. 생물 발견과 지형 이력을 다시 복사하지 않는다. 저장 제출 시 전체 검증·스레드 소유 사본·원자적 파일 확정은 유지한다.

## 실제 확인

Apple M2, Godot 4.7.2 Metal Forward+, 별도 기존 원정 사본, 1280×800 및 960×640에서 `check_polish_foundation.gd` 21항목을 확인했다. 감도 10회 변경의 그래픽 적용 0회·최종 쓰기 1회·재로드, 맥락 충돌·힌트, 전환 차단, FOV, 화면 취소/미확정 설정 저장 제외, 실제 현장 저장을 확인했다. 처음 확인에서 슬라이더 API 오류를 찾아 드래그 신호 추적으로 수정했으며 마지막 실행에는 스크립트 오류가 없다.

![960×640 키 설정 130%](media/181-keys-960.png)

운영 시설 12개가 있는 별도 저장으로 전체 사본과 부분 초안의 산업 진행 결과를 비교했다. 이전 상태를 읽기 전용으로 고정해 변경 누출도 확인했다. 이 실행의 초안 구성 시간은 전체 1,420µs / 부분 1,321µs였다. 무관한 지형 기록 10,000건을 추가한 **합성 규모 검사**에서는 전체 7,985µs / 부분 1,044µs였다. 후자는 자연 플레이의 프레임 시간이나 전체 저장 성능이 아니다.

`check_request_commit.gd`는 중복/대기 입력·저장 확정 중 이동 보존·실패 시 원상 보존/성공 미공개를 확인했다. 제출 4.716~4.941ms, 동기 쓰기 0회, 실패 0건이다. `check_firearm_transport.gd`도 로컬 ENet의 신뢰 발행/재전송 보호를 확인했다.

## 행동 범위와 남은 경계

개인 설정은 세계 revision·거래·네트워크를 만들지 않는다. 동일값은 적용과 쓰기를 생략한다. UI 배율 변경 자체는 보이는 화면과 숨은 기존 UI 글자를 함께 갱신하며, 감도에는 이 순회를 실행하지 않는다. 강제 종료 직전 300ms 안의 마지막 조정은 유실될 수 있다.

산업은 운영 현장의 실제 시간·공유 원장만 변경한다. 닫힌 생산 화면과 별개로 도메인은 계속 진행한다. 전체 저장 검증/복사·저장 확정 중 탄도 대기는 남아 있으며 평균 FPS/60fps 보장으로 해석하지 않는다. 사수별 한 건·0.8초 버퍼와 미응답 4건 제한은 변경하지 않았다.

키 조회/가이드 연결과 대표 화면을 확인했으며 모든 키 조합의 실물 키보드 주행·모든 대화창 배율·컨트롤러·Windows/6인 외부망은 전수 확인하지 않았다. 새 모델·음원을 제작하지 않았다.
