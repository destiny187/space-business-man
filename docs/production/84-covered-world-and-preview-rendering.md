# 가려진 선내 렌더 중단과 정적 미리보기 재사용

2026-09-09 사용자 승인: 외부 비행 영상 뒤 선내 장면의 중복 렌더와 정지한 모델 미리보기의 매 프레임 렌더를 줄인다. [백그라운드 갱신 최적화](83-background-update-and-save.md)의 후속이다.

## 적용

- 실제 프레임을 그리기 직전에 외부 비행 영상의 표시·지상/전환 상태를 확인한다. 외부 영상이 화면을 덮는 동안 메인 뷰포트의 3D 패스를 중단한다. 우주와 UI 미리보기의 독립 SubViewport, 물리/호스트 진행은 유지한다.
- 선내 시점 복귀·외부 영상 숨김·원정 종료 때 메인 3D를 복구한다. 착륙/이륙 전환 중에는 지상 준비 렌더와 카메라 인계를 위해 중단하지 않는다.
- 공통 장비/시설/선체 미리보기는 `UPDATE_ONCE`로 렌더한 이미지를 재사용한다. 모델 교체/비우기, 드래그 회전, 카메라 위치·크기/투영 변경, 표시·크기 변경 때만 갱신한다. 숨긴 상태의 변경은 다음 표시까지 보류한다.
- 같은 선체의 장착 모듈 교체와 탐험복 색상 변경도 명시적으로 새 렌더를 요청한다. 재질/자식 모델 변경을 추가하는 후속 코드는 `request_render()`를 호출한다. 매 프레임 전체 메시/재질을 순회하지 않는다.
- 정거장 교역의 선체 미리보기도 선택 변경·다시 열기 때만 갱신한다. 연구/신체 증강의 실제 모션은 연속 렌더를 명시하며 숨기면 멈춘다. 움직이는 행성 미리보기의 셰이더 시간 표현은 유지한다.

## 실제 확인

Apple M2 / Godot 4.7.2 Metal Forward+, 1280×800, 격리 저장에서 확인했다.

- 같은 외부 시점에서 뒤쪽 메인 3D를 잠시 켠 대조는 메인 뷰포트 그리기 호출 **12회**, 중단 시 **0회**였다. 전체 우주 렌더나 게임 전체 드로콜이 0이라는 의미가 아니다. 우주 선체/배경과 UI는 화면에 유지됐다.
- `check_render_reuse.gd`: 외부/선내 전환·종료 복구, 전환 중 메인 렌더 허용, 정적 대기 중 재렌더 중단, 드래그·카메라·크기 변경, 숨김 중 교체/다시 표시, 빈 선택의 이전 이미지 제거, 연구 모션 지속/숨김 중단. 이미지 바이트 변화와 렌더 요청 상태를 포함한 15개 확인 실패 0. [로그](media/render-reuse/play.txt).
- `check_preview_details.gd`: 정거장 선체의 정지·교체 후 실제 이미지 변화·숨김/복귀와 동일 선체의 모듈 장착 변경 후 갱신. 7개 확인 실패 0. [로그](media/render-reuse/previews.txt).
- 구문 검사와 `git diff --check`를 확인했다. 외부 비행/선내 복귀 캡처를 직접 검수했다. 모델·음원·INK 품질 설정과 실제 사용자 저장은 변경하지 않았다.
