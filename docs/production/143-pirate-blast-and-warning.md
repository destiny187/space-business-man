# 해적 격파 폭발과 카툰풍 조우 경고음

2026-09-12. 사용자는 이전 폭발이 어색하고 품질이 부족하다고 지적하고 해적 조우에 별도 경고음을 요청했다. 이어 위협음도 **카툰풍 게임에 맞춰야 한다**고 정정했다. [해적 전투 소관](../game/28-pirate-interdiction.md)의 표현을 변경했으며 이전 [141 영상](141-pirate-combat-quality.md)은 변경 전 기록이다.

[변경한 실제 전투 영상](media/pirate-explosion/flight-combat.mp4) · [게임에서 녹음한 조우음](media/pirate-explosion/contact-in-game.wav)

## 실제 변경

- 저분할 구체 열 개와 고정 토러스 링을 제거했다. 0.16초의 불규칙한 별 모양 섬광 뒤에 세 단계의 따뜻한 색면을 가진 플라스마가 펼쳐진다. 방향·크기·시차가 다른 다섯 분출과 22개의 가는 잔광이 퍼지고, 열이 식으면서 투명하게 흩어진다. 밝은 구체가 여러 개 떠 있는 표현을 사용하지 않는다.
- 추진 고장 중의 구형 불꽃도 작은 분출과 얇은 불꽃 꼬리로 교체했다. 기존 1.1초 무력화 회전 후 폭발 시점과 호스트의 격파/인양 판정은 유지한다.
- 파편은 기존 Blender 선체·날개 메시와 INK 재질을 재사용한다. 각 부품의 실제 중심으로 회전축을 옮겨 공통 원점을 중심으로 빙빙 도는 현상을 줄였다. 최대 16개 부품이 관성을 유지하고 약 2.3~3.2초에 사라진다.
- 전용 `combat_blast.gdshader`의 투명 쿼드 효과다. 새 선박 모델·래스터 이미지·Blender 모델을 제작한 작업은 아니다. 불투명 파편의 기존 INK 재질과 전투 조명을 유지하며 화면 전체의 번쩍임·새 카메라 흔들림을 추가하지 않았다.
- 조우는 `sfx_pirate_contact_warning`을 사용한다. 처음 만든 거친 금속 경보안은 채택하지 않고 ElevenLabs에서 카툰풍 전자음을 다시 생성했다. 두 번째 테이크의 탄력 있는 시작음을 편집해 **0.96초, 세 번의 짧은 펄스**로 구성했다. 게임 파일은 48kHz 모노 WAV, 선형 피크 0.63이며 기존 항성 위험음과 별도다. 원본·설정·편집 방법은 [음원 이력](../../audio/manifests/pirate-contact-warning.json)에 보존한다.
- 항해 상태의 `combat_active`가 켜지면 재생 중이거나 대기 중인 항성계 진입음을 취소한다. 차단 상태에서는 새로운 진입음도 예약하지 않는다. 교전 종료 후 취소했던 진입음을 뒤늦게 재생하지 않는다.
- 조우 ID별 첫 경고 상태에 한 번 재생한다. 첫 스냅샷에서 사건 이력이 생략되어도 진행 중인 접근 경고를 들을 수 있다. 메뉴는 경고음을 중단하며 같은 조우에서 다시 울리지 않는다. 새 내부 비행 조우에는 새 경고음이 울린다.

첫 위험 안내 외 설명과 구분자 점을 추가하지 않았다. 기존 선박 교신은 자막으로 유지하며 음성 대사를 새로 만든 것은 아니다.

## 확인한 범위

- 현재 `crew_expedition.tscn`을 Metal Forward+에서 실행했다. 호스트 사격으로 움직이는 추격기를 격파하고 새 폭발·부품 파편의 시간 흐름을 1280×800 실제 화면과 확대 이미지로 확인했다.
- `render_pirate_explosion.gd`의 마지막 실행은 13개 확인, 실패 0이다. 저장된 접근 경고에서 전용음 재생, 진입음/대기열 취소, 실제 격파, 메뉴 중 효과/경고음 정지, 같은 경고 재진입 시 중복 방지, 새 내부 조우의 재생을 확인했다. 로그는 `output/pirate-explosion/movie-final.log`다.
- 첫 렌더는 초기 로딩이 기존 검수용 55초 제한을 넘어서 종료됐다. 검수 스크립트의 로딩 제한만 늘린 후 실제 장면 진입과 최종 출력을 확인했다. 실패한 실행을 통과로 세지 않았다.
- 영상은 자동 조종 입력과 Godot Movie Maker의 고정 60fps 렌더이며 실시간 성능 측정이 아니다. 영상 음원은 실제 게임 믹스이고 새 경고음 구간도 따로 추출했다. 원본 WAV 네 후보와 편집본의 길이·파형/피크를 비교했다.

개인별 최종 청감 평가, 실제 마우스 손맛, 6인 원격 재접속/믹스, 여러 기체의 동시 격파 및 전 시드 검수는 이번 범위가 아니다. 기존 지상전·일반 항성 위험음·항해 밸런스는 변경하지 않았다.
