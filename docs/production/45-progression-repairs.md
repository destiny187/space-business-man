# 자연 진행 차단 복구·초반 철과 얼음 — 2026-09-07

[플레이 테스트](44-natural-progression-playtest.md)에서 확인한 문제에 대한 사용자 수정 요청을 적용했다. 사용자 저장을 덮어쓰지 않았고, 테스트는 별도 복사본에서 진행했다.

## 수정

- 착륙선 근처 F는 **착륙선 단말**을 연다. 환경·계약 탭에서 정산을 확인하고, 착륙선 탭의 탑승 버튼을 누르면 기존 전원 탑승·자동 이륙 흐름으로 진행한다. F 자체가 곧바로 이륙하던 진입 누락을 복구했다.
- F 창고의 양쪽 드래그 격자는 유지한다. 상단 **보급·로봇 관리**를 누르면 기존 창고 보급·로봇 회수/재파견 화면으로 전환한다. 추가 건설 창고에서는 해당 창고의 시설 관리도 접근한다. 창고 거리·공동 자금·호스트 권한·회수 조건은 계속 호스트가 검사한다.
- 작은 화면에서 상단 관리 버튼을 창고 선택과 같은 줄에 배치했다. 관리창의 중복 재고 요약을 숨기고 로봇 미리보기 높이를 조절하여 960×640에서도 보급/회수/재파견 실행 버튼이 들어오게 했다.
- 토대가 없는 지표 광맥이나 냉각 전 고온 광맥의 로봇 배정을 요청 단계에서 거절한다. 기존 작업 목표를 바꾸지 않는다. 지형 경로 전체를 사전 보장하는 기능을 추가한 것은 아니며, 이후 지형 변경·장애물에 따른 경로 상태는 기존 로봇 규칙을 따른다.

## 철·얼음 배치

사용자 확정: 초반 행성에서 필수 철·얼음을 확보하기 쉽게 한다. 이번 구현은 **착륙 가능한 생성 T1·T2 행성에서 시작 자원 보장**을 선택했다. 세부 수량/좌표는 조정 가능한 구현값이다. 소관 규칙은 [광물·강화](../game/14-minerals-gems-and-enhancement.md#2026-09-07--초반-철얼음-확보)다.

기존 철 400·구리 320·암석 400 광맥에 철 400과 얼음 400을 추가한다. 추가 광맥은 착륙지 기준 약 20m, 착륙선 기준 약 25m 이내의 평탄한 구역에 둔다. 해당 구역의 기존 철과 합치면 철은 800이다. Mk.1부터 채집할 수 있고, 주 지질 자원 분포는 유지한다. 고티어에 새 얼음/추가 철을 일괄 지급하지 않으며 태양계 착륙 제한도 유지한다.

원본은 `data/landing_resources.json`, 신규 ID는 `landing:iron:reserve`, `landing:ice`다. 기존 ID의 좌표·매장량·잔량을 덮어쓰지 않는다. 기존 현장에도 신규 ID만 나타나고 이후 고갈량을 저장한다. 협동 콘텐츠 해시에 해당 데이터를 추가하여 다른 버전의 시작 광맥을 사용하는 클라이언트 합류를 막는다. 저장 규칙 해시는 바꾸지 않아 기존 세계를 그대로 읽는다.

## 실제 확인

- Godot 4.7.2 / Metal Forward+ 창에서 `tests/check_progression_repairs.gd`로 관련 검사 **29개 실패 0**: 기존 저장 열기 → 신규 얼음 모델·실제 채집과 잔량 → 기존 고갈량 보존 → 창고 입출고 → 관리창 → 얼음 구매/100 Cr 차감 → 같은 ID 로봇 재파견/회수 → 부적합 배정 거절 → 실제 F 입력으로 단말 → 정산 확인/6,000 Cr 지급 → 탑승/이륙 → 저장 읽기.
- 이전 테스트에서 재료로 성장한 복원 완료 저장을 입력으로 사용했다. 새로 게임을 시작해 수동으로 전체 성장 시간을 다시 플레이한 것은 아니다. `--crew-ui-test --crew-folder=...`에 분리된 세계/프로필 복사본이 필요하다.
- 8개 초반 착륙 가능 표본과 문제를 재현했던 기존 행성에서 새 위치의 토대를 확인했다. T3 제외 분기를 확인했다. 모든 은하 시드의 전수 검사는 아니다.
- 기존 Blender 광맥·로봇 모델과 INK 렌더를 재사용해 실제 표시를 확인했다. 기존 ElevenLabs 실패 피드백 연결을 확인했다. 새 모델·음원은 생성하지 않았고 음향 전수 청취·다중 클라이언트·전체 회귀는 하지 않았다.
- 마지막 작은 화면 수정은 `--repair-layout-only`로 별도 재렌더 후 직접 검토했다. 로그는 `test-results/progression-repairs/`에 보존한다.
