# 토착 생물의 지상 교전 — 첫 연결

**후속 변경:** 아래는 첫 근접 연결 당시의 기록이다. 같은 날 승인된 실제 돌진·도약·지면 범위·연속 베기와 변경된 시간/피해는 [138 제작 기록](138-native-ground-attack-patterns.md)이 우선한다. 아래의 “한 공격 한 번 피해”·“전투용 점프 미구현”은 첫 버전의 경계다.

2026-09-12 사용자 승인: 토착 생명체와 실제로 교전할 수 있어야 하며 선공하는 종도 포함한다. 총기 기반에 이어 일반 지상 생물부터 개발한다. [전투 소관](../game/27-ground-and-flight-combat.md)의 비행 교전·추가 사건과 구분한다.

## 현재 연결한 범위

활성 토착 지상 동물에 선공·영역 방어·피격 반격·도주 성향을 부여한다. 공격 가능한 종 중 시드 해시 구간은 선공 24%, 영역 방어 48%, 반격 28%다. 이는 초기 배정 규칙이며 행성에 출현하는 생물의 24%가 반드시 선공한다는 뜻이 아니다. 원산 행성·서식 조건·배치와 외형 변이는 기존 배정을 유지한다. 공격 동작이 없는 종은 피격 시 도주하며 이식/휴면·비행·대기 생물은 이 지상 AI에 포함하지 않는다.

공격 연결 대상은 기존 지상 공격형 225종과 8체형 56종, 기본형 281개다. 새로운 종을 추가하거나 8,000종 전체를 적으로 바꾸지 않았다. 56종은 개형·고양이형·악어형·사슴형·소(牛)형·코뿔소형·전갈형·사마귀형의 기존 Blender 관절과 골격을 재사용한다. 턱·목·앞다리·집게·낫팔을 움직이며, 조직 스키닝과 각 관절의 원래 연결 축을 보존한다. 소리나 몸 전체 이동만으로 전용 관절 동작을 대신하지 않는다.

## 실제 교전 흐름

선공형은 시야 안 14m, 영역형은 6.5m에서 경고한다. 먼저 1.2초 동안 경고 자세와 울음을 보여 주고 접근한다. 매 공격의 준비가 시작될 때 방향을 고정하며 실제 타격 구간에서 거리·높이·정면 각도·지형/물리 장애물·제작한 엄폐물을 확인한다. 한 공격은 한 번만 피해를 준다. 플레이어는 옆으로 피하거나 사거리 밖으로 물러나고 엄폐 뒤에서 재장전할 수 있다. 공격은 기존 개인 실드→체력·구조 보호 규칙을 이용한다.

이동은 현재 서식 층의 지형과 몸의 공간을 확인하고, 막힌 정면 옆의 짧은 우회 방향을 찾는다. 서식 중심 24m 밖으로 추격하지 않으며 막힌 시야가 9초 지속되면 복귀한다. 착륙선 주변 22m와 구조 보호 중 승무원에게 선공하지 않는다. 시설이나 방벽을 자동 파괴하지 않는다. 원거리 길 찾기·무리 포위·전투용 점프까지 구현한 것은 아니다.

피격 시 0.28초 경직과 반응을 보이고, 경직 재발동은 3.2초 간격으로 제한한다. 도주형과 체력 22% 미만의 비선공형은 거리를 벌린다. 교전 중인 생물을 Q로 즉시 수납하는 우회는 막고, 기존 스캔·무력화 후 표본 수납 경로를 유지한다. 동물에게 총기 전리품을 새로 배정하지 않는다.

## 호스트·저장·표현

`FrontierWildlifeCombat`가 0.1초 간격으로 결정·위치·공격 시각·피해를 확정한다. 후보/지면 캐시는 파생값이며 근처 참가자의 실제 원산 종만 선택한다. 선택 필드 `crew.wildlife_encounters`는 최대 96개다. 상태는 기존 총기와 같은 2초 체크포인트에 함께 저장하며 저장 오류 시 기존 세션 정지 경로를 따른다. 체력·무력화 위치는 기존 `combat`/`wildlife_stops`와 호환한다. 재실행/재접속 시 미완료 공격은 취소하고 현재 위치에서 복귀한다.

장비 명중·스캔·렌더가 같은 교전 위치를 참조한다. 총의 생물 조준은 중심점 대신 광선과 표적 구의 앞면을 사용해 실제 충돌체 앞에서 탄이 잘리는 경우도 맞게 판정한다. 이전 배회 코드의 진행 방향과 Blender 동물의 +Z 정면이 반대였던 부분을 교전/배회에서 바로잡았다.

FINCH 독립 출동은 행성별 대상·지형·제작 엄폐 공간을 사용한다. 호스트의 원격 행성에는 교전 개체의 경량 충돌체를 연결했다. 메뉴로 입력이 막힌 근처 참가자만 남아 있을 때는 개체 상태를 보존해 멈추며, 오프라인 메뉴를 여닫는 것으로 위치가 초기화되지 않는다. 실제 6인 인터넷 플레이는 이번에 실행하지 않았다.

## 모델·음원·확인

기존 Blender 원본과 GLB를 재사용했다. 새 메시/종/원본 리깅을 제작했다고 기록하지 않는다. Godot Forward+에서 8체형과 기존 차기/내려치기 대표 2종의 공격 준비·타격 20장을 렌더해 관절·실루엣·접지·효과를 확인했다. [대표 모음](media/native-combat/combat-motion-board.jpg), [촬영 기록](media/native-combat/render-records.json).

ElevenLabs에서 경고·타격·피격 3종을 새로 생성했다. 경고 1.2초, 타격 0.85초, 피격 0.65초로 편집했으며 준비는 경고 음원의 높은 피치, 무력화는 피격 음원의 낮은 피치를 재사용한다. 원본·실제 프롬프트·생성 조건은 [`native-combat-sources.json`](../../audio/manifests/native-combat-sources.json), 편집·해시는 [`native-combat.json`](../../audio/manifests/native-combat.json)에 보존한다. 생물 명중에는 금속 피격음 대신 생물 반응을 사용한다. 메뉴/비활성 창에서 교전 음원을 정지한다. 종마다 별도 울음 281개를 생성한 것은 아니다.

규칙 검사 24개, 실제 Forward+ 플레이 확인 14개에서 실패 0. 시드 71503의 실제 원산 행성 305183에 배정된 `biota_lobopod_siphons_25`를 찾아 착륙했다. 선공→경고→추격→공격·체력 피해→총기 대응→무력화·저장/재로드를 확인했다. 규칙 확인에는 공격 1회 판정, 옆으로 회피, 지형/실물 방벽 차단, 실드 우선 피해, 비선공/도주 성향, 표본 수납 우회 방지, 입력 차단 시 상태 보존이 포함된다. 전체 회귀·6인 실기는 실행하지 않았다.

실제 렌더에서 등을 보인 채 이동하는 축 오류를 발견해 +Z 정면으로 수정했다. 메뉴/입력 차단 때 교전 기록이 지워지던 경로는 상태를 보존해 일시정지하도록 수정했다. 자동 실행의 창 포커스 조건은 기존 `test_mode`와 일치시켰고, 일반 실행에서 포커스가 없는 창의 음원 차단은 유지한다.

재현 명령:

```sh
./tools/godot.sh --headless --script res://tests/check_wildlife_combat.gd
./tools/godot.sh --script res://tests/check_wildlife_combat.gd -- --crew-ui-test --crew-folder=/tmp/native-combat-play --play
./tools/godot.sh --script res://tests/render_wildlife_combat.gd
```

위 플레이 확인은 `/tmp/native-combat-play`의 전용 세계/프로필을 사용한다. 사용자 저장이나 실행 중이던 게임 프로세스를 교체하지 않았다.

## 남은 범위

- 전체 생물의 공격 확대, 수중/비행 교전, 독액 발사체, 약점·부위 손상, 군집 AI, 장거리 경로 탐색.
- 기존 생물 사건의 거대/둥지 개체를 일반 교전 AI와 통합하는 작업 및 신규 전투 사건.
- 플라스마의 생물 대상 광역 2차 피해(현재 직접 명중은 적용), 종별 드롭/사체 자원, 고티어 전투 밸런스.
- 종별 전용 음원, 모든 281종의 수작업 동작 검수, 원격 다중 클라이언트 실기.
