# T3 설비 준비와 첫 생산 경로

2026-09-10. 사용자가 [T3 획득·묶음 생산·운영 보급](105-tier3-blueprints-and-supply.md)의 다음 작업 진행을 요청했다. 설치 전 준비 안내와 대표 수급 경로를 연결했다. 설계 가격·레시피·생성 규칙·복원 대금은 유지한다.

## 설치 전 준비 화면

Tab → 테라포밍 → 보급 계획에서 **설비 준비 · T3**를 선택한다. 기존 **가동 보급 · 5분**과 전환할 수 있다.

- 설계 6종의 모델 카드와 공동 사용권/가격·기록고 획득 경로를 표시한다. 신축, Mk.1부터 개조, Mk.2부터 개조 중 출발 단계를 고른다. 유입원 제어 장치는 신축만 표시한다.
- 지도에서 선택한 위치의 현장 창고만 반영한다. 완제품과 중간 부품을 먼저 사용하고 한 묶음에서 남는 수량을 후속 공정에 반영하여 추가 원료를 계산한다.
- 원료는 아이콘·수량·최소 채집기 등급으로, 중간 제품은 가공 순서·묶음 수·완성 수량·최소 제작소 단계로 표시한다. 합금 프레임/저온 셀은 필요한 현지 지질과 직접 운송을 명시한다.
- 보유 생산 거점은 해당 지질의 후보로 표시한다. 실제 제작소 설치 여부와 전력은 현장에서 확인한다. 거점이 없으면 복원 계약 또는 별도 생산 이용권 경로를 안내한다.
- 새 세계의 기초 광맥 누락 규칙을 반영한다. 대표 저온 행성처럼 구리가 생략된 경우 **직접 반입 · Lotus 보급**으로 표시한다. 현지 분포 후보라는 표시는 발견·채집 완료나 잔량 보장이 아니다.

`production_plan.gd`는 현재 카탈로그·개조 비용·생산 레시피를 읽는 조회 전용 계산이다. 저장·재고·제작 예약을 변경하지 않는다. 한 설비의 재료 견적이며 발전기·창고·선행 제작소는 각각 마련한다. 선박·배낭·다른 현장 재고를 자동 합산하거나 이동시키지 않는다. 신규 바이너리 모델/음원 없이 기존 INK 미리보기·자원 아이콘·UI를 재사용했다.

## 대표 경제 경로

현재 레시피에서 **Mk.2 제작소 → Mk.3**의 직접 비용은 산업 코어 1개·강화 프레임 2개다. 초기 부품 재고가 없을 때 이를 풀면 다음 원료가 필요하다. 발전·창고·Mk.2 제작소·채집기 준비 비용은 이 표에 포함하지 않는다.

| 원료 | 수량 |
| --- | ---: |
| 철 | 24 |
| 구리 | 16 |
| 암석 | 12 |
| 얼음 | 24 |
| 니켈 | 16 |
| 티타늄 | 8 |
| 리튬 | 12 |

공정 중 금속 가공 행성에서 합금 프레임 2개, 저온 가공 행성에서 저온 셀 2개를 만든다. 한 곳으로 운반하여 제어 회로 2개와 산업 코어로 조립한다. 티타늄에 필요한 Mk.2 채집기는 기초 가공품으로 직접 제작·장착할 수 있어 산업 코어가 선행하지 않는다. 기존 장비 개조를 선택하면 선박 증강 장치의 접근 조건을 따른다.

시드 **71503**, 행성 ordinal **17(금속)**·**11(저온)**의 대표 경로를 실행했다.

1. 새 원정 기본 자금·Lotus 출항 지급품에서 시작하고 정거장에서 제작소 설계도 1개를 구매했다.
2. 금속 거점 이용권을 구매하고 창고·태양광·제작소를 실제 재료로 건설했다. Mk.2 제작소와 Mk.2 채집기를 마련한 뒤 실제 광맥에서 티타늄·니켈을 채집하고 합금 프레임 2개를 제작했다.
3. 저온 행성의 기초 구리 광맥 누락을 확인했다. 그곳의 창고·발전·제작소 신축과 Mk.3까지의 가공에 필요한 구리 **45개**를 선적했다. 합금 프레임도 현장 창고 → 배낭 → 공동 선박으로 옮겼다.
4. 저온 거점 이용권·세 시설을 마련하고 저온 셀 2개를 생산했다. 운반한 합금 프레임을 현장에 입고하고 산업 코어를 조립하여 첫 Mk.3 제작소를 설치했다.

구매 비용은 **설계도 1,200 + 생산 이용권 500 × 2 = 2,200 Cr**, 남은 공동 자금은 **3,800 Cr**이었다. 가격이나 원료를 검사 중 보충하지 않았다. 출항 지급품 외 실제 추가 채집량은 철 168·구리 28·암석 80·니켈 16·티타늄 8·리튬 12개였다. 묶음 생산으로 남는 재고는 그대로 보존했다. 이 경로에서 원료 부족은 행성 간 직접 운송으로 해결했으며 Lotus 유료 보급은 사용하지 않았다.

모든 설계도를 한 번에 구매하면 5,400 Cr이고 두 생산 이용권까지 더하면 6,400 Cr이다. 따라서 최초 6,000 Cr으로 전부 선구매하는 흐름을 기본 경로로 잡지 않는다. 위 검사는 첫 제작소 설계부터 선택적으로 확보하는 경로의 성립을 확인한 것이며, 전체 복원 사업의 수익성이 확정됐다는 뜻은 아니다. 추가 설계는 현재 문제에 맞춰 구매하거나 기록고를 복원하고 계약 대금을 재투자한다.

## 확인과 남은 범위

- `audit_t3_material_route.gd`: 호스트 명령 165회로 채집·비용 차감·실물 입출고·생산 예약·개조·저장을 확인했다. 원료/시설/설계도/전력을 주입하지 않았고 다른 거점 창고가 암묵적으로 차감되지 않음을 확인했다. 전력·토대 판정을 포함한 산업 tick으로 공정을 완료했다.
- 행성 도착·도보 좌표와 생산 시간 진행은 검사에서 제어했다. 공정 진행 누적 183초는 채집·이동·위험 대응 시간을 제외한 시뮬레이션 값이며 실제 플레이 소요 시간이 아니다. 비행 연료·왕복 시간·생존/전투·FINCH 운송을 이 검사에서 검증한 것으로 기록하지 않는다.
- `check_t3_preparation_play.gd`의 실제 Forward+ 게임 창 확인 8항목이 통과했다. 1280×800·960×640 선택/스크롤·기존 가동 보급 복귀, 조회 시 재고 불변과 누락 광물 반입 안내를 확인했다. 대표 화면은 아래에 둔다.
- 원료부터 **행성 복원 계약 전체 정산**까지의 수동 완주, 모든 시드·6인 협동·Windows 실기·경제 최종 균형은 남아 있다. 이번 작업은 첫 T3 생산 진입의 재료·운송 경로와 설치 전 안내를 완료했다.
