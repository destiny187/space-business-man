# 전진 중심 비행과 적 기체 선회

2026-09-13 사용자 승인: 전진 중심 전투와 Q/E 회전으로 변경하고 적 기체도 같은 방식으로 이동한다. 규칙의 단일 소관은 [비행·해적 전투](../game/28-pirate-interdiction.md)다.

## 첫 튜토리얼 후속

같은 날 사용자가 첫 튜토리얼에 안내만 추가한 뒤 커밋하도록 요청했다. 기존 첫 세 카드에 전진 가감속·키를 놓을 때 속도 유지·Q/E 롤, Shift/Space·감속 선회·Alt 정밀 전후진, 화성 주시 스캔과 F 궤도 작업을 나누어 안내한다. 별도 연습 단계·통과 조건·네트워크 요청·진행 저장 필드는 추가하지 않았다. 대기 관측 완료 후 다음 신호 안내에 남아 있던 E 표기도 F로 맞췄다.

기존 안내 카드와 Label을 재사용하며 표시만으로 선체 모델·세계 revision을 바꾸지 않는 것을 확인했다. 별도 저장의 현재 원정 장면·Metal Forward+·960×640 창에서 세 카드의 실제 문구·화면 경계, 메뉴에서 숨김, 정상 종료의 8개 최소 확인을 통과했다. 화면과 로그는 `output/forward-flight/tutorial/`, `output/forward-flight/tutorial-preview.log`에 두었다. 안내의 표시 확인이며 직접 키보드 조작·항해 전체 검사를 다시 실행한 것은 아니다.

## 구현

- 원정선·FINCH의 W/S는 전진 가속·정지까지 감속이다. 키를 놓으면 현재 속도를 유지한다. Shift만으로 전진 부스트를 시작하며 Space는 제동한다. Alt+W/S는 정밀 전후진으로 제한한다.
- Q/E는 실제 선체의 롤이다. 마우스·A/D는 회전한 기체의 축을 따라 선회하며 상하 회전의 극점 제한을 없앴다. 고속에서는 선회가 완만하고 저속에서는 빠르다. 카메라·포구·미사일 발사 위치·외부 운반 화물도 해당 자세를 따른다.
- 궤도의 기업 조사·대기 관측·화물 작업은 F 유지로 옮겼다. 행성 접근·도킹·전투 잔해 인양은 F의 현재 대상을 사용한다. 조사 대상이 있는 같은 입력으로 항로까지 출발하지 않도록 우선순위를 통일했다. 지상 E/Q/F는 유지한다.
- 추격기 2척·미사일함 1척은 기수를 제한된 속도로 돌린 뒤 그 방향으로 전진한다. 감속 조준·전방 발사·측면 통과·이탈·재접근을 연결했다. 미사일함은 더 넓게 선회한다. 장애물/플레이어를 피하는 방향을 먼저 찾고, 막히면 정지 후 선회한다. 위치를 밀어내는 보정과 방향에 무관한 횡이동을 제거했다. 공격 준비 중 장애물로 이탈하면 충전 표시도 해제한다.
- 메뉴·창 포커스 상실·끊긴 입력은 회전/무장을 끄고 제동한다. 기존 입력 배열의 앞 일곱 항목을 유지하고 롤·제동·정밀 조작을 뒤에 추가했다. 새 열 항목에서도 미사일 입력이 처리되도록 길이 판정을 수정했다.

`flight_experience.json`의 초기 조정값은 롤 1.8rad/s, 저속/고속 선회 배율 1.45/0.65, 정밀 전진 35m/s·후진 18m/s다. 적의 가감속·회전·사격각·통과 간격은 `space_combat.json`에서 조정한다. 확정 밸런스나 장시간 교전 결과가 아니다.

기존 Blender 선체·노즐·무장과 INK 재질, ElevenLabs 추진/자세 제어·함포·미사일 음원을 재사용한다. 새 3D 모델이나 음원을 생성하지 않았다. 회전용 노즐을 기존 모델로 배치하고 실제 회전량에 따라 양쪽 추진 입자와 자세 제어음을 연결했다.

## 기존 저장과 공동 처리

항해 상태에 선택적인 `up` 축을 추가한다. 해당 축이 없는 저장은 기존 수평 기준으로 읽으며 이후 조종·저장부터 실제 자세를 유지한다. 성간 출발 때도 초기 자세를 읽어 출발 정렬을 이어간다. 예전 후진 속도는 일반 조작에 복귀하면 정지시킨다. 기존 `interdictor`·기동 기록을 읽을 수 있게 유지한다. 해적이 없던 구 저장을 소급 활성화하지 않으며 화물·개인 장비·소유 선박·은하 배정을 바꾸지 않는다.

입력과 적 이동은 호스트가 결정한다. 입력 범위·유효 시간·중복 순서 검사를 유지한다. 원정선과 독립 FINCH 모두 같은 조종 함수를 사용한다. 원격 다중 클라이언트·재접속 화면은 이번에 실행하지 않았다.

조사 완료의 기존 세계 전체 깊은 복사를 제거했다. 저장 전 전체 유효성 검사와 원자적 파일 교체, 기존 주기의 공동 스냅숏·체크포인트 비용은 남는다. 얕은 맵 복사는 해당 맵 항목 수에 비례하며 대기 관측의 기존 이름 이행/발견 번호 조회도 전체 관측/이름 기록을 살핀다. 산업 등 이번 변경과 무관한 정기 전체 초안 비용을 해결한 것으로 기록하지 않는다.

1280×800과 960×640의 전투 화면을 렌더해 확인했다. 원정선 펄스와 플레이어 미사일은 실제 입력 처리로 발사하고, 적 기동은 원래 호스트 AI를 사용했다. 전투 중 적 위치·방향·속도 표본은 `output/forward-flight/play/enemy-motion.json`에 남겼다. 최종 로그는 같은 폴더 상위의 `forward4.log`, `maneuvers5.log`, `surveys-scope5.log`, `live-host3.log`다.

현재 Mac이 잠겨 있어 창 포커스를 받아 실제 키를 누르는 검사는 수행하지 못했다. 포커스 없는 조작 차단은 실제로 확인했고, 렌더 검사는 테스트에서 호스트 입력을 보내 진행했다. 운영체제 잠금이나 게임의 일반 입력 차단을 해제하지 않았다. 음원 스트림/재생 연결은 확인했으나 직접 청감·원격 6인·Windows·장시간 밸런스는 미확인이다.

기존 광범위 조사 검사는 현재 fixture와 맞지 않아 완료 수에 넣지 않았다. `check_corporate_traces.gd`는 고정 항성계 702에 흔적이 없고, `check_freight_salvage.gd`는 시작 연출이 남은 fixture의 항해 step 뒤 진행 항목 참조에서 중단됐다. 변경한 세 완료 경로와 저장 경계는 별도 집중 검사로 확인했다. 기존 검사 파일을 삭제하거나 전체 묶음으로 확대하지 않았다.
