# 무기 드롭·옵션·속성 공격 첫 구현

2026-09-14 사용자 후속 승인: “이전에 설계는 했는데 반영은 안되었던것 같아 진행해줄래?”에 따라 [무기 드롭 소관](../game/29-weapon-loot-and-elements.md)의 현재 T1~T3 첫 묶음을 게임에 연결했다. 이 문서는 실제 범위와 확인 기록이며 T4/T5 총기·계승까지 완료했다는 뜻은 아니다.

## 실제 바뀐 플레이

- 기존 9계열·17개 정의의 기술 티어와 드롭 등급을 분리했다. 일반/매직(초록)/고급(파랑)/희귀(보라)/전설(황금), 새 옵션 수 0/1/2/3/3+전용 효과를 사용한다. 전설은 최초 네 전용 계열에서 추첨한다.
- 새 사건은 생성 때 총기 유무·정의·등급·속성·옵션값·전설을 확정해 저장한다. 현장의 실제 모델/짧은 등급 표식과 F 회수, 아이템 카드/회전 모델/속성 아이콘/옵션 표시로 연결했다. 회수 후 자동 장착하지 않는다.
- 휴대 제작에서 물리/열/냉기/전격/부식을 선택하고 추가 재료를 낸다. 일반 제작품은 옵션 없이 같은 속성 공격을 사용한다. 기존 6종 탄약을 공유하며 새 유한 탄약 총기는 빈 탄창으로 지급한다.
- 피해·약점·재장전·반동·정조준·탄창·교체·상태 축적/지속·레이저 열/냉각·탄속 중 계열/속성에 유효한 옵션만 고른다. 직접 피해와 약점 옵션의 중복을 차단한다. 새 등급 자체에 구형 고정 배율을 다시 곱하지 않는다.
- 상세에서 실제 개체 옵션, 전설 조건, 일반 체력 대상 직접 피해/장전 포함 지속 DPS, 탄창/장전, 현재 총과의 차이를 표시한다. 열 지속 피해와 전설 추가 피해는 기본 DPS에 더하지 않는다. 작은 화면에서는 속성/옵션을 기본 지표보다 먼저 표시하며 나머지는 세로 스크롤로 읽는다.
- 잠금과 확인창을 거치는 분해를 제공한다. 장착/잠금 중 분해를 막고 부품·장전된 실탄/예약탄을 수납할 수 있을 때만 무기를 소모한다. 기존 8칸 기본 배낭과 증강 확장 규칙을 사용한다.

## 다섯 속성과 전설 네 종

속성/옵션/전설/드롭 확률/분해량은 `data/weapon_loot.json`을 공유한다. 수치는 첫 실행값이며 장기 밸런스 확정이 아니다.

| 속성 | 실제 판정 |
| --- | --- |
| 물리 | 기존 직접 피해 |
| 열 | 직접 피해 0.9배, 체력 명중 축적 후 3초 연소. 장전 포함 기반 DPS의 10%/초 |
| 냉기 | 직접 피해 0.9배, 체력 명중 축적 후 2초 일반 이동 감속. 생물 20%, 로봇 10% |
| 전격 | 실드 1.25배, 체력 0.9배. 넘친 피해에 실드 배율을 다시 적용하지 않음 |
| 부식 | 실드 0.9배, 로봇 체력 1.2배, 일반 생물 체력 1배 |

축적은 발사 간격/탄립 수로 정규화하고 실드만 맞히면 쌓이지 않는다. 호스트가 최대 256개 표적의 상태를 0.25초 간격으로 처리한다. 같은 표적의 연소는 가장 강한 것 하나만 피해를 주고 기여자/남은 시간은 저장한다. 비활성 행성·접속자가 없는 곳에서 상태와 피해를 진행하지 않는다. 냉기는 원본 이동속도를 바꾸지 않고 유효한 동안 일반 이동에 곱한다. 공격 돌진/준비/모션 시간을 재조정하지 않는다.

| 전설 | 계열 / 속성 | 실제 효과 |
| --- | --- | --- |
| 잔화 | 카빈 / 열 | 자신의 연소가 남은 적을 직접 격파하면 가까운 한 대상에 짧게 전이. 전이된 연소의 재전이 금지 |
| 쇄빙 | 산탄총 / 냉기 | 자기 냉각이 남은 적에 12m 안에서 같은 사격의 탄립 4개가 맞으면 냉각을 소모하고 파쇄 |
| 도약 전류 | 기관단총 / 전격 | 같은 적에 2초 안에 서로 다른 사격 3회 명중 시 주변 최대 두 대상에 도약 |
| 천공 | 저격총 / 물리 | 약점 명중 후 같은 직선 뒤쪽 한 대상에 추가 관통 |

전이는 거리·지형·방벽·호스트 장애물 판정을 사용한다. 추가 피해는 일반 옵션 축적/전설을 다시 발동시키지 않는다. 종별 별도 내성 프로필은 아직 배정하지 않았고 첫 판정은 실드/로봇 체력/일반 생물의 구분이다. 수중·가스행성 교전이나 PvP를 추가하지 않았다.

## 자산·표현·사운드

- `tools/build_legendary_weapons.py`가 기존 Blender 총기 원본에서 열 방열부·냉각 탱크·전류 코일·관통 레일을 제작한다. 네 `.blend`와 네 `.glb`를 보존하고 `Anim_Bolt`/`Anim_Magazine`을 유지했다. [자산 매니페스트](../../art/blender/equipment/legendary_weapons.json)를 사용한다.
- Blender Cycles 네 장과 Godot Forward+ INK 네 장, 투명 미리보기 네 장을 생성했다. 실제 원정에서 네 전설 손 모델과 가동부 연결을 확인했다. 기존 모델 전체를 교체한 작업은 아니다.
- 등급 테두리와 다른 모양의 속성 SVG 다섯 개를 분리했다. 발사/명중/전이의 색은 실제 호스트 결과의 속성을 따른다. 연소 틱은 기존 피해 표시/접촉 효과로 보이며 표적을 덮는 상시 큰 파티클을 추가하지 않았다.
- 기존 ElevenLabs 계열별 사격/재장전 음원을 재사용한다. 네 사격 ID의 실제 재생과 SFX 버스 녹음 11.605초, 비영 샘플을 확인했다. [재사용/해시/측정 기록](../../audio/manifests/weapon-loot-reuse.json)을 남겼다. 새 속성별 음원 생성이나 직접 청감 평가를 했다고 기록하지 않는다.

## 기존 저장과 행동 범위

`loadout.weapon_rolls`의 새 `roll_version=2`와 `loot_pool_version=3`을 사용한다. 구형 무기는 기존 피해/재장전 배율, ID/탄약/슬롯을 유지하며 새 옵션이나 전설 효과를 소급 추첨하지 않는다. 표시 등급명만 대응하고 상세에 구형 효과를 표시한다. 이미 생성된 구 풀 사건과 기존 확정 장비 보상도 보존한다. 새 사건의 `gun_reward_v2`는 완성 결과를 저장하며 로드 시 실제 옵션/계열/전설 조합을 검증한다. 활동형 구조 미션이 만드는 사건도 월드 시드를 전달한다.

| 행동 | 추적한 변경·처리 범위 |
| --- | --- |
| 제작/잠금/분해 | 해당 승무원·배낭·영수증의 기존 국소 거래 초안을 사용. 관련 없는 지형/사건 분기는 읽기 공유하고 변경하지 않음 |
| F 회수 | 해당 사건의 확정 보상과 회수자만 변경. 일반 사건의 기존 보수적 전체 거래 초안/검증 비용은 남아 있음 |
| 발사/전설 | 기존 탄도 큐의 사수 상태·실제 표적·가까운 후보만 변경. 추가 타격에 총알이나 전설을 재귀 생성하지 않음 |
| 상태 틱 | 저장된 표적 최대 256개와 접속자 행성만 순회. 기존 전투 결과 발행/체크포인트에 합류하며 매 틱 파일 저장을 추가하지 않음 |
| 상세/슬롯 | 옵션·소유 목록 변경 시 갱신. 열린 아이템 목록의 변경 키에서 매 프레임 무기 대기 상태를 제외. 닫힌 목록은 재구성하지 않음 |

만석 회수 실패는 보상과 소유품을 보존한다. 잠금 초안의 미확정 변경이 원본에 새지 않는 것, 분해 재전송이 기존 영수증을 반환하는 것을 확인했다. 새 저장의 검증/직렬화와 기존 정기 체크포인트 전체 복사는 유지되며 성능 비용을 없앴다고 주장하지 않는다. 다수 비활성 행성의 상태도 저장 상한에 포함되고 상한 도달 시 새 상태 축적은 생략된다.

## 실제 확인

기존 격리 원정 검수 픽스처를 사용했다. 사용자의 실제 저장은 열거나 변경하지 않았다. 전체 회귀/6인 장시간 검사는 실행하지 않았다.

| 좁은 확인 | 결과 |
| --- | --- |
| `check_weapon_loot.gd` | 29개 통과. 다섯 등급/결정적 옵션·구형 성능·실탄 용량·실드 넘침·열/냉각 만료·호스트 제작/잠금/분해/중복 |
| `check_weapon_legendaries.gd` | 15개 통과. 네 실제 피해 경로에서 발동·추가 대상 피해/전이 제한·확정 보상 |
| `review_weapon_loot.gd` 실제 Forward+ | 29개 통과. 현재 지상 원정·네 모델/가동부/사격/음원·F 전리품/정확한 옵션·메뉴 차단·저장 |
| 같은 검수의 `--ui-only` 후속 | 8개 통과. 1280/960 화면 재확인, 속성 선택의 실제 가시 범위, 저장 재읽기 시 옵션/전설/탄 수 동일 |
| `check_weapon_boundaries.gd` | 11개 통과. 국소 초안·만석 보존·보상 검증·오프라인 상태 정지·전이 장애물 |

최초 분해 중복 검사에서 테스트가 원래 요청과 다른 revision으로 재전송해 실패했다. 원래 revision으로 수정해 영수증 재사용을 확인했으며 게임의 중복 검증을 완화하지 않았다. UI 후속 검사 스크립트의 저장 읽기 함수명을 실제 `read_state()`로 수정한 뒤 실행했다. 960px에서 옵션/속성 선택이 기본 통계 밑으로 밀리던 실제 표시 문제는 순서/밀도를 수정하고 위 화면으로 재확인했다.

로그는 로컬 `output/weapon-loot/`, 실제 검수 저장/원음 녹음은 `/tmp/weapon-loot-play-20260914/`, 대표 렌더는 이 문서의 `media/weapon-loot/`에 둔다. [검수 집계](media/weapon-loot/verification.json)는 실제 결과와 경로를 보존한다.

## 남은 범위

- 현재 총기 정의는 T1~T3이다. W04의 T4/T5 기반총/제작, 추가 전설 두 종, 지정 옵션 정밀 제작·계승은 후속 설계다.
- 현재 무기 유입은 기존 사건 전리품과 일반 제작이다. `cache/elite` 가중치는 연결했고 `general` 표는 미래 유입원용 데이터다. 무기 지급 여부 65%와 등급별 가중치는 장기 플레이로 조정하지 않았다.
- 속성별 적 도감 내성, 전설 발견 도감, 독립 등급/속성 정렬, 두 모델의 나란한 비교와 별도 상태 종료 효과/신규 속성 음원은 미구현이다. 현재 이름/등급/속성 검색, 단일 회전 모델과 현재 무기 수치 차이를 제공한다.
- 6인 실기/외부망·모든 생물·장시간 드롭 경제 검수는 하지 않았다. 호스트 처리·저장 재개·중복 요청의 좁은 확인과 구분한다.
