# 특이 식물·미생물 100종과 전체 기본형 1,000개

2026-09-10. 사용자 요청에 따라 식물·미생물 기본형을 합쳐 100개 추가했다. 제작 배분은 식물 60개·미생물 군락 40개다. 확정 방향과 티어별 표시 후보 확률의 소관은 [발견·연구·생태](../game/09-discovery-research-and-ecology.md), 이름·구조·환경은 [100종 목록](../game/25-xenoflora-catalogue.md)이다.

![20개 구조군 대표](media/xenoflora/overview.jpg)

## 실제 제작과 연결

| 범주 | 이전 | 추가 | 현재 기본형 |
| --- | ---: | ---: | ---: |
| 동물 | 700 | 0 | 700 |
| 식물 | 125 | 60 | 185 |
| 미생물 | 75 | 40 | 115 |
| 전체 | 900 | 100 | 1,000 |

12개 식물 구조군과 8개 미생물 군락 구조군에 각각 5개의 형태 레시피를 만들었다. 기관 수·갈래·연결·배치·비율이 다른 별도 Blender 기본형 100개이며, 단순한 색·전체 크기 변이는 이 수량에 세지 않는다. 새로운 외형 프로필은 기본형당 20개, 합계 2,000개이며 전체 외형 프로필은 20,000개다. 미생물 모델은 육안으로 보이는 군락·생물막이다. 단일 세포를 인간 크기로 확대하거나 실제 발견된 생물이라고 설정하지 않는다.

반전환엽·현수근낭·나선배상·대향막경·격자화방·현수종등·접선관엽·공낭연경·빗살촉엽·환공차광·분지권엽·중첩개협 식물, 흡관 모자이크·기포 뗏막·천공 첨탑·유로 장미·편조 생물막·다낭 광막·투공 망막·층상 파문 군락이다. 현무암·건조·한랭·동굴·온대·결정·열수 환경에 나뉜다.

- 제작 레시피: `tools/bestiary/xenoflora_roster.py`, Blender 제작: `tools/build_xenoflora.py`.
- 원본: `art/blender/xenoflora/*.blend` 100개와 각 제작 기록 JSON.
- 게임: `우주-비즈니스/assets/models/xenoflora/`의 near/far GLB 200개.
- 카탈로그: `data/bestiary/xenoflora_forms.json`, `xenoflora_appearances.json`, `xenoflora_recipes.json`.
- 모델·LOD·INK 재질: 기존 `render_assets.json`에 신규 100개만 등록하고 식물의 foliage 처리를 연결했다.
- 도감: 100개 실제 렌더 이미지와 기존 회전 모델·스캔·표본·연구 경로를 사용한다.

공통 Blender 곡면·열린 컵·막·식물 잎·생물막과 INK 재질/출력 도구를 재사용한다. 원본을 보존하고 게임용 모델을 내보낸다. 검수 중 떠 보이는 잎·꽃과 씨방 지지부를 발견해 빗살 줄기·나선 줄기의 잎 부착 위치·격자 꽃받침·종꽃 가지·고리 꽃·말린 잎·겹씨방의 연결을 보정했다. 보정한 기본형만 다시 출력·렌더했다. 최종 삼각형 범위와 자산 해시는 [자산 확인](media/xenoflora/asset-verification.json) 및 `media/xenoflora/render-records/`에 둔다.

## 자연 출현과 저장 호환

새 은하 manifest에 `flora_catalog_hash`를 추가한다. 기존 600개 선택 풀과 앞선 동물 확장의 900개 선택 풀은 유지하고, 이 표지가 있는 새 은하만 1,000개 풀을 사용한다. 현재 전체 도감 카탈로그는 1,000개를 읽으며 기존 저장의 계통·자연 배치를 소급 재추첨하지 않는다. 협동 콘텐츠 해시에도 새 카탈로그를 포함한다.

기원 가중치·티어별 동물 계통 수·근처 표시 상한은 이번 작업에서 바꾸지 않았다. 식물·미생물의 환경별 1계통을 데이터 필드로 드러냈으며, 예전 저장에 해당 필드가 없으면 동일한 1계통을 사용한다. 모델 수 증가와 생물권 행성 비율 증가를 구분한다. 티어별 수치·휴면체 표시·셀 후보 비중은 [생태 소관](../game/09-discovery-research-and-ecology.md)과 [산출 기록](media/xenoflora/probabilities.json)을 따른다.

기존 유기체 상태 동작을 새 컬렉션에도 연결해 잎·막·군락의 흔들림과 수축을 표현한다. idle/move/feed/dormant/stressed의 기존 상태 및 두 LOD를 유지한다. 새 자유 이동 AI나 종별 독립 대사 시뮬레이션을 구현했다는 뜻은 아니다.

## 확인한 범위

- Blender에서 원본 100개·GLB 200개를 제작했다. Cycles로 각 구조군의 첫째·다섯째 기본형, 총 40개 원본을 렌더했다.
- Godot 4.7.2 Forward+ / Metal에서 기본형 100개를 실제 INK 렌더했다. near/far와 다섯 상태의 관절 연결을 확인하고 구조군 대표의 상태·그늘·역광을 출력했다. 100종 비교판과 보정 후 대표 모델을 직접 확인했다. [자산 기록](media/xenoflora/asset-verification.json).
- `tests/check_xenoflora.gd`: 수량·고유 모델/이름·군락 표현·20,000개 외형·900개 저장 선택 풀 보존·새 자연 배치·스캔/표본·JSON 저장을 대상으로 151개 확인, 실패 없음. [규칙 기록](media/xenoflora/rules-check.json).
- `tests/check_xenoflora_play.gd`: 시드 71491의 T1 행성 8에서 자연 선택된 **삼등뿌리수**와 **겹문망막군**을 확인했다. 플레이어 접근 위치를 준비하고 실제 원정 장면에서 모델·두 LOD·동작·E 스캔·J 검색/도감·Q 실물 표본·두 범주 저장/재개를 검사했다. 960×640 도감과 메뉴 중 도구 차단을 포함해 29개 확인, 실패 없음. 생물을 강제로 추가하거나 기후를 바꾸지 않았다. 일반 첫 원정 전체를 수동 완주한 검사는 아니다. [현장 기록](media/xenoflora/play-check.json).
- 기존 ElevenLabs 조사·표본 획득 효과음을 실제 호스트 결과에 연결해 재생 이벤트와 SFX 버스 출력을 확인했다. 새 음원을 생성하지 않았으며 원본 생성 정보·프롬프트·해시는 [재사용 기록](../../audio/manifests/xenoflora-reuse.json)에 보존한다.
