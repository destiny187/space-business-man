# T1~T3 자유 배치와 테라포밍 분포 탭

2026-09-09. 사용자가 [자유 배치 기획](../planning/15-free-placement-terraforming.md)을 승인하고 **대기·수질·토양·오염원을 모두 테라포밍 탭에서 시각화하며 T3까지 개발**하도록 요청했다. 이 기록은 고정 지역 방식 이후의 구현이다. 탐험 발견·설계도 획득/판매는 별도 작업으로 유지한다.

## 실제 변경

- 새 세계 `regional_rules` v3의 T1~T3는 고정 복원 포인트·5개 목표 구획을 사용하지 않는다. 시설 좌표를 기준으로 지표의 24m 환경 셀을 만들고 실제 신규 개선·환경 조건·유지 시간을 만족한 면적을 합산한다. 셀 중심 위에 건설할 필요는 없다.
- 공장·창고는 필요에 따라 지원 지표 범위 안에서 자유롭게 건설한다. 이전 거점 65m 건설 제한을 이 버전에서 제거했다. 현장 지지·시설/광맥/선박 통로와 근접 건설 조건은 유지한다.
- 기존 생산·전력·재고 처리는 512m 공급 구획으로 분리해 유지한다. 이는 복원 목표가 아니다. 가까운 창고 입출고는 해당 창고, 생산·개조 요청은 해당 시설의 공급 구획을 사용한다. 멀리 있는 재고를 자동 차감하지 않는다. 구획 경계에서도 대상 시설과 창고를 사용할 수 있다.
- 물·열·토양·생태의 실제 처리 예산을 도달 셀에 나누어 적용한다. 물/토양의 주기형 재료는 설비 단위로 한 번 소비한 뒤 처리량을 분배해, 특정 셀만 반복 선택되는 현상을 피했다. 현재 면적 단위에 맞춘 처리량 계수는 데이터에 둔다.

### 시설별 규칙

| 대상 | 현재 동작 |
| --- | --- |
| 대기 | 구면의 64×32개 동일 면적 권역에 산소·기압·독성을 저장한다. 설비가 설치된 권역을 처리하고 인접 권역과 유한량을 교환한다. 같은 거점 추가 설비는 처리량에 기여하며 반대편이 즉시 개선되지 않는다. |
| 수질 | 자연 지형의 주변 96m 네 방향 대비 낮은 입지에 최대 ×1.75 급수 산출 효율을 적용한다. 원료 얼음은 실제 소비하고, 다른 유역으로 자동 물류를 제공하지 않는다. 기존 실제 설비 외곽의 완전 침수 판정에 따라 가동·소모품 소비가 정지하며 물이 빠지면 재평가한다. |
| 토양·배양 | 같은 셀에서는 가동 가능한 가장 강한 배양 설비 하나만 담당한다. 동일 설비를 포개어 속도/면적을 늘릴 수 없다. 남는 능력은 자기 범위의 다른 셀에 배분하고, 완료된 토양은 재배치해도 남는다. |
| T3 오염 | 반응성 가스 또는 산성 수질의 시드 오염 구역을 둔다. 해당 전문 기능은 설비 기준점이 구역 안에 있을 때만 작동한다. 외부 설비의 반경만 걸쳐서는 처리하지 못한다. 내부에서도 전력·정격·실제 처리 팩이 필요하다. |

오염 작업 구역은 반경 120m의 고정 설치 자격 경계이며, 그 안의 잔류량은 실제 처리로 변한다. 정화로 시설의 설치 자격이 갑자기 사라지지 않는다. 제어 장치는 현재 반경 160m 안의 잔류 처리와 유입 억제를 맡고, 수질/가스 Mk.3는 자기 범위의 전문 정화를 한다. 이는 설치 한 번으로 즉시 완료되는 효과가 아니다. 구역 내부의 정확한 위치와 설비 개수는 정하지 않는다.

기존 T3 제품 7종·시설 기능 5종·설계도 사용권 6개를 재사용한다. Mk.3 생태 설비의 기초 배양 수분과 선구종 팩은 서로 다른 잔여 연료 시간을 사용해 다른 소모품으로 바뀌지 않는다. 전문 대기/수질 설비도 구역 밖에서는 일반 기능을 사용할 수 있지만, 해당 오염 전문 기능은 무효라고 표시한다.

## 지도와 현장 표현

Tab 행성 화면의 **행성지도 / 테라포밍** 탭을 전환한다. 테라포밍에서 대기·수질·토양·오염원 버튼을 선택하면 **회전 가능한 구체와 현장 확대 지도**가 함께 바뀐다. 구체는 드래그 회전, 지도는 드래그 이동과 휠 확대, 클릭한 지점의 상태는 하단 수치로 확인한다.

- 대기 구체는 현재 적합도와 위경도 선을 보여 주고, 선택 지점의 산소·기압·독성을 표시한다.
- 수질 지도는 현재 급수/염류와 저지대 이점을 구분한다. 아직 계산하지 않은 미래 수위를 확정 예측하지 않는다.
- 토양 지도는 실제 개량 상태, 생태/선구종 정착 상태와 처리 범위를 보여 준다.
- 오염 지도는 보라색 작업 구역 경계와 주황색 잔류 오염을 따로 표시한다. 구역으로 이동해 볼 수 있으며 현재 억제율·오염 목표도 확인한다.
- 실제 Blender 건설 고스트에 지형을 따라가는 영향 범위와 입지 안내를 붙였다. 수질은 효율·설비 상단/기준 해수면과 침수 중단을, 토양은 중첩 후보와 단일 효과를, 제어 장치는 구역 내부/외부를 표시한다.
- 지표 셰이더는 희소 환경 셀의 텍스처를 읽는다. 이전 20개 복원 점 배열 한도에 새 셀을 억지로 넣지 않는다. 현장 대기 샘플·지표 복원·지도는 같은 호스트 원장을 참조한다.

**구체는 게임의 환경 분포 도식**이다. 지원 지표 x를 경도, z를 위도의 사인 값에 대응시키는 동일 면적 주소를 명시적으로 사용한다. 실제 천체 반지름의 실측 축척이나 자유 구면 보행을 구현했다는 뜻은 아니다. 지표 동서 끝에서 캐릭터를 순간 이동시키지 않으며 대기의 구면 경도 연결만 순환한다. 구체의 대기는 시드 초기 상태와 실제 처리 결과이고, 수질/토양/오염의 밝은 표시에는 실제 현장 기록이 반영된다. 초기 지표와 완료된 땅을 구분하며 전 행성을 복원 완료로 칠하지 않는다.

## 면적·보상·저장

현재 조정값은 `data/regional_terraforming.json.free_placement`에 저장한다. 신규 계약의 수치 스냅샷이 세계와 함께 보존된다.

| 티어 | 유효 복원 면적 | 유지 | 공간 변화 |
| --- | --- | --- | --- |
| T1 | 2,304m² | 30초 | 물·열·배양 반경 32m, 작은 기지 주변 복원 |
| T2 | 27,648m² | 30초 | 지표 설비 반경 64m, 한 설비 묶음의 면적만으로 완료 불가 |
| T3 | 55,296m² | 45초 | 분산 생활권 면적 + 구역 내부 전문 정화·유입 억제 + 선구종 정착 |

평가하는 유효 면적은 도달 원의 합이 아니라 실제 환경/토양/급수/생태 조건을 만족하고 안정 시간을 유지한 셀의 합이다. 처음부터 좋은 땅은 실제 개선이 일어나기 전에는 신규 성과로 세지 않는다. T3는 생활권이 좋아도 오염 구역 잔류 평균이 8을 넘거나 90% 이상 유입 억제를 45초 유지하지 못하면 정산하지 못한다. 전 행성 면적의 완료가 아니라 지원 지표에서 조성한 생활권 사업이다.

30%·65% 면적 단계에서 각각 총 계약금의 20%를 한 번 지급하고, 최종 정산에서 기지급액을 차감한다. 시설 철거·재설치나 재오염으로 같은 단계를 다시 지급하지 않는다. 협동 사업량은 기존의 처리 대상 부피 계수로 한 번 적용하며 면적에 다시 중복 곱하지 않는다. 부재중에는 기존 호스트 세션 산업 시간만 사용한다.

기존 세계·진행 중 계약은 소급 전환하지 않는다. 지역 v1/v2는 종전의 지역 목표로 유지하며, 구 검사 스크립트도 해당 규칙을 고정한 이행 확인용으로 보존했다. v3는 공급 구획·셀 상태·구면 대기·실제 재료와 단계 지급을 저장하고, 오염 장부의 `초기량 + 유입량 − 제거량 = 현재량`을 확인한다.

## 제작과 확인 범위

새 시설 모델이나 음원을 추가하지 않고 기존 Blender 본체·Mk.3 모듈·가동부와 ElevenLabs 작업 루프를 재사용했다. 구체/지도/영향선은 게임 UI의 데이터 시각화다. 기존 모델의 현장 연결은 실제 Forward+ 창에서 확인한다.

- `check_free_terraform.gd`: 수질형과 가스형 각각 자유 위치 건설·독립 재고·오염 내부/외부·토양 중복·구면 교환·JSON 보존, 실제 정화/선구종/안정/단계 지급·최종 정산을 확인한다. 전체 사업 사례의 기후·시설·재고는 검수 준비 데이터다. 정상 플레이의 채집/운송부터의 경제 완주 시간으로 해석하지 않는다.
- `check_free_terraform_play.gd`: 실제 착륙·현장 스트리밍, 호스트 P3 생산·Mk.3 개조, Blender 모듈/가동부·ElevenLabs 작업 루프, 네 시각화 레이어·작은 화면·건설 영향 표시·전체 저장을 확인한다.
- `check_free_intro.gd`: 별도 준비 조건의 T1/T2 면적·토양/생태/유지 동작과 새 저장을 확인한다.
- 실제 종료에서 발견한 레이더의 빈 세션 접근은 세션/배우 존재 확인으로 수정했다.

최종 수질형·가스형 검사 각각 30개, T1/T2 검사 7개, 실제 창 검사 12개가 실패 없이 완료됐다. 준비된 T3 사례는 두 유형 모두 시뮬레이션 264초에 완료했으며 정상 플레이 시간 목표가 아니다. [확인 기록](media/free-terraforming/verification.json). 아직 수동 채집부터의 경제 밸런스 완주, 모든 시드의 최적 입지, 대형 기지의 장시간 성능, 6인 원거리 협동·Windows 실기까지 확인한 것은 아니다. 자동 물류·자연 유역의 물량 전달·T4/T5 정격/전 행성 완료 판정은 이번 T3 완료 범위에 포함하지 않는다.
