# 강화에 따른 탐험복 외장과 부위별 염색 기반

2026-09-09 사용자 요청: 기존 디자인·리깅을 유지하면서 강화할수록 멋져지는 실제 부품을 추가하고, 추후 파츠별 염색이 가능하게 준비한다.

## 구현

- 기존 `surveyor_suit.blend`의 39개 기본 메시와 13개 뼈대를 보존하고 별도 `art/blender/crew/surveyor_augmented.blend`를 제작했다. `tools/build_suit_augmentation.py`는 공통 Blender 제작 도구·재질을 재사용한다. 편집 가능한 부품 원본을 먼저 저장하고 내보내기 복사본만 16개 메시로 묶는다.
- 기동: 정강이 보호판, 부츠, 측면 피스톤, 허벅지·무릎 보호대, 종아리 동력 커버. 전투: 팔 보호대, 어깨 보강, 액추에이터, 상완 커버, 어깨 코어·손등 보호판. 생존: 가슴 코어, 흉부 보호판, 배낭·복부 보강, 목 보호대, 흉부 외골격·배낭 척추 커버.
- 계열별 5단계가 누적되는 15개 외장 묶음이다. 기존 관절에 스킨 가중치를 연결하며 관절 사이를 딱딱한 부품으로 묶지 않는다. 기존 절차적 동작과 충돌체를 유지한다.
- `data/suit_appearance.json`의 각 계열 4개 능력에 투자한 단계 합계를 사용한다. 현재 외장 문턱은 1/4/8/12/16이며 조정 가능한 구현값이다. 외장에 별도 비용이나 능력치를 추가하지 않는다. 이전 저장도 기존 증강 수치에서 외형을 계산한다.
- 호스트 확정 스냅샷으로 실제 승무원과 I → 신체 미리보기, 증강 장치의 모델을 갱신한다. 강화 트리의 생성 일러스트는 유지한다. 기존 1인칭에서 자기 몸을 숨기는 규칙은 유지한다.
- 헬멧·흉부·팔·다리·배낭·벨트의 주색/보조색/포인트색 총 18개 `DYE::<part>::<channel>` 재질을 분리했다. 기존 캐릭터 개인 색상은 보조색으로 유지한다. `FrontierSuitAppearance.set_dye`와 `sync`로 인스턴스별 변경할 수 있어 다른 승무원에게 색이 번지지 않는다.
- **염색 메뉴·염료 경제·색상 저장·네트워크 요청은 아직 구현하지 않았다.** 이번 범위는 실제 파츠별 재질과 로컬 적용 API 준비다. 팔·다리는 좌우를 같은 도색 그룹으로 다룬다. 코어의 계열별 발광색과 금속/고무는 도색 영역에서 제외한다.

## 실제 확인

Blender 5.2.1 Cycles로 굽힌 다리와 외장을 렌더했다. Godot 4.7.2 Metal Forward+에서 기본/5단계 비교, 대기·걷기·달리기·점프·수영·물에 뜨기, 6부위 염색(배낭 후면)을 렌더했다. 13개 뼈대, 15개 표시 그룹, 18개 독립 도색 재질을 확인했다. 전체 자산은 58,032 삼각형·66개 표면이며 잠긴 외장은 숨긴다. 6인 동시 성능은 측정하지 않았다.

격리 실제 앱 검사 `tests/check_suit_augmentation.gd`는 7개 확인을 통과했다. 장치에서 사파이어를 사용한 실제 구매 직후 기동 외장만 추가되고, I 신체 미리보기와 일치한다. 최대 단계 fixture·1280/960 화면·저장/로드에서 같은 외형이 파생되는 것을 확인했다. 첫 실행의 최대 단계 검사는 구매 전에 잡아 둔 오래된 fixture 사전을 수정해서 실패했으며, 현재 호스트 사전을 다시 가져와 수정한 뒤 해당 검사만 재실행했다. 게임 데이터 처리의 오류는 아니었다. 다중 클라이언트 전체 회귀 검사는 실행하지 않았다.
