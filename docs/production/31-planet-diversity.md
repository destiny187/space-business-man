# 행성 외형·복합 지질·초기 환경

## 확정 요구와 적용

2026-09-07 사용자 요청: 같은 종류의 행성에도 Blender 외형과 색상 변형을 제공한다. 자원 조합, 원래 존재하는 물, 양호하거나 나쁜 대기를 행성 특징으로 삼는다. 가스 행성은 움직이는 대기 효과로 구분한다. 추가 요청으로 불타는 행성을 냉각하여 내부 자원을 얻는 진행을 연결한다.

기본 5종을 유지하고 종류별 3개, 총 15개 외형 계열을 사용한다. [데이터](../../우주-비즈니스/data/planet_diversity.json)가 이름·색상·환경·지질·지형 진폭의 원본이다. 수치는 초기 밸런스다.

| 기본 종류 | 외형 계열 |
| --- | --- |
| 암석형 | 산화 사막, 습윤 대륙, 충돌 고원 |
| 빙하 암석형 | 균열 빙원, 해빙 툰드라, 극저온 설원 |

| 얼음 거대행성 | 청색 폭풍대, 청록 구름대, 보랏빛 극대기 |

## 생성과 연결

- 외형 계열을 시드로 선택하고 제한된 범위에서 흙·암석 색조, 밝기, 수자원, 기압, 온도, 지형 진폭을 변형한다. 같은 데이터로 우주 표면의 팔레트·바다 판정·구름량, 지표 재질·하늘·안개, 새 개발 사업의 초기 환경을 구성한다. 새 은하의 생태 원형 온도·기압·수분도 같은 값을 사용한다. 기존 생태 저장은 보존한다.
- Blender는 구형 암석의 굴곡·충돌구·균열과 거대행성의 편평도를 제작한다. 원본 15개와 GLB 15개를 보존한다. 정점 마스크를 게임 셰이더에서 사용하고 공통 INK 명암을 적용한다. 생성 스크립트는 `tools/build_planet_variants.py`, 출처·메시 비용은 `art/blender/planet-variants/manifest.json`이다.
- 지질 프로필은 기존 8개에 얼음 퇴적 분지·빙저 화산층을 추가한 10개다. 주 지질과 같은 기본 종류의 보조 지질을 섞어 보조 광물과 보석 후보를 확장한다. 모든 광물을 모든 행성에 넣지는 않는다. 기존 티어별 특이 소재 제한을 유지한다.
- 수자원은 환경 지표이며 실제 구면 해양 면적 백분율이 아니다. 따뜻하고 수자원이 있는 새 행성은 시작 구역 밖의 낮은 분지에 물 표면을 표시한다. 착륙 지점과 기존 시작 동굴의 안전 구조는 유지한다.
- 가스 행성은 위도별 이동 속도가 다른 구름 띠, 회전하는 폭풍 무늬와 국소 섬광을 사용한다. 착륙 불가 규칙과 태양계 보호 규칙을 유지한다.
- 스캔 홀로그램은 외형 계열, 수자원·대기 특징 또는 고온 광맥 안내를 표시한다.

## 불타는 행성의 냉각

불타는 화산은 약 320°C에서 시작한다. 이 값은 게임 환경 지표이며 실제 용암 온도를 재현한 수치가 아니다. 지표 균열과 궤도상의 용암 무늬를 발광시킨다.

현재 기후 조절탑의 전력·기술·제작 비용과 냉각 처리를 사용한다. 개발 구역 안이 80°C 이하가 되면 2티어 이상 광맥이 드러나고 수동 채광·로봇 채광이 가능하다. 냉각 중 지표 발광이 줄며, 구역 밖은 뜨거운 상태를 유지한다. 기본 광물은 설비 준비를 위해 채집 가능하게 둔다. 지하 광맥은 냉각 후에도 실제 굴착·노출 조건을 충족해야 한다. 자원을 새로 추첨하는 것이 아니라 시드에 이미 정해진 광맥을 해금한다.

## 저장·협동

새 은하는 `planet_rules`와 광물 규칙 v2를 매니페스트에 저장한다. 선택 후보를 정렬하여 JSON 저장 순서 변화가 결과를 바꾸지 않도록 한다. 지표 메시 작업자·호스트 지형 판정·광물 접지·운반 로봇 경로에 같은 지형 특성을 전달한다. 협동 콘텐츠 서명에 외형 규칙을 포함한다.

기존 은하는 새 외형을 사용하되 기존 지형 좌표와 저장된 사업 환경·광맥 규칙을 보존한다. 새 지형과 복합 광물 규칙은 새 은하에서 적용된다. 기존 은하에서 앞으로 등록하는 사업은 행성 특성의 초기 환경을 받는다. 이미 개발한 지역의 온도를 강제로 바꾸지 않는다.

## 범위의 한계

- 우주와 지표는 색상·환경·지질 계열을 공유한다. 구면 대륙의 특정 위경도와 착륙 지역을 정확히 대응시키는 구형 지리·해안 스트리밍은 아직 아니다.
- 자연 수면은 시각 표현이다. 수영·유체 이동·자연수 직접 채취·동굴 침수 시뮬레이션을 추가하지 않았다.
- 냉각은 현재 한 개발 구역의 환경 시스템이다. 행성 전체 냉각이나 여러 구역의 독립적인 열 확산은 후속이다. 구역 냉각이 궤도상의 행성 전체 발광을 끄지는 않는다.
- 연소 화학·불 끄기 무기·행성 지표의 별도 열 피해는 추가하지 않았다. 기존 기후 조절탑의 동작·음원 연결을 사용하며 신규 효과음은 생성하지 않았다.
- 새로운 15개 외형의 별도 저해상도 LOD는 미제작이다. 태양계의 기존 LOD는 유지한다.

## 지표 자연물과 평지 확장 — 설계 제안

2026-09-07 사용자 피드백: 지면이 매끈하고 행성의 개성이 약하므로 행성 특징에 맞는 디자인용 자갈 등 자연물을 정의하고, 행성별 차이를 유지하면서 부족한 평지를 늘리는 방향을 검토한다. 아래 목록·수치·배치 방식은 제안이며 아직 구현하거나 밸런스를 확정하지 않았다.

### 현재 구조와 개선 방향

현재 `FrontierTerrainField.height()`는 착륙 원점에서 반경 18m까지 기본 지면의 요철을 억제하고 65m까지 노이즈를 섞는다. 그 밖은 공통 노이즈에 행성별 `relief` 진폭과 작은 요철을 더하며, 물 분지 보정과 시작 동굴 보호 능선을 별도로 적용한다. 넓은 평원·고원 구역의 비율과 연결성을 지정하는 규칙은 없다. 현재 실제 평지 면적 비율을 측정한 것은 아니다.

큰 지형은 평원·구릉·산악으로 나누고, 작은 표면 변화는 자연물과 지면 재질로 표현한다. 지형 진폭만 일괄 낮추지 않고 넓은 평지 사이에 완만한 통로를 만든다. 고도가 높은 고원도 평지 후보에 포함해 모든 건축 공간이 저지대에 몰리지 않게 한다.

### 착륙 가능한 9개 계열의 자연물 후보

아래 비율은 **물에 잠기지 않은 지표의 수평 투영 면적 중 평탄 구역의 목표 범위**다. 평탄 구역은 우선 경사 5도 이하를 제안하되, 실제 건축 가능 여부는 시설 바닥 전체의 높이차·장애물·위험 조건으로 별도 판정한다. 수면·동굴 바닥은 비율에서 제외하고, 착륙 안전지대의 비율은 일반 지역과 따로 본다. 얼음 지표는 평지에 포함할 수 있으나 안전한 건축 지반을 뜻하지 않는다. 모든 행성과 청크가 같은 비율을 강제로 맞추지는 않는다.

| 기존 계열 | 가까이서 보이는 작은 자연물 | 군집·대표 경관 | 평지 목표와 형태 |
| --- | --- | --- | --- |
| 산화 사막 (`oxidized`) | 붉은 각진 자갈, 얇게 깨진 돌판, 반쯤 묻힌 풍화암 | 바람 방향의 자갈 띠, 마른 유로, 침식 잔구 | 45~55% · 넓은 사막 바닥과 완만한 돌 평원 |
| 습윤 대륙 (`continental`) | 둥근 강자갈, 젖은 돌, 조건부 이끼·풀 무리 | 수변 퇴적대, 낮은 암반, 조건부 관목 군락 | 50~60% · 하천 주변 평야와 높은 대지 |
| 충돌 고원 (`cratered`) | 회색 각력, 충격 유리 파편, 반쯤 묻힌 바위 | 충돌구 바깥 파편 띠, 무너진 테두리 | 35~45% · 넓은 충돌구 바닥과 평탄한 고원 |
| 균열 빙원 (`fractured`) | 얇은 얼음 조각, 눈 덮인 암편, 낮은 얼음 융기 | 균열 가장자리 파편, 드문 얼음 기둥 | 45~55% · 넓은 빙판 사이에 집중된 균열 |
| 해빙 툰드라 (`tundra`) | 빙하가 남긴 자갈, 작은 잔설, 조건부 지의류·낮은 풀 | 돌무더기 띠, 해빙 웅덩이 주변, 조건부 관목 | 50~60% · 완만한 퇴적 평원과 해빙 분지 |
| 극저온 설원 (`frozen`) | 서리 덮인 돌, 얼어붙은 판상 조각, 낮은 눈둔덕 | 바람결을 따른 눈 능선, 드문 얼음 노두 | 40~50% · 넓은 설원과 얼음 고원 |
| 불타는 화산 (`volcanic`) | 검은 용암 자갈, 기공 많은 화산암, 무광 유리질 파편 | 용암류 가장자리 잔해, 굳은 용암 판, 화산 기둥 | 25~35% · 굳은 용암 대지와 산 사이 분지 |
| 염류 분지 (`salt`) | 깨진 소금 껍질, 낮은 염류 돌기, 밝은 자갈 | 마른 호수의 다각형 균열, 가장자리 퇴적 띠 | 60~70% · 넓은 염원과 호수 주변 평지 |
| 황토 열수대 (`ochre`) | 황색 침전 조각, 얇은 광물 껍질, 작은 다공질 돌 | 열수 주변 침전 턱, 낮은 광물 언덕 | 35~45% · 침전 평지와 완만한 계단식 대지 |

자연물은 가상 게임 환경의 후보이며 실제 관측된 생태·지질로 표시하지 않는다. 식물·이끼·지의류는 해당 행성의 생태·온도·수분·기질 또는 테라포밍 정착 조건이 맞을 때만 배치한다. 습윤하거나 산소가 있다는 이유만으로 생명을 자동 보장하지 않는다. 가스/얼음 거대행성 6계열은 착륙 불가이므로 지표 자연물 대상에서 제외한다.

### 자연스럽고 플레이를 방해하지 않는 배치

- 바닥 무늬(모래결·균열·퇴적색), 작은 모델(자갈·얼음 파편), 드문 큰 모델(노두·기둥)의 세 크기를 조합한다. 잔돌만 고밀도로 채우지 않고 드러난 흙과 비어 있는 구간을 남긴다.
- 시드로 군집 위치를 정하고 지질·경사·상대 고도·물가 거리·균열/절벽 마스크로 배치 후보를 제한한다. 절벽 아래에는 각진 잔해, 유로에는 둥근 자갈, 빙하 균열 주변에는 얼음 조각을 모은다. 전역 균등 무작위 배치를 피한다.
- 같은 군집에서도 모델·크기·회전·부분 매몰량을 변형하고 기울기를 지면에 맞춘다. 색만 바꾸어 행성 차이를 표현하지 않는다. 자연물의 색과 대비는 실제 자원·생물보다 낮게 유지한다.
- 작은 디자인용 자연물은 충돌·채집·스캔·레이더 대상을 갖지 않는다. 채광 자원의 실루엣·발광·표시를 재사용하지 않는다. 큰 바위는 보이는 형태에 맞는 충돌을 두고 이동/건축 판정과 연결한다. 연구할 대표 경관은 별도 상호작용 콘텐츠로 정의한다.
- 착륙 동선·동굴 입구·자원 접근로·시설 출입 공간에는 큰 장애물을 배제한다. 건설 확정 영역의 작은 장식은 숨기고, 취소한 미리보기는 영구 제거를 만들지 않는다. 굴착으로 지지면이 사라지면 해당 장식을 제거하거나 재접지해 공중에 남기지 않는다.

### 평지 생성·보존 제안

- 저주파 지역 마스크로 평원·구릉·산악을 먼저 구분한다. 평원 안은 작은 요철을 억제하고 경계는 완만하게 연결한다. 산악의 봉우리·절벽은 유지한다.
- 면적 비율과 함께 **기지에서 여러 시설과 로봇 통로로 확장할 수 있는 연결된 면적**을 본다. 시작 후보는 약 60~100m 폭의 연결 평지를 초기 목표로 두되 실제 시설 크기·보행 거리로 조정한다. 이후에도 연결된 추가 기지 후보가 생기게 한다.
- 물이 있는 행성은 평원을 전부 수면 아래로 낮추지 않는다. 건조한 대지와 해안 평야를 함께 둔다. 화산의 평지는 형태만 평평하며 냉각 전 안전·자원 해금 조건은 기존 규칙을 유지한다.
- 평지 비중, 구역 크기, 전이 폭, 요철, 자연물 가중치·군집 밀도는 버전이 있는 데이터로 관리한다. 비율은 생성 가중치와 구별하여 실제 지면에서 확인한다.
- 새 생성 규칙은 새 은하에 적용하고 기존 저장의 지형·시설·광맥 좌표를 재생성하지 않는다. 지역/장식 ID는 행성 시드·월드 좌표·규칙 버전으로 재현하며 청크 로드 순서에 의존하지 않는다. 호스트·클라이언트·원경·충돌·로봇 경로는 같은 지형 정의를 사용한다.
- 장식은 청크별 인스턴싱·거리별 밀도/LOD를 적용한다. 제거·건설·굴착 차이는 호스트의 저장된 세계 상태로 반영한다. 장식용 난수열이 기존 자원·생물 배치를 바꾸지 않게 분리한다.

### 제작 순서와 현재 상태

먼저 산화 사막·균열 빙원·불타는 화산으로 색/실루엣/평지 차이를 비교하는 작은 구현을 제안한다. 이후 나머지 계열로 확장한다. Blender 원본·GLB와 실제 렌더를 제작하고 [INK v1](06-rendering-quality-standard.md)을 유지한다. 작은 돌의 검은 선이 뭉치면 밀도·LOD·내부 디테일을 조정한다. 동작·환경음이 필요한 분출공 등은 별도 제작 범위로 두고 ElevenLabs 음원과 실제 게임 재생을 연결한다.

초안 작성 시에는 코드·기존 데이터와 문서만 확인했다. 이후 사용자가 Blender 다종 제작과 게임 반영을 요청하여 아래 범위를 구현했다. 위 후보 목록 전체의 완성을 뜻하지 않는다.

## 자연물 제작과 평지 반영 — 2026-09-07

사용자 확정: 자연스러운 지표를 위한 여러 종류의 Blender 모델·렌더를 제작하고 게임에 반영한다. 앞서 논의한 평지 확대도 함께 적용했다.

- **제작물:** 착륙 가능한 9계열 × 독립석·판상 파편·잔해 군집·낮은 노두 4변형, GLB 36개. Blender 편집 원본은 계열별 9개와 비교 장면 1개다. 돌의 비대칭 윤곽·깨진 면·둥근 풍화·서리 덮임·화산암 기공을 구분했다. [제작 스크립트](../../tools/build_surface_details.py), [출처·삼각형 수](../../art/blender/surface-details/manifest.json), 공통 `render_assets.json` 목록에 등록했다. 총 11,910삼각형이며 모델별 52~1,138삼각형이다.
- **실제 실행 연결:** 기본 공동 원정의 `FrontierCrewSurfaceScene`에서 `FrontierSurfaceDetails`를 생성한다. 24m 타일의 시드와 별도 군집 노이즈로 모델·크기·회전을 고르고 지형 법선에 맞춰 일부 묻는다. 같은 계열에서도 시드에 따라 배치가 다르다. 청크 준비를 기다려 근거리 타일을 프레임당 하나씩 만들고 MultiMesh·거리 페이드로 표현한다. 세부 가중치는 `surface_details.json`에 있으며 협동 콘텐츠 서명에 포함한다.
- **표면 표현:** 사막에는 바람결, 빙원·설원에는 표면 결, 염류 분지에는 다각형 균열을 더했다. 공통 INK 3단 명암·윤곽과 기존 화산의 지역 냉각 연출을 유지한다. Blender 렌더와 Godot 실제 셰이더 비교판을 각각 제작했다.
- **배치와 세계 변화:** 모두 작은 비상호작용 장식으로 충돌·채집·스캔·자원 보상을 갖지 않는다. 물속·가파른 면·착륙선 진입부를 제외하고 지지면을 확인한다. 호스트의 건설 기록에 있는 시설·창고 아래는 장식을 숨기며 철거 후 시드 배치를 복원한다. 굴착 완료로 지면을 잃은 장식은 재생성 대상에서 제외된다. 미리보기는 영구 제거를 만들지 않는다.
- **평지:** 새 `planet_rules` v2의 `terrain_layout`으로 저주파 평원 구역·완만한 고원 높이·산악 구역을 혼합한다. 착륙 평탄화는 반경 40m에서 85m까지 전이한다. 기존 시작 동굴의 보호 능선은 유지한다. 물이 있는 행성은 낮은 분지만 내려 마른 평원이 전부 잠기는 문제를 피한다.
- **기존 저장:** 저장된 v1 행성 규칙에 `terrain_layout`을 주입하지 않아 지형·광맥·시설 좌표가 유지된다. 기존 행성에도 계열에 맞는 장식과 표면 재질은 적용된다. 확대된 평지 지형은 새 은하에서 적용된다. 구형 독립 `planet_exploration` 실증 장면의 자연물 연결은 이번 범위가 아니며 현재 기본 원정 경로에 연결했다.
