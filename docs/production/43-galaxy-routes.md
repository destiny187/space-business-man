# 3D 은하 항로·항속거리·주변 별 항해

2026-09-08 확대 렌더 변경: 아래의 고배율 성운 숨김·동일 평면 항성 표시를 [확대 입체감 개선](64-galaxy-map-depth.md)으로 대체한다. 실제 항로 거리와 권한 규칙은 유지한다.

## 사용자 확정 — 2026-09-07

고속 이동의 목적지는 3D 은하 항로 지도에서 항성계를 눌러 선정한다. 거리와 비행체별 항속거리를 표시하고 고급 비행체일수록 멀리 이동한다. 미방문 내부 정보 제한은 유지하지만 항로 선택은 허용한다. 첫 지구 출격도 이 흐름을 따른다.

추가 확정: 원거리에서는 적은 별을 표시하고 확대에 따라 늘린다. ‘이동 가능한 근처’는 실제 항속거리 안만 확대·렌더한다. 초반 항속거리는 줄여 가까운 별을 조금씩 탐험한다. 우주 화면에서도 방향별 가까운 별의 포인트를 주시/호버해 지도 선택 없이 출발한다.

이 결정은 이전의 미방문 항성계 클릭 전체 차단과 첫 출격 자동 목적지 선택 UI에 우선한다. 기존 `tutorial_depart` 요청은 호환 경로로 남지만 새 기본 버튼은 호출하지 않는다.

## 현재 구현

- G/출격하기 → 은하 지도 → 항성계 선택 → 실제 거리·항속거리 → 고속 항해 출발. 이후에도 G로 같은 지도를 연다. 방문하지 않은 항성계는 항성 이름과 항로 거리만 보여 주고 행성 자원·환경·모델 상세를 공개하지 않는다.
- 출발 시 호스트가 현재 좌표와 선택 좌표의 거리를 다시 계산하고 실제 선체·장착 추진 모듈의 항속거리와 비교한다. 조종사·승선·준비·에너지·선체·진행 중 요청 제한은 기존 경로를 유지한다. 거리 초과는 명확한 실패 이유를 반환한다.
- 은하 지도는 목적지 선택에 사용한다. 호스트가 고속 항해 시작을 확정하면 지도를 닫고 외부 우주 비행 화면과 렌더를 복구해 기존 정렬·가속·순항·감속·진입 애니메이션을 보여 준다. 비행 화면 별 표식으로 출발해도 같은 경로다. 소요 시간은 기존 12초 설정이며 지도상의 임의 위치 변경이나 순간이동으로 대체하지 않는다.
- ‘이동 가능한 근처’는 현재 항성계를 중심으로 확대하고 거리 안의 실제 항성계만 보여 준다. 범위 원·현재 위치 사각형·선택 원·항로선을 함께 표시한다. 전체 은하로 돌아가려면 현재 항성계/은하 항로 전환 또는 G 재진입을 사용한다.
- 평소 외부 비행에는 항속거리 안의 별을 8방향으로 나눈 뒤 각 방향의 가장 가까운 별 하나만 표시한다. 화면 밖 방향은 가장자리 화살표다. 주시점/마우스가 표식에 닿으면 이름·거리·클릭/F 안내가 나타난다. 클릭/F는 동일한 호스트 항해 요청을 보낸다. 메뉴·지표·항해 중에는 숨기고 조종사만 출발한다.
- 정거장 선체 비교 막대와 정비 요약에도 항속거리를 표시한다. 항속거리 규칙을 협동 콘텐츠 해시에 포함하며 저장된 은하 좌표·선체·모듈 원본은 변경하지 않는다. 이미 진행 중인 기존 항해는 완료하고 다음 출발부터 제한한다.

## 데이터와 초기 조정값

단일 원본은 `data/stellar_navigation.json`이다. KESTREL 8, SWIFT 16, MULE 24 항로 단위이며 추진 모듈 표준/개량/희귀 배율은 1.15/1.35/1.65다. 이는 밸런스 확정값이 아닌 초기 구현 수치다. 항로 단위는 기존 은하 지도 좌표의 게임 단위이며 실제 광년으로 표기하지 않는다. 예전 90/160/210 실험값은 사용자 축소 요청으로 폐기했다.

## 3D 제작·렌더 최적화

Blender 원본 `art/blender/space/galaxy_map.blend`, 제작 스크립트 `tools/build_galaxy_map.py`, 게임 GLB를 구분해 보존한다. Blender 별 무리와 기존 Blender 중앙 블랙홀, Godot 전용 투명 은하 나선팔/먼지 셰이더를 사용한다. 은하는 게임 생성 표현이며 실제 은하 관측 재현이나 중력 렌즈 물리 시뮬레이션이 아니다. INK v1의 UI·발광/투명 효과용 예외를 따른다.

- 별 무리 LOD: 원거리 584개, 중거리 2,334개, 근거리 14,000개. 거리 단계에서 한 가지 메시만 표시한다. 주변 보기/고배율에서는 전체 별 무리와 은하 안개를 숨기고 화면 내 실제 항성계의 인스턴스만 그린다.
- 항성계 좌표는 1.5ms 작업 예산으로 점진 구축한다. 행성 백만 개의 상세 레코드를 만들지 않는다. 공간 셀과 주변 결과를 캐시해 근처 필터와 방향별 별 검색을 공유한다.
- 전체 지도의 목적지 표식은 확대 수준에 따른 표본과 화면 밀도로 제한한다. 근처 보기는 실제 범위 검색 후 화면 밀도를 적용한다. 겹친 별은 더 확대하면 선택할 수 있다.
- 은하 SubViewport는 카메라/표시 별 변경 시에만 렌더한다. 정지 지도와 항해 진행률 표시는 이미 렌더한 3D 텍스처 위에 항로만 갱신한다. 큰 은하 지도 뒤의 실제 비행 SubViewport도 렌더를 중단하고 닫으면 재개한다.
- 휠 확대, 우클릭 이동, 휠 버튼 드래그 회전. 작은 화면에서도 목적지·거리·출발 버튼을 유지한다.

## 사운드

기존 ElevenLabs `ui_discovery`를 표식 선택에 재사용한다. 기존 출발 요청/충전/추진/도착 음향은 실제 호스트 상태 경로를 유지한다. 신규 음원은 제작하지 않았다.

## 확인 범위

Blender 원본과 LOD 내보내기, Blender 렌더를 확인했다. Godot 4.7.2 Metal Forward+ 실제 창에서 1280×800·960×640 은하/주변/항해 화면을 확인한다. `tests/check_galaxy_routes.gd`는 미방문 항로, 상세 숨김, 호스트 거리 초과 거부, 상위 선체 범위 증가, 실제 출발/도착·저장, 주변 필터와 방향별 항로를 대상으로 한다. 캡처는 로컬 `test-results/galaxy-routes/`에 둔다. 최종 실행 결과는 구현 현황에 기록한다.

다중 클라이언트·인터넷·전체 게임 회귀는 실행하지 않는다. 모든 은하 시드의 항로 연결성·최종 밸런스·최저 사양 성능은 보장하지 않는다. 천문 거리/실제 은하 좌표의 새 생성기나 항해 중 임의 이탈은 이번 범위가 아니다.

### 최종 최소 확인 결과

항로 검사에서 실제 미방문 출발·도착·저장, 호스트 범위 초과 거부, 상위 선체 범위, 주변 필터, 표식 호버/F 출발이 통과했다. 초기 정지 렌더 검사는 색인 생성이 끝나기 전 실행한 문제와 UPDATE_ONCE 상태를 검사하는 문제로 실패했다. 동일 좌표 인스턴스 재설정을 막고 렌더 후 명시적으로 중단하며, 근처 확대는 컨테이너 레이아웃 다음 프레임에 중심을 맞췄다. `check_galaxy_idle.gd`의 수정 확인은 PASS(주변 11개, 은하/배후 비행 SubViewport 중단). 60프레임 평균 25.45ms는 다른 Godot 인스턴스가 함께 실행된 로컬 측정이며 단독 성능/최저 사양 보장이 아니다. 전체 항로 검사를 반복하지 않고 발견된 정지 렌더 문제만 재확인했다.

### 2026-09-07 — 출발 후 실제 비행 화면 복구

사용자 정정: 지도에서 목적지를 선택할 수 있지만 출발하면 실제 우주 화면으로 전환해 기존 이동 애니메이션을 유지한다. 고속 항해 시작 스냅샷에서 은하 지도를 다시 열던 연결을 제거하고, 외부 시점·비행 SubViewport를 즉시 복구한다. 성간 출발 거절 시에는 선택 지도를 유지하고 기존 오류 안내를 표시한다. 호스트의 항해 진행·캐시·목적지 사전 준비·도착 규칙은 그대로다.

실제 Forward+ 창에서 지도 출발→외부 비행 화면/렌더 복구→항해 진행→선택 항성계 도착과 저장을 확인했다. 항해 16% 정렬 단계의 선체·출발 천체·진행 표시를 캡처로 검수했고, 목적지 4행성 사전 준비 재사용도 통과했다. 관련 최소 검사 실패 0. 전체 회귀·다중 클라이언트 검사는 하지 않았다.
