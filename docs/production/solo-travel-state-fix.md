사용자가 다른 컴퓨터에서 원격 `main`을 받아 혼자 첫 항성계 이동을 실행할 때 “세계 상태가 바뀌었습니다. 최신 상태에서 다시 요청하세요.”가 발생한다고 제보했다. 즉시 수정·커밋·푸시 요청에 따라 당시 원격 `1bc57d50f`에서 수정만 분리했다.

## 원인과 변경

이 메시지는 Git 버전이 아니라 요청의 `crew.revision` 불일치를 뜻한다. 기존 지도는 항로 선택 성공 후 `travel_action`에서 준비 요청을 보내고, 준비가 아직 표시되지 않았으면 출항을 포기했다. 이미 준비된 경우에는 또 준비를 저장하면서 같은 이전 revision으로 출항을 대기열에 넣어 거절됐다. 착륙 상호작용과 정거장 접근도 준비·이동을 연속 요청했다.

`send_travel_request`는 싱글플레이·독립 FINCH의 이동 요청에 본인 자동 준비 의사를 담는다. 호스트는 해당 선박의 실제 접속 인원이 한 명이고 요청자가 조종사인지 확인하고, 본인 준비와 이동을 기존 독립 초안·영수증·비동기 저장 한 건으로 확정한다. 준비 조건, 실제 항로/항속거리·착륙/정거장 조건, revision 거절, 중복 요청 방지는 유지한다. 이동 거절이나 저장 실패에는 준비도 확정하지 않는다. 공동선의 다인 준비는 자동 변경하지 않는다.

## 단일 행동 범위

지도 한 번 선택은 기존처럼 항로 선택 한 건과 출항 한 건이다. 중간의 불필요한 준비 저장·revision·스냅샷 발행 한 건을 없앴다. 항해 초안은 기존 전체 독립 복사와 저장 검증을 유지하며, 변경 대상은 본인 준비·항해·에너지·관련 영수증이다. 실패는 원본을 보존하고 중복 요청은 추가 저장·에너지 차감을 만들지 않는다. 이번 수정으로 모든 일반 거래의 복사·직렬화 비용이 제거된 것은 아니다. 닫힌 화면이나 지형을 별도로 새로 갱신하는 경로는 추가하지 않았다.
