# UI 밝은 배경 투명화와 티어별 행성 음악

2026-09-10 명칭/설정 변경: 이 문서는 당시 제작·검수 이력이다. 현재 전투로봇 제조사는 **쿠퍼테크(CooperTech)**이며, 과거 회사명·심볼은 현재 제작 기준에서 제외한다. [현재 설정·표시·심볼과 호환 경계](106-coopertech-rebrand.md)를 우선한다.

2026-09-09 사용자 확정: UI/UX의 흰색 바탕을 투명하게 바꾸고, 높은 티어의 험난함을 소리로 구분하는 행성 BGM을 제작한다.

## 변경

흰색·크림색 스튜디오 바탕이 있던 발견/사건·생물·시설·자원 미리보기 PNG 657개를 기존 Blender 제작 GLB와 Godot Forward+ INK 렌더로 다시 출력한다. 이미지의 밝은 색을 지우지 않으며 모델의 흰 재질과 윤곽을 유지한다. 첫 출항 Lotus 편지의 종이색 패널은 투명으로 바꾸고 본문은 공통 밝은 글자색으로 조정한다. 기존 어두운 메뉴 배경·선택 테두리·흰 글자·지도 표식은 유지한다.

재생성 목록은 `data/transparent_ui_renders.json`, 실행은 `tools/godot.sh --script res://scripts/showcase/render_equipment_icons.gd -- --all-white-backgrounds`다. 단일 출력은 `--only-output=res://assets/ui/...png`를 추가한다. 향후 스튜디오 품질 캡처가 UI PNG를 다시 생성하면 이 투명 출력도 갱신한다. 전체 도감 품질 캡처의 배경은 이 변경의 대상이 아니다.

| 티어 | 곡명 | 제작 방향 |
| --- | --- | --- |
| T1 | First Light Frontier | 따뜻한 피아노·패드·마림바, 여유로운 개척 |
| T2 | Rustwind Traverse | 건조한 현악·손북·베이스 맥박, 경계하며 걷는 황야 |
| T3 | Toxic Glasslands | 유리 타악·불규칙 전자 리듬·금속 질감, 낯선 위험 |
| T4 | Obsidian Tempest | 저음 현악·거친 드론·묵직한 타악, 혹독한 폭풍 지대 |
| T5 | Eventide Abyss | 깊은 베이스·불협화음·산업 타악, 극한 생존 |

각 2분·기악·변형 1로 ElevenLabs Music v2에서 생성했다. 원본 MP3를 보존하며 게임 파일은 2패스 -20 LUFS / -3 dBTP 목표로 음량을 맞췄다. 과도한 음량 증가 대신 악기·리듬·화성으로 난도를 표현한다. 프롬프트·실제 생성 링크·해시·편집 정보는 [생성 기록](../../audio/manifests/planet-tier-music.json)에 있다. 웹 입력 갱신 문제로 T2가 두 번 생성돼 최신본을 선택했다(화면 표시 1,800 크레딧 × 총 6회).

`expedition_audio.gd`가 로컬 스냅샷의 착륙 주소로 `planet_tier`를 조회한다. FINCH의 독립 출동도 같은 로컬 문맥을 사용한다. 행성 주소가 바뀔 때만 곡을 계산하고, 같은 티어에서는 재시작하지 않는다. 2.5초 교차 페이드·0.45초 반복 경계 페이드·음악 음량·메뉴/포커스 일시정지를 유지한다. 누락 음원은 기존 행성 곡으로 복귀한다. 기존 우주/발견/위험 곡과 저장 형식은 그대로 사용한다.

## 확인 범위

657개 모두 모서리 알파 0·비어 있지 않은 모델 출력을 확인했다. 실제 Godot Forward+의 공통 카드 6종을 [화면](media/transparent-ui-tier-music/game-ui.png)으로 확인했다. 동시에 진행된 일루티 외형 작업의 전용 캡처 경로에도 UI 출력 단계의 투명 배경·스튜디오 바닥/문구 제거를 적용했다. 대표 비교판은 [여기](media/transparent-ui-tier-music/previews.jpg)에 있다.

`check_planet_tier_music.gd`의 로컬 스냅샷 fixture로 T1~T5 각 120.03초 스트림 선택·실제 재생·Music 버스 신호·메뉴 중 위치 보존을 확인했다. 첫 실행의 포커스 변경은 창 전면 배치로 해결했고, 종료 검사의 프레임 순서 대기는 0.1초로 보정한 뒤 T1만 사용해 우주 복귀·세션 종료 정지를 다시 확인했다. 게임 재생 로직의 실패로 기록하지 않는다. `--stop-only`가 해당 최소 재확인 경로다.

고정된 로컬 스냅샷의 실제 오디오 노드 검사이며 지형 로딩/착륙 전체 흐름이나 FINCH 다중 클라이언트 실행 검사는 아니다. 전체 음원 청감·긴 반복 피로·전체 UI 화면 순회는 이번 범위가 아니다. PNG 대표 화면과 새 음원 임포트, `git diff --check`를 확인했다.
