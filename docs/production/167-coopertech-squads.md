## 모델·동작·명중·소리

Blender로 서로 다른 몸체를 제작하고 편집 원본과 GLB를 함께 보존했다. BASTION은 11관절, RAPTOR는 17관절이며 `idle/ready/walk/wake/fire/cool/destroyed` 7클립을 갖춘다. 실제 이동 거리와 보행 위상, 기동·포 반동·냉각 코어·격파 자세를 게임에 연결했다. 기존 보초는 기존 가동 부품을 재사용한다. 개별 발의 지형 IK나 복잡한 경로 탐색까지 구현한 것은 아니다.

공통 INK v1 재질·윤곽선, 원본 CooperTech 심볼을 사용한다. 발견 도감에도 실제 모델을 렌더한 기체별 아이콘을 제공한다. `tools/build_coopertech_squads.py`와 `art/blender/incidents/coopertech-squads.json`에 재현 경로·삼각형·원본/내보내기·클립을 기록했다. Blender Cycles와 Godot Metal Forward+의 실제 렌더를 검수했다. 외형을 가리는 과도한 실드 투명도를 낮췄다.

두 차체의 몸통·머리·사지·냉각 코어와 실드 명중 영역을 분리하고, 이동한 호스트 위치를 총알 판정에 사용한다. 공격과 이동은 지형·물·제작 엄폐물·물리 장애물에 막힌다. 격파 후 각 기체의 부품과 기존 시드 전리품을 F로 회수한다. 중복 지급 방지·배낭 공간·원자적 저장은 기존 사건 거래를 따른다.

음원은 기존 ElevenLabs의 기동·펄스·플라스마·작동부·모터 음원을 재사용했다. 새 합성으로 기록하지 않는다. 기동/준비/발사/착탄에 연결하고, 이동 모터는 속도와 기체에 맞게 재생하며 메뉴 중에는 중단 또는 일시 정지한다. 출처와 게임 파일 해시는 `audio/manifests/coopertech-squads.json`에 둔다. 직접 청감에 의한 최종 음색·피로도 평가는 남아 있다.

## 저장·협동·단일 행동 처리 범위

기존 사건 배치 RNG를 건드리지 않고 마지막에 별도 `coopertech-squad-v1` 후보를 추가한다. 기존 단독 로봇의 위치·남은 체력·단서 연결·회수 완료 기록은 바꾸지 않는다. 현재 저장에서도 새 분대 후보를 만나면 등록한다. 원점 주변 150m와 기존 시설 주변은 제외하며, 새 분대를 만들기 위해 시설이나 기존 사건을 이동하지 않는다.

각 기체의 체력·실드·단계·위치·순찰 경로/목표·이동 거리·그룹 ID를 호스트 사건 기록으로 저장한다. 행성에서 멀리 벗어나면 진행을 멈추고 다시 접근하면 이어 간다. 개별 기체를 새로 생성해 회수 보상을 반복 지급하지 않는다. 같은 행성의 기존 사건 스냅샷으로 전송하며 분대 전용 세계 전체 패킷을 새로 만들지 않는다.

한 발은 피격된 기체와 같은 분대의 경보 상태만 바꾼다. 분대 탐색은 사건 목록 순회가 남지만 다른 분대를 깨우지 않는다. 순찰 0.25초 갱신은 실제 활성 범위 주변 사건만 독립 복사하도록 `WorldDraft.incidents`를 좁혔다. 다른 지역의 이탈 운반자는 기존대로 화물을 내려놓을 수 있다. 이동 자체 때문에 매 갱신마다 전체 저장을 강제하지 않으며, 기존 정기 저장·공격 단계/피해 저장을 이용한다.

사건 목록의 얕은 복사·순회, 현재 지역의 엄폐물/지형 분기 복사, 공격 단계 변화의 전체 저장 검증·직렬화 비용은 남는다. 화면에서는 이미 로드한 기체의 변환·골격·표시만 갱신한다. 로봇 한 걸음으로 지형·시설·아이템 카드 전체를 재생성하지 않는다. 실제 6인 외부망과 대규모 분대 밀도의 최악 성능은 확인하지 않았다.
