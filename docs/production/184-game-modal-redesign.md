# 게임 공통 모달 교체 — 2026-09-14

사용자 확정: 첨부한 지역 복원 계약 인계 창과 같은 저품질 기본 모달을 모두 게임 수준에 맞게 교체한다. 기존 Q01~Q09 보강에 이어 진행하는 UI 구현이며 신규 콘텐츠·정산 보상·소유권 규칙을 추가하지 않는다. 시각 소관은 [FIELD v1](22-uiux-guide.md), 기존 세 묶음은 [고도화 계획](../planning/17-existing-play-polish-plan.md)을 따른다.

## 적용

`FrontierGameModal`에 기본 OS 제목줄 없는 게임 프레임, 배경 감광, 한국어 행동 버튼, 키보드 포커스, 고정 하단 행동, 본문 스크롤, 0.14초 등장을 모았다. 테마·글꼴·UI 배율은 현재 원정 공통 설정을 사용한다. Window의 배타 입력과 기존 커서 판정은 유지한다.

| 기존 창 | 교체한 구성 |
| --- | --- |
| 계약 인계 / 생산 거점 보유 정산 | 이번 지급액, 공동 자금 전후, 이미 지급한 중간 보상, 시설·로봇·재고·보관 장비 수량 카드. 계속 보유하는 개인/회수 자산은 고정 하단에 표시 |
| 탐험복 모듈 분해 | 실제 아이템 아이콘·이름과 사라질 대상, 반환 재료. 확인을 연 시점의 ID와 리비전을 요청에 고정 |
| 원정선 모듈 추첨 / 분해 | 비용 아이콘·금액, 등급별 확률 막대·확정 횟수·중복 전환. 분해 대상 이미지와 연구 부품 반환량 |
| 현장 창고 / 원격 관측 광물 | 검색·분류·정렬과 자원 이미지 격자. 관측 목록은 수량 숨김 유지 |
| 알려진 사용처 | 기존 Blender 자산의 INK 3D 미리보기, 작업 장소와 필요 재료. 실제 사용처로 이동하는 행동을 하단에 고정 |
| 궤도 / 대기실 개인 장비 | 캐릭터 이름과 장비별 아이콘·등급·특성 카드 |
| 항해 기록 / 생산 거점 기록 | 공통 프레임과 검색·페이지, 선택 항로 / Earth 귀환 고정 행동 |
| 구 실행 장면의 사업 확인 / 관측 자료 | 같은 게임 프레임. 결과 영역 및 관측 천체별 수치 카드로 분리 |

런타임 `scripts/`와 실행 장면에서 기본 `AcceptDialog`·`ConfirmationDialog` 생성/사용을 제거했다. 드롭다운의 `PopupMenu`는 이미 적용된 FIELD 테마를 유지하며 확인 모달로 바꾸지 않는다. 일반 대형 관리 패널 전체의 정보 구조를 이번 모달 작업의 완료 범위로 확대하지 않는다.

## 입력·거래·행동 범위

- Esc / 닫기 / 돌아가기는 요청을 보내지 않는다. 손실이 있는 확인 창은 처음에 돌아가기 버튼에 포커스를 둔다.
- 새 모달이 열리면 앞의 미확정 창을 취소한다. 한 창의 연속 확정은 한 번만 신호를 보낸다. 소유 패널을 닫으면 모달도 닫고 감광/입력 차단을 해제한다.
- 확인은 기존 호스트 요청으로 연결한다. 정산 미리보기는 보상 지급·현장 이용권 변경·성공 소리를 발생시키지 않는다. 기존 저장 성공/실패와 수량 반영 경로를 유지한다.
- 정산 조회는 대상 현장의 지역 재고만 합산한다. 지역이 있으면 대표 현장 재고를 다시 더하지 않는다. 은하·다른 현장 순회, 전체 장부 복사·저장·네트워크 발행을 추가하지 않았다.
- 프레임 생성/조회는 열 때, 크기 계산은 열기/해상도 변경 때만 한다. 닫힌 창을 매 프레임 재구성하지 않는다. 기존 커서의 Window 등록/제거 목록을 그대로 사용한다.

## 확인

실제 Godot 4.7.2 Metal Forward+의 기존 지상 원정을 `/tmp` 복사본으로 실행했다. `check_game_modals.gd`의 기본 경로 46개 확인을 통과했다. 1280×800 정산과 960×640 / UI 130%에서 정산 양쪽, 자원, 사용처 3D, 추첨, 탐험복 분해, 항해 기록, 개인 장비, 구 확인/관측 창을 렌더했다. 구 관측 자료는 표시용 샘플로 레이아웃을 확인했다.

Esc 입력, 모달 뒤 조작 차단, 최초 포커스, 연속 확정 한 번 발행, 조건 미충족 정산의 지급 없음, 검색 빈 결과, 새 모달로 교체, 소유 패널 닫기, 저장 종료를 확인했다. 초기 검사에서 발견한 Esc 처리 누락과 누락 이미지 경로를 수정했고 최종 기본 경로는 스크립트/리소스 오류 없이 종료했다.

별도 `--actions-only` 경로 10항목으로 실제 소유 모듈 분해를 확인했다. 창을 연 뒤 선택을 바꿔도 원래 보여준 ID를 분해하며 정제 철 2개 지급·저장·기존 성공음이 한 번만 발생했다. 원정선 분해는 표시용 모듈로 반환량/이미지를 렌더하고 취소했다.

작은 화면의 큰 글씨에서는 긴 본문을 스크롤한다. 정산의 보유 경계와 실행 버튼은 고정한다. 기존 이미지 타일의 내부 그림 글자 크기는 현재 공통 타일 규격을 유지한다. 모든 실물 아이템별 시각 전수 검수, 외부망/6인 플레이, Windows 실기, 장시간 체감은 이번 확인 범위가 아니다. 새 모델·음원을 만들지 않았으며 기존 제작 자산을 재사용했다.
