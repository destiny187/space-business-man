# T3 설계도 획득·생산 묶음·현장 보급 계획

2026-09-10 후속: [설비 준비·대표 수급 경로](107-tier3-preparation-and-economy.md)에서 설치 전 원료/가공/반입 견적과 실제 채집·운송으로 첫 Mk.3 진입을 확인했다. 아래 최초 범위의 설치 후 5분 보급과 별도 화면이며 전체 수동 계약 정산·이동 시간은 여전히 미확인이다.

2026-09-10. 사용자가 T3 설계도 획득과 생산·운반·복원 연결 개선을 함께 개발하도록 요청했다. 후속 외형 지시는 **낡고 겨우 돌아가는 장치, 또는 오래된 기록 문서로 읽히는 로스트 테크놀로지**다. 이 기록은 [T3 전문 설비](100-tier3-terraforming.md)와 [자유 배치 복원](102-free-terraforming-and-globe.md)에 추가한 획득·운영 접점의 범위다.

## 실제 획득 경로

- 우주정거장 F 교역 메뉴의 **T3 설계도** 탭에서 시설 모델 카드 6개를 선택한다. 기존 정거장은 6종을 모두 확정 판매하며 물자 재고와 별개다. 공동 지출은 기존처럼 호스트가 확정하고 모든 승무원이 같은 세계의 사용권을 공유한다.
- 은하 지도 **교역 신호**는 현재 준비된 항로와 항속거리 안에서 가장 가까운 정거장을 선택한다. 미방문 행성의 세부 정보를 공개하거나 항해를 자동 실행하지 않는다. 신호가 없으면 주변 항성으로 이동하거나 지도 준비 뒤 재확인한다.
- T3 이상 지표의 **로스트 테크놀로지 기록고**에서 손상 기록 회수 → 제어 회로·정제 구리로 전원 복구 → 기록 대조·설계 복원을 진행한다. 각 단계는 해당 지점의 E 유지 조사 뒤 F로 확정한다. 신호 추적·전투·운반 사건 전체를 새로 구현한 것은 아니다.
- 복원하면 위치·세계 시드로 정한 6종 중 하나의 공동 설계도를 등록한다. 이미 아는 설계이면 정제 구리 2개를 한 번 회수한다. 보상은 접속·재방문으로 다시 추첨하지 않는다. 복구에 필요한 제어 회로 1개·정제 구리 2개는 T2 가공 경로를 사용한다.
- 설계도는 완제품 지급이 아니다. 확보 뒤에도 제작소 단계·재료·전력·시설 토대가 필요하며 같은 설계의 해금 연구를 추가로 요구하지 않는다.

| 설계 | 초기 조정 가격 |
| --- | ---: |
| 제작소 Mk.3 | 1,200 Cr |
| 선택성 대기 처리기 | 800 Cr |
| 폐쇄 수자원 순환기 | 800 Cr |
| 지역 열교환기 | 600 Cr |
| 선구종 정착기 | 1,000 Cr |
| 유입원 제어 장치 | 1,000 Cr |

가격·상품 모델·용도는 `facility_blueprints.json`에서 관리한다. 전부 구매하면 5,400 Cr이며 최초 공동 자본 6,000 Cr 안이다. 그러나 생산권·지원 운송비·기존 구매까지 포함한 모든 경로의 예산을 보장한다는 뜻은 아니다. 필요한 설계부터 구매하거나 기록고를 활용하고 기존 복원 대금을 재투자한다. 기존 원료/제품 레시피와 계약 대금은 바꾸지 않았다.

## 생산과 직접 보급

현장 제작소에서 **1~20묶음 생산**을 예약한다.

화면 검수 중 발견한 기존 탭 이름 문제도 수정했다. Godot가 `/`를 `_`로 바꾼 노드 이름과 메뉴 대상을 동일하게 정규화하여 제작소의 부품/생산·개조 화면과 착륙선 환경/계약 탭에 실제로 접근할 수 있다. 표시 제목은 원래 한국어 제목을 유지한다. 선택 수량에 맞춰 완성품 수량·총 재료·기본 예상 시간을 표시한다. 호스트는 해당 현장 창고의 전체 재료를 한 번 차감하고 한 묶음씩 생산한다. 창고가 가득 차면 완료된 묶음의 출고를 기다리며 작업을 잃지 않는다. 남은 묶음과 진행도는 저장한다. 기존 단일 생산 저장은 1묶음으로 읽는다.

Tab → 테라포밍 → **보급 계획**에서 설치한 현장별 설비 수·전력과 향후 5분의 소모품 필요량, 현지 재고, 추가 운반량을 아이콘 카드로 본다. 지도에서 보기로 그 현장에 초점을 맞춘다. 설비를 설치하기 전에는 해당 오염 문제의 제어·정화·선구종 시설을 안내한다.

표시량은 활성화한 설치 설비가 조건을 충족해 연속 가동한다고 가정한 **보수적인 상한**이다. 이미 투입한 팩은 제외하고 공동 효율과 물 설비의 공학 개량을 반영한다. 목표 도달·정전·침수·중첩 처리 제한은 실제 소비를 줄인다. 제작 예약 재료는 예약 시 이미 차감되므로 소모품 표에 다시 더하지 않는다. 다른 현장의 재고는 합산하지 않는다. 시설 건설 재료나 행성 간 왕복 시간까지 계산하는 자동 공정 계획기는 아니다.

FINCH·배낭·선박을 이용한 직접 운반과 현장 창고 입고는 기존 경로를 사용한다. 자동 물류·화물 순간 이동·새 보급 화폐는 추가하지 않았다.

## 아트와 음향

`tools/build_lost_archive.py`로 원본 `.blend`와 게임 GLB를 만든다. 벗겨진 외피와 녹, 파손된 저장층·비뚤어진 지지대, 끊긴 배선, 깨지고 각인된 기록판이 남은 형상이다. 임시로 넣는 새 제어 회로만 현재 산업 재질로 구별한다. 기존의 깨끗한 완제품 외형을 교체했으며 Blender 형상 렌더와 Godot Forward+의 INK v1 렌더를 별도로 확인한다.

기록 회수 후 덮개가 열리고, 호스트의 전원 복구 성공 뒤 회로·설계 투영이 나타난다. 회전부는 느리고 간헐적으로 돌며 작은 상태등이 불안정하게 켜진다. 조사 메뉴 중에는 도구 입력과 현장 반복음이 차단된다. 기존 ElevenLabs 작업·개방·발견·제작·거래 효과음을 재사용하고 신규 음원은 생성하지 않았다. 매핑은 `audio/manifests/t3-progression-reuse.json`에 둔다.

## 저장과 범위

크레딧 차감·설계도 등록·기록고 단계/보상은 기존 호스트 저장 거래를 통과한 뒤 공개한다. 같은 구매 요청 재전송과 이미 아는 설계 구매는 이중 차감을 만들지 않는다. 저장 실패는 비용·보상·사용권을 함께 되돌린다.

기록고는 기존 발견 배치의 난수열을 소비하지 않는 별도 스트림이다. T3 이상 320m 타일별 45% 후보·평탄도·수면·기존 발견 간격 조건으로 배치한다. 이전 발견/조사 기록과 기존 정거장 물자 재고는 보존한다. 기존 세계의 지역 규칙 v1/v2/v3나 지하 배치를 소급 전환하지 않는다.

이번에는 **기록고 한 유형에 설계 6종**을 연결했다. T3 신규 탐험 후보 전체, 독립적인 종이 문서 수집 체계, T4/T5 전문 복원, 새로운 정거장/기업 거점, 자동 운송은 구현 범위가 아니다.
