# A01 — 신체 증강 저장·능력치 기반

2026-09-08 후속: [A02 보석 거래](63-gem-augmentation-transactions.md) 기반을 완료했다. 아래 보석 소비 미구현 표기는 A01 당시 범위이며, 실제 장치·플레이 화면은 계속 A03~A04 대기다.

2026-09-08 [전체 A01~A09 계획](../planning/12-augmentation-and-research-commits.md)의 첫 구현을 완료했다. **증강 단계의 저장·실제 적용을 완료한 것이며 보석 소비, 증강 장치·연출, 고티어 연구 해금은 아직 아니다.**

## 변경

- `crew_augmentation.json`과 `FrontierCrewAugmentation`에 기동·전투·생명 3계열과 단계/효과를 정의했다. 첫 구현값은 최대 5단계, 단계당 이동 +10%·무기 피해 +10%·최대 체력 +20%다. 보석 배정은 사파이어·루비·에메랄드이며 아직 소비하지 않는다.
- 개인 증강은 세계의 승무원 레코드에 저장한다. 장비 교체·해제와 무관하고 원본 개인 프로필에 반출하지 않는다. 새 참가자의 프로필에 주장된 증강을 수용하지 않는다.
- 이전 물류 성장의 이동속도는 같은 기동 단계로 한 번 이행한다. 기존 가방 칸은 유지하며 이후 개인 물류 개조는 가방만 늘린다. 미이행 저장을 읽는 계산도 기존 속도를 유지하고, 호스트 시작 시 검증 후 저장한다.
- 호스트의 지상 이동과 클라이언트 예측에 같은 기동 배율을 연결했다. 전투 증강은 실제 펄스 무기의 피해 계산에 적용하고 원본 무기 정의는 변경하지 않는다. 채집기·지형 도구의 성능과 채집 등급은 그대로다.
- 개인 최대 체력을 저장 검증·회복·HUD에 반영했다. 상한 증가만으로 현재 체력을 자동 충전하지 않는다. 체력 HUD는 현재/최대를 함께 표시하고 위험 색상은 개인 상한의 30%를 기준으로 한다.
- 범위 밖 단계·누락 필드·개인 상한보다 높은 체력을 거절한다. 증강 규칙은 협동 콘텐츠 해시에 포함한다.

## 최소 확인

Godot 4.7.2 / Apple M2 / Metal Forward+에서 확인했다.

- `check_augmentation_foundation.gd`: **28개, 실패 0**. 과거 저장의 속도/가방/현재 체력 보존, 중복 이행 방지, 무기 교체 뒤 피해·원본 정의 보존, 채집기 분리, 회복 상한·잘못된 단계 거절, 호스트 권한 아래 참가/재접속·개인별 분리·JSON 재로드를 확인했다.
- `check_augmentation_foundation_ui.gd`: **8개, 실패 0**. 실제 원정 장면의 지형 충돌 로드 후 지상 속도 **7.80m/s**(기본 6 × 기동 1.3), 개인 체력 상한 **140**, 현재/최대 HUD, 960×640 배치, 종료 저장을 확인했다.
- 초기 화면 확인 도구가 주변 지형 충돌 준비 전에 이동을 측정하여 0을 얻었다. 지형 준비와 바닥 충돌을 기다린 뒤 실제 속도를 확인하도록 도구를 수정했다. 최초 fixture의 고정 행성 주소도 최신 항속/착륙 조건에 맞지 않아, 항해 검사를 확장하지 않고 시험용 궤도 위치를 준비한 뒤 실제 착륙 명령으로 fixture를 만들었다.
- 같은 폴더의 별도 로딩 화면 개발 변경은 수정·커밋하지 않았다. 실행 검수는 `4c478ed8`의 진입 코드에 이번 이동 계산만 적용한 `/tmp/augmentation-a01-project` 분리본으로 수행했다. 공유 에셋을 재사용하고 검수 세계는 `/tmp/augmentation-a01*`에 두어 사용자 저장을 바꾸지 않았다.
- 새 모델·작동음은 이번 기반 커밋에서 제작하지 않았다. 실제 피해 수치 계산은 확인했지만 전투 장면 완주·원격 ENet 이동 예측·6인 인터넷·FINCH 왕복은 이번에 재검증하지 않았다. 보석 차감의 거래/장치 피드백 검수는 A02~A04에서 수행한다.

## 재현

```sh
./tools/godot.sh --headless --script res://tests/check_augmentation_foundation.gd
./tools/godot.sh --script res://tests/check_augmentation_foundation_ui.gd -- --crew-ui-test --crew-folder=/tmp/augmentation-a01-ui
```

두 번째 도구는 첫 번째가 만든 격리 세계를 복사한다. 증강 단계와 장비·궤도 위치는 검수용 준비 데이터다. 정식 플레이에서 보석을 써서 증강을 획득하는 경로는 A02 이후이며 현재 제공한다고 주장하지 않는다.
