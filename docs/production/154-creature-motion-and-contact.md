# 생물별 리깅 다양성과 이동·타격 품질

2026-09-12. 사용자는 [153의 대표 외형](153-creature-type-studies.md)을 승인하고, 이 품질을 유지하면서 이동·공격이 어색하지 않도록 다듬고 특히 타격 표현을 고도화하도록 요청했다. 후속 질문에 따라 **6종은 검토 대표 수이며 전체 생물을 여섯 리깅으로 제한하지 않는다**는 원칙을 명시한다.

이번 제작은 승인한 6개 외형을 보존한 **동작·접촉 검토 장면**이다. 기존 8,000종에 적용하거나 원정의 생물 전투를 교체한 상태와 구분한다. 원정·협동·저장에 쓰는 모듈은 이번 작업에서 수정하지 않았다.

## 2026-09-12 후속 — 빠른 이동과 노란 원형 효과 제거

사용자는 대표 6종의 외형·동작을 승인하고, 느린 이동에서만 자연스러운지 확인하기 위해 빠르게 달리는 상황을 보완하도록 했다. 타격 때 노란 원형 효과는 제거한다. 이 승인을 전체 종 교체로 확대하지 않는다.

기존 9개 동작을 보존하고 각 전용 골격에 `run_loop`를 추가한다. 걷기/빠른 이동은 이동 거리와 보폭·지지 시간·주기를 함께 맞추며, 경계에서 걷기/빠른 이동이 반복 전환되지 않도록 속도 기준을 나눈다. 가속과 감속 중에도 발 교대 위상을 이어 간다. 사족은 빠른 대각 교대, 다족은 세 발 지지 교대, 도약형은 압축/도약, 무족은 몸통 파동, 날개형은 날갯짓을 사용한다. 공격 준비·방출·회복과 공격 속도는 이동 배속의 영향을 받지 않는다.

| 대표 | 걷기 m/s | 빠른 이동 m/s | 기존 걷기 대비 |
| --- | ---: | ---: | ---: |
| 갈래돛 초식수 | 0.97 | 2.68 | 2.8배 |
| 여섯발 그늘사냥꾼 | 0.74 | 2.13 | 2.9배 |
| 숨항아리 포격수 | 0.39 | 0.75 | 1.9배 |
| 접등 도약수 | 0.95 | 2.78 | 2.9배 |
| 갈대막 분사수 | 0.71 | 2.02 | 2.8배 |
| 겹막 활공수 | 1.17 | 2.71 | 2.3배 |

위 수치는 검토 장면의 동작 기준이며 원정 전투 밸런스가 아니다. 묵직한 세 발 포격수를 다른 생물과 같은 속도로 강제하지 않는다. 더 높은 이동 속도나 큰 체형 변화에는 추가 조정이 필요하다.

노란 지면 확장 링과 일반 생물 명중 때의 둥근 황색 먼지를 제거했다. 짧은 각진 접촉 표시·피격 동작·물리 파편과 액체 비산은 유지하며, 실드의 청록 방어 반응은 보존한다. 기존 공용 총기 이펙트를 변경하지 않고 대표 생물의 효과 연결만 수정했다.

[빠른 이동·수정된 타격 영상](media/creature-speed/contact-review.mp4) · [6종 동시 비교](media/creature-speed/contact-motion.webp) · [확인 근거](media/creature-speed/evidence.json). 이전 느린 검토 영상은 아래 이력으로 보존한다. Godot 4.7.2 / Metal Forward+에서 대표 6종의 빠른 이동과 명중/실드/회피 18사례를 확인했다. 최종 영상은 30fps·93.8초다. 기존 9클립씩 총 54개 동작의 출력 데이터를 이전 GLB와 비교해 동일함을 확인했고, 각 골격에 빠른 이동 클립만 하나씩 추가했다. 승인 메시도 보존했다. 경사·험지·임의의 더 높은 속도·원정/협동까지 확인한 결과는 아니다.

재현: 기존 Blender 원본에서 `tools/refine_creature_motion.py`를 실행한 뒤 `./tools/godot.sh --script res://scripts/showcase/creature_contact_lab.gd -- --speed-review`로 걷기→가속→빠른 이동→감속→정지와 타격을 확인한다. 대표당 현재 10클립이며 아래 9클립 수량은 최초 제작 시점의 기록이다.

## 1. 여섯 리깅으로 통일하지 않는다

실행 카탈로그의 동물은 5,600종이다. 현재 메타데이터에는 체형/기존 가족 구분 93개, 스킨 골격의 `layout` 이름 15개, `template` 이름 301개가 기록돼 있다. 이 숫자는 **기존 데이터의 분류명 집계**이며 301개의 완성도 높은 리깅을 이번에 만들었다는 뜻이 아니다. 구형 700동물에는 같은 스킨 템플릿 필드가 없다. [분류 집계와 원칙](media/creature-motion/rig-diversity.json).

| 생물 구조 | 따로 맞춰야 할 골격·움직임 |
| --- | --- |
| 사족·두발 | 다리 비율, 무릎/발목 방향, 견갑·골반, 발굽/발바닥/발톱, 체중 이동 |
| 다족·절지 | 다리 수와 지지 조합, 몸통 마디, 집게·낫팔, 개별 관절 축과 공격 중 지지발 |
| 방사형·고리·항아리·기둥 | 방사 대칭/비대칭, 중심축·분기, 지지 조직, 압력 기관·밸브·섭식부 |
| 무족·리본·나선·연쇄 | 실제 몸통 분절, 배면 접촉, 파동 진행, 감김/펴짐과 목·구강의 독립성 |
| 날개형 | 주익/보조익, 날개 손가락과 막, 비행근, 꼬리 조향, 접는 다리와 착륙 |
| 수중·대기 부유형 | 지느러미·막·분사·부력 조직, 물/대기 속 추진, 가스행성 관측 표현 |
| 분지·군체 | 분기별 변형, 개체/군락의 독립 반응, 지지와 섭식의 중심, 군체 전체의 전파 |

같은 사족형이라도 관절 방향·중심 질량·사지 수·몸통 분절·공격 기관이 다르면 별도 리깅을 만들거나 수정한다. 색·크기만 바꾸거나 공통 강체 흔들림만 적용한 것을 전용 리깅 완료로 기록하지 않는다. 구조가 호환된다고 확인한 경우에만 골격 일부와 동작 원리를 재사용한다.

**공유하는 것은 접촉 결과·발사/명중 시각·피해와 표현의 연결 규칙이다.** 특정 골격 수나 이름으로 생물의 다양성을 제한하지 않는다. 검토용 `sailhorn` 등 여섯 ID에 기존 종을 자동 배정하는 변환표도 만들지 않았다.

## 2. 승인 외형을 보존한 동작 수정

새 제작기는 기존 `.blend`를 열어 **정점·면을 변경하지 않고** 액션과 접촉점을 작성한다. 수정 전후 메시 해시가 같은지 확인했다. 153의 원본·GLB·승인 이미지는 보존하고 새 결과는 `creature_studies_motion`에 출력한다.

| 항목 | 이번 변경 |
| --- | --- |
| 보행 | 이동 속도와 보폭/지지 시간을 연결. 제작 시 월드 기준 지지발 위치를 풀고 런타임의 수평 이동과 중복되지 않게 클립을 출력 |
| 몸의 반응 | 발 디딤과 몸통의 낮은 상하/좌우 이동, 머리 안정화와 꼬리의 지연 반응을 조정 |
| 정지·방향 전환 | `stop`, `turn_left`, `turn_right` 전용 클립과 0.15~0.18초 전환 사용. 영상의 실제 연속 흐름은 접근→정지→공격이며 회전 클립은 자산으로 포함 |
| 공격 | 준비·힘 방출·후속 동작·회복 시간을 유형별 데이터로 구분. 다족의 좌우 베기와 원거리 연속 발사는 각각 다른 시각 사용 |
| 도약 | 압축→상승→하강→착지 압축을 분리. 발의 상승량을 몸의 상승에 중복 가산하던 동작을 수정 |
| 피격·방어 | `hurt`, `blocked` 클립, 짧은 피격 색 반응, 밀림과 감쇠, 회복을 접촉 결과에 연결 |

대표당 9개 클립: `idle_loop`, `move_loop`, `feed`, `attack`, `hurt`, `blocked`, `stop`, `turn_left`, `turn_right`. 공통 클립 이름이 공통 골격이나 동일한 움직임을 뜻하지 않는다. 각 모델의 기존 전용 본과 가중치를 사용한다.

## 3. 타격은 실제 접촉 결과를 따른다

153의 검토 장면은 정해진 시각·지점에서 탄/먼지를 보여 주는 단계였다. 이번 장면에서는 뼈에 붙은 머리·발/발톱·발사점의 위치와 탄의 이전→현재 위치로 접촉을 계산한다. 접촉 이벤트가 발생해야 피격·실드 손실·소리·효과가 나온다.

| 공격 | 타격과 표현 |
| --- | --- |
| 돌진 | 머리 접촉점의 이동 구간을 검사. 준비 자세→앞으로 밀기→접촉→짧은 멈춤과 회복. 한 공격에서 중복 피해 방지 |
| 두 번 베기 | 좌/우 전지 접촉점을 별도로 추적. 각 베기에 한 번씩 피해·짧은 궤적·피격 반응 |
| 곡사 포격 | 준비 때 목표 방향을 확정하고 실제 발사점에서 포물선 탄 생성. 비행 중 생물/실드/지면 중 먼저 닿는 곳에서 파편·착탄 반응 |
| 도약 착지 | 실제 도약 클립의 착지 시각과 두 발 접촉 위치를 사용. 착지 반경 안의 대상에만 반응, 지면 충격과 낮은 먼지/파편 |
| 액체 분사 | 실제 구강에서 세 발 분사. 각 액적의 경로·명중을 분리하고 짧은 비산과 지면 잔액을 표현 |
| 골침 | 두 발의 골침이 진행 방향을 향하며 이동. 각 이동 구간의 접촉을 검사하고 피격/실드 반응 연결 |

실드에 닿으면 실드 손실·청록 파편과 짧은 방어 반응을 사용한다. 회피한 생물에게 피격 효과를 강제로 주지 않으며 탄은 계속 날아가 지면에 닿는다. 공격 시각 전체를 느리게 만드는 대신 근접 접촉에 30~45ms의 짧은 정지를 사용하고 투사체·피격체·효과의 시간은 계속 진행한다. 카메라 반응은 0.007~0.018m로 제한했다. 이 수치들은 검토 장면의 초기 표현값이며 확정 전투 밸런스가 아니다.

접촉 대상은 검토 장면의 몸통 타원체와 지면이다. 정교한 부위별 히트박스·관절별 피해·엄폐 충돌·네트워크 권한/호스트 시간·협동 동기화는 후속이다. 장면 안의 실제 체력/실드 계산을 원정 전투 전체에 적용했다고 기록하지 않는다.

## 4. 결과와 실제 확인

[이동·명중·방어·회피 영상](media/creature-motion/contact-review.mp4) · [타격 모음](media/creature-motion/impact-board.jpg) · [동작 비교](media/creature-motion/contact-motion.webp) · [검토 결과](media/creature-motion/evidence.json).

Blender 5.2.1 원본 렌더와 Godot 4.7.2 / Metal Forward+ / Apple M2에서 실제 모델·클립·접촉·소리를 재생했다. 원정 플레이나 전체 게임 성능 측정과 구분한다. 카메라를 타격면이 보이는 쪽으로 조정하고, 생물 표면의 짧은 피격 반응도 추가했다.

6대표 × 명중/실드/회피의 18사례에서 명중 피해와 공격별 타수, 방어 시 실드 손실·체력 보존, 회피 시 체력 보존을 확인했다. 중복 피해 이벤트는 0개다. 빗나간 원거리 탄과 착지 공격에는 지면 접촉이 남으므로 접촉 수가 0이어야 한다는 조건으로 검사하지 않았다. 기존 8,000종 카탈로그를 수정하지 않았고, 승인 메시와 기존 GLB 12개의 보존을 확인했다. 구체적인 수치와 출력 해시는 검토 결과에 기록했다.

최종 영상은 30fps·69.8초이며, 실제 출력 오디오의 신호와 클리핑 0개를 확인했다. 동작 비교 WebP는 174프레임이다. 주관적인 청감 평가는 아직 확인하지 않았다.

효과음은 기존 ElevenLabs의 경고·타격·피격·실드·물 분사 5개 원본 계열을 재사용했다. [재사용·믹스·미생성 프롬프트](../../audio/manifests/creature-motion-reuse.json). 새 생성 도구/API 설정이 없어 생물별 전용 압력/분사/골침 음원은 미생성으로 남겼다. 실제 재생/출력 신호 확인과 주관적인 청감 평가는 구분한다.

## 5. 파일과 재현

- [`refine_creature_motion.py`](../../tools/refine_creature_motion.py): 승인 모델을 읽어 메시 보존을 확인하고 유형별 9클립·접촉점을 출력.
- [`creature_motion_profiles.json`](../../우주-비즈니스/data/creature_motion_profiles.json): 이동/타격 시각·거리·초기 표현값의 원본.
- [`creature_motion_studies.json`](../../우주-비즈니스/data/creature_motion_studies.json): 독립 결과 6개의 모델·골격·클립·접촉점.
- [`study_motion_actor.gd`](../../우주-비즈니스/scripts/actors/creatures/study_motion_actor.gd): 실제 GLB와 골격 재생, 접촉점 계산, 피격 색 반응.
- [`creature_study_contact.gd`](../../우주-비즈니스/scripts/domain/creature_study_contact.gd): 이동 구간 접촉·첫 충돌·중복 타격 방지·장면 내 체력/실드 결과.
- [`study_impact_effects.gd`](../../우주-비즈니스/scripts/actors/creatures/study_impact_effects.gd): 접촉 결과를 따르는 파편·궤적·충격과 음원. 효과 입자 96개·음성 12개 상한.
- [`creature_contact_lab.gd`](../../우주-비즈니스/scripts/showcase/creature_contact_lab.gd): 접근·정지와 명중/방어/회피의 실행 가능한 검토 장면.
- [`compose_creature_motion.py`](../../tools/compose_creature_motion.py): 실제 GPU 영상·오디오와 모음판을 정리하고 18사례의 타수/체력·출력 파일·기존 승인 GLB 보존을 확인.

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/refine_creature_motion.py
./tools/godot.sh --script res://scripts/showcase/creature_contact_lab.gd
# 특정 대표만 재생할 경우 마지막에 -- sailhorn 등을 추가
```
