# 플레이어 복원 결과의 우주 외형 연결

2026-09-10 사용자 요청: 직접 테라포밍한 행성의 외형도 우주에서 실제로 변하게 한다. 후속 선택으로 **복원한 지역부터 녹지·물·대기가 퍼지는 모습**을 확정했다. 기존 지역 계약을 행성 전체 복원 판정으로 바꾸지 않는다.

## 현재 구현

`FrontierOrbitalTerraform`은 호스트가 보유한 사업 원장을 읽어 진행 중/정산 완료 행성의 시각 상태를 산출한다. 신규 자유 배치의 실제 처리 셀과 구면 대기, 이전 지역 구획 및 단일 지역 환경을 지원한다. 정산 후 생산 거점 보유와 시설 인계 모두 포함한다. 이미 완료한 기존 저장도 같은 기록을 읽으므로 다시 정산할 필요가 없다.

- 녹지: 실제 생태량·수분·온도·기압·오염·토양/염류 조건으로 피복을 혼합한다. 지질과 기존 고원/분지 형상은 유지한다.
- 물과 해빙: 수분·액체 유지 조건에 따라 해당 외형의 낮은 지형에 푸른 수면과 해안을 표시하고, 지역 온도에 맞춰 결빙과 화산 발광을 완화한다.
- 대기: 자유 배치의 64×32 대기 원장 중 초기보다 개선된 권역을 별도 텍스처로 읽는다. 지표 식생이 아직 없어도 대기 개선을 반영한다. 원래 대기의 기압·독성 표현에서 맑은 푸른 가장자리로 변화한다.
- 구름: 수분과 대기가 함께 개선된 곳의 구름층·지표 그림자가 변한다. 원래 구름이 없던 착륙 가능 행성도 이 경로를 가진다.
- 실제 비행, 재방문 시 재생성, 미리 준비한 목적지와 근/원거리 LOD에 같은 셰이더를 적용한다. 항성지도 카드도 같은 상태·구름·대기층을 쓰고 복원 구역을 카메라 쪽으로 보여 준다. 열린 카드는 1초 간격으로 상태를 확인하며 모델을 다시 만들지 않는다. 닫힌 미리보기는 렌더를 중단한다.

호스트 스냅샷에 요약만 추가한다. 클라이언트의 성공 요청으로 외형을 확정하지 않는다. 현장 시간·복원 리비전·정산 상태별로 요약을 재사용하고, 실제 렌더 재질도 내용이 바뀔 때 갱신한다. JSON 저장의 키 정렬 전후에도 같은 결과를 얻도록 셀과 구역의 계산 순서를 고정했다.

## 표현의 범위와 저장

외형은 **게임용으로 압축한 지역 표현**이다. 지상 x/z를 테라포밍 탭과 같은 동일 면적 구면 주소에 대응시킨다. 지표 변화는 최대 16개 공간 묶음으로 합치고, 작은 생활권도 우주에서 식별되도록 최소 각반경 0.14rad를 적용한다. 부드럽고 불규칙한 경계와 환경별 혼합을 사용한다. 이 반경은 실제 사업 면적이나 천체 실측 축척이 아니다. 멀리 떨어진 셀을 한 묶음으로 요약하므로 개별 건물/셀 경계까지 정확히 표현하지 않는다.

계약 성공 한 번으로 행성 전체를 초록색으로 칠하지 않는다. 대기는 저장 원장의 실제 전달 결과만 확대되고, 지표는 처리한 곳의 상태를 따른다. 외형의 해안선과 실제 착륙 지형이 동일한 지도라는 뜻은 아니다. 전 행성 해수면·구형 보행·자립 생태/기후·T4/T5 신규 계약을 추가하지 않았다.

지형·광물·시설·계약 조건·정산 금액·기존 저장 구조는 유지한다. 렌더용 요약을 영속 저장하거나 구형 은하 설정을 교체하지 않는다. 미작업 행성·거대행성·태양계와 별도로 제작된 Space Y 화성은 원래 표현을 유지한다. 원격 스캔의 기존 생성 환경 수치는 전 행성 복원 상태로 바꾸지 않는다.

## 제작과 확인

기존 Blender 행성 메시·근/원거리 자산과 INK v1을 재사용했다. `render_orbital_terraform_sources.py`로 산화 사막·균열 빙원의 `.blend`를 직접 열어 Cycles 렌더로 확인했다. 원본/GLB를 수정하거나 신규 모델·음원을 제작하지 않았다.

Godot 4.7.2 Forward+ / Metal 실제 창에서 다음을 확인했다.

- `check_orbital_terraform.gd`: 준비된 기후·셀에서 실제 계약 정산, 호스트 스냅샷, 복원 전/진행/후 렌더, 디스크 JSON 재로드, 기존 사업 저장 검증, 보유/인계·구 단일 지역 기록·화성 제외, 재방문·원거리 LOD. 15개 확인, 실패 0.
- `check_orbital_terraform_play.gd`: 격리된 새 원정의 실제 스냅샷→외부 행성→항성지도 카드, 열린 카드의 환경 갱신/모델 재사용, 960×640 화면, 닫힌 카드 렌더 중단, 기존 선박 사운드 레이어 연결. 7개 확인, 실패 0.
- `git diff --check`: 공백 오류 없음.

수동 채집부터 계약을 완주한 검사는 아니다. 검수용 준비 환경을 사용했고 실제 사용자 저장은 열거나 수정하지 않았다. 모든 시드·한랭/화산 행성 전수 게임 렌더·다중 클라이언트·Windows·장시간 성능과 청감 검수는 수행하지 않았다. 선박 음원은 기존 연결을 확인했으며 새로운 복원 전용 효과음을 추가하지 않았다.
