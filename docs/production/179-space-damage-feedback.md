# 우주전 피격음·피해 숫자

2026-09-14 사용자 요청: 우주전의 피격 사운드를 확인하고 지상과 같은 데미지 수치를 표시한다.

## 확인한 누락과 수정

우주전에는 `impact → sfx_gun_impact`, `break → sfx_shield_break`와 미사일 폭발음이 이미 연결돼 있었다. 일반 실드/선체 피격의 음향 구분과 피해 숫자는 없었다. 지상 `firearm_damage_numbers.gd`를 그대로 재사용해 대상별 합산·상승/소멸·실드 아이콘·파괴 표식·격파 표식을 우주 HUD에 연결했다. 실드만 줄면 청색, 선체도 줄면 장갑색으로 표시한다. 표시 위치는 해당 기체의 보간된 위치를 따라간다.

피해 함수에서 확정한 실드 흡수량과 실제 선체 감소량을 기존 `impact`/`break` 사건의 선택 필드 `damage`에 넣는다. 기본 함포·미사일·피해 스킬·선체 접촉은 같은 피해 함수를 거친다. 표적 피해 증가 효과를 포함하고 과잉 피해는 남은 실드/선체보다 크게 표시하지 않는다. 빗나감·이미 격파된 대상·빈 실드에 실드 전용 공격을 한 경우는 숫자를 만들지 않는다. 자기 선박 피격은 기존 실드/선체 게이지·방향 피격 표시를 유지하고 숫자는 지상처럼 적 대상에 붙인다.

일반 실드 타격에는 기존 ElevenLabs `sfx_gun_hit_shield`를 추가 연결한다. [지상 무기 음원 이력](../../audio/manifests/ground-weapon-feedback.json)의 재사용이며 신규 음원 생성은 없다. 선체 타격·실드 파괴·미사일 폭발의 기존 음원, 비행 SubViewport의 3D 청취자와 거리 감쇠를 유지한다. 각 사건의 실제 흡수량으로 실드 효과/소리를 판단해 같은 스냅샷 안에서 뒤늦게 실드가 깨졌더라도 앞선 타격을 선체 피격으로 오인하지 않는다.

## 행동 범위·기존 저장

- 입력 → 기존 호스트 명중/피해 함수 → 해당 실드·선체와 기존 사건 1개 → 현재 스냅샷 → 사건 순번을 한 번 소비 → 해당 숫자/피격 효과·소리의 경로다. 같은 스냅샷 재처리는 합산/소리를 반복하지 않는다.
- 숫자는 지상과 동일하게 최대 16개, 0.75초 이내 연타 합산, 마지막 타격 후 0.95초 수명이다. 현재 모델 사전에서 해당 기체 위치만 조회하며 모델·지형·아이템 카드 재생성을 추가하지 않는다. 사건 큐는 기존 최대 32개를 유지한다.
- 별도 RPC·전체 저장·전체 은하 복사·캐시 무효화를 추가하지 않았다. 기존 호스트 스냅샷의 `crew` 깊은 복사, 기존 전투 저장/검증 비용은 남는다. 이번 작업이 그 공통 비용을 제거했다는 뜻은 아니다.
- 메뉴에서는 숫자와 소리를 지우고 사건 순번을 소비해 닫은 뒤 과거 피격을 재생하지 않는다. 다른 항성계/전투 밖 숫자도 지운다.
- 새 피해 필드는 선택 사항으로 유효성 검사한다. 필드가 없는 기존 저장의 사건은 그대로 허용하고 임의 피해 수치를 추정하지 않는다. 저장된 과거 사건은 최초 접속 때 재생하지 않으며 새 타격부터 숫자가 표시된다.

## 최소 확인

호스트 피해 규칙 검사는 9항목 통과했다. 실드/선체 분리·실드 파괴·과잉 피해·빈 실드·격파 대상 중복·자기 선박·JSON 왕복·잘못된 피해 필드·기존 사건 호환을 확인했다. 현재 Godot 4.7.2 / Metal Forward+ / Apple M2 원정 검수 19항목도 통과했다. 실제 함포 피해 16, 실드 16+선체 10의 합산 26과 실드 파괴 표식, 연타 18+2의 합산 20, 실제 미사일 명중 피해 44를 확인했다. 같은 사건 재소비 방지·자기 실드 피격·메뉴 정지/재개·현재 세션 저장도 확인했다. 1280×800과 960×640 화면에서 숫자·색·표식을 시각 검수했다.

7.04초 SFX 버스 녹음에서 피크 0.213, RMS 0.0170, 클리핑 표본 0을 확인했다. 음원 재생·출력 신호 확인이며 주관적인 청감 승인과 구분한다. 원본 녹음은 `output/space-damage-feedback/hit-feedback-sfx.wav`에 보존한다. 최종 실행에 스크립트 오류는 없었다. 첫 실행에서 발견한 새 연결부의 좌표 형식 불일치는 배열 전달로 수정했고, 검사 기대값에 영향을 주던 ORION 표적 강화와 AI 시간 진행은 검수 장면에서 분리했다.
