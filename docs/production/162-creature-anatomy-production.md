# 다수 종의 해부 구조별 연속 제작

2026-09-12. 사용자는 승인 품질을 유지하며 전체 동물 5,600종의 리모델링을 끝까지 계속하도록 요청했다. [155 전체 제작 소관](155-creature-remodel-rollout.md)을 따른다. 이 기록의 첫 완료 범위는 **R03 대표 98종**이며, 앞선 65종과 합쳐 일반 원정 표시 **지상 162·비행 1종**이다. 나머지 제작 중인 파일과 전체 4,333종의 공정 대응을 적용 완료 수에 포함하지 않는다.

## 제작 구조

원본 `biota_forms.json`의 지상 동물 중 14개 구성에 해당하는 4,333개 ID를 읽는다. 방추·엽족·방사·탑·안장·외투·나선·편평·연쇄·쌍체·관·항아리·띠·가지 몸 구조에 일곱 기관 계통을 연결한다. 중간 체형 교체종 178개, 비행·부유형 384개, 기존 동물 중 미교체 640개는 각각 별도 제작 대상이다. 이 공정에 맞지 않는 종을 공통 몸체로 처리하는 대체 경로는 없다.

각 종은 연속된 피부, 지지 사지의 상·하 관절과 발, 몸통의 부모-자식 연결, 실제 말단 기관과 입 소켓을 갖는다. 수축하는 마디형 구강, 배면 여과구, 가지 끝의 개별 입, 달팽이형 감각 자루, 긴 목의 두개골과 하악을 구분했다. 일곱 기관 계통은 갑판·아가미·큰턱·감각 부채·분사관·돛막·촉수의 실제 메시와 관절을 사용한다. 색·크기만 바꾼 것을 구조 다양화로 집계하지 않는다.

종마다 Blender 원본과 두 단계 GLB, 11개 동작, 원본 렌더를 저장한다. 게임 검토는 기존 T5 도주 속도 4.025m/s까지의 가속·감속·정지 선회·섭식, 공격 준비/타격/회수, 무력화·원거리 LOD를 사용한다. R03 대상은 원래 호스트 공격 성향이 없는 종이며 공격 동작 검토를 신규 피해 판정의 활성화로 해석하지 않는다.

## 현재 확인한 범위

- 98종의 서로 다른 정규화 메시와 **68가지 이름을 제외한 관절 연결 구조**를 확인했다. 14개 체형별 정지 화면 전체와 빠른 이동/타격 화면을 검토했다.
- Godot Forward+ / Metal에서 종마다 실제 스킨을 240단계 구동하고 9개 상태 화면을 저장했다. 루트 위치 오차 0, 최대 발 접지 오차 약 **7.8mm**였다. 임포트 전 최신 GLB를 직접 읽는 검토 경로를 사용했다.
- 두 LOD의 정규화 스킨 가중치, 유한 좌표, 11개 클립, 반복 동작의 시작/끝 연결과 내보낸 해시를 확인했다. 원본 생물 카탈로그 네 파일의 해시를 보존했다.
- 게임에서는 종별 작은 메타데이터를 필요할 때 한 번 읽고 재사용한다. 생물 하나의 표시 변경을 위해 전체 월드 저장·동기화·다른 생물 모델 재생성을 수행하지 않는다.

Blender 원본 검토의 조명·카메라·해상도는 유지하고 EEVEE의 광선 추적·접촉 음영을 사용했다. 전달 품질 판정은 기존 Godot INK v1 렌더를 사용한다. 승인작의 Cycles 참조는 보존한다.

## 재개와 완료 판정

`run_production.py`는 서로 겹치지 않는 종을 네 Blender 작업으로 나눈다. 이는 로컬 제작 프로세스이며 작업 에이전트나 예약 자동화가 아니다. 종별 입력과 제작 코드의 지문, 실제 GLB 해시가 같으면 재출력을 건너뛴다. 중간 실패한 파일은 완료로 등록하지 않는다. `publish_manifest.py`는 현행 지문에 맞는 완성 자산만 공개하고, 게임 렌더와 화면 확인 후에만 표시 목록에 등록한다.

이 제작은 사용자가 요청한 전체 명부를 처리하는 오프라인 작업이다. 실행 중 게임의 한 행동이 명부 전체를 다시 처리하는 기능과 구분한다. 큰 종별 루프의 근거는 전체 리모델링 요청이며, 월드·저장 데이터는 읽기만 한다.

현재 다수의 기관과 큰 분기 구조를 갖는 추가 98종을 제작·확인 중이다. 전체 5,600종 완료, 저장된 생물 사건의 새 치수 적용, 비행/부유 전수 제작, 새 음원 생성과 전체 원정 회귀 검사는 이 기록의 완료 범위에 포함하지 않는다.
