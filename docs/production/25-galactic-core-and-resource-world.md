# 자원 기반 은하와 중앙 블랙홀

2026-09-06 사용자 요청. 기존 광물·보석 A/B 모델을 기반으로 하나의 은하에 자원을 분포시키고, **지구가 있는 외곽은 저티어·중심에 가까워질수록 고티어 비중이 증가**하도록 유지한다. 중앙 블랙홀은 큰 시각적 이정표로 강조한다. 단순 고리·막대처럼 보였던 첫 형태는 사용자 피드백으로 교체했다.

## 이번 결과

- 단일 은하의 125,000개 항성계·1,000,000개 행성 주소와 지구 출발을 유지한다. 행성 목록 전체를 메모리에 만들지 않는다.
- 착륙 가능한 행성에 지질 8종의 시드 기반 프로필을 부여한다. 주력·보조 광물, 지하 보석과 상위 특이 소재가 행성마다 달라진다.
- 80m 단위 지역에서 지표·지하 광맥을 필요할 때 계산한다. 일반 지역은 주변 9개 타일, 최대 63개 후보만 조회하며 별도로 시작 광맥·동굴 보석을 유지한다.
- 지하 광체는 상부가 노출되어야 표시·채집된다. 기존 동굴에는 실제로 접근 가능한 보석을 배치했다. 레이더의 광물 접점은 지하 후보도 포함한다.
- 호스트 채집·배낭·창고·채광 효과 및 아이콘을 신규 자원에 연결했다. 미채굴 타일 전체를 저장하지 않고 수정한 광맥 잔량을 보존한다. 로봇은 지표 광맥을 배정할 수 있고 지하 작업 배정은 현재 경로 지원 범위 때문에 거절한다.
- 상세 생성·저장 구조는 [기술 문서](../technical/06-mineral-galaxy-open-world.md)를 따른다.

## 중앙 블랙홀 제작·확대

[Blender 생성기](../../tools/build_galactic_core.py), [원본 기록](../../art/blender/galactic-core/manifest.json), [실제 게임 이미지](media/mineral-galaxy/black-hole-hero.png)를 보존한다.

연속 강착 원반은 512×192 분할, 휘어진 후면 원반은 상하 각각 320×80 분할로 만들었다. Blender에서 가스층의 명암·색·투명도를 정점 채색했다. 불투명한 검은 중심과 발광 가스의 대비를 우선하며, 제트는 끝이 막힌 원통 대신 투명도가 줄어드는 열린 가스층 6개로 구성한다.

Godot의 실제 `FrontierGalacticCore`는 원본 GLB를 읽고 가스 흐름의 시간 변화, 비대칭 밝기, 거리별 미세 무늬 완화와 발광을 적용한다. 불투명 중심은 공통 INK 경로이며 가스층은 투명 발광 효과용 셰이더다. 금속 재질·다른 불투명 조명 체계로 바꾼 것이 아니다. 블랙홀의 렌즈 효과는 조형과 가스층으로 표현한 게임 연출이며 실제 상대론적 광선 추적·중력 계산은 구현하지 않았다.

**항법창의 은하 지도 중앙을 클릭하면 큰 블랙홀 보기 창이 열린다.** [실제 확대 창](media/mineral-galaxy/black-hole-observatory.png)을 촬영했다. 중심 표식과 확대 창은 같은 GLB/효과를 렌더한다. 현재는 관측 이정표이며 블랙홀로 직접 항해·돌입하는 목적지, 중력 피해, 내부 콘텐츠는 후속이다. 숨긴 지도는 미리보기 렌더 갱신을 중단한다.

## 확인 범위

[자원 세계 검사](../../우주-비즈니스/tests/test_mineral_world.gd)에서 새 광물 채집·반납, 얻은 재료로 Mk.2 제작, 동굴 보석 채집, JSON 저장 후 재고·잔량 보존을 호스트 요청 경로로 확인했다. 가스 행성 광맥 제외, 지역 주소 상한, 옛 생성기 유지, 동일 시드 재현도 포함한다. 최종 **332개 확인, 실패 0**이다.

외곽부터 중심까지 각 권역의 40개 행성 표본 평균 티어는 **1.15 / 2.025 / 2.85 / 4.00 / 4.925**였다. 각 권역의 실제 지도 반경도 함께 확인했다. 특정 표본 결과이며 모든 행성이 중심 방향으로 한 단계씩 단조 증가한다는 뜻은 아니다. 확률 분포 자체가 고티어 쪽으로 이동한다.

[GPU 렌더 확인](../../우주-비즈니스/tests/render_mineral_galaxy.gd)은 Apple M2 / Godot Metal Forward+에서 실행했다. 블랙홀·은하 지도와 실제 지표 스트리머(75개 청크)·자원 표시(17개 엔티티)를 촬영했다. 초기 발광 셰이더와 오래된 개발 중 규칙 스냅샷의 누락 키 오류를 수정하고 최종 렌더에서 오류가 없음을 확인했다. [검증 기록](media/mineral-galaxy/verification.json)을 따른다.

현재 지표는 기존 **16.384km × 16.384km 지역**이다. 완전한 구형 행성 지표 전체의 연속 이동, 보석 강화 소비처, 지하 로봇 경로, 장시간·다중 클라이언트 실기 검증은 완료 범위에 넣지 않는다. 새 자원 분포는 **새로 만든 세계**에 적용하며 자원 규칙이 없는 기존 저장은 원래 광맥을 유지한다. 지구 지표는 실제 지리·생태의 재현이 아닌 현재 게임용 생성 지형이다.
