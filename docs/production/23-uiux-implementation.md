# FIELD v1 UI/UX 첫 적용

2026-09-06. 사용자가 공통 UI/UX의 시각 표현 우선 원칙을 문서화하고 실제 화면에도 적용하도록 요청했다. 기준은 [공통 UI/UX 가이드](22-uiux-guide.md)다.

## 변경

- 지상 상시 로고·설명문·큰 버튼 행을 숨기고 위치·귀환 거리·현재 장비/재사용 막대·소형 메뉴 아이콘·5개 장착 타일로 교체했다.
- 조준 대상에 자원 아이콘·잔량 막대·장비 최소 등급·상호작용 키를 표시한다. 공격무기로 동물을 조준할 때는 체력 막대를 제공한다.
- 아이템창을 세 열의 물건 중심 화면으로 바꿨다. 실제 INK 3D 회전 미리보기, 장비/제작/화물 격자, 선택 성능·등급·재료 보유/필요량, 하단 슬롯으로 구성한다.
- 드롭다운 장착을 없애고 선택한 소유 장비의 슬롯 클릭/끌어놓기를 연결했다. 호스트의 기존 `equipment_equip` 저장 거래를 사용한다. 같은 장비가 두 슬롯에 복사되지 않는다.
- 배낭/공동 창고의 각 자원을 아이콘·수량으로 표시하고 공동 자금은 따로 표시한다. 반납은 기존 실제 거리/원장 판정을 유지한다.
- 원정의 공통 테마와 건설·선박 정비 패널의 기본 스타일을 통일했다. 아직 두 패널의 상세 구조는 기존 방식이 남는다.
- 정상 발사의 반복 성공 문구를 제거하고 기존 펄스·반동·ElevenLabs 음원으로 전달한다. 정상 저장은 짧은 표식, 실패는 메뉴 위에 보이는 알림으로 처리한다.

## 제작물

`interface_style.gd`, `item_tile.gd`, `equipment_preview.gd`, `field_hud.gd`와 개편한 `equipment_panel.gd`. 공통 UI 코드는 `scripts/ui/`에 둔다. 메뉴 진입 아이콘 4개는 직접 작성한 SVG다.

기존 Blender 장비 3종의 모델을 재사용했다. `render_equipment_icons.gd`로 공통 INK 렌더러에서 카드용 PNG를 다시 촬영하고 `assets/ui/equipment/`에 저장했다. 신규 3D 형상·Blender 원본 변경·신규 음원 생성은 없다. 회전 가능한 선택 모델은 별도의 실제 3D SubViewport에서 렌더하며 메뉴를 닫으면 렌더를 중단한다.

## 확인 범위

Godot 4.7.2 / Metal Forward+ / Apple M2, 임시 프로필/세계와 실제 창에서 확인했다. `test_uiux_play.gd`는 기존 장비의 짧은 동작 흐름에 새 화면과 장착 조작을 추가한다. 재료와 광맥 접근 위치는 기존 제한된 검사 상태다.

초기 작은 화면에서 상세 영역의 최소 높이 때문에 제작 버튼이 밀리는 오류를 발견했다. 간격·본문 최소 높이를 수정하고 **25개 확인 항목, 실패 0**을 기록했다. 실제 모델·7개 시각 설계도·기존 HUD 숨김·960×640 레이아웃·슬롯 클릭·드롭 처리에 의한 이동·제작·굴착·장비별 음원·등급 채광·메뉴 차단·저장/호스트 재개를 포함한다. 이 검증을 모든 화면의 사용자 경험 검증으로 확대 해석하지 않는다.

공통 폰트의 기본 가변 굵기가 지나치게 얇게 보이는 문제는 명시적 500 굵기로 수정했다. 메뉴는 깨끗한 글자, 경관 위 HUD는 작은 그림자로 구분했다.

끌어놓기는 타일의 드롭 처리 호출로 확인했으며 실제 포인터 드래그 전체 흐름과 모델 회전 드래그는 별도로 확인하지 않았다. 집중 동작 확인 이후 작은 표현 변경은 파싱/임포트와 최종 실제 창 렌더로 확인했다. 최종 화면은 임시 세계 복사본이며 자원 수량을 가독성을 위해 조정했다.

공격 대상 체력 막대의 동물 실기, 다중 클라이언트, 전체 회귀, 장시간 성능, 패드/접근성 전체 검사는 이번 범위에 포함하지 않았다. 기존 3D 프레임률을 새 UI 성능으로 재인용하지 않는다. 메뉴 미리보기는 열려 있을 때만 렌더하지만 실제 대규모 원정의 추가 렌더 비용은 후속 측정 범위다.
