# 무기 최소·최대 피해와 품질 ±20%

2026-09-14 사용자 확정: 개체의 최소~최대 피해를 생성/저장하고, 피해 품질은 기준값의 **±20%**로 한다. [무기 소관](../game/29-weapon-loot-and-elements.md)의 후속 구현이며 기존 [186 드롭 개편](186-weapon-loot-and-elements.md)을 확장한다.

## 실제 적용

- 새 일반 제작품과 새 무작위 사건 전리품에 품질 0.8~1.2를 등급/옵션과 독립적으로 추첨한다. 동일 모델·등급에도 기본 피해 차이가 생긴다.
- 현재 고정 피해 D를 평균으로 유지하는 기준 범위 `0.8D~1.2D`를 둔다. 이 범위 폭은 구현 선택이고 사용자 확정인 개체 품질 ±20%와 별개다. 품질은 양 끝값에 공통으로 곱한다. 기준 20~30이면 최저 품질은 16~24, 최고 품질은 24~36이다.
- 기존 D에 대한 개별 타격의 전체 가능 폭은 품질과 타격 편차가 합쳐져 0.64~1.44배다. 피해 옵션·속성·약점·신체/모듈은 기존 순서에 적용한다. ±20%를 최종 타격의 절대 상한으로 표시하지 않는다.
- 사격이 실제로 허용된 후 호스트가 피해를 한 번 추첨한다. 같은 산탄 사격의 탄립은 공통 추첨값을 쓰고, 물리 탄도 큐에 그 값을 보관한다. 직접 명중/방벽/폭발에 동일 값과 각각의 기존 감쇠를 적용한다.
- 레이저는 기존 탄약/과열이 진행되는 한 판정마다 추첨한다. 장전·과열·총구 막힘·잘못된 요청 등 실패에는 추첨 순서를 전진시키지 않는다.
- 평균 DPS와 연소/전설의 기준 피해는 범위의 평균을 사용한다. 직접 타격의 행운이 지속 피해를 추가 증폭하지 않는다.
- 상세는 최소~최대 피해와 평균 DPS를 표시한다. 제작 미리보기는 기준 범위와 품질 80~120%를 안내하고 임의의 결과를 확정품처럼 보여 주지 않는다. 장착품 비교는 같은 무기 자체 성능 기준으로 맞췄다.

## 저장·개조 경계

새 `weapon_rolls.damage_profile`에 버전·품질·기준 최소/최대·생성 최소/최대를 함께 저장한다. 옵션과 별개인 하위 프로필이어서 기존 `roll_version=2`를 재작성하지 않는다. 이미 보유한 무기·이미 확정된 전리품·기존 확정 장비 보상은 재추첨하지 않고 프로필이 없으면 기존 고정 피해를 유지한다.

`weapon_states.damage_shots`에 사격 추첨 순서를 저장한다. 호스트 월드 시드·소유자·무기 ID·저장된 순서로 피해 난수를 만들며 클라이언트 요청의 피해값을 받지 않는다. 중복 요청은 기존 결과를 반환한다. 품질 범위, 역전된 피해 범위, 생성값과 품질의 불일치, 비정상 순서는 저장 검증에서 거절한다.

일반→매직 개조안에서는 원본 `damage_profile`을 그대로 보존하고 옵션만 추가한다. **매직 개조 기능과 설치형 제작대는 이번 작업에서 구현하지 않았다.** 개조용 원본 무기 품질을 유지하는 규칙을 소관 문서에 반영했다.

## 단일 행동 범위

생성은 기존 개체/전리품 결과에 작은 프로필 하나를 추가한다. 사격은 해당 무기의 정수 순서 한 개와 기존 발사 결과에 피해값 한 개를 추가한다. 물리 탄도는 이미 생성하는 해당 사격의 스냅샷에서 값을 읽는다. 피해 추첨을 위해 세계를 복사하거나 파일을 새로 저장하거나 다른 무기를 순회하지 않는다.

기존 발사 중복 처리와 체크포인트/직렬화 경로를 유지한다. 실패 발사와 중복 요청에서 순서/탄약이 늘어나지 않는 것을 확인했다. 닫힌 아이템창은 기존 갱신 차단을 유지하고 열린 상세에서만 피해 범위 문자열을 계산한다. 무기 상태 변화만으로 전체 아이템 목록을 재생성하는 코드를 추가하지 않았다.
