# SP06 — Space Y 항만 경비 편대

2026-09-10 구현. [SP05 무역선](113-space-y-freighters.md)에 WARDEN 경비기를 추가했다. 새 세계의 `corporate_space.traffic.patrol` v1에서 지구·화성 항만마다 2기를 생성한다. 기존 SP05 저장은 무역선 2척을 유지하며 경비대를 소급 생성하지 않는다.

## 기체와 운항

WARDEN은 CARRIER의 긴 화물 레일과 구분되는 후퇴익·분리 쌍발 엔진·경사 수직 안정판·하부 무장·기수 센서 기구를 갖춘다. Space Y 날개/상부 심볼은 기존 벡터 원본에서 만든 실물 표식이다. `tools/build_space_y_fighter.py`는 공통 Blender 산업 제작/내보내기 도구를 사용한다. 원본에는 개별 부품을 유지하고 GLB에는 부모/재질별 정적 면을 묶었다. 근거리 15메시·12,016삼각형, 원거리 14메시·852삼각형이다.

항만 외측의 타원 순찰선에서 180m 편대를 유지한다. 호스트가 항만 3,500m 안으로 진입한 원정선 또는 FINCH를 인지하면 확인 접근 12초→센서 확인 6초→순찰 복귀 12초를 진행한다. 이 값들은 저장 설정의 초기 조정값이다. 확인 중 동일한 선박 주소의 위치를 갱신하고, 신호가 영역을 벗어나면 마지막 수신 위치를 확인한 뒤 복귀한다. 천체 안전 경계를 보정하고 무역선/플레이어 주변을 비켜 간다. 실제 가속도·강체 충돌 기반 편대 AI는 아니다.

편대별 시작 시간·대상 선박 주소·수신 위치·재진입 가능 상태를 `navigation.traffic_patrols`에 저장한다. 동일 체류 중에는 다시 확인하지 않는다. 확인 시작 뒤 90초가 지나고 선박이 영역을 벗어나 있으면 재활성화해 다음 방문부터 반응한다. 시작 시각과 관측 위치는 호스트가 결정하고 모든 소형선 항해 스냅샷에 전달한다. 클라이언트는 공유 시간에서 모델 자세와 위치를 재현한다. 재접속으로 별도 검문/보상을 생성하지 않는다.

엔진 자세·추진광·기체 기울기·센서 회전이 상태에 연결된다. 주시 HUD는 두 기체 형상과 편대 역할을 보여 준다. 무역선용 화물 슬롯은 경비기에서 표시하지 않는다. 센서/복귀 관제 신호는 기존 ElevenLabs 음원을 사용하고 다른 선박 신호와 15초 간격을 공유한다. 가까운 두 기체가 동시에 같은 말을 반복하지 않는다. 메뉴/숨김 화면에서는 주시 정보와 음향을 차단한다. 신규 음성·음원 생성 및 주관적 청감 확인은 수행하지 않았다.

플레이어의 항해·거래·첫 출항을 막지 않는다. 무장 외형은 존재하지만 발사·피해·적대 판정·전투 임무를 추가하지 않았다. 운항 규칙은 NPC 회사 활동이며 플레이어 자동 물류와 경제 재입고를 제공하지 않는다.

## 실제 확인

Godot 4.7.2 Forward+ / Metal / Apple M2의 현재 원정 앱에서 [17항목](media/corporate-space/fighter-check.txt)을 확인했다. 6기체 모델, 호스트의 센서 단계 전환/관제 이벤트, 편대 간격/천체 회피, 체류 중 재확인 방지, 재접근 대기, LOD, 960×640 HUD, 메뉴 음향 차단, 저장 후 같은 ID/위치/진행을 확인했다. 테스트의 편대 관찰 카메라는 실제 비행 렌더러에서 별도로 고정했으며, 실제 조작으로 30초 전 과정을 따라간 검사는 아니다.

후속으로 이동하는 확인 대상을 같은 선박 주소로 추적하고 경비기가 무역선을 피하도록 보완했다. 최초 추적 확인은 관심 영역에 선박 주소가 누락돼 실패했으며 필드를 연결한 뒤 [해당 부분만 재확인](media/corporate-space/fighter-follow.txt)했다. 동일 시드의 왕복 1,200초를 샘플링한 최솟값은 NPC 사이 약 180m다. 이 후속 결과를 다른 모든 시드/조건의 충돌 보장으로 확대하지 않는다. 최종 편대 이미지는 이 보완 후 같은 Forward+ 렌더러에서 확인했다.

실제 다중 클라이언트·Windows·다중 시드 전수·장시간 성능은 검사하지 않았다. 현재 같은 항성계 6기체를 매 프레임 표시하며, 시드별 기업 활동 지역과 다수 먼 항로의 저빈도 계산은 SP07에서 확장한다. CooperTech와 mine/Lotus 우주 흔적은 이후 SP08·SP11 범위다.
