# 공통 UI 정돈·실드 상태 아이콘

2026-09-11. 사용자 요청은 실드처럼 다른 시각 언어가 섞인 부분을 통일하고 UI/UX를 더 깔끔하게 만드는 것이다. 공통 규칙은 [FIELD v1](22-uiux-guide.md)에 두며 이 문서는 실제 변경과 확인 범위를 기록한다.

## 후속 정정 — 같은 색·게이지 위 숫자

사용자는 실드 아이콘의 색도 다른 상태와 같게 만들고, 회복 중 등 상태 문구를 아예 삭제하며 숫자를 게이지 위에 배치하도록 정정했다. 아래 최초 적용의 청색 실드/옆 수치/상태 문구는 이전 이력이다.

- HUD의 세 상태 아이콘과 모듈 화면의 실드 요약 아이콘을 같은 공통 청록색으로 맞췄다. 낮은 체력/스태미나 소진에도 아이콘 자체는 같은 색을 유지한다.
- `FrontierStatusMeter`를 상단 아이콘/우측 숫자 → 하단 게이지로 바꿨다. 게이지 폭을 고정하고 이동 키 안내 길이에 따라 흔들리지 않게 했다.
- 상태 Label과 문구 생성 경로를 제거했다. 충전/회복/위험/미장착·지속 효과 문구를 상시 표시하지 않는다. 미장착은 `—`와 빈 게이지, 낮은 체력/스태미나 소진은 숫자와 게이지의 주황색으로 표시한다. 이동 키 안내와 순간 피격/소진 사건 피드백은 유지한다.

후속 최소 확인: Godot Forward+ 실제 1280×800·960×640에서 기본/충전·낮은 체력·스태미나 회복·미장착 화면을 확인했다. 세 아이콘은 모두 `83d9c5ff`이며 숫자는 각 게이지 위에 있다. 960px 창에서 상태 영역 하단 554px, 단축키 상단 572px로 겹치지 않는다. 표시 변경만 촬영했고 이전 조립/장착·전체 회귀를 반복하지 않았다. 촬영은 정상 완료했으며 스크립트 오류는 없었다. 검수 프로세스 종료 시 ObjectDB 인스턴스 1개 잔류 경고는 별도로 기록했고 원인 추적은 이번 HUD 확인에 포함하지 않았다.

## 최초 적용

- 실드 HUD의 광물용 `shielding_material.svg`를 전용 방패 선 아이콘으로 교체했다. 자원용 아이콘은 보존했다. 체력·스태미나와 원본 크기·선 굵기·표시 크기를 맞췄다.
- `FrontierStatusMeter`가 상태 아이콘, 얇은 게이지, 우측 정렬 수치, 별도 상태 문구를 함께 관리한다. 충전 대기시간이 바뀌어도 앞의 열이 움직이지 않는다. 실드 미장착, 충전 중, 낮은 체력의 위험, 스태미나 소진 회복을 구분하며 HUD 높이에 맞춰 하단 단축키 위에 배치한다.
- `FrontierInterfaceStyle`에 아이콘 생성·HUD 글자 그림자·막대 스타일·색상/간격을 모았다. 공통 테마를 사용하는 버튼·탭·입력창·팝업 메뉴·스크롤바·툴팁의 선택/호버/포커스와 배경을 정리했다. 기존 화면별 전용 배치를 전부 재설계한 것은 아니다.
- I 모듈의 카드 전체 희귀도 착색을 없애고 작은 색선·희귀도 이름·티어 눈금을 사용한다. 실제 Blender 부품과 Godot INK 미리보기는 유지한다. 빈 부위는 작은 공통 선 아이콘으로 표시한다.
- 모듈 케이스 수와 최대 실드를 분리하고 기초 실드 조립 비용은 데이터의 `starter_cost`와 개인 재고를 공통 재료 표시로 연결했다. 기본 성능/추가 옵션은 짧은 제목으로 구분하고 중간점 구분자를 제거했다.

새 3D 모델·음원은 제작하지 않았다. 조립/장착의 기존 ElevenLabs 음원 호출과 호스트 결과 이후 갱신 경로를 유지한다. 피해·재충전·비용·희귀도 확률·저장 형식은 바꾸지 않았다.

## 최초 적용 확인

Godot 4.7.2 / Metal Forward+ / Apple M2의 실제 창에서 격리한 검수용 세계로 HUD·I 모듈·아이템·제작 화면을 확인했다. 검수용 모듈·재료와 실드/체력/스태미나 상태를 준비한 장면이며 자연 획득 플레이의 측정으로 해석하지 않는다.

- 1280×800·960×640에서 상태 아이콘/막대/숫자, 하단 단축키 간격, 모듈 격자/상세/실행 버튼을 확인했다. 작은 화면의 상세 간격을 줄여 기본 성능 수치가 첫 영역에 들어오도록 조정했다. 긴 옵션은 기존 별도 스크롤을 사용한다.
- 모듈 화면의 지상 HUD/입력 차단, 공통 필터 팝업·키보드 포커스, 아이템/제작 탭과 스크롤바를 확인했다.
- 실제 조립 버튼 → 호스트 성공 → 재료 반영/조립 영역 닫기, 장착 버튼 → 방어 부위 변경, 해제 → HUD 미장착 표기, 검수 세션 저장까지 관련 **9개 확인·실패 0**이었다. 이후 공통 구분선 수정과 최종 화면 촬영을 완료했으며 전체 검사 묶음을 반복하지 않았다.
- 최종 충전 중/낮은 체력 위험/스태미나 회복 화면을 실제 호스트 상태에 맞춰 확인했다. 최종 실행 로그에 스크립트/런타임 오류가 없었다. 최초 검수 자료의 모듈 ID/재고 준비 오류와 거래 후 낡은 Dictionary를 수정하던 촬영 스크립트 문제는 격리 자료에서 수정했다.
