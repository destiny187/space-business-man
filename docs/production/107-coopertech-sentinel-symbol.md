# 쿠퍼테크 — 전투로봇 심볼 v3

2026-09-10 사용자 요청: 이전 CT가 G로 보이는 문제를 없애고 Lotus처럼 회사의 역할을 상징하는 문양으로 만든다. 쿠퍼가 강인한 전투로봇을 개발하는 회사라는 설정은 유지한다.

투구·분리된 바이저·두꺼운 턱 장갑·넓은 어깨를 대칭 실루엣으로 묶었다. 글자 조합은 제외한다. 이름은 후속 요청에 맞춰 **CooperTech**의 대소문자를 워드마크에도 유지한다. 주형과 소형의 틈을 각각 조정하고 단색에서도 로봇 형상을 유지한다. Lotus·Space Y·mine은 변경하지 않았다.

![현재 심볼](../game/media/corporations/company-symbols-v3.svg)

원본은 `art/branding/corporations/coopertech.svg`, 현재 버전은 `identity.json`의 `corporate-identity-v3`다. `tools/build_corporate_identity.py`로 28개 출력과 비교판을 재생성한다. 기존 v2 비교판과 전환 문서는 당시 이력으로 보존한다.

실제 SVG 렌더에서 주형·24/32/48px·밝은 배경의 단색을 확인했다. 이 커밋은 벡터 변경이며 3D 명판·게임 조사/기록 적용은 이어지는 SP02에서 기록한다.
