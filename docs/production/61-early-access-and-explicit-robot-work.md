# 초반 개방·로봇 작업 직접 선택

2026-09-08 사용자 요청 반영.

## 구현

- `early_access.json`으로 로봇·대기·온도·물·생태·회수 기초 설계를 기본 제공한다. 기본 로버 물류 I도 제공한다. 기존 기술 구매 기록과 잔액은 보존하며 중복 구매는 차감 없이 거절한다. 기존 사업 저장 해시는 변경하지 않고 네트워크 콘텐츠 해시에 새 규칙을 포함한다.
- 제작 재료, 공장 Mk.2와 고급 부품 조건은 유지한다. J에서 기초 설계 구매 탭을 제거하고 생태 조사·분석, 선택적 성능 개조, 운송 장비 개조를 둔다. 개조는 재료를 소비하는 성능 향상이며 초반 제작 잠금이 아니다.
- 출고·재파견 로봇은 대기한다. F 작업 화면에서 자동(전체) 또는 발견 광물 아이콘 선택 후 작업을 시작한다. 지정 종류도 범위 안에서 자동 탐색한다. R은 한 광맥만 작업하며 고갈 후 대기한다. 기존 우선 로봇 선택·귀환·충전·회수 조작을 유지한다.
- 완료한 스캔 또는 실제 채광을 행성별로 기록하고 호스트가 종류 선택을 검증한다. 반입 재고로는 발견되지 않는다. 기존 저장의 스캔 기록도 표시한다. 새 기록 이전의 채광만으로는 과거 발견을 소급하지 않는다. 지하·등급·온도·경로 제한은 그대로 적용한다.
- 기존 로봇은 최초 로드 시 `work_mode_version=2`로 이행해 대기한다. 운반 중 화물과 충전은 유지한다. 이후 직접 고른 설정은 저장해 유지한다.
- 제작 순서를 강요하는 도움말을 기본 조작으로 줄였다. 자동화 완료를 진행 목표로 강제하지 않는다.

## 확인

격리된 기존 세계로 기초 기술 없이 Mk.2 제작, 출고 대기, 미발견 광물 거절, 발견 목록 공개, 직접 작업 시작·설정 유지와 저장 유효성 등 17개 검사를 통과했다. 실제 Godot Forward+/Metal 창에서 960×640 로봇 카드·J 탭·입력/작업음 차단 상태 등 6개를 확인했다. 확인 도구는 `check_early_access.gd`, `check_early_access_ui.gd`이며 기존 `/tmp/first-automation-audit/world.json` 격리 fixture를 사용한다. 사용자 저장은 변경하지 않았다. 실제 원격 협동과 모든 광물의 배치·장시간 작업은 이번에 재검사하지 않았다. 새 모델·음원 제작은 없고 기존 모델·아이콘·피드백을 재사용했다.

## 후속 설계

상위 티어를 연구 또는 별도 재화 획득으로 개방하는 방향을 따른다. 구체적인 연구 과제·재화·비용은 미정이다. 이번에는 새 상위 해금 체계를 만들거나 기존 P3 실물 생산을 추가로 잠그지 않았다. 생태 분석 화면 자체의 전면 시각 개편도 이번 범위에 포함하지 않는다.
