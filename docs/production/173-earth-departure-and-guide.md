# 지구를 등지는 근접 출발·원정별 첫 가이드

2026-09-13 사용자 재정정. 지구를 가까이 바라본 뒤 실제 선체·카메라가 방향을 바꾸고 지구를 등지는 짧은 이동으로 시작한다. 새 원정에서 가이드가 04로 시작하거나 스캔 결과를 가리는 문제도 함께 수정한다.

## 원인과 변경

- 기존 로컬 경로는 지구 거리 650→약 1,101로 제한돼 있었으나 마지막까지 지구를 바라보며 후진했다. 요청한 출발 방향이 아니었다. 원격 main에 앞선 수정 커밋이 빠진 문제와 이 로컬 연출 오류는 구분한다. 기존 진단의 20초 시점도 지구 거리 약 1,103이며 태양계 밖으로 이동한 결과는 아니었다.
- 새 `solar_opening` v2는 지구 앞에서 1.5초 주시하고 1.5~5초에 선회한다. 5~8초에 지구 반대 방향으로 300 전진하며 8.5초에 정지·업무 안내로 인계한다. 거리 650→950, 밝은 쪽의 시작 방향과 시간은 `space_presentation.json`의 조정값이다. 넓은 전경을 찾는 후보 탐색은 제거했다. 끝 자세의 위쪽 축도 조종 상태에 넘겨 인계 때 기체가 다시 돌아가지 않게 한다. 전진 추진을 후진 제동으로 표시하지 않는다.
- 가이드가 캐릭터 ID만으로 진행을 읽어 새 은하에도 이동·가속·스캔 완료 기록을 가져올 수 있었다. 이제 은하 ID와 캐릭터 ID로 분리한다. 새 출항은 01, 같은 원정 이어하기는 현재 단계를 유지한다. 시작 연출의 자동 선회/이동을 조작 연습으로 인정하지 않는다.
- 가이드 z값 80을 0으로 낮추고 지상 HUD보다 먼저 그린다. 업무 안내 모달은 기존 최종 z값 90을 유지한다. 우주 스캔 결과는 3D 뷰포트 안에 그려지므로 z값만으로 해결되지 않는다. 스캔과 가이드가 같은 결과 사각형을 사용해 화면 배치를 피하고, 작은 화면에서 작업 안내까지 겹치면 가이드를 잠시 숨긴다.
- 실제 화면 검사에서 비어 있는 대기층 관측 창도 발견했다. 관측 UI가 숨긴 뒤 외부 시점 코드가 매 프레임 다시 `show()`하던 호출을 제거했다. 대상·차단 조건에 따른 관측 창의 표시 결정을 유지한다.

## 저장·단일 행동 범위

새 세계만 v2 경로를 생성한다. v1 경로·경과 시간·저장된 위치는 그대로 읽는다. 출항 기록이 없거나 완료된 기존 원정에 새 경로를 주입하지 않는다. 기존 가이드의 캐릭터 키는 삭제하지 않으며, 기존 원정을 처음 읽을 때 원정별 키가 없으면 그 기록을 이행한다. 새 원정의 진행은 다른 원정 키를 바꾸지 않는다. 가이드 끄기 설정은 유지한다.

연출 한 단계는 항해 위치·방향·위쪽 축·속도·경과/공전 시간과 비행 위치만 바꾼다. 가이드 저장은 원정 변경/단계 완료 때만 실행하고 스캔 겹침 판정은 로컬 UI 사각형만 사용한다. 새 전체 세계 복사·지형 생성·네트워크 메시지·디스크 저장을 프레임 경로에 추가하지 않았다. 기존 스냅샷·체크포인트의 전체 처리 경계는 [160](160-transaction-drafts.md)에서 다루며 이번 작업에서 해결한 것으로 기록하지 않는다.

## 확인 범위

`check_earth_departure_guide.gd`는 격리된 새 저장과 이전 원정 이력이 있는 테스트 캐릭터, 완료된 기존 01~03 가이드 기록으로 현재 원정 장면을 실행한다. Godot 4.7.2 / Metal Forward+ / M2에서 항해 시간을 0.1초씩 제어해 **전체 연출→업무 안내 확인→가이드 01**을 렌더한다. 실제 키보드 조종·외부망 협동 검증은 아니다. 스캔 화면은 실제 렌더러에 완료된 화성 보고서를 주입한 표시 재현이며 스캔 조작 성공 검사와 구분한다.

24개 확인을 통과했다. 전체 85개 항해 표본의 지구 거리는 최대 약 951.46이고 마지막 속도는 0, 지구를 향한 방향 내적은 약 -1이다. 시작·중간·인계 동안 항성계는 Sol이며 행성 충돌 안전거리와 다른 세계/승무원 상태 불변을 확인했다. 같은 원정 가이드 재읽기·기존 캐릭터 키 보존, v1 경로 해석, 1280×800 및 960×640의 스캔/작업 안내 겹침 방지와 결과 종료 후 가이드 복원도 확인했다.
