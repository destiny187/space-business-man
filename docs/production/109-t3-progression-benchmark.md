# 1인·2인 T3 진입 시간 비교

> **변경 전 측정 기록:** 이 결과는 T3~T5 선박 항해 내성 조건을 넣기 전의 2026-09-10 기준이다. [후속 선박 진입 조건](116-vessel-tier-access.md)을 적용한 현재 버전에서 기본 KESTREL로 이 경로를 실행하면 T3 착륙이 거절된다. 아래 24분 27초/23분 21초를 현재 플레이 시간으로 사용하지 않는다. 새 밸런스의 전체 진행 시간은 아직 재측정하지 않았다.

2026-09-10. 사용자 요청: 새 게임에서 T3를 열고 해당 티어 행성에 도달하는 데 걸리는 1인/2인 시간과 크레딧·채집량·운송 횟수를 비교한다.

## 측정 정의

- 시드 71503, 신규 세계·기본 캐릭터·기본선·기초 원료 각 50개·공용 FINCH 한 대로 시작한다. 세계 자금은 인원수로 늘리지 않는다.
- 시작점은 세계/캐릭터 준비가 끝난 출항 전이다. 대기실 접속/사용자 준비 시간은 제외한다.
- **T3 생산 해금**은 공동 제작소 설계도를 정거장에서 유료 구매하고, 실제 가공품으로 첫 Mk.3 제작소를 개조한 시점이다. T3 시설 설계 6개 전체 확보나 T3 개인 장비·선체 전체 완성을 뜻하지 않는다.
- **T3 도달**은 위 생산 준비 후 T3 행성에 착륙하고 지상 조작으로 전환된 시점이다. 현재 항해/착륙 규칙에 설계도나 T1/T2 정산을 요구하는 티어 진입 잠금은 없다. 따라서 생산 준비를 생략해 먼저 T3로 항해하는 별도 경로도 가능하며, 이번 경로를 최단 도달 시간으로 해석하지 않는다.
- 도착 좌표·물자·시설·설계도·생산 전력을 주입하지 않는다. 실제 항속거리 안의 성간 경유, 에너지 충전/천체 접근, 착륙/이륙, 충돌을 포함한 캐릭터 보행, 광맥 채집/등급/대기시간, 배낭·현장 창고·공동선 화물 입출고, 원료 차감·생산 틱·개조/저장을 사용한다.

## 자동 조작 조건

`benchmark_t3_progression.gd`와 `t3_benchmark_session.gd`는 검사 전용이다. 원본 게임의 규칙·캐릭터 물리·콘텐츠는 변경하지 않는다. 두 캐릭터를 한 호스트 물리 장면에서 독립적으로 움직이고 같은 호스트 거래 규칙에 명령을 보낸다. 2인 경과시간을 1인 시간의 절반으로 계산하지 않는다.

두 경우 모두 정해 둔 지질/정거장/목적지와 동일한 공정 순서를 이용한다. 물리 보행은 기본 6m/s, 질주·로버는 사용하지 않는다. 2인은 기초 원료 채집/창고 반입 작업을 나누고, 호스트가 건설·생산·공동 자금 지출·티타늄 채집을 맡는다. 첫 Mk.2 채집기는 호스트 한 명에게 제작한다. 채집 재료를 50개 이하 작업으로 나누어 각각의 가방과 이동을 처리한다. 두 사람이 모두 돌아온 뒤 공동선으로 출발한다.

공동선으로 같은 거점을 순서대로 진행하는 분담 방식이다. 지급 FINCH를 이용한 서로 다른 행성의 동시 작업, 두 번째 Mk.2 채집기 투자, 추가 제작소를 통한 병렬 생산은 사용하지 않는다. 이 결과로 협동의 최대 효율을 판단하지 않는다.

물리 60Hz·일반 처리 10Hz(`--fixed-fps 10`)의 헤드리스 자동 조작 검사다. 채집 쿨다운도 동일 게임 시계를 사용한다. 렌더러가 없는 환경에서는 착륙/이륙의 렌더 완료 프레임 신호만 일반 처리 프레임마다 검사에서 공급하며 원래 준비 프레임 수와 연출 타이머·지형 충돌 준비 조건을 유지한다. 일반 처리 주기에 따른 입력/화면 전환 지연을 포함하므로 일반 60fps 창 플레이와 초 단위로 일치하는 측정은 아니다. GPU 렌더 성능이나 인터넷 지연을 검증하지 않는다.

이 수치는 **정해 둔 경로를 자동 조작한 게임 내 경과시간**이다. 사람의 탐색·지도 판단·메뉴 선택·협의·실수를 계측하지 않았으므로 초보자 평균 플레이 시간이나 출시 목표 시간으로 확정하지 않는다. 실행 프로그램의 현실 경과시간은 성능 참고용으로 별도 기록한다. 1개 시드와 한 작업 분담 방식으로 모든 행성/협동 전략을 대표하지 않는다.

## 경로

지구 출항 → T1 금속 가공 행성 16408 → 현장 창고/태양광/제작소·Mk.2 채집기 → 합금 프레임과 구리 선적 → T2 저온 행성 16412 → 저온 셀·산업 코어 → 인근 항성계 12477 정거장 구매 → 저온 거점 Mk.3 개조 → T3 행성 356688.

금속·저온 두 생산 행성은 같은 항성계 2051에 있다. 저온 행성의 구리 광맥 누락을 반영하여 구리 45개를 운반한다. 두 번째 거점 창고의 철·돌은 선박에 남지 않았으므로 착륙 후 직접 채집한다. 창고가 생기기 전에는 건설자의 배낭에 모으고 이후에는 현장 창고를 사용한다. 기본선의 항속거리 제한에 따라 성간 경유하며, 중간 항성계 통과와 실제 화물 목적지 이동을 구분한다. 별도 생산 이용권은 두 행성에 각각 500 Cr, 제작소 설계는 1,200 Cr이다.

## 재현

저장소 루트에서 아래처럼 실행한다. 각 실행에는 기존 저장이 없는 별도 `/tmp/t3-benchmark-` 폴더를 사용한다. 현재 사용자 게임 저장은 사용하지 않는다.

```sh
tools/godot.sh --headless --fixed-fps 10 --script res://tests/benchmark_t3_progression.gd -- --crew-ui-test --crew-folder=/tmp/t3-benchmark-1-replay-20260910 --benchmark-players=1
tools/godot.sh --headless --fixed-fps 10 --script res://tests/benchmark_t3_progression.gd -- --crew-ui-test --crew-folder=/tmp/t3-benchmark-2-replay-20260910 --benchmark-players=2
python3 tools/report_t3_benchmark.py /tmp/t3-benchmark-1-replay-20260910 /tmp/t3-benchmark-2-replay-20260910 --output docs/production/media/t3-benchmark
```

보고 도구는 양쪽의 완료 여부·실패 수·최종 T3 착륙·세계 저장 유효성·생성 조건 일치를 확인하고 원본 측정값을 보존한다. 탐색 봇의 작업 위치·작은 바위 충돌체 경로·빈 채집 위치 선택·두 번째 창고 재료 수급을 보완한 예비 실패 실행은 최종 수치에 섞지 않는다. 바위 경로 수정은 실제로 막혔던 지점을 동일 60Hz 물리로 통과하는 좁은 검사에서 확인했다. 실패 저장을 이용한 후반 경로 진단도 시간 비교와 분리한다. 최종 비교는 새 게임부터 연속 완료한 실행만 사용한다.

## 결과

Godot 4.7.2의 2026-09-10 작업본에서 각 조건을 **새 게임부터 연속 1회 완료**했다. 양쪽 모두 종료 코드 0, 실패/오류/경고 0, 세계 유효성 검사 통과, 저장에 Mk.3 제작소와 목표 T3 착륙을 확인했다. 생성 시드/설정도 일치한다. 최종 두 실행에서 막힘 후 물러나기 분기는 발생하지 않았다. 아래 시간은 모두 출항부터 누적하며 초 단위로 반올림했다.

## 시간 구성과 해석

| 계측 항목 | 1인 | 2인 |
| --- | ---: | ---: |
| 항해·착륙·승선 단계 합계 | 10분 15초 | 10분 37초 |
| 실제 제조 완료를 기다린 시간 | 3분 00초 | 2분 59초 |
| 호스트 보행 시간 / 거리 | 11분 06초 / 3.85km | 9분 36초 / 3.32km |
| 동료 보행 시간 / 거리 | 해당 없음 | 1분 47초 / 0.62km |
| 채집 동작 시간 | 41.2초 | 호스트 31.3초 + 동료 16.5초 |

이 항목들은 서로 겹치는 구간이 있으며, 특히 두 사람의 보행/채집 시간 합을 원정 경과시간에 더하지 않는다. 단계 집계 오차는 한 물리 틱 이내다. 실행 프로그램의 현실 시간은 1인 16분 12초, 2인 16분 04초였으며, 이를 플레이 시간으로 쓰지 않는다.

이번 분담에서는 채집·가공·거점 운반을 묶은 구간이 약 89초 줄었으나, 2인 승선/착륙 절차에 시간이 더 들어 최종 차이는 약 66초였다. 공동 항해와 가공 대기는 거의 같고 건설·선박/창고 운반도 호스트에게 집중되어 있다. 따라서 이 결과는 2인 플레이 전반의 효율 한계가 아니라 위 분담 방식의 결과다.

현재 구조에서는 T1/T2 사업을 정산하지 않아도 출항 자금 안에서 이 생산 진입이 가능하다. 밸런스 목표를 정할 때 **T3 첫 생산 진입 시간**과 **행성 복원/사업 정산 완료 시간**을 분리해야 한다. 본 측정을 초보자 평균 시간, 전 시드 평균, 최단 경로 기록, T3 설계도 6종 전체 확보, 인터넷 2클라이언트 검증, 행성 판매 완료로 확대하지 않는다.
