# 시설별 작업 인터페이스 — 2026-09-07

## 확정 요구사항

사용자 확정: B는 건물 배치 전용이다. 로봇은 로봇 제작소를 먼저 건설하고 해당 건물을 F로 조작하여 별도의 제작 인터페이스에서 만든다. 생산·연구·정비도 해당 물체의 역할에 따라 나눈다.

| 진입 대상 | 작업 |
| --- | --- |
| B 건설 | 건물 카드·비용·배치 고스트·설치 |
| 로봇 제작소 (`factory`) | 로봇 제작 전용 화면, 공통 제품 생산, 공학 시제품. 같은 제작소의 작업 예약 공유 |
| 현장 창고 | 자원 반납·인수·보급, 창고 주변 로봇 회수·운송 로봇 재파견 |
| 로봇 본체 | 해당 로봇의 광맥 배정·복귀·긴급 충전·Mk.2 개조 |
| 개별 시설 | 해당 시설의 가동·정지·철거·Mk.2 개조, 관련 생물공학 시험·설치 |
| 착륙선 단말 | 무료 개발 등록·기술 구매·환경/계약 정산·연구실·선박 정비·출항 |
| I / J | 개인 장비와 기초 휴대 제작 / 발견 기록 조회. 생태 작업 실행은 착륙선 연구실 |

F로 연 물체 ID를 고정하여 다른 건물을 목록에서 다시 고르지 않는다. 대상 소멸·거리 이탈·계약 인계 시 작업을 계속하지 못하게 한다. 재료·권한·전력·작업 중복 여부는 호스트가 확정한다. 생산을 시작한 플레이어는 탐험하러 떠날 수 있다.

기초 휴대 제작과 첫 시설의 직접 건설을 유지한다. 전문 정제기·조립기·배양 생산망과 충전 패드의 다중 로봇 관리는 후속이다. 이번에는 기존 `factory`와 Blender 자산·ElevenLabs 재생 경로를 재사용한다. 첫 시설 건설에 자기 산출물을 요구하는 순환 선행 조건을 추가하지 않는다. 현장 창고는 기존 공동 재고를 사용한다. 독립 저장고 물류망은 별도 구현이다.

## 구현 순서와 상태

현재 원정 진입 경로에 첫 분리를 구현했다.

- B는 건설 카드와 배치만 표시한다. F는 조준한 건물/로봇의 ID를 고정한다.
- 로봇 제작소는 M-01의 회전 가능한 실제 INK 모델, 재료 아이콘, 제작 준비/진행/전력 상태를 갖는 전용 화면으로 열린다. 제품 생산·공학 시제품·해당 제작소 관리만 함께 제공한다.
- 생산/개조에서 전체 현장의 대상을 고르는 목록을 제거했다. 일반 설비의 개조 화면에는 해당 설비 모델을 표시한다.
- 로봇 본체에서는 해당 로봇의 작업 배정/복귀/긴급 충전과 개조를 제공한다. 창고의 로봇 화면은 회수/재파견만 제공한다.
- 창고에는 실제 재고 아이콘 격자·반납·1개/20개 인수·보급을 제공한다. 추가 저장고도 같은 공동 재고의 접근점이다.
- 착륙선 근처의 F는 단말을 연다. 등록·기술·계약·연구실·선박 정비·출항을 이곳에 배치했다. 단말이 열리는 위치는 기존 탑승 거리이며, 조준한 현장 물체가 있으면 그 물체의 F를 우선한다.
- J는 기록 조회, 착륙선 연구실은 실제 생태 작업 실행을 제공한다. 기존 I 개인 장비/휴대 제작/공동 창고 접근은 유지하며 인수 거리 검증은 호스트가 수행한다.
- 열린 시설/로봇의 거리 이탈 시 창을 닫는다. 같은 제작소의 로봇 제작 중복 예약을 호스트에서 차단한다. 로봇 명령은 본체 근처, 기술 구매/계약 인계는 착륙선 근처에서 확정한다.

주요 파일: `scripts/ui/business_panel.gd`, `robot_factory_panel.gd`, `production_panel.gd`, `scripts/app/crew_expedition.gd`, `scripts/ui/expedition_navigation.gd`. 창의 공통 레이아웃과 자료 갱신은 재사용하지만 표시 기능과 작업 대상은 진입한 물체에 따라 분리한다.

## 확인과 남은 범위

`tests/check_facility_interactions.gd`로 임시 세계에서 실제 Godot 4.7.2 Forward+ / Metal 창을 사용했다. 착륙선 등록 → B 건설만 표시 → 태양광/충전기/제작소 설치 → 실제 조준/F → 지정 제작소 로봇 예약·중복 거절 → 출고를 확인했다. 저장 세계를 이어서 로봇 본체 관리, 생산 대상 고정, 창고 분리, J/연구실 구분, 작은 창과 저장을 확인했다. 대표 화면의 로봇/제품 모델과 창고 격자를 직접 검수했다.

첫 실행은 Jolt 작업 지연 경고로 제한 시간 내 출고를 확인하지 못했으며 저장에는 정상 가동 중 17/18초 진행 상태가 남았다. 충분한 진행 시간 후 출고를 확인했다. 초기 검사의 로봇 메뉴 실패는 호스트 생성 직후 공개 스냅샷 전에 열었던 검사 순서 문제였고, 화면에 로봇이 반영된 뒤 확인하도록 수정했다. 물리 엔진 지연 자체를 수정했다는 의미는 아니다.

기존 Blender 모델/프리뷰를 재사용하며 신규 모델·음원을 제작하지 않았다. 기존 건설·조립 시작·완료의 ElevenLabs 재생 경로를 연결했다. 전체 음량 청취 비교·다중 클라이언트·모든 설비별 공학 시험/계약 정산의 실제 재실행은 이번에 하지 않았다. 전문 생산 시설, 충전 패드의 다중 로봇 정비창, 독립 창고 간 물류는 후속이다.

최종 추가 확인: 지정 제작소의 정제 철 생산 완료와 시작/완료 ElevenLabs 음원의 실제 재생 호출을 확인했다. 960×640에서 제작 버튼이 아래로 밀리는 부분을 조정하고 로봇/시설 관리의 정적 사진을 회전 가능한 실제 모델로 바꾼 뒤 Forward+로 재렌더했다. 마지막 관련 실행은 오류 없이 종료했다.
