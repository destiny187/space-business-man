# 탐험 배경음악

2026-09-07 사용자 확정: 우주용 배경음악 2분과 잔잔한 행성용 배경음악 2분을 한 곡씩 제작한다. 여성 AI 음성은 같은 날 후속 지시에 따라 이번 적용에서 제외했다.

## 제작·적용

| 게임 ID | 곡명 | 사용 장소 | 길이 |
| --- | --- | --- | --- |
| `music_stellar_v1` | Stellar Solitude | 항성계 비행·성간 이동·함선 | 120.03초 |
| `music_planet_v1` | Terraforming Hope | 행성 착륙 이후 지표·지하 | 120.03초 |

ElevenLabs Music v2에서 길이 2m·기악·변형 1로 각각 생성했다. 스테레오 44.1kHz·192kbps MP3 원본과 게임 파일을 보존했다. 화면 표시 비용은 곡당 1,800 크레딧이었다. 정확한 프롬프트·생성 페이지·다운로드명·해시는 [제작 매니페스트](../../audio/manifests/expedition-music.json)에 있다. 여성 음성·안내 자막·Voice 재생 코드는 게임에 추가하지 않았다.

`crew_expedition.gd`의 앱 수명에 `expedition_audio.gd`를 연결한다. 승인된 최신 세션의 플레이 단계와 공동 착륙 상태를 읽어 곡을 선택한다. 로비에서는 음악을 시작하지 않고, 진행 중 저장으로 복귀하면 해당 장소의 곡을 재생한다. 반복 스냅샷으로 같은 곡을 다시 시작하지 않는다.

- 장소가 바뀌면 2.5초 교차 페이드한다. 각 곡은 반복하며 루프 경계의 클릭을 피하도록 앞뒤 0.45초에 음량 페이드를 적용한다.
- 원정 메뉴·설정 창 또는 게임 창 비활성 상태에서는 위치를 유지한 채 음악과 교차 페이드를 멈춘다. 닫거나 복귀하면 이어 재생한다. 세션 종료 시 두 곡을 정지한다.
- 설정의 **조작 · 소리 → 배경음악 음량**에서 전체 음량과 별도로 조절한다. 기존 설정 파일에는 기본값 0.65가 적용된다. 효과음·환경음의 기존 연결은 유지한다.
- 전환 시간·루프 페이드·기본 레벨은 `data/expedition_audio.json`에서 관리한다. 음원은 기존 Git LFS 규칙을 따른다.

## 확인 범위

두 파일의 길이·형식과 Godot 임포트를 확인했다. 실제 Godot Forward+ 창의 원정 앱에서 두 스트림·Music 버스 신호·스냅샷 연속성·장소 전환·끝 구간 반복·메뉴 일시정지·음량·세션 종료를 최소 실행으로 확인했다. 메뉴 일시정지 중 재생 시작 조건이 개입하던 문제를 수정하고 재확인했다. 행성 상태 전환은 오디오 확인용 로컬 스냅샷으로 주입하며 실제 지형 로딩·멀티클라이언트 회귀는 이번 검사 범위가 아니다.
