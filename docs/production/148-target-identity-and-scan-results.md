# 조준 대상 정보와 스캔 결과 분리

2026-09-12 사용자 요청: 정체를 조사하지 않은 생물의 이름·표본 그림을 단순 조준으로 노출하지 않는다. 스캔 성공 후에만 수 초 동안 상세 정보를 표시하고, 평소에는 조준 대상의 필요한 상태만 표시한다.

## 적용

- 일반 동물·식물·미생물의 평시 조준에서 종 이름·표본 아이콘·표본 활용 안내를 제거했다. 이미 조사한 종도 동일하다. 동물은 장비에 관계없이 조준 중에만 104px 체력 막대를 표시한다. 배경판·조준 대상·생명체·무력화 문구도 없으며 조준을 벗어나거나 무력화되면 막대를 숨긴다. 식물/미생물의 E 스캔 동작 안내는 유지한다.
- 호스트가 확정한 지상 공통 스캔 결과는 성공부터 4초만 표시한다. E를 계속 유지하거나 동일 대상의 수치가 갱신되어도 시간을 연장하지 않는다. E를 놓고 다시 스캔하면 다시 확인할 수 있다. 메뉴·착륙 연출·지상 이탈은 결과를 닫고 이전 결과를 자동 재생하지 않는다.
- 미조사 광맥은 미확인 광맥으로 표시하고 재료 이름/아이콘은 조사 후 표시한다. 광맥 위에 따로 뜨던 3D 이름/수량/작업 글자도 제거했다. 채집 도구 조건과 채집·로봇 지시 동작은 유지한다.
- 미조사 발견물과 식물/미생물은 일반 제목도 없이 E 스캔 동작만 표시한다. 조사 후에는 현재 F 작업과 필요한 도구/재료, 완료 여부만 보조한다.
- 생물 사건의 종 이름, 사건의 상시 제목, 전투로봇의 상시 전술 설명을 제거했다. 사건 진행에 필요한 상호작용은 유지한다. 전투로봇도 조준 중 체력/실드의 작은 막대만 표시하며 이름·설명·배경판을 붙이지 않는다.
- 소유 시설·로봇의 작업 상태, 이미 식별 가능한 선박/항만의 상호작용, 직접 여는 도감/아이템의 정보는 각 기능의 표시를 유지한다. 스캔 저장·표본 채집·전투 판정은 변경하지 않았다.

## 확인

`tests/check_target_identity_ui.gd`로 별도 저장의 자연 배정 동물을 실제 Forward+ 창에서 조준했다. 미스캔 비노출 → 실제 E 조사/호스트 기록 → 유지 입력 중 4초 만료 → 조사된 종의 평시 비노출 → 명시적 재스캔 → 메뉴 닫기 후 재노출 없음 → 960×640 결과 표시를 확인했다. 후속 확인에서는 총기/채집기 모두 배경판 없이 체력만 표시하는 것까지 확인했다. 캡처는 `output/target-identity-ui-20260912/`에 있다.

식물·미생물은 동일 생물 HUD 분기를 사용하는 것을 코드로 확인했다. 광맥·발견물·생물 사건·전투로봇과 기존 도감/시설의 표시 경로를 점검했다. 후속 홍보 촬영에서는 실제 채집/건설/스캔과 쿠퍼테크 로봇 교전에서도 표시를 확인했다. 모든 종류/사건의 전수 실플레이나 다중 클라이언트 검증은 수행하지 않았다. 새 모델·음원은 제작하지 않았다. 후속 타격 효과 변경은 [149 기록](149-ground-impact-shapes.md)을 따른다.
