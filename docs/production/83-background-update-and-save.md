# 백그라운드 갱신과 주기적 저장 최적화

2026-09-09 사용자 승인: [추가 조사](81-background-performance-audit.md)에서 발견한 낭비를 실제로 수정한다. 그래픽 품질·게임 규칙·호스트 권한은 유지한다.

## 적용

- 우주 SubViewport 렌더가 꺼진 동안 공전·조명·카메라·표식 계산을 멈추고 가장 최근 항해 스냅샷만 보관한다. 스캔과 추진음도 중단한다. 화면을 다시 표시하면 최신 스냅샷·위치·방향을 반영한다. 착륙/이륙 연출이 준비를 소유하는 동안에는 필요한 시스템 준비를 허용한다.
- 닫힌 FINCH·선박 단말·교역·조선소는 반복 스냅샷의 화면 갱신을 생략한다. 기존 메뉴 열기 경로에서 최신 상태를 즉시 적용한다. 조선소를 열 때 연구 상태도 갱신한다.
- 지상에서 지도를 닫으면 항성 인덱스 준비를 멈춘다. 우주 배경 준비는 프레임당 250µs, 지도 열림은 기존 1,500µs 예산이다. 페이지 읽기/쓰기 등 단일 작업의 최대 시간을 보장하는 하드 제한은 아니다. 지도 종료 때 외부 시점뿐 아니라 선내 창도 우주 렌더를 복구한다.
- 5초 주기 체크포인트는 검증·깊은 복사 후 직렬화/파일 처리를 작업 스레드에 맡긴다. 원본 스냅샷, 임시 파일 재읽기·JSON 파싱, 검증된 기존 파일의 백업과 원자적 교체를 유지한다. 거래·도착·종료는 이전 작업 완료 후 동기 저장하며 성공 전에 확정하지 않는다. 상세 저장 계약은 [협동 저장](../technical/04-coop-networking-and-session-save.md#2026-09-09--주기적-체크포인트의-작업-스레드)에 둔다.

## 재계측

Apple M2 / Godot 4.7.2 Metal Forward+, 1280×800, 보통·100% 렌더, FPS/VSync 제한 해제. 이전과 같은 격리 저장·위치·시점에서 스트리밍 완료 뒤 200프레임 콜백을 계측했다. 메인 스레드 콜백의 경과 시간이며 엔진 대기를 포함한다.

| 콜백 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 숨겨진 우주 비행 | 4.203ms/프레임 | **0.0038ms/프레임** |
| 항해 UI | 1.688ms/프레임(인덱스 준비 중) | **0.146ms/프레임** |
| 세션 `_process` | 0.957ms/프레임 | 0.376ms/프레임 |
| 전체 외곽 콜백 합계 | 11.854ms/프레임 | 7.860ms/프레임 |

인덱스 준비 비용은 준비가 끝나면 원래도 감소한다. 전체 콜백은 물리 단계 횟수·생물 모션·환경 처리 및 함께 진행 중인 물 구현 변경도 영향을 주므로 합계 차이를 이 수정만의 확정 개선율로 해석하지 않는다. 숨겨진 우주 콜백은 실제로 계산을 생략하는지 별도 기능 확인도 통과했다.

수정 후 타이머를 끈 120프레임은 평균 **19.35ms / 51.7 FPS**, p95 22.72ms였다. 계측을 켠 구간은 평균 23.06ms / 43.4 FPS로 변동했으며 이전 조사와 동일 실행 내 A/B 비교가 아니다. **60 FPS 달성이나 일정한 FPS 개선율을 보장하지 않는다.** [CPU 원본](media/background-performance-fix/cpu-profile.json), [프레임 원본](media/background-performance-fix/results.json).

## 최소 확인

- `check_background_save.gd`: 격리 저장의 유효성, 비동기 스냅샷 독립성, 체크포인트→거래 저장 순서, 이전 정상 백업, 손상 파일 복구/보존, 작업 스레드 I/O 오류 전달, 잘못된 입력 거부. 14개 확인 실패 0.
- `check_background_play.gd`: 실제 Forward+ 창에서 저장된 지상 진입, 숨겨진 공전 중단 중 호스트 시간 진행, 지상 지도 준비 중단, 닫힌 단말 갱신 중단/열기 즉시 반영, 체크포인트, 실제 이륙과 최신 우주 상태 복구, 은하 지도 열기/닫기와 선내 창 복구, 작업이 남은 상태의 정상 종료/재읽기. 18개 확인 실패 0. [실행 기록](media/background-performance-fix/play.txt).
- 소스 구문 검사와 `git diff --check`를 확인했다. 실제 사용자 저장은 수정하지 않았다. 캡처에서 지상과 이륙 후 선체·우주 배경 복구를 확인했다.

## 남은 비용과 범위

주기적 저장의 세계 검증/복사와 중요 거래·산업 생산·스캔의 동기 저장은 남는다. 작업 스레드가 진행 중이면 중요한 저장/종료가 기다릴 수 있다. 전체 저장의 비동기 거래 체계로 바꾼 것은 아니다. INK 윤곽선·하늘·지형 셰이더의 GPU 최적화, 이동/굴착 순간 지연, 6인·Windows·장시간/전 항해·교역 경우의 검증은 이번 범위에 포함하지 않았다. 새 Blender/음원 자산 제작이나 시각 품질 하향은 없다.
