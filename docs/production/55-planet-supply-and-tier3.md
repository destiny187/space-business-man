# 생산 거점·직접 운송·첫 P3 생산 구현

2026-09-08 사용자가 [행성 특화·후반 공급망](../game/17-planet-specialization-and-supply.md)의 방향을 승인하고 개발을 요청했다. 이번 범위는 개발 순서의 **복수 거점 보유 → 직접 운송 → 첫 P3 소비처**다. 원격 생산, 추가 행성 외형, 복합 지표 재질까지 완료한 기록은 아니다.

## 실제 플레이

1. 착륙선 단말의 **생산 거점** 탭에서 이용권을 확보한다. 복원 계약 하나가 다른 행성에서 진행 중이어도 독립 생산 거점을 만들 수 있다. 시설 배치에는 기존 가방 재료·평탄한 지면·접근 거리·기술 조건이 그대로 적용된다.
2. 금속 지질의 Mk.2 제작소에서 **고합금 프레임**, 빙하 지질의 Mk.2 제작소에서 **저온 전해 셀**을 만든다. 원료의 현지 조달과 수입은 모두 가능하지만, 이 두 부품의 현지 가공 역할은 분리된다.
3. 기존 창고에서 배낭으로 인수하고 우주선에 적재한다. 다른 거점에서 하역·반납하여 두 부품을 모은다. 원격 창고 재료를 제작 비용으로 바로 차감하지 않는다.
4. 어느 계열의 Mk.2 제작소에서든 **산업 코어**를 조립한다. 코어를 소비해 제작소를 Mk.3로 개조하면 부품·로봇 조립 속도가 Mk.1 대비 2배다. 기존 Mk.2의 1.5배에서 증가하며, 중복 곱셈하지 않는다.
5. 항성 지도 **생산 거점**에서 목적지를 선택한다. 기존 항속·조종사·승선/준비·출발 조건을 따른다. 거점 목록은 호스트 원장의 현재 이용권·재고를 사용하고, 이전 방문 기록이 없는 클라이언트도 소유 거점을 다시 선택할 수 있다.

이 현지 가공 제한은 **게임 특화 규칙**이다. 실제 합금이나 전해 셀을 해당 행성 종류에서만 만들 수 있다는 과학적 주장과 구분한다. 광상 품위·환경별 공정 비용·대체 교역으로 확장할 수 있도록 역할과 레시피를 데이터에 둔다. 기존 10종 지질 중 금속 5종·빙하 3종·열수/화산 2종을 분류한다. 열수/화산은 이번 전용 부품이 없으며 최종 조립은 가능하다. 가스/얼음 거대행성과 태양계 참조 천체에는 생산 이용권을 주지 않는다.

## 권한·정산·저장

수치 원본은 [`planet_supply.json`](../../우주-비즈니스/data/planet_supply.json)이다. 이번 초기 밸런스는 이용권 500 Cr, 최대 8곳, 보유 정산 시 계약 대금 60%다. 사용자가 확정한 최종 밸런스 수치는 아니다.

- 복원 계약은 기존 `business.active` 하나를 유지한다. 이용권은 현장별 `production_lease`이며, 계약 없이 운영하는 상태는 `supply`다. 계약이 진행 중이면 이용권과 `active`가 함께 존재한다.
- **전부 인계**는 기존 계약 대금 전액을 받고 시설·로봇·창고와 이용권을 넘긴다. **생산 거점 유지**는 이용권을 먼저 확보하고 대금의 40%를 포기한다. 시설·재고·로봇은 남고 복원 계약은 종료된다. 두 경로의 지급·소유 결과를 동시에 얻을 수 없다.
- 정산 기록이 있는 거점에서는 계약을 다시 등록하거나 보상을 중복 지급하지 않는다. 과거 `settled` 거점의 이용권을 소급 복구하지 않는다.
- 비운 거점의 이용권은 환급 없이 반납할 수 있다. 시설·로봇·작업·창고 자원·개인 보관 장비가 남아 있으면 거절한다. 광맥 고갈 기록과 이미 받은 정산 기록은 지우지 않는다.
- 이용권 지출·반납·정산은 호스트만 수행한다. 제작·창고 거래는 기존 협동 권한과 요청 순번·리비전·저장 후 공개 구조를 사용한다. 저장 실패 시 비용과 권리는 확정되지 않는다.
- 착륙 중인 현재 행성의 시설·로봇·공학·로버 제작·선박 개조는 생산 거점에서도 기존 경로로 운영한다. **다른 행성 및 항해 중 생산은 정지**하며, 재방문 시 남은 작업부터 계속한다. 현실 시간 소급 생산은 없다.
- 이전 저장에는 이용권을 자동으로 부여하지 않는다. 새 필드가 없는 기존 현장 구조도 읽는다. 기존 세이브 규칙 해시를 바꾸지 않고, 협동 콘텐츠 해시에는 새 공급 규칙을 포함한다. 과거 모든 버전의 저장 호환성을 새로 보장한 것은 아니다.

## 연결한 코드·표현

- [`planet_supply.gd`](../../우주-비즈니스/scripts/domain/planet_supply.gd): 역할, 권한, 보유 정산 지급액, 최대 8개 거점 요약.
- [`expedition_business.gd`](../../우주-비즈니스/scripts/domain/expedition_business.gd): 건설/운영 경계, 정산·저장 검증. `production_tier2.gd`는 기존 이름을 유지하고 P3 추가 데이터와 Mk.3 제작소를 읽는다. 다른 분야의 Mk.3 개조는 열지 않는다.
- [`planet_supply_panel.gd`](../../우주-비즈니스/scripts/ui/planet_supply_panel.gd): 부품 연결 카드와 거점별 실제 창고 아이콘. 생산 메뉴의 재료 보유/필요량·역할 부족 이유·등급 표시를 연결한다.
- P3 세 품목은 기존 Blender 제작 부품의 GLB·아이콘을 재사용하고 III 등급과 이름으로 구분한다. 별도 신규 고유 모델 제작 완료로 기록하지 않는다. 제작소 Mk.3에는 기존 회로 모듈을 외벽에 부착한다. 공통 INK 셰이더·기존 작업 효과와 ElevenLabs 작업 루프·완료음에 연결한다. 기존 모델의 가동 부품 애니메이션 경로는 보존했으며 이번 검수에서 별도 모션 전수 검사를 수행하지 않았다. 새 음원은 생성하지 않았다.

## 확인한 범위

Godot 4.7.2 / Apple M2 / Metal Forward+에서 다음 최소 확인을 수행했다.

- [`check_planet_supply.gd`](../../우주-비즈니스/tests/check_planet_supply.gd): 41개 확인, 실패 0. 두 현장 등록, 저장 실패 롤백, 반복 이용권 구매 거절, 다른 역할 제작 거절, 창고↔배낭↔공동 우주선 운송, 산업 코어 소비/Mk.3, 저장·다시 읽기, 보유 정산/중복 보상 차단, 실제 현재 현장 전력·생산 재개, 부재중 작업 정지.
- [`check_planet_supply_ui.gd`](../../우주-비즈니스/tests/check_planet_supply_ui.gd): 실제 게임 진입, 두 거점 카드, 생산 버튼, 작업 루프 연결, 월드 개조 모듈, 메뉴 중 입력/소리 차단, 재방문 목록, 저장 종료. 8개 확인, 실패 0. 작은 화면은 세로 스크롤로 조작에 접근하며, 최종 재검수는 준비 재료를 보충한 격리 저장에서 수행했다.
- 재료와 궤도 이동 위치는 **격리된 검수용 저장의 준비 데이터**다. 실제 제작/거래 명령은 호스트 저장 경로로 수행했다. 처음부터 채광·건설·성간 이동을 모두 수동 완주하거나 실제 두 클라이언트를 접속한 검사가 아니다.
- 1280×800 및 960×640 화면에서 카드·스크롤·생산 상세와 게임 렌더를 확인했다. 음원 노드 재생 연결을 확인했으며 사람의 음색 청음·장시간 성능 검수와 구분한다.

## 남은 단계

원격 집계 생산·자동 운송·배치 제작, 공급처 도달/고갈 대체 경로의 모든 시드 보장, 희토류·두 특이 광물의 전체 P4/P5 수요, 해양/염수/탄소/가스 산업은 미구현이다. 이번 공급 제약은 선택적인 제작소 효율 확장에만 적용하므로 기존 초반 복원·장비·항해 진행에 새 필수 왕복을 넣지 않는다. [표면 재질·복합 지역 설계](../technical/09-planet-surface-materials-and-biomes.md)의 결빙·해빙·보조 지질 표현도 별도 후속 범위다.

검수 재현은 실제 사용자 저장과 분리한다. 먼저 `./tools/godot.sh --headless --script res://tests/check_planet_supply.gd`, 이어서 `./tools/godot.sh --script res://tests/check_planet_supply_ui.gd -- --crew-ui-test --crew-folder=/tmp/planet-supply-20260908`를 실행한다.
