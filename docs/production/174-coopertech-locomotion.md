# 쿠퍼테크 이동·이족 리깅과 발 접지

2026-09-13 사용자 요청: 순간적인 이동과 발 동작 불일치를 구조적으로 수정하고 이동속도에 보폭·보행 빈도를 맞춘다. 추가 확인에서 이족 로봇의 리깅 자체를 우선 수정하기로 했다. 영상은 비행전투 컷만 원거리 미사일 발사와 교차 기동으로 다시 촬영한다.

## 원인과 변경

기존 사건의 0.25초 위치 갱신에 화면의 별도 0.25초 갱신과 급한 위치 추종이 겹쳤다. 옆걸음·후진에도 전진 보행을 재생했고 보초의 발은 다리 관절과 분리돼 있었다. BASTION은 골반 연결 없이 고관절을 루트에 두었으며 거의 완전히 편 다리를 기본 자세로 사용했다. 위치 보간만 바꾼 첫 검수에서도 이족의 연속 접지 구간이 없어, 그 상태를 수정 완료로 처리하지 않았다.

- 전투 판단·피해·사건 생성은 4Hz, 가까이 있는 활성 분대의 이동은 20Hz로 분리한다. 가속·감속을 제한하고 최신 10Hz 스냅샷의 위치·속도로 화면의 이동을 연결한다. 공격 판정·저장·보상은 호스트가 유지한다.
- 보초의 실제 허벅지 연결점에 고관절을 두고 골반–고관절–무릎–발목–발 메시를 연결한다. 기계 부품은 각 관절에 강체로 연결한다. 골반과 상체 회전축도 분리한다.
- BASTION은 골반 본을 추가하고 상체와 두 고관절을 골반 아래로 연결한다. Blender에서 두 이족의 무릎을 굽힌 접지 기본 자세를 제작하며 메시와 바인드 자세를 함께 갱신한다. BASTION의 전진 보행 클립도 각도 반복 대신 두 관절 IK로 제작한다. 원본과 GLB를 모두 보존한다.
- 실제 이동 거리로 보행 주기를 진행하고 속도에 따라 보폭과 발 들기 높이를 조정한다. 디딘 발은 월드 위치와 방향에 고정하며 옆걸음·후진·회전은 실제 이동 방향의 다음 발 디딤 위치와 고관절–무릎–발목 IK로 표현한다. RAPTOR는 기존 전용 사족 골격을 유지한다.
- 상체 준비·발사·냉각과 다리 보행을 분리하고, 표시용 단계 시계를 연속 진행한다. 사건형 동물의 짧은 이동/정지 판정 흔들림과 리모델링 동물의 보행/달리기 전환 속도만 완충한다. 동물 전종의 골격을 다시 제작한 것은 아니다.

수치의 원본은 `coopertech_squads.json`이다. 기본 자세의 높이 변화에 맞춰 표시 충돌 높이와 총구 위치를 조정했다. 기존 사건 ID·체력·보상과 저장은 유지하며 새 이동 필드가 없는 저장도 읽는다. 이 작업의 저장 재현 중 발견된 출항 연출 버전의 JSON 정수/실수 판정 오류도 수정했다. 정상 버전 1·2를 정수값으로 검증하며 촬영용으로 저장 검증을 우회하지 않는다.

## 단일 행동 범위

이동은 활성 행성의 가까운 살아 있는 기체만 갱신한다. 변경할 때 세계·사건·records를 얕게 복사하고 해당 기체 행만 별도로 소유한다. 위치·속도 배열은 교체하며 경로 배열, 승무원, 재고, 지형, 건물은 공유 읽기 전용이다. 발 IK는 표시 기체 안에서만 처리하고 도메인·네트워크·저장을 호출하지 않는다. 메뉴/비활성 승무원은 이동을 진행하지 않는다.

기존 사건 레코드 키 순회와 근처 장애물/엄폐 검사는 유지한다. 전체 세계 복사·전체 지형 무효화·발걸음마다 저장을 추가하지 않는다. 기존 4Hz 사건 단계 변경의 원자적 저장과 10Hz 스냅샷 생성 비용은 그대로이며 외부망 보간·많은 기체의 장시간 성능은 별도 확인 범위다.

## 확인

규칙/저장 36항목과 이동 분리·가속·장애물·이전 스냅샷 보존·국소 복사·기존 필드 누락·JSON 재로드 14항목을 확인했다. Blender 렌더와 Godot Forward+의 저속/고속/옆걸음/후진/정지·회전 검수는 `output/motion-crossing-20260913/`에 보존한다. 수정된 이족 골격으로 600프레임을 다시 렌더한 결과 보초 560·BASTION 590·RAPTOR 815개의 연속 접지 표본을 확인했다. 디딘 발의 프레임 간 최대 이동은 각각 0.58·0.39·0.35mm였다. 발끝 방향도 접지 중 고정했으며 프레임 간 회전 차이는 부동소수점 정밀도를 포함해 0.001rad 미만이었다. 평지의 통제된 저속→최고속→옆걸음→후진→정지/회전 측정이며 모든 지형과 모든 네트워크 조건의 상한으로 해석하지 않는다.

영상은 원거리 약 760m에서 접근해 미사일을 발사하고 적 편대와 교차하는 실제 호스트 시뮬레이션을 재촬영했다. 교차 컷 3.6초만 교체하고 나머지 기존 컷을 유지했다. 최종 길이는 48.4초, H.264/AAC, 출력 1920×1080/60fps다. 게임 렌더 1280×720을 확대했으며 60fps 고정 촬영은 실시간 게임 60fps 보장을 뜻하지 않는다. 2,904프레임 디코드·서로 다른 프레임 확인, 검은 구간 없음, 통합 음량 -16.18 LUFS·최대 true peak -1.30dBTP를 확인했다. 원거리 미사일 발사/폭발과 교차 후 컷 종료를 확인한다.

실제 원정 확인 20항목도 통과했다. 새 이족/사족 모델의 로딩·플레이어 탄 명중·분대 경보, BASTION 준비/발사/회복, RAPTOR 연속 사격, 호스트 순찰 위치 변화, 메뉴 이펙트·모터음 정지와 저장을 확인했다. 첫 실행은 정지한 관찰자의 생존 유지가 없어 포격 회복 대기가 시간 초과했고, 기존 RAPTOR 검수와 동일하게 관찰자의 체력을 유지해 재확인했다. 실제 게임의 피해나 회복 규칙을 약화하지 않았다. 외부망 6인·장시간 대규모 전투와 전종 동물 보행은 이번에 재검수하지 않았다.

## 자연스러운 속도 보정 — 같은 날 후속 정정

위의 첫 접지 수치는 발이 움직이지 않는 표본만 측정했고, 최고 티어의 과도한 본체 속도와 회전 중 발 디딤 순서를 충분히 검증하지 못했다. 지상 영상이 이전 버전인 것과 별개로 실제 게임에도 문제가 남아 있었다. 이번 수정과 측정이 앞의 자연스러움 판단보다 우선한다.

기준 재생속도 1의 보폭/주기와 최대 보행 배율을 역할 데이터에 둔다. 보초는 1.15m/1초, BASTION은 1.15m/1.25초, RAPTOR는 1.1m/0.8초이며 최고 이동은 각각 약 1.38·1.06·1.79m/s로 제한한다. 좌우/후진은 도메인 속도와 발의 보폭을 함께 줄인다. 속도 추종에 가속 한도를 적용하고, 옆걸음 방향의 정규화 때문에 사인 곡선의 영점에서 바로 최고속 반전하던 계산을 수정한다.

발은 실제 이동거리와 회전거리로 순서를 진행한다. 다른 지지 다리를 남기고 한 쌍씩 발을 들며, 다음 착지 위치에 선회 방향까지 예측한다. 회전을 정지 후 발 정렬로 잘못 처리해 같은 다리만 반복해서 들던 조건을 분리했다. 완전히 편 다리가 되지 않도록 표시용 몸체 높이를 최대 14cm 보정하며 관절 길이와 호스트 위치는 바꾸지 않는다. 기존 골격/Blender 수정은 유지한다.

현재 Forward+ 600회 갱신(촬영 599프레임)의 저속→최고속→옆걸음→후진→정지·회전에서 지지 발이 전혀 없는 프레임은 세 기체 모두 0이었다. 연속 접지 중 프레임 간 최대 이동은 보초 0.919mm, BASTION 0.676mm, RAPTOR 0.346mm다. 회전 방향 전환·몸체 높이 보정과 실제 게임의 분대 이동·조준·사격·메뉴·저장을 확인했다. 추가로 0.12m/s를 10초 유지할 때 보폭도 함께 줄여 접지 오차가 세 역할 모두 0.6mm 미만이 되도록 했다. 수치만으로 모든 지형의 자연스러움을 보장하지 않는다. 동물 전종의 리깅 재제작과 외부망 6인 검수는 수행하지 않았다.
