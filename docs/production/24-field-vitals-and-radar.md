# 지상 탐험복 상태·획득 알림·주변 레이더

2026-09-06 사용자 승인: 체력, 달리기/스태미나, 실제 획득량 알림, 주변 탐색 레이더를 현재 협동 지상 플레이에 연결한다. [FIELD v1](22-uiux-guide.md)의 시각 표현 우선 원칙을 따른다.

## 현재 구현 규칙

- 좌측 하단 심장/번개 아이콘과 막대에 체력·스태미나를 표시한다. Shift를 누르고 지상에서 이동하면 달린다. 소진 시 걷기로 전환하고 일정량 회복 후 다시 달릴 수 있다. 메뉴·스캔 중에는 달리기를 입력하지 않는다.
- 체력은 호스트의 실제 지형 충돌에서 낙하 속도로 피해를 계산한다. 피격 시 화면 가장자리와 기존 ElevenLabs 오류음을 짧게 재생한다. 착륙선 지원 거리 또는 선내에서 피해 후 대기시간이 지나면 회복한다.
- 체력 소진 시 착륙 지점으로 긴급 구조한다. 개인 장비·화물은 보존하고 낮은 체력과 짧은 낙하 보호시간을 부여한다. 현재 사망/아이템 분실 규칙은 추가하지 않았다. 동물의 플레이어 공격·환경 독성 피해는 아직 연결하지 않았다.
- 우측 획득 알림은 자원 아이콘·이름·실제 증가량을 표시한다. 같은 자원의 연속 획득은 합산하고 3.5초 후 사라진다. 한 번에 최대 4종을 표시하고 나머지는 순서대로 보여준다. 광물, 굴착 암석, 회수 화물, 표본에 적용한다. 실패한 거래에는 표시하지 않고 재전송한 수령 기록은 중복 합산하지 않는다.
- 우측 상단 레이더는 북쪽 고정, 반경 80m의 탐험복 기본 기능이다. 지표 높낮이, 광맥 마름모, 조사 완료 생물의 원, 동료의 이중 원, 착륙선 아이콘과 플레이어 시선을 표시한다. 동료·착륙선이 범위 밖이면 가장자리 방향 표식을 유지한다. 광맥/생물은 2초 간격으로 갱신한다.
- 지형도는 생성 지표 높이의 32×32 단계색 투영이다. 지하에서는 ‘지표 투영 · 지하’를 명시한다. 실제 동굴 단면·굴착 편집 지도나 이동 경로 안내로 오해하지 않도록 구분한다. 지표 이미지는 8m 이상 이동하거나 행성이 바뀔 때 다시 만든다.
- 스캐너는 별도 무기 슬롯을 점유하지 않는 탐험복 기본 기능이다. 대상 E 유지 스캔, 기존 진행 막대와 조준 표식을 유지하고, 조사 완료한 생물이 레이더에도 나타난다. J는 연구, Tab은 항해·승무원 메뉴이며 레이더를 대체하는 탭이 아니다.

## 데이터와 동기화

구현 수치는 밸런스 확정값이 아니며 `data/crew_surface.json`의 `vitals`와 `radar`에서 관리한다. 체력/스태미나 최대값은 각각 100, 달리기 배율 1.65, 초당 소모 22/회복 18, 소진 해제 25, 안전 낙하 속도 12m/s를 초기값으로 사용한다.

`FrontierCrewVitals`는 호스트 지상 충돌 처리에서만 상태를 변경한다. 클라이언트는 달리기 의사만 보내고 체력·이동 속도를 주장하지 않는다. 만료된 이동 입력으로 계속 달리지 않는다. `crew.members[id].vitals`는 기존 스냅샷과 세계 체크포인트/종료 저장에 포함된다. 기존 기록에 이 필드가 없으면 호스트 입장 시 기본값을 채우며 유효 범위 밖의 저장은 거절한다. 개인 프로필을 이용해 현재 세계의 체력을 덮어쓰지 않는다.

획득량은 호스트 거래의 전후 재고/표본 차이로 계산한 `result.gains`이며 저장 성공 후 응답한다. UI는 세션 ID와 요청 순번으로 중복을 제거한다. 정상 채집의 기존 흡입·입자·ElevenLabs 효과음은 유지한다. UI용 2D 아이콘만 추가했으며 신규 모델·음원은 생성하지 않았다.

## 확인과 한계

`tests/test_field_instruments.gd`로 임시 세계의 실제 Godot Forward+ 창에서 이동, 소모/회복, 메뉴 차단, 지형 충돌 피해, 구조, 착륙선 지원 회복, 실제 채집량/중복 수령, 레이더, 960×640 배치, 스냅샷 형식, 저장/재접속/구버전 보완을 확인한다. 위치·낙하 초기 속도·소진 직전 스태미나는 짧은 재현을 위한 테스트 입력이다.

작은 화면에서 달리기 키 안내와 메뉴 버튼 간격이 부족한 것을 발견해 상태 영역을 위로 옮겼다. 실제 다중 클라이언트 전송, 장시간 성능과 전체 회귀는 이번 검사에 포함하지 않는다. 체력 시스템이 추가되었다고 모든 전투·환경 위험이 구현됐다고 해석하지 않는다.

최종 실행 결과와 화면은 [검증 기록](media/field-instruments/verification.json), [지상 화면](media/field-instruments/field.png), [작은 화면](media/field-instruments/field-960.png)에 기록한다.

최종 결과: **23개 확인, 실패 0**. 별도 진행 중인 광물/은하 변경을 제외하고 스테이징한 코드로 분리 실행했다. 기존 모델/음원 자산은 재사용했다. 이후 밝은 배경에서 획득 문구가 흐려 보이는 문제는 배경판을 추가하고 좁은 실제 화면 촬영으로 확인했다. 최종 정지 화면의 획득 알림은 이미 확인한 저장 수령 기록을 재생한 것이다. 실제 다중 클라이언트와 전체 회귀를 통과했다고 주장하지 않는다.

## 2026-09-06 — HUD 가림 최소화

사용자 요청으로 획득 알림의 배경판·테두리를 제거하고 아이콘과 수량만 표시한다. 글자에는 작은 그림자만 유지한다. 레이더는 외곽 패널·테두리·하단 제목/범례를 제거하고 원형 지도와 탐색 표식만 남긴다. 지도 배경의 투명도는 10%(불투명도 90%)이며 방향·대상 표식은 식별을 위해 유지한다. 기존 프레임이 보이는 이전 검증 이미지는 당시 구현 기록이다.

Godot Forward+ 실제 창 960×640에서 배경 비침과 획득 문구를 확인했다. 표시 변경만 좁게 촬영했으며 게임 규칙 전체 검사는 반복하지 않았다. [프레임 제거 당시 화면 — 투명도 90%의 이전 기록](media/field-instruments/field-borderless-960.png).

사용자가 투명도 수치를 10%(불투명도 90%)로 정정하여 지도 배경 알파를 0.9로 변경했다. 프레임 제거와 표식은 유지한다.

획득 알림은 사용자 요청에 따라 아이콘·설명을 한 묶음으로 가운데 정렬한다. 알림 영역의 중심은 우측 레이더 중심에 맞추며, 짧은 설명에 고정 폭의 빈 공간이 남지 않도록 글자 길이에 맞춰 배치한다.

가운데 정렬과 투명도 10%의 최종 상태를 Godot Forward+ 실제 창에서 확인했다. [최종 HUD 화면](media/field-instruments/field-centered-960.png).
