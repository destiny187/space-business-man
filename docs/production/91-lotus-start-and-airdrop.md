# Lotus 출항 지원과 보급선

후속 변경: L 단축키를 제거하고 선박 F 메뉴로 옮겼으며 최초 지상 시설 자동 배치를 제거했다. 아래 L 표기와 과거 캡처는 최초 구현 당시 기록이다. 최신 동작은 [선박 단말·빈 착륙지](93-ship-terminal-and-empty-landing.md)를 따른다.

2026-09-09. [사용자 승인과 스토리 경계](../game/19-lotus-story-and-support.md)에 따라 현재 기본 원정에 출항 화물·공용 FINCH·현장 보급을 연결했다. 급여, T4 독립, Space Y 사건, 지구 구조 엔딩은 이번 구현에 포함하지 않는다.

## 실제 동작

- 새 세계를 처음 시작할 때 공동 원정선의 철·구리·암석·얼음을 각각 50개로 구성하고 공용 FINCH 한 대를 정박시킨다. 착륙선 옆 실제 FINCH에서 F로 탑승한다. 개인 소형선이 없는 승무원이 정박한 공용선을 빌릴 수 있으며 재접속으로 복제하지 않는다.
- 지표에서 L 또는 하단 Lotus 버튼으로 재료 아이콘·실제 HERON 모델·무료 잔여 횟수·공동 크레딧·배송 상태를 표시한다. 호스트 저장 성공 응답 뒤 접수 안내와 호출음을 재생한다.
- 신청 위치에서 18~42m 이내의 시드 기반 후보를 찾는다. 평평한 지표, 원정선·시설·광맥·로봇·차량·승무원·소형선·다른 상자·수역·장식 지질·생물 후보와 물리 충돌을 확인한다. 보급 지점은 새 건설의 금지 반경으로도 예약한다.
- 출발 준비 후 네 덕트 팬이 회전하는 HERON이 접근한다. 집게 해제·추진 효과와 함께 상자를 내려놓고 떠난다. 호스트가 도착을 확정해야 상자 충돌·F 수령을 활성화한다.
- 접근 후 투하 직전에 자리를 다시 확인한다. 안전 공간이 사라지면 주변 후보를 다시 찾아 접근을 재개하며 모두 막히면 배송을 보존하고 대기한다.
- 해당 행성에 아무도 없고 사업 구역을 등록하지 않았어도 보급 원장을 갱신한다. 도착·수량·좌표를 저장하며 뒤늦은 방문은 상자만 표시한다. 수령량은 배낭의 남은 공간으로 제한하고 상자 잔량을 유지한다. 빈 상자는 짧은 뚜껑 연출 뒤 정리한다.

## 초기 밸런스와 저장

원본은 `data/lotus_support.json`. 한 번에 기초 재료 한 종류 50개, 세계 공동 무료 3회, 이후 개당 철 5 / 구리 7 / 암석 3 / 얼음 5 Cr다. 공동 호출 간격은 90초, 준비 20초·접근 8초·투하 3초·이탈 8초이며 최대 24개 보급 기록을 보존한다. **구현을 위한 초기 수치이며 사용자 확정 밸런스가 아니다.**

초기 구성은 새 세계만 받는다. 기존 저장에는 지원 원장만 추가하며 기존 선박·화물·분포를 보존한다. 저장된 v1~v3 광맥은 유지하고 새 v4는 고유 광물에서 누락된 기초 원료 한 종류를 시작 보장 목록에서 생략할 수 있다. 자연 광맥 전체를 제거하지 않는다.

진행은 호스트 활성 세션의 게임 시간이다. 현실 시간 오프라인 배송은 없다. 호스트 요청 중복 처리·리비전·저장 실패 롤백 경로를 사용하며 회사 지원은 원정선/개인 소형선의 현재 행성을 구분한다.

## 모델·음향

- 제작기: `tools/build_lotus_support.py`, 공통 `tools/ink_blender.py` 산업 재질 재사용.
- 원본: `art/blender/lotus/heron.blend`, `supply_crate.blend`. 게임 출력: `assets/models/lotus/`의 같은 이름 GLB.
- HERON: 네 덕트 팬과 가동 로터, 크림색 상부 몸체·청록 기구부, 배터리/열 배출부, 화물 레일·집게, 주황 Lotus 표식. 상자: 충격 받침대·보강 프레임·힌지 뚜껑·잠금쇠·손잡이.
- Blender Cycles 렌더와 실제 Godot Forward+ INK 렌더를 확인했다. 두 모델을 공통 `render_assets.json`에 등록한다.
- ElevenLabs에서 보급선 루프·착지·접수·개봉 4종을 생성했다. 원본 WAV와 프롬프트·생성 옵션·해시·후처리는 `audio/manifests/lotus-support.json`, 재처리는 `tools/import_lotus_audio.py`에 보존한다.
- 게임 파일은 48kHz PCM16 모노. 엔진 80ms 루프 크로스페이드, 나머지 가장자리 트림과 8ms 페이드, RMS/피크 제한을 적용했다. 엔진·착지·개봉은 공간 음향이며 메뉴/연출 입력 차단과 연계했다.

## 확인과 한계

현재 요청에 해당하는 최소 검사만 수행했다. `check_lotus_support.gd`는 새 화물·단일 FINCH·재시작 보존·안전 위치 거절·차감 롤백·중복 요청·공동 호출 간격·도착 전 수령 거절·건설 예약·무인/미등록 행성 배송·저장 재개·수령·공용선 대여·v4 분포를 확인했다. 25개 통과.

`check_lotus_play.gd`는 격리 저장으로 실제 Forward+ 창에서 FINCH 배치, 1280×800/960×640 보급 화면, 실제 호출·대기·비행·투하·F 수령, 로터/추진/엔진 스트림, 메뉴 음향 정지, 상자 충돌·뚜껑·저장을 확인한다. 23개 통과. 뒤늦게 생성한 현장 뷰에 상자만 남고 비행·투하음이 재생되지 않는 것도 확인했다. 코드 파싱 오류와 diff 공백 오류는 없었다. 첫 편지의 Lotus 안내도 960×640 창에서 버튼과 본문 표시를 별도 확인했다.

음원 파일·길이·레벨·게임 스트림 연결과 재생 상태를 확인했다. 사용자의 실제 출력 장치에서의 청감 밸런스 승인을 의미하지 않는다. 여러 실제 클라이언트를 동시에 연결하는 장시간 시험, 전 시드/극한 지형 탐색, 보급선 비행 경로의 동적 장애물 회피, 월급/독립/엔딩은 검증 또는 구현 완료로 기록하지 않는다. 투하 지점 안전 판정은 적용했으며 비행선은 연출 경로로 이동한다.
