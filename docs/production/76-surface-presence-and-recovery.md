# 지표 공간감·복원 풍경·환경음

2026-09-09 후속: 기존 자연물·장소별 소리와 바다/하천은 [추가 구현 기록](79-surface-scenery-and-hydrology.md)을 따른다. 아래의 하천 미구현 표기는 이 첫 작업 당시의 범위다.

2026-09-09 사용자 승인: 기존 Blender 에셋을 유지하면서 지표 플레이의 그래픽·사운드와 테라포밍에 따른 환경 변화를 함께 개선한다. 소관 게임 규칙은 [테라포밍](../game/04-terraforming-and-sales.md), 기존 표현은 [대기](41-surface-atmosphere.md)·[지표 재질](56-planet-surface-materials.md)을 따른다.

## 구현

- **지역 복원 풍경:** 호스트가 전달한 기압·독성·온도·물·생태, 적용되는 토양·염류 조건으로 풀과 나무의 정착 가능성을 계산한다. 작은 군락부터 나타나고 생태가 충분히 높아지면 나무까지 늘어난다. 여러 조건의 부족을 평균 점수로 숨기지 않는다. 조건 악화 시 표현도 점차 줄어든다.
- **기존 에셋 재사용:** `ink-study/frontier_grass.glb`, `tree.glb`의 모델·재질 원본은 수정하지 않는다. 시드로 정한 군락 위치, 크기·방향·단계와 기존 INK 셰이더의 선택적 흔들림을 사용한다. 풀은 군락당 MultiMesh로 묶고 원거리 표시를 제한한다.
- **배치 보호:** 착륙선·하선 공간·중앙 동선·시설·실제 광물 주변과 물속·급경사·지지 없는 지면을 피한다. 건설 기록·지형 변경을 받아 접지 위치를 갱신한다. 기존 자연물 배치와 충돌은 유지한다.
- **지표·물:** 기존 지표 셰이더에 지역 수분과 기압을 연결했다. 기존에는 초기 수분 공급만 사용하던 경로다. 적합한 온도·기압에서 기존 지형에 밀착한 작은 습윤 수면이 점차 드러난다. 원래 자연 수면은 유지한다.
- **공간감·움직임:** 주광 아래 접촉 음영의 기여를 보강했다. 공유 천체 시계·행성 시드에서 돌풍을 만들고 지표 입자·식생·물결·바람/잎 소리가 같은 강도를 사용한다. 바람을 막는 지형·충돌체와 동굴 진입에 따라 외부 소리를 줄인다.
- **활동 흔적:** 지면의 발자국·로버의 두 바퀴 자국과 호스트가 승인한 채집/굴착 위치의 잔여 흔적을 최대 40개로 유지하고 시간·바람에 따라 지운다. 지형 변경 때 이전 흔적을 제거한다. 실제 가동 중인 시설에만 작은 작업등 변화를 연결한다.
- **음향:** 황무지/자연음의 생태 35점 단발 교체를 현재 원정에서 해제하고, 바람·자갈·잎·물·지열을 완만하게 혼합한다. 복원 식생과 물 가까이에서 해당 소리가 커진다. 생물 자연음·방향성 울음은 주변의 실제 활성 동물에만 연결한다. 한랭·수분·대기가 있는 환경에는 긴 간격의 얼음 균열 사건을 둔다. 지형 뒤의 기존 기계음은 고역을 줄인다. 메뉴/포커스 이탈 시 새 재생기를 멈추고 종료 시 전용 잔향 버스를 해제한다.

표현 설정은 `surface_presence.json`, 환경 해석은 `FrontierSurfaceRecovery`, 배치/효과는 `FrontierSurfacePresence`, 음향은 `surface_soundscape.gd`가 맡는다. 생태 종합 수치가 이미 존재하는 지역을 재현하는 읽기 전용 표현이다. 저장 형식·경제·시설 소비·드롭·건설 충돌을 변경하지 않는다.

## 사운드 제작

ElevenLabs 웹에서 잎·풀 마찰, 자연 얼음 균열, 얕은 물가 3종을 각각 4초·프롬프트 영향도 30%로 생성하고 첫 변형을 선택했다. 잎과 물은 반복 설정, 얼음은 단발 설정이다. 48kHz 스테레오 PCM 원본과 게임용 편집본을 별도로 보존한다. 반복본은 80ms 연결 편집 후 3.92초이며 RMS -21dBFS 목표·피크 -4dBFS 상한을 사용했다. 프롬프트·생성 URL·다운로드명·체크섬·측정은 [매니페스트](../../audio/manifests/surface-recovery.json)에 있다. 기존 ElevenLabs 바람·자갈·지열·생물 소리도 재사용한다.

## 실제 확인

Godot Forward+ 실제 원정에서 착륙 후 동일 시점의 황무지/초기/성숙 복원 3단계, 근접 군락·습윤 수면·흔적을 촬영했다. 기존 Blender 모델이 현장에 배치되고 흔들림·그림자와 함께 렌더되는 것을 확인했다. 모델 원본을 수정하거나 새 Blender 모델을 제작하지 않았다.

`check_surface_presence.gd`의 관련 20개 확인은 실패 0이었다. 식생/물 단계, 실제 식생·물 근접 음원과 얼음 사건 재생, 출력 녹음, 생물 없는 환경의 자연음 억제, 기존 환경음 중복 방지, 메뉴 정지, 무대기/한랭 조건, 지역 경계와 저장 종료를 확인했다. 준비된 호스트 환경값을 전달하고 표현 시간만 빠르게 진행한 비교이며, 시설을 수시간 가동해 복원한 자연 진행 검증은 아니다. 비교를 위한 주광 시각을 고정했으며 실제 플레이에서는 공유 낮밤이 유지된다.

추가로 저장된 지표 재진입, 환경값 복원, 직접광 접촉 음영, 차폐 샘플, 반복 스냅샷의 노드 유지, 저장 종료와 음향 버스 해제 7개를 실패 없이 확인했다. 로버 주행 흔적과 전 시설 조합은 연결 코드 확인 범위이며 실제 주행 전수 검증은 하지 않았다.

대표 화면은 `media/surface-recovery/`에 보존한다. 녹음은 로컬 `/tmp/surface-recovery-mix.wav`, 측정값은 음원 매니페스트에 둔다. 주관적 청감 평가·전체 회귀·6인·Windows·장시간 성능 검사는 수행하지 않았다.

## 경계

- 복원은 기존 사업의 **지역 반경**에 적용한다. 행성 전체 기후·우주에서 보는 대륙 변화는 이번 구현이 아니다.
- 물은 기존 지형의 완만한 면에 생기는 얕은 습윤 표현이다. 호수 수위·하천 유동·바다 생성·새 수자원 채집 또는 물리 유체 시뮬레이션은 없다.
- 풀·나무는 생태 수치를 보여 주는 장식 피복이다. 별도 채집/조사 자원을 만들지 않는다. 고유 생물의 연구·이식·실험 구획 규칙은 보존하며, 지역 복원만으로 새로운 동물 계통을 생성하거나 전 행성으로 번식시키지 않는다.
- 기존 자연물 군집 배치는 이미 지질/시드를 사용하므로 재배치하지 않았다. 새 피복만 같은 지역 안에 추가한다.
- 위치·목표 성장 단계는 시드와 호스트 환경값으로 재현한다. 나타나는 보간 시간과 발자국/바퀴 자국은 로컬 표현이며 저장하거나 다른 승무원에게 동기화하지 않는다.
