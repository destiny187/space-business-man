# SP05 — Space Y 지구–화성 무역선

2026-09-10 구현. [기업 우주 계획](../planning/16-space-corporations-commits.md)의 SP05다. 새 세계에 저장하는 `corporate_space.traffic` v1과 기존 두 항만을 사용한다. SP04 이전 저장의 화성·항만·재고·플레이어 자산을 소급 변경하지 않는다.

CARRIER Y-01/Y-02 두 척은 은하 ID에서 파생한 고정 주소와 시드별 출발 위상을 가진다. 호스트 `orbit_time`만 사용해 하역→적재→계류 해제→상승 가속→순항→감속→접근 승인 대기→접안을 반복한다. 600초 편도는 초기 조정값이며 데이터로 저장한다. 두 선석을 나눠 사용하고 항만의 현재 공전 위치를 따라간다. 카메라 회전·항성계 재방문·저장 복원으로 새 배나 화물을 뽑지 않는다. 현실 부재중 운송 시간을 추가하지 않는다.

주 항로는 공전면 위 60km에 둔다. 상승/하강은 항만 상공에서 진행해 항성·행성·위성을 피한다. 최대 6인 원정선/FINCH 위치를 호스트가 공유하고 근접 항로를 부드럽게 비켜 간다. 접안 중인 갑판은 NPC 작업 구역이며 플레이어 선체 피해·차단벽을 추가하지 않는다. 실제 강체 비행/회피 AI나 궤도 역학 시뮬레이터가 아니라 동일 시간에서 재현하는 게임 운항이다.

현재 태양계의 두 선박만 생성한다. 다른 항성계에는 배 Node나 프레임 운항을 만들지 않는다. 같은 항성계에서는 근거리/원거리 모델을 유지하고 거리 히스테리시스와 먼 실루엣 페이드를 적용한다. 카메라 방향 때문에 기체를 재생성하지 않는다. 이 2척의 경로 샘플은 매 프레임 계산하며 더 큰 시드 항로의 관심 영역별 저빈도 계산은 SP07 범위다.

## 제작과 화면

Blender 원본은 중앙 동력부·모듈 포드 네 개·잠금 레일·착륙 슈·쌍발 엔진·Space Y 실물 표식으로 구성했다. `tools/build_space_y_freighter.py`가 공통 산업 재질/베벨/부모별 표면 병합을 사용한다. 근거리 20,748삼각형, 원거리 1,428삼각형이며 각각 32메시다. 포드·엔진 가동 부모와 배기 소켓을 유지했다. Godot에서는 화물 모듈 인양/적재와 크레인 회전, 추진광·엔진 자세 변화가 운항 단계에 연결된다. 크레인의 자석과 포드를 물리 결합한 관절 시뮬레이션은 아니다.

주시한 기체에만 회사 심볼·호출부호·상태·목적지·화물 슬롯을 표시한다. 천체 뒤 기체는 주시 대상으로 선택하지 않는다. 전체 항로 선을 우주 시야에 깔지 않는다. 교역 재고나 개인 가방은 운항 표현에서 수정하지 않는다. 플레이어 자동 운송·실제 물량 장부·시장 재입고·경제 가격 반응은 후속이다.

## 확인과 남은 경계

Godot 4.7.2 Forward+ / Metal / Apple M2에서 현재 원정 앱으로 출항 단계·추진 반복음·관제 이벤트·주시 정보·저장 복원을 확인했다. 왕복 1,200초의 천체/두 선박 간격과 단계 경계 연속성은 도메인 시간을 샘플링한 검사이며 실제로 20분 기다린 실행은 아니다. 가장 가까운 두 선박 간격은 이 시드에서 약 1,826m였다. 후반 단계 이미지들은 같은 실제 비행 렌더러의 별도 검수 카메라/시간 위치에서 촬영했다.

초기 검사에서 테스트 창 포커스와 외부 카메라 오프셋이 주시·음향 확인을 막았다. 검수 조건을 고쳤고, 커서 해제와 메뉴 음향 차단을 분리했다. 재확인 15항목 중 14개 통과 후 남은 메뉴 검사는 정지된 반복음에도 `stream_paused`를 요구한 기대값 오류였다. ‘정지 또는 일시정지’로 고친 최소 메뉴 재확인을 별도로 실행했다. [운항 검사](media/corporate-space/freighter-check.txt) · [메뉴 재확인](media/corporate-space/freighter-menu.txt).

음향은 기존 ElevenLabs 엔진과 관측 완료음을 함내 합성 센서/관제 수신음으로 재사용했다. 메뉴·숨김 뷰에서는 재생을 차단한다. 신규 음성이나 효과음 생성은 없고 주관적 청감 검수는 수행하지 않았다. [음원 매핑](../../audio/manifests/space-traffic-reuse.json). 전수 회귀·실제 다중 클라이언트·Windows·장시간 성능 검사는 수행하지 않았다.
