# 고속 항해 출발 후 실제 비행 화면

## 2026-09-10 — 간결한 항해 화면과 연속 선회

사용자 요청으로 성간 이동 중 단계명·초고속 순항 문구·퍼센트·남은 초·에너지 자동 공급 설명을 제거했다. 작은 진행선과 점, 속도(m/s), 기존 별빛/추진 효과로 이동 상태를 전달하고 도착 시 항성계 이름과 짧은 밑줄만 표시한다. 첫 Sol 소개도 같은 구성을 따른다. 이동과 첫 방문의 큰 도착 소개 동안 미니맵·튜토리얼 카드·속도 외 일반 계기를 숨기며 항성 위험·실패 안내와 명시적으로 여는 메뉴는 유지한다. 이동 중 설명 단계를 별도 카드로 세지 않아 가이드는 조작·관측·출발·착륙·장비·채집의 7단계로 표시한다.

기존 출발 방향은 현재 기수에 가장 가까운 안전 방향이었다. 새 출발은 선택한 항성계의 은하 지도 방향을 우선하며, 기존 천체·위성·항만·기업 시설·화물의 공전 여유를 포함한 안전 경로 검사로 보정한다. 정렬 구간에서 최단 회전으로 기수를 돌린 뒤 기존 직선 출발 경로로 가속한다. 임의의 곡선 이동으로 장애물 검사를 우회하지 않는다.

표시 진행은 호스트 진행 사이를 최대 0.2초 보간하며, 호스트의 항성계 교체 전에는 다음 항성계 좌표를 표시하지 않는다. 출발 감쇠 구간부터 도착 감쇠 종료까지 하나의 회전을 이어가므로 교체 순간 기수 목표가 꺾이지 않는다. 추적 카메라의 위치와 방향이 같은 보간 회전을 따르고, 실제 표시 선회가 기존 자세 제어 추진/음원에 연결된다. 안전 반경·호스트 항로·도착 위치를 유지한다. 회전/보간 조정값은 `space_presentation.json`의 `stellar_transition`에 둔다.

기존 Blender 선체·천체, INK v1 렌더와 ElevenLabs 추진·도착 음원을 재사용했다. 새 모델·음원은 제작하지 않았다.

### 후속 승인 — 속도와 조작 전환

속도는 이동·첫 방문 소개에서도 오른쪽 아래에 유지한다. 타이머·단계 설명은 추가하지 않는다. 첫 방문 이름은 기존 6.5초 소개를 사용하지만 WASD·Shift·E/F 또는 마우스 조작을 시작하면 0.25초 동안 사라지고 미니맵·조준/스캔·가이드는 즉시 복구한다. 도착 전부터 누른 이동/스캔 입력도 반영하며 메뉴·비활성 창·첫 지구 시작 연출은 이 입력으로 넘기지 않는다.

항성계 재방문은 위쪽 중앙의 작은 이름과 짧은 밑줄을 2.2초 표시하며 레터박스·HUD 숨김을 적용하지 않는다. 세계의 기존 행성 방문 기록을 항성계 단위로 판정하고 Sol은 출발지로 취급한다. 저장 후 재시작·참가로 현재 항성계를 처음 그리는 경우도 작은 이름을 사용한다. 첫 지구 시작 연출의 Sol 소개는 유지한다.

새 항해의 정렬 시간은 안전하게 보정한 출발 방향과 현재 기수의 각도로 결정한다. 현재 초기 조정값은 0.4~3.6초이며 나머지 비행 시간은 기존 12초 중 9.6초를 유지한다. 짧은 회전은 빨리 출발하고 큰 회전은 시간을 확보한다. `transit.alignment_seconds`와 `transit.revisit`를 선택 필드로 저장·검증하며, 이 필드가 없는 기존 항해 중 저장은 원래 타이밍을 따른다. 호스트 이동·모델 교체·카메라·추진음·음악이 동일한 단계 변환을 사용하고, 안전 경로에는 최대 정렬 시간을 포함한 공전 여유를 확보한다.

시야각은 정렬 동안 사용자 설정값을 유지하고 가속하며 넓어진 뒤 감속 구간에 복귀한다. 초기 증가값은 최대 20도이고 상한은 기존 110도다. 시작 연출과 일반 수동 부스트의 시야각은 유지한다. 조정값은 `space_presentation.json`의 `stellar_transition`과 `stellar_arrival`에 둔다.

### 후속 확인

Godot 4.7.2 / Apple M2 / Metal Forward+의 실제 960×640 원정 창에서 반대 방향 출발→첫 항성계 도착→W/마우스 입력으로 소개 종료→정렬된 방향으로 Sol 귀환을 확인했다. [관련 확인 21개, 실패 0개](media/stellar-refinements/verification.txt). 첫 출발은 13.2초, 정렬된 귀환은 약 10초였다. 사용자 시야각 76도에서 정렬 76→순항 96→감속 약 79.7→진입 76도를 확인했다. 속도·재방문 HUD를 실제 렌더로 검수하고 기존 추진 음원 재생, 새/기존 항해 저장 형식 및 방문 기록 저장 후 읽기를 확인했다. 전체 회귀·모든 시드·실제 다중 클라이언트는 실행하지 않았다.

[이동 속도](media/stellar-refinements/speed.png) · [첫 방문 이름](media/stellar-refinements/first-arrival.png) · [재방문 이름과 HUD](media/stellar-refinements/revisit.png)

초기 검사 실행에 `--crew-ui-test`가 빠져 기존 솔로 저장을 열고 항해 위치/목표를 변경한 실수가 있었다. 확인 즉시 복구 전 파일을 별도로 보존했다. 직전 좌표의 백업은 남지 않아 기록된 항성계의 안전한 진입점과 기존 방문 행성을 항해 목표로 복구했다. 항해 상태·승무원 준비 외 원정 콘텐츠가 동일함을 비교하고 세계 유효성 검사를 통과했다. 검사에서 만든 공동 세계 파일도 별도 폴더로 옮겼다. 최종 확인은 `--crew-ui-test`와 임시 저장 경로 일치 확인 후 수행했다. 이 사고를 기존 저장 무변경으로 기록하지 않는다.

### 직전 변경 확인

Godot 4.7.2 / Apple M2 / Metal Forward+의 960×640 실제 원정 창에서 확인했다. 격리한 검사 세계를 시작 연출 완료 상태로 준비하고 선택한 별의 반대 방향을 바라보게 배치한 뒤, 정상 항로 선택·호스트 승인으로 출발했다. 목적 방향의 안전 검사, 정렬·가속·교체·도착, 이동 중 HUD 숨김, 기존 음원 재생, 유효한 도착 상태와 저장을 확인했다. [관련 확인 16개, 실패 0개](media/stellar-minimal/verification.txt).

[선회](media/stellar-minimal/turn.png) · [이동 화면](media/stellar-minimal/transit.png) · [도착 이름](media/stellar-minimal/arrival.png)

초기 실행에서 비행 뷰 준비 전의 미니맵 참조 오류를 수정했다. 검사 도구의 임시 폴더/이전 스냅샷 참조도 수정했고, 비활성 창에서 자동 음소거·제목 숨김이 적용되어 네이티브 게임 창을 활성화한 뒤 소리와 제목을 다시 확인했다. 최종 실행에 스크립트/엔진 오류는 없다. 선회 중 263개 렌더 프레임의 방향 변화를 확인했으며 캡처를 포함한 최대 프레임 회전은 약 13도였다. 전 방향·모든 시드·다중 클라이언트/중간 합류·성능 회귀는 실행하지 않았으며 기존 사용자 저장을 사용하거나 덮어쓰지 않았다.

2026-09-07 사용자 정정: 은하 지도는 목적지 선택에 사용하며 출발하면 실제 우주 화면으로 전환해 기존 정렬·가속·순항·감속·진입 애니메이션을 보여 준다. 지도상의 임의 이동이나 순간이동으로 대체하지 않는다.

호스트가 `jump` 시작을 확정한 스냅샷에서 메뉴를 닫고 외부 시점·우주 비행 SubViewport를 복구한다. 지도에서 선택하거나 비행 화면에서 목적지를 정하더라도 같은 승인 경로를 따른다. 성간 출발 거절 시에는 선택 화면과 기존 실패 이유를 유지한다. 항해 진행·목적지 모델 준비·캐시·저장 규칙은 변경하지 않는다.

실제 Godot 4.7.2 Metal Forward+ 창에서 지도 출발→외부 비행 화면/렌더 복구→진행→선택 항성계 도착·저장을 확인했다. 항해 16% 정렬 단계의 선체·출발 천체·진행 표시를 검수했고, 목적지 4행성 사전 준비 재사용도 통과했다. 관련 최소 검사 실패 0. `tests/check_planet_preparation.gd`에 승인 후 비행 화면·렌더·미완료 항해 상태 검사를 추가했다. 로컬 캡처는 `test-results/navigation-cache/flight-transition.png`다. 전체 회귀·다중 클라이언트는 수행하지 않았다.
