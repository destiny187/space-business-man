# 흡입 채집·표면 스캔·카빈 동작 개선

2026-09-07 후속 사용자 제보: 클릭 유지 중 ‘준비 중’이 반복되어 연속 채집이 매끄럽지 않다. [B1](../planning/09-ground-play-feedback.md)에 미해결로 등록했다. 작업 자체의 재시작인지 알림 표시 문제인지는 미재현이며, 아래 과거 확인 결과로 해당 제보가 해결됐다고 판단하지 않는다.

2026-09-07 사용자 요청: 곡괭이처럼 느껴지는 채집 동작을 흡입기로 명확하게 바꾸고 스캔·공격의 시청각 품질을 높인다. INK v1과 FIELD v1을 유지한다. 기존 장비 종류·등급·채집량·호스트 승인 규칙은 소관 장비 규칙을 따른다.

## 현재 구현

- 채집 성공마다 발생하던 장비 타격 반동·금속 타격음·방사형 파편을 제거했다. 흡입 팬은 서서히 가속하고 장비는 앞으로 작게 당겨진 안정된 자세와 미세한 진동을 유지한다. 채집 주기 사이에도 가동이 이어지고 마지막 처리 후 감속한다.
- 광맥에서 실제 흡입구로 수렴하는 네 줄의 가느다란 기류, 이동하는 밝은 조각, 가속하며 작아지는 자원색 파편을 연결했다. 물리 레이가 광맥 뒤 지면에 닿는 경우 선택된 실제 광맥 모델 위치로 보정한다. 획득 연출은 기존 호스트 성공 응답 이후에만 시작한다.
- 스캔은 무작위 입자 대신 대상의 실제 메시 표면 위로 조사선·잔상·희미한 눈금이 이동한다. 진행은 호스트의 스캔 값을 사용하고 새 완료 전환에만 짧은 녹청색 표면 반응과 발견음을 재생한다. 이전에 알려진 대상을 다시 보기만 해서는 새 완료음을 내지 않는다. 대상 변경·메뉴·장면 종료 시 기존 오버레이를 복구한다. 메시가 없는 대상에는 구형 조사 범위를 대체 표시한다.
- 카빈은 짧은 후퇴 후 감쇠하며 복귀하는 별도 반동과 총구 발광을 사용한다. 탄착 입자를 요청 성공 시점과 탄 도착 시점에 중복 생성하던 경로를 정리했다. 생물 전투 시스템 자체의 변경은 아니다.
- 메뉴에서는 팬/조사 루프와 기류·표면 스캔을 중단하고 메뉴를 닫아도 지난 흡입 동작을 재개하지 않는다. 장비 모델 교체 때 남은 입자와 동작을 정리한다.

## 제작 자산과 음향

기존 Blender 원본/GLB의 M-02·카빈과 `Anim_Fan`·`Anim_Piston` 연결점을 재사용했다. 새 모델 제작이나 Blender 원본 변경은 없다. 새 효과는 Godot 메시 리본 및 투명 셰이더이며 실제 게임의 INK 렌더로 검토했다. 모델 자체의 고품질 재제작 완료를 의미하지 않는다.

ElevenLabs 신규 생성 없이 [기존 원본·프롬프트·해시](../../audio/manifests/elevenlabs.json)를 재사용했다. 채집은 `sfx_terraform_active` 팬/압축기 루프에 작동 강도별 음량·피치를 적용하고, 스캔은 `sfx_robot_charge`에 조사 진행별 피치를 적용한다. 획득·발견·카빈 소리는 각각 `sfx_pickup_resource`, `ui_discovery`, `sfx_combat_pulse`를 유지한다. 개인 흡입에서 기존 드릴 계열 `sfx_robot_work`와 금속 타격음은 사용하지 않는다. 공통 흡입 오디오 함수를 쓰는 이전 사업 장면도 팬 루프를 사용한다.

## 실제 확인

Godot 4.7.2 / Metal Forward+ / Apple M2, 1280×800의 현재 원정 장면에서 **12개 확인, 실패 0**. 임시 세계로 착륙한 후 실제 광맥 조준→호스트 채집/잔량 감소→흡입 가동/무반동→스캔 진행/완료→카빈 발사→메뉴 중단/재개 차단→저장을 확인했다. 위치 이동과 카빈 재료 공급은 검사 전용 상태다. 첫 검사에서 재료 fixture가 필수 자원 키를 누락하여 저장·공격이 거부됐다. 전체 품목 기본 재고를 사용하도록 fixture를 고친 뒤 해당 흐름만 다시 확인했다. 실제 오디오 재생 상태를 확인했으며 주관적 청감 승인으로 간주하지 않는다.
