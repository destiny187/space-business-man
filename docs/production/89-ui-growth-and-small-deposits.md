# 아이템 표시, 강화 트리, 작은 광맥

2026-09-09 사용자 요청의 현재 실행 경로 적용 기록이다. 기존 성능 조사와 멀티플레이 검증 작업은 별도 변경으로 보존했다.

## 아이템과 건설

- 하단 번호 슬롯을 80×80으로 늘리고, 70×70 아이콘 영역의 가로·세로 중앙에 비율을 유지해 그린다. 이름은 툴팁으로 유지하고 번호와 등급은 모서리에 둔다. 5칸 전체 폭으로 화면 중앙을 계산한다.
- UI의 중간점 구분자를 제거했다. 자원 요약에도 같은 처리를 적용한다. 건설 카드는 건물 이미지, 이름, 재료 아이콘과 필요 수량을 함께 표시한다. 내 배낭에서 부족한 품목의 숫자만 빨간색이다. 선택 상세는 보유/필요량을 보여 준다.
- 배치 버튼은 카드 목록 위에 두어 작은 창에서도 접근할 수 있다. 부족 상태에서 실행하면 `재료가 부족합니다.`를 표시한다. 호스트 배치 검사도 같은 문구를 사용한다. 가방 전용 소비와 별도 창고 입출고는 유지한다.
- I의 소유 장비 상세에서 장비/탐험복 개조 이동 버튼과 다음 개조 비용을 제거했다. 보강 프레임은 실제 가공 부품이므로 삭제하지 않는다. 실제 장치의 장비 개조 탭에서 기능 설명과 재료 아이콘을 확인한다. 휴대 제작의 부족 비용도 숫자로 표시하고 실행 시 부족 이유를 알린다.

## 신체 강화 트리

`crew_augmentation.json`이 단계, 재료, 선행 조건, 효과의 원본이다. 3개 계열, 12개 능력, 각 5단계이며 아래 수치는 이번 구현의 조정 가능한 밸런스다. 신체 성장과 소유 장비의 Mk. 개조는 별개다.

| 계열 | 능력 | 한 단계 효과 | 선행 조건 |
| --- | --- | --- | --- |
| 기동 | 보행 강화 | 이동속도 +10% | 없음 |
| 기동 | 도약 | 점프 높이 +12% | 보행 강화 1 |
| 기동 | 지구력 | 달리기 소모 −8% | 보행 강화 1 |
| 기동 | 호흡 회복 | 스태미나 회복 +15% | 지구력 2 |
| 작업/전투 | 근력 강화 | 무기 피해 +10% | 없음 |
| 작업/전투 | 속사 | 사격 빈도 +8% | 근력 강화 1 |
| 작업/전투 | 정밀 채집 | 채집 빈도 +10% | 근력 강화 1 |
| 작업/전투 | 굴착 제어 | 굴착 반경 +6% | 정밀 채집 2 |
| 생존 | 생체 강화 | 최대 체력 +20% | 없음 |
| 생존 | 충격 흡수 | 낙하 피해 −12% | 생체 강화 1 |
| 생존 | 재생 촉진 | 선박 근처 체력 회복 +20% | 생체 강화 1 |
| 생존 | 회복 적응 | 낙하 피격 후 체력 회복 대기 −12% | 재생 촉진 2 |

각 단계의 변화는 기본값 기준으로 합산하며 기존 탐험복/숙련 효과와는 곱한다. 도약은 발사 속도에 높이 배율의 제곱근을 적용한다. 호스트 이동과 클라이언트 예측/재실행에 같은 배율을 전달한다. 물속 상승 조작에는 점프 보너스를 적용하지 않는다.

기동은 사파이어, 작업/전투는 루비, 생존은 에메랄드를 소비한다. 기존 기본 능력의 가격은 유지하고 새 1차 분기는 4×다음 단계, 마지막 분기는 6×다음 단계다. 선행 조건은 호스트가 다시 검사한다. 기존 3능력 v1 저장은 검증 후 v2로 확장하고 구매 단계는 그대로 둔다. 다른 능력은 0부터 시작한다. 무료 초기화/환불/배타적 선택은 추가하지 않았다.

12노드의 연결선, 서로 다른 기능 아이콘, 잠금 선행 단계, 현재/다음 효과, 보석 비용을 표시한다. 960×640에서도 전체 노드와 비용·실행 버튼은 보인다. 상세 내용은 필요하면 스크롤한다. 기존 Blender 캐릭터/증강 장치와 INK 렌더, 보석 투입·호스트 결과 연출 및 ElevenLabs 음원을 재사용한다. 새 기능 아이콘은 코드 기반 SVG다.

## 광맥 분포 v3

새 은하의 생성 규칙에만 적용한다. 기존 은하의 저장된 규칙, 광맥 ID와 고갈 잔량은 재작성하지 않는다.

- 착륙지: 큰 광맥 5개(150~310)에서 작은 광맥 최대 25개(철 40, 구리/암석/얼음 30)로 분산한다. 시드별 지면을 찾아 배치하며 광맥끼리 최소 5m 간격을 유지한다.
- 일반 80m 지역: 지표 후보 4→12개, 지하 후보 3→6개. 원래 재료 풀, 주변 지형/원정 구역 제외 조건은 유지한다.
- 일반 원광 매장량: 180~319에서 기본 18~45로 줄인다. 행성 티어가 하나 오를 때 +8, 착륙지에서 1km마다 +10(최대 +50)을 더한다. 일반 지하 보석은 40→8이며 별도 보장 동굴 표본은 기존 규칙을 유지한다.
- T2 원정 규소/인산염은 한 곳 160에서 최대 4곳에 35씩 배치한다. 일반 월드와 마찬가지로 예전 은하의 ID/잔량은 보존한다.
- 한 번의 도구 작동당 획득량과 등급 제한은 유지한다. 이번 변경은 한 광맥에서 오래 캐는 시간을 줄이는 매장량/분포 조정이다.

## 확인과 남은 범위

Godot 4.7.2, Metal Forward+, 실제 게임 창 1280×800 및 960×640에서 변경 화면을 렌더했다. 격리된 `/tmp/ui-growth-refresh` 세계를 사용했다. 기존 사용자 저장은 열거나 변경하지 않았다.

`check_ui_growth_refresh.gd`의 변경 관련 최소 확인: 새 세계/지상 규칙, 다수의 작은 광맥, 구 강화 저장 확장, 선행 조건의 호스트 거절, 기본/분기 능력 구매와 보석 차감, 저장 복원, 실제 캐릭터 점프 초속 변화, 낙하 피해 감소, 소유 장비 안내 제거, 슬롯 중앙 정렬, 지상 건설 카드와 부족 메시지, 실제 작은 광맥 채광 요청의 잔량 차감. 21개 확인에서 실패 0건. 실제 장치의 기존 효과·음원 연결을 확인했으며 전체 음향 청감 검수는 수행하지 않았다.

검수 중 JSON의 실수 버전 값을 정수 배열 `in`으로 판정해 신규 세계를 거절하는 오류를 발견해 명시적 값 비교로 수정했다. 작은 창에서 강화 비용/실행 버튼이 밀리는 문제는 하단 고정 영역으로, 건설 실행 버튼은 카드 위로 옮겨 수정했다.

전체 회귀, 6인 실제 접속, 모든 시드의 광맥 수와 장시간 경제 밸런스, 전체 12능력의 현장 전수 시험은 하지 않았다. 기존 은하에 새 분포를 이식하는 저장 이행은 이번 범위에 포함하지 않는다.
