# 원정 기본 플레이 품질 복구

## 확정 방향과 원인

2026-09-06 사용자가 콘텐츠 확장 중 사라진 장비·건설 비주얼·사운드를 지적하고 첫 커밋 수준의 기본 동작과 시청각 품질을 현재 게임에 유지하도록 요청했다. 텍스트는 보조이며 필요한 애니메이션·이펙트·사운드를 기능과 함께 제공한다. 제작 도구는 사운드 ElevenLabs, 3D 모델링 Blender와 렌더러 검수로 명시한다. 저장소 전체의 필수 규칙은 [AGENTS.md](../../AGENTS.md#기본-플레이-품질-유지--필수)가 원본이다.

비교 기준 `d73b1d6e`의 `manual_tool.glb`, `FrontierEffects`, `FrontierAudio`, 실제 INK 도감 이미지와 16종 ElevenLabs 음원은 삭제되지 않고 기존 사업 장면에 남아 있었다. 새 기본 진입 경로인 `crew_expedition.tscn`에서 장비/오디오/효과를 연결하지 않았고 새 건설 화면을 목록 위주로 구성한 것이 체감 퇴행의 원인이다. 추가로 INK 화면 합성의 우선순위 100이 투명 배치 고스트와 입자를 덮어 지우는 오류를 실제 GPU에서 발견했다. 공통 윤곽선 패스를 투명 효과 이전(-128)으로 옮겼다. 단순히 노드가 생성됐다는 검사를 넘어 실제 출력 픽셀로 검증한다.

구 게임으로 되돌리는 대신 현재 자유 탐사·오프라인/협동 원정에서 사용한다.

## 현재 연결

- 기존 Blender 수동 장비를 현재 1인칭 카메라에 장착한다. 공통 INK 셰이더, 걷기 흔들림·흡입 팬·피스톤·펄스 반동·총구 광원과 자원 흡입/파편을 적용한다.
- 클릭은 조준한 사업 광맥이면 채광, 그 외에는 기존 지형 굴착이다. F 현장 작업과 우클릭 시선 조작은 유지한다. 펄스의 실제 결과는 현재 굴착이며 미구현 생물 피해/전투를 구현 완료로 표시하지 않는다.
- 요청 순번에 조준점과 행성을 기록하고 저장 성공 응답 이후 효과를 재생한다. 거절 시 실패음/조준점 색으로 알린다. 행성 전환/재접속의 과거 기록으로 성공 효과를 재생하지 않는다.
- 건설 탭은 시설별 실제 INK 게임 렌더 카드와 재료 아이콘, 기존 월드 배치 고스트를 연결한다. 로봇 탭에도 실제 모델 이미지를 복구하며 환경·계약 탭은 대기·온도·물·생태 진행 막대를 제공한다.
- 실제 스캔 진행 막대와 대상의 청록 입자, 발견 완료음, 표본/반납 확인음을 연결한다. 건설·로봇 생성/광맥 고갈은 새 공유 상태를 관찰해 효과를 재생한다.
- 황무지/복원 환경음, 근처 로봇 이동·채광·충전과 테라포밍 설비의 가동 루프/입자를 기존 음원/버스로 연결한다. 3D 높이·거리 및 동시 12개 제한을 유지하고 메뉴 중 루프/도구 작업을 중단한다.
- 메뉴 중 이동·굴착·표본 채집·현장 작업 입력을 차단한다. 개인 음량 설정은 기존 SFX/Ambience/UI 버스를 사용한다.

## 제작 자산과 제한

새 유료 음원이나 모델을 생성하지 않았다. 기존 [ElevenLabs 생성 이력](../../audio/manifests/elevenlabs.json), Blender 원본과 [INK 렌더 목록](../../우주-비즈니스/data/render_assets.json)을 재사용한다. 신규 종별 음성·선내/항해 전용 환경음은 [사운드 미생성 목록](02-audio-and-elevenlabs.md#탐험-확장의-준비-목록--미생성)에 남는다. 현재 수동 장비 형상의 고품질 재제작, 생물 전투 AI/피해, 모든 연구·교역 화면의 시각화, 행성 전체 최종 아트·음향 완료를 의미하지 않는다.

## 검증

`tools/test_play_quality.sh`로 전용 임시 폴더에서 실행한다. `test_expedition_presentation.gd`는 기존 실제 혼자 진입/항해/착륙/굴착/저장 재개 흐름에서 장비·성공/실패 효과·음원·메뉴 억제·전체 건설 카드·960×640 배치 고스트를 검사한다. 일반 사용자 저장 대신 `--crew-folder`의 전용 파일을 쓴다. 첫 커밋 계열의 기존 규칙·입력·연출 검사는 `tools/test_game.sh --with-ui`로 별도 유지한다. 실제 실행 결과와 미검증 항목은 아래에 기록한다.

### 2026-09-06 실행 결과

[검증 수량·로그 해시](media/play-quality/verification.json). 키 입력을 사용하는 기존 연출 검사는 단독 테스트 창에서 재실행하여 통과했다.

- Godot 4.7.2 / Metal Forward+ / Apple M2의 실제 창: 혼자 시작·항해·착륙·장비 성공/실패·메뉴 억제·전체 건설 카드·저장 재개 **70개 통과**. 이 중 가동 상태별 음원/3D 높이/정리는 비영속 표현용 합성 상태 검사이며 실제 자원 생산 검사로 합산하지 않는다.
- 실제 두 ENet 클라이언트/두 Metal 창의 채광·운반·건설·로봇 제작/가동·지역 복원·정산·호스트 재시작 **234개 통과**. 위치 제어와 산업 시간 가속을 사용했다. 인터넷 실기/6인 장기 부하 검증은 이번에 수행하지 않았다.
- 투명 고스트/실제 입자의 최종 픽셀과 두 카메라 윤곽·기울어진 지면의 공통 렌더 검사 **11개 통과**. 기존 검사의 고정 1440×900 픽셀 접근 오류도 실제 이미지 크기를 읽도록 수정했다. 일반 검사 출력이 승인 참조 PNG를 덮어쓰지 않도록 `test-results/`로 분리했다.
- 자원 UI **9개 통과**. 기존 게임의 자산 계약·경제·이벤트·신뢰성·완결 루프·온보딩·68개 오디오·19개 입력·25개 연출·33개 그래픽 검사도 통과했다. 최초 전체 실행에서 발견한 렌더 검사 오류는 수정 후 해당 검사를 다시 실행했다.
