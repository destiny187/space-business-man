# Q04~Q06 — 제작·운반·복원 결과 연결

2026-09-14 [세 묶음 개발 승인](../planning/17-existing-play-polish-plan.md)의 두 번째 구현이다. 기존 사용처·묶음 생산·로봇 작업 선택·지역 환경 규칙을 보강했다.

## 플레이 변경

- 배낭 재료의 알려진 사용처에서 개인/현장 재고를 구분한 비용을 표시한다. 제품은 8m 안 실제 제작소를 열고 멀리 있으면 지역지도에 목적지를 찍는다. 확인한 산지는 기존 스캔의 `vein_id`만 해석한다. 없는 장소는 건설 선택이나 추가 관측으로 안내한다. 지도 연결은 이동/채집/구매를 실행하지 않는다.
- 제품 조건은 호스트와 UI가 같은 읽기 전용 함수를 사용한다. 묶음 수량의 재료 조건을 표시하고, 최대 버튼은 소비 후 재고·다른 제작소의 예약 완성품·실제 창고 용량을 고려한다. 기존 예약은 보존하며 수동 수량으로 공간보다 많은 생산을 예약하면 기존처럼 출고 대기한다. 배낭 재료를 현장 재료로 합산하지 않는다.
- 창고 연결·수량·최대 버튼을 한 줄로 정리하고 필수 재료는 상세 스크롤 밖에 유지한다. 제출 직후 버튼을 막고 호스트 확정/실패 뒤 다시 표시한다. 기존 화물 선택/방향/수량과 부분 인출 기능은 재사용한다.
- 로봇 F 작업창에 실제 배터리·화물 게이지와 현재 정지 사유에 대응하는 창고/발전·충전/위치 연결을 추가했다. 자동 전체·발견 자원 선택·현장 지시는 기존처럼 구분한다. 이동속도·채광률·레시피는 바꾸지 않았다.
- 테라포밍 지도에서 선택 지점의 실제 처리 반경에 해당하는 설비와 호스트 가동/정지 상태를 연결한다. 기존 복원 계산·지면 표현을 그대로 사용한다.
- 정산은 이번 지급/중간 지급/공동 자금 전후와 실제 시설·로봇·지역 재고·보관 장비 수량을 구분한다. 정산 후 기존 공동 연구/선박 정비로 이동할 수 있다. 확정 스냅샷의 새 단계·정산만 기존 짧은 알림에 반영하고 첫 수신/반복 수신은 재생하지 않는다.

## 확인과 근거

Apple M2 / Godot 4.7.2 Metal Forward+, `/tmp/t3-preparation-play`의 별도 사본에서 `check_polish_workflow.gd` 26항목을 확인했다. 재료는 검사 준비 단계에서 창고에 제공했다. 실제 제작소 위치 접근 → 제품 사용처 연결 → 호스트 2묶음 생산 → 지역 창고 완성품 → 로봇 실제 조립/출고 → 명시적 자동 작업 선택과 세계 저장을 확인했다. 최대량의 읽기 전용·수납 부족·재료 부족도 비교했다.

![960×640 제작 재료·수량](media/182-production-960.png)

작은 화면에서 새 버튼이 상세 영역을 누르는 문제를 발견해 수정하고 `--layout-only`로 수정 화면만 다시 확인했다. 재료 수치·실행 버튼·상세 스크롤 높이를 확인했고 스크립트 오류가 없다. 정산 한국어 버튼과 수질 처리 설비 연결도 실제 렌더에서 확인했다.

![선택 지점의 실제 수자원 처리 설비](media/182-environment-960.png)

정산 비교는 실제 저장 원장의 금액/자산으로 표시했고, 알림의 첫 수신/새 단계/중복 수신은 별도 표시용 스냅샷 입력으로 확인했다. **이번 검사에서 복원 완료 조건을 새로 달성해 최종 정산을 실제 지급하지는 않았다.** 실제 현장 생산 확인과 알림 주입 검사를 구분한다. 로봇 자동 선택 이후 전 채광/운반/하역 주기 및 장시간 노동 감소·밸런스는 이번 국소 확인에 포함하지 않았다.

기존 `check_planet_supply.gd`는 예전 출항 연출/지역 저장 준비 때문에 실패했다. 현재 변경의 통과 근거에 넣지 않았고 테스트 파일을 삭제하지 않았다. 첫 전체 UI 검사 종료에서 ObjectDB 3개 정리 경고가 있어 검사 장면 해제를 명시했고, 후속 레이아웃 검사에는 해당 경고가 없었다.

## 처리 범위와 기존 저장

위치 연결·수량 견적·자산 비교는 읽기 전용이다. 현재 현장의 알려진 시설·관측과 해당 레시피/예약만 살핀다. 같은 재료 표시는 재생성하지 않고 닫힌 제작 화면의 요청 알림은 대기 ID만 보관한다. 생산 클릭 한 번은 기존 요청→지역 재료 차감/예약→전체 검증·원자적 저장→확정 스냅샷 경로를 유지한다. UI에서 별도 자원/돈을 지급하지 않는다.

세이브 형식·세계·기술·소유권·기존 예약·수량은 변경하지 않았다. 새 아트/음원 제작, 모든 환경/시드 경제 균형, 외부망/6인 검수 완료를 의미하지 않는다.
