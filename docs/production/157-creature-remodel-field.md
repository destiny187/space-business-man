# 동물 리모델링 — 첫 원정 연결과 지형 보행

2026-09-12. 사용자의 전체 작업 계속 요청에 따라 [155의 제작 모델](155-creature-remodel-rollout.md)을 원정의 `bestiary_actor.gd`에 연결했다. **지상 6종의 일반 원정 표시를 교체했고, 지상 8종의 이동을 실제 임포트 모델과 Forward+ 렌더로 확인했다.** 전체 5,600동물 제작 완료와 구분한다. 새 모델 수는 이전과 같은 9개이며 이번에는 기존 Blender 제작 자산의 게임 연결을 진행했다.

기존 기본형의 `attack: none`만 읽어 비공격이라고 판단하면 안 된다. `wildlife_combat.json`의 `anatomical_attacks`가 cervid를 ram, felid를 claw로 바꾸고 felid에는 도약 행동을 적용한다. 이 두 종을 먼저 적용했다가 공격 동작과 실제 판정이 어긋나는 일을 피하기 위해 원정에서는 기존 모델/구동기를 유지한다. 최종 적용 6종은 실제 호스트 `pattern()`도 `none`임을 확인했다. 검토 장면의 분사·물기·타격 제작 클립이 있다는 이유로 새 전투 성향이나 피해를 활성화하지 않았다.

거대/둥지/동굴 등 **저장된 생물 사건은 기존 모델을 유지**한다. 사건 저장에 기록된 폭·높이·길이와 공격 시각에 맞춘 별도 연결이 필요하기 때문이다. 일반 지상 동물과 사건의 적용 수를 합쳐 기록하지 않는다.

## 표시와 데이터의 경계

- `creature_remodel_runtime.json`이 명시한 종 ID에만 교체를 적용한다. 분류·원산 행성·발견 이름·표본·저장 해시를 가진 원본 카탈로그 네 파일은 수정하지 않았다.
- 모델 선로딩과 지연 far LOD 설치가 같은 새 경로를 사용한다. 원본 카탈로그를 덮어써 저장 호환을 우회하지 않는다. 기존 모델/Blender 원본도 유지한다. 원거리 접지 조회 간격을 보존하고, 지형 수정·순간 이동에는 접지 캐시를 초기화한다.
- 기존 일반 원정의 배치 여유·조준 높이·물리 캡슐은 새 외형 경계를 읽는다. 공격거리·피해·추격 속도·티어 배율은 변경하지 않았다. 전투 부위별 피격 상자까지 교체한 것은 아니다.
- 새 모델의 INK 정점색과 재질 구분을 유지하고, 기존 개체의 색 변이는 기본 팔레트에 대한 상대 변화로 적용한다. 크기 배율은 모델과 보폭 환산에 함께 반영한다.
- 사건은 `allow_remodel=false`로 기존 표시를 명시한다. 다른 7,994종의 일반 표시도 기존 경로를 유지한다.

## 동작 연결과 수정

`remodel_motion.gd`는 기존 지상 이동 구동기의 권위 위치·부드러운 회전·순간 이동/정지 경계를 재사용하되, 새 관절에는 Blender의 전용 클립을 재생한다. 기존 절차식 `Anim_*` 관절 변형을 새 스킨 위에 겹쳐 적용하지 않는다.

걷기와 달리기의 재생률은 실제 이동 거리, 종별 보폭/지지 비율/클립 주기, 개체 크기로 계산한다. 속도 경계에서는 왕복 전환을 줄이고 주기 위상을 이어 간다. 멈출 때 발을 다시 디디며, 제자리 선회에는 전용 선회 동작을 사용한다. 호스트의 위치나 시간·이동 수치를 바꾸지 않는다.

경사에서는 각 발의 실제 두 관절 길이와 굽힘 방향을 보존해 지면을 보정한다. 지지 중인 발은 고정하고, 다리 도달 한계가 가까워지면 일찍 떼어 다음 보행으로 넘긴다. 도약의 공중 구간과 타격/무력화에는 발을 억지로 고정하지 않는다. 무족형은 몸통 파동을 유지하며 꼬리의 국소 지형 높이를 보정한다.

연결 과정에서 다음 문제를 재현해 수정했다.

1. **임포트 클립 이름**: 직접 GLB로 읽은 `move_loop`와 달리 Godot 씬 임포터는 `_loop` 접미사를 소비해 `move`로 저장했다. 실제 임포트 이름과 직접 로딩 이름을 모두 해석한다.
2. **상수 트랙과 접지 누적**: 임포터가 상수 트랙을 제거할 수 있으므로, 이전 프레임의 접지 변형을 다음 애니메이션의 초기 자세로 남기지 않도록 순수 애니메이션 자세를 복원한다.
3. **지지발 과신전**: 빠른 이동/회전에서 일부 삼족·방사형 발이 오래 고정되어 최대 약 0.33m의 목표 오차가 났다. 무릎 압축 여유·실제 도달 한계에서 발 떼기·정지 중 재디딤으로 수정했다.
4. **긴 머리의 입 위치**: glTF의 bone-parent empty 변환을 그대로 신뢰하지 않고, 움직이는 골격과 rest 바인딩으로 실제 입 소켓을 계산한다. 모델 LOD와 함께 입 소켓도 전환한다.

## 실제 확인과 한계

Godot 4.7.2 / Metal Forward+ / Apple M2에서 임포트된 원정 배우를 직접 실행했다. 평균 약 8도 경사와 국소 굴곡, 걷기→2.5배 이동→감속→선회→일시정지→far LOD→1.35배 크기/색 변이·섭식을 렌더했다. 2.5배는 재생 확인용 입력이며 게임 밸런스가 아니다.

8종 모두 실제 뼈 자세가 움직이고, 권위 위치 오차는 0이었다. 일시정지 동안 관절/시각 위치가 유지됐다. 검사한 지지발 목표 오차는 최대 0.012436m였으며, 이는 검토 코스의 IK 도달 오차다. 모든 지형·발 미끄러짐·지하·절벽의 완전한 품질 보증 수치가 아니다. 무족형의 0은 다리 IK 대상이 없기 때문이며 꼬리 접지 오차를 뜻하지 않는다.

최종 원정 매니페스트의 6종은 실제 호스트 공격형이 none임을 확인하고, 선로딩 PackedScene 전달·지연 far 설치·입 소켓·사건 opt-out·돌진/도약 원본 유지 경로를 최소 실행으로 확인했다. 원본 카탈로그 네 해시와 사용한 GLB 해시도 보존됐다.
