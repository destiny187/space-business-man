# 테라포밍 전·중·후의 지표 재질

2026-09-11 사용자 승인: 자연스러운 바닥 재질을 늘리고 테라포밍 전·진행 중·복원 후를 지면에서 느끼도록 한다. 성능 우선, 기존 INK v1, 실제 호스트 환경에 따른 변화와 기존 저장 보존을 유지한다. 아래 재질 수·표현 단계·수치는 이번 구현 선택이다.

| 단계 | 범위 | 상태 |

| T02 | 수분/토양/염분/생태 기반 지면 변화·복원 경계·실제 전후 확인 | 구현·최소 확인 완료 |

## 제작과 적용 범위

기존 17종에 건조 균열토 `desiccated_clay`, 돌 섞인 흙 `stony_loam`, 각진 붕적 파편 `talus_fragments`, 둥근 퇴적 자갈 `alluvial_pebbles`, 풍식 지각 `wind_scoured`, 화산재 퇴적 `ash_drift`, 개량 부식토 `humus_crumb`, 선구 생물 피복 `pioneer_mat`를 추가해 **25종**으로 확장한다. 앞의 6종은 계열별 퇴적 재질 후보로, 뒤의 2종은 복원 진행용으로 사용한다. 생물 피복은 환경 상태의 시각 표현이며 스캔·표본 대상인 새로운 기본종을 추가한 것이 아니다.

Blender 생성기 `tools/build_terraform_surfaces.py`, 편집 가능한 `art/blender/surface-materials/terraform-surfaces.blend`와 매니페스트를 보존한다. 1024² 선형 RGBA에 법선 XY·높이·거칠기를 저장하며 광원 그림자를 굽지 않는다. 기존 지질 제작 경로와 공통 INK 재질을 따른다.

행성 시드의 독립 퇴적 재질 선택을 사용하며 지형 높이·동굴·광맥·시설·저장 좌표는 변경하지 않는다. 모든 재질을 한 행성에 동시에 로드하지 않는다. 자연 지면 배열은 기존 최대 6장 범위를 유지한다. 개발 현장의 복원 배열은 별도로 공유하는 512² 두 장이다. RGBA8와 밉맵 기준 추가 약 2.67 MiB, 자연 지면 6장까지 포함한 배열 최대 약 34.7 MiB다. 전체 게임 VRAM 측정값은 아니다.

작업 자료·로그·비교 기준은 `output/terraform-surfaces-20260911/`에 둔다. 전후 화면에 사용한 준비 데이터와 실제 진행 확인을 구분해서 기록한다.

T01 (`6b038717`): Blender 5.2.1 Cycles와 Godot 4.7.2 Metal Forward+의 [동일 회색 INK 비교](media/terraform-surfaces/godot-soils.png), [Blender 원본 렌더](media/terraform-surfaces/blender-soils.png)를 확인했다. 균일한 원형 자갈·고리형 군락을 비대칭 자갈과 불규칙 피복으로 수정했다. 12개 계열의 시드별 퇴적 재질 선택 재현성과 지역 없는 기본 배열 3~4장 재사용을 확인했다.

## 실제 환경에 따른 변화

`terraform_surface_material.gd`가 저장된 자유 복원 현장의 초기 수분·토양·염분·생태를 기준으로 진행 정도를 전달한다. 단순히 현장 셀이 생겼다는 이유로 개량토나 생물 피복이 생기지 않는다. 이전 방식의 현장은 원래 행성 수분과 생태 0을 기준으로 하며, 원본 토양 기록이 없으므로 토양 개선량을 임의로 추정하지 않는다.

- 수분 증가·염분 감소에 따라 젖은 퇴적층이 드러나고, 토양 개량이 진행되면 부식토의 요철과 색이 나타난다.
- 실제 생태와 온도·대기·오염·토양·염분의 생존 조건, 수분이 함께 충족되면 선구 피복이 넓어진다. 기존 지표 식생과 수면 표현도 같은 현장 상태를 받아 나타난다. 새로운 기본종이나 식생 모델을 추가한 것은 아니다.
- 암반·지질 구역은 남기고 퇴적층에 복원 재질을 적용한다. 기존의 넓은 지질 분포를 재사용해 복원 텍스처 좌표를 휘어 반복 무늬를 줄인다.
- 자유 복원 아틀라스의 환경값과 점유 마스크를 함께 선형 보간한다. 빈 픽셀의 0 값은 점유율로 정규화해 가장자리의 가짜 저온·저수분을 방지한다. 표시 경계는 12 m 셀의 가장자리에서 최대 반 셀만큼 부드러워지는 근사이며, 생산·채집·저장·네트워크의 셀 판정은 변경하지 않는다.
- 기존 온도 기반 용암 냉각과 눈·얼음의 해빙을 유지한다. 전역 시간이나 임의 진행 연출로 복원 상태를 앞당기지 않는다.

복원 피복은 기존 퇴적층 샘플을 대체한다. 암반·퇴적층·눈·얼음에 복원 재질을 추가로 겹쳐 읽지 않는다. 환경 아틀라스도 기존 최대 3회 읽기를 유지한다. 생태가 자라면서 기존 식생이 증가하는 비용은 그대로 존재한다.

## 확인한 화면과 실행 범위

`render_terraform_progression.gd`에서 격리된 T2 산화 행성의 실제 `CrewSurfaceScene`을 사용했다. 일정한 조명·기후, 시설 두 개와 재고는 검수용으로 준비했고 단계 진행은 실제 `FreeTerraform.local_machine`의 급수·토양 개량·생태 처리 및 재료 소비로 수행했다. 일반 플레이의 건설·전력·운송·진행 시간을 재현한 검사는 아니다.

| 화면 | 수분 | 토양 | 염분 | 생태 |
| --- | ---: | ---: | ---: | ---: |
| [복원 전](media/terraform-surfaces/progression/0-barren.png) | 0.0 | 10.0 | 65.0 | 0.0 |
| [급수·제염](media/terraform-surfaces/progression/1-hydrated.png) | 36.6 | 10.0 | 0.0 | 0.0 |

위 실행에서 12개 관련 확인이 통과했다. 실제 재고 감소와 환경 증가, 근거리·원경 지형 준비, 배열 크기, 현장 JSON 왕복 후 초기 조건과 GPU 환경 입력 재현을 확인했다. 준비 현장 전체는 일반 게임 저장 검증 대상이 아니며 사용자 저장은 수정하지 않았다. 실제 저장 종료·재접속·협동 검사는 이번 범위에 포함하지 않았다.

`render_terraform_climates.gd`는 재질 검수 평면에 준비한 상태를 적용했다. [용암 전](media/terraform-surfaces/climates/volcanic-0.png) → [냉각 중](media/terraform-surfaces/climates/volcanic-1.png) → [냉각·정착](media/terraform-surfaces/climates/volcanic-2.png), [빙결 전](media/terraform-surfaces/climates/frozen-0.png) → [해빙 중](media/terraform-surfaces/climates/frozen-1.png) → [해빙·정착](media/terraform-surfaces/climates/frozen-2.png)을 실제 Forward+로 확인했다. 뜨겁거나 생태가 없는 중간 단계에서 생물 피복을 조기 생성하지 않았다. 이 비교는 행성 전체를 테라포밍한 플레이 기록이 아니다.

Apple M2, 보통, 1280×800, 수직 동기화·FPS 제한 해제 상태에서 최종 지상 장면의 지형·식생을 고정하고 복원 재질만 꺼짐→켜짐→켜짐→꺼짐으로 비교했다. 각 20프레임 준비 후 120프레임 측정에서 드로우콜은 모두 1,121회였다. 두 구간 중앙값 평균은 꺼짐 25.60 ms, 켜짐 25.70 ms로 약 0.09 ms 차이였다. 짧은 측정의 변동 범위를 고려해야 하며 성능 개선율이나 전체 플레이 FPS 보장으로 해석하지 않는다. GPU 시간은 이 환경에서 제공되지 않았다. [실행·측정 원자료](media/terraform-surfaces/progression/report.json)를 보존한다.

신규 사운드는 만들지 않았다. 기존 지표 장면과 식생·수면 연결을 확인했으며 별도 청취, 25종 전체 지상 플레이, 장시간·다중 클라이언트 검사는 수행하지 않았다.
