# 테라포밍 전·중·후의 지표 재질

2026-09-11 사용자 승인: 자연스러운 바닥 재질을 늘리고 테라포밍 전·진행 중·복원 후를 지면에서 느끼도록 한다. 성능 우선, 기존 INK v1, 실제 호스트 환경에 따른 변화와 기존 저장 보존을 유지한다. 아래 재질 수·표현 단계·수치는 이번 구현 선택이다.

| 단계 | 범위 | 상태 |
| --- | --- | --- |
| T01 | 자연 지면 6종·복원 재질 2종 제작, 행성별 퇴적 재질 선택 | 제작·최소 확인 완료 |
| T02 | 수분/토양/염분/생태 기반 지면 변화·복원 경계·실제 전후 확인 | 개발 중 |

## 제작과 적용 범위

기존 17종에 건조 균열토 `desiccated_clay`, 돌 섞인 흙 `stony_loam`, 각진 붕적 파편 `talus_fragments`, 둥근 퇴적 자갈 `alluvial_pebbles`, 풍식 지각 `wind_scoured`, 화산재 퇴적 `ash_drift`, 개량 부식토 `humus_crumb`, 선구 생물 피복 `pioneer_mat`를 추가해 **25종**으로 확장한다. 앞의 6종은 계열별 퇴적 재질 후보로, 뒤의 2종은 복원 진행용으로 사용한다. 생물 피복은 환경 상태의 시각 표현이며 스캔·표본 대상인 새로운 기본종을 추가한 것이 아니다.

Blender 생성기 `tools/build_terraform_surfaces.py`, 편집 가능한 `art/blender/surface-materials/terraform-surfaces.blend`와 매니페스트를 보존한다. 1024² 선형 RGBA에 법선 XY·높이·거칠기를 저장하며 광원 그림자를 굽지 않는다. 기존 지질 제작 경로와 공통 INK 재질을 따른다.

행성 시드의 독립 퇴적 재질 선택을 사용하며 지형 높이·동굴·광맥·시설·저장 좌표는 변경하지 않는다. 모든 재질을 한 행성에 동시에 로드하지 않는다. 자연 지면 배열은 기존 최대 6장 범위를 유지한다. 복원 재질의 실제 연결과 추가 상주량은 T02 확인 뒤 기록한다.

작업 자료·로그·비교 기준은 `output/terraform-surfaces-20260911/`에 둔다. 전후 화면에 사용한 준비 데이터와 실제 진행 확인을 구분해서 기록한다.

T01: Blender 5.2.1 Cycles와 Godot 4.7.2 Metal Forward+의 [동일 회색 INK 비교](media/terraform-surfaces/godot-soils.png), [Blender 원본 렌더](media/terraform-surfaces/blender-soils.png)를 확인했다. 균일한 원형 자갈·고리형 군락을 비대칭 자갈과 불규칙 피복으로 수정했다. 12개 계열의 시드별 퇴적 재질 선택 재현성과 지역 없는 기본 배열 3~4장 재사용을 확인했다. 테라포밍 연결과 실제 지상 전후는 T02 범위다.
