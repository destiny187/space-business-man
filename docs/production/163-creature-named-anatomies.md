# 생물체 리모델링 — 이름 있는 체형과 전수 제작

2026-09-13. [전체 범위](155-creature-remodel-rollout.md), [대량 체형 제작](162-creature-anatomy-production.md)의 후속이다. 사용자 요청은 동물 5,600종 전체 교체이며, 이 기록을 전체 완료로 해석하지 않는다.

## 이번 연결

R04의 26개 체형 대표와 코끝 기관형 추가 6종, 총 32종을 새 Blender 원본·근거리/원거리 GLB로 제작했다. 기존 261종에 더해 현재 표시 연결은 293종이다. 원본 카탈로그의 종 ID·원산지·저장 해시와 전투 거리·속도·피해량은 변경하지 않았다.

체형별 척추·목·턱·다리와 발굽·접착 발가락·집게·독침·코끝 구강을 분리했다. 코끝 공격 기관은 세 관절 목과 별도 구강 관절로 연결하며, 실제 스킨의 소켓을 따라간다. 갑각·긴 목·두 발 도약·낮은 포복·사행 구조를 같은 골격의 크기 변경으로 처리하지 않는다. R04 첫 32종은 정규화한 형상 32개와 이름을 제외한 관절 부모 구조 15개다.

## 확인과 수정

- Blender EEVEE 원본 렌더와 Godot Forward+ INK v1에서 32종의 걷기·빠른 이동·감속·선회·섭식·공격 준비/타격/회복·무력화·원거리 LOD를 확인했다. 각 종은 실제 이동 240단계와 9개 정지 캡처를 남겼다. 체형별 대표 화면과 빠른 이동/공격 판을 검토했다.
- 호스트 전투 8종의 명중·빗나감·엄폐 24사례를 확인했다. 실제 피해 이벤트와 타격 효과의 개수가 같으며, 다른 개체의 상태와 공격 수치가 보존된다. 두 번 베기는 기존 호스트의 두 타격 시점에 원본 애니메이션의 두 고점을 맞춘다.
- 돌진 차단 뒤 반동에서 긴 다리가 닿지 않는 문제를 수정했다. 다리를 늘이지 않고 해당 개체의 스킨 골격을 국소적으로 낮추어 접지를 회복한다. 수정한 돌진 3종의 9사례 모두 발 목표 오차 4.6mm 이하로 확인했다.
- 먼저 실패한 검사의 개체가 뒤 캡처에 남던 검수 장면 문제를 수정했다. 해당 32종의 화면을 깨끗한 장면에서 다시 생성했다. 다른 종의 검사 결과를 현재 종의 완료 기록으로 쓰지 않도록 ID 일치도 확인한다.
- R03의 짧고 넓은 리본형은 다리 두 마디의 최대 도달 거리뿐 아니라 최소 도달 거리도 사용해 발을 다시 디디도록 수정했다. 해당 3종 재검사에서 최대 2.1mm, R03 먼저 연결한 196종 전체에서 최대 10.1mm였다.

원본/가중치/애니메이션 반복 경계와 실제 렌더 증거는 `media/creature-remodel/r04/evidence.json`, 호스트 결과는 `host-evidence.json`에 둔다. 최초 호스트 로그의 돌진 실패 6건은 후속 돌진 검사로 대체하며, 최초 통과한 나머지 15건과 수정 후 9건을 구분해 보존한다.

## 진행 중인 범위

R03 4,333종과 R04 178종의 미완성분은 종별 체크포인트를 사용해 계속 제작 중이다. 완료된 R03 자산은 별도 게임 렌더 과정이 이어서 읽는다. 제작 완료, 실제 렌더 검사, 표시 연결을 구분하며 미완성 자산을 자동으로 연결하지 않는다.

R05 대기 부유형·조류형은 별도 제작 중이다. 날개의 좌우 대칭 접이/날갯짓과 종별 주기를 다듬고 있다. 반복 원본은 닫힌 세 번의 날갯짓을 사용하고, 기존 종의 주파수에 맞춰 재생 시간을 조정한다. 비행 경로·속도 설정을 수정하지 않는다. 아직 이 묶음 전체를 연결하거나 완료로 기록하지 않는다.

이 단계의 확대 검사는 개별 배우를 사용하는 제작 장면이다. 전체 자산의 최종 Godot 재임포트, 새 원정의 조우와 생물 사건 연결, 나머지 기존 640종 교체는 남아 있다. 새 음원을 생성하지 않았다.
