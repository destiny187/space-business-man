# 일반 토착 생물 — T1~T5 전투 강화

2026-09-12 사용자 승인: 같은 유형의 생물도 고티어에서 체력·공격력이 높고 유형에 맞는 속도/범위 차이를 갖게 한다. [전투 소관](../game/27-ground-and-flight-combat.md)과 [공격별 대응 구현](138-native-ground-attack-patterns.md)을 잇는다. 아래 수치는 조정 가능한 초기 밸런스다.

## 현재 적용

일반 토착 지상 동물은 **현재 서식 행성의 `planet_tier`**를 사용한다. 자연 배치 후보에 파생 `combat_tier`를 붙여 호스트 AI·총기 표적·체력 HUD·생물 동작/지면 표시가 같은 `FrontierWildlifeCombat.profile()`을 사용한다. 서로 다른 행성에서 같은 유형이 등장해도 각 행성의 티어로 계산하며 원산 종·외형 ID·배치 좌표·출현 확률을 바꾸지 않는다.

수치 원본은 [wildlife_combat.json](../../우주-비즈니스/data/wildlife_combat.json)의 `tier_scaling`이다. T1의 기존 전투 수치를 유지하고 체력은 최종 정수 반올림, 피해는 소수 계산을 유지한다.

| 행성 티어 | 체력 배율 | 피해 배율 |
| --- | ---: | ---: |
| T1 | 1.00 | 1.00 |
| T2 | 1.35 | 1.12 |
| T3 | 1.80 | 1.28 |
| T4 | 2.40 | 1.48 |
| T5 | 3.20 | 1.72 |

| 유형 | T1 → T5의 특성 강화 |
| --- | --- |
| 돌진 | 돌진 속도 12 → 17.4m/s, 최대 거리 9 → 12.06m. 추격 속도 20% 증가. 실제 이동 시간은 거리/속도로 계산해 예고한 거리와 일치시킨다. |
| 도약 | 최대 거리 6 → 8.4m, 착지 반경 1.45 → 1.8125m, 도약 시간 0.70 → 0.658초. 추격 속도 28% 증가. 높이와 최초 착지 목표 고정은 유지한다. |
| 지면 내려치기 | 반경 4.2 → 5.88m, 추격 속도 8% 증가. 경고 원과 실제 피해 반경에 같은 값을 사용한다. |
| 두 번 베기 | 근접 사거리 20%, 추격 속도 22% 증가. 두 타격 간격 0.65 → 0.52초. 각각 한 번만 피해를 주는 판정은 유지한다. |
| 일반 근접 | 근접 사거리 12%, 추격 속도 26% 증가. 공격 후 회복 시간은 12% 짧아진다. |
| 도주형 지상 동물 | 체력 배율과 도주/복귀 속도 최대 15% 증가만 적용한다. 공격을 새로 부여하지 않는다. |

모든 티어에서 경고·공격 준비 시간, 몸의 크기·충돌 부피, 선공/영역/반격/도주 성향을 유지한다. 돌진 접촉 폭과 도약 높이를 무조건 늘리지 않는다. 엄폐·옆 이동·점프·착지 범위 이탈·반격 창과 착륙선 보호 영역은 기존 판정을 사용한다. 삭제 요청한 회피 요령·반격 기회 HUD 문구를 다시 표시하지 않는다.

## 기존 저장과 협동 경계

- 기존 은하에도 파생 전투 배율을 적용하되 은하/종/지형/배치 기록을 다시 생성하지 않는다.
- 이미 `crew.combat`에 저장된 **남은 체력은 숫자 그대로 보존**한다. 새로운 최대 체력으로 회복하거나 비율 환산하지 않는다. 아직 피해 기록이 없는 개체는 새 최대 체력에서 시작한다. 예전에 다친 고티어 개체는 새 개체보다 체력이 낮게 남을 수 있다.
- 체력 0과 `wildlife_stops`의 무력화 위치를 유지한다. 재시작 때 미완료 공격을 취소하는 기존 규칙도 유지한다.
- 활성 `wildlife_encounters.combat_tier`는 선택 필드로 1~5 정수를 검증한다. 필드가 없는 이전 저장도 읽으며 다음 호스트 갱신에 해당 행성의 티어를 기록한다. 호스트가 생성한 배치 후보를 기준으로 계산하고 클라이언트 발사 요청에서 티어를 받지 않는다.
- 현재 최고 기본 체력은 512다. 기존 공용 체력 검증 상한은 데이터에서 300 → 600으로 늘려 고티어 피해 기록을 저장할 수 있게 했다. 상한 600을 모든 개체의 체력으로 적용하지 않는다.
- 플레이어가 운송해 이식한 표본, 별도 생물 사건 개체, 수중/비행 생물은 이번 강화 대상이 아니다. 소형선으로 다른 행성에 출동한 참가자의 대상도 해당 행성 후보로 계산한다.

## 실제 확인

`check_wildlife_tiers.gd`의 제한된 확인만 실행했다. 첫 연결에서 행성 키를 `tier`로 잘못 사용한 것을 `planet_tier`로 수정했고, 범위 타격 시험 시각을 부동소수 경계 바로 뒤로 옮겼다. 아래는 수정 후 결과다.

- 헤드리스 16개 확인, 실패 0: T1~T5 기본 강도·성향/몸집/준비 시간 보존, 행성 티어 전달, 이식 제외, 실제 지면 돌진 속도/거리, T1 범위 밖에서 T5 내려치기 43 피해, 더 빠른 두 번째 베기, 고정 도약 거리 확대, 300 초과 체력 저장/읽기, 기존 남은 체력·무력화 보존.
- Godot 4.7.2 / Metal Forward+ / Apple M2 실제 원정 14개 확인, 실패 0: 시드 71503의 **자연 T4 행성 311384 / `biota_saddle_sails_26`**을 찾아 착륙했다. 체력 360, 피해 35.52, 돌진 속도 15.6m/s, 거리 11.07m가 호스트·모델·예고선·HUD에서 일치했다. 실제 돌진 피격, 총격 후 체력 333, 저장/재읽기를 확인했다.
- 기존 Blender 모델·리깅·INK 렌더와 ElevenLabs 경고/타격 음원을 재사용했다. 실제 게임의 음원 호출을 확인했으며 새 모델·리깅·음원을 제작하거나 청감/음량을 새로 검수한 것은 아니다.


규칙 비교의 T1/T5는 같은 유형에 티어를 부여한 격리 조건이며 실제 자연 T5 전투를 완주한 것이 아니다. 저장/프로필은 `/tmp/native-tier-play`에 격리했다. 실제 창 확인은 T4 돌진형이며 다른 전투 유형은 판정 수준에서 확인했다. 전 유형·전 티어의 실제 원정 완주, 6클라이언트 실접속, 장시간 난도·성장/장비 밸런스 조정은 후속이다. 별도 전투 사건·전리품 강화·보스 규칙은 추가하지 않았다.
