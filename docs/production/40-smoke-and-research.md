# 착륙 연기·즉시 채광·독립 연구 화면

2026-09-07 사용자 요청 반영. 개발권 연구/등록을 첫 채광의 선행 조건으로 두지 않는다.

- **착륙 연기:** 배경과 선체 앞 구름이 공유하는 `arrival_smoke.gdshaderinc`에 부드러운 기울기 노이즈, 회전한 5개 옥타브, 흐름 좌표 변형을 적용했다. 격자 값 보간의 네모 무늬를 없애고 연기가 선체 앞을 지나가도록 유지한다. 전경은 최대 65% 투명도 혼합 상한을 유지하며, 지표 로딩 중 배경의 완전 차폐도 유지한다.
- **즉시 채광:** 착륙 시 무료 탐사 현장(`exploration`)을 만들고 광맥 잔량을 보존한다. 기존 미등록 저장도 첫 채광 요청에서 초기화한다. 채광·회수 화물·기술 구매는 복원 계약과 분리한다. 다른 행성에 활성 계약이 있어도 채광과 기술 구매가 가능하다. 별도 등록 버튼을 제거했고 시설·창고 운영의 첫 성공 요청에서 복원 사업으로 전환한다. 활성 복원 사업 1개와 기존 정산 자산 인계 규칙은 유지한다. 장비 등급·거리·시야·배낭·고온 광맥 제한은 그대로다.
- **연구 화면:** J 또는 착륙선의 연구 버튼으로 독립 `research_panel.gd`를 연다. 기술 설계도는 모델 카드, 연구 상태, 선택한 실제 INK 3D 모델, 선행 기술 연결, 설명과 비용으로 구성했다. 생태 조사·분석 탭은 기존 조사 도감/생물 미리보기와 분석·시험·표본 이식 작업을 연결한다. 외부에서는 열람하고 연구실 범위에서는 실행한다. 공동 기술 구매의 호스트 권한과 크레딧/선행 기술 검증은 서버에서 유지한다. 제작소의 생물공학 시제품·시설 개조는 해당 설비에서 실행하는 규칙을 유지한다.

## 확인

Godot 4.7.2 Metal Forward+ 실제 창에서 전경 연기의 서로 다른 3개 시점과 선체 가림을 확인했다(`render_arrival_foreground.gd`). `check_direct_mining.gd`로 미등록 채광, 활성 계약 분리, 탐사 상태 저장 검증, 직렬화된 광맥 고갈량, 계약과 독립된 기술 구매를 확인했다. 별도 세계의 `check_research_arrival.gd`로 실제 착륙, 1280×800/960×640 연구 화면, 기술 카드 구매, 채광과 저장 후 자원·잔량 보존을 확인했다. 작은 화면에서도 구매 버튼은 상세 스크롤 바깥에 고정한다.

기존 Blender 모델·생태 아이콘·사운드 경로를 재사용했다. 기술 카드 6개는 실제 INK 게임 렌더로 어두운 공통 배경에 다시 캡처했다(`tools/render/research_icons.gd`, `assets/ui/research/`). 전체 회귀·다중 클라이언트·전체 생태 실험의 재검증은 수행하지 않는다. 캡처는 로컬 `test-results/research-arrival/`, `test-results/arrival-foreground/`에 둔다.
