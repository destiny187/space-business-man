# 태양계 보호와 행성 주시 스캔

2026-09-07 사용자 확정: 태양계 8행성은 착륙·테라포밍 불가다. 우주 화면의 숫자 입력칸을 제거하고 천체를 바라보면 중앙 게이지가 차며 완료 후 이름과 최소 설명을 홀로그램 형태로 표시한다.

## 실제 적용

- 태양계는 호스트 착륙 요청과 신규 개발 등록에서 거절한다. 기존 지상 저장의 신규 건설/현장 연구와 환경 변화도 제한한다. 태양계의 공전·모델 크기는 변경하지 않는다. 과거 광맥 주소·지질은 저장 검증을 위해 보존하고 기존 저장·시설을 삭제하지 않는다. 기존 태양계 사업 장부를 다른 행성으로 이전하는 기능은 포함하지 않는다.
- 원정 화면의 행성 주소 입력 위젯을 제거했다. 새 원정은 외부 우주 시점과 닫힌 항법도로 시작한다. 외부 시점에는 상단 제목·일반 상태·하단 메뉴 버튼을 숨긴다. Tab 항법도·F10 설정은 유지한다. 별도 대기실의 세계 시드 안내는 우주 HUD와 구분한다.
- 기존 천체의 상시 3D 이름표를 숨긴다. 화면 중앙 광선과 가장 가까운 행성을 선택하고 같은 대상을 기본 1.8초 주시하면 분석이 완료된다. 시간은 은하 비행 설정의 `scan_seconds`에서 관리한다. 시선을 벗어나면 미완료 진행을 초기화하고 메뉴·성간 순항에서는 표시를 중단한다.
- 완료 카드는 연결선·반투명 청록 테두리·옅은 주사선으로 표현한다. 이름·유형·티어·테라포밍 가능 여부를 최소 정보로 표시하고 태양계에는 보호 안내를 우선한다. E로 선택 행성 접근 항해, Tab으로 항법도를 연다.
- 스캔은 공개 천체 기본 정보를 보여 주는 로컬 관측 연출이다. 보상·자원 발견·호스트 연구 완료를 발생시키지 않는다. 완료 캐시는 현재 비행 뷰 세션에만 유지하며 저장 도감과 혼동하지 않는다. 완료음은 기존 ElevenLabs `ui_discovery`를 재사용한다.

## 확인

태양계 8행성 제한·실제 호스트의 지구 착륙 거절·새 세계 유효성·주시 진행·완료·메뉴에서 숨김을 최소 실행으로 확인했다(16개 확인, 실패 0). Godot Metal Forward+의 [진행 화면](media/planet-gaze/scanning.png), [완료 홀로그램](media/planet-gaze/solar-hologram.png)을 렌더링하고 검수했다. 새 3D 모델이나 새 음원은 제작하지 않았다. 기존 태양계 사업의 이전·전체 회귀·다중 접속 실기는 검사하지 않았다.
