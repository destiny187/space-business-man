2026-09-11. 사용자 승인: 총기마다 특색을 넣고 지상전을 먼저 고도화한다. 슬라이딩은 제외한다. 생물체의 본격적인 전투 행동과 추가 전투 사건은 다음 단계다. 목표 설계는 [전투 소관](../game/27-ground-and-flight-combat.md), 실제 첫 범위는 이 문서를 따른다.

## 연결한 범위

- 권총·카빈·기관단총·산탄총·경기관총·지정사수총·저격총·플라스마의 8계열, T1~T3 유효 조합 15개. 기존 `pulse_1`/`pulse_2`와 소유·번호 슬롯을 보존한다. 계열마다 Blender 외형을 구분하고 같은 계열의 티어는 같은 기본형을 사용한다. 15개를 별도 기본형 15종으로 세지 않는다.
- 좌클릭 발사, 우클릭 정조준, 총기 장착 중 R 재장전, Ctrl 낮은 자세. 총기가 아닌 장비의 R 로봇 지시는 유지한다. 기존 달리기·점프와 연결하며 슬라이딩·자동 턱 넘기는 추가하지 않았다.
- 탄창·발사 간격·재장전·피격 결과는 호스트가 판정한다. 몸을 낮추면 눈높이·충돌체·이동 속도·기존 Blender 리그 다리 자세를 함께 바꾼다. 머리 위 공간이 없으면 일어서기를 거절한다.
- 발사 반동·가동부, 탄창 이동·재장전 진행, 실드/약점/격파 명중 표식, 저격 조준 화면을 연결한다. 명중 성공 연출은 호스트 결과를 받은 뒤 표시한다.

| 펄스 카빈 | 연사할수록 탄 퍼짐이 안정화 |

수치·희귀도 배율·드롭 확률은 `data/firearms.json`과 `data/equipment.json`의 초기 밸런스다. 현재 재장전은 무한 예비탄에서 탄창을 채운다. 별도 탄약 자원 생산·탄종·관통·느린 물리 폭발탄·전설 전용 추가 효과는 아직 없다. 플라스마는 즉시 착탄 판정과 폭발 연출이다.

## 제작·드롭과 소유

개인 휴대 제작에서 계열/티어를 고르고 실제 재료를 소비한다. T2 가공품과 T3 전문 제품을 쓰며 기본 제작품은 일반 품질이다. 기존 사건의 고정 보상을 유지하면서 회수 가능한 사건 화물에 확률적으로 총기를 추가한다. 일반·개량·희귀·유니크·전설 품질은 이번 첫 범위에서 피해·재장전 배율을 바꾼다.

동일 세계·행성·사건의 결과를 시드로 고정하며, 공개된 화물 위에 총기 모델과 희귀도 표식/이름을 표시한다. F로 기존 화물을 회수할 때 총기도 인수한다. 배낭이 부족하면 전체 거래를 거절해 현장 화물을 보존한다. 자동 장착하지 않는다. 소유 창고에 넣고 꺼낼 때 개체 품질·탄창 상태를 함께 보존한다.

독립 무기 상자·적 종류별 전용 드롭 풀·획득 전 양쪽 무기 비교창·분해·복원/정밀 제작은 후속이다. 현재 UI는 소지 총기의 모델·티어·희귀도·기본 수치와 고유 작동을 보여준다.

## 생산하는 엄폐물

| 시설 | 제작·배치 | 실제 보호 |
| --- | --- | --- |
| 낮은 방벽 | 배낭의 철·돌로 B 건설 | 1.35m 판넬. 낮은 자세로 숨고 일어서서 위로 사격 |
| 장갑 엄폐벽 | Mk.2 제작소에서 키트 생산→창고에서 인수→B 건설 | 1.95m 전면. 양옆으로 나와 사격 |

기존 건설의 재료·지지 지형·거리·통로·시설 수·사업 규칙을 사용한다. 고스트는 바라보는 방향을 따른다. 조립이 끝나면 실제 판넬과 받침의 충돌체가 활성화된다. 적 로봇 탄을 막으며 내구도가 소진되면 모델이 무너지고 충돌/보호가 해제된다. F 시설 메뉴에서 재료를 써 수리한다. 파손 잔해는 이동·총탄을 막지 않는 상호작용 전용 영역으로 계속 선택할 수 있다. 철거 환급은 남은 내구도 비율로 줄여 손상된 키트의 무료 복원을 막는다. 기존 산업 시설의 내구도/환급 규칙은 바꾸지 않는다.

이번 장갑형에는 사격구가 없다. 벙커·실드 방벽·날씨 보호·적의 우회 AI·단계별 판넬 탈락은 후속이다.

## 저장·통신

장비 정의를 기존 슬롯에 연결하고 총기 개체의 `weapon_states`/`weapon_rolls`는 선택 필드로 저장한다. 구 저장의 미사용 총기는 처음 사용할 때 탄창을 초기화한다. 선박/현장 보관 시 총기 메타데이터를 보관품에 옮긴다.

기존 신뢰성 요청 통로에서 발사·재장전·자세를 처리하며 요청 순번·동일 장비·지상 위치·조작 활성·발사 간격을 확인한다. 구 공격 요청으로 탄창을 우회할 수 없게 한다. 각 탄환마다 전체 세계를 복제/저장하지 않고 기존 상태 송신과 최대 약 2초 간격의 전투 저장을 사용한다. 강제 종료 직전의 마지막 짧은 구간은 되돌아갈 수 있다. 정상 저장/종료에는 현재 상태를 보존한다.

## 2026-09-12 — 중단된 전용 음원 적용 재개

사용자의 중단 작업 재개 요청에 따라 카빈 생성본의 다운로드를 마치고 나머지 전투 음원을 ElevenLabs 웹에서 생성했다. 발사 8계열·재장전·장갑 명중·실드 파괴의 원본 11개를 `audio/source/elevenlabs/ground-combat/`에 보존한다. 계열별 발사음이 별도 파일을 사용하며, 기존 공용 코일·초기 가공본의 생성 출처는 지우지 않았다.

원본은 WAV 48kHz stereo PCM16, 게임 파일은 mono PCM16이다. 단발음 앞뒤 무음과 가장자리를 정리하고 -19dBFS RMS 목표·-5dBFS 피크 상한으로 조정했다. 짧은 클릭형 소리는 피크 상한을 우선하므로 평균 음량이 목표보다 낮을 수 있다. 각 생성의 첫 후보를 잠정 적용했으며, 귀로 비교해 최종 후보를 골랐다는 뜻은 아니다.

- 프롬프트·생성 날짜·다운로드 파일명·설정: [원본 목록](../../audio/manifests/ground-combat-sources.json).
- 편집·길이·해시·음량: [적용 이력](../../audio/manifests/ground-combat.json). `python3 tools/prepare_firearm_audio.py`로 보존된 원본에서 재생성한다. 원본이 빠졌으면 게임 파일 변경 전에 중단한다.
- 파일 11개의 무음 여부·클리핑·가장자리·신호 시작 확인: [신호 측정](../../audio/manifests/ground-combat-signal-check.json). 이는 청감 평가를 대신하지 않는다.
- 재장전은 호스트가 확정한 시간에 맞춰 효과음 재생 속도를 조절한다. 메뉴·승선 등으로 지상 조작이 꺼지면 남은 총기/실드 파괴음을 멈춘다. 기존 환경·채집 음향은 각자의 제어를 유지한다.

실제 Godot Forward+ 창에서 8계열 사격, 권총/경기관총의 재장전 길이, 메뉴 중 전투음 정지, 명중·실드 파괴 재생, SFX 버스 녹음과 저장의 20개 확인을 통과했다. 전체 회귀는 실행하지 않았다. [실행 로그](../../audio/review/ground-combat/game-check.txt), [게임 화면](media/ground-combat/play-audio-review.png), [26.53초 실제 출력 WAV](../../audio/review/ground-combat/combat-runtime-mix.wav), [큐별 시간](../../audio/review/ground-combat/combat-runtime-timeline.json), [측정 결과](../../audio/review/ground-combat/verification.json)를 보존한다. 출력 피크는 -8.34dBFS, 클리핑 표본은 0개다. 소리 길이는 실제 재생 버스 녹음 기준이다.

재현 명령: `./tools/godot.sh --script res://tests/check_ground_combat.gd -- --crew-ui-test --crew-folder=/tmp/ground-combat-play --play --audio-review`. 기존 검사와 같은 임시 세계를 재생성하며 사용자 원정 저장은 사용하지 않는다.

이번 확인은 실제 지상 장면의 전투 오디오 경로를 대상으로 한다. 현재 도구의 오디오 입력 미지원으로 음색의 적합성·헤드폰 위치감·장시간 청취 피로도를 직접 청취 평가하지 못했다. 첫 후보는 잠정 선정이며 출력 녹음으로 후속 청감을 확인한다. 원격 6인 믹스도 미확인이다.

아직 전체 회귀·실제 6인 접속·장시간 밸런스·모든 시드·귀로 청취 검수는 하지 않았다. 생물체의 보복/도주/공격 예고를 포함한 본격 교전, 적 역할 확대, 신규 전투 사건, 공중전·우주전은 이 완료 범위에 포함하지 않는다.
