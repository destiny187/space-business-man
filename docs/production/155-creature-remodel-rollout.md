# 전체 동물 리모델링 — 승인과 단계별 제작

2026-09-12. 사용자는 [154의 빠른 이동과 원형 효과 제거](154-creature-motion-and-contact.md)를 승인하고 변경분 커밋 후 전체 리모델링 착수를 요청했다. 승인 기준과 조사·모델·동작·렌더는 `c53641d80`에 보존했다. 이번 요청의 중심인 **동물 5,600종 전체**를 대상으로 하며 식물 1,585종·미생물 군락 815종은 이번 동물 제작 과정에서 기존 자산을 유지한다. 전체 기본종 수는 8,000이다.

사용자는 같은 날 후속으로 창작 방향을 위임하고 현재 품질을 유지하며 자연스럽게 다양성을 확대하도록 했다. 특히 **공격 머리가 몸통에서 멀리 떨어진 구조**도 실제 기관 위치·도달·회수 동작에 맞추도록 한다. 몸통 중심에 공통 공격점을 찍는 방식으로 대체하지 않는다.

같은 날 추가 정정: 이번 제작에서 실제 게임의 공격거리·이동 속도·피해량을 확정하지 않는다. 검토 장면의 숫자는 동작과 접촉 결과를 재현하기 위한 값이다. 원거리형은 사거리 밸런스를 제작 제약으로 삼지 않고 발사 기관의 위치/방향·준비/방출/반동/회복에 집중한다. 최종 공격거리·피해·추격 속도는 전투/이동 데이터에서 정하고, 보폭·주기와 재생 속도는 그 실제 값에 연결한다. 긴 목형의 접촉 위치 확인도 게임 사거리 확정을 뜻하지 않는다.

## 확정 방향

- 승인한 여섯 대표의 형태·INK 품질·보행/빠른 이동·근접 및 원거리 동작을 품질 기준으로 사용한다.
- 전체 리깅 종류는 여섯으로 제한하지 않는다. 사지 수·방향·몸통 분절·대칭·분기·섭식/공격 기관과 추진 방식에 맞는 골격을 제작한다.
- 독특한 조형을 유지하며, 감각·섭식·지지·힘 전달이 한 몸에서 이해되도록 다듬는다. 색·전체 크기만 바꾼 복제본을 다른 기본종으로 만들지 않는다.
- 노란 타격 원은 다시 넣지 않는다. 접촉 결과와 피격·파편·실드·필요한 폭발 표현을 연결한다.
- 종 ID·원산 행성·기존 발견 이름·표본·변이·무력화와 저장을 보존한다. 제작 레시피의 구조 수를 검수 완료한 리깅 수로 세지 않는다.

## 전체 제작 목록과 진행 구분

[`queue.json`](media/creature-remodel/queue.json)에 고유 동물 ID 5,600개를 빠짐없이 넣었다. 기존 92개 구조 구분과 종별 사지 수·방사 수·배열·기관·기존 템플릿을 기록한다. 이 분류는 제작을 시작하는 색인이며, 최종 리깅 수를 미리 제한하는 배정표가 아니다. 다른 관절이나 내부 구조가 드러나면 묶음을 더 나눈다.

진행 상태는 **목록 등록 → 몸 구조 설계 → Blender 모델/골격/웨이트 → 느린/빠른 이동·공격/회복 → INK 실제 렌더 → 원정 연결 → 개별 확인**으로 구분한다. 모델 파일이 생성됐다는 이유로 원정 적용이나 전종 검수를 완료로 기록하지 않는다.

## 확인과 남은 경계

Blender 5.2.1에서 원본 3개·두 LOD GLB 6개를 제작하고, Godot 4.7.2 / Metal Forward+ / Apple M2에서 실제 렌더했다. 고리형 22본·오방사형 33본·긴 목형 18본이며 각 10클립을 포함한다. 원본·정면 형상·느린/빠른 이동·명중/실드/회피를 확인했다.

새 3종의 명중/방어/회피 9사례는 초기 피해·타수와 일치했고 원본 실행 카탈로그 4개의 해시는 그대로다. 긴 목형은 첫 실행에서 준비 구간의 넓은 접촉 시간이 회피보다 먼저 열리는 문제를 재현했다. 이 종의 실제 물기 시각에 맞춰 판정 창을 1.015~1.16초로 좁혀 수정했다. 수정 뒤 1.033초, 몸통 기준 약 3.122m 떨어진 실제 접촉점에서만 명중/실드 손실이 발생했고 회피에는 피해 0이었다. 이 수치는 검토 장면의 결과이며 원정 밸런스 확정값이 아니다.

형상 촬영은 월드·저장 모듈을 불러오지 않는 독립 렌더를 사용한다. 체형이 보여 주는 공격 기관을 실제 위치에서 구동했지만 원정의 부위별 피격 상자·경사 접지·공격 AI/호스트 판정·협동 연결은 남는다.
