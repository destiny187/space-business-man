# UX02 — 발견 도감·제작소·생태·항해 자원

2026-09-08 사용자의 ‘커밋하고 2차 진행’ 요청으로 [전체 개편 계획](../planning/13-uiux-renewal-commits.md)의 U05/U06/U10/U11을 개발했다. UX01은 `9e02c4a5`에 이미 커밋되어 있었으며 이번 변경은 그 위에 쌓았다.

## 구현한 화면

- **J 발견 도감**: 광물/보석·생물, 현재 행성/전체 발견, 이름 검색, 24개 단위 페이지 이동. 이전처럼 마지막 24개만 접근하는 제한을 없앴다. 선택 상세에 발견 행성·필요 채집기·알려진 활용 또는 실제 생물 모델·서식 조건을 표시한다. 행성을 떠나도 이미 관측한 생물을 다시 조회한다. 같은 페이지를 갱신하면 선택을 유지하며 검색 결과가 없으면 이전 선택/행동을 지운다.
- **제작소**: 7개 탭의 가로 나열을 ‘제작 / 시설 관리’와 제작 분류(부품·로봇·로버·시험기·생물공학·소형선)로 정리했다. 부품에는 이름 검색·제작 가능만 필터와 실패 이유를 제공한다. 목록과 긴 상세만 따로 스크롤하며 생산 버튼은 고정한다. 다른 제작 종류의 기존 호스트 명령과 개인/공동 재료 출처는 유지했다.
- **생태**: 선택한 생물의 관측·분석·서식지·이식을 단계로 표현하고 현재 행동을 강조한다. 이미 끝난 분석, 없는 실물 표본, 선택과 관련 없는 행동을 나열하지 않는다. 타 행성 운송 표본만 이식 후보로 표시하며 연구실 거리·기질·재료·지원 구획 조건을 반영한다. 최종 거래 판정은 기존 호스트가 수행한다.
- **생물공학**: 프로젝트 카드와 실제 생물/설비 미리보기, 분석→시제품→현장 시험→개조 단계, 진행률·현재 단계의 비용/행동을 표시한다. 다른 설비에서 해야 할 다음 작업은 그 위치를 알려준다.
- **항해/거점**: 지도 자원 4개 뒤에 `+N` 또는 전체 보기를 제공한다. 전체 창은 이름 검색·분류를 공유한다. 항해 기록은 이름 외에 조사된 광물·실제 거점 재고로 검색한다. 생산 거점은 전체 창고 열기와 실제 진행 제품/진행률/가동 상태를 표시한다.
- **없는 품목**: 전체 창고 창도 수량이 양수인 품목만 만든다. 제작 필요 재료와 발견 지식은 보유 목록과 구분한다.

## 저장·통신 경계

기존 광물 저장 `crew.survey`의 256개 초과 시 오래된 기록 삭제를 제거했다. 행성/자원 단위의 중복 방지는 유지한다. 기존 저장 형식은 그대로 읽으며 **이전 버전에서 이미 삭제된 기록은 복원하지 못한다.** 이동 스냅숏에는 최대 최근 256개만 포함하고 전체 도감은 접속된 승무원의 요청에 따라 신뢰 채널로 24개씩 반환한다. 검색·페이지 변경은 세계나 재화를 바꾸지 않는다. 조회 일련번호로 오래 도착한 화면 응답을 무시한다. 생태의 전체 관측/행성 원장을 이동·지표 패킷으로 보내지 않는다.

항해 기록에는 실제 지표 관측 자원 ID를 선택적으로 보존한다. 원격 광물 정보는 스캔 기록 또는 기존 태양계 참고 정보가 있는 천체에서만 계산한다. 단순 방문·즐겨찾기만으로 미조사 행성의 생성 자원을 검색하지 않는다. 도감은 호스트 세계의 현재 전체 기록이고, 항해 기록은 플레이어가 동기화해 확인한 기록이므로 같은 저장소는 아니다. 거점 창고 팝업은 연 시점의 조회이며 다시 열면 최신 재고를 받는다.
