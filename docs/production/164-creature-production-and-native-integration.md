# 동물 5,600종 전수 제작과 게임 표시 교체

2026-09-13. [전체 교체 범위](155-creature-remodel-rollout.md), [체형별 제작](163-creature-named-anatomies.md)의 후속이다. 동물 5,600종의 전수 제작·게임 표시 교체·캐시 설치를 완료했다. 식물·미생물 2,400종은 이번 대상에 포함하지 않는다. 아래 중간 기록의 수량·대기 상태는 각 기록 시점의 제작 경과이며, 최종 상태는 바로 다음 절을 따른다.

2026-09-13 자산 정리: 구형 동물 바이너리와 임시 임포트 사본을 제거하고 UI도 현재 모델을 사용하도록 연결했다. 아래 중간 단계의 구형 대체 경로는 폐기했으며, 삭제·보존·확인 범위는 [172 정리 기록](172-retired-animal-assets.md)을 따른다. 단계별 임포트 파일 목록은 최종 전수 대조로 통합했다.

## 전수 완료와 검수 범위

동물 **5,600종 전부**의 제작과 게임 표시 등록을 완료했다. R01 9·R02 56·R03 4,333·R04 178·R05 384·R06 640종이다. 초기 65종의 품질을 보존하고 나머지 5,535종을 제작했다. 근거리/원거리 **11,200개 GLB**가 실제 골격·애니메이션 클립 검사를 거친 게임 캐시와 일치한다. 임포트 대기나 원본만 존재하는 항목을 최종 완료 수에 합산하지 않았다.

좌표를 정규화한 형상 지문은 5,600개이며 관절 이름과 나열 순서를 제외한 부모 연결 구조는 **1,991가지**다. 사용되는 골격의 본 수는 14~201개다. 연결 구조 수는 모든 종이 완전히 다른 해부학적 분류라는 뜻이 아니며, 같은 연결 구조에서도 실제 사지 길이·축·기관·부착 위치와 모션을 구분한다. 여섯 검토 대표를 전체 골격 제한으로 사용하지 않았다.

전수 파일/동작 검사와 사람이 확대해 본 화면은 구분한다. 각 종의 두 LOD·스킨/클립·실제 Forward+ 캡처를 확인했고, 체형/기관/보행 구조의 극단을 담은 비교 화면 및 발견한 접촉 문제의 재현 영상을 검토했다. 낮은 체형의 무릎·입, 나선형의 몸통 접지와 떠 있는 중복 감각기관을 수정했다. 실제 호스트 명중/회피/엄폐, 원산 종 사건의 거대·운반·보호 표시, 기존 시드 비행 경로 연결을 해당 검토 장면에서 확인했다. 모든 종의 모든 피부 정점·모든 프레임 충돌 검사나 원정 전체 플레이를 반복한 결과로 해석하지 않는다.

종 ID·원산지·기존 저장 카탈로그의 해시와 게임 속도·공격 거리·피해량·성향을 보존했다. 이번 작업은 기존 동물의 표현 교체이며 새로운 공격 성향, 수중 교전, 가스행성 항법이나 새 음원을 추가한 것은 아니다. 생물 타격의 노란 원형 효과 제거를 유지한다. 최종 파일별 지문과 수량은 [최종 대조 기록](media/creature-remodel/integration/final-coverage.json)에 둔다.

## 초기 표시 연결 — 보존한 제작 이력

새 모델 표시 목록에 지상 938종과 비행/부유 15종, 합계 **953종**을 연결했다. 임포트가 아직 끝나지 않은 항목은 기존 모델을 표시하고, 완료된 자산부터 새 모델을 사용할 수 있다. 기존 65종에 R03 696종, R04 178종, R05 14종을 더한 수다. 제작 중인 원본 파일 수를 표시 연결 수에 합산하지 않는다. 원본 종 ID·원산지·저장 카탈로그와 게임의 이동 속도·공격 거리·피해량·공격 성향은 보존했다.

R03 696종은 정규화 형상 696개와 관절 부모 구조 322개를 확인했다. 먼저 검토한 14개 큰 구조에 이어 새로 늘어난 방사형·절지형·방추형의 기관/관절 수 극단을 빠른 이동과 타격 화면에서 검토했다.

R04는 계획한 178종 전부의 Blender 원본, 두 LOD, 실제 Forward+ INK 렌더를 완료했다. 정규화 형상 178개와 관절 부모 구조 55개다. 26개 큰 체형의 가장 복잡한 기관 사례도 검토했다. 최초 호스트 공격 24사례에 기관이 긴 돌진·도약·두 번 베기의 명중/회피/엄폐 15사례를 추가했다. 표시가 호스트 상태·공격 수치·다른 개체를 바꾸지 않으며, 실제 피해 횟수와 타격 효과 횟수가 일치했다.

R05의 첫 14종은 지표 조류 7유형과 가스 대기 부유 7유형이다. 닫힌 세 번의 날갯짓 원본을 종의 기존 주파수로 재생한다. 지표 조류는 실제 시드 비행 시계의 휴식·이륙·비행·착륙과 휴면/이식 개체의 지상 유지를 확인했다. 가스 부유형의 포즈 검수를 실제 가스행성 항법 구현으로 기록하지 않는다.

## 현지 생물 사건

일반 토착 개체뿐 아니라 원산 종을 쓰는 사건 개체도 같은 리모델링 등록을 사용한다. 사건의 저장된 종·색 변이·크기 배수·이동 경로와 호스트 수치는 유지한다. 표시 모델의 실제 경계로 해당 개체의 충돌 모양을 맞추고, 운반 물건은 현재 구강 소켓을 따른다.

둥지 보호 개체는 저장된 경고 시간·공격 시도 횟수·재사용 대기 시간을 준비/공격/회복 포즈에 연결한다. 이 표현 어댑터는 피해를 적용하거나 명중을 추측하지 않는다. 호스트가 제공하지 않는 명중 결과를 성공 타격 효과로 만들지 않는다.

실제 임포트된 모델로 거대·운반·보호 3사례를 Forward+에서 확인했다. 원본 사건 필드와 다른 개체의 관절 상태가 보존됐다. 보호 사례는 기존 저장 역할의 표현 호환 검사이며, 원래 비공격 종을 새 보호 종으로 배정했다는 뜻은 아니다.

거대 개체에서는 부모의 호흡 스케일 때문에 두 관절 해석의 잔차가 커졌다. 관절 회전을 최대 세 번 보정해, 세 축 4배 사건 개체의 최대 발 목표 오차를 약 39.6mm에서 **1.99mm 이하**로 줄였다. 다리 길이나 호스트 위치를 바꾸지 않는다. 이후 돌진 차단 사례도 1.96mm 이하로 확인했다.

## 품질을 유지하는 제작 가속

해부 구조 제작 함수는 매 프레임 관절을 초기화하고 원본 좌표에서 직접 자세를 계산한다. 이 과정에서 불필요하게 반복하던 장면 평가를 제외하고, 계산한 30fps 관절 키를 한 번에 기록하도록 별도 제작 경로를 추가했다. 메시·본·프레임 수·클립·셰이더·렌더 샘플 수를 줄이지 않는다.

기존 Blender 원본과 새 기록 방식의 4사례에서 총 1,406,718개 키프레임의 시간/값 및 보간·핸들 종류가 일치했고 최대 값 오차는 0이었다. 지상 분기형 189본, 돌진형, 이착륙을 포함한 조류, 기존 달리기형을 비교했다. 별도 분기형 시간 비교에서는 장면 재평가 제외만으로 98.25초에서 31.43초로 줄었다. 기기 부하와 체형이 다르므로 이 비율을 전체 제작 시간 예측값으로 쓰지 않는다.

여섯 제작기를 오래 유지했을 때 그래픽 메모리 부담도 확인했다. 다른 두 제작 묶음과 함께 실행하는 R03은 두 제작기로 나누고, 48종 묶음마다 Blender를 다시 열어 그래픽 자원을 회수한다. 기하·클립·렌더 설정은 유지한다.

새 경로는 `animation_capture.py`와 `produce_captured.py`다. 기존 완료 자산은 원래 제작 지문으로 보존하고, 새 자산에는 해부 구조 원본과 가속 구현 양쪽 지문을 기록한다. 생성·실제 렌더·검사·표시 연결을 분리한다. 변경되지 않은 바이너리의 해시는 크기/수정 시각/검증된 해시가 모두 같을 때만 재사용한다.

## 중간 임포트 경과 — 전수 완료 이전 기록

생성 중인 다른 모델을 건드리지 않도록, 같은 리소스 경로와 임포트 설정의 별도 Godot 프로젝트에서 완료 모델을 임포트한다. 실제 스켈레톤·본 수·클립을 로드해 확인한 뒤 해당 캐시를 게임에 설치한다. 첫 484개 GLB를 검증·설치했고, 그 캐시로 위 사건 3사례를 확인했다. 이후 늘어난 953종 연결분의 추가 임포트는 진행 중이다. 소스 모델의 직접 렌더 검사와 최종 게임 캐시 설치를 구분한다. 원본 GLB만 있고 엔진 임포트가 없는 경우 `ResourceLoader.exists`가 거짓인 것을 별도 최소 프로젝트로 재현했다. 표시 등록은 두 LOD의 로드 가능 여부를 확인하며, 미완성 임포트에서는 기존 모델을 유지한다. 이 대체 경로와 임포트 후 등록 복귀, 기존 개체의 노드/포즈 유지, 개별 메타데이터 1회 읽기를 실제 Forward+ 검사로 확인했다. 직접 GLTF 검수는 생성한 장면과 해당 메타데이터를 명시적으로 함께 전달한다.

R03 4,333종과 R05 384종의 남은 생산을 계속한다. 기존 640종 R06에서는 처음 46개 대표 구조의 분리된 형상과 관절을 확인했다. 이어서 과거 25종 묶음에서 5개 체형 번호가 반복되던 부분을 다른 큰 체형·구강·지지·추진 계통으로 나누는 중이다. 이 후속 수정의 94개 계통 대표와 전체 640종은 아직 완료·연결 수에 넣지 않는다.

전체 원정 플레이 흐름의 재검사, 모든 자산의 최종 임포트, 남은 모델의 생성/렌더/표시 연결은 아직 남아 있다. 새 음원은 생성하지 않았고 기존 등록 음원을 사용한다. 근거는 `media/creature-remodel/r03`, `r04`, `r05`, `integration`에 둔다.


## 후속 적용 — 1,476종

953종 체크포인트는 `43ccf5a54`에 보존했다. 이후 R03의 990종(형상 990개·관절 부모 구조 403개), R05의 149종(형상 149개·관절 구조 74개), R06의 94개 계통 대표(형상 94개·관절 구조 78개)를 검수해 표시 연결 목록을 **1,476종**으로 늘렸다. 첫 953종의 추가 1,292개 GLB와 후속 858개·188개 GLB를 순서대로 실제 로드 검증하고 설치해, 1,476종의 게임 캐시 설치를 완료했다. R06의 수중·구형 날개 생물은 새 추진 관절과 형태의 표현을 연결한 범위이며, 새 수중 항법이나 지표 조류의 이착륙 규칙을 추가했다는 뜻은 아니다.

R06 대표의 발차기·집게·지면 타격·두 번 베기·돌진 10종에서 실제 호스트 명중/회피/엄폐 30사례를 확인했다. 타격 흔적은 발끝·집게 끝·좌우 교대 공격 기관의 실제 관절을 따른다. 짧은 여섯 다리 돌진형은 회복 중 몸통이 움직이면서 이전 착지 목표가 관절 범위를 벗어나는 문제가 있었다. 다시 딛는 동안 현재 고관절 위치를 기준으로 착지점을 보정해 해당 3사례를 재확인했고, 30사례의 최대 접지 오차는 1.963mm 이하다. 실패 로그는 수정 전 근거로 보존했다.

R03의 추가 21개 구조/기관 극단, R05의 28개 날개/부유 기관 극단, R06의 94개 계통 대표 전체를 실제 빠른 이동 화면에서 검토했다. 전체 5,600종의 제작·최종 캐시 설치·최종 적용은 계속 진행 중이다.


## 동일 LOD 애니메이션의 중복 출력 제거

근거리와 원거리 LOD의 스켈레톤·관절 애니메이션이 같은데도 Blender가 두 번 계산하던 부분을 분리했다. `produce_reused.py`는 동일 해부 구조와 30fps 관절 원본을 만들고, 원거리 메시만 기존 비율로 감량해 내보낸 뒤 근거리의 동일한 애니메이션 바이트를 연결한다. 관절 이름·부모·역바인드 행렬을 확인하며, 빈 소켓 재평가의 미세한 반올림 차이 때문에 기본 변환 비교에는 0.000002 허용오차를 둔다. 원거리 메시를 현재 대기 자세로 굳혀 내보내지 않도록 바인드 상태를 사용하고 작업 장면의 자세 모드를 복구한다.

분기형 4,257개 트랙과 조류형 4,320개 트랙에서 메시 위치·법선·스킨 가중치·관절 인덱스·삼각형 인덱스 및 애니메이션 입력/출력 바이트가 기존 방식과 일치했다. 조류 검사는 같은 Blender 장면의 같은 감량 메시를 두 방식으로 출력해 비교했다. 동일 장면에서 원거리 내보내기 자체는 101.889초에서 1.486초로 줄었다. 이 수치는 모델링·근거리 출력·렌더를 포함한 전체 제작 시간이나 다른 체형의 예상 시간이 아니다. 서로 다른 부하에서 측정한 종 전체 제작 시간은 가속 비율의 근거로 사용하지 않는다.

새 전체 제작 경로의 지상 다관절형과 110본 비행형을 실제 Forward+에서 확인했다. 전자는 접지 오차 1.955mm 이하, 후자는 시드 비행 시계의 휴식·이륙·비행·착륙과 지상 유지 오차 0.359mm 이하였고 두 LOD의 가중치와 반복 클립을 확인했다. 근거는 `integration/lod-reuse-*.json`이다. 기존 방식으로 완료한 모델은 지문과 파일 해시가 일치하면 그대로 보존하며, 남은 모델만 새 경로로 제작한다.


추가 원거리 출력에서 생략된 glTF 기본 배율과 반올림된 단위 배율을 다르게 취급한 검사 오류를 수정했다. 실제 실패 파일 네 개에 동일 허용오차를 유지한 채 기본값을 적용해 통과했고, 이전 출력 구현을 `compat`에 보존해 정상 완료 자산의 제작 지문은 유지했다. 새 제작기는 Blender Python 오류를 0이 아닌 종료 코드로 받고, 다른 제작기가 남아 있는 동안 진행 상태를 유지하며 최종 누락 종 검사도 수행한다. 잘린 묶음의 미완료 종은 전체 목록 재개 시 다시 제작한다.

## 공격 정지 화면과 거리 전환 보정

검수용 정지 화면에서 섭식에서 공격으로 바꾼 직후 시간을 진행하지 않아 이전 동작의 전환 블렌딩이 남는 문제를 발견했다. 공격 준비·타격·회수는 종별 모션 프로필의 정확한 시점에 직접 맞추고, 두 번 베기는 두 타격을 각각 촬영한다. `authored_pose_capture_version=2`를 기록하며 이전 이동·접지 검증은 보존하고 해당 정지 화면과 원거리 화면만 갱신한다. 기존에 실제 시간을 진행한 호스트 공격 검증과 동영상은 이 문제와 구분한다. R02 56종과 R04 178종의 정지 캡처 갱신을 완료했고, R03·R06은 전수 제작과 함께 갱신 중이다.

가려진 LOD의 재생기가 이전 동작에 머물러 있다가 다시 표시될 때도 같은 전환 잔상이 생길 수 있었다. 보이는 LOD를 바꾸면 현재 공통 포즈에 즉시 맞추도록 했다. 기존 모델 노드·월드 위치·보행 위상·발 접점은 보존한다. 실제 임포트된 달리기형에서 숨겨진 달리기 LOD를 타격 중 표시하는 검사로 확인했고, 근거리와 원거리의 관절 변환 최대 차이는 약 0.000000246이었다.

방사형 `crown_stalker`는 첫 타격에 움직이는 왼쪽 기관 대신 중앙 기관을 접점으로 선택하던 메타데이터도 수정했다. 내보낸 스킨의 바인드 행렬과 한 쌍의 갈고리 뿌리에서 실제 기관 끝을 구하고, 기존 두 접점과 좌표계 일치를 확인한 후 왼쪽/오른쪽 순서로 연결한다. Blender 메시·애니메이션 바이트와 호스트 수치는 바꾸지 않는다. 실제 Forward+에서 각 타격 기관이 준비 자세로부터 약 0.500m·0.640m 이동했고, 명중·회피·엄폐 3사례를 다시 확인했다. 근거는 `integration/pose-capture-and-contact.json`과 관련 로그다.

## 발톱·집게·교대 베기의 후속 보정

R04의 고양잇과 발톱형 6종, 전갈 집게형 7종, 사마귀 베기형 7종은 공격 기관과 접점 연결을 더 다듬었다. 발톱형은 준비 때 앞발을 들고 전방으로 휘두른 뒤 다시 딛으며, 사마귀형은 두 공격 기관을 실제로 번갈아 내민다. 집게/발끝을 타격 접점으로 기록한다. 나머지 158종은 이전 제작 파일을 `compat`에 보존해 원본 지문과 검수한 자산을 유지한다. 20종의 후속 Blender 원본·두 LOD·실제 Forward+ 렌더와 게임 캐시 설치를 완료했다. 대표 3종의 실제 호스트 명중/회피/엄폐 9사례와 명중 영상 254프레임을 보존했다. 발톱형의 기존 호스트 도약 패턴은 유지한다. 근거는 `r04/contact-revision-host-evidence.json`, `r04/contact-revision-motion.mp4`다.

## 제작과 검수 처리량 개선

종별 근거리/원거리 파일과 Blender 원본의 검증 해시는 파일 크기·수정/변경 시각·inode가 모두 같은 동안 재사용한다. 파일이 바뀌면 다시 읽으며, 검수 도중의 변경도 확인한다. 이미지 보드는 현재 실제 캡처로 다시 조합한다. 최초 R03 196종의 체형별 공격 보드와 6종 비교 보드도 수정된 공격 시점 캡처로 갱신했다.

메모리 여유를 확인하고 진행 중인 Blender 묶음의 저장/렌더가 끝난 뒤 R03 다섯 작업기·R06 한 작업기로 재배분했다. 24종마다 Blender를 다시 열며, 메시·애니메이션·렌더 샘플 수와 두 LOD의 제작 기준은 유지한다.

후속 검수에서 R03 406종의 구조 극단 185종, 다음 115종의 빠른 이동 전수 화면을 확인했다. R06 32종과 68종의 빠른 이동 전수 및 유형별 공격 화면을 추가로 확인해 표시 등록은 2,863종이다. 이 단계의 추가 게임 캐시 임포트는 진행 중이다. 3,045개 제작 형상의 묶음 간 정규화 형상 해시를 비교했을 때 중복은 없었다. 이 검사는 전체 5,600종 최종 확인을 대신하지 않는다.

R03 외투막형 후속 211종도 검증했고, 유형/모드별 사지·기관 수와 너비·높이 극단 92종의 빠른 이동 보드 11개 및 공격 대표 보드를 확인했다. 표시 등록은 R03 1,987·R04 178·R05 384·R06 460·초기 65, 총 3,074종이다. 후속 게임 캐시 설치는 진행 중이며, 앞서 완료한 2,242종의 캐시 설치 기록과 구분한다.

추가 812개 GLB의 스켈레톤·클립 검증과 게임 캐시 설치로 2,648종까지 반영을 확인했다([최종 전수 대조](media/creature-remodel/integration/final-coverage.json)). 이어진 852개 GLB는 별도 설치 중이다. R06 후속 66종의 빠른 이동 8개 보드와 유형별 공격 화면을 확인해 표시 등록은 3,140종이다.

나선형 후속 197종의 파일/동작 검사와 구조 극단 77종의 빠른 이동 9개 보드·공격 대표 화면을 확인했다. 표시 등록은 R03 2,184·R04 178·R05 384·R06 526·초기 65, 총 3,337종이다. 아래 낮은 체형의 새 접지 보정은 별도로 재검수 중이며 등록 수를 해당 보정의 완료 수로 해석하지 않는다.

852개 GLB의 실제 골격/클립 검증과 설치를 마쳐 게임 캐시 반영도 3,074종까지 확인했다([최종 전수 대조](media/creature-remodel/integration/final-coverage.json)). 이어지는 등록분 263종의 526개 GLB도 같은 검증·설치 절차를 마쳐 3,337종의 캐시 반영을 확인했다([최종 전수 대조](media/creature-remodel/integration/final-coverage.json)).

R06 전체 640종의 Blender 원본·두 LOD·첫 실제 게임 캡처가 완성된 뒤 제작기 여섯 개를 남은 R03에 배정했다. R06 최종 화면에서 발견한 일부 나선형의 피부 접촉 문제는 별도로 수정하며, 생산 완료와 최종 품질 확인을 구분한다.

기존 1,498개 GLB 임포트의 완료 캐시 481개를 보존한 후, 남은 처리를 같은 상대 경로와 설정을 쓰는 네 독립 프로젝트로 나눴다. 각 프로젝트는 실제 골격·클립과 유한한 바인드 행렬을 확인하고, 모든 작업의 성공 및 설치 직전 원본 지문 일치를 확인한 뒤 게임 캐시에 설치한다. 사용자가 열어 둔 Godot 창은 종료하지 않았다. 이 전환 자체를 설치 완료로 계산하지 않는다.

이 1,498개 GLB의 검증·설치를 마쳐 4,086종 등록 단계의 추가 임포트를 완료했다([최종 전수 대조](media/creature-remodel/integration/final-coverage.json)). 나선형 재제작으로 달라진 기설치 33종은 다음 재임포트에 포함한다. 이어지는 1,750개 GLB는 추가 등록 842종과 그 수정 33종이며, 검토한 정확한 변경 목록으로 선택했다. 다음 작업부터는 근거리/원거리 쌍을 같은 작업기에 배정해 큰 메시와 작은 메시의 처리량을 고르게 나눈다.

## 낮고 넓은 체형의 무릎과 입 접지

외투막형의 확대 화면에서 발 목표가 지면에 맞아도 무릎 피부가 약 10cm 파묻히는 문제를 재현했다. 낮은 장갑형과 방사형에서도 같은 다리 구조의 문제가 있었고, 방사형은 배 쪽 입술이 최대 3.2cm 겹쳤다. 기존 접지 수치는 발 관절 목표의 오차였으므로 이 피부 겹침을 잡지 못했다.

`mantle`·`flat`·`radial`의 낮은 다리는 실제 무릎 캡슐의 반경을 고려한다. 발과 다리 길이를 유지하면서 무릎의 굽힘 방향을 지면 위로 회전시키며, 접지에서 풀린 발도 지면 아래를 지나가지 않게 했다. 배 쪽 입의 지지점은 GLB 스킨 정점에서 추출해 머리 관절만 필요한 만큼 들어 올린다. 몸 전체의 이동 위치, 원본/두 LOD와 공격 수치는 바꾸지 않는다. 이 보정은 `body_support_version=2`로 기록하며 기존 캡처와 구분해 갱신한다.

세 재현 개체의 실제 스킨을 굽힌 상태로 다시 측정했다. 무릎·입 정점의 5mm 초과 겹침은 사라졌고 외투막형 한 발끝에는 5.8mm 접촉이 남았다. 세 개체를 각각 240단계의 걷기·최고 도주 속도·감속·정지 선회·섭식으로 재실행했을 때 발 목표 오차는 최대 0.44mm, 정의한 관절/입 지지 오차는 최대 3.7mm였다. 이 수치를 전체 종의 모든 프레임·피부 충돌 검증으로 확대하지 않는다. 같은 구조의 나머지 종은 실제 동작 캡처를 갱신하고 있다.

재현과 수정 결과는 `r03/low-body-support-reproduction.json`, 전후/섭식 화면은 `r03/low-body-support-comparison.jpg`에 보존한다.

외투막형 재현 개체의 360프레임·30fps 실제 동작을 `r03/low-body-support-motion.mp4`로 보존했다. 걷기부터 빠른 이동·감속·섭식·공격/회복·무력화까지 포함한다. 빠른 보행 여섯 시점은 `r03/low-body-support-strides.jpg`에서 별도로 확인했다. 무음 검토 영상이며 새 음원을 생성한 것은 아니다.

## 후속 적용 — 4,086종과 관절 접촉 보정

R03 749종의 실제 파일·240단계 이동 검사를 추가로 마쳤다. 22계통의 체형/기관 극단 138종을 담은 빠른 이동 16개 보드와 공격 대표 5개 보드, Blender 대표 2종을 확인했다. R03은 2,933종이며 전체 표시 등록은 4,086종이다. 추가 1,498개 GLB의 게임 캐시 설치는 진행 중이다. R03 낮은 체형의 `body_support_version=2` 검사는 현재 903종에서 최대 지지 오차 3.7mm 이하이고, 기존 보드 274종의 관련 캡처를 갱신했다. 피부의 모든 정점·모든 프레임을 검사했다는 뜻은 아니다.

R06 최종 검토에서는 다중 나선형의 입/하부 피부가 빠른 이동 자세에서 최대 약 53cm, 나선 척추형은 약 41cm 지면에 들어가는 사례를 확인했다. 발의 목표 위치만으로는 검출되지 않았다. 실제 몸통 축의 반경과 구강 스킨의 경계를 지지점으로 기록해, 다리 IK 전에 해당 축을 필요한 만큼 들어 올린다. 낮은 가지형은 분기 끝 구강을 지지하고 실제 무릎 반경을 반영한다.

나선 척추형은 발이 고관절 바로 아래로 오면 길이가 서로 다른 두 다리 마디가 지면 위로 접힐 수 없는 구간도 있었다. 고관절과 마디 길이를 보존하고 무릎이 지면 위로 접힐 수 있는 가장 가까운 발 위치로 보정했다. 몸의 이동 위치·게임 속도·공격 수치는 유지한다. 재현했던 두 나선형과 낮은 가지형의 수정 자세에서 5mm 초과 피부 겹침이 사라졌고, 해당 걷기/달리기 구간의 지지 오차도 해소했다. 중간 버전 3의 전수 캡처에서 한 나선형의 감속 구간이 기존 몸통 높이 보정 상한에 걸리는 것을 확인했다. 필요한 접촉 보정량만 적용하되 상한을 넓힌 최종 `body_support_version=4`로 같은 제작 구조 70종의 240단계 재캡처를 마쳤다. 정의한 몸통/입 지지 잔차는 모두 0, 발 목표 오차는 최대 0.62mm였다. 빠른 이동 보드 8개와 공격 보드 4개를 확인했다. 모든 피부 정점·프레임에 대한 충돌 판정으로 확대하지 않는다.

R03의 후속 276종을 검사하고 12계통의 구조 극단 83종을 담은 빠른 이동 10개 보드·공격 4개 보드를 확인했다. R03 3,209종, 전체 표시 등록 4,362종이며 이 추가분의 캐시 설치는 앞선 임포트 다음에 진행한다.

후속 246종의 실제 파일·동작 검사와 9계통의 구조 극단 117종 검토를 마쳤다. 빠른 이동 보드 13개, 공격 보드 5개, 다중 구강형 Blender 원본을 확인했다. R03 3,455종의 정규화 형상과 1,029가지 관절 부모 구조를 확인했고, 전체 표시 등록은 4,608종이다. 이 등록분의 캐시 설치는 진행 중인 임포트와 구분한다.

이어 206종을 검사하고 8계통의 구조 극단 109종을 담은 빠른 이동 보드 13개·공격 보드 4개 및 압력낭 다중 구강형의 Blender 원본을 확인했다. R03 표시 등록은 3,661종, 전체는 4,814종이며 후속 임포트를 기다린다.

## 나선형 감각기관의 부착 위치

최종 공격 확대 화면에서 `bio_spiral_hinge_07`의 보조 감각기관이 열린 나선 사이에 떠 있는 것을 발견했다. 입 주위 감각기관은 실제 구강 관절을 따랐지만, 중복으로 배치한 한 쌍이 보이지 않는 고정 가슴 관절에 붙어 있었다. 여섯 나선 제작 구조 60종에서는 이 중복 쌍만 제거하고, 관절에 붙은 구강 감각기관을 유지한다. 다른 580종은 보존한 제작 소스를 사용해 기존 원본 지문과 자산을 유지한다. 이 60종의 재제작·실제 렌더 확인이 끝나기 전까지 R06 최종 품질 완료로 기록하지 않는다.

대표 나선형의 Blender 원본과 실제 Forward+ 달리기·공격 화면에서 부착 위치를 확인했다. 두 LOD 각각 1,881개 애니메이션 트랙의 입력/출력 바이트가 수정 전과 같고, 골격 부모 관계·소켓·원본 모션 설정도 일치한다. 240단계 검사에서 정의한 몸통 지지 오차는 0, 발 목표 오차는 0.47mm 이하였다. 전후 화면과 자산 지문은 `r06/sensory-attachment-comparison.jpg`, `r06/sensory-attachment-reproduction.json`에 보존한다.

수정 대상 60종의 재제작과 실제 240단계 동작 캡처를 모두 마쳤다. 빠른 이동 7개·공격 7개 보드와 Blender 확대 원본을 확인했다. 다른 580종의 두 LOD 지문은 그대로이며, 전체 640종의 골격 부모 관계와 소켓도 보존됐다. 이전 비교 페이지는 해당 수정 종이 있는 페이지만 현재 캡처로 갱신했다. R06 최종 114종도 등록해 R06 640종 전부, 전체 4,928종의 표시 목록을 연결했다. 수정된 60종의 재임포트와 마지막 등록분의 캐시 설치는 별도로 진행한다.
