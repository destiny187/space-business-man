# 승인 생물의 호스트 공격·비행 연결

2026-09-12. 전체 동물 리모델링을 계속 진행하면서, 앞서 표시 전환을 보류했던 승인작 3종의 연결을 마무리했다. **일반 원정 표시 전환은 지상 64종·대기 비행 1종, 합계 65종**이다. 전체 5,600종과 저장된 생물 사건의 전환 완료를 뜻하지 않는다. 전체 제작 소관은 [155](155-creature-remodel-rollout.md)다.

## 실제 변경

- `sailhorn` / `biota_spindle_armor_25`: 기존 호스트의 돌진 속도·이동·충돌 판정을 사용한다. 머리를 낮춘 달리기 `charge_loop`를 추가하고 실제 이동 거리에 보행 위상을 맞췄다. 준비·돌진·차단·회복 동안 발 접지를 유지한다.
- `shearprowler` / `biota_lobopod_armor_26`: 호스트의 단일 착지 공격에 맞춰 `leap_prepare`, `leap_air`, `leap_land`를 추가했다. 공중 이동은 호스트의 높이/위치를 사용하고 지상 준비·착지 때만 지형에 발을 맞춘다. 기존 두 번 베기 시안 클립은 보존한다.
- 두 지상 승인작에 `down`을 추가했다. 저장된 무력화 자세를 즉시 복원할 때 이전 애니메이션의 전환 혼합이 남는 문제도 수정했다. 실제 루트 본이 내려가는 것과 중복 복원 입력의 자세 유지를 확인했다.
- `veilglider` / `biota_bilateral_armor_11`: 접은 날개와 접지 발의 휴식, 이륙, 순항, 착륙을 추가했다. 기존 시드 비행 경로의 시간·혼합률을 사용하며 원산지, 운송 개체의 비행 제한과 휴면 상태를 보존한다.
- 세 종 모두 승인된 원본 메시 해시가 그대로다. 새 Blender 파일과 두 단계 GLB를 별도 `creature_remodel/combat`, `creature_remodel/flight` 경로에 보관한다.

## 타격 표현과 갱신 범위

새 표시의 접촉 효과는 호스트가 발행한 `attack.hits` 비트 변화에만 반응한다. 공격 포즈로 명중을 예측하지 않는다. 표적의 위치와 실드 변화를 사용해 실제 표적 쪽에 짧은 접촉 자국과 파편을 만들며, 노란 원형 이펙트를 재사용하지 않는다. 착지 충격은 호스트의 두 번째 도약 펄스에 연결한다. 기존 원정 음성/효과음 신호를 유지하고 표시 어댑터에서 중복 재생하지 않는다.

파편은 생성 지점의 지형 높이를 한 번 읽어 보존한다. 기존 검토 장면의 Y=0 가정을 제거해 지하/음수 높이의 접촉이 지상으로 튀지 않게 했다. 입자 수·음성 수의 기존 상한을 유지한다.

대량 제작의 후속 등록을 위한 종별 작은 메타데이터 경로를 추가했다. 새 항목은 요청한 종의 파일만 한 번 읽고 이후 경로/치수 조회에서 재사용한다. 기존 승인 65종의 작은 매니페스트 초기 적재와 종별 조회를 구분한다. 이 변경은 월드 직렬화·저장·요청 발행을 호출하지 않으며 다른 생물 노드·포즈·위상을 재생성하지 않는다.

## 실제 확인

- Godot 4.7.2 Forward+ / Metal에서 기존 호스트 공격 함수를 실제로 실행해 돌진·도약의 명중/회피/차단 **6가지**를 확인했다. 명중 1회, 빗나감/차단 피해 0회, 표시 접촉도 각각 1/0회였다. 최대 발 접지 오차는 약 **0.54mm**, 호스트 루트 위치 오차는 0이었다.
- 같은 실행에서 전투 수치·호스트 공격 상태·별도 생물의 모델 노드와 위상이 유지됐다. 무력화 최종 포즈와 저장 복원은 본의 실제 위치로 확인했다.
- 기존 48초 시드 비행 경로에서 휴식·이륙·비행·착륙 네 상태와 네 클립을 확인했다. 위치 오차는 0이며, 휴면 및 운송 개체는 지상 상태를 유지했다.
- 실제 임포트 경로로 지상 64종의 미리 읽기/지연 LOD와 라이브 입 소켓을 확인했다. 비행형은 같은 Actor의 원본 GLB 로딩과 시드 비행 구동으로 확인했다.
- 원본 카탈로그 및 밸런스 파일은 수정하지 않았다. 기존 월드의 새로운 서식 배정이나 새 전투 성향을 추가하지 않았다.
