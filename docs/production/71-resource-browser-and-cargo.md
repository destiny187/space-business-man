# UX01 — 자원 탐색·창고 이동·건설 화면

2026-09-08. [전체 UX01~UX03 계획](../planning/13-uiux-renewal-commits.md)의 1차 구현이다. 조사 U01/U02/U03/U04/U08/U09/U12를 적용했다. 도감·제작소 구조·항해·성장 메뉴 재배치·정비/교역은 후속이다.

## 구현

- **없는 품목 숨김:** 아이템/화물은 양수 재고와 실제 소유 장비만 표시한다. 빈 칸을 가짜 아이템으로 채우지 않는다. 증강 보석과 연구대 소지 표본도 보유량이 있을 때만 후보가 보인다. 공동 연구 기록은 발견한 표본을 유지한다. 기존 저장의 0 값은 지우지 않는다.
- **공통 탐색:** `FrontierItemBrowser`의 이름 검색, 전체/광물/보석/부품/장비 분류, 이름순/수량순을 아이템·양쪽 창고에 연결했다. 제작 설계에는 이름 검색을 둔다. 검색/정렬은 실제 중첩과 소유 데이터를 변경하지 않는다.
- **이름과 수량:** 짧은 이름과 수량 배지를 함께 그린다. 긴 이름은 말줄임하고 툴팁에 전체 이름을 보존한다. 동일 품목의 여러 중첩도 실제 수량 단위로 남긴다.
- **명시적 이동:** 선택 이름·출발/도착·최대 가능량을 같은 위치에 표시한다. 수량 입력과 `1 / 중첩 / 최대`, Shift+클릭, 반대편 영역 드래그를 제공한다. 최대는 보유량과 목적지 여유를 반영하며 호스트가 거래 시 다시 검증한다. 일부만 옮기면 선택을 유지하고, 마지막 수량을 옮기면 선택/카드를 정리한다.
- **사용처:** 알려진 장비 제작, T2까지 제품, 건설, 보석 증강과 발견한 심부 연구를 데이터에서 찾아 표시한다. 처음 3개와 나머지 메뉴, 실제 모델·필요 재료·작업 장소를 제공한다. 아이템 제작/건설 설계·신체/공동 연구 기록으로 연결하며 조회는 원격 제작이나 재료 소비를 실행하지 않는다. 미개발 사용처와 미해금 T3 제품은 가능한 행동처럼 나열하지 않는다.
- **아이템 배치:** 격자를 왼쪽, 모델/상세를 오른쪽에 두고 주요 버튼을 고정했다. 상세만 따로 스크롤한다. 작은 창은 미리보기를 줄이고 뷰포트 기준으로 열 수를 계산한다. 화물은 전체 폭을 쓰며 장착 슬롯을 숨긴다. 아이템/제작에서는 하단 장착 슬롯 공간을 확보한다.
- **건설:** 배낭/창고 전 품목 나열을 제거하고 현재 작업의 재료 출처와 선택 시설의 필요 재료만 표시한다. 없는 필요 재료는 `부족`으로 안내한다. 단일 건설 탭 머리글과 중복 안내를 줄이고 카드 이름 영역을 확보했다.
- **렌더/문구:** 기존 Blender 시설 8종을 Godot Forward+로 재렌더해 투명 카드 배경을 적용했다. `--facilities-only`와 알파 검사로 재생성한다. 가방 확장/부재중 생산 안내를 현재 규칙으로 수정했다. 거점·항해 재고 툴팁과 회수 화물 문자열에서도 0개를 제외한다.

## 확인

Godot 4.7.2 / Metal Forward+ / Apple M2. `--crew-ui-test --crew-folder=/tmp/uiux-ux01`로 A06 테스트 세계/프로필의 복사본을 사용했다. 품목 수 관찰용으로 정상 저장 규칙 내 가방 용량과 창고를 준비했으며 자연 성장으로 확보한 상태라는 뜻은 아니다. 사용자 플레이 저장은 열지 않았다.

- [실제 창/거래 확인](media/uiux-ux01/run.txt): **23개, 실패 0**. 0개 제외, 보석 분류, 한글 검색, 사용처 열람, 행성 창고 방향/최대 수량, 실제 호스트 전량 입고·1개 인수, 마지막 수량 소진, 작은 창 폭/하단/실행 버튼, 메뉴 중 장비 입력 차단, 저장 파일의 거래 기록과 전용 세션 종료.
- [최종 작은 창 확인](media/uiux-ux01/layout.txt): **4개, 실패 0**. 거래 확인 후 간격을 다듬고 960×640의 아이템 경계·사용처 창·화물 두 줄 이상 표시를 확인했다. 거래 규칙은 변경하지 않았다.
- [시설 렌더](media/uiux-ux01/facilities.txt): 8종 투명 배경 알파 검사. 실제 건설 화면에서 배경과 시설 이름을 확인했다.
- 발견 후 수정: 빈 검색어에서 모든 항목이 숨는 문제, 넓은 창의 격자 최소 폭이 작은 창에 남는 문제, 화물 조작 영역 때문에 목록이 한 줄만 보이는 문제. 최초 검증용 창고의 잘못된 ID/티어는 저장 검증에 걸렸으며 테스트 데이터만 수정했다.

전체 회귀·6인/다중 클라이언트·인터넷·패드·장시간 검사와 선박 화물의 별도 전 거래 재검사는 수행하지 않았다. 공통 UI에서 기존 호스트 거리/소유/공간 검증을 유지한다. 신규 모델/음원은 없고 기존 Blender 자산·INK 미리보기·거래 피드백을 재사용했다. 별도 음향 녹음/청음 검사는 하지 않았다.
