# 우주 그래픽·사운드 고도화

2026-09-09 사용자 승인: 제안한 그래픽 여섯 항목과 사운드 네 항목을 모두 개발한다. 현재 원정·공동선·FINCH의 실제 비행 화면에 연결했다. INK v1의 검은 윤곽선·3단 명암, Blender 제작, ElevenLabs 음원 제작을 유지한다.

## 적용 결과

행동 연출은 수신한 항해 상태를 따른다. 메뉴·포커스 이탈 중 추진 재생기/입자를 정지하고 음악 전환 시간을 동결한다. 충전/출발 효과에 기존 ElevenLabs 부스트·제동 음원을 변형 재사용하며, 도착 성공은 기존 호스트 결과와 연결된다.

## 구현 경계

천체 좌표·세계 시드·공전·충돌·항해 비용·저장 규칙은 유지한다. 근접 파편은 시각 연출이며 채집·새 충돌 대상이 아니다. 공간 셀마다 같은 조각을 재현하고 활성 필드당 최대 605개를 사용한다. 1,400~1,800 거리에서 크기를 줄여 셀 교체 전에 사라지게 한다.

천체 그림자는 수신 재질마다 각크기가 큰 구체 8개와 가장 가까운 고리 1개를 사용하는 근사다. 다중 산란·체적 유체·모든 파편의 상호 그림자는 구현하지 않는다. 구름은 근거리 독립 껍질과 원거리 표면 표현을 전환한다. 번개는 장식 연출이며 날씨/피해 판정을 추가하지 않는다.

지구 도시 불빛은 육지 마스크를 사용한 게임 연출로, 실제 도시 위치 관측 데이터가 아니다. 생성 행성에는 문명 근거 없이 도시 불빛을 추가하지 않았다. 기존 태양계 모델의 범위를 유지했으며, 위성 일식은 현재 생성 항성계의 실제 위성 모델에 연결된다. 여성 AI 음성을 추가하지 않는다.

## 자산·코드

- Blender 신규 3종: 자세제어 노즐·궤도 암석·궤도 얼음. [원본/내보내기 기록](../../art/blender/space-polish/manifest.json), `tools/build_orbital_details.py`, `data/render_assets.json`에 등록했다. 공통 산업 재질과 제작 함수를 사용하며 자연물 색은 별도다.
- ElevenLabs 신규 5종: 반응로·FINCH 터빈·고출력 배기 각 8초 생성, 발견/위험 음악 각 120초 생성. [프롬프트·선택본·원본·해시·확인 기록](../../audio/manifests/space-polish.json)을 보관한다. WAV 루프는 120ms 교차 연결 후 7.88초, RMS -21dBFS 목표/피크 -3dBFS 상한으로 편집했다. 음악은 원본 MP3를 보존한다.
- `scripts/world/orbital_presentation.gd`, `orbital_debris.gd`, `vessel_drive_effects.gd`와 우주 셰이더를 현재 `crew_flight_view.gd`에 연결했다. 공통 셀 셰이더의 천체 가림은 우주 재질에서만 활성화한다.
- `scripts/app/vessel_sound.gd`, `expedition_audio.gd`, `data/space_polish.json`, `space_audio.json`, `expedition_audio.json`이 시각/음향 설정을 소유한다.

## 실제 확인 — 최소 범위

Godot 4.7.2 Forward+ / Metal / Apple M2의 실제 창에서 확인했다. 전체 회귀 묶음은 실행하지 않았다.

1. Blender Cycles 3종 렌더와 Godot INK 3종 렌더를 비교했다. 노즐 기구·곡면·재질과 암석/얼음 면·윤곽을 확인했다.
2. 실제 비행 장면에서 지구 낮/밤/대기 테두리·도시 불빛, 토성 고리, 근접 얼음 149개·소행성대 암석 303개, 생성 행성 구름 이동, FINCH 배기/노즐을 확인했다. 위성을 의도적으로 정렬한 별도 렌더에서 행성 표면의 그림자를 확인했다. 자연 공전 중 일식이 올 때까지 기다린 검사는 아니다.
3. 실제 원정 앱을 격리 저장 폴더로 시작하고 추진·선회·제동·메뉴 정지/복귀·실제 출발 거래·성간 이동·도착/위험 음악·FINCH 모델/믹스·선내 버스·960×640 화면을 확인했다. 항해 상태와 진행률을 시험용으로 공급했으며, 전체 자연 진행이나 FINCH 제작 거래 검사가 아니다. 해당 관찰 15개는 통과했다.
4. 이 실행 중 종료된 단발 재생기를 정리하는 오류를 발견했다. 해제된 객체에 대한 typed filter를 제거했고, 반복 단발 재생 종료·도착 직전 정적·차단 중 이벤트 방지의 최소 재현 경로를 다시 실행해 오류 없이 통과했다. FINCH 배기 빌보드가 입자 스케일을 잃던 오류도 수정하고 새 렌더로 선체가 가려지지 않는 것을 확인했다. 두 수정 후 실제 원정 경로를 다시 실행하여 15개 확인 통과·스크립트 오류 없음을 확인하고 대표 화면/녹음을 갱신했다. 종료 시 `ObjectDB` 객체 1개가 남았다는 경고는 계속 발생했으며, 종류/원인은 아직 확인하지 않았다.
5. 공통 셀 조명에 대한 기존 국소 조명 검사 3개를 통과했다. 점등 거리별 밝기와 소등이 유지됐다. 최신 자산 가져오기 및 상세/일식 렌더에 파싱·셰이더 오류가 없었다.
6. 게임에서 실제 오디오 재생기·버스 신호와 약 1.88초 출력 녹음을 확인했다. 효과음 PCM 레벨·루프 연결부 및 MP3 형식/길이를 측정했다. 이 작업 환경은 오디오 내용을 청취할 수 없어 주관적 음색·두 음악의 전곡 청취·헤드폰/스피커 청감 검수는 수행하지 않았다.

기존 사용자 저장 대신 `/tmp/space-polish-v2-20260909`를 사용했다. 6인 접속·Windows 실기·장시간 성능·전 천체 조합·지상 기본 플레이 전체 흐름의 재검사는 이번에 수행하지 않았다.
