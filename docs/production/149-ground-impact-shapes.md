# 지상 타격 효과 형태 교체

2026-09-12 사용자 요청: 이상하게 보이는 타격 이펙트를 교체한다. 조준 문구 제거는 [148 UI 기록](148-target-identity-and-scan-results.md)을 따른다.

## 변경

- 총구의 반복 꽃 모양 섬광을 길이가 다른 비대칭 화염으로 교체했다. 명중점은 65~90ms의 작은 접촉 섬광으로 표현한다.
- 생물/지표는 불투명한 둥근 덩어리 대신 낮은 불투명도의 불규칙 먼지 한 조각과 미세 파편을 사용한다. 금속에는 가늘고 짧은 방향성 불꽃을 남긴다.
- 실드는 중심을 가리지 않는 끊어진 얇은 호로 표현하고, 파괴 시 작은 파편 다섯 조각을 더한다. 플라스마 접촉도 같은 형태 체계를 사용한다.
- 전투로봇/드론은 상태 번호가 바뀔 때마다 몸 중심에서 추가되던 보라색 공통 폭발을 제거했다. 생물의 피격/무력화 신호가 추가하던 몸 전체의 베이지색 고리도 제거했다. 발걸음에서도 같은 큰 고리가 겹치던 부분을 작은 발치 먼지로 바꿨다. 각 생물의 소리와 동작은 유지하며 실제 총알 명중점의 재질 효과와 중복되지 않는다.
- 피해량·총기별 발사 규칙·피해 숫자·조준 피드백과 기존 ElevenLabs 효과음은 유지한다. 호스트가 거절한 발사에는 섬광을 만들지 않는다. 풀 상한 144개, 첫 렌더 프레임 보존, 메뉴 진입 시 정리를 유지한다.
- 새 모델/음원은 제작하지 않았다. 기존 절차적 효과와 셰이더를 수정했고 INK v1의 형태 가독성과 제한된 발광을 따른다. 공통 우주전 셰이더는 변경하지 않았다.

## 실제 확인

별도 저장의 자연 배정 생물과 지표에 실제 발사해 호스트 명중 접촉·기존 생물 타격음·효과 만료·거절 발사의 비노출·메뉴 진입 정리를 확인했다. `tests/check_target_identity_ui.gd --impacts-only`의 최종 확인은 14항목, 실패 0이다. Forward+ 실제 창의 생물 명중, 금속/실드/파괴 재질의 시작·감쇠 화면을 캡처했다. 재질 확대 화면은 명시적인 연출용 접촉이며 실제 실드 피해 검증으로 해석하지 않는다.

첫 지표 확인은 클라이언트와 호스트의 발사 간격이 모두 끝나기 전에 재발사해 실패했다. 확인 스크립트의 대기를 수정한 뒤 실제 지표 접촉을 확인했다. 검사 중 위치 이동 직후 운동 상태 없이 자세 표시 플래그만 전달될 때 발생한 `crew_pose` 오류도, 속도 상태가 도착할 때까지 자세 갱신을 기다리도록 수정했다.
