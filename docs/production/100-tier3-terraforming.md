# T3 유입원 제어·전문 생산·지역 복원

2026-09-09. 사용자가 [T3-01~10 구현 계획](../planning/14-tier3-terraforming-implementation.md)을 커밋하고 개발하도록 요청했다. 기존 지역 테라포밍과 계획은 `1b2c994d`로 커밋했으며, 이 기록은 뒤이은 T3 구현의 범위다. 탐험 발견·사건·설계도 획득/판매 콘텐츠는 별도 작업으로 유지한다.

## 실제 플레이

1. 새 T3 행성의 Tab 지도에서 착륙지·유입원·정화지·선구종 복원지 네 현장을 확인한다. 시드에 따라 **산성 수질 또는 반응성 가스** 한 문제가 선택된다. 지도 화살표는 유입원→정화지→복원지의 영향 방향이다.
2. 기존 금속/저온 가공 부품과 산업 코어로 Mk.3 제작소를 마련한다. 산업 코어는 기존대로 Mk.2에서 제작하며, 최초 Mk.3에 Mk.3 전용 부품을 먼저 요구하지 않는다. 설계도 보유와 실제 제작 재료는 별도 조건이다.
3. Mk.3 제작소에서 전문 제품을 만들고 필요한 현장의 창고로 직접 운반한다. 원격 현장 재고를 자동 차감하지 않는다. 기존 T1/T2 설비는 기본 급수·대기·온도·토양 작업에 계속 사용한다.
4. 유입원 근처에 제어 장치를 건설하고 전력과 문제에 맞는 처리 팩을 공급한다. 가동 중에는 유입을 억제하고 주변 잔류물도 처리한다. 설치만 하거나 전력이 없는 상태로는 원인을 해결하지 못한다.
5. 영향 지역에서는 해당 문제를 처리할 Mk.3 대기/수질 설비를 가동한다. 기본 설비나 다른 방식의 처리기를 늘려도 해당 잔류 오염이 없어지지 않는다. 최종 복원지에는 기초 환경·토양을 조성하고 선구종 정착기를 운영한다.
6. 현장마다 5개 구획 중 3곳이 조건을 45초 유지하면 그 현장이 안정된다. 세 외부 현장에는 각각 총대금의 15%를 한 번 지급하고, 모든 현장을 안정시킨 뒤 착륙선 단말에서 잔금을 정산한다. 거점을 보유하면 기존 총대금 60%에서 이미 지급한 금액을 차감한다.

소모품이 끊기거나 제어 장치를 끄면 유입이 다시 늘어난다. 지도/H 상세에서 잔류량·유입 억제율·제어 장치의 남은 보급 시간을 확인할 수 있다. 복원에 사용한 제품이나 개량한 토양·시설을 통째로 초기화하지 않으며, 같은 현장을 다시 복원해도 중간 대금을 재지급하지 않는다.

## 데이터·설비

원본은 `data/terraforming_tier3.json`이다. 새 세계 `regional_rules` v2에는 T3 현장과 환경 규칙을 함께 저장한다. 프로필·시드·초기 잔류량·유입/이동/처리량·공급 시간·안정 조건은 현재 조정 가능한 게임 수치이며 실제 화학/유체의 단위나 현실 공정을 재현한다는 뜻이 아니다.

| 시설 | 구현 형태와 기능 |
| --- | --- |
| 유입원 제어 장치 | 별도 Mk.3 시설. 원인 48m 이내 배치·지역 전력·중화/흡착 팩으로 최대 98% 유입 억제 |
| 선택성 대기 처리기 | 대기 설비 Mk.3 개조. 기본 대기 처리와 반응성 가스 포집 |
| 폐쇄 수자원 순환기 | 물 설비 Mk.3 개조. 산성 잔류물 처리, 같은 얼음의 급수 지표 개선량 1.5배 |
| 지역 열교환기 | 열 설비 Mk.3 개조. 기존 대비 향상된 국소 온도 조절; T4 극한 정격 기능은 아님 |
| 선구종 정착기 | 생태 설비 Mk.3 개조. 정화·급수·온도·토양 조건 뒤 표준 선구종 정착 팩 소비 |

P3 신규 제품은 **내식 합금·선택 교환막·수질 중화 팩·가스 흡착 팩·순환 모듈·지역 열교환 모듈·선구종 정착 팩** 7종이다. 기존 원료·산업 코어 경로를 재사용한다. 새 화폐나 보석 의무 소비는 추가하지 않았다. 이 제품들의 패키지 모델/아이콘은 기존 Blender 부품 자산을 재사용하고 이름·III 단계·레시피·소비처로 구분한다.

전문 개조 모듈은 기존 시설 옆에 실제 모델로 부착한다. 지지 면적과 이웃 시설 간격을 개조 전에 검사하고, 개조 후 충돌·토대·침수 외곽도 확장한다. 침수 범위는 Blender 출력 바운드를 기존 시설 외곽과 합친 데이터이며, 호스트가 매번 GLB를 읽지 않는다.

순환기의 급수 효율은 현재 환경 지표의 재사용 효율로 구현했다. 행성 물리 수면에 새 물을 생성하거나 지역 사이에 화물·물을 자동 전송하지 않는다. 지도 영향망은 잔류 오염의 이동 계산이며 범용 파이프/자동 운송망과 구분한다.

## 원인·영향·저장

`FrontierTerraformTier3`가 원인 유입, 원인 억제와 소모품, 두 영향 연결, 잔류량 및 선구종 정착을 관리한다. 연결의 출발 상태를 먼저 읽고 적용하므로 한 프레임에 두 연결을 건너뛰지 않는다. 처리량은 대상 구획에 비례 배분하며 동일 소모품/처리량을 구획마다 중복 적용하지 않는다.

`초기 잔류량 + 생성량 − 제거량 = 현재 전체 잔류량` 장부를 저장 검증한다. 지역 이동은 전체 합계를 늘리지 않는다. 현장 창고와 시설 연료 잔여 시간, 원인 제어 이력, 구획별 오염·정착·안정 시간, 지급 기록은 호스트 원장에 남는다. 협동의 사업 시작 인원에 따라 처리 대상량과 대금을 고정하고 기존 개인 이동/채집 속도를 바꾸지 않는다.

기존 호스트 세션의 부재중 산업 틱에 연결했으며, 현실 시간 소급 진행을 추가하지 않았다. 저장 후 상태를 공개하는 기존 거래 경로를 사용한다. 실제 시설 모델의 작업 상태와 사운드도 해당 호스트 결과를 읽는다.

기존 은하에는 새 T3 지역을 소급 생성하지 않는다. `regional_rules` v1 은하의 T3는 이전 단일 지역 규칙을 유지한다. 기존 사업 저장 해시는 보존하고 신규 전문 시설 정의는 추가 콘텐츠로 조회한다. 지역 규칙 도입 전 저장의 기존 Mk.3 제작소 권한은 보존하며, 이번에 추가한 다섯 전문 설비는 기존 저장에서도 설계도를 요구한다. 기존 T1/T2 구획·지표/지하 배치를 재배치하지 않는다.

## 설계도 담당 작업과 연결

`facility_blueprints.json`의 공동 사용권은 다음 6개다.

| ID | 권한 |
| --- | --- |
| `facility_factory_mk3` | 기존 Mk.3 제작소 |
| `facility_source_control_mk3` | 유입원 제어 장치 신축 |
| `facility_atmosphere_mk3` | 선택성 대기 처리 개조 |
| `facility_water_mk3` | 폐쇄 수자원 순환 개조 |
| `facility_thermal_mk3` | 지역 열교환 개조 |
| `facility_biolab_mk3` | 선구종 정착 개조 |

획득 담당은 기존 `FrontierFacilityBlueprints.register(world, id, source, reference)`를 호스트 거래 안에서 호출한다. `source`는 `exploration` 또는 `station`이며 발견/구매 자격과 중복·크레딧 차감은 획득 담당의 책임이다. 여기에서는 보유 판정·중복 사용권 방지·저장·실제 건설/개조 잠금을 제공한다. 획득 뒤 같은 설계의 필수 연구를 다시 추가하지 않는다.

**실제 탐험 획득·정거장 판매는 이 작업에서 연결하지 않았다.** 정상 플레이의 설계도 지급 경로가 아직 없으면 새 세계의 T3 전문 설비는 잠겨 있다. 임시 무료 지급이나 임의 해금 RPC를 추가하지 않았다. 검수용 설계도 보유 저장을 실제 획득 플레이로 설명하지 않는다.

## 아트·음향과 확인 범위

`tools/build_terraform3.py`로 제어 장치와 네 개조 모듈의 편집 가능한 `.blend`·GLB를 제작하고, Blender 5.2.1 LTS의 형상 렌더와 Godot 4.7.2 Forward+ / Apple M2의 INK 렌더를 확인했다. 기존 시설 본체를 재사용하며 가동 부모를 실제 시설 작업 모션에 연결했다. 유입원 주변 암석은 기존 Blender 광물 형태를 환경 표식으로 재사용하고, 제한된 입자/변색으로 유입 상태를 표현한다. 탐험 발견물로 등록하거나 채광 보상을 주지 않는다.

신규 음원 생성 없이 기존 ElevenLabs 작업 루프와 건설/개조/제작·실패·정산 효과음을 재사용했다. 제어 장치의 작업 루프가 실제 현장에서 생성되는 것을 확인하며, 음향 매핑과 주관적 청감의 구분은 `audio/manifests/terraform3-reuse.json`에 남긴다.

검수는 해당 기능에 필요한 범위로 제한했다. 수급·환경 준비 데이터와 실제 실행한 거래/시뮬레이션을 구분한다. 최초부터 일반 플레이로 모든 원료를 채집하고 항성 간 운송까지 완주한 시간/경제 검수, 6인 분산 접속·장시간 부재중 운영·전 시드 공급량·Windows 실기는 수행하지 않았다. 최종 검사 결과와 대표 화면은 아래 실행 기록을 따른다.

## 실행 기록 — 2026-09-09

- 수질형과 가스형에서 각각 `check_terraform_tier3.gd`의 24개 관련 확인을 통과했다. 초기 기후·설치·재고는 준비 데이터이며 잔류 오염 제거·지역 이동·선구종 정착·안정 시간은 실제 런타임으로 진행했다. 가스형 사례는 이 준비 조건에서 시뮬레이션 566초에 계약 조건을 충족했으며, 일반 플레이의 소요 시간 목표가 아니다. 실제 정산 명령과 중복 지급 거절, JSON의 오염량 보존을 확인했다.
- `check_terraform_tier3_play.gd`의 실제 Forward+ 창에서 11개 확인을 통과했다. 새 T3 착륙·현장 스트리밍, 호스트 저장 경로의 P3 생산/Mk.3 개조, 유입 억제, 새 모듈/가동부, ElevenLabs 제어 장치 루프, 20구획 지표, 작은 지도와 전체 세계 저장을 확인했다. 개조 후 확장된 토대 판정을 반영한 상태에서 재확인했다.
- 기존 T1/T2 지역 검사는 이번 연결 초기에 27개 통과했다. 새 설비 추가 때문에 기존 사업 해시를 바꾸지 않는 경로를 사용했다.
