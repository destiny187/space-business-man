# 재화 SVG와 수량 표시

## 결정 기록 — 2026-09-06

사용자 요청에 따라 텍스트·기본 도형 중심 재화 UI를 SVG로 개선한다. 획득 알림은 아이콘과 부호 있는 수량으로 표시한다. 메인 산업·협동 기능 개발과 분리해 자산과 UI 연결만 변경한다. 경제·저장·네트워크 규칙은 변경하지 않는다.

## 실제 적용

- `assets/ui/resources/`: 철·구리·암석·얼음·희귀 결정·크레딧 6종. 편집 가능한 128×128 SVG 원본이다. 굵은 검은 외곽, 단계별 면 명암, 서로 다른 실루엣으로 INK v1의 UI 표현을 따른다.
- 기존 실행 HUD: 보관함의 단색 마름모 교체, 크레딧 아이콘, 채집 아이콘과 `+수량` 알림. 이름 범례는 유지한다.
- 건설·로봇 제작 비용: 재화 아이콘과 보유량/필요량. 화물 관리에는 아이콘과 이름을 함께 표시한다.
- 탐험 HUD·알림, 협동 상태·지표 정보, 원정 사업 창고/배낭: 숫자가 따라오는 자원명을 공통 표시 컴포넌트로 치환한다. 안내 문장 자체는 유지하고 툴팁에 원래 이름과 수량을 보존한다.
- 협동·생태 연구 버튼의 광물 비용도 아이콘과 수량으로 표시한다. 클릭은 기존 버튼이 처리하며 툴팁에는 원문을 보존한다.
- 공통 연결: `FrontierResourceIcons`, `FrontierResourceReadout`. `광물`은 현재 탐험에서 소비하는 암석(`stone`)과 같은 아이콘이다. 실제 카탈로그 ID와 이름은 변경하지 않는다.

모든 설명문·선택 목록·버튼·3D 월드 이름표를 제거하는 작업은 아니다. 이름은 안내 및 자원 학습에 계속 사용한다. 새 배포 앱/ZIP은 만들지 않았으며 소스 실행에 적용했다.

## 검증

`tools/godot.sh --script res://tests/test_resource_icons.gd`로 실제 Metal 렌더에서 SVG 로드, 부호·0·보유량/필요량 보존, 일반 문장 유지, 툴팁 원문, HUD 아이콘과 수량 연결을 확인한다. 작은 창의 건설 카드에서는 아이콘과 수치 및 분수가 분리되어 줄바꿈되지 않도록 묶는다.

[아이콘 모음](media/resource-icons/board.png) · [게임 채집 알림과 HUD](media/resource-icons/game.png). 추가 UI 회귀 결과는 아래 검증 기록에 남긴다.

- 재화 전용 검사: `RESOURCE_ICONS failures=0`. 실제 HUD와 960×640 건설 카드 렌더를 직접 확인했다.
- 협동 작은 화면: `CREW_LAYOUT_CHECKS 12 FAILURES 0`. 아이콘 비용 버튼, 장비 팝업, 사업 패널 스크롤과 화면 경계 검사를 통과했다. [협동 화면](media/resource-icons/crew.png) · [건설 비용](media/resource-icons/costs.png).
- 탐험 운반 UI: 격리 저장 플래그로 실행한 `test_courier_ui.gd`의 `COURIER_CHECKS 19 FAILURES 0`. 실제 굴착·운반·저장/재개·중복 없는 하역을 확인했다. 성능 측정은 동시 작업 환경이므로 이번 UI의 성능 개선 수치로 사용하지 않는다.

## PRD 전체 보완

사용자의 후속 요청에 따라 기존 실행판 6종 범위를 PRD 대조 SVG 73종으로 확장했다. [전체 목록·출처·상태](16-prd-resource-icon-coverage.md)가 후속 자산 목록의 기준이다. 기존 6종만으로 PRD 전체 재화를 충족했다고 보지 않는다.
