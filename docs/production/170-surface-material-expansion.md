# 지표 재질 43종·국소 무늬 변화

2026-09-13 사용자는 반복적인 지표 인상을 줄이기 위한 재질 추가와 실제 적용을 승인했다. 사막·암석·빙결 계열을 대표로 재질·지역 표현을 개선하고 기존 INK v1을 유지한다. 18종 구성과 아래 수치는 이번 구현 선택이다.

## 제작과 연결

기존 25종에 서로 다른 높이장으로 제작한 18종을 추가해 **43종**을 등록했다. 1024² 선형 RGBA의 법선 XY·높이/명암·거칠기 계약을 유지한다. 게임의 충돌 지형을 변위시키는 텍스처가 아니다.

| 계열 | 신규 재질 |
| --- | --- |
| 사막·퇴적 | `dune_crossbeds` 사층리 모래, `wind_ripple_sand` 끊어진 사문, `desert_pavement` 사막 포석, `eroded_clay` 침식 점토 홈, `scoured_sandstone` 풍식 사암 선반, `flint_shingle` 편평한 부싯돌 |
| 암반·파편 | `granite_plates` 화강암 박리판, `schist_ridges` 편암 엽리, `vesicular_basalt` 기공 현무암, `pebble_conglomerate` 역암 노출면, `shale_chips` 박편 셰일, `mineral_veins` 맥상 암반 |
| 동결 | `glacier_foliation` 압축 빙하층, `blue_ice_bubbles` 기포 얼음, `frost_heave` 동결 융기토, `snow_sastrugi` 바람 침식 설릉, `firn_granules` 입상설, `ice_shards` 얼음편 |

원본은 `art/blender/surface-materials/surface-expansion.blend`, 생성기와 이력은 `tools/build_surface_expansion.py`와 같은 원본 폴더의 `surface-expansion.json`이다. Blender에서 편집 가능한 높이 메시와 패킹 이미지를 함께 보존한다. 원본의 변위 미리보기와 게임의 노멀 표현을 구분한다. 원본·PNG·대표 렌더는 기존 LFS 규칙을 따른다.

`surface_materials.json`의 12개 지상 계열에 적합한 후보를 연결한다. 기본 암반/퇴적물 외에 행성 시드로 보조 퇴적물 하나를 선택하고 넓은 구역에서 교대로 표시한다. 동결/툰드라 계열에는 눈·얼음 후보도 연결한다. 새 맵의 실제 반복 크기는 재질 데이터에 둔다. 기존 시드의 재질 외형 선택은 달라질 수 있지만 재실행·JSON 왕복에서 재현된다.

기존 저장에 있는 지역의 암반 후보도 현재 미술 라이브러리에서 선택한다. `@rock`은 행성 주 암반을 따른다. 지역 규칙이 없는 오래된 저장에는 새 지형·지역을 생성하지 않으며 주/보조 퇴적물과 무늬 변형만 표시한다.

## 반복·중거리 표현

- 행성별 일관된 텍스처 방향과 시드 위치를 사용한다. 회전한 높이 무늬에 맞춰 패킹 법선을 역회전한다. 타일마다 모래 바람 방향이 뒤집히지 않는다.
- 정점에서 계산하는 넓은 변화장으로 무늬 좌표를 완만하게 휘고 암반 노출·퇴적물 면적을 바꾼다. 기본 지역 크기는 42m, 대표 계열은 34~55m다. 실제 온도·눈/물 분포·광물·생태 판정은 기존 값을 사용한다.
- 더 넓은 풍화색은 미세 노멀이 사라지는 거리에도 유지한다. 미세 잡음을 색상에 덧씌우지 않으며 INK 윤곽·3단 조명은 변경하지 않는다.
- 사막·충돌 암석·빙결의 기존 Blender 장식은 방향 정렬을 완화하고 가로세로 비율을 0.85~1.18로 변주한다. 네 메시·MultiMesh 묶음·후보 좌표와 난수 소비 순서를 유지한다. 새 바위 모델을 제작한 것은 아니다.

보조 퇴적물은 원래 퇴적물 읽기를 대체하며 새 혼합 레이어를 추가하지 않는다. 복원 지면은 기존과 같이 실제 환경 상태가 승인한 개량토/선구 피복을 우선한다. 회전 법선은 일치하지만 완만한 좌표 휨의 미분까지 법선에 보정하는 방식은 아니며, 실제 형상·침식 시뮬레이션과도 구분한다.

## 변경·갱신 범위와 성능 경계

행성 진입 때 해당 행성의 재질만 배열로 만든다. 지역 없는 행성은 최대 5장, 지역이 있는 행성은 최대 7장이다. 1024² RGBA8+mip의 7장 원본 용량은 약 37.3MiB이고 복원용 512² 두 장까지 약 40MiB다. 이전 최대 6장보다 자연 지면 한 장 약 5.3MiB 증가하며 전체 게임 VRAM 실측값은 아니다. 43장을 모두 상주시키지 않는다. 기존 약한 참조 캐시와 32개 항목 상한을 유지한다.

렌더 재질의 구성은 착륙 장면 초기화에서 수행하고, 이동·건설·환경 변화마다 재구성하지 않는다. 새 무늬 변화는 GPU 정점 계산이며 제어 텍스처 생성·지형 작업 스레드·별도 드로 패스를 추가하지 않는다. 장식 변주는 기존 타일 생성 시에만 계산한다. 건설·철거는 기존 건물 발자국과 겹치는 타일만 갱신하고, 동일 스냅샷은 갱신을 예약하지 않는다.

도메인·호스트 거래·저장·네트워크는 수정하지 않는다. 기존 전체 체크포인트의 검증/직렬화 비용은 그대로이며 이 변경을 저장 성능 개선으로 기록하지 않는다. 물리 지형·굴착·시설·광맥·사건 좌표·원산지·기존 원정 파일은 보존한다.

## 실제 확인

- Blender 5.2.1 LTS Cycles에서 18종 원본 렌더 완료. Godot 4.7.2 Metal Forward+에서 동일 회색의 18종 INK 비교를 확인했다.
- 현재 43종 카탈로그와 12개 계열의 시드 선택, 지역 없는 배열 최대 5장과 살아 있는 배열 재사용을 확인했다. 이어 12계열 × 24시드에서 신규 18종 모두의 선택 가능성·최대 7장·JSON 재현·입력 행성 정의 불변·오래된 지형의 지역 규칙 제외를 확인했다. [선택 기록](media/surface-expansion/selection.json).
- 실제 `CrewSurfaceScene`의 사막·충돌 암석·빙결에서 같은 시드·좌표·조명으로 전후를 촬영했다. 근경 청크 75개씩, 원경 타일 100/100/110개, 장식 149/378/183개와 착륙 바닥 높이·공유 재질 연결을 확인했다. 전후 각각 관련 확인 20개, 실패 0이었다. 준비된 임시 호스트/고정 카메라의 실제 지상 장면이며 일반 플레이 전체를 완주한 검사는 아니다.
- 건설·철거 검사는 현재 거래 완료를 기다리고, 실제 장식이 있는 배치 가능 좌표와 반환 재료용 창고를 준비하는 방식으로 검사 도구를 정정했다. 검사 도구가 공급한 재료가 진행 중인 이전 저장 초안으로 교체되던 문제를 해결했으며, 현재 원정의 건설 규칙이나 반환 공간 요구를 완화하지 않았다.
- 마지막 `--construction-only` 실행에서 실제 태양광 건설·철거와 주변 장식 제거/복구, 기존 타일 유지, 무관한 MultiMesh 유지, 동일 스냅샷 갱신 생략 등 **18개 확인, 실패 0**이었다. [범위 기록](media/surface-expansion/construction.json). 종료 시 ObjectDB 인스턴스 1개 경고가 남았으며 최종 실행의 스크립트/셰이더 오류는 없었다. 원거리 충돌 스트리밍을 기다리는 장식 타일은 런타임의 `presentation_ready()` 기준으로 구분하고, 재질 변경과 관계없는 전체 지형 무효화 검사는 최종 범위에서 제외했다.

첫 비교 실행의 정지 장면 단발 중앙값은 사막 46.17→53.67ms, 암석 18.65→31.03ms, 빙결 30.89→29.83ms였다. 다른 제작 작업과 실행 환경 변화가 있었고, 사막 첫 촬영은 창 크기 전환으로 실제 출력 약 2393~2396×1496~1498, 다른 두 장면은 1280×800이었다. 원시 보고서의 공통 `1280x800` 설정 문자열로 모든 촬영의 실제 해상도가 같았다고 해석하지 않는다. 이 값으로 추가 비용이 없다고 주장하거나 게임 전체 FPS 증감률을 계산하지 않는다. GPU 시간은 제공되지 않았다.

후속으로 같은 충돌 암석 장면·동일 텍스처 배열에서 새 무늬 처리를 끔→켬으로 한 번 비교했다. 실제 출력은 두 구간 모두 1280×800, 드로 콜은 모두 420이었다. 준비 30프레임 뒤 각 90프레임의 중앙값은 44.62→39.31ms, p95는 54.18→64.17ms였다. 중앙값과 긴 프레임의 방향이 달라 비용을 확정하거나 성능 향상으로 해석하지 않는다. 추가 패스가 없다는 점과 큰 실행 변동을 확인한 단발 정지 비교이며 실제 보행 FPS 보장은 아니다. [원시 비교](media/surface-expansion/shader-cost.json).

검사 도구의 `MemoryWorldStore`도 일반 거래/자동 저장의 새 진입점까지 메모리 저장으로 연결하고 경로를 검사 폴더로 고정했다. 첫 실행에서 기본 저장 경로에 만들어진 두 검사 파일은 시드 71491과 검사 캐릭터가 일치하는 것을 확인해 작업 폴더로 옮겼다. 기존 보존 파일은 건드리지 않았으며 후속 실행에서 기본 경로에 검사 파일이 생기지 않는 것을 확인했다.

남은 범위: 수동 보행 중 장시간 프레임·전 계열 플레이·협동/재접속·전체 회귀·발소리 청취는 이번 확인에 포함하지 않았다. 기존 원거리 지형 LOD 경계와 암벽의 거친 내부 윤곽은 남아 있다.
