# 현지 서식종의 특이 개체 사건

2026-09-09 사용자 승인. [사건 소관 규칙](../game/21-exploration-incidents.md)의 부품 수집·둥지 보호·동굴 성체·거대 이동·희귀 색 변이 다섯 유형을 실제 현지 계통과 연결한다. 거대 이동 개체는 사용자 후속 요청에 따라 기본 외형의 세 축 모두 4배다.

## 구현

`native_incidents.json`에서 역할별 최소 티어·서식층·가능한 체형·크기·이동/관찰·보상과 T1~T5의 성체/대형/이색 가중치를 관리한다. `FrontierNativeIncidents`는 이미 해당 행성에 선정된 동물 계통 중에서 사건 ID와 생태 시드로 고른다. 지표 사건은 지표종, 동굴 사건은 동굴종만 사용하며 적합한 종이 없으면 생성하지 않는다. 외계의 다른 종을 임의로 끼워 넣지 않는다.

- T1 부품 수집: 입에 물린 기존 부품 모델, 흔적, 실제 이동, E 분석과 경로 진행 조건 후 F 은닉품 회수.
- T2 둥지 보호: 같은 종의 작은 개체 둘, 접근 경고 → 방어 공격 → 이탈 시 중단. 안전 거리에서 분석하면 먹이를 찾아 이동하고 현장 보상을 회수할 수 있다.
- T2 동굴 성체: 기존 시드 공동의 바닥 경로와 천장 여유를 검사해 배치한다. 동굴을 새로 파거나 구조를 바꾸지 않는다. 저음·발자국·분석·개체와의 거리로 회수 조건을 연결한다.
- T3 거대 이동: 선형 4배, 실제 체형 크기의 충돌 상자, 몸집을 반영한 관찰 범위. 신체 주변 지형 기복을 검사한 이동로만 사용하고 크기에 따라 느린 보행을 적용한다. 이색 변이와 함께 나와도 4배를 유지한다.
- T3 희귀 색 변이: 원래 종의 제한된 색조 변화, 가까이 다가가면 빠르게 이동, 거리를 두고 분석한 후 탈락물 회수.

종/기본 외형 ID·배율·색·이동 거리·방향·경고·관찰·수령을 호스트가 저장하고 잘못된 개체 정보를 거절한다. 관측은 원래 생태 계통에 기록하고 J 사건 상세는 해당 변이의 모델·이름·높이·기본 대비 크기와 실제 재료 보상을 보여준다. 회수는 기존 소재/보석과 개인 소유 랜덤 모듈로 연결되며 한 장소에서 중복 지급하지 않는다. 이미 기록된 예전 부품 수집 사건은 당시 형태/동작으로 남긴다.

## 재사용 자산과 표현

기존 Blender 생물 카탈로그의 실제 GLB·재질·가동부를 재사용한다. 새 종 모델이나 기존 생물 전체 리모델링을 제작했다고 기록하지 않는다. 원래 계통의 색을 바탕으로 이색 개체만 색조를 바꾸며 일반 개체·도감 기본 외형은 유지한다. 같은 종의 기본 개체와 특이 개체를 Godot Forward+ INK 스튜디오에서 나란히 렌더링했다.

[부품 수집 비교](media/native-incidents/scavenger.png) · [4배 거대 비교](media/native-incidents/giant.png) · [둥지 보호 비교](media/native-incidents/guardian.png) · [지하 비교](media/native-incidents/cave.png) · [색 변이 비교](media/native-incidents/rare.png).

둥지/부품/결정 탈락물은 기존 사건용 Blender 자산을 재사용한 첫 표현이다. 흔적은 체형별 발자국·발톱·홈의 간소화된 지면 메시이며 발과 지형에 맞춘 완전한 보행 IK·흔적 변형은 아니다. 기존 ElevenLabs 생물 소리를 크기에 맞춰 낮은 피치로 재생하며 새 거대 생물/종별 음원을 생성한 것은 아니다. [재사용 음원 목록](../../audio/manifests/native-incidents-reuse.json)을 따른다.

## 확인

`check_native_incidents.gd`의 최소 도메인 확인 55개를 통과했다. 다섯 역할의 실제 현지 계통·시드 재현·JSON 저장·변조 거절·4배 크기·재료 유효성·중복 보상 거절·둥지 경고/방어 타격/후퇴/관찰 후 이동·기존 기록 보존을 확인했다. `prepare_native_incident_play.gd`로 실제 생성 타일에서 다섯 유형 모두를 찾았다.

실제 화면은 `check_native_incident_play.gd -- --crew-ui-test --crew-folder=/tmp/native-event-play --role=...`의 격리 저장에서 확인한다. 시작 위치만 자연 발생 사건 근처로 옮기고, 실제 E 관찰·이동 조건·F 회수·개인 모듈 소유·J 상세·저장/다시 열기를 사용한다. 자연 보행으로 사건까지 찾아가는 전체 원정 검증과 구분한다.

부품 수집 15개·거대 역할 15개·둥지 보호 16개·지하 15개·희귀 색 변이 15개 실제 확인을 통과했다. 첫 거대 배치에서 이동로 끝의 급경사 때문에 관찰 범위를 벗어난 문제를 발견해 몸집 주위의 지형 기복을 검사하도록 고쳤다. 수정 후 자연 위치에서 실제 회수/저장까지 확인했다.

지하 실제 실행에서 근처 지진 사건의 음수 회전각이 기존 저장 검증의 0~TAU 범위를 벗어나는 오류를 발견했다. 지진 생성 각도를 정규화하고 같은 위치에서 생물 분석·보상·저장을 다시 확인했다. 새 타일 준비 검사도 생성 기록의 저장 유효성을 확인한다.

희귀 개체의 첫 화면 검사에서는 회수 요청이 한 차례 확정되지 않았다. 실패 응답 기록과 조기 종료를 검수 도구에 보강한 재실행에서는 전체 회수·저장이 통과했으며, 첫 미확정의 원인을 해결했다고 주장하지 않는다.

## 남은 범위

전 시드·전 종의 발 접지/동굴 여유 전수 검수, 살아 있는 특이 개체 포획·이식, 종별 새 음향·고유 생체 아이템, 무리 이동/생태 먹이사슬은 포함하지 않는다. T4/T5는 기존 사건의 특별 개체 비중이 증가하며 새로운 고티어 생물 시나리오 전체를 구현한 것은 아니다. 모듈은 현재 T3까지다. 6인 동시 실행·Windows 실기는 이번 최소 확인에 포함하지 않는다.
