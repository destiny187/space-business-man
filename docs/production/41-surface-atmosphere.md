# 행성 지상 하늘·지역 테라포밍 대기

## 후속 확정 — 낮밤·태양·별 이동·구현 전

2026-09-07 사용자는 정적인 하늘을 개선하되 **낮밤과 태양·별의 이동까지 포함**하도록 확정했다. [I5·Q7 결정 이력](../planning/09-ground-play-feedback.md). 구름/안개 이동만 하는 초기 추천안에서 범위를 확대한다. 아래 시드 구름은 시간 이동이 없는 기존 구현이다. 환경값에 따른 색·농도 전환과 시간에 따른 하늘 움직임은 다른 기능이며, 이번에 애니메이션이나 낮밤을 추가하지 않았다.

구현 설계 제안:

최신 사용자 확정은 항성계의 현실적 조건 안에서 낮밤 규칙을 시드로 정하는 것이다. 물리 주기·동주기 예외·공유 시계·시간 압축·기존 우주 공전과의 연결은 [시드 천체 시간 명세](../technical/08-seeded-planetary-cycles.md)를 원본으로 한다. 아래는 표현 방향이며 주기 수치를 별도로 재정의하지 않는다.

- 행성 시드와 호스트가 공유하는 시간으로 낮밤 위상을 정하고 태양의 겉보기 위치, 방향광·그림자, 수평선/환경광을 일치시킨다. 같은 지역의 참가자들이 동일한 시간대를 보게 하고 저장·재접속으로 낮으로 초기화하지 않는다.
- 별의 겉보기 이동은 같은 하늘 시간에 연결하며 대기와 주광에 맞춰 가시성을 조절한다. 진공에는 구름을 생성하지 않고 태양·별 이동과 광원 변화로 시간 흐름을 드러낸다.
- 대기가 있는 행성의 구름/안개 흐름은 기존 시드 분포와 테라포밍에 따른 대기량을 유지하며 움직인다. 구름만 움직이고 태양·조명이 정적인 상태를 이번 확정 범위의 완료로 기록하지 않는다.
- 밤의 탐험·채광·건설 대상과 시설 상태는 기존 도구·작업등 및 FIELD/INK 가독성 기준으로 확인한다. 태양광 발전의 야간 감소·축전은 별도 운영 규칙이므로 시각 주기 추가만으로 기존 생산을 임의 중단하지 않는다. 발전 영향·낮밤 길이·행성별 자전 차이는 구현 설계에서 정한다.
- 실제 구형 행성 물리·위성 궤도 전면 재현·강수/폭풍 등 날씨 시뮬레이션은 이번 답변으로 확정되지 않았다. 성능 집중 안정화는 후순위로 유지하고 반복 환경 갱신 비용을 제한한다.

2026-09-07 사용자 요청: 행성별 하늘과 테라포밍에 따른 대기 형성·개선이 지상에서 보여야 한다.

## 기존 상태와 변경

기존 공동 탐험 장면은 행성의 바다·먼지 색으로 정적인 하늘색을 정했지만, 지역 사업의 환경 수치를 하늘에 연결하지 않았다. 초기 행성별 안개 농도도 매 프레임 `.0007`로 덮였다. 구 캠페인의 하늘 셰이더 존재를 현재 탐험의 구현 완료로 보지 않는다.

현재 `surface_atmosphere.gd`가 호스트 지표 패킷의 환경값을 받아 `surface_sky.gdshader`와 안개·환경광·태양광 색을 갱신한다.

| 조건 | 지상 표현 |
| --- | --- |
| 진공·희박한 대기 | 어두운 천정·수평선, 더 선명한 별, 낮은 대기 안개·환경광 |
| 기압 증가 | 대기 산란을 표현하는 하늘빛·수평선 밝기 증가, 별 감쇠 |
| 독성 높은 대기 | 행성 고유 먼지색의 하늘·탁한 원경 안개 |
| 독성 감소·온도 안정 | 푸른 하늘·밝은 수평선, 오염 안개 완화 |
| 물·온도·기압 조건 확보 | 부드러운 구름 생성·증가. 분포는 행성 시드로 재현 |
| 지하 | 실제 지역 지표 높이를 기준으로 어두워짐. 음수 고도의 지상과 동굴을 구분 |

색·농도·반응 시간은 `data/surface_atmosphere.json`의 게임 표현값이며 실제 기체·기후 계산식이 아니다. 산소는 기존 생존/평가 수치를 유지하며 하늘의 푸른색을 산소량 자체로 정하지 않는다. 태양계 참조 행성은 기존 테라포밍 금지를 유지하고 고유 환경으로 표시한다.

## 범위·성능·보존

현재 실제 환경 시뮬레이션은 지역 복원 사업 단위다. 개발 반경 안에 온전히 반영하고 반경의 3배 거리까지 원래 하늘로 부드럽게 돌아간다. 작은 시설 하나로 행성 전체 대기가 바뀌었다고 표현하지 않는다. 광역 대기 순환·전체 행성의 궤도 외관 변화·날씨/강수 시뮬레이션은 이번 범위가 아니다.

전환은 약 4초의 지수 평활로 이어진다. 초기 진입은 저장된 현장 환경을 즉시 읽고, 이후 패킷 변화는 점진적으로 반영한다. 하늘은 `TIME` 없는 시드 구름을 쓰며, 균일값을 양자화해 0.2초 간격으로 실제 차이가 있을 때만 갱신한다. 기존 지형 LOD·INK 모델·그림자·개인 안개 설정을 유지한다. 프레젠테이션은 환경 원장을 변경하지 않는다.

## 확인 범위

`tests/check_surface_atmosphere.gd`는 별도 세계로 실제 착륙 후 동일 위치·시점에서 진공/오염 대기/복원 대기 상태를 호스트 지표 패킷으로 전달한다. 대기 형성·구름·오염 안개 감소, 지역 밖 고유 환경 복귀, 지하 환경광과 안개 옵션을 확인한다. Godot Forward+ 캡처는 로컬 `test-results/surface-atmosphere/sky-stage-0/1/2.png`에 둔다. 설비 수백 초 가동·전체 행성 전수·다중 클라이언트 회귀 검사는 수행하지 않는다.
