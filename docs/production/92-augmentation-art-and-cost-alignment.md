# 강화 일러스트·SVG·재료 정렬 개선

2026-09-09 사용자 요청: ImageGen으로 강화 이미지를 고도화하고, 스탯 비교 화살표를 없애 증가분만 표시하며, SVG 아이콘과 건설 재료 중앙 정렬을 개선한다.

## 실제 변경

- 내장 `image_gen.imagegen`으로 기동의 다리·전투의 팔·생존의 흉부 일러스트 3장을 제작했다. 기존 탐험복의 크림·청록 외장과 주황 잠금장치를 참고하고 3단 카툰 명암·검은 윤곽을 유지했다. 각각 1536×1024 PNG이며 강화 상세의 작은 장치 미리보기 대신 계열별 이미지로 표시한다.
- 사용자가 명시한 ImageGen 교체는 **강화 능력 설명용 그림**에 적용한다. 실제 장비·캐릭터·장치의 Blender 모델을 변경하거나 새 외형 장착을 의미하지 않는다. 일반 아이템의 회전 모델 미리보기는 유지한다.
- 기존 단선 기호를 64px 원본의 SVG 12종으로 개선했다. 신발·장갑·흉부·배터리·호흡기·발사부·광석·굴착기·방패·회복/시간 모티프에 검은 경계, 밝은 외장, 중간 명암과 계열색을 사용한다. 트리는 32px 아이콘을 사용하며 I의 신체 목록도 같은 아이콘을 공유한다.
- 상세 수치는 **이번 한 단계로 얻는 효과** 하나만 표시한다. 예: 이동속도 +10%, 점프 높이 +12%, 낙하 피해 -12%. 현재 누적 효과는 툴팁과 I의 신체 목록에 유지하며, 최고 단계에서는 누적 효과를 표시한다. 강화 완료 알림도 화살표 없이 최종 단계만 표시한다. 비용·선행 조건·효과 계산·저장 형식은 변경하지 않는다.
- 장치의 실제 보석·트레이·스캔 동작과 기존 ElevenLabs 처리/성공/실패 연결을 유지한다. 이미지로 가려진 3D 미리보기의 지속 렌더는 중단한다. 그림 아래 상태 띠와 슬롯·메시지가 준비/진행/결과를 표시한다.
- 건설 카드마다 필요한 재료와 선택 시설의 보유/필요 재료를 중앙 정렬했다. 기존 재료 아이콘과 빨간 부족 수량은 유지한다.

## 제작 파일과 프롬프트

내장 ImageGen 사용. CLI나 외부 API fallback을 사용하지 않았다. 세 이미지의 공통 프롬프트와 계열별 전체 프롬프트, 원본 참조와 생성 경로는 [generation.json](../../우주-비즈니스/assets/ui/augmentation/generation.json)에 기록했다. 생성물을 편집하거나 재압축하지 않고 프로젝트에 복사했다. Git LFS의 기존 PNG 규칙을 따른다.

## 확인 범위

Godot 4.7.2 Metal Forward+ / Apple M2의 현재 기본 장면에서 3개 계열 선택, 실제 강화 거래 한 번, 사파이어 3개 차감, 새로운 이미지 전환, 숨긴 3D 렌더 중단, 1280×800·960×640 화면, 착륙 후 건설 비용 중앙 정렬을 확인했다. 작은 창에서 스탯이 상세 스크롤 아래로 밀리던 문제를 발견해 이미지 높이와 중복 배낭 표시를 줄였고, 상승분이 스크롤 없이 보이는 것을 재확인했다. 필요한 보석 수량/보유량은 고정 투입 영역에 남긴다.

[실행 기록](media/augmentation-art/play.log)의 화면/강화 확인 12개는 통과했다. 마지막 종료 확인은 임시 검사 배낭을 만들 때 필수 0개 재료 키를 빠뜨린 fixture 오류였다. 제품 저장 코드의 오류가 아니다. fixture를 공통 inventory()로 수정하고 **같은 격리 저장의 종료·다시 읽기와 구매 단계 보존만** 별도로 확인하여 통과했다([기록](media/augmentation-art/save.log)). 사용자 저장에 접근하지 않았다. 전체 회귀·다중 클라이언트·효과음 청감 전수 검사는 실행하지 않았다.
