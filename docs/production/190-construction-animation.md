# 클릭 설치의 홀로그램 조립 연출

2026-09-14 사용자 정정: 원래 요청은 건물 외형이 아니라 **클릭해서 짓는 순간의 애니메이션·이펙트**였다. 189에서 고도화한 9종 모델은 그대로 유지하고 설치 연출을 추가 개선했다. 누구든 자기 배낭 재료로 건설한다. “호스트 승인”은 방장의 수동 허락이 아니라 기존 서버의 배치·비용·저장 판정이다.

## 실제 연출

기존의 즉시 완성 모델 + 원형 발광/입자를 새 건설에 한해 교체했다. 기초 모서리 고정 → 실제 건물 형태의 반투명 홀로그램 → 위로 이동하는 조립 프레임과 접합부 빛/불꽃 → 완성 재질·가동부 복귀 순서다. 1.8초 연출 중에도 플레이 입력과 기존 시설 규칙은 유지한다. 전투 엄폐물은 원래 조립 시간·충돌 개방 시점을 유지한다.

- 실제 Blender 모델 메시를 재사용한다. 같은 모델의 다른 설치물이나 미리보기 재질은 수정하지 않는다.
- 불투명 INK 표면에는 인스턴스별 높이 절단을 사용하고, 투명 유리 등은 완성 단계에서 복귀한다. 새 별도 건물 모델/음원 제작은 없다.
- 기존 ElevenLabs `sfx_build_place`는 시작, `sfx_factory_complete`는 종료에 낮은 음량으로 연결한다. 생성 출처는 `audio/manifests/elevenlabs.json`이다.
- 원정의 서버 저장 반영 패킷에서 새 건물 ID를 발견했을 때만 시작한다. 비동기 모델 로딩이 끝난 뒤 연출하며 저장 불러오기·실패·같은 패킷의 재수신에는 재생하지 않는다.
- 같은 현장의 관찰자도 같은 새 건물 변경을 받아 연출한다. 멀리 있는 건물은 생략하며 한 화면 최대 6개, 60m 이내, 모델 대기 최대 5초다. 수치는 `data/construction_presentation.json`에 둔다.

## 확인과 범위

Godot 4.7.2 Forward+/Metal 실제 원정에서 B 선택·고스트·회전·설치·배낭 비용 한 번 차감·모델 연결·시작/종료 음원 재생 호출·셰이더 복귀·실패 무연출·중복 패킷 무연출·저장 재읽기 **23항목 통과**. 단계별 사진은 실제 설치 연출을 일시 정지해 각 시점을 촬영했다. 개인 저장과 실행 중인 사용자 게임은 수정하지 않았다. [검사 출력](media/construction-effect/play-check.txt).

태양광 설치를 직접 검수했다. 다른 건물은 같은 모델 경계/재질 경로를 사용하지만 모든 건물별 미적 검수·6인 외부망 시간차·주관적 청음 판정은 완료로 기록하지 않는다. 설치 도메인이나 연구/비용은 변경하지 않았다.

## 단일 행동 범위

기존 패킷의 신규 ID 비교 → 해당 ID의 모델 준비 → 그 모델의 메시만 1회 열람 → 짧은 인스턴스 파라미터/프레임 갱신 → 자동 해제다. 원본 재질·전체 지형·다른 모델을 재생성하지 않는다. 연출 중에만 해당 모델의 홀로그램 사본·프레임 20개와 16개 불꽃 MultiMesh가 추가된다. 가동 관절과 가림 메시를 잠시 보류하고 완료/제거 시 복귀한다. 성공 전에 연출하거나 추가 저장/네트워크 메시지를 보내지 않는다.

```sh
tools/godot.sh --script res://tests/check_construction_effect_play.gd -- --crew-ui-test --crew-folder=/tmp/construction-effect-play
```

착륙한 테스트 원정의 `world.json`·`profile.json`을 위 격리 폴더에 준비한다. 테스트는 해당 격리 저장에 건물 1개를 추가한다.
