# 항성 발광·궤도 표현·우주선 추진 상태

2026-09-07 사용자 요청: 별의 발광, 행성 크기 차이와 느린 공전, 우주선 체력·고속 이동 스태미나, 비행/고속 비행의 불빛·사운드를 연결한다.

## 실제 변경

- 항성 표면에 HDR 발광·작은 표면 변화, 주위에 가산 혼합 코로나·광선과 Glow를 적용했다. 항성 위치의 광원이 행성·우주선을 비춘다. 기존 상수 방향광은 약하게 남긴다.
- 태양계 게임 반지름은 수성 110 / 금성 250 / 지구 270 / 화성 155 / 목성 1,050 / 토성 850 / 천왕성 540 / 해왕성 520으로 차등화했다. 일반 암석형과 거대행성도 다른 크기 범위를 사용한다. 현실 축척·실제 천체력 수치가 아닌 게임용 조정값이다.
- 궤도마다 시드 기반 4~17도 기울기·승교점 방향을 적용하고, 같은 항성 원점을 중심으로 공전한다. 기존 공전 주기는 유지하며 스냅샷 사이에도 화면의 궤도 시간을 부드럽게 진행한다. 행성 간 크기 차이에 맞춰 궤도 간격과 비행 경계 32,000을 넓혔다.
- 조정 원본은 `data/space_presentation.json`이다. 현재 저장에도 표현 좌표/크기가 적용되며 행성 ID·지질·건물 기록은 바꾸지 않는다. 변경 전 비행 위치는 보존되므로 목적지를 다시 접근하면 새 궤도에 맞춰진다. 별도 천문학적 실측 정보와 구분한다.
- 원거리 태양계 LOD 재질명이 `.001`로 끝나 정점색이 꺼지던 오류를 수정했다. 가까이서만 색이 보이고 멀리서는 하얗게 보이던 문제를 실제 렌더로 확인했다.

## 선체·추진

선체 체력과 추진 에너지는 호스트 항해 상태에 저장하고 HUD에 표시한다. 초기값 100, 기존 저장에 없으면 기본값을 적용한다. W+Shift로 고속 추진하며 에너지를 소모하고, 일반 비행·대기 중에는 자동 충전한다. 성간 항해는 에너지 30을 사용하지만 화폐·아이템을 요구하지 않고 충전 후 다시 이용할 수 있다. 초기 속도·재충전·소모·수리율은 `galaxy.json` 비행 설정의 조정값이다.

빠른 천체 접근 충돌은 선체 피해를 주고 이동을 막는다. 체력이 0이면 추진·출발을 중단하고 피해 후 대기 시간을 거쳐 응급 수리한다. 충돌 보호 시간으로 매 프레임 중복 피해를 막는다. 함선 파괴·잔해·전투 무기 피해는 이번 범위에 포함하지 않는다.

기존 Blender Kestrel의 실제 노즐 위치에 GPU 배기 입자와 청색 광원을 연결했다. 일반 이동보다 고속 추진·성간 항해에서 분사 길이와 조명이 강해지고 시야각도 넓어진다. 기존 ElevenLabs 추진 루프의 음량·피치를 강도에 연결하고 정지하면 멈춘다. 충전/진입 및 충돌 알림음도 기존 자산을 재사용한다. 새 전용 엔진 음원이나 새 선체 GLB는 제작하지 않았다.

## 최소 확인

크기 차이·궤도 기울기·시간에 따른 공전·추진 소모/충전·충돌 피해·응급 수리·저장 검증과 입자/음원 재생을 확인했다(12개 확인, 실패 0). [항성계 렌더](media/space-polish/solar-light-orbits.png), [배기광 렌더](media/space-polish/boost-exhaust.png)는 Godot Metal Forward+의 실제 모델 화면이다. 음원 재생 연결을 확인했으며 청취 품질 비교·장시간·다중 클라이언트 검사는 수행하지 않았다.
