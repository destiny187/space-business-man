## 기본종과 외형 변이

추가 레시피는 동물 4,900·식물 1,400·미생물 700이다. 동물의 기존 14가지 몸 조직과 7가지 기관계 조합 중 140종을 조류형으로 분화하고, 식물의 28가지 성장 구조, 미생물의 14가지 군락 구조로 140개 제작 그룹을 구성한다. 각 그룹은 주요 기관 수·배열·몸 조직·환경 적응 구조를 바꾼 50개 기본형을 가진다. **140개 모두가 서로 무관한 수작업 원형이라는 뜻은 아니다.**

2026-09-11 후속으로 동물 98그룹의 중앙 두 슬롯, 196종을 식별 가능한 28체형으로 교체했다. 각 체형은 7기관 계통을 공유하므로 계통 안의 외형 유사성은 남는다. 28종에는 기존 조류 리깅을 확장한 섭금류·올빼미형도 포함한다. 구성 코드는 83유형, 해부 체형 구분은 85유형이다. 체형별 눈과 얼굴 세부 수정은 [교체 제작 기록](129-biota-midpoint-silhouettes.md)을 따른다.

이름·색·전체 크기만 바꾼 것은 기본종에 포함하지 않는다. 기본형당 20개 색/크기 외형은 별도 집계한다. 미생물 모델은 육안으로 보이는 군락·생물막 표현이다. 세포 하나를 동물 크기로 확대해 자연 배치한 것으로 취급하지 않는다. 전체 유형과 환경별 레시피 수량은 [생물 유형 색인](126-biota-type-index.md)을 따른다.

## 환경 적응

종마다 기존 18개 행성 유형 중 원산 환경을 지정한다. 같은 환경을 공유하는 여러 행성 가운데 자연 원산지는 한 곳으로 배정한다. 적응 유형은 모델과 별개 이름표가 아니라 차열판·단열 주름·저수낭·기질 접촉면·감각면·부력막 등의 실제 형상에 연결한다. 지표·지하와 실제 온도·압력·수분 조건도 검사한다.

- 고온·노출 암반: 몸과 연결된 광물성 보호판과 보호된 개구부.
- 건조·염류·알칼리: 두꺼운 저장낭과 외부 기질 교환을 제한한 통로.
- 냉각·동결: 겹친 단열막과 보호된 내장부.
- 퇴적·온대: 넓은 접촉면·여과 구조·집광/감각면.
- 지하: 차광 환경과 길어진 촉각. 지표의 가상 극한 온도를 지하 온도로 그대로 사용하지 않는다.
- 거대행성 대기: 지상 접지부 대신 부력낭·평형막·현수 여과기관. 궤도 관측 대상으로 구분하며 착륙·지상 표본 채집을 제공한다고 기록하지 않는다.

## 유형별 골격과 웨이트

사용자의 추가 확정에 따라 제작 중 강체 피벗만 사용하던 방식을 확장했다. `tools/bestiary/biota_rig.py`는 83가지 구성 유형에 축형·분절형·방사형·입상형·교각형·판상형·나선형·쌍열형·물결형·분지형·조류 흉곽과 사지형·도약형·절지형·뱀형의 15가지 골격 배치를 지정한다. 140개 제작 그룹은 해당 몸 조직과 실제 기관 수·위치·부모 관계를 조합한 리깅 템플릿을 사용한다.

조류형 140종에는 별도 흉곽 조직 본과 부모 관계로 연결한 날개 어깨·팔꿈치·손목, 고관절·무릎, 조향 꼬리를 적용한다. 중앙 체형 교체 후 전체 리깅 템플릿은 343개다. 지상 대기압 50kPa 이상인 지정 기질에서만 배정하며, 동일 행성의 고유종 규칙을 유지한다. 48초의 결정적 주기로 휴식 12초·이륙 5초·순회 비행 26초·착륙 5초를 적용한다. 실제 날갯짓은 유형별 1.25~2Hz, 반경 4.5~6.5m와 높이 4~5.4m의 초기 게임 수치다. 지형 높이 위로 비행하고 출발한 접지 지점으로 돌아온다. 플레이어 운송 외래종은 격리 구획 안에서 휴식한다. 독립 먹이사슬·무리 AI·공중 교전·나무 착지는 이번 범위가 아니다. 지상 이동 사건의 후보에는 조류형을 배정하지 않는다.

유연한 주 조직에는 여러 본의 스킨 웨이트를 적용하고, 단단한 기관은 자체 관절 본에 결합한다. 원본 `.blend`에 Armature·본·웨이트를 보존한다. 게임은 기본 자세 위에 유형별 조직 변형과 해당 기관의 동작을 적용하며 두 LOD가 같은 자세를 사용한다. 무작위 ID나 색이 골격을 결정하지 않는다.

이 방식은 7,000종 각각을 수작업으로 웨이트 페인팅하거나 모든 관절에 발 접지 IK를 작성했다는 뜻이 아니다. 유형별 절차적 골격과 웨이트가 실제로 보존되고 움직이는지를 검수한다. 기존 1,000종 원본을 이번 작업에서 일괄 교체한 것도 아니다. 기존 생물의 리깅 상태는 별도 이력으로 유지한다.

다섯 상태의 리깅 검수와 원정에서 상태가 선택되는 조건은 구분한다. 조류형은 별도 비행/착지 순환을 사용하고 비공격 생물 사건은 해당 이동 동작에 연결된다. 지상 동물의 배회·회피와 창 비활성 시 정지는 별도 현장 행동 코드가 상태를 선택한다. 이 문서의 수량·리깅 완료를 모든 야생동물의 사냥·먹이사슬 AI 완료로 해석하지 않는다. 공격 동작이 없는 종을 둥지 수호자에 강제 배정하지 않는다.

제작 도감은 `tools/godot.sh res://scenes/showcase/bestiary.tscn -- --biota`로 새 생물부터 열 수 있다. 유형·변이·동작·거리별 모델을 선택해 확인한다. 일반 플레이의 발견 기록은 J 연구/도감에서 실제 원산 행성의 모델과 관측 층을 표시한다.

![대표 네 체형의 실제 게임 골격](media/biota/rigs/type-rig-board.jpg)

위 화면은 연쇄체·방사체·양치형·권곡 군락의 Godot Skeleton3D 본 위치와 부모 연결을 실제 모델 위에 표시한 검수 결과다. 주황 점이 본 위치이며, 청록 선은 부모 연결이다. 바닥 기준 루트와 조직 변형용 제어 본을 포함한다. 일반 플레이에는 골격 표시를 노출하지 않는다.

## 검수와 현재 경계

Blender 원본 렌더, Godot Forward+ INK 렌더, 본·스킨 연결, 기본/이동/섭식/휴면/스트레스 자세와 두 LOD를 확인한다. 구조 검사만 통과해도 육안 렌더가 잘못되면 미완료다. 초기 스킨 적용 중 본의 기본 위치를 덮어써 형상이 뭉치는 오류가 실제 렌더에서 발견되어 기본 자세를 보존하도록 수정했다.

색과 전체 크기를 제외한 정규화 형상 해시로 기본형 중복을 검사한다. 이 해시는 형태가 얼마나 창의적인지 자동 판정하지 않으므로, 생물군별 대표 화면도 직접 검토한다. 최종 완료 수량·실제 플레이·확률은 [작업 기록](124-biota-8000-work.md)의 완료 이후 갱신한다.
