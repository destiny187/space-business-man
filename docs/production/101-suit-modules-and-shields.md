# 내장 모듈·실드 T1~T3 제작 기록

후속: 현재 5희귀도·전설 11효과는 [전설 확장 기록](102-legendary-module-effects.md)을 따른다. 아래는 최초 4희귀도 구현 당시의 확인 기록이다.

2026-09-09. [소관 규칙](../game/22-suit-modules-and-shields.md). 수치·케이스 분리·획득 가중치는 현재 조정 가능한 구현값이다.

## 연결한 범위

- `suit_modules.json`과 `FrontierSuitModules`: 6부위·T1~T3·4희귀도·부위별 기본 성능·16종 옵션, 장소별 획득 풀과 고정 시드, 개인 소유·장착·해제·분해·32칸 케이스.
- 사건 8종의 최종 보상에 모듈 1개, 조사형 발견의 장소별 35% 보상, T3 행성에서는 T3 아이템. 기존 완료 장소는 소급 지급하지 않는다. 기본 실드의 철 6/구리 4 조립은 개인당 한 번이다.
- 체력·이동·점프·운반 감속·달리기 소모·회복·채집/사격/분석 속도·무기 피해에 장비 값을 적용한다. 가방 용량 축소가 물건을 없애지 않도록 거절한다. 낙하 옵션은 추가하지 않았다.
- 실드 우선 흡수·초과 체력 피해·무피격 충전 대기·자동 재충전·발생기 교체 충전 방지·구조 시 비우기를 공통 피해 함수로 연결했다. 실제 일루티 탄과 지진 폭발이 이 경로를 사용한다. 낙하는 기존 증강 계산으로 실드를 통과한다.
- 요청의 소유자·장비 버전·배낭/케이스 여유와 저장 성공을 호스트에서 검사한다. 기존 저장은 모듈/실드 없이 시작하며, 획득 옵션·장착과 실드 현재량/대기를 저장한다.
- I 모듈 탭의 6슬롯·모델 카드·희귀도/티어·기본/랜덤 옵션·현재 장착 대비 증감·분해 확인. HUD의 실드 수치/대기·별도 게이지·피격/소진 및 다른 승무원의 순간 실드 효과.

## 모델·음원

`art/blender/tier2/`의 보강 프레임·열전달 유닛·광물 필터·제어 회로 Blender 원본 및 대응 GLB를 내부 부품의 첫 표현으로 재사용한다. 같은 케이스를 쓰는 일부 부위는 모델이 같으며 새 최종 모듈 6종 모델을 제작했다고 기록하지 않는다. 캐릭터 상시 외형은 변하지 않고 실드 피격의 일시적인 투명 효과만 별도로 표시한다.

음원은 [기존 ElevenLabs 재사용 목록](../../audio/manifests/suit-modules-reuse.json)에 기록했다. 신규 생성이나 전용 실드 음향 완성을 주장하지 않는다.

## 최소 확인

- `check_suit_modules.gd`: 실드 흡수/초과 피해/충전 대기·낙하 통과, 티어별 옵션 유효성/6부위/4희귀도, 중복 획득 거절, 수납 축소 거절, 분해, 저장 실패 원자성, 저장/다시 열기 301개 확인 통과. 저장 검사에서 JSON 숫자의 정수/실수 표현 차이로 동일 장비를 다르다고 보던 테스트 비교를 정규화했다.
- `check_suit_module_play.gd`: 자연 생성 T3 행성(시드 71491, ordinal 211372)의 일루티 사격 → 실드 흡수·체력 보존 → 실제 도구 교전·F 회수 → T3 모듈 획득 → I 장착 → 저장 21개 확인 통과. 현장까지의 이동과 초기 장비/6부위 비교 표본은 격리 검수 준비 데이터이며, 자연 보행 완주·모든 장비의 자연 드롭 실측과 구분한다.
- 실드 아이콘의 원본 최소 크기가 HUD를 밀어내던 문제와 동기식 성공 응답 뒤 대기 문구가 덮이던 문제를 수정했다. 저장 재접속 뒤 UI 부분 확인 4개 통과. 1280×800·960×640의 모델 카드·옵션·장착 결과·실드 게이지를 실제 Forward+ 창에서 검수했다. 실드 피격/획득/장착의 기존 ElevenLabs 음원 호출을 확인했으며 사람의 청감 품질 평가와 구분한다.

## 남은 범위

T4/T5 모듈, 옵션 재설정/강화, 모듈 교환/공동 창고/판매, 인간 적/PvP는 포함하지 않는다. T3 신규 사건 시나리오와 시설 설계도 획득/정거장 구매를 이 작업의 완료로 세지 않는다. 전체 행성 보행 완주·6인 실행·Windows 실기는 이번 최소 확인에 포함하지 않는다.
