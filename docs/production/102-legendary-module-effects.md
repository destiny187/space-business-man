# 5희귀도·전설 특수 효과 제작

2026-09-09. [소관 설계·11효과 목록](../game/22-suit-modules-and-shields.md). 기존 [내장 모듈·실드](101-suit-modules-and-shields.md)의 후속이다.

## 구현

- 일반·개량·희귀·유니크·전설 5희귀도, 전설의 랜덤 능력치 3개와 특수 효과 1개. T2부터 전설을 낮은 확률로 획득한다. `epic`은 기존 물건을 보존하며 표시만 유니크로 바꾼다.
- 자가복원·실드 파쇄·소진 가속·분석 충전·낙하 완충·정지 충전·운반 효율·처치 회복·완충 공격·위기 충전·과잉 회복 전환을 실제 호스트 계산에 연결했다. 수치·부위·추첨은 `suit_modules.json`에서 관리한다.
- 동일 특수 효과는 장착 부위 수와 무관하게 한 번 적용한다. 공격/피격과 장비 교체는 자가복원 대기를 초기화한다. 반복 분석이나 이미 파괴한 로봇으로 추가 발동하지 않는다.
- 실드 파쇄는 남은 기본 공격량만 체력에 전달한다. 새 T3 이상 일루티 로봇은 실드와 충전량을 저장하고 파란 방어막을 표시한다. 이전 실드 없는 로봇 기록은 유지한다.
- I 모듈의 금색 특수 효과 설명·교체 시 해제되는 효과, 순간 발동 HUD와 기존 ElevenLabs 발견 음원을 연결했다. 기존 Blender 부품·로봇 자산을 재사용하고 방어막은 일시적인 투명 효과로 표현한다. 캐릭터 외형은 유지한다.

## 확인

`check_legendary_modules.gd`의 79개 조건 확인을 통과했다. 11종의 시드 추첨·저장/로드·효과 유효성, 비전투 대기와 자기 공격 초기화, 실드 추가 피해의 체력 초과분, 낙하 잔여 피해의 곱연산, 중복 제한·가속 만료·분석 충전·운반/정지 조건·위기 대기·과잉 회복·처치·완충 공격을 확인했다.

5희귀도로 갱신한 `check_suit_modules.gd`의 301개 확인도 통과했다. 기존 소유권·장착·수납·분해·저장 실패 원자성과 이전 모듈 기능을 확인하는 해당 파일만 실행했으며 전체 테스트 묶음은 실행하지 않았다.

`check_suit_module_play.gd -- --crew-ui-test --crew-folder=/tmp/suit-module-play --legendary-review`의 실제 Forward+ 확인 26개를 통과했다. 자연 생성 T3 일루티의 실드 60 → 위상 파쇄로 소진 → 처치·F 회수로 T3 모듈 획득 → 전설 비교 표본의 UI 해제/장착 → 저장을 확인했다. 자연 회수한 물건은 T3 희귀이고, 전설 센서 코어는 정상 시드 추첨으로 만든 검수용 표본이다. 모든 전설을 자연 탐험으로 획득한 장기 파밍 검증과 구분한다.

1280×800·960×640에서 전설 이름·조건 설명·장착 결과를 확인했다. 작은 화면의 상세 능력치는 오른쪽 스크롤로 읽는다. [전설 1280px](media/legendary-modules/modules-1280.png), [전설 960px](media/legendary-modules/modules-960.png), [실제 로봇 실드·피격](media/legendary-modules/shield-hit.png). 기존 ElevenLabs 음원의 발동 경로를 확인했으며 사람의 청감 평가와 구분한다.

화면 검수의 준비 장비와 위치 이동은 격리 저장의 검수 데이터다. 먼 사건 위치의 스트리밍 대기 실패가 있어 이전에 확인한 가까운 사건으로 검수 위치를 조정했다. 해당 먼 위치의 스트리밍은 이번 모듈 확인에서 해결·검증 완료로 기록하지 않는다.

## 남은 범위

정거장 모듈 판매, T4/T5 모듈, 인간 적/PvP, 전설 외형/전용 신규 음원, 이름 고정 세트·재설정·강화·교환은 이번에 구현하지 않았다. 전체 원정 완주·6인·Windows 실기는 실행하지 않았다. T3 신규 사건 시나리오와 로스트 테크놀로지 시설 설계도 획득/판매의 완료로 세지 않는다.
