# 신규 생물 유형 색인

2026-09-10. 추가 7,000종의 제작 레시피 색인이다. 원본·내보내기·게임 검수의 실제 완료 범위는 [작업 기록](124-biota-8000-work.md), 참고 자료와 리깅 방식은 [제작 기준](125-biota-research-and-rigging.md)을 따른다.

### 조류형 140종

쌍낭체 계열의 신규 350종 중 140종은 전용 조류 체형으로 분화한다. 나머지 210종과 기존 생물 자산은 유지한다. 넓은 깃날개·낫날개·겹날개·비막·부채꼬리의 다섯 비행 구조에 7기관계를 연결한다. 대륙·툰드라·염류 분지·퇴적 분지·열수대 적응을 사용한다. 어깨→팔꿈치→손목의 날개 관절, 접이 발, 조향 꼬리, 흉곽 조직 골격이 있다. 전체 동물 수는 4,900종이고 식물/미생물과 합친 구성 유형은 중앙 체형 교체 후 83개다. 실제 제작·플레이 검수 상태는 작업 기록에 둔다.

### 중앙 두 슬롯의 28체형 교체

각 동물 그룹의 25·26번째, 196종은 사슴·거수·개과·고양이·거북·악어·장경·낙타·중갑·들소·개구리·오리너구리·천산갑·절갑·도마뱀붙이·유선 도마뱀·도약·토끼·섭금류·올빼미·거미·전갈·게·소라게·족제비·뱀·사마귀·딱정벌레를 참고한 가상 체형으로 교체했다. 각 체형에 7기관 계통을 적용하며 섭금류·올빼미 14종은 조류 140종에 포함된다. 전체 8,000종과 신규 동물 4,900종은 그대로다. 유형별 실제 골격·눈 구조·얼굴 검수는 [교체 기록](129-biota-midpoint-silhouettes.md)을 따른다.
