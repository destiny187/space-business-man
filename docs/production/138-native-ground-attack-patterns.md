# 토착 생물 지상전 — 공격별 대응 고도화

2026-09-12 사용자 승인: 기존 근접 공격의 몸짓/수치 차이를 넘어 피하는 방법과 반격 시점을 다르게 만들고 지상전을 우선한다. [전투 소관](../game/27-ground-and-flight-combat.md), [첫 교전 기반](137-native-wildlife-combat.md)을 잇는다. 아래 배정·수치는 위임된 초기 구현 선택이다.

## 현재 범위

기존 공격 지원 281종 가운데 155종의 실제 공격 방식을 변경했다. 원산 행성, 종/외형 ID, 자연 배치와 선공·영역 방어·반격·도주 배정은 유지한다. 신규 종을 추가하거나 모든 야생동물을 적으로 만들지 않는다.

| 방식 | 기본형 수 | 실제 공격과 대응 |
| --- | ---: | --- |
| 직선 돌진 | 71 | 기존 들이받기형·사슴/소/코뿔소형. 1초 준비 후 최대 9m를 12m/s로 이동한다. 준비 때 방향을 고정하고 몸의 부피와 이동 구간으로 장애물/접촉을 검사한다. 옆으로 피하거나 엄폐 뒤로 숨는다. |
| 고정 착지 도약 | 7 | 고양이형만 적용. 0.95초 준비 후 최대 6m, 높이 1.65m의 곡선으로 0.7초 동안 도약한다. 처음 표시된 착지점을 추적 수정하지 않으며 착지 반경 1.45m에 피해를 준다. 원 밖으로 이탈한다. |
| 지면 범위 내려치기 | 35 | 1.35초 준비와 0.15초 내려치는 동작 뒤 반경 4.2m를 한 번 타격한다. 정면 각도와 무관하며 범위 밖 이탈·점프·엄폐로 피한다. |
| 두 번 낫 베기 | 42 | 기존 낫 베기·사마귀형. 준비 0.85초 후 첫 타격 0.10초, 다음 타격은 그로부터 0.65초 뒤다. 각 12 피해를 독립 판정한다. 첫 타격 후에도 거리를 유지한다. |
| 기존 정면 근접 | 126 | 물기·나머지 할퀴기/집게·차기는 기존의 거리/각도 기반 한 번 타격을 유지한다. |

자료 원본은 [wildlife_combat.json](../../우주-비즈니스/data/wildlife_combat.json), 분포 집계는 [coverage.json](media/native-patterns/coverage.json)이다. 공격 지원 수는 실제 목격률이나 선공 개체 비율을 뜻하지 않는다.

돌진·내려치기 후 회복은 1.9초, 도약은 1.65초, 두 번 베기는 1.5초다. 회복 구간에 맞힌 총기는 각각 1.35배·1.25배·1.30배 피해를 준다(두 번 베기는 추가 배율 없음). 첫 피격 경직으로 회복 상태가 끝나면 배율도 종료한다. 기존 실드→체력→구조 보호를 사용하며 시설을 파괴하는 공격은 추가하지 않았다.

## 호스트 판정과 보호 경계

- [wildlife_attacks.gd](../../우주-비즈니스/scripts/domain/wildlife_attacks.gd)가 시작점·고정 목표·피격 참가자·타격 차수·이동량을 관리한다. 기존 `attack` 상태 내부의 선택 필드로 저장하며 예전 저장에는 필요하지 않다.
- 돌진/도약 이동은 최대 0.25m 간격으로 검사한다. 실제 서식 지면·몸의 공간·엄폐의 회전된 부피·해당 행성의 Godot 물리 월드를 함께 사용한다. 돌진 접촉은 실제 모델의 주둥이/뿔 길이도 포함해 몸 중심이 플레이어에 겹치기 전에 멈추며 경로 표시도 그 사거리를 포함한다. 막힌 돌진은 옆으로 자동 조향하지 않고 멈춘다. 도약은 지나갈 수 없는 지형/천장/엄폐에서 취소된다.
- 지면 위치와 공중 높이를 분리해 도약 모델·현지/원격 충돌체·총기의 표적이 같은 실제 몸 위치를 사용한다. 공중에서 무력화되면 지상으로 떨어지고 최종 지면 위치를 보존한다. 생존 중 도약의 공중 구간은 피격 경직으로 멈추지 않는다.
- 범위/정면 타격은 같은 행성의 유효 참가자마다 판정한다. 두 번 베기는 타격마다 각 참가자에게 최대 한 번, 돌진은 첫 접촉에서 멈춘다. 보호 중/착륙선 주변 참가자는 피해 대상에서 제외한다.
- 착륙선 주변 22m 안으로 돌진하거나 도약하지 않는다. 원래 안에 있던 생물이 밖으로 나가는 이동은 허용한다. 실제 게임에서 발견한 ‘안쪽에서 밖으로도 도약 불가’ 오류를 수정했다.
- 메뉴에서의 일시 정지, 체크포인트, 재실행 시 공격 취소와 지상 복귀를 유지한다. 거대/둥지 사건 개체 통합, 군집 전술, 지형을 돌아가는 장거리 경로 탐색은 추가하지 않았다.

## 표현과 소리

기존 Blender 모델/관절/스키닝을 재사용한다. 돌진의 달리는 다리·낮춘 머리, 도약의 웅크림·접은 다리와 실제 공중 이동, 내려치기의 몸/팔다리 준비, 두 번 베기의 왕복 관절 동작을 연결했다. 신규 모델·리깅을 제작했다고 기록하지 않는다.

위험 범위는 돌진 방향과 폭, 고정 착지 원, 내려치기 반경으로 표현한다. 경사진 지면에서 긴 선이 묻히지 않도록 Forward+ 데칼로 투영한다. 데칼용 벡터 무늬는 코드로 생성·공유하며 기존 풀의 먼지/고리/베기 효과를 재사용한다. 표적 HUD는 공격 준비·회피 방향·회복 중 반격 기회를 구분한다. 색과 문구만으로 실제 동작을 대신하지 않는다.

기존 ElevenLabs 생물 음원 3종을 재사용했다. 공격 준비, 돌진/도약 출발·접촉/착지, 베기 두 차수에 호스트의 누적 타격 번호로 연결해 두 번째 소리가 누락되지 않도록 했다. 타격 음원 재생 피치는 돌진 0.78·도약 1.18·내려치기 0.65·두 번 베기 1.08이며 데이터에 둔다. 새 음원 생성은 하지 않았다. 실제 SFX 출력 녹음을 보존하되 주관적인 청감 검수를 완료했다고 주장하지 않는다.

[재사용 매니페스트](../../audio/manifests/native-ground-patterns.json). 고양이형 원정 출력 18.912초·최고 -5.29dBFS, 돌진형 출력 21.408초·최고 -4.75dBFS이며 두 녹음 모두 클리핑 0이다. 환경·총기 등 함께 재생된 SFX를 포함한다.

## 실제 확인

- 기존 교전 기반 24개 확인을 통과했다. 새 판정 20개 확인은 돌진 이동/옆 회피/반복 피해 차단/엄폐/반격 배율, 도약 높이/고정 착지/착지 피해/공중 격파, 지면 후방/범위 이탈/점프, 연속 베기/두 번째 회피, 보호 구역·저장 상태를 확인한다. 이 검사의 다른 공격형은 격리된 규칙 시험이며 자연 출현 검수와 구분한다.
- Godot 4.7.2 / Metal Forward+ / M2의 실제 원정에서 시드 71503의 자연 원산 고양이형(행성 486659)과 소(牛)형(행성 311384)을 각각 실행했다. 선공·준비·실제 이동/도약·피해, 보이는 충돌체와 호스트 위치, 메뉴 정지, 장착 총기로 격파, SFX 재생과 저장/재읽기를 확인했다.
- 네 대표형의 준비/타격/회복과 사마귀 두 번째 베기를 실제 Forward+로 렌더하고 [화면 기록](media/native-patterns/render-records.json)을 보존한다. 실제 원정의 짧은 도약 장면을 놓치던 시험 캡처의 0.3초 대기를 제거했다.

최종 새 판정 20개, 고양이형 실제 원정 16개, 돌진형 실제 원정 15개 확인은 모두 실패 0이다. 대표 렌더는 4형태·13장이다. [공격 비교](media/native-patterns/motion-board.jpg), [실제 돌진 예고](media/native-patterns/patterns-bovid-windup.png), [실제 도약](media/native-patterns/patterns-felid-motion.png).

```bash
./tools/godot.sh --headless --script res://tests/check_wildlife_patterns.gd
./tools/godot.sh --script res://tests/check_wildlife_patterns_play.gd -- --crew-ui-test --crew-folder=/tmp/native-combat-play --play
./tools/godot.sh --script res://tests/check_wildlife_patterns_play.gd -- --crew-ui-test --crew-folder=/tmp/native-combat-play --play --charge
./tools/godot.sh --script res://tests/render_wildlife_patterns.gd
```

검사는 `/tmp`의 전용 세계/프로필을 사용한다. 기존 사용자 저장과 실행 중이던 편집기는 교체하지 않았다. [원시 기록·집계](media/native-patterns/verification.json).

## 남은 범위

독액 발사체·무리 포위·부위 약점·종별 전용 음원·종별 자원 드롭·생물 전투 사건·수중/비행 교전은 후속이다. 155종 전체의 수작업 동작 검수, 6클라이언트 실기, 지연 조건에서의 손맛·고티어 밸런스는 확인하지 않았다. 도약은 평탄한 지면의 짧은 공격이며 절벽/단차를 넘는 탐색 AI는 아니다. 원격 전투 시각 보간과 호스트 0.1초 판정 간격의 추가 고도화도 남는다.
