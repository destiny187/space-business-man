# 항성 외형 계열과 궤도선 제거

2026-09-07 사용자 승인: 항성을 황색·적색·청백색·활동성의 네 가지 시각 계열로 구분하고 사용자에게 보이는 행성 공전선을 제거한다.

## 적용

`star_visuals.json`을 시각 설정 원본으로 사용한다. 태양은 황색을 유지한다. 다른 항성은 항성계 시드와 분광형으로 외형을 결정하며 활동성은 별도의 시각 변형이다. 과학적 항성 분류 체계를 새로 정의하는 것이 아니다.

| 계열 | 표면 | 코로나·홍염 |
| --- | --- | --- |
| 황색 | 중간 크기의 표면 입상 무늬 | 절제된 부드러운 코로나 |
| 적색 | 큰 대류 무늬·느린 흐름 | 넓은 코로나·느리게 움직이는 아치형 홍염 |
| 청백색 | 작은 무늬·빠른 흐름 | 가늘고 날카로운 코로나 |
| 활동성 | 큰 흑점·간헐적인 밝기 변화 | 비대칭 아치형 홍염과 약한 플레어 |

기존 구형 항성 메시를 유지하고 표면·코로나 효과 셰이더를 교체했다. 새 Blender 모델 제작은 없으며, 홍염은 빌보드 효과로 표현한다. 효과가 표면 무늬를 덮지 않도록 코로나의 중심부를 비우고 밝기를 제한했다. 항성의 광원 에너지는 기존 값을 유지한다.

우주 장면의 궤도 선 메시를 생성하지 않는다. 항법도의 공전 원도 제거하되 행성 선택 표시와 성간 이동 경로는 유지한다. 실제 공전 위치·속도, 위성 공전, 행성 고리는 그대로 유지한다.

새로운 위험도·피해·플레어 공격을 추가하지 않았다. 기존 항성 근접 경고·피해 규칙을 그대로 사용한다. 외형은 기존 galaxy-v3 저장에도 적용되며 행성 주소와 항성계 배치는 변경하지 않는다. 신규 음원은 제작하지 않았다.

## 확인

`render_star_variants.gd`에서 실제 항해 로더로 네 계열을 Godot 4.7.2 Metal Forward+에 렌더한다. 태양의 황색 외형, 궤도 메시 제거, 시간 경과에 따른 행성 위치 변화를 함께 확인한다. 전체 회귀·다중 클라이언트 검사는 수행하지 않는다.
