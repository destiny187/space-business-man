# 추가 동물 300종과 티어별 자연 생태

2026-09-10. 사용자가 요청한 동물 기본종 300개와 무생물 행성 유지·티어별 생물권 증가를 구현했다. 확정 방향과 초기 확률의 소관은 [발견·연구·생태](../game/09-discovery-research-and-ecology.md), 각 이름·구조·서식 환경은 [300종 목록](../game/24-xenofauna-catalogue.md)이다.

![30개 신체 구조군 대표](media/xenofauna/overview.jpg)

## 제작한 실물

| 항목 | 실제 수량 |
| --- | ---: |
| 새 동물 기본형 | 300 |
| 새 신체 구조군 | 30 |
| 편집 가능한 Blender 원본 | 300 |
| 게임용 GLB | 600 — 기본형마다 near/far |
| 추가 외형 프로필 | 6,000 — 기본형마다 20개 |
| 전체 동물 기본형 | 700 — 기존 400 + 추가 300 |
| 미생물·식물 포함 전체 기본형 | 900 |
| 전체 외형 프로필 | 18,000 |

고리형 몸통, 쌍궁 골격, 방사형 손, 열리는 구강판, 현수 내장, 이중 낭체, 다완 군체, 편조 몸통, 격자 골격, 나선 척추 등 30개 구조군이다. 군마다 기관 수·분기·연결·배치·길이와 비율이 다른 10개 해부 레시피를 작성했다. 색이나 전체 크기만 바꾼 프로필을 300종에 세지 않았다. 실제 생물학적 분류나 관측종이 아니라 게임에서 만든 가상종이다.

`tools/bestiary/xenofauna_roster.py`가 이름·구조·감각기관·서식 환경을 관리하고 `tools/build_xenofauna.py`가 Blender에서 각 기본형을 제작한다. 두꺼운 열린 구강의 안팎 면, 곡선 골격, 막, 가동 기관과 접지부를 만들며 공통 재질 및 `ink_blender` 출력을 재사용한다. 게임 실행 중 몸을 무작위로 생성하지 않는다.

- 원본: `art/blender/xenofauna/*.blend`, 제작 기록 `*.json`.
- 게임: `우주-비즈니스/assets/models/xenofauna/*_near.glb`, `*_far.glb`.
- 별도 카탈로그: `data/bestiary/xenofauna_forms.json`, `xenofauna_appearances.json`, `xenofauna_recipes.json`.
- 재질·LOD 등록: 기존 `data/render_assets.json`에 새 항목만 추가했다.

근거리 삼각형은 기본형에 따라 3,224~80,272개, 평균 약 20,368개다. 원거리에는 해부 윤곽을 보존하는 축소 모델을 사용한다. 신규 세계의 근처 생물 표시 한도는 16개이고 가시성/거리 LOD를 재사용한다. 전 시드·6인·최악 밀도의 성능 측정을 완료했다는 뜻은 아니다.

## 게임 연결과 기존 저장

새 은하는 생성 시 `ecology_expansion.json`의 초기 규칙과 추가 카탈로그 버전을 manifest에 고정한다. 무생물·휴면·정착 기원을 구분하고, 높은 티어에서 정착 가중치와 동물 계통 수가 증가한다. 같은 행성에서는 서로 다른 구조군을 먼저 선택한다. 지질 환경군은 현무암·건조·한랭·동굴·온대·결정·열수로 확장했다. 신규 종은 앞의 여섯 환경에 각 43종, 열수에 42종이다.

정착 추첨과 실제 활동은 별도다. 온도·압력·수분·기질이 맞고, 지형 위에 몸이 들어갈 공간이 있어야 나타난다. 신규 세계의 육상 자연 생물은 액체 바다가 있는 행성의 기본 해수면 아래에 배치하지 않는다. 표시 반경/상한은 호스트 표적 판정과 클라이언트가 같은 규칙을 사용한다.

기존 은하는 이전 카탈로그 선택 풀·기원 비율·종 구성·개체 ID를 보존한다. 새 자연 분포는 새 은하부터 적용한다. 구 카탈로그 600개와 해시를 교체하지 않고 별도 카탈로그를 추가했다. 현지 생물 사건에서는 지하/거대/희귀 변이 등 기존 역할 조건에 맞는 신규 종을 사용할 수 있다. 신규 종의 공격은 `none`이므로 수호자 교전에 넣지 않는다.

기존 생성형 행성의 `traits.pressure`는 bar였으나 생태 서식 범위는 kPa였다. 예를 들어 시드 71491·행성 8의 약 1.023 bar가 25~160 kPa와 비교되어 휴면 처리되었다. 새 프로필은 kPa와 단위를 저장하고, 기존 프로필은 기후 판정 시에만 변환하여 저장된 원형·계통을 보존한다. 발견물의 압력 변환도 단위 표기를 확인해 이중 변환을 피한다.

현장 모델·스캔·표본 아이템·연구/공학 미리보기·발견 도감·생물 갤러리가 별도 모델 경로를 읽는다. J 도감에는 각 기본형의 실제 렌더 이미지와 회전 가능한 모델을 표시한다. 기본 동작에 구조별 호흡·수축·막 개폐·기관 흔들림을 더하고 기존 상태/LOD 전환을 유지한다.

## 실제 확인

- Blender 5.2.1 LTS로 300개 원본/600개 GLB를 출력했다. Cycles로 구조군별 2개와 보정한 열린 고리 3개, 총 63개 원본을 렌더했다. 초기 곡선 이음새·단면을 다듬었고 최종 비교에서 열린 고리 3종의 감각기관을 남아 있는 몸 조직 쪽으로 옮겼다.
- Godot 4.7.2, Forward+ / Metal, Apple M2에서 300개 기본형을 실제 INK 렌더했다. 각 모델의 near/far와 idle/move/feed/dormant/stressed 다섯 상태의 관절 연결을 확인했다. 30개 구조군 대표의 그늘/역광 및 상태 이미지도 출력했다. 300개 실루엣 비교판을 눈으로 확인했고, 마지막 보정 3종은 다시 출력했다.
- `tests/check_xenofauna.gd`: 추가 수량·원본/LOD·구 카탈로그 보존·압력 버그 재현/수정·새 자연 배치·중복 표본 방지·JSON 검증·티어 가중치에 한정해 확인했다. 결과는 [규칙 기록](media/xenofauna/rules-check.json)이다.
- `tests/check_xenofauna_play.gd`: 새 은하 시드 71491·T1 행성 8에 자연 선택된 **천막궁수**(`bio_double_vault_09`) 앞에 플레이어 위치를 준비했다. 실제 원정 장면에서 지상 배치·두 LOD·동작·E 스캔·J 도감·Q 채집·저장을 확인했다. 실제 생물을 강제로 추가하거나 환경을 적합하게 바꾸지 않았다. 960×640 도감과 메뉴 중 입력 차단을 확인했다. 첫 검사에서 검수용 착륙 저장에 남은 출항 연출이 Q를 막아 준비 데이터를 출항 이후로 고친 뒤 16개 확인이 통과했다. 일반 플레이 전체 원정을 완주한 기록이 아니다.
- 기존 ElevenLabs `sfx_creature_call`을 실제 현장 soundscape에서 재생하고 오디오 버스 출력을 확인했다. [재사용 매니페스트](../../audio/manifests/xenofauna-reuse.json)에 원본 프롬프트·생성일·해시와 재생 기록을 보존한다. 신규 음원을 생성하거나 종별 300개 목소리를 만든 것은 아니다.

## 남은 경계

기본 모델과 기존 게임 경로를 확장했다. 일반 개체의 자유 배회·무리 생활·먹이망·새 포식 행동·수영/비행 이동·300종별 독립 음성·새 생물 전용 연구 과제는 포함하지 않는다. 일반 개체는 고정 자연 배치 위치에서 동작하고 실제 이동은 기존 생물 사건 경로를 따른다. 종 분화/변이는 준비된 사례·프로필을 선택하며 새로운 해부 구조를 런타임에서 만들어 내지 않는다.

정착 가중치가 실제 방문 중 발견률과 같지는 않으며 T1/T2 체감 빈도·장기 생태 분포는 추가 플레이에 따라 조정할 초기 밸런스다. 이번에는 생물 관련 최소 검사·화면/재생을 수행했고 전체 회귀 묶음·멀티클라이언트·Windows 실기는 실행하지 않았다.
