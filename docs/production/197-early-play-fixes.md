# 초반 플레이와 화물 회수, 굴착 수정

2026-09-15 사용자 요청 9항목을 반영했다. 기존 원정의 천체와 소유품을 보존하고 새 첫 출격 행성의 환경 보장은 새 원정에만 적용한다.

## 변경

| 번호 | 반영 내용 |
| --- | --- |
| 1 | F 자동 접근 중 전진, 후진, 좌우, 롤, 제동, 가속 또는 정밀 이동 키를 누르면 즉시 수동 비행으로 돌아온다. 메뉴의 중립 제동 패킷과 마우스 시점 이동은 취소 입력으로 취급하지 않는다. 진행 중 성간 이동은 유지한다. |
| 2 | 이미 스캔한 행성은 응시하면 기존 데이터를 즉시 보여준다. 행성 표면 강조는 T 유지 중 또는 최초 완료 직후 1.2초에만 표시한다. 대상을 바꾸면 완료 강조를 해제한다. |
| 3 | 출발 때 이전 행성을 돌아보는 카메라 보정을 제거했다. 현재 비행 방향의 안전한 출발 경로를 사용하고 카메라는 그 방향에서 뒤로 물러난다. 출발 변위는 5차 가속 곡선, 출발 속도 표시는 그에 맞는 4차 곡선을 사용한다. 도착 감속과 항로 안전 판정은 유지한다. |
| 4 | 대기 진입 화면의 장식용 주황색 뱃머리 원을 제거했다. 비행선, 구름, 기류와 기존 착륙 음향은 유지한다. |
| 5 | 새 원정의 첫 출격 목적지 주소와 전용 규칙을 은하 설정에 보존한다. 철, 얼음, 구리는 원격 스캔과 실제 착륙 주변 광맥에 포함하며 물은 최소 30%, 대기 적합도는 최소 30을 만족하는 낮은 난이도로 만든다. 현재 초기 구현값은 기온 18°C, 기압 1atm, 산소 21%, 독성 최대 10이다. 기존 저장의 행성 기후, 지질과 광맥은 변경하지 않는다. |
| 6 | 착륙선 단말에서 신체 증강 카드를 제거했다. 개인 I의 신체 화면과 기존 장치 접근은 유지한다. 신체 증강의 운송 숙련 탭은 제거하고 선체를 판매하는 일반 정거장의 선체 구매, 보유 선체, 항해 개장 화면에서 운송 개조를 연다. 비용은 개인 배낭, 기존 운송 개조 단계는 그대로 사용한다. |
| 7 | 내려놓기 수량 아래에 최대, +10 버튼을 같은 줄로 배치했다. 선택 수량 확인 후 내려놓으며 작은 화면에서도 버튼이 잘리지 않도록 창 높이와 구성을 조정했다. |
| 8 | 일반 사건 화물의 F 회수를 내용물과 내 배낭이 나란히 보이는 창으로 바꿨다. 아이템 클릭 또는 배낭으로 끌어놓기로 선택한 품목만 회수한다. 총기 옵션과 품질은 기존 호스트 확정값을 그대로 사용한다. 모듈은 별도 모듈 케이스로 들어가며 위치를 창에 안내한다. 미회수 품목, 부분 회수 수량과 총기 회수 여부는 저장된다. 운반형 사건은 회수 신호기까지 운반한 다음 내용물을 연다. |
| 9 | 지형 변환기는 왼쪽 마우스 버튼을 누르고 있으면 장비 간격에 맞춰 연속 사용한다. 굴착은 영향받는 근거리 메시와 충돌체만 함께 교체한다. 원경 재생성 요청, 지표 장식 전체 갱신, 물길 전체 철거, 높이만 사용하는 물가 메시의 재생성을 줄였다. |

## 확인된 원인

총기 회수는 모듈, 재료, 별도 장비, 총기를 한 번에 지급했다. 배낭에 총기 한 개가 들어갈 공간이 있어도 다른 보상 또는 모듈 케이스의 한도가 차면 전체 거래가 취소됐다. 새 회수는 선택 품목의 수납 조건만 검사하고 실패 시 해당 품목을 그대로 남긴다. 이 원인을 확인했으며 제보한 이름의 사용자 저장 원본을 직접 재현한 것은 아니다.

굴착 완료 신호가 원경 갱신 요청, 주변 물길 전체 제거와 장식 전체 무효화를 함께 유발했다. 비동기 임시 지면은 새 메시가 준비되기 전에 제거되는 경로도 있었다. 임시 지면은 교체 준비까지 유지하고, 근거리 굴착은 기존 메시/충돌의 동시 교체를 유지한다. 지형을 소프트웨어 가림 판정에서 제외하고 양면으로 그려, 지하에서 표면 뒷면이 사라지는 경로와 지형 자체 가림의 오판 가능성을 줄였다. 지형 가림용 형상은 다른 물체를 가리는 데 계속 사용한다.

## 단일 행동의 처리 범위

- 자동 접근 해제는 호스트의 항해 상태와 현재 비행 입력만 바꾼다. 입력 배열의 13번째 값으로 명시적인 이동키 입력을 구분하며 기존 길이의 패킷도 받는다.
- 스캔 강조는 로컬 대상 하나와 완료 타이머만 변경한다. 지식 기록은 기존 스캔 저장 경로를 사용한다.
- 일반 화물 선택 회수는 행동한 캐릭터, 배낭과 사건 하나를 복사한다. 다른 보관함의 0개 표본 정리도 이 요청에서는 실행하지 않는다. 완료 시 별도 연구 상태를 바꾸는 폭풍 기록 사건은 기존 전체 초안을 유지한다. 호스트 거리, 조준, 사건 단계, 요청 순번, 최신 리비전과 원자 저장 검사는 유지한다.
- 열린 화물 창은 내용물, 배낭 또는 장비가 달라질 때 격자를 갱신한다. 닫을 때 응답/스냅샷 구독을 해제한다.
- 굴착 뒤 지표 장식은 해당 영역만, 생태 지면 캐시는 영향받는 위치와 실패한 배치만 무효화한다. 물길은 굴착 주변 표본을 포함한 물길 단위로 재생성하며 해안선은 고정 높이를 사용하므로 굴착 때문에 재생성하지 않는다.
- **남은 비용:** 지형 행동의 호스트 전체 가변 상태 초안, 전체 무결성 검증과 저장 체크포인트, 일부 현장 갱신/발행은 남아 있다. 이 변경을 전체 지상 렉 해소 또는 일정 FPS 보장으로 기록하지 않는다. 양면 지형과 지형 가림 제외는 추가 그리기 비용이 있을 수 있다.

## 실제 확인

사용자 원본 저장 대신 `/tmp`의 격리 원정을 사용했다. Godot 4.7.2 Forward+ / Metal, Apple M2에서 실제 창과 게임 렌더를 확인했다.

- `check_early_play_fixes.gd`: 18항목 통과. 새 첫 행성 조건과 실제 광맥, 이전 생성 설정 보존, 중립 입력과 이동키 취소 구분, 성간 이동 유지, 정거장 운송 개조와 중복 단계 거절, 정확히 3칸 여유에서 총기 개별 회수, 중복 지급 거절, 나머지 화물과 직렬화 보존, 사건 초안 분리를 확인했다.
- `check_followup_travel_play.gd`: 실제 출발부터 도착까지 13항목 통과. 현재 방향에서 카메라가 따라가는 출발을 확인했다. 이후 더 완만하게 조정한 최종 출발 곡선은 아래 우주 검사에서 별도로 확인했다.
- `check_early_space_play.gd`: 실제 창 6항목 통과. 최초 스캔 강조, 기존 데이터와 비강조 상태, T 유지 강조, 최종 출발 곡선, 선체 판매 화면의 운송 개조를 확인했다. 동일한 출발 진행 간격 .23/.26/.29의 변위는 2.4m/76.8m/583.2m였다.
- `check_early_field_play.gd`: 실제 창 최종 14항목 통과. 화물 열기와 선택 총기만 호스트 확정 회수, 나머지 유지, 최대/+10 수량, 착륙선 증강 카드 제거를 확인했다. 고정 관찰점에서 굴착 1회 후 원경 생성 횟수는 1회 그대로였고 관련 없는 근거리 청크 71개가 유지됐다. 지하 내부의 지형 면도 렌더로 확인했다.
- 기존 Blender 모델과 ElevenLabs 음원 연결을 재사용했다. 새 모델/음원은 제작하지 않았다. 마지막 스크립트 로드와 `git diff --check`에서 오류가 없었다.
