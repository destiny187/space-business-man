# 리소섬 — 첫 바위형 생물 시연

2026-09-06 사용자가 서브 작업으로 생물 한 종 제작·시연을 요청해 `lithotherm`의 Blender 원본, 게임용 모델과 독립 Godot 관찰실을 만들었다. **상태는 `visual-prototype`이며 최종 형태 승인·행성 출현·연구·표본 운송·번식·협동 동기화를 완료한 것이 아니다.** 종의 게임 원리와 조건은 [발견·연구·생태](../game/09-discovery-research-and-ecology.md), 시각 기준은 [INK v1](06-rendering-quality-standard.md)을 따른다.

## 실제 제공한 것

- 넓은 현무암 외피, 여섯 다리·넓은 발·규산염 발톱, 보호된 감각 기관, 광물 분쇄 턱, 열 틈과 작은 청록 공생 피각을 갖춘 형상. 생물학적 실재를 주장하지 않는 가상종이다.
- 휴면·제자리 보행·섭식·스트레스 네 가지 절차 동작. Blender의 이름 붙인 10개 피벗을 Godot에서 움직인다. 베이크한 골격 애니메이션, 실제 이동 AI·지형 추종·먹이 소비는 미구현이다.
- 가까운 모델 45,580삼각형, 원거리 모델 13,646삼각형. 같은 피벗·상태를 유지하며 거리 18m는 관찰실의 임시 전환값이다. 양쪽 모두 메시 노드 46개로 드로콜 최적화는 남아 있다.
- 공통 `FrontierInkStyle`·3단 명암·검은 윤곽선·4× MSAA·FXAA. 별도 셰이더를 만들지 않았다.
- 독립 관찰실의 상태 버튼·키 입력, 회전·확대, 일시정지, 주광·역광·그늘, 총 9개체 군집 보기.
- 단순 충돌 캡슐을 함께 두되 현재 충돌 레이어·마스크는 0이다. 실게임 물리와 캐릭터 충돌을 연결했다고 해석하지 않는다.
- 공통 렌더 목록에 `visual-prototype`으로 등록하고 단독 촬영·도감 PNG를 추가했다. 기존 31종 렌더는 보존하고 발견·환경 모음만 새 표본을 포함해 재조립했다. 이번 생물은 기존 31종에 추가한 항목이다. 메인 개발의 신규 우주선 등은 별도로 추가될 수 있으며 기존 27종의 형태 교체 상태는 바뀌지 않는다.

## 검수와 한계

Godot 4.7.2 / Metal / Apple M2의 실제 창에서 27개 항목을 통과했다. 상태 키 입력·버튼 연결·일시정지/재개·잘못된 상태 거부·섭식 턱 자세 초기화·근거리/원거리 형상 크기와 피벗·공통 재질·휴면 상태의 실제 정점 접지를 검사했다. 메시 AABB는 회전 후 실제 표면보다 아래로 확장될 수 있어 접지 검사는 실제 표면 정점으로 확인한다. 보행은 수평 관절 회전과 발 들기를 사용하며 실제 바닥 추종 기능이 아니다.

단독 네 상태, 역광·그늘, 원거리 모델의 근접 검수, 군집 등 1600×1000 PNG 8장을 저장했다. 군집의 화면 잘림과 관찰실 한글 글꼴 굵기를 보정했다. 10초 영상은 Godot Movie Maker의 실제 화면 300프레임을 Blender로 MP4 인코딩했다. 별도 음원은 제작하지 않았다.

9개체 관찰실의 120프레임 참고 측정은 평균 약 25.32ms, p95 28.67ms, 889드로콜이었다. 동일 호스트에서 메인 개발도 진행 중이며 VSync·외부 부하를 통제하지 않았다. 이 값은 확장 월드·최소 사양·6인 게임의 성능 보장이 아니다. 기록 원본은 검증 JSON을 따른다.

공통 도감 전체 검사는 실행 시점에 33자산·436항목 중 2항목이 실패했다. 둘 다 메인 작업에서 동시에 추가 중인 kestrel 우주선의 렌더·도감 이미지 미생성이며 리소섬 항목의 실패는 0건이었다. 전체 회귀 검사 통과로 기록하지 않는다.

실제 동굴·생물실·시험 이식 환경의 검수, 경로 탐색·발 접지, 먹이/열 수지·생존/번식, 저장·네트워크, 고유 음향과 최종 품질 승인은 후속 작업이다.

## 종수에 대한 제안 — 미확정

사용자는 생물 수의 적정 규모를 질문했으며 총량을 승인하지 않았다. 아래는 제작 계획을 위한 제안이다. 색·크기만 다른 변형이나 같은 종의 개체 수는 별도 종으로 세지 않는다.

| 단계 | 제안 범위 | 확인할 것 |
| --- | --- | --- |
| 첫 확장 실증 | 완성된 사례 1종 | 발견→연구→운송→시험 이식이 실제로 연결되는가 |
| 조합 실증 | 역할이 다른 3~5종 | 가열·집수·토양 처리 등 대체·공생·조건 차이가 있는가 |
| 첫 플레이 공개 범위 | 은하 전체 사례 12~20종 | 동물·식생·미생물이 섞이고 여러 원정에서 다른 해결법을 쓰는가 |
| 한 착륙 지역 | 적합한 3~6종을 선택하는 예 | 같은 곳의 생태 관계를 읽을 수 있는가; 무생물 지역은 0종 가능 |

예를 들어 전체 16종을 동물 6·식생 6·미생물 4로 배분할 수 있다. 행성마다 신규 모델을 전부 제작하는 방식보다 환경에 맞는 사례·드문 고유종·기록되는 계통 차이를 활용한다. 이 수량은 [생물 사례 범위 D-21](../planning/02-decisions-and-risks.md)의 확정값이나 현재 제작 완료 수량이 아니다.
