# 45초 가로 홍보 하이라이트

2026-09-12 사용자 정정: 전체 콘텐츠를 길게 나열하는 영상에서, 완성된 기지·고티어 무기·전투·우주 이동을 빠르게 보여 주는 30~50초 가로 영상으로 변경한다. 동일한 행성 위치의 변화도 몇 초 안에 이어 붙인다.

## 제작 범위

- 45초, 1920×1080, 60fps, 가로 16:9, 29개 컷. H.264 High / AAC 스테레오로 다운로드 폴더에 출력한다.
- T3 전설 기관단총·산탄총·플라스마·저격총·기관총의 실제 발사/피해, 토착 생물의 돌진, 로봇 채광과 로버 주행을 선별했다. T3 무기와 싸우는 쿠퍼테크 로봇은 촬영용 T2 현장의 실제 적이다.
- 우주전은 실제 호스트 입력·유도 미사일·편대 통과·폭발·급가속을 다시 촬영했다. 촬영 카메라의 시야각을 좁혀 기체를 크게 보여 준다. 항해·착륙 일부는 앞서 촬영한 원본을 사용한다.
- 황무지 → 태양광 → 시설 30개 → 녹지의 네 상태를 같은 카메라 경로로 촬영해 약 5초로 연결했다. 실제 게임 모델·지형·대기 렌더에 촬영용 건설/환경 상태를 준비한 연출이며, 정상 플레이에서 5초 만에 건설·복원이 끝난다는 뜻은 아니다.
- 제목이 나오는 마지막 장면도 완성 기지를 계속 이동하며 보여 준다. 기존의 긴 가로·세로 영상은 보존한다.

## 음원과 원본

ElevenLabs Music v2.5로 45초 기악곡 `Frontier Overdrive`를 생성했다. 원본·프롬프트·생성 정보는 [음원 매니페스트](../../audio/manifests/promo-impact-20260912.json)에 보존한다. 실제 녹화 효과음의 속도와 음량을 편집하고, 건설 전환에는 기존 ElevenLabs 건설음을 더했다. 총성·폭발에 따라 음악을 낮추고 최종 출력 음량을 정리했다. 게임 BGM 설정은 변경하지 않았다.

재현용 촬영 프로젝트·분리 저장·원본 AVI·편집 계획·FFmpeg 스크립트·검수 결과는 로컬 `output/instagram-impact-20260912/`에 둔다. `edit-plan.json`이 최종 컷 목록이며 `initial_edit_plan.py`는 초기안 이력이다. 게임의 사용자 저장을 촬영에 사용하지 않았다.

## 확인 범위

Godot Forward+ 실제 렌더로 신규 무기·기지·우주전을 촬영하고 컷별 화면을 확인했다. 우주전 촬영에서 실제 미사일 생성·명중·탈출 등 12개 확인이 통과했다. 최종 45초·1920×1080·60fps·2,700프레임 전체 디코딩을 확인했다. 출력 음량은 -15.07 LUFS, true peak -2.71 dBTP다. `final-check.json`에 메타데이터·음량·파일 해시를 기록했다. 녹화용 60fps는 실시간 게임 성능 측정값이 아니다. 사람의 최종 청감 평가와 Instagram 업로드 후 재압축 검수는 하지 않았다.
