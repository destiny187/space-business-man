# 발견에서 이어지는 보호, 조명, 경보와 공명

2026-09-15 사용자 승인: 모든 발견에 효과를 강제하지 않되 자연스럽게 연결되는 활용을 추가한다. 기존 43종 전시품을 유지하고 네 가지 실용 설계를 별도로 구현한다. 원본 자연물의 형태를 본체에 살린다. 수치와 비용의 단일 소관은 [discovery_utilities.json](../../우주-비즈니스/data/discovery_utilities.json)이다.

## 실제 기능

| 조사 완료한 발견 | 별도 연구하는 설비 | 실제 기능과 조건 |
| --- | --- | --- |
| 빈 껍질 피난처 | 껍질 쉼터 | 사람이 앞뒤로 드나드는 아치형 지붕. 지붕 아래에서 비와 산성비 보호. 전력과 소모품 없음. 낙뢰와 침수 보호는 없음 |
| 발광 얕은 수역 | 발광 배양 수조 | 실제 온대, 습지 또는 해양 미생물 표본 1개를 F에서 넣고 회수. 현장 온도 0~55°C와 1kW에서 10m 조명. 원래 표본의 정체성을 보존 |
| 수몰 기록기 | 침수 경보기 | 1kW로 30m 안 시설 기초가 실제 물에 닿는지 1초 간격 감시. 침수 중 경광등과 5초 간격 소리. F에서 경고음만 끌 수 있음 |
| 노래하는 돌기둥 | 공명 정원 | 16m 안에서 공명음을 감상. F에서 음소거와 3가지 음높이 선택. 전력과 소모품 없음 |

연구는 착륙선 F → 연구 → 공동 설비 → 설비에서 한다. 기존 완료 기록을 증거로 인정하며 연구는 원정 전체가 공유한다. B의 현장 설비에서 각자의 배낭 재료로 제작하고 배치한다. 해당 발견의 정적 전시품은 B의 발견 장식에 별도로 남는다. 기존 정적 전시품을 설치했다고 실용 효과가 생기지는 않는다. 도감은 실용 설계, 현재 기능, 작동 조건과 전시 복제품의 차이를 설명한다.

초기 연구 비용은 설계별 공동 자금 200 Cr와 연구자 배낭의 철 6, 구리 4다. 제작 비용은 쉼터 암석 30/철 10, 수조 암석 16/구리 12/철 8, 경보기 철 14/구리 12/암석 8, 정원 암석 24/구리 6이다. 최종 밸런스 확정값은 아니다. 이 네 종류에 임의 강화 수치를 추가하지 않았다. 전체 생산 설비의 계열 재편과 개별 강화 설계는 별도 소관을 유지한다.

## 표본과 환경

새 8,000종 분포의 실제 미생물 분류를 조사해 온대 분류를 포함했다. 이전 카탈로그의 습지와 해양 분류만 허용하면 새 원정에서 호환 표본을 확보하기 어려웠다. 물빛 장식만 배치해서 살아 있는 표본을 획득하는 방식은 없다. 발광 배양 원리를 적용하는 수조이며 모든 미생물 종에 새로운 고유 발광 특성을 등록한 것은 아니다.

설치하면 배낭에서 해당 표본 하나를 수조의 보관칸으로 옮긴다. 표본 원산지와 개체 ID, 기존 채집 기록은 유지한다. 기존 표본 중복 검사에 수조 보관칸을 포함했다. 중복 설치를 거부하며 배낭 공간이 있어야 회수할 수 있다. 표본을 넣은 상태의 철거는 거부한다. 온도나 전력 조건을 잃어도 표본을 소모하지 않고 빛만 멈춘다. 종별 사육, 번식, 사망, 배양액 보충, 생태 수치 보너스는 이번 기능이 아니다.

경보기는 현재 물 셀과 자연 수면을 사용한다. 완전 침수로 기계가 멈추기 전의 기초 침수를 감지하며 미래 강우나 수위 상승을 예측하지 않는다. 정적 전시품은 경보 대상에서 제외한다. 경보기 자체가 완전히 잠기거나 전력이 끊기면 작동하지 않는다. 수조와 경보기의 전력은 기존 현장 공급 및 우선순위에 합산한다.

## 제작과 표현

[Blender 제작기](../../tools/build_discovery_utilities.py)는 네 종류의 편집 가능한 원본, 게임 GLB, 검수 렌더와 모델의 침수 판정 범위를 생성한다. `-- shell_refuge`처럼 선택 재생성할 수 있다. [제작 매니페스트](../../art/blender/buildings/discovery_utilities.json)에 파일 경로를 기록한다. [Godot 검수 장면](../../우주-비즈니스/scenes/showcase/discovery_utilities.tscn)은 Forward+의 INK 셰이더로 네 모델과 투명 배경 건설 카드를 생성한다.

수조는 돌 웅덩이, 쉼터는 껍질 리브와 아치, 경보기는 퇴적물에 둘러싸인 기록기와 수위 탐침, 정원은 속이 빈 돌기둥에 작은 조절기를 결합했다. 쉼터는 통짜 원통 충돌과 상자형 가림 처리를 사용하지 않고 아치 지붕 충돌만 만든다. 수조의 군락은 표본을 넣었을 때만 현장에 나타난다. 실제 작동 상태로 조명과 발광 재질을 켠다.

공명 정원은 기존 ElevenLabs 제작 `amb_discovery_resonance`, 침수 경보기는 기존 `sfx_incident_beacon`을 재사용한다. 생성 출처는 기존 `exploration-discoveries.json`과 `exploration-incidents.json` 음원 매니페스트다. 별도 음악이나 신규 합성 음원을 생성했다고 기록하지 않는다. 근접 감쇠와 기존 Ambience/SFX 음량 버스를 사용하고 메뉴 또는 포커스 이탈 시 소리를 멈춘다. 음소거와 음높이는 승인된 호스트 상태를 읽는다.

## 단일 행동 범위

F 표본 이동, 음소거와 음높이는 `business_discovery_use` 한 요청으로 호스트에서 접근 거리와 대상, 보유 표본을 검사한다. 사전 성공 연출을 하지 않고 기존 거래 결과와 표면 스냅샷을 받아 표시한다. 요청 초안은 해당 승무원, 배낭과 현재 행성 현장만 복사한다. 다른 행성, 발견 기록과 전체 생태 기록은 읽기 전용으로 공유한다. 기존 거래 검증, 영수증, 원자적 저장과 표면 발행 경로는 유지한다. 현장 내부 지역 병합 때문에 현재 행성 현장 전체 복사 비용은 남는다. 연구 및 건설의 기존 전체 무결성 검사를 생략하지 않는다.

경보기의 1초 감시는 현장에 배치한 시설만 읽으며 지역 경계 양쪽의 가까운 시설도 감시한다. 각 표현 노드는 자신의 호스트 건물 기록만 읽고, 재질과 조명 노드를 재사용한다. F 동작으로 지형, 생물 전체 또는 원본 모델을 재생성하지 않는다. 정적 전시품에 동작 루프를 붙이지 않는다.

## 확인 범위

최소 도메인 검사에서 네 설계의 완료 증거와 공유 연구, 도감 연결, 표본 이동의 복사 범위와 중복 방지, 회수, 철거 거부, 온도 조건, 30m 경보 범위, 회전한 쉼터의 보호 범위와 음소거 및 음높이 필드를 확인했다. 네 Blender 렌더와 Godot Forward+ 렌더를 확인했다.

실제 Forward+ 원정에서 네 종류의 공유 연구 구매, B 카드와 배치 고스트, 재료 차감 건설, 모델 로딩과 F 조작을 확인했다. 960×640 화면에서 표본 선택 아이콘이 지나치게 크던 문제를 수정하고 표본 넣기 버튼이 화면 안에 보이는 것을 확인했다. 실제 원산 행성과 시드에 맞는 미생물 표본의 설치, 회수, 재설치와 재개 후 중복 없는 보관도 확인했다.

온도와 물은 임시 원정에서 제어한 입력으로 확인했다. 실제 시설 기초의 물 셀이 경광등과 음원 재생을 켜고 마르면 경보가 사라진다. 온도 초과 및 전원 끄기는 실제 수조 조명을 끈다. 메뉴를 열면 두 음원이 멈추고, 승인된 음높이와 음소거 상태가 실제 재생기에 반영된다. 도감 실제 상세 위젯에서도 수조의 1kW와 온도 조건을 확인했다. 쉼터 중앙 통로의 실제 충돌 여유를 확인했으며 장시간 이동 및 산성비 체류를 재현한 검사는 아니다.

초기 검사에서 임시 원정의 빈 재개 배낭과 자동 시뮬레이션 갱신이 검사 입력에 간섭했다. 재료 부족 시 연구를 거부하고 재료를 준비하면 200 Cr, 철 6과 구리 4를 정확히 차감하는 실제 버튼 동작을 별도로 확인했다. 제어 입력 검사는 대기 중 갱신을 마친 뒤 자동 시뮬레이션을 잠시 멈추고 호스트 규칙 및 스냅샷을 실행해 확인했다. 이러한 검사 준비 오류를 게임 기능 수정으로 기록하지 않는다.

검사 파일은 `check_discovery_utilities.gd`, `check_discovery_utilities_play.gd`, `check_discovery_utility_effects_play.gd`, `check_discovery_utility_research_play.gd`이며 도메인 검사 후 실패한 범위만 좁혀 재확인했다. 모델과 카드 생성은 `render_discovery_utilities.gd`를 사용했다. 검사 원정은 `/tmp/discovery-utilities-play`이며 사용자의 저장은 건드리지 않았다. 과거에 제보한 다른 PC의 저장 실패 조사는 이번 작업에 포함하지 않는다. 전체 협동 재접속 회귀나 장시간 자연 홍수 관측을 수행했다고 기록하지 않는다.
