# 지표 텍스처·추가 행성 3계열

2026-09-08 사용자 확정 범위는 **텍스처와 추가 행성 계열 두 작업**이다. 공급망·제품·경제의 추가 확장은 이번 범위에서 진행하지 않았다. 기존 INK v1 윤곽선·3단 명암과 현재 원정 진입 경로에 연결한다.

## 적용 결과

공유 1K 재질 10종을 제작했다. 암반·풍화토·모래·자갈·눈·얼음·염류·화산암·퇴적암·결정질 재질을 생성 행성의 착륙 가능한 **12계열 전부**에 연결한다. 기반암과 퇴적층을 지역 지질/경사로 혼합하고 온도·수분 공급·고도로 눈·얼음·습윤 피복을 더한다. 한 행성의 모든 면에 같은 텍스처를 붙이지 않는다.

| 신규 ID | 외형과 지표 | 기존 자원 지질 연결 |
| --- | --- | --- |
| `sedimentary` | 퇴적 분지: 층상 행성 표면, 낮은 판석, 퇴적암·모래 | `sedimentary` |
| `crystalline` | 결정질 고원: 각진 능선·기둥 결정, 결정 암반·자갈 | `pegmatite` |
| `alkaline` | 알칼리 광화대: 녹회색 암반·옅은 광화 무늬, 낮은 군집석 | `alkaline` |

외형 계열은 **15 → 18**, 착륙 가능 계열은 **9 → 12**다. 가스/얼음 거대행성 6계열은 착륙 불가 상태를 유지한다. 신규 3종은 기존 `basalt` 큰 분류 아래에서 시드로 선택된다. 현재 같은 큰 분류 안의 외형 후보는 균등 선택하므로 새 은하의 암석형 외형 구성 비율도 달라진다. 별도 원자재 ID·드롭/제품 밸런스·부재중 생산을 추가한 것은 아니다.

## 제작과 연결

- `tools/build_surface_textures.py`: Blender에서 주기적 높이 필드를 만들고 같은 높이에서 법선·거칠기를 출력한다. 고정 조명/그림자를 굽지 않는다. 고해상도 조각을 투영한 베이크와는 구분한다.
- `art/blender/surface-materials/surface-library.blend`: 10개 편집 가능한 높이 표면·연결 재질·내장 이미지. 같은 폴더의 매니페스트에 채널·해상도·해시·높이 진폭을 기록했다.
- `assets/textures/surfaces/*.png`: 선형 RGBA 데이터. **RG=법선 XY, B=혼합 높이/색 변조, A=거칠기**. 알파는 투명도가 아니다.
- `data/surface_materials.json` / `FrontierSurfaceMaterialLibrary`: 재질 순서·계열 조합·미터 크기·해빙 범위·전이 시간을 관리한다. Texture2DArray 하나를 공유하며 10×1024² RGBA8+mip 기준 GPU 원본 약 53MiB다. 측정된 총 VRAM 사용량은 아니다.
- `terrain.gdshader`: 월드 좌표의 세 축 투영, 높이를 이용한 경계 혼합, 암반 노멀·거칠기, 원거리 디테일 감쇠를 구현했다. 텍스처 거칠기를 INK 하이라이트에 연결하는 조건부 경로를 추가했고 다른 재질의 기존 `rough` 경로는 유지한다.
- 기존 `surface_geology.gd`의 암반/유로/모래 함수와 같은 미터 좌표·시드를 사용한다. 눈은 완만한 노출면, 얼음/젖음은 물질 공급이 있는 면에 제한한다. 기압이 낮으면 액체 젖음을 생략한다. 이는 게임용 표현 모델이며 수량 보존·실제 상평형 계산이 아니다.
- `business_site_view.gd`: 호스트가 전달한 현장 온도를 18초 시간상수로 부드럽게 반영한다. 개발 반경 밖의 본래 기후는 유지한다. 별도 결빙/해빙 히스테리시스·일사/바람 축적 모델은 아직 없다.
- `terrain_mesher.gd`: 원래 표면 아래 깊이를 정점 R 채널에 기록해 동굴·굴착면의 지상 피복을 억제한다. 메시 위치/법선/인덱스·충돌 생성은 유지한다.
- `tools/build_ink_planets.py --families=...`: 신규 3계열 Blender 원본과 근/원거리 6 GLB를 생성했다. 기존 15계열 자산과 기록을 보존하는 선택 빌드를 지원한다.
- `tools/build_surface_details.py --families=...`: 신규 3계열마다 자연물 4변형, 총 12 GLB와 Blender 원본을 추가했다. `surface_details.json` 및 `render_assets.json`에 등록했다. 장식 결정은 채집 광물이 아니며 실제 채집 대상은 기존 자원 시스템이 결정한다.
- 비행 화면과 항해 미리보기에서 같은 새 모델/기후 셰이더 값을 사용한다. 한랭 궤도 수면은 얼음색, 고위도는 제한된 서리로 표현한다. 원거리 모델 전환도 포함한다.

## 실제 확인

Blender 5.2.1 LTS에서 재질 라이브러리·신규 행성·자연물을 렌더했다. Godot 4.7.2 Metal Forward+에서 실제 `FrontierCrewSurfaceScene`의 스트리밍 지형과 Blender 장식을 사용해 12계열을 촬영했다. 지표 확인은 고정 주광/환경광·안개 없음·작업등 끔의 비교 조건이며 실제 낮밤 연출과 구분한다. 툰드라에는 현장 온도 18도를 주어 같은 가까운 카메라의 결빙/해빙 표현을 비교했다.

검수 도중 임시 스트리밍 면이 원거리 지형보다 먼저 만들어지면 재질이 비어 흰 면으로 보이는 문제를 발견했다. 최초 생성부터 재질을 연결하고 설치 시 갱신하며, 임시 면의 법선도 실제 표면에서 구해 경사 재질을 맞췄다. 해당 면의 재질 동일성 검사를 추가했다. 주광 검수 카메라에 야간 작업등 상태가 남는 문제는 검수 장면에서 명시적으로 끄도록 수정했다. 눈의 선형 색상값도 낮춰 강한 주광에서 요철이 하얗게 소실되는 현상을 줄였다.

- 지표 12계열: 재질 배열·지형/자연물 생성·착륙 바닥 높이·임시 면 연결 **50개 확인, 실패 0**.
- 기존 저장 v3 샘플의 492개 행성은 저장된 15계열 규칙을 사용한다. 새로운 계열로 바뀌지 않음을 확인했다.
- 기존 메시 생성기와 표면/지하 3청크의 위치·법선·인덱스가 동일했다. 노출 정점 628개와 지하 피복 제외 정점 1,687개를 확인했다.
- 궤도 18계열의 실제 비행 로더·근/원거리 모델 전환 **56개 확인, 실패 0**. 결과는 [궤도 확인 기록](media/planet-surfaces-v2/orbit/verification.json)을 따른다.

## 저장과 남은 경계

새 외형 3계열은 `planet_rules` v4를 저장하는 **새 은하**에서 등장한다. 기존 은하는 저장된 생성 규칙·지형·광물 분포를 보존하면서 공유 텍스처 개선을 받는다. 기존 세계에 새 계열을 소급 배치하거나 생성 규칙을 강제로 교체하지 않는다.

태양계 고유 궤도 모델 8종의 재제작은 이번 범위에 포함하지 않는다. 외형 특성이 없는 구형/고정 천체 지표는 `cratered` 기본 재질 조합을 사용하며 해당 천체의 고유 기후를 새로 구현한 것은 아니다.

이번 피복은 시각 표현이다. 두꺼운 적설·빙하 형상·보행 가능한 호수 얼음·파손/충돌·광물 추가·고유 발소리는 포함하지 않는다. 궤도 대륙과 착륙 지형의 정확한 지도 대응, 전 행성 기후 지도, 위도·일사·주야별 결빙, 여러 휘발성 물질의 상변화, 테라포밍에 따른 빙설 장식 모델 제거는 후속이다. 기존 자연물은 기본 계열로 배치되므로 해빙 뒤에도 일부 얼음형 장식이 남는다. 공통 CPU 표면 샘플에 모든 장식·발소리를 통합하는 설계도 아직 완료되지 않았다.

전체 행성 시드 전수, 장거리 카메라 이동/지하 실제 보행, 6인 실기, Windows, 장시간 성능·메모리 및 전체 기본 플레이 회귀는 실행하지 않았다. 이번 확인으로 해당 범위가 검증됐다고 표시하지 않는다.
