# 지상 탐험·연구·협동 사업량 — C09~C12

2026-09-08. 사용자가 C09~C12 구현과 개별 커밋을 승인했다. [커밋 계획](../planning/11-ground-commit-plan.md), [개발 명세](../planning/10-ground-development-spec.md)의 후속이다. C13 이후 로버·낮밤·집중 성능 안정화는 이 작업의 범위가 아니다.

## C11 — 개인 연구·공동 생산 효율

- 착륙선 연구에 효율 연구 카드·기존 Blender 모델 미리보기·현재/다음 단계·필요 부품·실패 이유를 연결했다. 각 분야는 5단계, 단계당 +10%, 최대 +50%이며 데이터로 관리한다. 개인 연구는 자기 가방 부품, 공동 연구는 호스트의 공동 크레딧으로 구매한다.
- 채집공학은 개인 채집 간격만 줄이며 광물 등급 제한을 해제하지 않는다. 개인 물류는 지상 이동 속도와 가방 1칸/단계를 늘린다. 다른 캐릭터·공동 채집기 정의에는 전파하지 않는다. 로버 해금은 아직 없다.
- 생산공학은 공동 로봇 조립·제품 생산·로봇 채집 작업·환경 시설의 처리 시간에 한 번 적용한다. 안정화 관찰 시간과 로봇 이동에는 배율을 붙이지 않는다. 기존 호스트 1초 틱에서 고품질 로봇의 누적 작업이 1을 넘던 오류도 수정해 완료한 사이클을 처리하고 소수 잔여량을 보존한다.
- 개인 연구는 해당 세계의 캐릭터 장비 기록, 공동 연구는 세계 사업 장부에 보존한다. 기존 누락 값은 0단계다. 다른 호스트 세계로 개인 프로필을 통해 수출하는 기능은 이번에 추가하지 않았다.
- `check_progression_research.gd`의 Forward+ 창에서 호스트 승인·자기 부품/공동 자금 차감·개인 소유 분리·로봇/환경 처리 배율·960px 화면·저장/재읽기·기존 ElevenLabs 발견음 재생을 확인했다. 이동 검사는 벽시계 시간의 프레임 지연과 재개 직후 지형 로딩 영향을 분리해 준비된 지면에서 같은 물리 프레임의 정상 속도 **6.0→6.6m/s**를 확인했다. 좁힌 재검사에서 실제 공장 작업 **1초→1.1초 처리**, +50% 상한도 확인했다(실패 0). [연구 화면](media/ground-growth/research-960.png). 주관적 청음·다중 클라이언트 실행은 하지 않았다.

## C09 — 첫 후보·기초 자원 동선

- 새 세계는 `ground_rules`를 은하 원형에 저장한다. 새 T1/T2에서 기본 철·구리·암석·얼음을 20~80m의 지지되는 지면에 나누고, 일반 무작위 광맥은 이 시작권 밖에 생성한다. T3 이상과 기존 원형의 자원·고갈·시설은 바꾸지 않는다.
- 시작권 보장량은 철 610·구리 205·암석 195·얼음 150이다. 첫 로봇·전력 재료는 가깝게, 뒤의 철·암석·운영 얼음은 더 바깥에 둔다. 행성의 원래 지질 분포는 시작권 밖에 유지한다.
- 첫 추천은 기초 복원에 실제 처리가 필요하면서 온도·대기·급수·생태 병행 시간이 150~360초인 T1 후보로 제한한다. 생성된 환경을 편한 값으로 덮어쓰거나 완료 대기 시간을 추가하지 않는다. 필요한 시작 광맥 5개가 지면에 배치되는지도 확인한다.
- 기존 기술·설비/로봇 제작식·운영 처리율은 유지한다. 안내는 대기·열·급수부터 가동하고 얼음을 보급한 뒤 로봇·배양을 병행하도록 바꿨다.
- `check_ground_rules.gd`에서 새 추천·자원 합계·거리와 기존 저장의 유효성을 확인했다. `/tmp/ground-c08-review/world.json`의 기존 현장/고갈 기록도 정상적으로 읽었다.

- 실제 Forward+ 창의 `check_intro_pacing.gd`에서 처음 착륙한 뒤 지급/틱 가속 없이 Mk.1 채집·보행·가방 건설 8개·운영 얼음 보급·로봇 제작을 진행했다. 기본 환경 조건은 **465.96초(7분 46초)**에 충족됐다. 마지막에 시작한 로봇 제작을 조기에 완료로 검사한 검수 코드를 수정하고, 저장을 재개해 남은 조립(조작권 반환 후 8.07초)·실제 호스트 정산·저장만 추가 확인했다(실패 0). 검사기 경로가 광맥/지상 물체에 막혔던 준비 실행은 정상 시간에서 제외했고, 실제 충돌을 피하는 이동으로 보완했다.
- 이는 경로와 제작 순서를 알고 메뉴 선택을 자동화한 관찰값이다. 초보자 10~20분의 실측 완료로 주장하지 않는다. 약 8분의 실행에 탐색·판단·메뉴 학습 여유를 두는 목표를 유지하며 숙련자에게 강제 지연을 추가하지 않는다. [실제 복원 화면](media/ground-growth/first-restoration.png). C10의 새 처리 제품은 이 T1 흐름의 재료/처리율을 바꾸지 않는다.

## C10 — 외곽 처리재와 새 T2 제품

- 새 원형의 T2에서 실제 지질에 규소/인산염이 있을 때 각각 담수 필터 모듈/토양 활성 팩을 복원 입력으로 선택한다. 두 재료를 모든 행성에 강제하지 않는다. 두 종류 모두 현지 확보 가능한 행성은 착륙 전 요약에서 추천한다.
- 필수 첫 물량은 지표의 지지되는 지면, 거점에서 450~509m에 각 160개를 배치한다. 시작권의 임의 규소/인산염 생성도 제외한다. 레이더 가장자리와 자원 아이콘·거리로 지질 단서를 제공한다. 지하 굴착·냉각·로버가 있어야 첫 재료에 접근하는 잠금은 없다.
- 담수 모듈은 기존 필터 2+규소 8, 활성 팩은 기반재 2+인산염 8로 제작한다. 기존 필터/기반재의 Blender 제작 패키지 모델·아이콘을 재사용하고 제품 이름·원료·용도를 구분한다. 실제 INK 미리보기와 ElevenLabs 생산 완료 재생을 확인했다. 기본 Mk.2 장비/설비 개조식은 유지한다.
- `restoration2.inputs`는 생성된 현장에 저장한다. 기존 T2 계약은 필터/기반재로 계속 처리하고 새 입력을 소급 추가하지 않는다. 신규 모듈을 공급해야 하는 현장은 기존 소모품만으로 우회할 수 없다.
- `check_external_treatment.gd`의 Forward+ 실제 창에서 외곽 지형 로딩·Mk.1 채광→입고→호스트 제품 생산→물/토양 지수 변화·원료 정확한 차감·기존 계약 경로·저장/재읽기를 확인했다(실패 0). 기본 설비와 공통 가공품은 검수용으로 공급했고 외곽 이동 위치를 직접 설정했으므로 전체 T2 완주 실측이 아니다. 두 단서를 연결한 평면 도보 하한은 249.91초(6m/s, 약 4분 10초)이며 실제 경사·탐색·채집 시간은 별도다.
- 낮은 해발의 정상 지표가 ‘지하’로 표시되던 오류를 발견해 지면 대비 깊이로 바꿨다. 저장된 외곽 현장만 다시 열어 ‘지표 탐사’ 표시를 확인했다(실패 0). [외곽 화면](media/ground-growth/external-surface-height.png), [960px 제품 화면](media/ground-growth/module-production-960.png). 제품 수가 늘어난 작은 창에서는 기존 세로 스크롤로 생산 조작까지 이동한다.
