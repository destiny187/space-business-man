# 8,000종·행성 독점 생태·50만 행성 작업 기록

2026-09-11. **기본종 8,000개 카탈로그와 신규 7,000개 모델·리깅·게임 렌더를 반영했다. 최종 T1/T2 지상 생물·조류 비행·가스 관측·도감을 확인했다. T2의 활성 창 골격 운동 확인을 마쳤으며, 작은 도감에서 미리보기가 잘리던 문제도 수정했다.**

## 확정된 최신 요구

- 기존 1,000개 기본종을 보존하고 총 8,000종으로 확장한다. 웹의 동물·식물·가상 생물 연구를 참고하며 생물군의 실제 구조 다양성을 우선한다.
- 사용자의 최종 정정에 따라 **종마다 자연 서식 행성은 하나뿐**이다. 같은 항성계에서도 다른 행성과 기본종을 공유하지 않는다. 같은 행성의 여러 개체와 플레이어가 직접 옮기는 외래종은 별개다.
- 새 은하는 50만 행성으로 줄이고 현재와 비슷한 항성계 간격을 유지하도록 크기를 조정한다. 기존 100만 행성 저장은 보존한다.
- 행성의 18가지 기존 유형에 맞춰 외형·기질·온도·압력·서식 층을 연결한다. 가스행성의 가상 대기층 생물은 착륙 대신 궤도 관측으로 만난다.
- 후속 사용자 확정: 시간이 걸려도 **생물체 유형별 전용 리깅이 필요**하다. 관절 수만 바꾼 공통 강체 모션을 최종 리깅 완료로 취급하지 않는다. 기본종 제작·등록과 체형별 골격/웨이트/동작 검수의 상태를 구분한다.
- 중심으로 향하는 주 탐험 방향(사용자 표현의 좌측)의 생명권 가중치를 훨씬 높인다. 반대 방향에도 무생물 자원·유적 등은 유지한다.

## 구현과 확인

신규 7,000종을 모두 제작하고 완성 카탈로그에 등록했다. 동물 4,900·식물 1,400·미생물 군락 700이며 기존 1,000종을 더한 전체는 8,000종이다. 실제 Blender 원본 7,000개와 게임용 near/far 모델 14,000개에 유형별 Armature·스킨 웨이트를 보존했다. 구성 유형 83개·해부 체형 85개·리깅 템플릿 343개·골격 배치 15개다. 모든 기본종의 정규화 형상 중복·스킨 오류는 0이다. 형상 해시의 차이가 예술적 다양성을 자동으로 증명하지는 않는다.

동물 98제작 그룹의 25·26번째 총 196종을 알아보기 쉬운 28체형으로 교체했다. 같은 체형의 7기관 계통은 외형 유사성이 남는다. 이어서 사용자 지적에 따라 이 196종의 안와·눈꺼풀·동공·홑눈/겹눈·주둥이·부리·수염을 수정했다. 전체 8,000개 얼굴을 일괄 재조형했다는 뜻은 아니다. [체형·눈 품질과 검수 범위](129-biota-midpoint-silhouettes.md)를 따른다.

140종은 날개를 사용하는 조류형이다. 그중 14종은 위 교체에 포함한 섭금류·올빼미형이며 가스행성 부유종과 구분한다. 대기압 50kPa 이상과 지정 기질·온도 조건에서 자연 배정한다. 흉곽·어깨/팔꿈치/손목·접이 발·꼬리의 실제 골격에 휴식·이륙·비행·착륙을 연결했다. 초기 비행 수치와 구현 범위는 [연구·리깅 기록](125-biota-research-and-rigging.md)을 따른다. 새 날갯짓/울음 음원은 ElevenLabs 생성 연결을 확인하지 못해 [프롬프트와 미생성 상태](../../audio/manifests/avian-pending.json)를 남겼다.

Blender 원본 전신 658개·게임 전신 658개, 85해부 체형의 다섯 자세, 교체 28체형의 원본/게임 얼굴 확대를 직접 검토했다. 신규 7,000종 전체의 두 LOD·다섯 상태 검사도 실패 0이다. 교체 196종의 실제 관절 계층·보행 한 주기 확인은 40,118항목 실패 0이다. 개별 모델/모션 해시를 `media/biota/visual-review.json`과 렌더 기록에 보존했다.

다른 최적화 작업이 변경한 생물 로딩 코드는 보존했다. 기존 렌더의 소스 해시를 바꾸지 않고, 변경 전후 코드의 모델·재질·관절·골격 포즈를 실제 비교한 증거를 별도 저장했다. 교체 외 6,804종의 비교는 차이 0이며, 이후 수정한 나선포엽 50종은 증거의 모델 해시가 달라 새로 렌더했다. `media/biota/runtime/equivalence.json`과 원본 코드 스냅샷을 함께 검증한다.

완성 카탈로그를 사용하는 시드 71491에서 신규 7,000종의 단일 원산지·환경 적합성·방문 순서 독립, 새 은하 50만 주소·평균 항성계 간격, 기존 100만 저장의 50만 이후 주소·원래 생물 보존을 확인했다. 7,745항목 실패 0이며 임시 레시피 주입을 사용하지 않았다. 원산 행성은 1,120개, 태양계에서 중심으로 향하는 쪽 1,018개·기타 102개다. 실제 발견 비율의 분모와 구간은 아래 표에서 구분한다.

## 발견한 문제와 수정

- 새 대표 모델의 첫 게임 촬영에서 Godot가 이전 가져오기 캐시를 사용한 것을 발견했다. 그 28개 촬영 기록은 격리하고 현재 GLB의 SHA와 실제 가져오기 MD5가 일치할 때만 렌더하는 확인을 추가했다. 가져오기를 끝낸 뒤 같은 28개 모델을 다시 렌더해 실패 0을 확인했다.
- 전수 시각 검토에서 나선포엽 식물의 층별 잎 사이에 지지 줄기가 빠진 문제를 발견했다. 해당 50종에 연속된 줄기를 추가하고 원본·게임 렌더를 다시 확인했다. 이 수정은 기본종 수를 늘리지 않는다.

- 2026-09-11 완료 점검에서 분지형 기관 연결 오류가 남아 있음을 확인했다. 기존 동작이 Blender에서 지정한 관절 회전을 절대 Euler 각도로 덮어써 줄기가 한 방향으로 모였다. 새 생물의 관절은 기본 변환에 로컬 동작을 합성하며, 분지 지지줄기는 조직 골격을 따라가도록 수정했다. 대표 분지형·방사형·식물·군락의 두 LOD와 다섯 상태를 재현·확인했고, 같은 코드를 쓰는 신규 전체 모델의 렌더를 갱신했다. 관절의 기본 방향을 잃는 과도한 회전과 뿌리 이탈을 검사에 추가했다.
- Blender 골격의 Godot 포즈에 rest 위치를 빼면 몸체가 원점으로 붕괴하던 문제를 수정했다. 뼈의 rest 변환에 체형별 변위를 결합한다. 대표 13개 유형에서 두 LOD·다섯 상태를 확인했다.
- 7,000종 전체 형상 검사에서 비대근경과 공동저장목 50개씩의 형상이 같던 문제를 찾았다. 공동저장목에 속이 빈 중앙 저장통·비대칭 분지·열린 옆 대사낭·별도 관절의 덮개를 제작해 실루엣과 기관 구조를 구분했다. 재제작 후 전체 형상과 스킨 검사에서 중복·오류가 없었다.
- 원산지 배정표의 부동소수 가중치가 JSON 왕복에서 미세하게 바뀌어 저장 검증값이 달라지던 문제를 수정했다. 확률 추첨은 실수로 계산하고 저장용 통계는 정수 천분율로 남긴다. 실제 저장·재열기와 JSON 왕복 검증값 일치를 확인했다.
- 관측/J 화면은 생물의 실제 형상 경계와 패널 종횡비로 확대한다. 가스 관측 중 지상 착륙 안내가 중첩되지 않는다. T2 재개 검수에서 960×640 도감의 고정 연구 메뉴가 위쪽 미리보기 영역을 줄여 생물 하단을 가리는 문제를 발견했다. 모델·설명·연구 메뉴를 같은 상세 스크롤에 배치하고, 다른 종을 선택하면 위로 돌아가도록 수정했다. 실제 동물/식물 전신 화면과 스크롤 후 표본 메뉴 접근을 확인했다.
- 생물 관측 설명이 왼쪽 환경 상태와 겹치던 화면을 수정했다. 기본 설명은 환경 HUD 아래에 두고, H 상세 환경을 펼치면 레이더 아래 반대쪽으로 옮긴다. 기본 상태의 T2 세 범주를 960×640 실제 창에서 확인했다.
- 지상 검수의 준비 위치에서 캐릭터가 실제 밀도 지면으로 내려앉은 뒤 조준 높이가 달라지는 문제는 검수 절차를 수정했다. 실제 지면에 선 캐릭터에서 다시 조준해 T1/T2 스캔·채집을 확인했다. 생산 코드의 스캔 판정을 넓혀 검사를 통과시키지 않았다. 재개 검수에서는 이동 동물에 고정 지연 후 Q를 누르던 검사가 간헐적으로 채집에 실패했다. 실제 클라이언트/호스트의 현재 조준 대상과 4m 이내 거리가 확인될 때 한 번만 Q를 누르도록 검사 절차를 수정했다. 동물 위치·속도·게임의 사거리 판정은 변경하지 않았다. 자동 검사 종료는 예약된 노드 해제를 한 프레임 더 기다린다. 한 차례의 ObjectDB 잔여 객체 경고는 수정 후 상세 로그 실행에서 재현되지 않았으며, 일반 플레이의 장시간 메모리 검사로 해석하지 않는다.
- 리본형 내보내기의 메시 경고를 원본/가공 후 메시로 분리해 조사했다. 원본 웨이트는 정상이었으며 메시 가공 뒤 일부 값이 미세한 음수가 되었다. glTF 내보내기의 기본 검증이 이를 정리하며, 해당 실제 near/far 파일의 본 인덱스·유한하고 음수가 아닌 웨이트·합계 1을 확인했다. 최종 전체 자산 검사에도 같은 조건을 추가했다. 이 경고를 형상 붕괴로 단정하거나 모든 자산을 불필요하게 재제작하지 않는다.
- 신규 자연 동물은 현재 원정의 비공격 생물 사건 후보에도 연결한다. 거대/희귀 개체는 해당 원산 행성의 기본종과 실제 두 LOD·골격을 사용한다. 공격 동작이 없는 새 종을 둥지 수호자 교전에 강제로 배정하지 않는다. 기존 세계와 새 세계의 생물 사건 후보 캐시도 생태 배정에 따라 구분한다. 이 연결의 데이터 조건은 현장 검사에서 확인하며, 사건 전체의 수집/호송 진행을 새로 플레이한 것은 아니다.
- 최초 분포의 고티어 발견률이 주 탐험 경로에서 낮아지는 것을 전수 집계로 확인해 배정량을 조정하고 완성 카탈로그로 다시 집계했다. 조건부 정착률을 전체 행성 발견률로 표현하지 않는다.


## 남은 경계

- 196종의 눈·얼굴은 체형별로 개선했으나 동일 체형의 7기관 계통은 비슷한 큰 구조를 공유한다. 나머지 얼굴의 일괄 재조형이나 종마다 독립 수작업 원형 제작으로 확대 해석하지 않는다.
- 기존 286종의 미연결 서식 환경, 새 조류 날갯짓/울음 음원, 사냥·먹이사슬 AI, 배포 패키지·Windows 실기·6인 접속은 이번 완료 범위가 아니다. 제작 자산의 존재와 자연 배정·실제 현장 행동의 범위를 구분한다.

## 기존 기본종의 접근 범위

기존 `forms.json`은 600종이다(초기 500 + `aberrant` 괴생물 100). 그중 동물은 400종이며 전체 기본종이 400종인 것은 아니다. 여기에 `xenofauna` 동물 300, `xenoflora` 식물/미생물 100이 더해져 작업 시작 기준이 1,000종이다. 이전 괴생물 100종을 누락하거나 이번 신규 7,000종에 다시 포함하지 않는다.

| 범주 | 보존한 기존 기본종 | 이번 추가 | 합계 |
| --- | ---: | ---: | ---: |
| 동물 | 700 | 4,900 | 5,600 |
| 식물 | 185 | 1,400 | 1,585 |
| 미생물 군락 | 115 | 700 | 815 |
| 전체 | 1,000 | 7,000 | 8,000 |

기본종별 색·크기 외형 20개는 별도다. 총 160,000개 외형 프로필을 기본종 수에 다시 더하지 않는다.

추가 모델의 실제 near/far 파일 합계는 13,827,147,324바이트(약 12.88GiB)이며 Blender 원본 폴더는 약 2.6GiB다. 가장 큰 한 모델은 near 193,028 / far 54,046삼각형, 골격은 최대 85본이다. 개발용 내보내기 파일 크기로, 압축된 배포 패키지 크기나 런타임 상주 메모리와 다르다. 자산 전수 결과는 `media/biota/asset-audit.json`에 둔다.

기존 1,000종 중 286종은 현재 지상 생성기의 서식 환경/이동 방식과 맞지 않아 자연 배정되지 않는다. 기존에도 미연결인 수생·수관·습지 등의 범위이며 자산과 기존 저장은 보존한다. 추가 7,000종은 모두 기존 행성 유형에 맞는 원산 행성을 배정한다. 전체 도감 수와 현재 자연 배정되는 종 수를 구분한다.

## 새 분포의 초기 밸런스 — 완성 카탈로그 전수 집계

값의 소관은 `data/native_biota.json`이다. 티어별 원산 행성 예산은 T1부터 30/80/160/300/550개이며 총 1,120개다. 독점종 수의 배분 가중치는 1/3/10/26/60, 원산 행성 안의 정착 기원 가중치는 65/72/80/86/92%다. 나머지 원산 행성은 휴면 생태이며 그 외 행성은 무생물이다. 정착 가중치는 전체 행성에서의 발견 확률이 아니다.

태양계가 지도 동쪽에 위치하도록 은하를 회전한다. 태양계에서 중심으로 향하는 구간의 생명권 가중치는 `0.12 + 120 × exp(-0.5 × (y / 4)²)`, 태양계보다 바깥쪽은 0.01이다. 지도 반대편의 자연 자원과 지형은 유지한다. 방문 순서와 무관하게 새 은하 생성 시 전체 배정을 확정한다.

조류형·중앙 체형·얼굴 수정을 포함한 완성 `biota_forms.json`으로 시드 71491의 50만 주소를 전수 집계한 결과다. 아래의 **주 경로**는 태양계와 중심 사이 `0 ≤ x ≤ Sun.x`, `|y| ≤ 4`인 좁은 구간이며 화면 왼쪽 절반 전체를 뜻하지 않는다. 분모는 해당 구간·티어의 모든 행성이다. 복원 전 숨겨진 휴면 동물은 제외하고, 관측 가능한 휴면 식물/군락은 포함한다. **지형 차폐·서식 층·실제 이동 시간까지 반영한 분당 목격률은 아니다.**

| 티어 | 주 경로 행성 수 | 동물 발견 가능 행성 | 식물 발견 가능 행성 | 미생물 발견 가능 행성 | 셋 중 하나 이상 |
| --- | ---: | ---: | ---: | ---: | ---: |
| T1 | 188 | 2.13% | 3.72% | 1.06% | 4.79% |
| T2 | 424 | 8.02% | 4.25% | 2.36% | 8.96% |
| T3 | 659 | 13.20% | 9.71% | 7.59% | 16.24% |
| T4 | 851 | 17.98% | 15.86% | 12.10% | 21.50% |
| T5 | 1,238 | 24.39% | 22.13% | 15.51% | 25.85% |

같은 범주들이 한 행성에 함께 살 수 있으므로 세 범주의 백분율을 합하면 안 된다. 은하 전체에서 임의의 같은 티어 행성을 고를 때 관측 가능한 생명이 있는 비율은 각각 0.025/0.067/0.155/0.297/0.547%다. 총 카탈로그 수만으로 생명 행성 확률이 자동으로 높아지는 것이 아니라, 종의 고유성·원산 행성 예산·진행 방향 가중치를 함께 적용한 결과다.

이 시드의 원산 행성당 평균 기본종 수는 T1부터 2.23/2.70/4.71/6.59/8.54종이다. 전체 배정 7,714종 중 추가 7,000종은 누락·다른 행성 중복이 없다. 시드가 달라지면 같은 예산에서도 방향별 비율과 실제 정착 수는 달라진다. 재현 도구는 `tools/measure_native_biota.py`, 원자료는 `media/biota/discovery-distribution.json`이다.

위 수량은 완성된 모델과 정식 카탈로그 등록을 확인한 값이다. 색·크기·이름·ID만 바꾼 항목을 새 기본종으로 세지 않는다. 외계 생물 자료는 가상/이론 자료이며 실제 외계 생명 발견 자료와 구분한다.

정식 7,000종 확장 카탈로그를 모든 새 원본/두 LOD와 해당 모델의 실제 게임 렌더·다섯 상태 검사가 끝난 뒤 생성했다. 일반 새 게임은 완성 카탈로그를 사용한다. 중간 검수용 카탈로그는 별도 경로에 보존한다.

검수용 부분 카탈로그와 원시 제작 레시피는 macOS/Windows 내보내기 제외 목록에 추가했다. 게임 실행은 완성된 기본종·외형·서식 조건 파일만 사용한다. 이번 작업에서 배포 패키지를 새로 빌드하거나 배포 검증을 완료했다는 뜻은 아니다.
