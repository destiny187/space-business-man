# 사격 반응·팔 IK·지속 레이저·협동 지연 보정

2026-09-13 사용자 후속 승인. 총기 고도화 잔여 항목을 진행했다. 기존 탄약/장전/탄도는 [166](166-firearm-ammunition-and-ballistics.md)을 바탕으로 유지한다. 현재 총기는 **9계열·17개 장비**, 탄약은 6종이다. 에이펙스와 동등한 완성도를 인증한 결과는 아니다.

## 플레이 변화

- 발사 입력에 양손과 카메라 반동이 즉시 반응한다. 반동은 입력 방향과 별도로 감쇠해 복귀하며, 호스트의 늦은 응답으로 같은 반동을 다시 넣지 않는다. 거절된 입력은 빠르게 복귀한다. 예측은 되돌릴 수 있는 손/반동에 한정하며 탄 소모·총구·발사음·명중 수치/보상은 호스트 확정을 따른다.
- Blender 장갑을 상완·전완·손목·손가락의 **17개 관절**로 확장했다. 양팔은 카메라에 고정한 어깨와 제한된 쇄골 전진을 기준으로 IK를 풀고 뼈 길이는 늘리지 않는다. 총을 잡는 거리도 조정했다. 총기마다 탄창 분리 방향·분리/삽입/작동 시점과 앞손 위치가 다르며, 손은 실제 가동 탄창의 중심과 장전 손잡이를 따라간다. 기존 탄창식 산탄총 설계를 유지한다.
- **프리즘 레이저 Mk.2/Mk.3**를 제작/장착/신규 전리품에 연결했다. 전용 광학 렌즈·측면 전지·가동 방열판을 Blender로 제작했다. 누르고 있으면 0.1초 단위로 호스트가 지속 광선의 명중과 전지 소모를 확정한다. 광선은 실제 엄폐물에서 끊긴다.
- 레이저 전지는 100단위씩 제작, 200단위 한 슬롯, 60단위 탄창을 사용한다. 발사당 열 0.065, 0.3초 후 초당 0.22 냉각, 열 1에서 잠금/0.28 이하에서 해제한다. 피해·가격을 포함해 초기 밸런스 데이터이며 사용자 확정 수치가 아니다. 전지 부분 장전·기존 예약 탄 규칙을 유지한다.
- 레이저 열 게이지와 과열 색, 실제 방열판 열림을 연결했다. 광선/음원은 사수별 하나를 갱신하고 마지막 확정 발사 후 0.18초 안에 사라진다. 방아쇠를 놓거나 메뉴를 열었을 때 무한히 남지 않는다.
- **기본 권총 T1~T3의 약한 위력·무한 예비탄·유한 탄창/R 장전은 유지**한다. 기존 저장에 재고나 새 레이저를 소급 지급하지 않는다. 기록된 기존 사건은 기존 전리품 풀을 유지하고 새로 기록되는 사건만 새 풀을 사용한다.

## 생물 피격과 협동 판정

`firearm_anatomy.gd`는 실제 로드된 모델의 스킨 가중치로 관절별 작은 경계를 계산하고, 현재 골격 변환을 적용한다. 머리/사지 이름을 판별할 수 있는 뼈에는 해당 피해 배율을 사용하며, 그 외 뼈는 몸통으로 처리한다. 종 ID별 예외 목록이나 이족 전제를 추가하지 않는다. 생물의 원산지·배치·기존 체력 저장은 바꾸지 않는다.

정점 분류는 단일 작업 스레드가 처리하고 메인 스레드는 모델 배열/뼈 정보 준비와 완료 결과 적용만 한다. 모델을 내린 뒤에는 등록을 해제한다. 준비 중이거나 호스트에 모델이 로드되지 않은 표적은 기존 몸통 경계를 사용한다. 삼각형별 정확 판정이나 8,000종 전수 자세 검수, 비행/수중 전투 확장 완료를 뜻하지 않는다.

`firearm_history.gd`는 총을 든 사수 주변 피격 경계와 발사 원점만 50ms 간격으로 6개 보관한다. 클라이언트가 실제 수신한 호스트 스냅샷 시점을 발사 요청에 붙이고, 호스트는 발행한 시점인지 검사한 뒤 최대 200ms까지 적용한다. 다른 행성·과도한 원점 이동·미발행/만료 시점은 현재 판정으로 돌아간다. 원점 사이와 탄 경로는 현재 지형·엄폐물로 다시 검사한다.

레이저는 허용된 과거 표적을 검사한다. 일반 탄환은 과거 발사 원점에서 탄속·중력·짧은 구간 충돌을 유지하며 지연분만큼 따라잡는다. 서버가 과거 체력/보상을 복원하지 않고 **현재 살아 있는 대상**에 한 번만 적용한다. 원격 발사와 착탄은 기존 신뢰 이벤트 전송을 유지한다. 인터넷 왕복 시간의 정밀 추정이나 표적 시점 보간을 추가한 것은 아니다.

## 변경 범위와 남은 비용

- 발사/레이저 한 단위: 사수 총기·해당 피격 대상·작은 영수증/이벤트만 갱신한다. 세계 전체 복사나 지형/시설 전체 재발행은 추가하지 않는다. 실패·중복 요청은 추가 탄 소모/피해/열/발사 이벤트를 만들지 않는다.
- 이력: 소지 총기가 있는 지상 사수의 가까운 표적만 보관한다. 재고·생태 세계·지형 원본을 복사하지 않는다. 근처 표적을 찾기 위한 기존 사건 기록 순회와 생물 배치 조회는 남는다. 6인 최대 밀집 생태계의 장시간 부하는 미측정이다.
- 생물: 정점 배열은 캐시가 없을 때만 읽고 분류 작업은 한 개만 실행한다. 128개 메시 캐시를 제한하며 발사 때마다 정점을 다시 계산하지 않는다. 준비 중 기존 경계 사용의 정확도 차이는 남는다.
- UI/효과: 6개 탄약 카드는 보존하고 닫힌 창은 갱신하지 않는다. 광선은 사수당 하나이며 새 장비/메뉴는 기존 효과 중단 규칙을 따른다. 전투 원자성을 위한 기존 전체 저장 검증·직렬화·체크포인트 대기는 유지한다.

## 자산과 실제 확인

Blender 5.2.1 Cycles와 Godot 4.7.2 Metal Forward+ INK 렌더에서 레이저·전지·팔을 확인했다. 생성기는 `tools/build_precision_laser.py`, `tools/build_firearm_support.py`, 카드 렌더는 `render_firearm_precision.gd`다. 원본 `.blend`, GLB, 렌더와 출처 매니페스트를 함께 보존한다.

레이저 루프는 보존된 **ElevenLabs plasma_v1.wav**의 에너지 꼬리를 이어 붙이고 순환 크로스페이드·저역 통과·DC 제거를 적용했다. 새 합성으로 표기하지 않는다. `audio/manifests/firearm-laser-loop.json`과 `tools/prepare_laser_audio.py`에 원본/결과 해시와 편집 구간을 남겼다. 직접 귀로 들은 음색·거리감·연사 피로도 평가는 미완료다.

- `check_firearm_precision.gd`: 레이저/열/부분 장전, 중복·엄폐·허용/만료/위조 시점, 과거 표적과 탄도 따라잡기, 실제 생물 27개 관절 경계와 자세 추종/해제 확인. 21항목 통과. 50ms 이력 표본의 반올림으로 200ms 상한이 늘어나지 않는 경계도 확인했다. 최초 동기 정점 분류 67.861ms를 작업 스레드로 옮겼으며, 같은 모델의 메인 스레드 준비는 0.262ms, 비동기 완료 관측은 104.576ms였다.
- `review_firearm_precision.gd`: 현재 원정의 9계열 발사·반동 복귀·장전/팔 접점, 레이저 지속/과열/냉각·단일 음원·해제, 960×640 탄약 UI·메뉴 차단·저장을 확인한다. 실제 창은 CUA로도 관찰했다. 최종 66항목 통과, 실행 오류와 종료 잔류 경고 0. 실제 SFX 출력 52.94초, 최대 -11.20dBFS, 클리핑 샘플 0이었다.
- `check_firearm_six_peers.gd`: 호스트+5개 ENet 클라이언트, 60/140/60ms 요청 보류, 18발 전체 승인/6명에게 각 18개 이벤트, 최근 시점 보정, 원격 중복 5개 무소모, 관련 없는 세계 분기 보존을 확인했다. 8항목 통과. 외부망 6인 플레이 결과는 아니다.

첫 실제 화면에서 Godot 관절 변환 적용 오류로 팔이 분리되어 보였다. 로컬 관절 변환을 바로잡고 총을 잡는 거리를 줄였다. 긴 총의 앞손 도달과 탄창 중심 접점도 추가 조정했다. 초기 화면 실패 18개/후속 도달 실패 5개와 수정 전 화면을 보존한다. 생물 등록 정리 중 생긴 중복 종료 함수 파싱 오류도 수정했다. 자료는 `output/firearm-precision-20260913/`에 있다.

현재 범위 밖: 직접 마우스로 다양한 상대를 추적하는 장시간 손맛/밸런스 평가, 모든 생물 자세의 실루엣 정합, 외부망 6인·패킷 손실/장기 지연, 직접 청감 평가와 에이펙스 동등 완성도 판정.

## 지상 보호막 표현 정정

같은 날 사용자 요청으로 지상 보호막의 시각 효과를 줄였다. 쿠퍼테크 로봇의 상시 구체와 승무원 피격 구체를 제거하고, 총탄이 맞은 위치에 0.09초의 작은 섬광과 미세 불꽃 1개만 남긴다. 파괴 때도 0.13초·미세 불꽃 2개로 제한하며 퍼지는 원/큰 파편은 없앴다. 명중 표시와 피해 수치 옆의 작은 파괴 표시는 유지하고 조준점 주변의 별도 파괴 배지·원호는 제거했다. 플레이어 피격은 화면 전체의 파란 테두리/균열 대신 기존 보호막 게이지 아래 짧은 선으로 표현한다. 크기·시간은 초기 조정값이다.

기존 ElevenLabs 보호막 타격/파괴 음원을 재사용한다. 일반 명중 확인음은 0→-1dB, 파괴 확인음은 +1→+3dB로 조정하고 기존 발사음 일시 감쇠 경로를 사용한다. 자신이 보호막을 잃을 때도 같은 파괴음 우선 경로를 적용한다. 음원을 새로 생성하지 않았으며 비행 보호막의 시각·소리는 변경하지 않았다.

행동 범위: 호스트가 확정한 접촉 하나당 기존 효과 풀에서 섬광 하나와 불꽃 최대 두 개만 사용한다. 보호막 체력·흡수·재충전, 피해 판정, 저장 형식과 네트워크 발행은 바꾸지 않는다. 승무원 표시는 기존 최대 6명 일련번호를 확인하고 같은 장소의 연결된 지상 동료만 반영한다. 동료 피격 스냅샷에는 정확한 접촉 위치가 없어 가슴 부근을 사용하며, 메뉴에서는 효과를 차단한다. 세계 복사·지형/모델 재생성·전체 UI 갱신을 추가하지 않는다.

`review_ground_shields.gd`로 현재 원정의 실제 Forward+ 창에서 보호막 흡수 20, 남은 보호막 3 파괴/체력 피해 17, 작은 접촉 효과·파괴음 재생·효과 소멸·메뉴 차단·저장을 확인했다. 최종 20항목 통과. 실제 SFX 녹음은 3.61초, 최대 -10.14dBFS, 클리핑 0이다. 자기 보호막 HUD는 표시 상태를 주입해 화면을 확인했으며 원격 동료 피격과 직접 청감 평가는 이번 실행에서 확인하지 않았다.

초기 검수 데이터가 정상 체력/보호막 상한을 넘어 저장이 거절되어 실제 정의값으로 고쳤다. 이어 저장 처리 중 첫 발이 `weapon_blocked`로 거절되어 검수에서 해당 저장 완료와 호스트 입력 준비를 기다리도록 했다. 일반 플레이의 저장 중 발사 거절 경로를 변경한 것은 아니다. 종료 시 RefCounted 2개 잔류 경고가 남았으며 원인은 이번 표현 변경 범위에서 해결하지 않았다. 실패/최종 로그·음원은 `output/ground-shields-20260913/`에 보존한다.
