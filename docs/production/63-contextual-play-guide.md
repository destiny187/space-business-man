# 우주 화면 직접 항해·플레이 가이드 — 2026-09-08

## 확정 방향

첫 태양계만 별도의 출격 방식으로 배우지 않는다. 사용자가 정정한 기준은 **G 은하 지도 중심 안내가 아니라 우주 화면의 항성계 표식을 조준하고 클릭/F로 직접 이동하는 방법**이다. 첫 플레이어에게 기본 표시하며 끌 수 있는 비강제 화면 가이드를 우주부터 지상까지 연결한다.

## 구현

- 태양계 환영 편지는 기존 형태·읽음 기록·접기 동작을 유지하고 이동 문구만 표식 조준/클릭/F로 갱신했다. 특별한 ‘출격하기’ 버튼 표기는 공통 보조 지도 버튼으로 바꿨다. 첫 태양계와 이후 항성계 모두 기존 `nearby_stars`의 실제 표식·같은 클릭/F·같은 호스트 항로 승인으로 이동한다. 튜토리얼이 목적지를 자동 선택하거나 출발시키지 않는다.
- 가이드가 실제 항속거리 내 표식 또는 화면 가장자리 방향 화살표에 선·테두리를 연결한다. 조준하면 별 이름/거리 확인과 클릭/F 안내로 바뀌고, 호스트가 항해를 승인하면 이동 중 안내로 바뀐다.
- 실제 다른 항성계 도착을 기록하고 착륙 가능한 행성 방향·접근·근접 F를 안내한다. 지상에서는 I 장비 준비→채집기 선택→광맥 조준/클릭 유지→기존 B 건설/F 작업 조작으로 이어진다. 자동화 완료를 필수 목표로 삼지 않는다.
- 승무원은 준비/조종사 권한을 안내한다. FINCH는 항성계 내부 이동과 공동선 합류를 안내한다. G 지도는 우측 상단의 작은 보조 버튼으로 유지한다.
- **설정 → 조작 · 소리 → 플레이 가이드**: `처음 플레이어만`(기본), `항상 표시`, `끄기`. 설정은 기존 로컬 설정 파일에 저장한다. ‘항상 표시’는 기존 플레이어도 다시 배울 수 있는 수동 선택이다.
- 개인 프로필과 같은 폴더의 `play_guide.cfg`에 캐릭터별 자동 대상 여부·항해 경험·아이템창 확인·첫 채집 완료를 기록한다. 세계가 바뀔 때 매번 신규 플레이어로 취급하지 않는다. 처음 적용할 때 이미 접속 이력이 있는 프로필은 자동 대상에서 제외한다. 기기 간 계정 동기화는 아니다.
- 첫 실제 지상 획득의 호스트 성공 응답 후 자동 가이드를 완료한다. 설정의 ‘항상 표시’는 완료 후에도 현재 장소에 맞는 도움말을 유지한다. 실패 응답만으로 완료하지 않는다.
- 로딩·설정·착륙 연출·관련 없는 메뉴에서 가리며, 안내 자체는 이동/입력을 가로채지 않는다. 새 모델·음원은 만들지 않고 기존 아이콘과 실제 항해 효과·음원을 사용한다.

## 확인과 경계

Godot 4.7.2 / Apple M2 / Metal Forward+ 실제 창, 격리한 임시 프로필/세이브로 확인했다.

- 편지를 접은 뒤 신규 플레이어 자동 표시·실제 주변 표식 5개·표식에 커서를 옮겼을 때 직접 출발 안내.
- 기존 표식의 F 입력 처리 → 호스트 `jump` 승인 → 다른 항성계 도착과 항해 경험 저장. 가이드만의 이동 API를 만들지 않았다.
- 설정에서 끄기 즉시 반영·자동 표시 복구. 도착 전/후 실제 렌더 확인.
- 구현 도중 지도 기반 안내를 검사용으로 실행했을 때 메뉴 차단 조건으로 안내가 숨고 후보 선택 검사가 실패했다. 사용자 정정 후 지도 후보 안내를 제거하고 위 직접 표식 흐름으로 검증했다.
- 실제 여러 기기의 신규 승무원, 인터넷 지연, 전체 회귀·자동화 전수·장시간 성능은 검증하지 않았다. 저장은 로컬 개인용이며 모든 UI 개편 완료를 뜻하지 않는다.

사용자 추가 정정: 환영 편지는 유지한다. 구현 중 제거했던 편지 UI·세계/캐릭터별 읽음 기록을 복구하고 직접 항해 문구만 변경했다. 편지 표시 중 가이드는 숨기며 접은 뒤 시작한다.

추가 최소 확인: 기존 격리 지상 세이브의 960×640에서 장비 안내·아이템창 확인 기록·설정 항목을 확인했다. 환영 편지 복구 후 같은 크기의 실제 창에서 편지 표시→접기→표식 안내 전환과 읽음 저장을 확인했다. 편지의 지역 변수와 가이드 제목 변수의 충돌을 수정했으며 마지막 실행 로그에 스크립트/엔진 오류가 없다. 함께 추가된 선내 설비의 `app.ui` 접근 오류는 기존 UI 루트를 멤버로 노출해 수정했다. 첫 채집 성공에 따른 자동 완료의 전체 실제 채집 흐름은 이번에 다시 실행하지 않았다.
