# 우주 화면 직접 항해·플레이 가이드 — 2026-09-08

2026-09-10 첫 화면 후속: 신규 원정의 지구 주시·Sol 제목·후진/선회 연출 동안 편지와 가이드를 숨기고, 연출 완료 뒤 직원 업무 안내 → 확인 → WASD 가이드로 연결한다. 튜토리얼 단계 자체와 끄기 옵션은 유지한다. [시작 연출·실제 확인](20-galaxy-start-and-lobby.md).

## 2026-09-10 후속 — 직원 대상 첫 원정 업무 안내

사용자 요청으로 첫 편지 제목을 `첫 원정 업무 안내`, 발신·서명을 `Lotus 개척사업부`, 닫기 버튼을 `확인`으로 정리했다. 원정 담당 배치·태양계 밖 후보지 조사·현장 선정과 작업 계획의 재량·회사 보급을 직원에게 전달하는 문체를 사용한다. 복원 화성이 있는 세계에는 Space Y 관리 사실만 덧붙인다. W/S·Shift·주시 스캔·항성 표식·F/Tab·FINCH 탑승 설명과 멘토식 표현은 편지에서 제거했다. [소관 이야기 규칙](../game/19-lotus-story-and-support.md).

별도 튜토리얼 순서·출발 잠금·옵션·읽음 저장은 그대로 연결한다. Godot 4.7.2 / Metal Forward+의 격리한 새 원정, 960×640 실제 창에서 짧아진 본문 전체·확인 버튼이 잘리지 않고 표시되는 것과 확인 후 WASD 가이드 전환을 확인했다. [실제 화면](media/solar-start-guide/employee-briefing-960.png) · [확인 기록](media/solar-start-guide/employee-briefing-verification.txt). 문구와 해당 화면만 확인했으며 항해 전체 회귀는 반복하지 않았다.

## 2026-09-10 — 태양계를 둘러보는 시작 가이드

사용자 변경에 따라 환영 편지를 접은 뒤 `WASD 이동 → Shift 가속 → 화성 주시 스캔 → 성간 출발`로 안내한다. 이 항목은 아래 2026-09-08의 비강제 출발 안내보다 우선한다.

- W/S 전후진과 A/D 좌우 선회가 실제 공동선 조종 입력으로 연결된다. 마우스 조향도 유지한다. 실제 전후진 또는 키보드 선회가 확인된 입력 1.5초, W + Shift와 호스트의 가속 상태가 확인된 입력 1초를 순서대로 완료한다. 시간은 `data/play_guide.json`의 조정값이며 별도의 대기 시간을 강요하지 않는다.
- 화성의 실제 공전 위치를 화면 표식/가장자리 방향으로 가리킨다. 기존 주시 스캔 원·결과·ElevenLabs 완료음을 이용한다. 화성 단계에서 화성을 보고 스캔 결과를 확인해야 완료한다. 앞서 조사한 화성도 다시 바라보면 기존 결과로 완료할 수 있다. 다른 행성이나 메뉴에서 본 알려진 정보만으로 완료하지 않는다.
- 앞 세 단계가 남아 있으면 주변 별 표식에 현재 필요한 행동을 표시하고 은하 지도 출발 버튼을 잠근다. 공통 로컬 요청 입구에서도 `navigate`·`depart`·구형 `tutorial_depart`의 성간 이동을 막아 미리 고른 항로로 건너뛰지 못한다. 태양계 내부 비행·자동 접근·항만 교역은 허용한다. 정상 호스트 항해 승인·기존 항속거리/선박 조건을 그대로 사용한다.
- 설정 `플레이 가이드 → 끄기`는 완료 여부와 관계없이 잠금을 즉시 해제한다. 다시 켜면 남은 단계부터 이어간다. 기본 `처음 플레이어만`에서 기존 자동 대상 제외 플레이어는 잠그지 않는다. 이미 성간 항해를 했거나 지상 가이드를 끝낸 캐릭터도 태양계로 돌아왔다는 이유로 재잠그지 않는다.
- 완료한 세 연습은 기존 캐릭터별 `play_guide.cfg`에 저장한다. 부분 연습 시간은 세션 중에만 누적한다. 메뉴·편지·로딩·조종 권한 없음·자동 접근 중에는 완료시키지 않는다. 협동에서는 실제 조종사의 로컬 가이드/옵션이 자신의 출발 요청을 제어하며 모든 승무원의 수료를 공동 필수 조건으로 만들지 않는다. 이는 개인 튜토리얼이며 호스트 보안 규칙을 새로 추가한 것은 아니다.
- 환영 편지와 후속 착륙·장비·첫 채집 안내를 보존한다. 새 모델/음원 제작 없이 현재 Blender 태양계 모델·INK 렌더와 기존 비행·스캔·성간 효과/음원을 재사용한다.


### 이번 확인과 경계

Godot 4.7.2 / Apple M2 / Metal Forward+ 실제 창, 별도 임시 프로필·세이브로 확인했다. A키가 호스트 선체를 실제 선회시키며 첫 단계를 완료하고, W + Shift 입력과 실제 가속 상태가 둘째 단계를 완료했다. Shift 단독·메뉴 중 키 입력은 완료시키지 않았다. 카메라를 화성으로 향하는 검사 보조를 사용했으며 실제 주시 스캔 타이머·완료·조사 기록과 기존 스캔 음원 재생을 확인했다.

완료 기록을 다시 읽은 실제 재실행에서 세 단계 보존, 미완료 상태의 성간 요청/지도 잠금, 옵션 끄기의 즉시 해제, 다시 켰을 때 기존 선택 항로의 출발 차단, 정상 항속거리 내 표식 출발·호스트 승인·성간 도착·저장을 확인했다. [마지막 관련 검사 기록](media/solar-start-guide/verification.txt)은 12개 실패 0개다. 전체 입력 흐름을 반복하는 대신 남아 있던 옵션/항로/저장 범위만 재확인했다.

확인 중 환영 편지의 본문 길이가 960×640에서 닫기 버튼을 밀어내는 문제를 본문 스크롤·고정 닫기 버튼으로 수정했다. 화성 표식이 카드 뒤에 숨는 경우 카드 위치를 옮기고 화성 이름을 붙였다. 초기 검사 도구는 구형 추천 목적지를 골라 거리 33.4 / 선체 항속 8 제한에 걸렸다. 실제 주변 별 표식의 도달 가능한 항로로 검사 대상을 수정했으며 항속거리 규칙은 바꾸지 않았다. 마지막 실행에 스크립트/엔진 오류가 없다.

## 확정 방향

첫 태양계만 별도의 출격 방식으로 배우지 않는다. 사용자가 정정한 기준은 **G 은하 지도 중심 안내가 아니라 우주 화면의 항성계 표식을 조준하고 클릭/F로 직접 이동하는 방법**이다. 첫 플레이어에게 기본 표시하며 끌 수 있는 비강제 화면 가이드를 우주부터 지상까지 연결한다.

## 구현

- 태양계 환영 편지는 기존 형태·읽음 기록·접기 동작을 유지하고 이동 문구만 표식 조준/클릭/F로 갱신했다. 특별한 ‘출격하기’ 버튼 표기는 공통 보조 지도 버튼으로 바꿨다. 첫 태양계와 이후 항성계 모두 기존 `nearby_stars`의 실제 표식·같은 클릭/F·같은 호스트 항로 승인으로 이동한다. 튜토리얼이 목적지를 자동 선택하거나 출발시키지 않는다.
- 가이드가 실제 항속거리 내 표식 또는 화면 가장자리 방향 화살표에 선·테두리를 연결한다. 조준하면 별 이름/거리 확인과 클릭/F 안내로 바뀌고, 호스트가 항해를 승인하면 이동 중 안내로 바뀐다.
- 실제 다른 항성계 도착을 기록하고 착륙 가능한 행성 방향·접근·근접 F를 안내한다. 지상에서는 I 장비 준비→채집기 선택→광맥 조준/클릭 유지→기존 B 건설/F 작업 조작으로 이어진다. 자동화 완료를 필수 목표로 삼지 않는다.
- 승무원은 준비/조종사 권한을 안내한다. FINCH는 항성계 내부 이동과 공동선 합류를 안내한다. G 지도는 우측 상단의 작은 보조 버튼으로 유지한다.
- **설정 → 조작 · 소리 → 플레이 가이드**: `처음 플레이어만`(기본), `항상 표시`, `끄기`. 설정은 기존 로컬 설정 파일에 저장한다. ‘항상 표시’는 기존 플레이어도 다시 배울 수 있는 수동 선택이다.
- 개인 프로필과 같은 폴더의 `play_guide.cfg`에 캐릭터별 자동 대상 여부·항해 경험·아이템창 확인·첫 채집 완료를 기록한다. 세계가 바뀔 때 매번 신규 플레이어로 취급하지 않는다. 처음 적용할 때 이미 접속 이력이 있는 프로필은 자동 대상에서 제외한다. 기기 간 계정 동기화는 아니다.
- 첫 실제 지상 획득의 호스트 성공 응답 후 자동 가이드를 완료한다. 설정의 ‘항상 표시’는 완료 후에도 현재 장소에 맞는 도움말을 유지한다. 실패 응답만으로 완료하지 않는다.
- 로딩·설정·착륙 연출·관련 없는 메뉴에서 가리며, 안내 자체는 이동/입력을 가로채지 않는다. 새 모델·음원은 만들지 않고 기존 아이콘과 실제 항해 효과·음원을 사용한다.

## 확인과 경계

Godot 4.7.2 / Apple M2 / Metal Forward+ 실제 창, 격리한 임시 프로필/세이브로 확인했다.

- 편지를 접은 뒤 신규 플레이어 자동 표시·실제 주변 표식 5개·표식에 커서를 옮겼을 때 직접 출발 안내.
- 기존 표식의 F 입력 처리 → 호스트 `jump` 승인 → 다른 항성계 도착과 항해 경험 저장. 가이드만의 이동 API를 만들지 않았다.
- 설정에서 끄기 즉시 반영·자동 표시 복구. 도착 전/후 실제 렌더 확인.
- 구현 도중 지도 기반 안내를 검사용으로 실행했을 때 메뉴 차단 조건으로 안내가 숨고 후보 선택 검사가 실패했다. 사용자 정정 후 지도 후보 안내를 제거하고 위 직접 표식 흐름으로 검증했다.
- 실제 여러 기기의 신규 승무원, 인터넷 지연, 전체 회귀·자동화 전수·장시간 성능은 검증하지 않았다. 저장은 로컬 개인용이며 모든 UI 개편 완료를 뜻하지 않는다.

사용자 추가 정정: 환영 편지는 유지한다. 구현 중 제거했던 편지 UI·세계/캐릭터별 읽음 기록을 복구하고 직접 항해 문구만 변경했다. 편지 표시 중 가이드는 숨기며 접은 뒤 시작한다.

추가 최소 확인: 기존 격리 지상 세이브의 960×640에서 장비 안내·아이템창 확인 기록·설정 항목을 확인했다. 환영 편지 복구 후 같은 크기의 실제 창에서 편지 표시→접기→표식 안내 전환과 읽음 저장을 확인했다. 편지의 지역 변수와 가이드 제목 변수의 충돌을 수정했으며 마지막 실행 로그에 스크립트/엔진 오류가 없다. 함께 추가된 선내 설비의 `app.ui` 접근 오류는 기존 UI 루트를 멤버로 노출해 수정했다. 첫 채집 성공에 따른 자동 완료의 전체 실제 채집 흐름은 이번에 다시 실행하지 않았다.
