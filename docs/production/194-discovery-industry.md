# 발견에서 환경 설비로 이어지는 첫 산업 연결

2026-09-14 후속: [195 구현](195-discovery-exhibits.md)에서 현재 특수 발견 21종과 사건 22종의 전시품을 추가했다. 아래 전시품이 후속이라는 설명은 이 작업 당시의 경계이며 현재 두 실용 설비는 그대로 유지된다.

2026-09-14 사용자 요청에 따라 모든 발견에 효과를 강제하지 않고 일부 발견을 입지와 공급 방식을 바꾸는 설비에 연결했다. 이후 사용자가 요청한 자연물과 결합한 디자인으로 두 모델을 다시 제작했다. 소관 설계는 [발견 활용](../game/30-special-discovery-uses.md), 계열별 다른 종류와 개별 1회 강화는 [시설 성장](../game/31-facility-growth-and-tradeoffs.md)을 따른다.

## 이번 구현

| 발견과 연구 | 새 설비 | 실제 조건과 출력 |
| --- | --- | --- |
| 이슬 돌그릇 조사 완료 → 착륙선 F 연구 → 공동 설비 | 응결 집수기 | 대기 15kPa 이상, 자연 수분 지표 18% 이상, 현장 온도 -10~55°C, 전력 4kW. 12초마다 냉각한 응결수인 얼음 1개를 현장 창고에 공급 |
| 열수 굴뚝 무리 조사 완료 → 같은 연구 경로 | 열수 발전기 | 해당 행성에서 조사를 완료한 실제 열수 굴뚝 48m 이내. 가동 시 해당 공급 구역에 18kW 공급 |

이 수치는 초기 밸런스다. 단일 데이터는 [discovery_industry.json](../../우주-비즈니스/data/discovery_industry.json)이다. 자연 수분 지표는 현행 생태 프로필의 moisture이며 별도의 실제 상대습도 시뮬레이션을 추가한 것은 아니다. 현장 온도는 복원 상태의 온도를 사용한다. 지형과 시드, 기존 발견 생성 위치는 바꾸지 않는다.

연구 비용은 공동 자금 350/500 Cr와 연구자의 철 12, 구리 8이다. 기존 공동 설비 연구처럼 호스트가 구매한다. 설계는 원정 공유이며 누구나 자기 배낭 재료로 해당 설비를 건설할 수 있다. 집수기 건설은 철 25, 구리 15, 암석 12이고, 발전기는 철 35, 구리 20, 암석 20이다.

두 종류는 기본 상태에서 한 번 강화한다. 각 건물마다 현장 창고의 열전달 유닛 2개와 보강 프레임 1개를 사용한다. 집수는 8초에 얼음 1개, 발전은 27kW가 된다. 원래 환경 조건은 그대로다. 게임에는 `설비 강화`, `강화 완료`로 표시하고 세 번째 강화는 제공하지 않는다. 내부 저장은 기존 tier 1/2를 재사용한다.

새 설비를 얻지 못해도 기존 얼음 채굴 및 운송, 기초 발전으로 진행할 수 있다. 스캔만으로 광물, 장비와 재화를 주는 보상을 되살리지 않는다. 열수 발전은 아무 곳에나 건설할 수 있지만 조사한 열원 범위 밖에서는 발전하지 않는다. 집수기도 조건이 맞지 않으면 멈추며 건설 자체를 행성 티어로 금지하지 않는다.

창고가 없거나 가득 차면 집수를 멈춘다. 전력이 없거나 정지, 침수, 지지 토대 붕괴, 습도와 온도 조건 미충족이면 생산하지 않는다. 얼음은 기존 수질 시설, 배양과 제조에서 사용하는 동일 자원이다. 임시 화면 수치나 별도 장식용 출력이 아니다.

## 자연과 결합한 형태 및 화면

원본 이슬 돌그릇과 열수 굴뚝의 게임 카드를 확인한 뒤 형태를 재설계했다. 집수기는 침전된 가장자리를 가진 세 수반과 중력 회수 배관, 작은 냉각기가 중심이다. 발전기는 높이가 다른 속 빈 광물 기둥에 고정구, 열 회수 배관과 작은 터빈을 연결했다. 자연의 구조가 본체를 이루고 기계가 그 기능을 돕는다.

Blender 원본은 `art/blender/buildings/dew_condenser.blend`, `geothermal_generator.blend`다. 게임 GLB와 투명 건설 카드, 편집 가능한 생성기 [build_discovery_industry.py](../../tools/build_discovery_industry.py)를 보존했다. 초기의 일반 공장 형태는 최종 디자인이 아니다. 강화 시 자연 본체를 유지하고 기존 제작된 소형 보조 팩을 옆에 추가한다.

T 스캔 결과와 J 발견 상세에 설비의 용도 및 연구 장소를 표시한다. 연구 전 B에서 해당 설비를 숨기고 연구 후 같은 카드가 열린다. 배치 고스트에는 현장 조건과 가동 가능 여부를 표시한다. 조건이 안 맞아도 배치 가능 상태를 유지하고 가동 불가 이유를 함께 보여준다. F에는 실제 가동 상태, 필요 조건과 강화 비용을 표시한다.

팬 및 터빈은 호스트의 working 상태에 따라 움직인다. 기존 ElevenLabs의 집수 및 열 설비 가동음을 재사용하고 기존 건설 완료 연출을 연결했다. 신규 곡이나 돌기둥 연주음을 제작한 것은 아니다.

## 변경 범위와 호환

신규 건물과 연구 정의를 별도 데이터에서 기존 카탈로그, 건설 목록과 연구 목록에 합친다. 기존 카탈로그와 사업 규칙 해시를 일괄 갱신하거나 실제 사용자 저장을 재작성하지 않는다. 예전 발견 완료 기록도 그대로 연구 증거로 인정한다. 라이선스는 기존 공용 목록, 강화와 생산 진행은 기존 건물 상태로 보존한다.

다른 행성으로 이동해도 연구 증거를 알 수 있도록 기존 발견 스냅샷 순회에서 두 연구의 완료 여부만 함께 집계한다. 다른 행성의 발견 위치와 전체 기록을 추가로 복사하지 않는다. 닫힌 연구 창은 미리보기 모델을 새로 만들지 않는다.

연구 요청은 해당 캐릭터, 비용과 라이선스 및 현재 사업 현장의 초안만 복사한다. 발견 원본과 다른 행성은 읽기 전용으로 공유한다. 지역별 facade 합치기 때문에 해당 현장의 전체 복사는 유지하며, 호스트 확정 및 저장 검증을 생략하지 않는다. 기존 전체 무결성 검사는 남아 있다.

산업 계산은 기존 현장 tick과 전력 배분에 연결한다. 새 집수기는 자신의 진행과 해당 창고 얼음만 바꾼다. 발전량은 해당 공급 구역에 반영하며 다른 행성의 지형과 모델을 다시 만들지 않는다. 열원 조회는 발견 기록 사전이 교체되거나 새 기록이 추가될 때 행성별 굴뚝 인덱스를 만들고 이후 같은 행성의 굴뚝만 읽는다. 단계와 완료 여부는 현재 기록 참조로 확인한다. 인덱스는 메모리에 한 원본만 보관하며 저장하지 않는다. 기존 스냅샷 순회와 사전 교체 시의 1회 전체 읽기 비용은 유지하고 매 발전기마다 전수 기록을 복사하거나 순회하지 않는다.

## 확인과 남은 범위

관련 규칙 검사 20개에서 발견 증거, 유료 연구와 중복 차감 방지, 이동 후 공용 증거, 환경 및 열원 거리, 실제 전력, 창고 출력 및 포화, 강화 1회와 거래 초안 범위를 확인했다. [규칙 검사](../../우주-비즈니스/tests/check_discovery_industry.gd)는 실패 없이 종료했다.

[Forward+ 원정 검사](../../우주-비즈니스/tests/check_discovery_industry_play.gd)는 별도 `/tmp/discovery-industry-play` 세계에서 실제 시드의 두 발견 위치, 원래 대기와 수분 조건, 공동 연구 버튼, 건설 카드와 배치, 18kW 발전, 창고 얼음 생산, 팬 동작, 유료 강화와 저장 후 다시 읽기를 확인했다. 해당 행성은 약 100kPa, 자연 수분 지표 29%, 초기 온도 약 48°C다. 기존 발견의 모든 굴착 및 관찰 단계를 새로 플레이한 검사는 아니며, 실제 발견 기록을 완료 상태로 준비한 뒤 새 연구부터 실행했다. UI 검사는 960×640 창에서 진행했다.

확인 중 설비 F가 관리 탭부터 열리는 문제, 새 설비에도 Mk 표기가 남는 문제, 강화 비용 화면이 설비 대신 플레이어 공급 구역의 재고를 참조하는 문제와 스크롤 아래 강화 버튼을 수정했다. 본 흐름의 마지막 실행은 34개 중 33개가 통과했고 서버의 강화 직후 화면 갱신을 기다리지 않은 검사 하나가 실패했다. 해당 검사를 스냅샷 반영 대기로 수정하고 전체 흐름을 반복하는 대신 [완료 상태 후속 검사](../../우주-비즈니스/tests/check_discovery_industry_finish.gd)에서 강화 완료 표시, 추가 강화 차단, 자연 모델과 보조 팩, 기존 가동음 연결 및 저장 재개 등 10개를 실패 없이 확인했다.

Blender Cycles와 Godot Forward+ / Metal의 INK 렌더 및 실제 원정 화면에서 자연 결합 모델을 확인했다. 떨어져 보이던 집수 계측기를 냉각기 측면에 고정하고 강화 팩도 기계부에 붙였다. 기존 물 및 열 설비 음원 스트림의 재생 연결은 확인했으나 청감 비교와 메뉴 개폐 시 실제 음향 차단은 완료 판정에서 제외한다. 직접 재생 직후 일시정지 속성을 읽는 보조 검사는 실패했으며 메뉴 실사용 재현으로 확정한 버그는 아니다. 종료 시 ObjectDB 잔여 인스턴스 경고가 남았고 이 변경에서 원인을 확정하지 않았다.

[강화 완료 화면](media/discovery-industry/enhancement-complete.png), [강화 집수기 현장](media/discovery-industry/enhanced-condenser.png), [열수 발전 현장](media/discovery-industry/natural-geothermal.png). 현장 캡처는 마지막 계측기 부착 위치 정리 전이며 최종 위치와 카드 외형은 위 INK 렌더를 따른다. 마지막 계측기 위치 수정 후 전체 원정 검사는 반복하지 않았다.

기본 연구와 가동 연결 두 종이 이번 범위다. 별도 특수 도감 탭, 연주 및 상호작용 놀이, 전시품 제작, 자성 선별, 생물 반응조, 수지 및 섬유 재배와 빛 제어 설비는 후속 설계다. 18개 설비 전체 재편과 복수 제조법의 구현 완료를 뜻하지 않는다.

열원 고갈, 열원별 발전 총량, 주변 열 감소와 발전 간섭은 아직 없다. 집수는 기존 수분 프로필과 현장 온도를 사용하며 날씨별 실시간 상대습도 및 수증기 유체는 미구현이다. 원본 발견물을 철거하거나 실제 살아 있는 표본을 이 두 설비에 장착하는 기능도 포함하지 않는다. 사용자가 다른 PC에서 분석하기로 한 저장 실패 제보는 조사하지 않았다.
