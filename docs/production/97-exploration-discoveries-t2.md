# 탐험 발견 T1/T2 — 20종 현장 구현

2026-09-09. [소관 기획](../game/20-exploration-discovery-expansion.md)의 후속 승인으로 T2까지 개발했다. T3부터 잃어버린 기술의 기록·도면을 복원하여 설계도를 확보하고 우주정거장에서도 구매할 수 있는 방향은 [경제·기술](../game/05-economy-and-progression.md)에 반영했다. 이 작업에서 T3 설계도 상점·해금이나 T3~T5 30종을 구현한 것은 아니다.

## 현재 원정에서 하는 일

멀리 보이는 지형·구조물을 찾아 접근한다. 가까이에서 보라색 조사 고리를 조준하고 **E를 유지하여 조사한 뒤 F로 단계 작업**을 수행한다. 다음 조사 지점으로 이동하거나 지형 변환기·채집기를 장착하고, 고장 난 장치에는 실제 배낭의 수리 재료를 소비한다. 완료한 장소와 보상은 세계에 저장되며 J의 탐험 장소 분류에서 모델 카드·단계·좌표·획득 성과를 확인한다.

- T1 10종: 노래하는 돌기둥, 운석 유리, 이슬 돌그릇, 소금꽃, 탈피 흔적, 화석 물결층, 휴면 종자 주머니, 철모래 띠, 빈 껍질 피난처, 추락 관측 캡슐.
- T2 신규 10종: 속 빈 수정암, 발광 얕은 수역, 매몰 수로, 열수 굴뚝 무리, 포자 돛, 자성 아치, 수몰 기록기, 화석 둥지, 거울 협곡, 버려진 시추기.
- 보상: 원료·인산염·소량 사파이어·가공 철/구리, 기존 생태 연구에 연결되는 실제 식물/미생물 표본, 실제 주변 광맥의 발견 및 좌표, 조사 지식 기록, 수로의 유한한 방수. 아이템 공간이 없으면 최종 회수는 실패하고 현장에 남는다.
- 단계와 실물은 호스트가 확정한다. 같은 요청 재전송은 같은 결과만 반환하며 다음 사람이 완료된 장소에서 실물을 다시 받을 수 없다. FINCH의 행성별 컨텍스트에서도 발견 기록을 공동 세계로 반영한다.

## 배치와 저장

`data/exploration_discoveries.json`이 20종·환경 조건·단계·도구·재료·보상·음원·밀도를 소유한다. 320m 타일당 T1 최대 4종, T2 이상 최대 6종이다. T2부터 적합한 신규 유형 2종을 먼저 시도하고 하위 유형을 섞는다. 현재 T3~T5에서도 T2까지의 카탈로그만 사용한다. 전체 기획의 8/10/12종 밀도는 후속 콘텐츠와 함께 늘린다.

대기·온도·수분·원생 생명 조건에 맞는 후보를 고르고 얕은 수역·기본 지형 높이·경사·35m 간격·착륙지 38m 제외 조건을 확인한다. 조건에 맞는 지점이 없으면 그 타일의 수량은 목표보다 적다. 조사 지점 사이 고도 차이를 제한해 표식이 지하에 묻히는 것을 방지한다. 새 표본은 임의 종을 만들어 넣지 않고 해당 행성의 시드 계통에서 선택하며 저장 검사도 같은 계통과 장소를 검증한다.

관측하지 않은 타일은 저장하지 않는다. 관측한 장소는 `world.discoveries.records`의 행성/장소 ID에 단계·스캔 단계·완료·발견자·표본·광맥 단서를 보관한다. 예전 저장은 발견 기록을 빈 상태로 추가한다. 해당 행성의 진행은 스냅샷에, 전체 발견 목록은 기존 페이지 조회에 연결한다.

기존 구매형 캠페인의 문명 생성 목록에서 `civilization`을 제거했다. 저장을 읽거나 확정할 때 기존 마을 이벤트는 `retired_civilizations`로 옮기고 진행 중 작전과 마을 접근을 없앤다. 계정·장비·로봇·기존 지급 재화·이력은 보존한다. 미래 고지능체용 코드·모델 자산 자체는 삭제하지 않는다.

## 모델·음향과 실제 범위

Blender 원본 20개, GLB 20개, Godot INK 카드 20개를 제작했다. 수정암 외피·퇴적 덮개 제거, 장치 덮개 회전, 시추기 회전, 포자 막 흔들림, 발광 수역 차광판 전개와 빛 변화, 열수 분출 입자를 연결했다. 공통 `ink_blender.py`/`ink_materials.json`과 현재 게임의 INK 스타일을 적용했다. 자산 목록에 `authored-discovery-first-pass`로 기록했으며 승인 기준작 이상의 최종 형태 완성을 주장하지 않는다.

[Blender T1](media/exploration-t2/blender-t1.png) · [Blender T2](media/exploration-t2/blender-t2.png) · [Godot T1](media/exploration-t2/godot-t1.png) · [Godot T2](media/exploration-t2/godot-t2.png)

ElevenLabs 웹에서 돌기둥 공명 루프와 발굴 효과음을 각 4초·1번 변형으로 생성했다. 원본 WAV, 모노 게임 믹스, 프롬프트·선택·길이·해시·처리 정보는 `audio/source/elevenlabs`와 `audio/manifests/exploration-discoveries.json`에 보존한다. 다른 발견의 물·열·생물·기계음은 기존 ElevenLabs 제작 음원을 재사용한다. 게임 메뉴에서는 현장 환경음·표식·작업 입력을 정지한다.

## 구현 경계

- 현재 단계 작업은 E의 실제 조사 시간과 F 확정으로 구성된다. 여러 지점 관찰은 이동을 요구하지만 실제 온도차·자력·풍향 센서 시뮬레이션은 아니다.
- 화석/정동 굴착은 현장 외피 모델과 충돌을 제거한다. 광활한 지형을 자유 굴착하는 기존 도구를 대체하지 않는다.
- 발광 수역은 낮/밤 밝기와 설치형 차광판으로 조건을 바꾼다. 밤을 기다리는 별도 강제 시간 퍼즐은 없다.
- 열수의 분출 중 회수 제한은 주기와 동기화한다. 별도 열 피해·자유 센서 설치는 후속이다.
- 수로는 한 번 유한한 물을 방출한다. 영구 자동 생산·행성 전체 수자원 해금은 아니다.
- 표본은 실제 연구 가능한 기존 계통이다. 새 20종 생물 모델 또는 전용 신규 연구 과제를 추가한 것은 아니다.
- 광맥 단서는 실제 자원 발견으로 로봇 직접 작업 선택에 활용한다. 모든 POI를 연결하는 연쇄 퀘스트나 새로운 탐험 전용 지도는 후속이다.

## 확인

20종의 자연 생성·티어 상한·단계별 조준/도구/재료·사전 조사 요구·완료 보상·같은 요청 재전송·전체 저장 검증·복원을 한정 검사했다. 초기 검사에서 대기압 단위, 존재하지 않던 원료 ID, 경사지 표식과 새 표본의 원산지 검증 연결을 수정했다. 수정 후 20종 모두 완료했고 실패 0이다. 광범위한 전체 회귀·다중 클라이언트·장시간 성능 시험은 수행하지 않았다.

실제 Godot 4.7.2 Forward+ / Metal / Apple M2 원정에서 정동의 E 유지 조사 3단계 → F 작업 → 외피 모델·충돌 제거 → 사파이어 획득, 960×640 발견 도감, 메뉴 중 현장 음원·표식 정지, 실제 디스크 저장·재읽기를 확인했다. 최종 현장 검사 17항목 실패 0, 별도 마을 생성/기록 이행 검사 5항목 실패 0이다. 게임 SFX 버스 신호를 확인했으며 음향 전체 청감·모든 20종의 개별 현장 동작을 실제 창에서 전수 검수한 것은 아니다.

[작업 전 정동](media/exploration-t2/geode-before.png) · [열린 정동](media/exploration-t2/geode-open.png) · [작은 발견 도감](media/exploration-t2/journal-960.png) · [확인 메타데이터](media/exploration-t2/verification.json)

현장 확인에서 재방문 시 로딩 완료 자산을 재사용하지 못하던 문제와 조준 선택 해제 시 공유된 장소 딕셔너리까지 비우던 문제를 수정했다. 마지막 실행에는 해당 스크립트 오류가 없었다. 이미 통과한 20종 규칙 검사를 반복하거나 전체 회귀로 확대하지 않았다.

재현 도구는 `tests/check_exploration_discoveries.gd`(20종 규칙, `--retirement-only`로 마을 이행만 확인), `tests/check_exploration_discovery_play.gd`(별도 `/tmp/exploration-discovery-play` 세계에서 현장 실행), `scenes/showcase/exploration_discoveries.tscn -- --capture`(20종 INK 렌더)이다. 일반 플레이 저장에는 검사용 원료·배치·완료 상태를 주입하지 않는다.
