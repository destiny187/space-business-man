# 행성 진입·접지·하선의 그래픽과 사운드

2026-09-09 사용자 승인: 기존 우주 연출을 먼저 커밋한 뒤, 행성 접근부터 캐릭터가 내릴 때까지 제안한 그래픽·사운드 개선을 적용한다. 선행 우주 작업은 `27e3df67`로 분리했다. 이 문서는 [기존 진입·착륙](35-planet-arrival.md)의 후속 구현 기록이다.

## 현재 연결

| 구간 | 표현 |
| --- | --- |
| 접근 | 실제 비행 카메라·선체 방향에서 보간하고 항성 조명을 유지한다. 궤도 엔진 레이어를 정리하고 착륙 추진음으로 전환한다. |
| 진입 | 기압으로 구름·기류·선수의 작은 열 발광을 조절한다. 준비된 지표의 낮/밤 구름색과 항성 방향으로 서서히 맞춘다. 기압 0이면 대기 흐름·바람을 제거한다. |
| 하강 | 고도와 수평 이동을 서로 다른 감속 곡선으로 줄이고 기수를 수평으로 정리한다. 고도가 낮아지면 제동 분사와 지면 반응음이 커진다. |
| 접지 | 노즐 아래 지면에서 바깥으로 입자가 퍼진다. 건조 토양·동결 환경·습윤 환경을 구분하고 입자는 수명에 따라 사라진다. 다리 압축, 선체의 짧은 흔들림, 접지음, 엔진 감쇠와 냉각음을 연결한다. |
| 하선 | KESTREL의 해치·램프 또는 FINCH 캐노피를 열고 출입 조명을 켠다. 소유 캐릭터 모델이 내려와 기존 승인 위치에 도착한 뒤 1인칭 조작으로 연결한다. 기존 발소리를 재사용한다. |
| 믹스 | 진입 준비 중 우주 음악을 유지하고 하강부터 지표 음악으로 크로스페이드한다. 연출 중 음악을 낮추며 문 개방에 맞춰 환경음이 드러난다. FINCH는 높은 피치·작은 분사와 압축 폭을 사용한다. |

INK v1 셰이더·윤곽선을 유지한다. 시점 전환을 위해 조준점과 창고 이름표를 잠시 숨긴다. 전환은 호스트가 실제 착륙을 승인한 뒤 시작하고 지형·충돌 준비와 실제 렌더 프레임 대기 조건을 보존한다. 포커스 이탈 중 시간·입자·음향을 멈춘다. 기존 접근·하강 시간을 활용하고 접지 1.35초 및 거리 기반 하선 2.8~6초를 사용한다. 표현 값은 `planet_arrival.json`에 둔다.

## 제작 자산

- `tools/build_landing_assembly.py`: 기존 KESTREL의 실제 출입구, 내부 바닥, 가동 해치·램프, 유압 다리와 하부 분사구를 Blender로 제작했다. 기존 `kestrel.blend`를 보존하고 `kestrel_landing.blend`와 게임 GLB를 구분한다. 공통 산업 재질과 베벨을 사용했다.
- FINCH는 기존 Blender 제작 자산의 캐노피와 다리 피벗을 재사용한다.
- ElevenLabs Sound Effects에서 접지 하중, 해치·램프, 냉각, 자갈 쓸림 네 음원을 새로 생성했다. 48kHz 스테레오 원본과 게임용 편집본을 보존한다. 설정·프롬프트·생성 URL·선택 변형·체크섬은 `audio/manifests/landing-polish.json`을 따른다.
- 접지·해치는 4초, 냉각·자갈은 80ms 연결 편집 후 3.92초 루프다. 기존 추진·대기·물·발소리·환경음과 함께 실제 재생기에 연결했다.

## 확인과 구현 경계

Blender Cycles와 Godot Forward+의 다리 수납/전개/문 개방 렌더를 확인했다. 실제 원정 창에서는 별도 저장 폴더의 호스트 착륙 요청부터 하선·조작 복구·작은 화면까지 확인했다. 화면에서 발견한 하선 카메라의 선체 겹침, 입자 스케일 소실, 연출 중 이름표/조준점 노출을 수정했다. 출입 조명이 전역 원점으로 옮겨지던 좌표 문제도 수정하고 실제 램프·지면 조명을 확인했다. 증거는 `media/landing-polish/`에 둔다.

최종 실제 경로는 KESTREL 대기 행성 16개 관찰, FINCH 희박 대기 행성 17개 관찰에서 실패 0이었다. 두 경로 모두 재탑승·이륙 후 우주 조종 복구까지 확인했다. 녹음한 착륙 믹스의 최고 피크는 각각 -15.25/-15.61dBFS, 클리핑 표본은 0이었다. 출력 녹음은 로컬 `/tmp/`에 두고 측정값을 음원 매니페스트에 보존했다. 전체 회귀 검사는 실행하지 않았다.

- 전체 구체 지표가 우주에서 연속 스트리밍되는 방식은 아니다. 준비 중에는 선체를 유지하는 대기/어두운 전환막을 사용한다.
- 신규 가동 출입구 제작 대상은 KESTREL이며 FINCH는 기존 캐노피를 사용한다. 다른 교체 선체의 전용 출입구 모델링은 포함하지 않는다.
- 하선 캐릭터는 로컬 표현 복제본이다. 권위 있는 캐릭터·충돌·자원·착륙 위치를 이동시키지 않는다. 6명 동시 하선 애니메이션 동기화는 이번 구현이 아니다.
- 물 입자는 실제 물 높이와 높은 함수율을 이용한 습윤 지면 표현이며 유체 시뮬레이션이 아니다. 열 발광은 진입 진행도와 기압을 이용한 표현이며 실제 재진입 열역학 계산은 아니다.
- 생성된 착륙 가능 행성의 기압은 0보다 커서 실제 FINCH 경로는 희박 대기에서 확인한다. 기압 0 분기는 구현했지만 자연 생성 무대기 착륙 전체 흐름은 확인하지 않았다.
- 실제 재생 신호와 출력 파형을 확인하는 것과 사람의 청감 평가는 구분한다. 음색 청감, Windows, 6인, 전 선체 조합, 장시간 성능 검사는 수행하지 않는다.
