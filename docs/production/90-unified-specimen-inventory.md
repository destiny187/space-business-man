# 생체 표본과 일반 아이템 통합

2026-09-09 사용자 추가 요청. 격리 화물칸과 분리된 표본 보관을 일반 아이템창으로 합쳤다. 현재 기본 진입 장면 `crew_expedition.tscn`에 적용한다.

## 사용자에게 보이는 변화

- Q로 확보한 생체 표본은 I의 재료·장비와 같은 배낭 목록에 나타난다. 표본 한 개가 수납 한 칸을 사용하며 별도 4개 한도는 없다. 배낭이 가득 차면 채집하지 않고 이유를 알린다.
- 이름 검색·분류의 표본 필터, 종류별 기존 아이콘, 선택한 생물의 실제 Blender 제작 모델·외형 색·채집 행성·용도 설명을 연결했다.
- I의 화물에서 일반 재료와 같은 입출고·끌어놓기·일괄 보관 경로를 사용한다. 배낭, 행성 창고, 공동 원정선 및 FINCH/로버의 기존 공간·거리 규칙을 따른다.
- 별도 격리 화물칸 이름과 HUD의 표본 전용 수량을 없앴다. J는 관측 지식 열람이며 실물 관리 버튼은 I로 연결한다. 연구대의 이식 후보는 내 배낭에 있는 해당 생물의 다른 행성 표본이다.
- 이식은 실제 장치 접근·원산지·환경·구획 검사를 유지하고 성공할 때 배낭 표본 한 개만 소비한다. 연구와 채집·이식 기록은 남긴다.

## 저장·거래

`specimen_items.gd`가 채집 원본과 일반 수납 원장을 연결한다. `ecology.specimens`는 원산지·원본 encounter·형태·외형·이식 상태의 기록이며 중복된 아이템 보관함으로 사용하지 않는다. 실제 물건은 `specimen|form|look|source_body|sample_id` 키와 수량 1로 기존 수납 원장 한 곳에만 존재한다. 같은 생물이라도 채집 개체가 다르면 별도 칸이다.

`ecology.item_storage_version=1`이 없던 저장은 호스트 시작 때 기존 `cargo` 상태 표본을 공동 원정선 창고로 한 번 연결한다. 저장의 표본·연구 원본을 유지하고, 창고 여유가 없어도 삭제하지 않으며 초과 보관으로 남겨 인수할 수 있다. 이미 이식된 표본은 다시 아이템으로 만들지 않는다. 구형 비협동 장면의 ecology-v1 저장은 읽을 수 있게 유지한다.

수납 원장 전체를 채집 원본과 대조하여 중복 위치·수량 변조·분실된 참조를 저장 검증에서 거절한다. 원정의 일반 거래는 0개가 된 표본 키를 정리한다. 채집·입출고·이식은 기존 호스트 저장/영수증 경로를 사용하며 실패 시 원본을 확정하지 않는다. 종료/연결 해제 시 배낭을 기존 회수 화물로 보존하는 규칙도 표본에 적용한다. 현장 창고에 표본을 둔 채 거점을 완전히 인계하지 못하게 하여 회수 불가능한 보관을 방지한다.

`inventory.json`의 표본 중첩/저장 버전을 네트워크 콘텐츠 해시에 포함한다. 서로 다른 수납 규칙의 실행판은 동일 콘텐츠로 접속할 수 없다.
