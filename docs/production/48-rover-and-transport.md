# 로버 제작·지상 운용·행성 간 운송

설계 기준은 [로버·운송](../game/16-rover-and-transport.md), 작업 구분은 [C13~C15](../planning/11-ground-commit-plan.md)이다. 전체 UI 재설계는 별도이며 실제 모델과 짧은 문맥 조작을 우선한다.

## C13 — 제작 자산

2026-09-08. Blender 5.2.1에서 SCOUT 2인승 밀폐형 바퀴 로버를 제작했다. 원본은 `art/blender/vehicles/scout_rover.blend`, 게임 모델은 `assets/models/vehicles/scout_rover.glb`다. `tools/build_scout_rover.py`로 재생성한다. 두 좌석·유리문, 전후 바퀴, 조향·서스펜션, 화물 덮개와 고정점 등 25개 동작/연결 노드를 제공한다.

Blender 렌더와 Godot 4.7.2 Forward+ / Metal의 INK v1 정면·후면·문/화물 개방·운전석 시야를 확인했다. 검수 이미지는 `media/rover/`, 실행 스크립트는 `tests/render_scout_rover.gd`다. 대시보드는 전방 시야 아래에 배치했다. 제작 자산 커밋에서 실제 게임에 미완성 제작 버튼을 노출하지 않는다.

ElevenLabs Sound Effects에서 주행 반복·시동·문·제동·적재 윈치 반복·고장 6종을 생성했다. 원음은 `audio/source/elevenlabs/`, 실제 WAV는 `assets/audio/`, 프롬프트·파일 해시·길이·가공 정보는 `audio/manifests/rover-sounds.json`에 보존했다. `tools/import_rover_audio.py`는 모노화·DC 제거·주파수 정리·루프 접합·음량 조정을 수행한다. 파일 신호와 길이를 확인했으며 청감 평가는 아직 하지 않았다. 실제 게임의 공간 재생 연결은 C14/C15에서 기록한다.

## C14 — 지상 로버

개인 현장 물류 I(기초 로봇공학·가방 재료), 가동 제작소의 공동 부품 예약/45초 조립/안전 출고, 호스트 주행·두 좌석, 안전 하차, 화물 4칸의 클릭/드래그 전송과 장비 소유권, 충전·수리·구조 충전·전복 복구를 연결했다. 데이터는 `data/rovers.json`, 소유 원장은 `world.rovers`다. 구 세이브의 차량 기본값은 없음이며 좌석·작업 예약은 영구 저장하지 않는다.

F는 문/후방 화물 문맥 조작, WASD는 주행, Space는 제동, V는 운전석/추적 시점이다. 동승자는 E로 스캔하고 정차 후 X로 빈 운전석에 이동한다. 차량 키는 기존 입력 재지정에 연결했다. 메뉴·입력 만료·운전자 이탈은 제동하며 차량 안에서는 개인 채광·공격·건설을 호스트가 거절한다. 실제 모델의 바퀴·조향·서스펜션·문/화물 움직임과 ElevenLabs 공간 음원, 좌석 자세, 운전 계기를 연결했다.

Godot Forward+ 실제 창에서 `tests/check_rover_ground.gd`로 연구→시설→실제 45초 제작→운전석/추적 주행→메뉴 제동/음원 정지→하차→클릭 화물→수리/구조 충전→저장/재읽기를 확인했다. 주행 루프의 재생 상태를 확인했으나 청감 평가는 미확인이다. 960×640 화물창과 1280×800 연구·제작·운전 화면을 검수했다. 별도 좌석/복구 검사에서 호스트 권한에 두 참가자를 넣어 같은 좌석 선점 거절·동승 스캔·개인 공격 차단·운전자 이탈 제동/점유 해제, 실제 3초 유지 복구와 전력 있는 충전 패드를 확인했다. 실제 두 클라이언트의 네트워크 주행이나 장거리/다양한 경사 주행은 실시하지 않았다.

검사 중 차량 화물의 필수 재고 키, 직접 진입 시 입력 바인딩 누락, 연구 모델 미리보기의 세로 늘어남, 복구 시작 시 입력 도착 여유와 안전 위치 후보 탐색을 수정했다. 테스트의 가짜 참가자 RPC 경고와 임의 운전자 이탈 후 화면 전환 상태는 검사 도구에서 분리했다. 차량 출고/복구의 실제 충돌 공간은 현재 로드된 지형에서 검사한다.
