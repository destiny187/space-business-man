# 유실 화물 연결 정지·홈 버전과 배경 배치

2026-09-14 사용자 후속 제보/요청. [견인 소관](../game/23-corporations-and-space-presence.md), [버전 소관](../release/01-playing-and-building.md), FIELD v1·INK v1을 따른다.

## 유실 화물

P03에서 거치대 표시는 제거했지만 `freight_salvage_view.gd`의 stage 1 보간이 남아 F 게이지 도중 포드를 선체 쪽으로 움직였다. 기존 검사도 이 이동을 정상으로 기대했다. 검사 기대를 수정한 실제 Forward+ 실행에서 완료 전 연결선·포드 이동 두 항목의 실패로 재현했다.

유실 화물 연결 중에는 공전 기준 원래 위치를 유지하고 회전을 멈춘다. 게이지와 기존 ElevenLabs 윈치 소리는 유지하며, 취소해도 포드를 선체에서 되돌리는 이동이 필요 없다. 호스트가 stage 2를 저장한 뒤에만 견인선을 표시하고 현재 포드 위치에서 선체 뒤 추종을 시작한다. 연결 완료 후 키를 놓아도 이동을 따라간다. 선박 메뉴의 유실 화물 표시도 거치대에서 견인 연결로 바꿨다. mine 정비 카트리지와 항만의 인계 설비는 기존 방식을 유지한다.

실제 Godot 4.7.2 Metal Forward+ 원정의 `check_tethered_freight_play.gd` **23항목 실패 0**: 연결 중 정지/선 없음/운반 미확정, 메뉴 취소/소리 정지, 재연결, F 해제 후 선박 이동·화물 추종, 인계·공동 대금·세션 저장. 이 검사는 기존의 테스트용 held-input 주입 경로를 사용하며 실제 하드웨어 F 키 타건/6인 실접속과 구분한다. 첫 수정 확인 중 취소 검사에 시각 0을 넣은 오류와 메뉴 후 창 포커스 복구 누락을 확인해 검사 준비만 바로잡았다. 기존 Blender 포드와 선박·ElevenLabs 음원을 재사용했고 신규 자산 제작은 없다.

## 홈

홈 우측 하단에 날짜+커밋 식별번호를 표시한다. 실행 시작 때 한 번 읽어 캐시하고, macOS/Windows 배포 스크립트는 같은 번호를 JSON으로 내장한다. 미커밋 변경과 ignore 대상이 아닌 새 파일은 개발 중으로 표시한다. 새 변경의 커밋을 push/pull한 뒤 실행하면 버전도 바뀌며 이미 받은 배포 파일은 새 빌드가 필요하다. Git 이력을 쓰거나 push 중 자동 커밋하는 훅은 추가하지 않았다.

홈 프리뷰 카메라의 위치와 주시점을 화면 왼쪽 방향으로 함께 7.5m 옮겨 기존 테라포밍 지형이 조금 오른쪽에 보이게 했다. 기존 카메라의 느린 이동과 모델은 유지한다. 실제 원정 카메라와 지형 좌표는 변경하지 않는다.

실제 Metal Forward+ 홈의 논리 1280×800·960×640에서 우측 하단 버전의 가독성/화면 내 배치와 3D 배경을 확인했다. 기준점은 화면 중심에서 각각 약 122px·97px 오른쪽으로 이동했다. 첫 캡처 보조 검사의 임의 60% 경계는 1280 화면의 약 59.5% 결과를 실패로 판정해, 요청한 조금 오른쪽 배치에 맞춰 56%로 바로잡고 실제 이미지를 확인했다.

## 행동 범위와 남은 비용

- F 입력은 기존 조종사·거리·속도·시선 검사→0.1초 호스트 진행→완료 시 해당 화물 원장 변경/저장→스냅샷의 기존 단계/활동→현재 화물 모델·선 갱신 경로를 유지한다. 진행 중에는 새 원장 저장을 추가하지 않는다. 연결선·포드 보간은 로컬 표시이며 프레임별 네트워크/저장을 추가하지 않는다.
- 완료 초안은 world/crew/화물 원장에 얕은 복사를 사용하고 마지막 인계에서만 사업 자금을 바꾼다. 기존 전체 저장 검증·직렬화·스냅샷 발행 비용과 화물 원장 순회는 남는다. 완료 상태·실패·중복 처리 도메인을 바꾸지 않았으며 이번에 실패 저장/6인 경합을 다시 실행한 것은 아니다.
- 홈 배경 변경은 기존 카메라 갱신 안에서만 처리한다. 모델 재생성/캐시 무효화·게임 저장·네트워크 변경은 없다. 버전의 Git 상태 조회는 홈 최초 진입 한 번이며 매 프레임 또는 메뉴 재진입 때 반복하지 않는다.
- 버전 JSON 생성과 빌드 셸 구문, diff 공백 검사를 확인했다. 전체 게임 재내보내기·Windows 실기·사용자 기존 저장·다중 클라이언트 검수는 수행하지 않았다.
