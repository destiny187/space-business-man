# 은하 생성·지구 출발·별도 대기실

2026-09-06 사용자 요청을 설계 문서에 먼저 기록한 뒤 기본 실행 경로에 반영했다. 규칙은 [은하·시드](../game/11-galaxy-tiers-and-seeds.md), [게임 시작·협동](../game/12-host-coop-and-crew.md)이 소관이다.

## 반영 내용

- 새 은하는 무작위 시드, 125,000 항성계와 100만 행성이다. 태양계 8행성·지구 궤도 출발을 고정했다. 기존 세계 이어하기는 저장 위치를 유지한다.
- 항성·공전 궤도·행성 표시는 같은 호스트 시간을 사용한다. 띠 구름과 반지름으로 가스/얼음 거대행성을 구분하고 서버 및 착륙 버튼에서 착륙을 차단한다.
- 은하의 대표 항성계 선택 지도, 현재 항성계의 천체 선택 궤도도, 행성 이름/종류 목록, 전체 행성 주소 탐색을 연결했다. 은하 지도 점은 대표 항성계이며 전체 백만 행성을 동시에 그린 화면이 아니다.
- 별도 대기실에서 게스트 준비 후 호스트가 시작한다. 대기실 준비와 출항 준비는 별개다. 혼자는 시작 준비를 자동 처리하고, 중간 입장은 진행 상태를 유지한다.
- 시작 화면의 ‘새 은하에서 혼자 시작’과 방 설정의 ‘새 은하로 방 만들기’는 고유 저장 파일을 만든다. 기존 세계와 생성기 설정을 보존하며 최근 세계를 이어할 수 있다.

## 확인한 범위

`tests/test_galaxy_start.gd`를 실제 Godot 4.7.2 Metal Forward+ / Apple M2 창에서 실행했다. 핵심 검사 **27개 통과, 실패 0개**, 엔진 오류 0개다. 결과는 저장소 `test-results/galaxy-start-final/`, 검사 목록은 [검증 기록](media/galaxy-start/verification.json)에 보존했다.

- 100만 주소 끝점·시드 재현·지구 출발·시간에 따른 공전·가스형 착륙 거부.
- 호스트 권한·준비되지 않은 참가자의 시작 차단·준비 완료·중간 입장 판정. 이 부분은 호스트 도메인 호출이며 실제 다중 ENet 클라이언트/인터넷 검증을 수행한 결과가 아니다.
- 마지막 주소까지 항해하고 항성 내부를 피하는 수치 시뮬레이션, 유효한 저장 상태와 구 생성기 매니페스트 수신.
- 실제 창의 대기실→호스트 시작→지구 궤도, 가스형 셰이더·착륙 버튼, 960×640 화면, 지구 지표 스트리밍과 기존 장비/건설 UI 연결.

[대기실](media/galaxy-start/lobby.png) · [지구 출발](media/galaxy-start/earth.png) · [가스 행성](media/galaxy-start/gas-giant.png)

기존 Blender 우주선·선내·수동장비와 기존 ElevenLabs 피드백을 재사용한다. 이번 천체는 기존 절차적 구체/대기 렌더의 유형 확장이며 새 3D 모델·음원을 제작하지 않았다. 기존 공통 INK 조명과 윤곽 경로를 사용하고 실제 게임 렌더로 확인했다. 신규 전용 음향이나 전 자산 재검수 완료를 의미하지 않는다.

## 남은 범위

항성계당 가변 행성 수·위성·타원 궤도·실제 천체력·중력계, 지구 도시/우주항과 실제 대륙, 가스형의 전용 스캔/연구/자원 획득은 후속이다. 현재 지구 착륙은 기존 시드 지형의 기능 연결이며 실제 지구 지표 재현이 아니다. 천체 크기·거리·공전 속도는 게임 축약값이다.

사용자의 초기 테스트 최소화 지시에 따라 전체 회귀·장시간·다중 클라이언트 검사는 실행하지 않았다. 기존 검증 파일은 보존했고, 구형 테스트의 고정 시작 주소·4행성·접속 즉시 플레이 전제는 변경된 규칙과 구분해야 한다. 새 슬롯 목록/선택을 위한 전체 저장 관리 화면은 아직 없으며 UI는 최근 세계와 새 세계, 구형 세계의 진입을 제공한다.

후속 갱신: 사용자 요청으로 태양계 8행성은 [Blender 원본·GLB 모델](21-solar-system-blender.md)로 교체했다. 위의 절차적 구체 설명은 최초 구조 구현 당시의 기록이다.

## 첫 태양계 시작은 성간 도착 연출에서 제외 — 2026-09-07

사용자 재확정: 새 게임은 태양계 내부의 지구 궤도에서 시작한다. 새 세계 생성은 성간 원경 진입 함수와 분리된 지구 근접 위치를 사용한다. 처음 여는 태양계 대기 화면에서는 선체 위치·방향을 즉시 적용하고 항성계 진입 제목·도착 효과음을 재생하지 않는다. 실제 성간 이동에는 기존 원경 이탈·접근과 도착 연출을 유지한다. 저장된 위치를 지구로 되돌리는 초기화는 하지 않는다.

`check_solar_start_view.gd`에서 지구 주소·태양계 내부 거리·즉시 시선·첫 도착 효과 제외와 이후 성간 연출 유지를 확인했다. Godot Forward+/Metal 실제 지구 근접 시작 화면을 검수했다.
