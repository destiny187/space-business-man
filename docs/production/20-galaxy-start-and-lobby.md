# 은하 생성·지구 출발·별도 대기실

## 2026-09-10 — 지구를 바라보는 Sol 출항 연출

사용자 최종 정정에 따라 새 원정의 첫 시선 대상은 **지구**다. `Sol` 도착 제목·기존 ElevenLabs 항성계 도착음으로 소개한 뒤, 선체와 카메라가 같이 물러나고 여러 행성이 보이는 방향으로 선회한다. 아래 2026-09-07의 첫 제목/도착음 제외와 지구 바로 앞 즉시 조작은 과거 이력이다.

- 새 세계만 `solar_opening` 경로를 생성하고, 공동 항해 상태로 이전해 호스트가 진행한다. 기본 연출은 8초다. 첫 1.2초는 지구 주시, 6.5초까지 후진, 3~7.4초에 전경 방향 선회, 마지막은 정지·인계다. 시간·후퇴 후보 위치·초기 거리·시야각은 `data/space_presentation.json`의 조정값이다.
- 실제 시드/공전 위치에서 후보 시점 288개를 비교한다. 시야 안의 행성 수·천체 간 가림·화면 간격·식별 크기를 점수화하고 화성 정면 고정은 피한다. 행성의 공전·축척·배치를 연출용으로 재배치하지 않는다. 지구 근접점부터 최종점까지 행성·태양의 안전거리를 확인한다. 선체는 실제 위치와 방향으로 이동하고 조작 인계 때 지구 앞으로 순간 복귀하지 않는다.
- 시작 로딩이 끝나기 전에는 연출 시간을 진행하지 않는다. 연출 중 조종·항해·작업 요청은 호스트에서도 거절하고, 일반 HUD·조사 표식·주시 스캔·업무 안내·튜토리얼을 숨긴다. 싱글플레이에서 메뉴나 창 비활성화 중에는 이 연출을 대기한다. 마지막에 직원 업무 안내를 표시하며 `확인` 뒤 기존 WASD → Shift → 화성 스캔 가이드가 시작된다. 가이드 끄기는 이후 튜토리얼 출발 잠금을 해제하며 시작 연출 자체의 표시 옵션으로 바꾸지 않았다.
- 경로와 경과 시간을 저장한다. 완료한 원정은 이어하기·태양계 재방문 시 연출을 반복하지 않고 실제 저장 위치를 유지한다. 연출 기록이 없는 기존 저장에는 새 시작점을 소급 적용하지 않는다. 논리 출발 주소는 태양계 지구를 유지한다. 협동 진행도는 호스트 항해 상태와 함께 전송하며 전원에게 개인 연출 완료를 요구하는 새로운 준비 절차는 없다.
- 기존 Blender 태양계/선체, INK v1 게임 렌더, ElevenLabs 도착·추진/자세 제어 음원을 재사용했다. 새 모델·음원은 제작하지 않았다. 실제 성간 이동의 출발·도착 경로는 유지한다.

### 실제 확인

Godot 4.7.2 / Apple M2 / Metal Forward+의 960×640 실제 창, 별도 임시 새 세계에서 지구 주시·Sol 제목·도착음 재생·선체/카메라 후진·방향 전환·업무 안내·튜토리얼 인계를 확인했다. 검사 시드에서는 8개 행성이 카메라 시야 범위에 들어왔으며 원거리 크기와 선체 가림까지 모든 시드에서 동일하게 보인다는 뜻은 아니다. 호스트의 연출 중 요청 거절과 완료 저장·재실행 시 미반복/위치 보존도 확인했다. [확인 기록](media/solar-opening/verification.txt)은 20개 실패 0개다.

[지구와 Sol](media/solar-opening/earth-sol.png) · [후진·선회](media/solar-opening/pullback.png) · [조작 인계 직전 전경](media/solar-opening/overview.png)

초기 구현의 타입 추론 오류는 명시적인 bool 선언으로 수정했다. 최초 요청 거절 검사도 요청 전송 여부와 호스트 성공 응답을 구분하도록 수정했다. 기존 `check_solar_start_view.gd`의 기대값은 최신 지구/Sol 연출에 맞췄다. 이번에는 위 실제 시작 흐름과 저장만 확인했으며 다중 클라이언트·전 시드·전체 회귀·기존 모델 재제작 검수는 수행하지 않았다. 기존 사용자 세이브를 변경하지 않았다.

2026-09-06 사용자 요청을 설계 문서에 먼저 기록한 뒤 기본 실행 경로에 반영했다. 규칙은 [은하·시드](../game/11-galaxy-tiers-and-seeds.md), [게임 시작·협동](../game/12-host-coop-and-crew.md)이 소관이다.

## 반영 내용

- 새 은하는 무작위 시드, 125,000 항성계와 100만 행성이다. 태양계 8행성·지구 궤도 출발을 고정했다. 기존 세계 이어하기는 저장 위치를 유지한다.
- 항성·공전 궤도·행성 표시는 같은 호스트 시간을 사용한다. 띠 구름과 반지름으로 가스/얼음 거대행성을 구분하고 서버 및 착륙 버튼에서 착륙을 차단한다.
- 은하의 대표 항성계 선택 지도, 현재 항성계의 천체 선택 궤도도, 행성 이름/종류 목록, 전체 행성 주소 탐색을 연결했다. 은하 지도 점은 대표 항성계이며 전체 백만 행성을 동시에 그린 화면이 아니다.
- 별도 대기실에서 게스트 준비 후 호스트가 시작한다. 대기실 준비와 출항 준비는 별개다. 혼자는 시작 준비를 자동 처리하고, 중간 입장은 진행 상태를 유지한다.
- 시작 화면의 ‘새 은하에서 혼자 시작’과 방 설정의 ‘새 은하로 방 만들기’는 고유 저장 파일을 만든다. 기존 세계와 생성기 설정을 보존하며 최근 세계를 이어할 수 있다.

## 남은 범위

항성계당 가변 행성 수·위성·타원 궤도·실제 천체력·중력계, 지구 도시/우주항과 실제 대륙, 가스형의 전용 스캔/연구/자원 획득은 후속이다. 현재 지구 착륙은 기존 시드 지형의 기능 연결이며 실제 지구 지표 재현이 아니다. 천체 크기·거리·공전 속도는 게임 축약값이다.

사용자의 초기 테스트 최소화 지시에 따라 전체 회귀·장시간·다중 클라이언트 검사는 실행하지 않았다. 기존 검증 파일은 보존했고, 구형 테스트의 고정 시작 주소·4행성·접속 즉시 플레이 전제는 변경된 규칙과 구분해야 한다. 새 슬롯 목록/선택을 위한 전체 저장 관리 화면은 아직 없으며 UI는 최근 세계와 새 세계, 구형 세계의 진입을 제공한다.

후속 갱신: 사용자 요청으로 태양계 8행성은 [Blender 원본·GLB 모델](21-solar-system-blender.md)로 교체했다. 위의 절차적 구체 설명은 최초 구조 구현 당시의 기록이다.

## 첫 태양계 시작은 성간 도착 연출에서 제외 — 2026-09-07

사용자 재확정: 새 게임은 태양계 내부의 지구 궤도에서 시작한다. 새 세계 생성은 성간 원경 진입 함수와 분리된 지구 근접 위치를 사용한다. 처음 여는 태양계 대기 화면에서는 선체 위치·방향을 즉시 적용하고 항성계 진입 제목·도착 효과음을 재생하지 않는다. 실제 성간 이동에는 기존 원경 이탈·접근과 도착 연출을 유지한다. 저장된 위치를 지구로 되돌리는 초기화는 하지 않는다.

`check_solar_start_view.gd`에서 지구 주소·태양계 내부 거리·즉시 시선·첫 도착 효과 제외와 이후 성간 연출 유지를 확인했다. Godot Forward+/Metal 실제 지구 근접 시작 화면을 검수했다.
