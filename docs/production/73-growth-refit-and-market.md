# UX03 — 성장 동선·선박 정비·교역

2026-09-09 사용자의 3차 진행 요청에 따라 [기존 계획](../planning/13-uiux-renewal-commits.md)을 확인하고 장치 배치·실행 경계를 먼저 보완한 뒤 U07/U13을 개발했다.

## 구현한 동선

| 화면/장소 | 역할 |
| --- | --- |
| I 아이템·신체 | 소유 장비·장착·휴대 제작 유지, 신체 증강과 탐험복/채집/수납/운송 숙련 열람. 개조 버튼은 장치 안내로 연결 |
| J 탐사 기록 | 공동 표본 연구·전체 발견 도감 열람. 성능/운송 구매 탭 제거, 생태 실행 대신 연구대 안내 |
| 실제 증강 장치 F | 기존 보석 증강, 장비·탐험복 Mk.2 개조, 개인 채집/수납 성능, 운송 숙련 |
| 실제 표본 연구대 F | 기존 공동 보석 분석, 공동 설비 성능, 생태 분석/서식지/이식/지원 |
| 선박 정비 K / 착륙선 단말 | 실제 선체·추진/공용 슬롯 선택, 보유 모듈과 제작 설계, 교체 비교, 차량 적재함 진입 |

새 모델이나 원격 작업장은 만들지 않고 기존 Blender 장치·선체·모듈을 재사용한다. 기존 지상 개조는 여전히 착륙 후 수행한다. 선내에서는 새 지상 작업 탭을 비활성화하고 기존 증강/표본 연구 기능은 유지한다. 호스트는 이전 장치 제공자로부터 실제 장치의 존재·행성·공간·거리를 확인한다. 버튼만 숨기고 원격 명령을 허용하지 않는다. 개인 재료/공동 자금의 출처, 기존 효과/가격/단계/저장은 보존한다.

연구대와 J는 같은 도감 컨트롤을 이동시켜 재사용한다. 선택/검색을 유지하면서 J로 돌아오면 실행 버튼을 숨긴다. 작업 장소 안내는 가까울 때 해당 장치 화면을 열고 멀면 착륙선 옆 장치의 F 상호작용을 안내한다. 순간 이동이나 원격 구매는 하지 않는다.

## 선박 정비

- 기존 선체와 장착 모듈을 실제 부착 좌표로 렌더하고 추진/공용 슬롯을 연결선으로 표시한다. 선체를 드래그해 회전할 수 있다.
- 선택 슬롯에 맞는 보유 모듈 또는 제작 설계만 보여 준다. 없는 보유 모듈은 카드로 만들지 않고 빈 슬롯/안내를 표시한다.
- 교체할 모듈을 임시 복사본에 적용해 질량·전력·항속·접근 성능·연구 속도·격납고를 비교한다. ‘교체 미리보기’는 실제 장착을 바꾸지 않는다.
- 기존 규칙의 복사본으로 작업 가능 이유와 한도를 계산하며 실제 명령/저장은 호스트가 확정한다. 승인 대기 중 추가 실행을 막고 결과 후 피드백을 낸다.
- 제작/개량 재료, 크레딧, 연구 부품, 인증 조건을 표시한다. 추첨은 소비·확률·확정까지 횟수·중복 반환을 확인하고 실행한다. 분해는 선택 모듈과 반환 부품을 확인한다.
- 모듈 3종과 탐험복 카드의 실제 Forward+ 렌더를 투명 PNG로 생성했다. 기존 차량 적재 진입은 작은 버튼으로 유지했다.

## 교역

이름 검색은 물자/선체/보유 선체에 적용한다. 물자는 종류와 ‘내가 판매할 수 있는 물자’로 거른다. 상점과 개인 가방 양쪽에 모두 없는 품목은 숨기며, 상점이 품절이어도 자신이 보유한 취급 물자는 판매 후보에 남긴다. 개인 미보유 수량은 0개로 쓰지 않는다. 빈 검색은 이전 거래 버튼·이미지를 지운다.

선택 물건과 이미지, 구매/판매 **단가**, 입력 수량과 **총액**을 분리한다. 실행 영역은 고정하고 긴 선체 성능만 스크롤한다. 거래 거리·호스트 권한·개인 가방 출처·승인 대기/결과 사운드는 기존 경로를 유지한다.

## 확인한 범위와 수정 과정

- Godot 4.7.2, Metal Forward+ / Apple M2, 960×640. `/tmp/research-a06-ui` 복사본 `/tmp/uiux-ux03`에서 테스트 모드와 저장 경로를 확인했다. 장치 접근과 재료는 준비된 fixture이며 자연 진행 전체를 검증한 것은 아니다.
- [첫 실행](media/uiux-ux03/run.txt): 장치 밖 개조 거절, 실제 장치의 개인 성능 구매, J 분리, 모듈 제작/장착·저장, 교역 필터/총액 등 15개 명시적 확인은 통과했다. 다만 초기 미생성 선박의 `modules` 접근 오류와 없는 탐험복 아이콘이 로그에서 발견되어 **이 실행을 오류 없는 통과로 기록하지 않는다.** 초기 선박을 읽기용 기본 상태로 처리하고 아이콘을 실제 렌더로 보완했다.
- [후속 실행](media/uiux-ux03/polish.txt): 실제 연구대 분석과 J의 읽기 전용 복귀, 초기 모듈 미리보기, 탐험복 아이콘을 확인했다. 9개 중 선체 영역/교역 이미지 배치 2개는 실패했다. 기존 차량 적재 카드의 높이, 거래 상세의 세로 배치를 수정했다.
- [작은 재현 창](media/uiux-ux03/layout.txt)에서 두 배치와 기존 교역 열기/환경음 재생 상태를 확인했다. 비교표 열 폭은 렌더에서 추가로 발견해 수정했고 [해당 화면 재확인](media/uiux-ux03/ship-layout.txt)을 통과했다. 최종 정비/교역 캡처는 동일 게임 컨트롤에 복사 저장·조회 데이터를 넣은 독립 Godot 창이다. 이후 비교표 열 간격만 소폭 늘렸다.
- 최종 직접 의존 스크립트 파서와 `git diff --check` 확인. 새 성장 작업의 선내 비활성화는 코드/파서 확인이며 별도 선내 플레이를 반복하지 않았다.
- 실제 6인·지연/재접속, 모든 등급/선체의 교체·분해·추첨, 개조 전 종류의 실제 구매, 생태 이식 전체 과정, 실제 교역 매매는 이번에 재검증하지 않았다. 교역 확인은 조회 snapshot fixture로 검색/가격/배치/오디오 재생 상태를 확인했다. 기존 ElevenLabs 파일을 재사용했고 별도의 청취 검수나 음원 제작은 하지 않았다.

## 범위 종료

[UX01~UX03](../planning/13-uiux-renewal-commits.md)로 나눈 U01~U13의 이번 개편을 구현했다. 모든 해상도·패드·전 거래 조합의 검증 완료를 뜻하지 않는다. A07 이후 고티어 연구 콘텐츠, 신규 성장 수치, 다른 선박 슬롯 확장은 이번 범위에 추가하지 않았다.
