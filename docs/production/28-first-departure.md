# 환영 편지와 첫 출격

2026-09-08 대체: 아래 환영 편지는 유지하며 이동 문구만 직접 항해로 갱신한다. 태양계 전용 출격 방식은 이전 이력이다. 현재는 [우주 화면 직접 항해 가이드](63-contextual-play-guide.md)를 사용한다.

2026-09-07 사용자 확정: 첫 진입에 편지 형식의 안내를 받고 태양계를 자유롭게 구경한 뒤, 태양계 전용 출격 버튼으로 가까운 다른 항성계에 고속 항해한다. 행성 홀로그램은 마우스 오른쪽 위에 조금 더 크게 표시한다.

## 구현

- 새 세계에서 태양계에 처음 진입하면 지구 개척 지원팀의 짧은 환영 편지를 보여 준다. 조작·주시 스캔·태양계 보호·첫 항해를 안내한다. 편지는 읽고 접으며 이때 출항을 강제하지 않는다.
- 편지 읽음은 로컬 `welcome_letters.cfg`에 은하 ID와 캐릭터 ID로 기록한다. 같은 캐릭터가 같은 세계에 재접속하면 반복 표시하지 않는다. 다른 기기에서는 읽음 상태가 공유되지 않는다.
- 태양계에서 대기 중인 조종사에게 `출격하기 [G]`를 표시한다. 편지를 닫은 뒤 버튼 또는 G로 시작한다. 마우스 시선 고정 중 버튼을 클릭하려면 Esc로 커서를 풀 수 있다.
- 호스트의 단일 `tutorial_depart` 요청으로 목적지 선정과 출발을 함께 확정한다. 태양계 밖·이동 중·비조종사의 요청은 거절한다. 협동에서는 연결된 승무원의 승선/준비 조건을 유지하고, 혼자 플레이는 기존 자동 준비 경로를 사용한다.
- 목적지는 외곽의 결정적 항성계 후보 최대 1,024개를 실제 지도 거리로 정렬하고, 착륙 가능한 T1 행성이 있는 가장 가까운 후보를 고른다. 은하 전체를 전수 검색한 절대 최단 항성계라는 의미는 아니다. 같은 세계는 같은 목적지로 연결한다.
- 무료 성간 항해의 기존 충전·가속·순항·감속·진입 모션과 음원을 사용한다. 도착 후 첫 행성 접근으로 이어진다. 새로운 이동 비용이나 점프권을 추가하지 않는다.
- 행성 홀로그램은 마우스 위치의 오른쪽 위에 배치한다. 마우스 고정 중에는 중앙 조준점을 기준으로 사용하고 화면 밖으로 잘리지 않도록 보정한다. 카드 최대 폭 420, 이름 27px, 설명 17px로 확대했다.

## 확인

첫 출격의 호스트 경로·T1/착륙 가능 목적지·준비 조건·실제 성간 항해·항성계 도착·태양계 밖 요청 거절·편지와 버튼 표시를 최소 실행으로 확인했다(10개 확인, 실패 0). 별도로 홀로그램의 변경 위치와 크기를 Godot Metal Forward+에서 렌더 확인했다. [편지 UI](media/first-departure/welcome-letter.png), [확대 홀로그램](media/planet-gaze/solar-hologram.png). 편지 이미지는 UI 확인용 실행 화면이며 최종 게임 시작 배경을 검증한 캡처와는 구분한다. 기존 투명 SubViewport의 SSR 비지원 경고가 있었으며 실행 오류는 없었다. 다중 클라이언트 실기는 수행하지 않았다.
