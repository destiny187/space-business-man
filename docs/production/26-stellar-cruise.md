# 항성계 오픈월드와 성간 초고속 항해

2026-09-10 후속: 이동 단계 문구·남은 시간 제거, 목적 방향의 안전 정렬과 연속 선회, 도착 이름 중심 화면은 [최신 연출 기록](45-stellar-flight-transition.md)을 따른다. 아래 단계명 표시는 당시 구현 이력이다.

## 확정 방향 — 2026-09-06

사용자는 은하 전체를 일반 추진으로 연속 비행하는 안 대신 항성계 내부 자유 비행·항성계 사이 빠른 이동을 선택했다. 기본 성간 항해는 무료이고, 순간적으로 넘어가는 퀀텀점프가 아닌 초고속으로 이동하는 개념이다. 초기 셀 2개·행성 매각마다 셀 1개 지급안은 적용하지 않는다. 은하의 고정 시드·외곽 저티어/중심 고티어·중앙 블랙홀은 유지한다.

## 실제 연결

- 현재 기본 협동/오프라인 원정 경로에서 조종사가 외부 시점(C)으로 전환하고 항해 패널(Tab)을 닫으면 W/S로 전후 추진, 마우스로 수평·수직 선회한다. 입력을 놓으면 제동한다. 화면 중앙으로 조준한 3D 행성을 클릭하면 항로 선택 창이 열린다. 목적지 자동 접근과 기존 착륙 버튼도 유지한다.
- 현재 항성계 외곽 반경은 20,000 게임 단위다. 외곽 안내 후 경계를 넘는 이동을 제한하고 선회·복귀를 허용한다. 항성·행성의 안전 반경에 진입하는 이동 선분을 검사해 통과를 막는다. 이는 물리 충돌 피해·궤도역학이 아닌 항해 안전 보조다.
- 다른 항성계로 출발하면 충전→가속→초고속 순항→감속→진입을 거친다. 기본 12초이며 설정 데이터의 초기 연출값이다. 호스트는 출발/도착 은하 좌표, 연속 진행률과 현재 항로 위치를 계산한다. 은하 항법도에도 항로와 위치를 표시한다.
- 출발 항성계는 가속하면서 원경으로 멀어지고, 항해 후반에는 목적지 항성계가 먼 곳에서 다가온다. 중간 교체는 원거리 감쇠가 끝난 시점에 수행한다. 별빛 흐름·시야각·진행 막대가 호스트 항해 상태를 따른다. 일반 조종으로 성간 빈 공간에 진입하거나 항로 중 자유 이탈하는 기능은 없다.
- 입력은 기존 만료되는 비신뢰 순서 보장 채널로 전달하며 현재 조종사 입력만 호스트가 사용한다. UI·설정 화면을 열거나 외부 시점을 끝내면 추진 입력을 보내지 않는다. 선체 내부 승무원 좌표를 변경하지 않는다.
- 항해 상태를 기존 저장에 포함한다. 기존 `jump` 식별자는 호환을 위해 내부에서 유지하며 사용자 표기는 성간 항해다. 예전 항해 중 저장에 경로가 없으면 현재 출발·목적지에서 복구한다. 신규 설정이 없는 저장에는 기본값을 사용한다.

## 자산·음향

기존 Blender 우주선·태양계/행성 모델을 재사용하고 Godot Forward+에서 실제 표시를 확인했다. 새 효과는 화면에 그리는 별빛 선과 진행 표시이며 새 3D 모델은 제작하지 않았다. 기존 ElevenLabs `sfx_robot_charge`(충전), `sfx_robot_move`(추진 루프), `ui_discovery`(항해 종료)를 재사용한다. 전용 성간 엔진 음원은 신규 생성하지 않았다. 엔진 루프의 피치가 진행률을 따르고 항해 종료 시 멈춘다.

## 확인 범위

[전용 실행 검사](../../우주-비즈니스/tests/test_stellar_cruise.gd)는 직접 추진·제동·외곽 제한·잘못된 입력 거절·무료 출발·단계별 상태/저장 검증·단조 진행·목적지 접근·착륙 연결을 확인한다. Apple M2 / Metal Forward+ 실제 창에서 [충전](media/stellar-cruise/phase-008.png), [순항](media/stellar-cruise/phase-058.png), [진입](media/stellar-cruise/phase-112.png)을 촬영했다. 최종 전용 검사 261개 확인, 실패 0이다. 음원 연결·충전 재생 호출도 검사했으며 청취 품질 평가는 별도로 남는다.

다중 클라이언트 실기·장시간 성능 검사는 실행하지 않았다. 항성계 생성/교체는 현재 동기식이며 이 구간의 완전한 무정지 성능을 보장하지 않는다. 실제 성간 공간 전체의 물리 시뮬레이션, 임의 항로 중단, 구형 행성까지 연속 착륙은 완료 범위가 아니다. 행성 이름 생성 체계는 이전 조사 제안 상태이며 이번 항해 변경에 포함하지 않았다.

## 마우스 시선·조종 — 2026-09-07

사용자 요청에 따라 평소 선내·지표 이동은 우클릭 없이 마우스 이동으로 시선을 돌린다. 외부 시점의 조종사는 마우스로 우주선을 선회하고, 자동 접근/성간 항해 중 또는 조종 권한이 없는 승무원은 항로를 바꾸지 않고 카메라로 주변을 본다. 감도·수직 반전 설정을 공통으로 적용한다.

메뉴·아이템창·항법도·설정이 열리면 커서를 풀고 선회 입력을 비운다. Esc로 별도 커서 해제가 가능하며, 창을 닫은 뒤 화면을 클릭하면 마우스 시선을 재개한다. 기본 플레이 중 커서는 중앙에 고정하고 외부 시점에 중앙 조준 표시를 둔다. 창의 포커스를 잃거나 원정을 종료할 때도 커서를 해제한다.

최소 실행에서 일반 시선·감도/반전·직접 조종 입력·자동 항해 둘러보기·실제 비행 카메라 렌더를 확인했다. 기존 사용자 설정 시작 처리에 대한 동시 작업 변경은 보존했다. 다중 클라이언트 반복 검사는 수행하지 않았다.

## 항성계 원경 출발·접근 — 2026-09-07

사용자 요청에 따라 진행률 18%에 천체를 숨기고 90%에 목적지를 갑자기 표시하던 방식을 교체했다. 출발 시 주변 천체를 피하는 전방 항로를 선택하고 선체를 정렬한 뒤, 카메라가 선체 뒤에서 전진을 따라간다. 우주선의 표시 위치가 그 항로를 따라 원래 위치에서 부드럽게 멀어진다. 출발 천체는 작아지며 점차 흐려지고, 50%의 보이지 않는 시점에 항성계를 교체한다. 목적지는 항해 후반의 먼 거리에서 나타나 도착 관찰 위치까지 감속 접근한다. 카메라 회전도 보간하고, 도착 제목은 실제 항해 완료 시 표시한다. 이동 중 스캔을 막고 완료 후 기존 스캔·직접 조종을 유지한다.

`space_presentation.json`의 `stellar_transition`에 표시 거리·교체 시점·감쇠 구간·원거리 클리핑을 둔다. 표시 이동은 호스트 항로 진행률을 따르며 실제 충돌 위치·항해 소요 시간·저장 스키마는 바꾸지 않는다. 원경 접근의 끝은 호스트의 `entry_position`과 같아서 이전 요청의 넓은 도착 시야로 이어진다. 기존 Blender 천체·선체와 ElevenLabs 엔진/추진 음원을 재사용한다.

최소 확인: `check_stellar_transition.gd`에서 출발/도착 천체 표시, 보이지 않는 교체 시점, 원경 클리핑 여유, 도착 위치 연속성과 투명도 복원을 확인했다. Godot 4.7.2 Forward+/Metal 실제 1280×800 화면에서 단계별 렌더를 검수했다(`test-results/stellar-transition`). 동기식 항성계 생성의 성능 한계와 다중 클라이언트 실기 미검증은 유지한다.

## 전방 항로 정렬 후 출발 — 2026-09-07

사용자는 출발 때 정면의 행성이 작아지며 사라져 후진처럼 보이는 점을 지적했다. 뒤쪽 항성계를 바라보던 출발 카메라와 선체 방향/표시 이동 방향의 불일치를 제거했다. 호스트는 현재 정면부터 각도를 넓히며 항성 경고 영역·행성 고리·위성·정거장을 피하는 직선 출발 항로를 찾는다. 천체의 출발 구간 공전 이동량과 추가 여유를 포함한다. 막히지 않은 정면은 그대로 사용하고, 가로막힌 경우 가까운 각도의 우회 방향을 우선한다.

출발 원점·기존 방향·선정 방향을 항해 상태에 저장한다. 처음 20% 구간에서는 위치 이동·주 추진을 멈추고 선체를 정렬한 뒤 같은 방향으로 가속한다. 카메라는 선체 뒤에서 진행 방향을 따른다. 항해 종료 후 원경 접근·관찰 위치와 기존 첫 지구 근접 시작은 유지한다. 새 항로 필드가 없는 기존 항해 저장은 표시 계층에서 안전 방향을 계산하는 호환 처리를 둔다.

`check_forward_departure.gd`의 실제 Godot Forward+/Metal 창에서 정면 지구 회피, 전방 인접 방향 우선, 정렬 전 정지, 기수/이동/카메라 방향 일치, 움직이는 행성 여유, 저장 방향 재현을 확인했다. 단계 화면은 `test-results/forward-departure`에 기록했다. 전체 회귀·다중 클라이언트 검사는 수행하지 않았다.
