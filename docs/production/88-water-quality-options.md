# 수면 품질 옵션 — 2026-09-09

사용자가 규칙적인 흰 점을 지적하고, 카툰 표현을 유지하면서 낮음과 최상의 물결 품질을 구분하도록 요청했다. 기존 모델과 물리 물 계산을 유지하고 현재 원정의 바다·하천·굴착으로 고인 물에 개인 수면 품질을 연결했다.

## 적용

설정의 **수면 품질 → 낮음 / 보통 / 최상**에서 즉시 바꾼다. 전체 그래픽 프리셋에도 포함하며 수면만 따로 선택할 수 있다. 기존 설정에 수면 값이 없으면 전체 프리셋을 따르고, 사용자 지정 상태였으면 보통으로 시작한다. 개인 설정 파일에 저장하며 호스트의 게임 상태에는 넣지 않는다.

| 수면 품질 | 표현 | 바다 메시 비용 |
| --- | --- | --- |
| 낮음 | 완만한 두 물결의 넓은 카툰 명암. 정점 변형과 세부 물결 반사 띠를 생략 | 정점 4개 / 삼각형 2개 |
| 보통 | 방향이 다른 네 물결, 움직이는 표면 법선, 약한 끊어진 반사 띠. 바다 높이 약 5cm 이내 변화 | 정점 2,561개 / 삼각형 5,056개 |
| 최상 | 근거리 잔물결 추가, 강해진 표면 굴곡·시선 각도에 따른 반사색, 물가 거품. 바다 높이 약 11cm 이내 변화 | 정점 8,193개 / 삼각형 16,256개 |

두 사인파의 최대점이 흰 점으로 반복되던 무늬를 제거했다. 서로 다른 방향·길이의 물결과 중간에 끊기는 물결 띠로 바꾸고 INK 공통 조명과 카툰 색 단계를 사용한다. 실제 화면 반사 SSR은 기존 효과 옵션을 따른다. 별도의 반사 카메라나 굴절 패스는 추가하지 않았다.

바다는 관찰자 근처에 정점을 집중한 연속 메시를 품질별로 한 번 만들고 재사용한다. 원거리 잔물결과 정점 진폭은 거리에 따라 줄이고 물가의 정점 변형도 수심에 따라 완화한다. 하천에는 흐름 방향의 무늬를 더하며, 하천과 물리 물의 셀 경계는 정점 파도로 변형하지 않고 표면 법선·색으로 표현한다.

이 옵션은 시각 품질이다. 기존 수위·유량·수영·침수 판정은 평균 수면을 사용하며 그래픽 옵션으로 달라지지 않는다. 기존 성능 개선의 처리 예산과 Blender 자산도 유지한다.
