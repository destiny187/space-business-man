# 항해 간소화와 공통 메뉴 전환

## 2026-09-07 사용자 확정

상시 항해 패널을 제거하고 지상과 같은 우측 상단 지도, 가까운 행성의 착륙 선택, 필요할 때 펼치는 큰 지도로 바꾼다. Esc에서 계속하기·설정·종료에 접근하고, 지도/아이템/건설/연구/정비를 전환하거나 닫을 때 마우스와 시점 조작이 정상적으로 복구되어야 한다. 시각 원칙은 [FIELD v1](22-uiux-guide.md)을 따른다.

## 현재 연결

- 우주 HUD는 180px 원형 항성계 지도, 선체/추진 상태, 목적지·주시 스캔 중심이다. 지도는 지상 레이더와 같은 우측 상단 여백을 사용하며 우주선 방향과 평면 밖 고도 표식을 표시한다. 성간 항해 중에는 은하 항로로 전환한다.
- Tab은 큰 항성 지도다. 휠 확대·우클릭 이동, 항성계/은하 전환, 선택 행성의 실제 Blender 제작 모델과 기존 Godot 재질 미리보기, 관측한 자원 아이콘, 수자원·대기 적합·기온 적합 막대와 방문 기록을 제공한다. 즐겨찾기 추가 버튼과 조사 상세 문단은 제거했다. 미리보기 렌더는 지도에서만 켠다. 목록에 있던 후보·방향 이동·중복 출발/착륙 버튼을 제거했다.
- 지도 선택은 개인 미리보기이며 항로 설정·출발을 누를 때 요청한다. 호스트 승인과 해당 리비전의 상태 수신 후에만 출발을 요청한다. 선택 단계에서 공동 목적지를 계속 바꾸지 않는다.
- 직접 비행/자동 접근 후 착륙 범위에 들어오면 F 착륙 안내가 나타난다. 바라보는 천체를 우선하고, 없으면 선택 목적지를 사용한다. 범위 경계 바깥의 짧은 여유 구간에는 접근 안내로 바뀐다. 자동 착륙이나 새 확인 팝업은 없다.
- 호스트는 조종자·현재 항성계·실제 거리·착륙 허용·연결된 승무원 준비를 검증한 뒤 목적지/방문 기록과 착륙을 함께 확정한다. 이전 자동 접근 완료 위치가 다른 행성이어도 직접 비행 도착은 허용한다. 고리 천체는 기존 항해 안전 반경을 사용한다. [기존 착륙 연출](35-planet-arrival.md)과 ElevenLabs 음원을 재사용한다.
- 지상 우주선 복귀 범위에는 F 이륙, 가까운 회수 화물에는 F 인수를 표시한다. P 승무원 화면에 준비·권한·내보내기를 모으고, K/메뉴에서 정비한다. 선내 보관함의 화물 이동은 I 공동 창고에 연결한다. 우주에서도 개인 아이템을 볼 수 있고 지상 제작/개조 조건은 유지한다.
- Esc: 열린 작업창 닫기 → 플레이 복귀. 작업창이 없으면 계속하기·설정·정비·승무원·시작 화면·종료 메뉴. 설정에서 Esc는 메뉴로 돌아온다. 종료/시작 화면은 기존 세션 저장·실패 처리 경로를 사용한다. 협동 세계를 일시정지시키지 않는다.

## 입력 버그 수정

기존 Esc는 `cursor_released`만 켜고 메뉴를 열지 않았다. I/B/J는 `_unhandled_input`에서 처리해 포커스된 UI에 키가 소비될 수 있었다. 이제 I/B/J/K/P/Tab/Esc를 UI 포커스 처리 전에 받되 글자 입력 중에는 편집을 우선한다. 큰 화면은 하나만 열며 같은 키/닫기/Esc 모두 공통 전환 경로를 따른다. 표시 변경과 설정 닫기에서 포커스·누적 선회·커서 해제 상태를 정리하고 게임 창에 포커스가 있으면 마우스를 다시 캡처한다. 메뉴·설정·팝업 중에는 이동/시선/도구/스캔을 차단한다. 닫기 클릭을 계속 누르고 있어도 지상 도구 입력으로 넘어가지 않도록 마우스 버튼 해제를 기다린다.

## 실제 확인과 제한

Godot 4.7.2 / Metal Forward+ / Apple M2의 실제 창에서 1280×800와 960×640 지도·선택 모델·조사 상세·Esc 메뉴를 렌더하고 확인했다. 임시 세계의 근접 위치를 구성해 F 요청부터 기존 접근/하강·지표 로딩·조작 복귀를 실행했다. 지도 경유 출발은 승인 응답 후 상태 수신 순서까지 확인했다. 먼 거리 요청의 거부, 저장·착륙 상태 재개도 확인했다.

`tests/check_navigation_interface.gd`에서 실제 마우스 캡처/해제, 포커스된 지도 버튼→아이템→지도→정비→아이템, 지상의 건설→아이템→연구→아이템→Esc를 확인했다. `test_interface_cursor.gd`의 기존 메뉴/설정/모달 커서 검사도 통과했다. `check_pause_input.gd`로 메뉴 바깥 도구 클릭·Q/F/C 입력 차단과 복귀를 확인했다. 최종 두 실제 창 실행 로그에 엔진/스크립트 오류가 없었다. 실행 이미지는 로컬 `test-results/navigation-interface/`에 둔다.

새 모델/음원을 제작한 작업이 아니다. 장시간 수동 항해, 인터넷/6인 동시 전환, 모든 해상도·패드·자유 착륙 지점은 확인 범위에 포함하지 않았다. 은하 지도는 기존 표본 항성계·기록·즐겨찾기 표시를 유지하며 모든 백만 행성을 한 화면에 나열하지 않는다.

## 후속 간소화 — 2026-09-07

사용자 요청으로 즐겨찾기 버튼과 조사 상세 버튼/긴 문단을 삭제했다. 행성 모델·이름·종류/티어·자원 아이콘·필요한 위험/착륙 제한·출발만 남기고 환경은 세 개의 0~100 막대로 전달한다. 수자원은 실제 비율, 대기/기온은 기존 평가식의 적합도이며 섭씨 온도 자체를 백분율처럼 표시하지 않는다. 정확한 비율·기온·기압·산소는 해당 막대 툴팁에서 확인한다. 미조사 행성은 막대를 숨기고 ‘미조사’만 표시한다. 기존 즐겨찾기 저장 기록은 보존한다.

실제 Forward+ 960×640 창에서 `clean-map.png`를 확인했다. 미관측 값 숨김·관측 후 막대 값·버튼 제거를 최소 확인했고 해당 실행의 엔진/스크립트 오류는 없었다. 항해/착륙 전체 검사는 반복하지 않았다.

## 우주 주시 스캔 말풍선 복구 — 2026-09-07

사용자 정정: 간소화 대상은 항성 지도이며, 우주에서 행성을 스캔했을 때 이동 여부를 판단하는 설명 말풍선은 유지한다. 지도 간소화 때 과도하게 축소했던 스캔 완료 홀로그램을 복구했다. 행성 이름·종류·티어·테라포밍/착륙 가능 여부, 자원 아이콘/이름, 수자원·대기 적합 막대/수치, 위험·환경 개선 부담, E 접근 안내를 다시 표시한다. Tab 안내는 현재 항성 지도로 연결한다.

우측 상단 미니맵과 겹치지 않게 말풍선을 조준점 왼쪽에 두며 메뉴 중에는 숨긴다. 항성 지도의 간소화와 즐겨찾기 버튼 삭제는 유지한다. 기존 제작 모델·재질과 주시 스캔/완료 음향을 그대로 사용한다. 실제 Godot Forward+의 1280×800 및 960×640 스캔 완료 화면을 확인했고 실행 오류는 없었다. 렌더 결과는 로컬 `test-results/scan-bubble/`에 둔다.

## 2026-09-07 — 방문한 항성계만 지도 상세 조회

사용자 확정: 항성 지도에서는 방문한 항성계만 눌러 확인한다. 현재 항성계와 개인 항해 기록의 `systems`에 있는 항성계만 선택 대상으로 등록한다. 항성계에 진입하면 기존 관측 기록으로 해제되며 행성 착륙은 필요하지 않다. 미방문 항성계의 기존 즐겨찾기는 선택 권한을 주지 않고, 기록 화면을 통한 미방문 행성 미리보기도 차단한다. 중앙 블랙홀은 위치 표식으로 유지하고 클릭 확대 창은 제거했다.

행성 수·생성 시드·항로 이동 규칙은 변경하지 않았다. 현재 100만 행성은 12만 5천 항성계에 배분되지만, 은하 지도는 고정 표본 약 200개와 현재/선택/방문/즐겨찾기 항성계를 그린다. 이 변경 당시에는 확대 시 추가 항성계를 불러오지 않아 성도가 성기게 보였다. 이후 아래의 확대 영역 표시로 대체했다.

최소 확인: 임시 단독 세계의 실제 Godot 4.7.2 Metal Forward+ 1280×800 창에서 신규 세계 선택 대상, 미방문 상세/클릭 차단, 블랙홀 팝업 차단, 기존 즐겨찾기 우회 차단, 방문 기록 이후 선택 해제와 행성 화면 진입을 확인했다(7개 확인, 실패 0). 캡처 `/tmp/map-visited.png`. 전체 회귀·저장 재개·다중 클라이언트 검사는 수행하지 않았다. 모델·음원 변경은 없다.

## 2026-09-07 — 확대 영역의 항성계 추가 표시

사용자 승인에 따라 고정 표본만 확대하던 표시를 전체 항성계 좌표 기반으로 확장했다. 기본 새 은하 12만 5천 항성계의 지도 좌표를 별도 작업 스레드에서 계산해 캐시하고, 확대·이동 시 화면에 해당하는 추가 항성계를 밀도에 맞춰 표시한다. 백만 행성의 상세 데이터나 Node를 한꺼번에 생성하지 않는다. 총 행성 수·생성 시드·저장된 위치 계산은 유지하며, 미방문 항성계 내부의 행성 상세는 계속 차단한다. 같은 시점에 반영된 3D 은하 항로 화면도 이 좌표 캐시를 사용한다.

실제 Metal Forward+ 창에서 12만 5천 좌표 준비 완료, 확대 후 기존 전체 보기에는 없던 주변 항성계 추가, 미방문 내부 상세 제한을 확인했다. 메인 스레드의 점진 계산이 3D 지도 렌더와 경쟁해 늦어지는 문제는 좌표 전용 작업 스레드로 옮겨 해결했다. 렌더·선택 처리는 메인 스레드에서 유지한다. 로그와 실제 1280×800 화면은 `test-results/launch-map/`에 둔다.

## 2026-09-07 — 후속 항로 선택 규칙으로 대체

미방문 항성계 클릭 전체 차단은 [3D 은하 항로](43-galaxy-routes.md) 요청으로 변경됐다. 미방문 항로 선택은 허용하며 내부 상세만 방문 후 공개한다. 확대별 별 밀도·공간 검색·근처 보기·항속거리·비행 화면 표식은 새 소관을 따른다.
