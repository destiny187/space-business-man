# 누구나 건설·원정 공용 튜토리얼

2026-09-14 사용자 추가 확정: 참가자 누구나 건설하고, 함께 플레이하는 튜토리얼은 누구든 한 명이 수행하면 모두가 진행을 공유한다. 190의 건설 연출과 별도 커밋으로 반영한다.

## 현재 규칙

- 건설은 기존처럼 모든 참가자가 자기 배낭 재료로 요청한다. 방장의 수동 승인/호스트 전용 건설 제한은 없다. 기존 연구 해금·공간·재료·저장 판정은 유지한다.
- 개인별 가이드 진행을 원정의 `crew.play_guide` 공용 단계와 합친다. 어느 한 명의 완료가 모든 참가자에게 전달되고, 늦게 합류한 참가자도 해당 원정의 완료 기록을 받는다.
- 전진·부스트·스캔·성간 이동·장비/아이템 확인·광물 조사/채집·첫 건설·테라포밍 확인·가동 후 안내 완료를 공유한다. 먼저 완료한 항목은 이후에도 유지된다. 아직 진행하지 않은 앞 단계까지 건물 하나로 임의 완료시키지는 않는다.
- 건설 완료는 건물/재료와 같은 서버 거래에서 기록한다. 광물 채집과 최초 광물 스캔도 실제 성공 기록과 연결한다. UI 방문·조작 연습처럼 로컬에서 관찰하는 항목은 허용된 11개 키만 공용 기록에 합친다. 단계 보고로 재료·연구·시설 권한을 얻지 않는다.
- 가이드 숨김 설정과 첫 안내 편지의 읽음 표시는 개인 설정이다. 한 명이 가이드를 꺼도 그 사람의 건설/채집/광물 조사는 공유된다. 장비 선택이 다른 참가자가 이미 완료한 공동 단계를 되돌리지 않는다.
- 새 원정의 공용 기록은 비어 있다. 현재 원정 키로 저장된 개인 진행은 합치고, 어느 원정인지 알 수 없는 옛 캐릭터 전역 진행을 새 원정에 복사하지 않는다. 기존 개인 기록 파일을 삭제하지 않는다.

## 처리 범위

서버 성공 거래에 공용 단계 몇 개를 추가하고 기존 저장/스냅샷 경로로 전달한다. `guide_progress` 전용 초안은 해당 승무원 요청 순번·수령 기록과 작은 공용 사전만 복사한다. 지형·행성·산업 원장을 깊게 복사하지 않는다. 합치기는 단방향이며 다른 참가자의 완료를 지우지 않는다. 최신 원정 revision과 달라도 합집합을 허용하지만 연결된 참가자·세션·순번·단계 목록을 검증한다.

클라이언트는 미전달 단계만 묶어 1개 요청으로 보내며 응답 대기와 2초 재시도 간격을 둔다. 공용 단계가 이미 같으면 아무 요청도 하지 않는다. 가이드 보고에는 성공 효과음/획득 표시를 내지 않으며 지표 패킷의 즉시 재발행도 요청하지 않는다. 정상 원정 스냅샷/원자적 저장의 기존 비용은 남아 있다. 메뉴가 닫혔거나 가이드를 숨겨도 공동 기록 수신은 계속한다.

## 검수

`check_shared_play_guide.gd`의 좁은 권한/저장 검사 17항목 통과: 일반 참가자 입장·실제 건설, 자기 배낭 사용, 저장 실패 시 공용 단계 미진행, 동일 요청 중복 처리 방지, 방장/참가자 동일 기록, 공용 사전 복사 격리, 이전 revision 보고의 합집합, 잘못된 단계 거절, 늦은 입장, 실제 저장 재읽기, 새 원정 초기 상태, 지표 재발행 제외를 확인했다.

Godot 4.7.2 Forward+/Metal 실제 원정에서 **16항목 통과**: 일반 참가자의 건설 거래 뒤 방장 화면이 10→11단계로 진행, 참가자 스냅샷의 동일 완료, 비어 있는 개인 가이드의 진행 인계, 건설 연출을 멈추지 않은 자연 재생·SFX 녹음·저장 재읽기를 확인했다. 검수용 참가자는 권한 계층에 입장시킨 논리 피어이며 별도 네트워크 클라이언트가 아니다. 처음 검수의 없는 원격 소켓으로 보내는 RPC 오류는 테스트 발행을 로컬에 한정해 수정했으며 최종 실행 오류는 없다. 테스트 원정은 `/tmp/shared-guide-play`, 규칙 검사의 저장은 `/tmp/shared-guide-rules.json`으로 격리한다. 외부망 6인 동시 조작·지연/유실 스트레스 검사를 수행한 것은 아니다.

```sh
tools/godot.sh --headless --script res://tests/check_shared_play_guide.gd
tools/godot.sh --script res://tests/check_shared_guide_play.gd -- --crew-ui-test --crew-folder=/tmp/shared-guide-play
```
