# 중간 유사 동물의 체형 교체

2026-09-11 사용자 요청. 8,000종을 넘겨 숫자를 늘리기보다 비슷한 묶음의 중간 개체를 아예 다른 종으로 교체한다. 기존 제작은 신체 구조·기관 98묶음에 각 50종인 동물 4,900종이며, 종별 색·크기 20외형은 기본종 수에 포함하지 않는다.

## 이번 구현 범위

각 동물 묶음의 25·26번째 총 196종을 교체한다. 이는 이번 작업에서 정한 첫 교체 범위이며 사용자가 196이라는 수를 직접 지정한 것은 아니다. 전체 기본종 8,000·동물 5,600·조류형 140을 유지하고 기존에 공개한 1,000종과 저장 파일은 건드리지 않는다. 대체 대상은 아직 정식으로 발행하지 않은 7,000종 확장의 제작 슬롯이다. 슬롯 ID는 유지하지만 새 해부 구조와 이름·환경 조건을 사용한다.

큰 체형 28가지는 사슴형/코끼리형, 개과형/고양이형, 거북형/악어형, 기린형/낙타형, 코뿔소형/들소형, 개구리형/오리너구리형, 천산갑형/아르마딜로형, 도마뱀붙이형/스킹크형, 캥거루형/토끼형, 섭금류형/올빼미형, 거미형/전갈형, 게형/소라게형, 족제비형/뱀형, 사마귀형/딱정벌레형이다. 각 체형에 7기관 계통을 조합한다. 지구 동물을 그대로 생태 자료로 등록하는 것이 아니라 식별 가능한 큰 구조에 외계의 여과·감각·차열·저수 기관을 결합한다.

Blender의 몸통·목·머리·사지 구성과 실제 관절 계층을 새로 제작한다. 네발/도약형은 엉덩이→무릎→발목, 집게는 팔→손바닥→두 손가락, 코/독침/꼬리는 연속 관절, 뱀은 연속 가중치 척추를 쓴다. 게임의 이동 상태에는 사지 길이·굽힘 방향으로 계산한 발 접촉 모션을 연결한다. 이것이 야생 동물의 추적·사냥·무리 AI 구현을 의미하지는 않는다.

행성별 허용 기질과 온도·압력 판정, 한 행성만의 자연 원산지 규칙은 유지한다. 차열 등딱지/중갑/전갈형 등과 온화한 기후의 초식/도약형을 구분해 배정한다. 실제 외계 생리가 확인됐다는 뜻은 아니다.

## 제작·확인 상태

2026-09-11 사용자 후속 지적에 따라 196종 전체의 눈·얼굴을 수정했다. 최종 원본은 척추형 140개 `midpoint-6-details`, 절지/조류형 56개 `midpoint-5-orbits`다. 안와의 두개골 표면을 실제로 오목하게 가공하고 홍채와 동공을 곡면에 맞췄다. 수염의 눈 가림·코 연결부 경계·둔한 부리 끝도 수정했다. 돌출된 동일 구형 눈 대신 체형별 눈구멍·눈매·눈꺼풀·가로/세로 동공·여러 홑눈·육각 렌즈의 겹눈·자루눈을 구분한다. 밝은 공통 청록 눈 대신 비발광 홍채·어두운 동공·체형별 색을 사용한다.

- 196종의 Blender 원본·게임용 두 LOD를 다시 제작하고 전신 화면을 전부 확인했다. 눈이 보이는 확대 얼굴은 28체형 모두 Blender와 실제 Godot INK 렌더에서 확인했다.
- 실제 가져오기 SHA/MD5가 맞는 모델로 다섯 동작 상태·두 LOD 검사를 통과했다. 196종의 골격 부모 계층·보행 한 주기·사지 길이·발 접촉 높이·발목 방향 확인은 40,118항목, 실패 0이다.
- 전체 확장의 대표 전신은 원본 658개·게임 658개, 동작은 85해부 체형을 직접 검토했다. 기본 모델 7,000개와 두 LOD의 전수 형상/스킨 검사도 오류 0이다. 정규화 형상 중복이 없다는 것이 예술적 다양성의 자동 증명은 아니다.
- 정식 확장 카탈로그에 반영했다. 최종 카탈로그의 원산 행성 배정 검사는 통과했다. 사용자 테스트 재개 요청 후 실제 활성 창의 T2 원산 행성 109808에서 교체 사슴형 `biota_spindle_mandibles_25`의 골격 운동·E/Q/J·기존 확인음·표본 저장/재열기를 확인했다. 27항목 실패 0이며, 비활성 창 일시정지를 우회하지 않았다. 얼음 행성 107972의 일반 동물/식물 검사는 40항목 실패 0이다. 대표 자연 원산지의 준비된 접근 위치에서 확인했으며 196종 모두의 개별 현장 탐험 검사로 확대하지 않는다.
- 이 과정에서 960×640 도감의 고정 연구 메뉴가 생물 미리보기 하단을 가리던 문제를 발견했다. 모델·설명·연구 메뉴를 같은 상세 스크롤에 넣고 종을 바꾸면 상단으로 돌아가게 수정했다. 교체 동물·일반 동물·식물의 전신 렌더와 스크롤 후 표본 메뉴 접근을 확인했다. 결과는 [교체 종 검사](media/biota/midpoints/field/t2-surface-check.json)·[일반 T2 검사](media/biota/t2-surface-check.json), 화면은 [교체 동물 도감](media/biota/midpoints/field/t2-animal-journal-960.png)에 둔다.

[대표 얼굴 비교](media/biota/midpoints/faces-game-prototypes-01.jpg) · [중앙 슬롯 교체 전후](media/biota/midpoints/before-after-game.jpg). 변경 전 196개 메타데이터와 원본/게임 캡처는 `output/biota-midpoint-before/`에 보존했다.

이번 얼굴 수정 범위는 교체한 196종이다. 기존 1,000종과 나머지 확장 모델의 얼굴을 일괄 재조형한 작업은 아니다. 같은 체형의 7기관 계통은 친연성이 보이는 외형을 공유한다. 눈 깜빡임·시선 추적·무리/사냥 AI·새 울음 음원은 이번 얼굴 수정에 포함하지 않았다. 조류 비행/착지·가스 관측·전체 도감은 최종 카탈로그로 확인했다. 전체 종수·환경·리깅·플레이의 실제 범위는 [8,000종 기록](124-biota-8000-work.md)을 따른다.

원본 정의는 `tools/bestiary/biota_midpoint.py`, 제작은 `biota_midpoint_art.py`와 기존 조류 제작 함수, 눈은 `biota_eyes.py`다. 전신·얼굴·동작 검수 기록은 `media/biota/visual-review.json`에 모델 해시와 함께 보존한다.
