# 완전 침수 시설의 사용 중단

2026-09-09 사용자 요청: 기존 물리 물 작업을 먼저 커밋한 뒤, 시설 전체가 물에 잠기면 사용할 수 없도록 한다. 기존 물리 작업은 `49a61c6a`에 커밋했다. 이 기록은 이후 시설 사용 규칙이다.

## 규칙

기존 시설 9종과 Mk.2/Mk.3 부착물의 실제 GLB 경계를 한 번 추출한 `data/facility_water_bounds.json`을 사용한다. `tests/export_facility_water_bounds.gd`로 다시 추출할 수 있다. 모델을 바꾸거나 시뮬레이션 중 GLB를 읽지 않는다.

호스트가 모델 상단의 모서리·중간점 9곳과 중앙의 수직 구간을 확인한다. 상단까지 물이 덮이고 몸체 중앙도 잠겨야 완전 침수다. 상단이 드러난 부분 침수, 마른 몸체 위에 떨어진 수면은 완전 침수로 보지 않는다. 판정에는 5cm 여유를 사용한다. 기존 1m 물 셀과 원래 해저 위의 바닷물 판정을 재사용하며, 육지 아래의 닫힌 동굴에 해수면 높이만으로 침수를 적용하지 않는다.

완전 침수 시 `submerged=true`, `active=false`, `working=false`, 상태는 **완전 침수 · 사용 불가**다.

- 발전기는 공급 전력에서 제외한다. 충전기·제작소·환경 처리기는 가동하지 않는다.
- 제품·로봇·로버·FINCH·공학 실험의 기존 활성 시설 검사에 연결되어 진행을 멈춘다. 진행률·재료·재고·사용자가 정한 전원 스위치는 보존한다.
- 시설 조작·생산·개조·연구 요청은 호스트에서 거부한다. 이미 열린 시설 화면도 다음 상태를 받으면 닫고, 물속 시설에 다시 접근하면 이유를 표시한다. 배수 후 다시 열 때 이전 침수 안내를 지운다.
- 설치한 보관함과 기본 현장 창고 모두 침수되면 인수·반납 접근점에서 제외한다. 기본 창고로 돌아오는 로봇은 사용할 수 있는 다른 보관함으로 향하며, 없으면 화물을 보존하고 대기한다. 보관 용량이나 저장된 재고는 삭제하지 않는다.
- 수위가 내려가면 정상 전력·토대·재료 조건에 따라 재개한다. 플레이어가 직접 꺼둔 시설은 계속 꺼져 있다. 기존 철거의 작업 중 제한과 자재 반환 규칙은 유지한다.

기존 모델의 가동 부품·작업등·작업음은 `active`/`working`을 통해 함께 정지한다. 시설 표시는 사용 불가 기호와 파란 상태색·짧은 이유를 사용한다. 새 Blender 모델이나 음원을 만들지 않는다.

## 비용·저장

별도 매 프레임 물리나 렌더 패스를 추가하지 않는다. 시설은 기존 1초 산업 계산에서 평가한다. 실제 요청도 최신 물 상태를 읽어 오래된 버튼으로 사용할 수 없게 한다. 비사업 상태에서도 존재하는 기본 현장 창고는 착륙 관심 구역 갱신에 연결했다. 저장·지표 복제에 선택 불리언을 추가하고 타입을 검사한다. 기존 필드가 없는 저장도 유지한다. 침수 판정 데이터는 협동 콘텐츠 해시에 포함한다.

## 확인과 경계

- `check_facility_flooding.gd`: 부분/완전 침수, 상단 일부 노출, 분리된 수면, 호스트 조작 거부, 제작 진행·재료 보존, 기본 창고 잠금, 발전량 제외, 배수 재개·수동 정지 유지, 저장·압축 복제를 확인했다. **22개, 실패 0**.
- `check_facility_flooding_play.gd`: 별도 임시 저장에서 실제 Godot 4.7.2 Metal Forward+를 실행했다. 제어된 수위로 기존 Mk.2 제작소의 가동 부품·작업음 중단, 물 메시와 침수 상태, 기본 창고/시설 화면 차단, 배수 후 재사용·체크포인트를 확인했다. **13개, 실패 0·엔진 오류 0**. [실행 기록](media/facility-flooding/verification.json), [침수](media/facility-flooding/submerged-factory.png), [배수](media/facility-flooding/drained-factory.png).

초기 시험은 구 항해 도우미의 착륙 대상과 제품 ID, 렌더 시험의 활성 사업 포인터를 수정했다. 기본 창고는 제작소보다 높고 위치도 달라 같은 작은 물 영역에 완전히 잠기지 않는 것이 확인되어 창고 시험의 수위·범위를 조정했다. 실제 화면에서 발견한 배수 후 오래된 침수 안내는 성공적인 재접근 시 제거하도록 수정했다. 사용자의 실제 저장은 건드리지 않고 메모리 세계 또는 명시한 임시 복사본을 사용했다.

상단과 중앙을 표본화하는 판정이며 모든 메시 삼각형의 잠김을 검사하지 않는다. 부식·영구 파손·재고 손실·시설 방수벽·차량 부력은 추가하지 않았다. 전체 회귀, 6인 실접속, 전 시설의 장시간 침수와 전체 FPS 비교는 수행하지 않았다.
