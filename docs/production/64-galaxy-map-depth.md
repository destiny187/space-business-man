# 은하 지도 확대 입체감 — 2026-09-08

## 요청과 원인

확대할 때 단순한 평면 점 지도로 보이는 문제를 개선한다. 기존 구현은 8배 확대 또는 근처 보기에서 Blender 별 무리와 성운을 모두 숨기고 실제 항성계를 동일한 Y=0 평면에 배치했다. 확대용 메시도 작은 저해상도 점과 2D 원으로 덮여 입체감이 약했다.

## 변경

- 별 무리의 원거리 LOD는 유지하고, 근거리에서는 Blender의 매끄러운 구형 항성 아이콘을 MultiMesh로 재사용한다. 3단 명암·절제된 빛 번짐·청색/크림색 변주와 확대 가독성을 적용했다. 색 변주는 지도 표현이며 미방문 항성의 내부 조사 정보를 공개하는 규칙이 아니다.
- 실제 항성계 좌표에서 재현되는 **지도 표현용 높이**를 부여한다. 저장 좌표·호스트 거리·항속거리·목적지 선정 규칙은 변경하지 않는다. 배경 성운을 확대 상태에서도 유지하고 미세 구조를 추가한다. UI·발광/투명 효과는 INK v1의 기존 전용 셰이더 예외를 따른다.
- 별 모델과 클릭 판정·현재/방문/선택 표식·항로선은 같은 3D 투영을 사용한다. 거리 기준면과 별의 높이는 가는 수직선으로 연결하고, 확대 범위 안에 옅은 기준 원을 표시한다. 범위 밖 별은 어둡게 유지한다.
- 근처 보기의 초기 각도를 더 기울여 깊이를 읽게 했다. 휠 버튼 드래그 회전은 현재 화면 중심의 은하 기준면 지점을 중심으로 유지한다. 전체 은하 중심만 회전해서 확대 구역을 잃던 동작을 보정했다.
- 화면 밀도 제한·실제 주변 항성계 필터·행성 상세 지연 생성·정지 시 SubViewport 렌더 중단을 유지한다. 확대한다고 은하 전체 상세 모델을 생성하지 않는다.

## 제작

`tools/build_navigation_star.py` → `art/blender/space/navigation_star.blend` → 게임 `assets/models/space/navigation_star.glb`. Blender 5.2.1에서 원본 저장·GLB 내보내기·Cycles 대표 렌더를 확인했다. 기존 전체 은하 재생성 도구도 같은 구형 품질을 출력하도록 맞췄다. 기존 은하 LOD/블랙홀 모델·항로 선택 사운드는 재사용했다. 새 음원은 제작하지 않았다.

## 최소 확인

Godot 4.7.2 / Apple M2 / Metal Forward+ 실제 원정 창에서 동일 격리 세계의 전/후를 비교했다.

- 약 53.1배 근처 보기의 입체 별 26개와 성운, 낮은 시점으로 회전 후 같은 구역의 별 23개 표시.
- 새 3D 투영 위치를 클릭했을 때 같은 항성계 선택, 실제 항로 거리/출발 버튼 표시. 960×640에서도 선택 화면 확인.
- 전체 은하↔근처 전환, 실제 모델 인스턴스의 높이, 정지 후 은하 SubViewport `UPDATE_DISABLED` 확인.
- 회전 보정 중 카메라의 임의 초점 평면을 기준으로 잡아 구역이 사라지는 문제를 재현했다. 화면 중심 광선과 은하 기준면 교차점으로 수정한 후 회전 구역 유지를 재확인했다.
- Blender 렌더·Godot 스크립트/셰이더 로드와 `git diff --check`를 확인했다. 전체 회귀·6인 인터넷·Windows·장시간 성능·모든 은하 시드/최대 확대 위치 전수 검사는 수행하지 않았다.
