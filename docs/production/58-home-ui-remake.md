# 홈 화면 UI/UX 개편

2026-09-08 사용자 요청: 어색한 버튼 배치와 과장된 문구를 자연스럽고 간결하게 정리한다. FIELD v1을 적용하며 현재 기본 진입 장면 `main.tscn`의 홈만 변경했다.

## 적용

- 왼쪽 상단 게임 제목, 왼쪽 하단 플레이 버튼, 그 아래 설정·종료로 정렬했다. 큰 테두리 패널 대신 왼쪽 배경에만 그라데이션을 두어 기존 INK 지형이 보이게 했다.
- 홍보성 소개와 LOCUS·KEPLER 영문 장식을 제거했다. 문구는 `이어하기`, `새 게임`, `함께하기`, `설정`, `종료`로 줄였다. 협동 인원은 별도 `최대 6명` 표식으로 남겼다.
- 최근 싱글 저장 또는 백업이 있을 때만 이어하기를 표시한다. 저장이 없으면 새 게임이 첫 강조 버튼이다. 기존 `solo`·`solo_new`·`multiplayer` 진입 경로와 새 세계의 별도 저장 방식을 사용한다.
- 공통 테마의 색·글꼴을 사용하고 첫 플레이 버튼에 키보드 포커스를 둔다. 설정 F10은 기존 단축키를 유지하고 툴팁으로 표시한다.

## 확인과 제한

Godot 4.7.2 / Metal Forward+의 실제 창에서 1280 폭 및 960 폭 렌더를 확인했다. 작은 창에서 모든 버튼이 UI 영역에 들어가며, 설정 열기·닫기와 함께하기→협동 대기실 진입을 확인했다. `git diff --check`를 통과했다.

첫 실행 중 별도 작업 파일 `vessel_terminal.gd`의 타입 추론 오류가 보고되었으나 해당 파일이 다른 작업에서 수정된 후 최종 실행에는 스크립트 오류가 없었다. 작은 창 검사에서 물리 창 좌표와 논리 UI 좌표를 혼용한 검사식은 같은 UI 좌표끼리 비교하도록 수정했다. 실제 화면 잘림은 없었다.

기존 모델·사운드 파일은 변경하지 않았다. 새 게임 생성·저장 재개 이후 플레이, 소리 청감, 네트워크 접속, 전체 회귀는 이번 홈 변경 확인 범위에 포함하지 않았다. 협동 대기실 자체의 레이아웃은 별도 후속이다.
